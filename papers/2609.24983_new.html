onPanda: Efficient Annotation of On-Policy Alignment Data for LLMs and Agents via Token-Level Correction

온판다: 토큰 단위 교정을 통한 LLM·에이전트용 온-폴리시 정렬 데이터의 효율적 주석 도구

모델 응답을 읽다가 처음 부적절한 토큰을 발견하면 후보 토큰 중 하나를 고르거나 직접 텍스트를 입력해 수정한 뒤 그 지점부터 모델이 이어 생성하게 하는 "위치 파악-교정-이어쓰기" 루프를 핵심으로 하는 주석 도구 onPanda를 제안하여, 수동 후편집 대비 주석 시간을 52% 단축하면서도 모델의 원래 샘플링 분포에 가까운 온-폴리시 정렬 데이터를 효율적으로 생성한다.

한 줄 요약

모델 응답을 읽다가 처음 부적절한 토큰을 발견하면 후보 토큰 중 하나를 고르거나 직접 텍스트를 입력해 수정한 뒤 그 지점부터 모델이 이어 생성하게 하는 "위치 파악-교정-이어쓰기" 루프를 핵심으로 하는 주석 도구 onPanda를 제안하여, 수동 후편집 대비 주석 시간을 52% 단축하면서도 모델의 원래 샘플링 분포에 가까운 온-폴리시 정렬 데이터를 효율적으로 생성한다.

배경 및 문제의식

LLM 정렬 및 에이전트 학습을 위한 고품질 데이터 확보는 여전히 병목이다. 처음부터 응답을 직접 작성하거나 수동으로 후편집하는 방식은 비용이 높고 결과물이 모델 자신의 분포에서 벗어난 오프-폴리시 데이터가 되며, 선호도(preference) 순위 매김 방식은 비용은 낮지만 응답 단위의 거친 감독만 제공하고 모델이 애초에 좋은 응답을 샘플링하지 못하는 경우에는 교정 신호를 주기 어렵다. 에이전트 궤적 주석은 더 까다로운데, 다단계 환경 상호작용이 포함되어 교정 후에는 실제로 도구를 재실행하고 피드백을 받아야 하기 때문이다. 기존 도구들은 실시간 관찰·개입은 가능하지만, 범용 툴콜 형식을 지원하면서 실시간으로 추론과 도구 호출을 모두 교정하고 실행할 수 있는 도구는 부재했다.

핵심 기여

  1. 토큰 단위 교정을 핵심 상호작용으로 삼아 LLM 정렬 데이터와 에이전트 궤적을 효율적으로 주석할 수 있는 도구 onPanda 제안.
  2. 통제된 실험을 통해 onPanda의 주석 효율성과 생성 데이터의 온-폴리시 충실도를 검증하고, 멀티모달·에이전트 궤적 주석 지원을 실증.
  3. onPanda로 주석한 중국어 비전-언어 데이터셋 Panda-CVL과 토큰 단위 교정 능력을 평가하는 벤치마크를 공개.

방법론

생성 요청은 logprobs와 함께 스트리밍되며, onPanda는 각 토큰의 샘플링 확률과 상위 k(기본 20개) 후보를 기록해 토큰 아래에 확률을 색상으로 표시한다(녹색일수록 높은 확률). 주석자가 첫 부적절한 토큰을 찾아 후보 중 하나를 클릭하거나 더블클릭으로 자유롭게 텍스트를 입력하면, 시스템은 해당 지점 이후를 잘라내고 교정된 접두사(prefix)에서 모델이 자연스럽게 이어 생성하도록 요청한다(vLLM의 continue_final_message 활용). 주석 세션은 각 교정이 새로운 노드를 만드는 트리 구조로 저장되며, 모든 중간 버전이 자동 보존되고 각 노드는 조작 로그와 품질 판정(is_good)을 가진다. 같은 프롬프트 하의 긍정/부정 노드 쌍은 응답 단위 선호도 데이터로, 교정 지점의 토큰 쌍은 위치가 정밀하게 짝지어진 토큰 단위 학습 삼중항(부정 샘플, 거부된 토큰과 위치, 선택된 토큰)으로 자동 변환된다. 추론모델·에이전트의 구조화된 메시지(reasoning, content, tool_calls)는 "응답 템플릿" 메커니즘을 통해 모델의 특수 토큰이 포함된 원시 토큰열로 렌더링해 교정 가능하게 하고, 교정 후 다시 구조화된 메시지로 파싱한다. 외부 도구는 MCP를 통해 연결되며 harness_to_mcp 어댑터로 Claude Code, Codex, OpenClaw 등 기존 하네스를 감싸 사용한다.

실험 설정 및 결과

21개 이미지 설명 프롬프트에 대해 3명의 주석자가 라틴 방격 설계로 onPanda, 수동 후편집(POTATO), 선호도 순위(Argilla, 4개 롤아웃 중 순위 매김)를 비교했다. onPanda의 중위 주석 시간은 330초로 POTATO(681초) 대비 51.5% 단축되었고 Argilla(336초)와 비슷했으며, 평균 시간도 POTATO·Argilla 대비 각각 27.5%, 24.7% 낮았다. GPT-5.5 기반 쌍대비교 승률에서도 onPanda가 66.7%로 가장 높았고, 인간 평가에서도 POTATO 대비 54.8%의 선호를 받았다. 온-폴리시 충실도(PPL 기준)에서는 onPanda(1.181, 기준 대비 +0.86%)와 Argilla(1.161, -0.83%)가 재표집 노이즈(약 ±2.8%) 범위 내였던 반면 POTATO는 +36.31%로 크게 벗어났다. onPanda는 SFT 커버리지 100%를 달성하면서 프롬프트당 평균 7.43개의 선호도 쌍을 도출해 Argilla(6.00)와 POTATO(0.95)를 능가했다. NASA-TLX 작업 부하 평가에서도 onPanda(3.1)가 Argilla(5.4), POTATO(6.8)보다 낮았다. 실제 프로덕션 배포에서는 비전·오디오·에이전트 3개 영역에서 총 13만 건 이상의 주석 세션을 통해 약 38.8만 건의 토큰 단위 교정을 생성했으며, 이 중 97.0%가 모델 생성 토큰, 2.1%가 후보 선택, 단 0.9%만 수동 입력으로 확인되어 인간 개입이 희소함을 실증했다. 별도 공개한 Panda-CVL 벤치마크에서 GPT-5.5, GPT-6, Kimi-K2.6 등 최신 모델들을 토큰 단위 교정 과제로 평가한 결과 최고 F1은 17.09%에 불과해, 이 과제가 현재 모델들에게 여전히 어렵다는 점도 확인했다.

한계점

onPanda는 어시스턴트 메시지 접두사에서 이어 생성하는 기능과 top-k 후보 logprobs 반환 기능을 모두 지원하는 추론 API에 의존하는데, 일부 독점 API는 이를 지원하지 않아 해당 모델에는 적용이 어렵다. 또한 효율성과 온-폴리시 이점은 모델 오류가 희소하다는 전제에 기반하므로, 모델이 목표 과제에서 크게 벗어나 교정이 밀집될 경우 이점이 줄어든다. 온-폴리시 특성도 주석 시점의 롤아웃 모델에 상대적이라 다른 모델을 학습시키거나 가중치가 계속 갱신되면 그 이점이 약화된다. 통제 실험 규모도 3명의 주석자와 21개 프롬프트, 단일 롤아웃 모델로 제한적이며, 품질 평가는 주로 LLM 심판에 의존했고, 에이전트 설정에 대한 통제된 실험은 수행되지 않았다. 무엇보다 토큰 단위 교정 데이터의 실제 다운스트림 학습 효과는 아직 학습 실험으로 검증되지 않았다.

시사점

토큰 단위 교정은 위치가 정밀하고 긍정-부정 쌍이 자연스럽게 짝지어지는 세밀한 감독 신호를 제공하면서도 인간 개입을 최소화해 모델의 원래 샘플링 분포를 보존한다는 점에서, SFT·선호도 학습·PRM 학습을 위한 새로운 형태의 효율적인 데이터 수집 방법론으로 자리잡을 잠재력을 지닌다. 저자들은 이를 기반으로 토큰 단위 교정 모델(보상 모델의 토큰 단위 대응물)과 토큰 단위 교정 최적화(DPO의 토큰 단위 대응물) 등 후속 학습 기법 개발과, 주석-학습이 서로를 가속하는 선순환 구조로의 확장을 향후 과제로 제시한다.
