Uncovering Understanding-Generation Synergy in Native Unified Multimodal Models

네이티브 통합 멀티모달 모델에서의 이해-생성 시너지 발견

시각적 이해와 생성을 하나의 모델로 통합한다고 해서 두 능력이 저절로 서로 도움을 주는 것은 아니며, 표현(representation)·과제(task)·시스템(system) 세 층위에서 통제된 실험을 통해 언제 어떻게 이해와 생성이 실제로 시너지를 내는지를 규명한 연구다.

한 줄 요약

시각적 이해와 생성을 하나의 모델로 통합한다고 해서 두 능력이 저절로 서로 도움을 주는 것은 아니며, 표현(representation)·과제(task)·시스템(system) 세 층위에서 통제된 실험을 통해 언제 어떻게 이해와 생성이 실제로 시너지를 내는지를 규명한 연구다.

배경 및 문제의식

최근 통합 멀티모달 모델(Unified Multimodal Models, UMM)들은 시각적 이해와 생성을 한 모델 안에서 동시에 수행할 수 있게 되었지만, 두 기능을 한 인터페이스로 묶었다는 사실 자체가 두 능력이 서로 강화되는지, 용량을 두고 경쟁하는지, 아니면 그냥 공존만 하는지를 보장하지는 않는다. 기존 UMM 연구들은 대규모로 두 기능을 동시에 지원할 수 있음을 보여주었지만, 두 목적함수의 공동 학습이 각 능력에 실제로 어떤 영향을 주는지에 대해서는 제한적이고 때로는 상충되는 근거만 제시해왔다. 저자들은 "이해와 생성은 언제, 왜 서로 돕고 언제 서로 방해하는가"라는 근본 질문에 답하기 위해, 사전학습된 비전 인코더나 이미지 토크나이저/VAE 없이 픽셀을 직접 입력·출력하는 "네이티브(native)" 설정을 채택해 외부 시각적 사전지식의 영향을 배제한 통제된 실험 환경을 구축했다.

핵심 기여

  • 표현·과제·시스템의 세 층위에서 이해-생성 상호작용을 체계적으로 분석하는 통제된 연구를 제시했다.
  • 표현 수준에서 이해와 생성이 서로에게 유용한 학습 신호를 제공할 수 있지만, 그 신호가 실제 성능 향상으로 이어지는지는 아키텍처 설계에 달려 있음을 밝혔다.
  • 기하 추론(geometry reasoning)부터 3D 공간 지능까지 다양한 사례 연구를 통해, 이해와 생성이 동일한 지식이나 능력을 공유할 때 과제 수준의 시너지가 발생함을 확인했다.
  • 이해·추론·생성이 긴밀히 얽혀야 하는 복잡한 과제(추론 기반 이미지 편집)에서, 종단간(end-to-end) UMM이 별도의 이해/생성 모델을 조합한 플래너-실행자 파이프라인보다 우수함을 시스템 수준에서 입증했다.

방법론

사전학습된 Qwen3-1.7B 언어모델을 기반으로, 이미지 패치를 컨볼루션 레이어로 토큰화해 입력하고(비전 인코더 없음), 텍스트는 자기회귀적으로, 이미지 토큰은 플로우 매칭(flow matching)으로 양방향 어텐션을 사용해 생성하는 하이브리드 방식을 채택했다. 표현 수준 분석을 위해 세 가지 라우팅 아키텍처를 비교했다. 1. Dense sharing: 텍스트, 이해용 클린 시각 토큰, 생성용 노이즈 시각 토큰을 모두 동일한 LLM 레이어에 통과시키는 방식. 2. Modality-decoupled MoT: 텍스트는 사전학습된 LLM 브랜치에 남기고, 모든 시각 토큰(이해·생성 모두)을 처음부터 학습하는 별도 브랜치로 분리하는 방식(Mixture-of-Transformers, MoT). 3. Task-decoupled MoT: 이해용 시각 토큰은 언어 브랜치에 남겨 사전학습된 언어 의미와의 직접적 연결을 유지하고, 생성용 노이즈 시각 토큰만 별도의 생성 전용 브랜치로 분리하는 방식. 두 브랜치는 동일한 텍스트 특징에 주의(attention)를 기울여 의미적으로 느슨하게 정렬되며, 편집·인터리브 샘플에서는 이해 브랜치의 맥락 이미지가 공유 어텐션을 통해 생성 브랜치의 조건으로 작동한다. 추가로 학습 혼합의 20%를 이미지 재구성(마스킹된 맥락 이미지를 편집 형태로 복원) 과제에 할당해 두 브랜치 간 연결을 강화했다.

과제 수준 분석에서는 기하 문제 풀이, SVG 이해/생성, 3D 공간 지능이라는 세 도메인에서 이해-생성 쌍을 구성한 데이터로 공동 학습을 진행했다. 시스템 수준 분석에서는 동일한 task-decoupled MoT 체크포인트에서 출발해, (1) 종단간 이해+생성, (2) 이해/계획만, (3) 생성/실행만 하는 세 가지 학습 포맷을 만들어 플래너-실행자 조합과 종단간 모델을 공정하게 비교했다.

실험 설정 및 결과

표현 수준: Dense sharing 모델에서는 공동 학습이 이해 성능(특히 Vision-centric & SI)을 높였지만 생성 성능은 크게 저하되었다. 반대로 modality-decoupled MoT에서는 생성 성능이 크게 향상된 반면 이해 성능이 떨어졌다. 레이어별 프로빙(ImageNet 분류, ADE20K 분할, NYUv2 깊이 추정)과 CKA 분석 결과, 생성 지도학습은 이해용 시각 표현을 풍부하게 만들고, 이해 지도학습은 생성 표현의 언어-비전 정렬을 개선하는 것으로 나타났다. 즉 두 목적함수는 서로에게 유용한 신호를 주지만, 동일한 연산 경로를 강제로 공유시키면 한쪽이 지배적이 된다. 저자들이 제안한 task-decoupled MoT는 이런 비대칭적 저하 없이 이해(General 69.02, OCR 72.09 등)와 생성(GenEval2 82.31 등) 모두에서 균형 잡힌 성능을 달성했다.

과제 수준: (1) 기하 문제 풀이에서 생성 목적함수를 추가하면 Geometry3K, PGPS9K, MathVerse, MathVista 등 4개 벤치마크 모두에서 성능이 향상되었고, 이는 동일 데이터를 텍스트 설명 형식으로 변환한 대조군보다 우수했다. (2) SVG 코드-이미지 양방향 변환 과제에서 공동 학습은 Image→SVG(81.70)와 SVG→Image(86.52) 모두를 개선했으며, SVG 코드만으로 이미지를 "마음속에서 그려보는" 능력(blind VQA 정확도 58.54%, 단일 스텝 예측 이미지 품질)도 향상시켰다. (3) 3D 공간 지능에서는 이해 벤치마크 9개 중 8개에서 성능이 향상(평균 57.15→59.01)되었고, 생성 과제(Spatial-Edit, View Sequence Completion)에서도 오차가 줄고 PSNR/SSIM/LPIPS가 모두 개선되었다.

시스템 수준: 추론 기반 이미지 편집 과제(RISEBench, KRIS-Bench)에서 종단간 UMM은 플래너(이해)-실행자(생성) 파이프라인보다 전반적으로 우수한 결과를 보였다(RISEBench Overall 18.88 vs 16.66, KRIS-Bench Overall 68.33 vs 66.48).

한계점

본 연구는 텍스트에 이산 자기회귀 모델링, 이미지에 연속 확산/플로우 매칭을 결합한 특정 모델링 방식에 초점을 맞추고 있어, 완전 이산(discrete) 또는 완전 자기회귀 방식의 멀티모달 모델링에도 결론이 그대로 적용되는지는 추가 검증이 필요하다. 또한 실험은 주로 저자들이 제안한 task-decoupled 아키텍처에 국한되어 있으며, 공유와 특화 사이의 최적 균형을 이루는 더 넓은 아키텍처 설계 공간(예: 태스크/토큰 조건부 라우팅을 사용하는 MoE)은 충분히 탐색되지 않아 향후 연구 과제로 남아 있다.

시사점

이 연구는 UMM의 가치가 단순히 하나의 인터페이스로 이해와 생성을 지원하는 데 그치지 않고, 적절한 아키텍처적 특화, 공유된 과제 지식, 종단간 최적화를 통해 실질적인 시너지로 전환될 수 있음을 보여준다. 목적함수가 충돌할 때는 연산을 특화하고, 지식과 결정이 공유될 때는 학습과 추론을 통합하라는 구체적인 설계 지침을 제시하며, 향후 세계 모델링이나 정책/행동 학습처럼 여러 능력이 공통된 잠재 지식을 공유하는 더 넓은 통합 학습 시나리오로 확장될 수 있는 가능성을 시사한다.
