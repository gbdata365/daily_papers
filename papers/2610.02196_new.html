InterEvolve: Test-Time Evolution of Reward Programs for Humanoid Loco-Manipulation

InterEvolve: 휴머노이드 보행-조작을 위한 보상 프로그램의 테스트 시점 진화

고정된(재학습하지 않는) 휴머노이드 전신 제어기를 그대로 둔 채, LLM 에이전트가 다단계 보상 프로그램의 구조를 반복적으로 수정하고 수치 최적화기(CMA-ES)가 그 상수를 조정하는 테스트 시점 진화(test-time evolution)를 통해, 학습 데이터에 없던 새로운 보행-조작(loco-manipulation) 과제를 재학습 없이 수행하게 만드는 프레임워크를 제안한다.

한 줄 요약

고정된(재학습하지 않는) 휴머노이드 전신 제어기를 그대로 둔 채, LLM 에이전트가 다단계 보상 프로그램의 구조를 반복적으로 수정하고 수치 최적화기(CMA-ES)가 그 상수를 조정하는 테스트 시점 진화(test-time evolution)를 통해, 학습 데이터에 없던 새로운 보행-조작(loco-manipulation) 과제를 재학습 없이 수행하게 만드는 프레임워크를 제안한다.

배경 및 문제의식

최근 인간 동작 데이터로 학습된 휴머노이드 전신 제어기는 다양한 보행 및 접촉이 많은 조작(loco-manipulation) 능력을 폭넓게 갖추게 되었지만, 개방형 환경에서 로봇은 학습 시 미처 다루지 못한 과제와 장면을 마주하게 된다. 예를 들어 상자를 밀고, 들고, 나르는 법을 배운 제어기는 상자를 다른 면으로 뒤집는 시연 데이터가 없더라도 해당 동작에 필요한 움직임 자체는 이미 보유하고 있을 수 있다. 문제는 이런 잠재 능력을 재학습 없이 어떻게 끌어내느냐에 있다. 기존의 과제 인터페이스(모션 레퍼런스, 목표 상태, 사전 정의된 스킬 라벨 등)는 접촉이 많고 다단계로 구성된 미묘한 상호작용을 표현하기 어렵다. 보상 함수는 이런 상호작용을 표현하는 데 더 유연하지만, 전통적으로는 보상을 한 번 바꿀 때마다 새 정책을 처음부터 다시 학습해야 해서 많은 후보를 빠르게 시도하기 어렵다는 근본적 제약이 있었다.

핵심 기여

  • 과제별 연산을 학습이 아니라 테스트 시점의 진화로 옮기는 프레임워크를 제안: LLM 에이전트가 문맥 내에서(in-context) 보상 프로그램을 작성·수정하고, 고정된 재사용 가능 제어기가 이를 실행한다.
  • 물체를 인식하는(object-aware) forward-backward(FB) 행동 기반 모델을 개발하여, 몸체에 대해서만 학습된 기존 FB 모델이 물체 상태를 구분하지 못하는 한계를 해결하고 보상 목표를 전신 상호작용 행동으로 변환.
  • 다단계 보상(완료 조건과 조정 가능한 상수를 포함한 staged reward)으로 과제를 표현하는 "보상 프로그램" 개념을 정의하고, LLM 에이전트의 구조 수정(외부 루프)과 CMA-ES의 상수 조정(내부 루프)을 결합한 2단계 진화 알고리즘을 설계.
  • 레퍼런스 추적 및 목표 조건부 과제에서 보상 설계와 축적된 경험(스킬 라이브러리)이 성능에 미치는 영향을 정량적으로 평가하고, 실제 Unitree G1 로봇에 온보드 인식만으로 자율 배포하여 검증.

방법론

InterEvolve는 과제를 언어 요청 ℓ과 장면 맥락 c로 정의하고, 고정된 사전학습 제어기 π(a|o,z)가 잠재 프롬프트 z에 따라 행동을 생성하는 구조를 사용한다. 에이전트는 이 둘을 "보상 프로그램" P를 통해 연결하는데, P는 각 단계(stage)마다 보상 코드 r_j와 완료 조건 g_j, 그리고 조정 가능한 상수 θ로 구성된 순서 있는 단계들의 집합이다. 예를 들어 상자를 발로 차는 과제는 "발로 밀어 차기" 단계와 "정지 상태로 안정화" 단계로 나뉘고, 각 단계는 자체 보상식과 다음 단계로 넘어갈 조건을 가진다.

이 프로그램을 매 후보마다 새로 정책을 학습하지 않고 실행하기 위해, 저자들은 forward-backward(FB) 행동 기반 모델("모터 모델")을 사용한다. FB 모델은 임의의 보상 함수를 그 정책을 유도하는 잠재 프롬프트(latent)로 변환할 수 있는데, 기존 FB 모델(BFM-Zero)은 몸체 상태만 관측하여 물체 목표가 다른 보상들이 동일한 행동으로 수렴해버리는 한계가 있었다. 이를 해결하기 위해 액터, forward map, backward map 세 네트워크 모두에 물체 특징(위치, 방향, 속도, 신체 부위-물체 표면 간 거리 벡터 등)을 읽는 학습 가능한 "물체 잔차(object residual)"를 추가하고, 몸체 관련 사전학습 가중치는 동결한 채 이 잔차만 대규모 인간-물체 상호작용(HOI) 데이터로 학습시켰다.

진화 과정은 두 개의 중첩 루프로 구성된다. 외부 루프에서는 매 라운드마다 LLM 에이전트(DeepSeek-V4-Flash)가 과제 설명, 장면 맥락, 검증 기준, 현재 최상위 프로그램의 실행 피드백, 그리고 이전에 검증된 프로그램들을 모은 "스킬 라이브러리"를 입력받아 여러 개의 새로운 프로그램 구조를 제안한다. 내부 루프에서는 이렇게 제안된 각 구조에 대해 CMA-ES가 상수(가중치, 임계값 등)를 수치적으로 조정한다. 모든 후보는 병렬 시뮬레이션 환경(192개)에서 평가되며, 현재 최상위 프로그램보다 노이즈 수준을 넘어서는 유의미한 개선이 있을 때만 교체된다. 매 라운드의 피드백은 기준(criterion)별, 단계별로 세분화되어 다음 에이전트 호출에 제공되어 수정이 구체적인 실패 지점을 겨냥하도록 한다. 검증된 최종 프로그램은 스킬 라이브러리에 저장되어 이후 과제에서 재사용·조합될 수 있다.

실험 설정 및 결과

실험은 OMOMO(대형 물체 전신 조작)와 GRAB(소형 물체 손 조작) 데이터로 사전학습한 FB 모델을 Unitree G1(고무 손 및 Inspire 손 버전)에 리타겟하여 Isaac Lab 시뮬레이터에서 수행되었다.

  • 레퍼런스 추적: 물체 인식 FB 모델은 추적 전용으로 학습된 전문 베이스라인(ULTRA)에 근접한 성공률을 보였으며, 몸체만 보는 BFM-Zero는 대부분의 클립에서 물체를 놓쳐 물체 인식 사전학습의 효과를 확인했다. 에이전트가 찾은 드리프트 보정 보상을 적용한 "Evolving" 버전은 오히려 ULTRA보다 높은 성공률(60%→72%)을 기록했다.
  • 범용 과제(8개 과제군: 마크로 밀기, 여러 높이로 나르기, 물체 뒤집기, 발로만 상호작용, 지지대 위로 들어올리기, 좁은 통로·장애물 통과 등): 사람이 작성한 보상이나 에이전트가 한 번 작성한 초기 프로그램은 대부분 실패했고, CMA-ES로 상수만 조정해도 개선은 제한적이었다(성공률 18~34.6%). 반면 InterEvolve의 전체 진화 과정은 성공률을 86.5%, 획득 기준 비율(Earned)을 95.6%까지 끌어올려, 동일하게 조정된 고정 프로그램 대비 성공률을 2배 이상 높였다.
  • 어블레이션: 단일 단계로 강제했을 때 성능 하락폭이 가장 컸고(구조화된 다단계 분해의 중요성), 수치 조정(CMA-ES)을 제거한 경우도 큰 하락을 보였다. 목표 지향적 수정(기존 프로그램 보완) 대신 매번 처음부터 재작성하거나, 다중 시나리오 평가 대신 단일 시작점만 사용한 경우도 성능이 떨어졌다. 라운드가 진행될수록 성공률이 대체로 증가했으나 완전히 단조롭지는 않았다(한 기준을 고치면 다른 기준이 깨지는 경우 존재).
  • 스킬 라이브러리 재사용: 이전에 검증된 프로그램들의 전체 라이브러리를 사용할 때 재배치·쌓기·나르기-놓기-차기 등 복합 과제에서 가장 높은 성공률을 보였고, 관련 접촉 모드를 포함하지 않는 부분 라이브러리(나르기 전용)는 제한적인 도움만 주었다. 즉 재사용의 효과는 단순히 경험이 저장되어 있는지가 아니라 해당 과제에 필요한 접촉 모드를 포함하는지에 달려 있었다.
  • 실제 로봇 배포: 온보드 카메라와 FoundationPose를 이용한 6D 물체 자세 추정만으로, 시뮬레이션에서 진화시킨 프로그램을 물리적 Unitree G1에서 자율적으로 실행해 상자 차기·밀기 과제를 성공적으로 수행했으며, 6개의 상자를 순서대로 배치하는 장기 과제(12단계 연속 실행)도 시연했다.

한계점

저자들은 킥(kick) 같은 학습 데이터에 드문 동작은 강한 전신 협응이 필요해 가장 어려운 과제군으로 남아있다고 밝혔다. 또한 완전한 성공률(SR)은 모든 기준을 동일 롤아웃에서 동시에 만족해야 하므로 한 기준의 개선이 다른 기준을 해칠 수 있어 라운드가 진행되어도 단조롭게 증가하지 않는 경우가 있었다. 계산 비용 측면에서는 시뮬레이션 롤아웃이 LLM 토큰 생성보다 훨씬 많은 시간을 차지해 전체 진화 속도의 병목이 되며, 저자들은 더 빠른 시뮬레이터(mjlab 등)로 대체하면 속도를 크게 개선할 수 있을 것이라 언급했다. 스킬 라이브러리의 재사용 효과도 해당 과제에 필요한 접촉 모드를 포함하는 경험이 저장되어 있을 때만 발휘되어, 완전히 새로운 접촉 모드가 필요한 과제에는 여전히 처음부터 진화가 필요하다.

시사점

이 연구는 로봇 지능의 "추론(계획)"과 "제어(실행)"를 서로 다른 시간 축에서 개선하는 새로운 역할 분담을 제시한다. 행동 기반 모델은 한 번 학습된 후 고정되고, 과제별 지식은 모델 가중치가 아니라 언어 모델이 읽고 수정하고 실행 결과로 검증할 수 있는 보상 프로그램의 형태로 외부에 존재한다. 이는 언어 모델의 테스트 시점 스케일링(더 많은 추론 연산으로 더 나은 해를 찾는 패러다임)을 물리적 로봇 제어로 확장한 사례로 볼 수 있으며, 로봇이 실제 실행 결과에 기반해 자신의 요구사항을 점진적으로 교정한다는 점에서 가정이 아닌 관측에 기반한 추론이라는 특징을 가진다. 보상 프로그램과 스킬 라이브러리가 검사 가능하고 재사용 가능한 형태로 축적된다는 점은, 향후 휴머노이드가 반복적인 실세계 시행을 통해 스스로 능력을 확장해 나가는 방향에 실용적인 토대를 제공한다.
