MIRIX-2.0: Multi-Agent Memory System

미릭스-2.0: 멀티에이전트 메모리 시스템

한 줄 요약

LLM 에이전트의 장기 기억을 완전한 타입별 기록으로 유지하면서도 명시적 예산 하에 검색이 가능하게 하는 "출처 하이퍼그래프(provenance hypergraph)" 기반 메모리 시스템 MIRIX-2.0을 제안하고, 정확성·실용성·효율성을 동시에 달성.

배경 및 문제의식

LLM 에이전트가 장기간에 걸쳐 작동하려면 대화나 과제 수행 과정에서 쌓인 정보를 세션을 넘어 기억해야 한다. 기존 메모리 시스템은 세 가지 요구사항(정확성, 실용성, 효율성) 중 적어도 하나를 포기하는 경향이 있었다. 기록을 추출된 사실이나 요약으로 압축하는 시스템은 컴팩트하지만 세부사항을 영구적으로 잃고, 모든 기록을 그대로 보관하는 시스템은 정보를 잃지 않지만 히스토리가 늘어날수록 검색 효율이 떨어지며, 그래프 기반 메모리는 이항(binary) 트리플로 n항(n-ary) 사실을 쪼개면서 사실 간 연결 관계를 잃는다는 문제가 있었다.

핵심 기여

  • 완전한 기록을 그대로 유지하는 시스템-오브-레코드 역할을 하는 6종의 타입별 메모리 에이전트(에피소드, 의미, 절차, 핵심, 리소스 볼트 등) 설계.
  • 에피소드·의미 기록을 자신을 인용하는 n항 프레임으로 인덱싱하는 "출처 하이퍼그래프"를 도입해, 검색 시 조사하는 근거량이 히스토리 길이에 비례해 늘어나지 않도록 함(명시적 예산 하 검색).
  • 쓰기 경로 밖에서 동작하며 중복 앵커를 병합하고(기록을 재작성하지 않음) 과제 세션을 스킬로 증류하는 오프라인 통합 메커니즘 "AutoDream" 제안.
  • 파인튜닝 없이 폐쇄형·개방형 모델 모두에서 동작하며 공개 코드를 제공.

방법론

질의가 들어오면 Meta Memory Manager가 입력을 타입별 쓰기 에이전트에 라우팅해 에피소드/의미/절차 메모리 등 증거 평면(evidence plane) Pu를 채운다. 출처 하이퍼그래프 Gu는 이 증거를 자신의 출처 행을 인용하는 n항 프레임으로 인덱싱한다. 검색 시 플래너가 질의에서 명명된 앵커로부터 그래프를 탐색하되, 사실·기저 회상·관계 인용 각각에 명시적 행 수 예산을 두어 비용을 제한한다. AutoDream은 쓰기 경로와 분리되어 비동기로 동작하며, 의미 메모리에서는 코사인 유사도(≥0.86)로 후보를 추려 LLM 검증자가 동일 개체 여부를 판정해 중복 앵커를 병합하고, 절차 메모리에서는 과제 세션의 성공/실패를 평가해 재사용할 경험과 피할 경험을 구분한 스킬을 생성·수정한다.

실험 설정 및 결과

5개 QA 벤치마크 중 4개에서 비교 대상 중 가장 높은 정확도를 기록했으며, LoCoMo에서 91.4%, LongMemEval-S에서 72.6%(최강 베이스라인 대비 +14.3점)를 달성했다. AutoDream을 끈 상태에서도 단일·다중 홉 문서 QA에서 HyperMem 대비 각각 +31.0, +22.0점의 개선을 보였다. 절차적 메모리로서는 ALFWorld와 WebShop에서 비교 대상 메모리 기법 중 가장 높은 평균 성공률을 달성했고, MetaClaw-Bench에서 GPT-5.2와 함께 49.2%를 기록해 MetaClaw의 스킬 라이브러리(44.0%)를 앞섰다. AutoDream을 끈 상태에서는 5개의 시간 측정 벤치마크 모두에서 HyperMem보다 빠르게 답했고, WebShop에서는 메모리 기법 중 가장 적은 토큰을 소비했다.

한계점

저자들이 직접 명시한 한계로, 어블레이션은 구성요소를 그룹 단위로 추가하는 방식이어서 n항 프레임, 인용된 출처 행, 발생 식별자, 답변 시점 검증, 그리고 절차 메모리의 판정자·증류기·큐레이터 각각의 개별 효과를 분리하지 못했다. 또한 사용자 메모리 결과는 단일 실행에 기반하며 일부는 LLM 심판으로 채점되었고, 일부 베이스라인 수치는 원 저자가 보고한 값을 그대로 사용했다.

시사점

저자들은 완전한 기록을 시스템-오브-레코드로 유지하고 그래프는 단지 제한된 인덱스 역할만 하도록 하며, 통합(consolidation)이 "무엇이 증거인지"가 아니라 "증거들이 어떻게 연결되는지"만 바꾸도록 설계하면 메모리 레이어가 정확성·실용성·효율성을 동시에 달성할 수 있음을 시사한다. 다만 윤리적 측면에서, 사용자 동의 없는 프로파일링에 사용되어서는 안 되며, 저장된 내용이 모델에 전송되므로 민감 정보 보호와 사용자 열람·수정·삭제 권한이 뒷받침되어야 하고, 고위험 환경에서는 학습된 스킬과 병합된 개체를 사람이 주기적으로 검토해야 한다고 강조한다.
