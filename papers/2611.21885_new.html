Language Models Can Rewrite Their Own Weights

언어모델은 스스로 자신의 가중치를 다시 쓸 수 있다

공개된 27B 언어모델에게 자신의 가중치, 채점된 연습문제 답안, 자기 자신을 실행할 수 있는 능력을 주었을 때, 그라디언트나 학습 과정 없이 오직 자기 추론만으로 자신의 가중치를 직접 읽고 고쳐 써서(self-rewriting) 새로운 문제에서 성능을 높이고, 손상된 자기 복제본까지 스스로 수리할 수 있음을 처음으로 보인다.

한 줄 요약

공개된 27B 언어모델에게 자신의 가중치, 채점된 연습문제 답안, 자기 자신을 실행할 수 있는 능력을 주었을 때, 그라디언트나 학습 과정 없이 오직 자기 추론만으로 자신의 가중치를 직접 읽고 고쳐 써서(self-rewriting) 새로운 문제에서 성능을 높이고, 손상된 자기 복제본까지 스스로 수리할 수 있음을 처음으로 보인다.

배경 및 문제의식

현재 언어모델은 한 번 학습되면 가중치가 고정(frozen)되고, 성능을 다시 높이려면 별도의 학습 파이프라인·대규모 클러스터가 필요하거나, 사용자가 프롬프트를 바꾸는 것(대화가 끝나면 사라짐) 정도만 가능하다. 반면 인간은 학습과 추론을 분리하지 않고 매 성공·실패로부터 스스로를 바꾼다. 선행 연구는 더 강력한(frontier) 모델이 훨씬 작은 모델의 가중치를 편집하는 것을 보였지만, "모델이 자기 자신의 가중치를 스스로 편집하는 것"은 그 연구에서조차 향후 과제로만 언급되었다. 저자들은 이 질문, 즉 모델이 자신의 실패를 스스로 진단하고 자신의 가중치를 직접 고쳐 쓸 수 있는지를 처음으로 검증한다.

핵심 기여

  • '자가 재작성(self-rewriting)'이라는 새로운 패러다임 제시: 모델이 자신의 가중치·답안·은닉 상태(hidden state)에 접근할 수 있지만 그라디언트 계산이나 어떤 형태의 학습도 금지된 환경에서, 모델 스스로 자신의 가중치에 수정(edit) Δ를 써넣는 세션을 설계.
  • 27B 모델의 자가 수정이 한 번도 보지 못한 490개 문제에서 정확도를 6.6%p 높였고(사전에 고정된 paired test로 통계적으로 유의미), 연속 8회 세션에 걸쳐 모델이 자신의 수정을 연습문제로 검증 후 제출/철회를 결정하며 성능이 꾸준히 개선됨을 보임.
  • 모델이 (한 블록의 가중치가 노이즈로 손상된) 자신의 복제본을 그라디언트 학습 없이, 원본의 손상되지 않은 가중치를 전혀 참조하지 않고 스스로 복구함을 보임. 텍스트 수학 문제만으로 찾아낸 수리법이 전혀 다른 영역인 이미지 과제 6종에도 전이되어 원본 모델 정확도의 83%까지 회복.
  • 동일 모델 패밀리의 네 크기(2B/4B/9B/27B)를 같은 과제·도구로 비교한 결과, 이 능력이 규모에 따라 창발(emergence)함을 처음으로 입증: 2B는 아예 수정을 시도하지 못하고, 4B·9B는 무작위적인 수정으로 자신을 망가뜨리며, 27B만 자신을 개선하고 손상된 복제본도 수리함.

방법론

모델 Mθ는 이름별 텐서 집합 θ=(Wk)로 구성되며, 수정 Δ는 같은 모양의 텐서 일부를 교체하는 것으로 정의된다(식 1~2). 모델은 연습문제 집합 P에서 자신의 채점된 답안으로 시작 진단을 받고, 턴(turn) 단위로 진행되는 세션에서 매 턴마다 ① CPU 상 Python으로 가중치 텐서를 직접 읽고 쓰는 Code(예: 특정 방향 u를 따라 쓰는 정도를 줄이는 W − αuu⊤W 연산), ② 수정 전/후 모델에 같은 문제·같은 시드로 답하게 해 쌍을 비교하는 paired test(Generate), ③ 자신이 고른 텍스트에 대한 은닉 상태를 보는 Read 중 하나의 행동을 선택한다. 세션은 정해진 횟수의 순전파(forward pass, B=20)와 코드 실행(C=200)을 넘기거나 시간/턴 제한에 도달하면 종료되며, 최종적으로 디스크에 저장된 수정안이 제출된다. 그라디언트 계산이나 옵티마이저 호출, GPU 사용, 모델 로딩/네트워크 접근은 모두 차단되어 있어 가중치의 모든 변경값은 순수히 모델 자신의 추론으로 작성된 것이다. 손상된 복제본 실험에서는 한 레이어의 MLP 출력 행렬 W의 연속된 행 블록을 표준편차 σ의 λ배 크기 가우시안 노이즈로 덮어쓴 뒤, "일부 값이 손상되었다"는 사실만 알려주고 모델이 스스로 손상 위치를 찾아 복구하게 했다.

실험 설정 및 결과

Qwen3.5 계열 2B/4B/9B/27B 네 크기 모델에 동일한 과제·도구를 제공해 비교했다. 27B 모델은 두 가지 프로토콜 모두에서 자신의 수정으로 성능을 향상시켰다: (1) 490개의 미공개 보류(held-out) 문제에서 57.2%→63.8%, 61.3%로 유의미하게 향상(사전에 고정한 평가에서 p<10⁻⁵), 토큰 한도 초과로 답을 못 내는 비율도 감소; (2) 연속 8회의 세션 동안 매 세션이 연습문제로 자신의 수정을 검증한 뒤 제출 여부를 결정했는데, 5번은 스스로 철회하고 2번(세션 2, 8)은 유의미한 개선을 제출해 전체적으로 성능이 단조롭게 상승. 손상된 복제본 복구 실험에서는 27B가 손상된 행렬을 정확히 찾아내 0.0%→33.0%로 복구했고(원본 모델은 58.5%), 이 텍스트 기반 수리 능력이 ScreenSpot-v2를 포함한 6개 이미지 벤치마크(MMStar, HallusionBench, POPE 등)에서도 7.3%→70.2%로 전이되어 원본 모델 정확도의 83%를 회복했다(손상된 복제본의 약 9.6배). 반면 2B 모델은 수정을 전혀 시도하지 못했고, 4B·9B 모델은 무작위적 수정으로 자신을 파괴했다(예: 9B는 자신의 가중치 수정 후 47.5%→0.0%로 붕괴).

한계점

저자들이 명시한 바로는, 자가 재작성 능력이 모델 크기에 강하게 의존하며 더 작은 모델(2B·4B·9B)에서는 작동하지 않거나 오히려 모델을 손상시킨다. 또한 수정 시 입력 임베딩, 마지막 정규화층, 출력층에 대한 편집과 텐서 전체를 단순 재조정(temperature 변화와 유사한 효과)하는 편집은 명시적으로 차단되어 있어, 실험이 통제된 제약 조건 아래에서만 이루어졌다. 세션은 제한된 순전파·코드 실행 횟수 및 시간/턴 한도 내에서 진행되므로 실제 무제한적 자가 개선 상황과는 차이가 있다. 저자들은 이 경로가 재귀적 자기개선(recursive self-improvement)으로 가는 하나의 단계일 수 있음을 강조하면서도, 모델이 스스로 만든 모든 수정을 사람이 과제 성능뿐 아니라 안전성 측면에서도 평가·확인하는 "사람이 참여하는(people in the loop)" 절차가 반드시 필요하다고 명시적으로 경고한다.

시사점

이 연구는 학습(training)과 추론(inference)의 경계가 지능의 본질적 속성이 아니라 현재 도구의 한계일 수 있음을 시사한다. 테스트-타임 스케일링과 달리 자가 재작성의 이득은 매 응답마다 추가 연산 없이 가중치에 영구히 기록되며, 학습과 달리 그라디언트나 옵티마이저, 별도의 학습 인프라가 전혀 필요 없이 서빙(serving)과 동일한 순전파만으로 동작한다. 이는 "대화를 통해 모델을 더 좋게 만드는" 새로운 개선 경로를 열 수 있으며, 특히 훈련 환경과 다른 상황에 놓인 임베디드 에이전트(로봇 등)가 에피소드 사이에 스스로를 수정해 나가는 식의 응용 가능성을 제시한다. 동시에 능력이 모델 규모에 따라 창발한다는 발견은 더 강력한 모델일수록 자가개선 능력도 커질 수 있다는 가능성과 함께, 재귀적 자기개선에 대한 안전성 검토 및 인간 감독의 필요성을 동시에 제기한다.
