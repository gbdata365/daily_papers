Tev: Scaling Long-Horizon Agentic Environments with Dense Progress Rewards

테브: 조밀한 진행도 보상을 통한 장기호라이즌 에이전트 환경 스케일링

수 시간~수일 단위로 자율 수행해야 하는 '장기호라이즌(long-horizon)' 에이전트 작업을, 정답이 보장된 '잠재 세계(latent world)'로부터 역으로 생성하고 매 스텝마다 조밀한 진행도 보상을 부여하는 학습 레시피를 제안해, 오픈소스 모델의 장기 과제 수행 능력을 크게 끌어올린 연구다.

한 줄 요약

수 시간~수일 단위로 자율 수행해야 하는 '장기호라이즌(long-horizon)' 에이전트 작업을, 정답이 보장된 '잠재 세계(latent world)'로부터 역으로 생성하고 매 스텝마다 조밀한 진행도 보상을 부여하는 학습 레시피를 제안해, 오픈소스 모델의 장기 과제 수행 능력을 크게 끌어올린 연구다.

배경 및 문제의식

최근 LLM 에이전트는 수 시간에서 수일간 자율적으로 작업을 수행하는 능력(장기호라이즌 작업)이 중요해지고 있으며, 이는 자동화된 연구 발견이나 재귀적 자기개선(RSI)의 핵심 전제다. 그러나 오픈소스 모델은 이런 장기 작업에서 여전히 취약한데, 그 이유는 (1) 학습 데이터 부족과 (2) 검증된 학습 레시피 부재다. 기존 공개 데이터셋(SWE-Smith, TMAX, Endless Terminals, CLI-Gym, SETA, Terminal-Universe 등)은 대부분 PR 단위 수정이나 짧은 터미널 세션 수준이며, 합/불합(pass/fail)만 알려주는 희소 보상만 제공한다. 반면 진짜 장기호라이즌 벤치마크(ALE, Terminal-Bench 등)는 사람이 직접 만든 소수의 평가셋으로만 존재해 학습에는 쓸 수 없다. 또한 GRPO 같은 그룹 상대 강화학습(RL)에서는 한 그룹의 모든 롤아웃이 실패하면 어드밴티지가 전부 0이 되어 학습 신호 자체가 사라지는 '보상 기아(reward starvation)' 문제가 있으며, 이는 정책이 약한 학습 초반의 장기 과제에서 가장 심각하다.

핵심 기여

  • latent-world-first synthesis: 정답이 확정된 '잠재 세계'로부터 거꾸로 장기호라이즌 작업을 구성하는 파이프라인을 제안해, 정확한 검증, 난이도 조절, 중간 단계의 진행도 보상을 동시에 확보했다.
  • Tev-Gym: 소프트웨어 공학, 데이터 엔지니어링, AI/CS 연구, 수학, 운영연구, 보안·포렌식, 인프라 관리 등 7개 도메인에 걸쳐 1,170개의 검증된 장기호라이즌 작업 환경으로 구성된, 조밀한 보상을 제공하는 최초의 장기호라이즌 에이전트 학습 데이터셋을 공개했다.
  • Tev-27B / Tev-9B: Tev-Gym과 progress-potential reward shaping(PPRS)으로 학습한 모델이 ALE-CM, Terminal-Bench(TB) 3.0/4.0/2.1 등에서 우수한 성능을 보였고, 동일 레시피를 더 큰 베이스 모델(GLM-5.3-Flash)에 적용한 Tev-320B도 성능 향상을 확인했다.

방법론

작업 생성은 "Stage 0~6"의 단계로 이뤄진다. 먼저 7개 도메인별로 시드가 되는 과제 사양을 수집/작성한다(Stage 0). Stage 1에서는 시드와 난이도(scale tier)로부터 완전하고 정답이 보장된 '잠재 세계' W(예: 소매 창고의 고객·상품·거래 데이터 전체)를 절차적으로 생성하고 불변 조건을 검증하며, 동시에 어떤 레코드/필드를 나중에 손상시킬지 정의하는 결함 계획(defect plan)도 함께 뽑는다. Stage 2에서는 이 세계의 작업 흐름을 단계 간 의존관계를 가진 방향성 비순환 그래프(DAG)로 컴파일하며, 이 DAG의 critical path가 작업의 '호라이즌(horizon)'과 진행도 전위(potential)의 뼈대를 결정한다. Stage 3은 W를 에이전트가 보게 될 CSV/TSV/JSON/SQLite 등 실제 입력 파일로 렌더링하고, 원본 W로 다시 복원 가능한지 검증한다. Stage 4에서는 Stage 1의 결함 계획을 적용해 스키마 드리프트, 중복/누락 레코드, 범주 드리프트 등 역전 가능한 손상을 주입해 에이전트가 받는 초기 작업공간(s0)을 만든다. 손상이 역전 가능하므로 s0만 보고도 정답이 되는 W를 정확히 역산할 수 있다. Stage 5~6에서는 에이전트가 보는 공개 사양(프롬프트, 입력, 요구되는 산출물, 허용 도구)과, 채점에만 쓰이는 비공개 검증 스위트(의미보존 변환, 그럴듯하지만 틀린 상태에 대한 반사실적 검사 등)를 각각 만든다.

보상 설계 측면에서는, 각 환경의 산출물을 체크 가능한 노드들의 가중합으로 표현하는 '진행도 계약(progress contract)' Φ를 정의한다. 각 노드는 선행 조건이 모두 만족되어야 점수를 얻는 선행조건-게이트 방식이며, Φ는 검증기가 작업을 승인할 때 정확히 1이 되고, 아무 작업도 안 했을 때 정확히 0이 되도록(익스플로잇 방지), 단조 증가하도록(진행 타당성), 검증기·참조 솔버와 코드가 분리되도록(역할 독립성) 설계된다. 이 Φ의 스텝별 변화량(진행도-전위 보상 형성, PPRS)을 보상에 추가해 R(τ) = 1[합격] + λ·Φ(종료 상태)의 형태로 희소 보상을 보강한다(λ=0.25). 이를 통해 그룹 내 모든 롤아웃이 실패하더라도, 서로 다른 깊이까지 진행한 롤아웃 간에 0이 아닌 어드밴티지가 생겨 GRPO 기반 RL의 보상 기아 문제를 완화한다. 학습은 DPPO로 Qwen3.5-9B와 Qwen3.8-27B에 적용했으며, 27B는 전체 코퍼스, 9B는 unit 난이도 티어의 264개 작업 서브셋을 사용했다.

실험 설정 및 결과

평가는 Agents' Last Exam(ALE)의 computing-and-math 서브셋(ALE-CM)을 주요 인도메인 벤치마크로, Terminal-Bench(TB) 3.0/4.0의 CM 서브셋과 TB 2.1을 제로샷 일반화 벤치마크로 사용했다. ALE-CM에서 Tev-9B는 Qwen3.5-9B 대비 Pass@5를 83% 향상시켰고, Tev-27B는 Qwen3.8-27B 대비 65% 향상되어 GPT-6 Astra, Claude Opus 5와 Pass@5 기준 대등한 수준(0.28)에 도달했다. ALE 전용 데이터로만 학습했음에도 TB 3.0/4.0에서 Pass@1이 각각 56%, 150% 향상되었고 GLM 5.2와 Gemini 3.7 Flash를 능가했다. 또한 제로샷으로 평가한 중간 호라이즌 벤치마크 TB 2.1에서 Tev-9B는 Pass@1을 28% 끌어올렸고, Tev-27B는 Pass@1 0.794로 Claude Opus 4.8 수준의 성능을 보였다. 동일 레시피를 GLM-5.3-Flash에 적용한 Tev-320B는 TB 3.0/4.0 Pass@1을 각각 35%, 28% 향상시켰으며, TB 4.0에서는 Claude Opus 5, Claude Fable 5, GPT-5.6(sol)에만 뒤처지는 최고 수준의 오픈소스 성능을 기록했다. 어블레이션 결과, latent-world 기반 생성과 숨겨진 정답 검증을 제거한 변형(공개 뷰 검증기, 프롬프트 우선 베이스라인)은 베이스 모델 대비 개선이 없었고, PPRS는 터미널 전용 희소 보상이나 단순 가산적 보상보다 더 나은 성능-학습 효율 균형을 보였다.

한계점

현재 연구는 합성 터미널 환경에 초점을 맞추고 있으며, Tev 모델과 최상위 프런티어 에이전트(예: Claude Opus 5) 사이에는 여전히 상당한 성능 격차가 남아 있다. 새로운 작업 흐름을 지원하려면 추가적인 환경 구성 요소의 작성과 검증이 필요해 확장에 수고가 든다. 저자들은 향후 과제로 더 강력한 오픈소스 모델로 데이터 생성 과정을 단순화하고, 도메인 커버리지를 확장하며, 사람이 만든 단계별 라벨이나 LLM 판정자 없이도 재현 가능한 RL을 가능하게 하는 것을 꼽았다.

시사점

이 연구는 "정답이 보장된 잠재 세계로부터 역으로 작업을 생성한다"는 아이디어로, 장기호라이즌 에이전트 학습에서 데이터 품질(정확한 검증)과 학습 신호의 조밀함(진행도 보상)을 동시에 해결할 수 있음을 보여준다. 특히 희소한 터미널 보상만으로는 학습 초반 약한 정책에서 그룹 전체가 실패해 그래디언트가 소실되는 문제를, 중간 진행 상태를 측정하는 보상 형성으로 완화할 수 있다는 점은 다른 장기 에이전트 RL 파이프라인에도 폭넓게 적용 가능한 시사점을 준다. 또한 동일 레시피가 서로 다른 크기의 베이스 모델(9B, 27B, 320B급)에 전이되어 일관된 개선을 보인다는 점은 이 방법론의 범용성을 뒷받침한다.
