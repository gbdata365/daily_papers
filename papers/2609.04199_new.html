Compile by Training: Turning Natural-Language Specifications into Local Neural Functions

컴파일 바이 트레이닝: 자연어 명세를 로컬 신경망 함수로 컴파일하기

자연어로 작성한 함수 명세를 교사 모델이 생성한 예시로 한 번 학습시켜, 이후에는 대형 모델 호출 없이 로컬에서 반복 실행 가능한 소형 신경망 함수로 "컴파일"하는 방법을 제안한다.

한 줄 요약

자연어로 작성한 함수 명세를 교사 모델이 생성한 예시로 한 번 학습시켜, 이후에는 대형 모델 호출 없이 로컬에서 반복 실행 가능한 소형 신경망 함수로 "컴파일"하는 방법을 제안한다.

배경 및 문제의식

이메일 분류처럼 규칙으로 구현하기는 애매하지만 매번 대형 원격 LLM을 호출하기에는 너무 좁고 빈번한 텍스트 함수들이 존재한다. 매 호출마다 원격 모델을 쓰면 지연시간, 비용, 외부 서비스 의존성이라는 반복 비용이 발생한다.

핵심 기여

  • 자연어 명세를 한 번의 빌드 과정을 통해 재사용 가능한 신경망 프로그램으로 변환하는 "compile by training" 개념 제시
  • 기존 Program-as-Weights(PAW)의 즉시 예측 방식보다 정확도를 크게 높이는 컴파일타임 학습 전략
  • 웹사이트 헬퍼, 언어 제어 3D 아바타, 영어-Claudish 양방향 번역기 등 실제 서비스에 배포하여 여러 컴파일된 함수의 조합 가능성을 시연

방법론

사용자가 자연어로 함수를 명세하면, 교사 모델(주로 저비용 모델과 고성능 모델을 2:1로 혼합)이 입력-출력 예시 데이터셋을 생성한다. 이 데이터로 공유된 동결(frozen) Qwen3-0.6B 인터프리터 위에 가벼운 LoRA 어댑터를 파인튜닝하며, PAW의 amortized 컴파일러가 예측한 초기 파라미터를 웜스타트로 활용한다. 완성된 프로그램(어댑터+런타임 스캐폴드+명세)은 패키징되어 로컬 SDK에서 교사 모델 호출 없이 실행된다. 또한 교사 생성과 학습을 오버랩시켜 컴파일 지연시간을 줄이는 서비스 아키텍처를 구현했다.

실험 설정 및 결과

PAW 고속 컴파일러가 정확히 일치하는 답을 내지 못한 FuzzyBench-Hard 부분집합에서, LLM 판정 기반 지표인 LEM(LLM Exact Match)으로 평가한 결과 PAW의 0.224에서 compile by training은 0.836으로 크게 향상되었다(컴파일 시간은 3.5초에서 50.9초로 증가). 교사 모델 혼합 비율과 데이터 규모에 대한 스윕 실험에서도 성능 향상이 확인되었으며, B300 GPU 기준 콜드 컴파일은 약 51초가 소요되었다. 공개 서비스에서는 4개 동시 컴파일 작업의 평균 대기시간이 1초 수준이었고, 영어-Claudish 번역 데모는 약 열흘간 10만 건 이상의 요청을 성공적으로 처리했다.

한계점

교사 모델이 생성한 합성 데이터의 오류를 그대로 물려받을 수 있어, 정확성이 보장되어야 하는 응용에서는 출력 검증이나 결정론적 제어 경로를 별도로 두어야 한다. 논문은 조합과 구조화된 실행 사례를 중심으로 다루며, 체계적인 사용자 연구는 향후 과제로 남겨두었다.

시사점

반복적이고 좁은 범위의 텍스트 함수를 매번 원격 LLM 호출 없이 처리할 수 있게 함으로써, LLM 활용을 "런타임 의존"에서 "빌드타임 도구"로 전환하는 소프트웨어 개발 패러다임의 가능성을 보여준다.
