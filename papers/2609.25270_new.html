RULER: Instance-aware Rubric Rewards for SVG Generation

RULER: SVG 생성을 위한 인스턴스 인식 루브릭 보상

자연어 지시문으로부터 SVG(벡터 그래픽)를 생성하는 개방형(open-ended) 과제에서, 인스턴스별로 맞춤화된 6항목 루브릭을 VLM 심판 모델이 채점하여 강화학습 보상으로 사용함으로써, 기존 스칼라 지표(CLIP, Aesthetic 등) 기반 보상의 리워드 해킹 문제를 해결하고 SVG 생성 품질을 크게 끌어올린 연구이다.

한 줄 요약

자연어 지시문으로부터 SVG(벡터 그래픽)를 생성하는 개방형(open-ended) 과제에서, 인스턴스별로 맞춤화된 6항목 루브릭을 VLM 심판 모델이 채점하여 강화학습 보상으로 사용함으로써, 기존 스칼라 지표(CLIP, Aesthetic 등) 기반 보상의 리워드 해킹 문제를 해결하고 SVG 생성 품질을 크게 끌어올린 연구이다.

배경 및 문제의식

  • SVG 코드 생성은 하나의 지시문에 대해 무수히 많은 시각적으로 타당한 결과물이 존재하는 개방형 과제로, 절대적인 정답(ground truth) 이미지가 없다.
  • 이 때문에 두 가지 문제가 서로 얽혀 있다.
  • 평가 지표의 신뢰성 부족: CLIPScore, 미학 분류기(Aesthetic classifier), Human Preference Score(HPS) 등은 사실적인 자연 이미지에 맞춰 보정된 지표라서, 양식화된 벡터 그래픽에는 잘 전이되지 않는다. 실제로 깨진(broken) SVG에 오히려 더 높은 점수를 주는 등 인간 판단과의 상관관계가 낮다.
  • 학습 신호의 부정확성: 지시문-SVG 쌍에 대한 지도미세조정(SFT)은 데이터셋에 특화된 템플릿을 단순 모방(behavioral cloning)하는 데 그쳐 일반화에 실패한다. 강화학습(RL)이 대안이지만, 보상으로 위의 불안정한 지표를 그대로 재사용하면 정책이 "속이기 쉬운" 신호 쪽으로 편향되는 리워드 해킹(reward hacking)이 발생한다.
  • 저자들은 900개의 사람이 평가한 SVG 샘플을 통해, 다축(multi-axis) 루브릭으로 비전-언어 모델(VLM)을 프롬프팅해 채점하는 방식이 스칼라 지표보다 사람의 평가와 훨씬 더 잘 일치함을 실증적으로 확인했다(Spearman ρ=0.7929, Goodman-Kruskal γ=0.7574, 대비 CLIP은 각각 0.5518/0.5295).

핵심 기여

  1. 루브릭 기반 SVG 평가 방법론 제시: 표준 스칼라 지표가 도메인 변화(자연 이미지→양식화된 벡터 그래픽)에서 실제 시각 품질에 둔감함을 체계적으로 규명하고, 루브릭 기반 채점이 인간 선호와 훨씬 더 잘 상관됨을 보였다.
  2. RULER (Instance-aware Rubric Rewards for Reinforcement LEaRning) 제안: 각 지시문마다 의미적 충실도(Semantic Fidelity), 시각적 품질(Visual Quality), 렌더링 스타일(Rendering Style)의 3개 축에 걸친 6개 항목의 인스턴스별 맞춤 루브릭을 생성하고, 이를 조밀(dense)하고 질의 조건부(query-conditioned)인 RL 보상으로 사용해 모호한 시각적 판단을 명시적으로 검증 가능한 하위 목표로 전환한다.
  3. 최고 수준의 성능 입증: MMSVG-Illustration 및 MMSVG-Icon 벤치마크에서 전용 SVG 특화 모델들과 표준 RL 베이스라인을 능가하는 최고 루브릭 점수를 달성했다.

방법론

  • 과제 정식화: SVG 생성을 토큰 단위 마르코프 결정 과정(MDP)으로 정의한다. 지시문 Q가 주어지면 정책 모델 πθ가 SVG 시퀀스를 자기회귀적으로 생성하고, 렌더링 엔진 E가 이를 이미지로 변환하며, 보상함수 R(·)이 이 이미지에 대해 계산된다. 절대 정답이 없으므로 R(·)의 설계가 핵심 과제로 부각된다.
  • 인스턴스 인식 루브릭 생성 (§3.3): 프론티어 모델(예: Claude-Opus-4.6)이 텍스트 지시문 하나만으로(정답 SVG 없이) 6개 항목·3개 축(의미/시각/스타일)으로 구성된 루브릭 C_Q = {(c_k, w_k)}_{k=1}^6 을 생성한다. 각 항목은 픽셀·경로 수준의 정확한 재현이 아니라 "설계 의도" 수준에서 기술되어 개방형 해 공간을 보존하며, 서로 겹치지 않는 독립적 판단 기준이 되도록 구성된다.
  • 보상 계산 (§3.4): 렌더링된 이미지 I_gen을 심판 VLM(M_judge, 학습 시 Qwen3-VL-8B)이 각 루브릭 항목별로 0~1 사이의 연속적 만족도 s_k로 채점하고, 가중 평균 R(I_gen) = Σw_k·s_k / Σw_k 를 최종 보상으로 사용한다.
  • 정책 최적화: Group Relative Policy Optimization(GRPO)을 사용해, 같은 지시문에 대해 G=8개 롤아웃을 샘플링하고 그룹 내 상대 보상으로 정규화된 어드밴티지를 계산해 클리핑된 대리목적함수로 정책을 갱신한다. KL 정규화는 사용하지 않는다.
  • 학습 데이터: MMSVG-Icon(약 2만개), MMSVG-Illustration(약 1.1만개) 학습 분할에서 프롬프트를 샘플링해 루브릭을 생성하고, 구조·품질 필터링(이상적 SVG의 자체 채점 점수가 0.9 미만인 루브릭 제외)을 거쳐 총 30,737개의 프롬프트-루브릭 쌍을 구축했다.
  • 정책 백본은 Qwen3-8B(및 강건성 실험에서 Qwen3-4B), 학습은 VERL 프레임워크와 vLLM 롤아웃 엔진, H800 GPU 8장 1노드에서 수행되었다.

실험 설정 및 결과

  • 벤치마크·지표: MMSVG-Illustration(삽화형), MMSVG-Icon(아이콘형) 두 벤치마크에서 CLIP Score, Aesthetic Score, HPS와 함께, GPT-5-mini를 독립 심판으로 사용한 범용(universal) Rubric Score를 핵심 지표로 사용.
  • 주요 결과 (Table 2): RULER는 Qwen3-8B 백본 대비 Rubric 점수를 Illustration에서 0.432→0.693, Icon에서 0.395→0.683으로 향상시켰으며, 훨씬 큰 DeepSeek-V3(0.686/0.673)와 대등하거나 이를 상회하고, VectorFusion/SVGDreamer 등 확산 모델 기반 최적화 기법 및 IconShop/OmniSVG/JanusCoder 등 SVG 특화 모델을 모두 능가했다. 토큰 수는 확산 최적화 기법 대비 훨씬 적다(2.0k vs 31.4k~124.3k).
  • 인간 선호도 평가: 150개 프롬프트에 대한 블라인드 쌍대비교에서 RULER는 모든 비교 대상(Qwen3-8B, Qwen3-32B, VectorFusion, OmniSVG, JanusCoder) 대비 비무승부 승률 53.3%~96.5%를 기록했다.
  • 보상 설계 비교(RQ2, Table 4): CLIP+Aesthetic+HPS 조합 보상(C+A+H RL)은 미학 점수를 인위적으로 부풀리며(Icon 6.210) 심각한 리워드 해킹을 일으켜 Rubric 점수가 오히려 0.395→0.262로 하락(중복·겹친 획으로 토큰 길이 폭증 6.3k). 범용(query-agnostic) 루브릭 RL은 안정적이나 인스턴스별 맥락을 반영하지 못해 RULER보다 낮은 성능(Icon 0.591 vs 0.683)을 보였다.
  • 어블레이션(RQ3): 6개 항목 중 시각적 품질(Visual Quality) 축 제거 시 가장 큰 하락(0.693→0.580), 렌더링 스타일 축 제거가 그 다음(→0.599), 의미 충실도 축 제거는 상대적으로 영향이 작음(→0.623, Qwen3-8B의 기존 텍스트-이미지 정합 능력 때문으로 추정). 더 엄격하지만 스타일 축이 빠진 대안(Rubric-S)은 오히려 "텍스트 힌트 해킹"(프롬프트 단어를 그대로 이미지에 그려 넣는 편법)을 유발하며 가장 낮은 점수(0.536)를 기록해, 축의 다양성이 채점 엄격성보다 중요함을 보였다.
  • 강건성(RQ4): 정책 백본을 Qwen3-4B로 축소해도(0.372→0.561/0.338→0.559) 향상이 유지되며, 루브릭 생성 모델을 Claude-Opus-4.6에서 GPT-5.5로 바꿔도 비슷한 성능 향상(Icon Rubric 0.662 vs 0.646)을 보여, 특정 모델에 종속되지 않는 견고함을 입증했다.
  • 비용: 루브릭 생성은 오프라인 1회성 전처리로, 학습 데이터 전체(30,737건) 생성 비용은 약 $2,013(프롬프트당 약 $0.0655)이며, 정책 학습 중에는 루브릭 생성 모델을 다시 호출하지 않는다.

한계점

  • 프론티어 모델(루브릭 생성)과 VLM 심판이라는 두 외부 모델에 의존하므로, 보상 품질이 이들의 편향·실패 양상을 그대로 물려받을 수 있으며, 학습 분포 밖 프롬프트에서는 심판이 피상적 단서를 과대평가하거나 미묘한 스타일적 특성을 과소평가할 수 있다.
  • 매 학습 스텝마다 SVG 렌더링과 VLM 심판 질의가 필요해 CLIP 등 경량 스칼라 보상 대비 계산 비용이 크게 증가하며, 이는 더 큰 모델·긴 롤아웃·넓은 하이퍼파라미터 탐색으로의 확장을 제약할 수 있다.
  • 인스턴스별 루브릭이라 해도 품질을 의미/시각/스타일 3개 축으로 고정 분해하는 구조 자체는, 모든 예술적 의도나 도메인별 선호를 완전히 포착하지 못할 수 있다. 상호작용적, 사람이 직접 조정 가능한, 또는 도메인 적응형 루브릭 설계는 향후 과제로 남는다.

시사점

  • 정답이 없는 개방형 생성 과제에서 스칼라 보상 대신 다축·인스턴스별 루브릭을 VLM으로 채점해 RL 보상으로 쓰는 접근은 리워드 해킹을 억제하면서도 조밀한 학습 신호를 제공할 수 있음을 보여준다.
  • 이 방법론은 SVG에 국한되지 않고, 절대 정답이 존재하지 않는 다른 개방형 시각적 코드 생성(예: 다이어그램, UI 코드) 과제에도 확장 가능한 일반적 패러다임으로 볼 수 있다.
  • 루브릭 축의 "다양성(complementarity)"이 채점 기준의 "엄격함"보다 리워드 해킹 방지에 더 중요하다는 발견은, 향후 루브릭 기반 보상 설계 시 항목 수를 줄이거나 특정 축을 제거하는 것에 신중해야 함을 시사한다.
