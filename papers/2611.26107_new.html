HiUni: Harmonizing Understanding and Generation in Shared Visual Space

하이유니: 공유 시각 공간에서의 이해와 생성 조화

이해와 생성을 위해 별도의 시각 인코더나 작업별 백본을 두지 않고, 사전학습된 비전-언어 모델(VLM)의 언어정렬 ViT와 밀집(dense) Transformer 백본을 그대로 공유하면서, 출력 단계에서만 픽셀 확산 헤드(Pixel Diffusion Head)와 경량 게이팅 모듈(HiGate)로 생성에 필요한 세밀한 공간 정보를 보완하는 통합 멀티모달 모델 HiUni를 제안한다.

한 줄 요약

이해와 생성을 위해 별도의 시각 인코더나 작업별 백본을 두지 않고, 사전학습된 비전-언어 모델(VLM)의 언어정렬 ViT와 밀집(dense) Transformer 백본을 그대로 공유하면서, 출력 단계에서만 픽셀 확산 헤드(Pixel Diffusion Head)와 경량 게이팅 모듈(HiGate)로 생성에 필요한 세밀한 공간 정보를 보완하는 통합 멀티모달 모델 HiUni를 제안한다.

배경 및 문제의식

통합 멀티모달 모델(UMM)은 이해와 생성을 하나의 프레임워크에서 지원하는 것을 목표로 하지만, 기존 방법 대부분은 이해에는 언어정렬 ViT, 생성에는 VAE 기반의 별도 시각 표현 공간을 유지하거나(Janus 계열), 백본 내부를 작업별로 분리하는 Mixture-of-Transformers 구조(Bagel 등)를 사용해 두 표현 공간을 나눈다. 이러한 분리는 각 작업의 개별 성능은 지켜주지만 이해와 생성 간의 직접적인 시각 표현 상호작용을 제한한다는 문제의식에서, 저자들은 "공유된 시각 공간이 작업별 백본 연산 없이도 이해와 생성을 내부적으로 조화시킬 수 있는가"라는 질문을 던진다.

핵심 기여

  • 사전학습 VLM으로부터 바로 확장해 이해·생성·편집이 동일한 언어정렬 ViT, 동일한 밀집 백본을 공유하고, 작업별 연산은 출력 모듈로만 한정하는 새로운 UMM 구축 관점 제시.
  • 픽셀 공간 생성에 특화된 Pixel Diffusion Head와, 패치 병합·깊은 의미 추상화로 약화된 세밀한 공간 정보를 보완하는 경량 게이팅 경로 HiGate를 설계.
  • 광범위한 실험으로 HiUni가 사전학습 VLM 수준의 이해 성능을 유지하면서 이미지 생성·편집에서도 경쟁력 있는 성능을 달성함을 입증하고, 공유 밀집 백본의 규모를 키우는 것이 작업별 백본보다 더 효과적일 수 있음을 통제 비교로 보여줌.

방법론

HiUni는 Qwen3-VL-4B-Instruct에서 초기화되어, 입력 이미지를 ViT와 패치 병합기(M)로 인코딩한 동일한 시각 토큰을 이해·생성 모두에 사용하고, 이 토큰들은 다시 하나의 밀집 Transformer 백본에서 처리된다. 텍스트 출력은 기존 언어모델링 헤드가 맡고, 이미지 생성은 새로 도입한 Pixel Diffusion Head가 담당한다. 표준 DiT의 반복적인 AdaLN 변조가 학습 불안정(loss spike)을 일으키는 것을 관찰하여, AdaLN을 제거하고 시간 토큰과 최종 단일 변조층만 사용하는 단순화된 확산 헤드를 설계했다. 또한 ViT·패치 병합이 약화시키는 세밀한 공간 정보를 보완하기 위해, 노이즈 이미지를 ViT 경로와 별도로 픽셀 단위 잔차 경로로도 인코딩하고, 토큰별 게이트를 학습하는 HiGate를 통해 이 픽셀 특징을 생성 타깃 특징에 융합한다. 텍스트-이미지 생성과 이미지 편집은 조건(텍스트 프롬프트, 혹은 프롬프트+참조 이미지)만 다를 뿐 동일한 생성 경로를 공유하며, 언어모델링 손실과 x-예측(velocity 기반) 확산 손실을 함께 최적화하는 3단계(생성 워밍업 → 전체 통합 사전학습 → 지도 미세조정) 학습을 거친다.

실험 설정 및 결과

MathVista, MMBench, RealWorldQA, MMStar, HallusionBench, AI2D, OCRBench, OmniDocBench 등 8개 이해 벤치마크에서 HiUni는 평균 75.56점으로 사전학습 기반인 Qwen3-VL-4B-Instruct의 75.61점과 거의 동등한 성능을 유지했다. 이미지 생성에서는 Qwen-Image-Bench 중국어 항목에서 통합 멀티모달 모델 중 최고점을 기록했고 영어 항목에서도 최상위권 모델에 근접했으며, OneIG·LongText 벤치마크에서도 경쟁력 있는 성능을 보였다. 이미지 편집에서는 ImgEdit 종합 점수 3.66으로 비교 대상 통합 모델 중 2위(1위는 UniSpace의 3.82), GEdit에서는 중국어/영어 각각 6.70/6.81점을 기록했다. 밀집 백본과 작업별 라우팅(MoT) 구조를 통제 비교한 결과, 동일 규모에서는 MoT가 생성 성능에서 다소 유리했지만, 유사한 총 파라미터 수에서 더 큰 공유 밀집 백본(HiUni-Dense-4B)을 사용하면 이해 성능이 크게 향상되면서도 경쟁력 있는 생성 성능을 유지할 수 있음을 확인했다. HiGate 분석에서는 픽셀 레벨 특징을 직접 잔차로 주입하는 방식이 ViT 특징을 사용하는 것보다 생성 품질(OneIG)을 더 높였고(0.267→0.284→0.314), 게이트의 기여도는 노이즈가 많은 단계에서는 약하다가 깨끗한 이미지에 가까워질수록 강해져 세밀한 공간 단서가 디노이징 후반부에 주로 활용됨을 보여주었다.

한계점

이미지 편집 성능은 편집 전용으로 학습된 특화 모델(LongCat-Image-Edit, Qwen-Image-Edit-2511 등)에는 여전히 못 미치며, 이해-생성 간 교차 작업 전이를 실험한 결과(이미지 편집 지도 추가 시 이해 평균은 62.64→64.49로 향상되었으나 생성 OneIG 평균은 0.538→0.528로 소폭 하락) 공유 백본 내에서 작업 간 전이와 간섭이 공존하는 등 일관된 시너지(synergy)는 아직 미해결 과제로 남아있다. 저자들 스스로도 현재의 HiUni는 "공존(coexistence)" 수준의 통합이며, 상호 지식 공유를 통한 "시너지(synergy)" 수준의 통합은 향후 과제임을 명시했다.

시사점

별도의 생성 전용 인코더나 작업별 백본 없이도 사전학습된 VLM의 표현을 그대로 재사용해 이해와 생성을 통합할 수 있다는 점은, 더 간단하고 확장 가능한 통합 멀티모달 모델링 경로를 제시한다. 저자들은 이 설계가 향후 성숙한 VLM을 더 풍부한 생성 능력, 더 넓은 과제, 더 상호작용적인 멀티모달 시나리오로 확장하는 유망한 방향이 될 수 있다고 전망한다.
