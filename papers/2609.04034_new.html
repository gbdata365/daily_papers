Editable Visual Design

편집 가능한 비주얼 디자인

VLM을 "창작 뇌", 이미지 생성 모델을 주문형 "시각 세계 시뮬레이터"로 분업시켜, "먼저 상상하고 그다음 행동한다"는 폐루프 워크플로우로 레이어가 분리되고 텍스트가 정확한 편집 가능한 디자인 산출물(포스터, 인포그래픽 등)을 코딩 에이전트가 생성하는 새로운 패러다임을 제안한다.

한 줄 요약

VLM을 "창작 뇌", 이미지 생성 모델을 주문형 "시각 세계 시뮬레이터"로 분업시켜, "먼저 상상하고 그다음 행동한다"는 폐루프 워크플로우로 레이어가 분리되고 텍스트가 정확한 편집 가능한 디자인 산출물(포스터, 인포그래픽 등)을 코딩 에이전트가 생성하는 새로운 패러다임을 제안한다.

배경 및 문제의식

확산 모델 기반 이미지 생성(GPT-Image-2, Nano-Banana 등)은 시각적 표현력은 뛰어나지만 결과물이 평면화된 비트맵이라 텍스트 오류가 잦고 레이어별 후편집이 불가능하다. 반대로 코딩 에이전트를 통한 코드 기반 시각 생성은 정밀한 레이아웃 제어와 레이어 분리를 제공하지만, 전역적인 미적 직관이 부족하고 복잡한 시각 자산(영화 같은 배경, 3D 히어로 비주얼, 정교한 일러스트 등)을 코드로 그려내기 어렵다는 상반된 한계를 갖는다.

핵심 기여

  • VLM(창작 뇌)이 요구사항 이해·작업 계획·미적 판단을 담당하고, 이미지 생성 모델(시각 세계 시뮬레이터)이 독립적인 시각 자산을 합성하는 협업 메커니즘을 갖춘 Editable Visual Design 패러다임 제안
  • "먼저 상상하고 그다음 행동한다"는 폐루프 워크플로우: 상상된 비주얼 생성 → 독립적인 자산 생성 → 네이티브 HTML/CSS 작성 → 렌더링 피드백 기반 반복 수정
  • 전문 디자이너의 창작·추론 궤적을 충실히 재현하는 "Agent Design Replay"를 도입해 요구사항 분해부터 자산 생성, 코드 반영·수정까지 전체 과정을 투명하고 추적 가능하게 기록
  • 레이어가 분리되고 실제 텍스트를 가진 편집 가능한 산출물을 전달해 사용자가 마우스로 드래그하며 직관적으로 레이아웃을 조정할 수 있게 함

방법론

전체 워크플로우는 5단계로 구성된다: (1) 이해 및 디자인 계획 — 에이전트가 요구사항을 파악하고 이미지 모델을 호출해 "상상된 비주얼"을 만들어 미적 참조로 삼음, (2) 시각 시뮬레이션 — VLM이 상상된 비주얼에서 색조·구도·스타일 특징을 시각적으로 파싱해 이후 코드 구축의 전역 참조로 사용, (3) 구조적 코딩 및 생성 — 텍스트 없는 배경이나 독립된 피사체 같은 깔끔한 개별 시각 자산을 온디맨드로 생성하고(알파 채널 직접 요청 또는 그린 배경+매팅 스크립트로 분리), 이를 네이티브 HTML/CSS로 조합해 명확한 타이포그래피 계층과 그리드 정렬을 갖춘 다층 페이지를 구성, (4) 검증 및 시각적 자가 치유 — 헤드리스 브라우저에서 결정론적 레이아웃 규칙 검사를 수행한 뒤 렌더링된 스크린샷을 VLM 리뷰어에게 제공해 시각적 반성과 국소적 패치 수정을 반복, (5) 편집 가능한 디자인 전달 — 텍스트·자산·배경 레이어가 완전히 분리된 네이티브 DOM 노드 형태로 최종 산출물 전달. 실험 시스템에서 창작 뇌는 GPT-5.6 Sol 기반 Codex, 시각 시뮬레이터는 GPT Image 2를 사용했다.

실험 설정 및 결과

동일한 요구사항에 대해 순수 확산 이미지 생성, 순수 LLM 코드 레이아웃, Editable Visual Design 세 방식을 비교한 결과, 순수 확산 모델은 시각 품질은 좋지만 텍스트가 왜곡되고 레이어가 뒤엉켜 편집이 어려웠고, 순수 코드 생성은 구조는 깔끔하지만 전역적 미적 사전지식이 없어 결과물이 단조로웠다. 반면 Editable Visual Design은 이미지 시뮬레이터로부터 좋은 색감과 분위기를 얻으면서도 코드 재구성을 통해 명확한 타이포그래피와 레이어 분리를 동시에 달성했다. 이벤트 포스터, 인포그래픽, 마케팅 자료, 장문 레이아웃 등 다양한 디자인 유형에 걸쳐 파이프라인이 적응함을 보였으며, 레드판다 백과사전 인포그래픽 사례 연구에서는 Agent Design Replay가 요구사항 파싱부터 자산 생성, 렌더링 관찰, 레이아웃 세부 수정까지의 전체 창작 궤적을 투명하게 보여주었다.

한계점

이 방법은 기저 모델이 갖지 못한 능력을 새로 만들어내지 않으며, 코딩 에이전트나 이미지 모델 중 어느 하나의 능력이 부족하면 결과물도 그만큼 제한된다. 특히 이미지 모델이 반환하는 참조가 기술적으로는 깨끗하지만 구도상 평범하고 뚜렷한 초점이나 색 아이디어가 없을 경우, 에이전트가 이를 발전시킬 여지가 적다. 여러 페이지에 걸친 일관성이 필요한 다중 페이지 덱이나 전체 웹사이트는 단일 포스터보다 훨씬 어렵고, 본 보고서의 사례는 모두 단일 페이지 디자인에 국한된다. 또한 미적 품질에는 정답이 없어 정량적 점수 대신 사례 중심으로 보고했으며, 편집 가능성 역시 레이어 수나 DOM 구조로는 완전히 측정되지 않는다.

시사점

생성 모델을 최종 산출물이 아니라 "상상"을 통해 미적·구성적 사전지식을 코딩 에이전트에 공급하는 전처리 시뮬레이터로 배치하는 것이, 생성이 멀티모달 이해와 의사결정에 피드백하는 자연스러운 방식이 될 수 있음을 시사한다. 이는 "비트맵 출력"에서 "구조화된 전달"로 나아가는 디자인 자동화의 실용적 방향을 제시한다.
