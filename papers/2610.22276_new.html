MJev-Spatial: System One Spatial Intelligence via Native Attention Matching

MJev-Spatial: 네이티브 어텐션 매칭을 통한 시스템 1 공간 지능

한 줄 요약

비전-언어모델(VLM)이 공간 질문에 답할 때 불필요하게 텍스트를 생성·디코딩하는 대신, 사전학습된 어텐션의 쿼리·키 projection만 재사용해 후보(옵션/수치구간/이미지영역) 중 하나를 즉시 분류하는 "System 1" 방식의 공간지능 모델 MJev-Spatial을 제안한다.

배경 및 문제의식

기존 VLM들은 "두 물체 중 어느 것이 앞에 있는가", "거리가 얼마인가", "어디에 물건을 놓아야 하는가" 같은 공간 질문에 자유형 텍스트 생성으로 답한다. 그러나 실제 정답 공간은 몇 개의 선택지, 하나의 스칼라 값, 2D 좌표처럼 매우 작다. 그럼에도 모델은 답을 토큰 단위로 순차 생성(autoregressive decoding)하고 이를 다시 파싱해야 하므로, 추론 지연(latency)과 불필요한 텍스트 형식 학습 부담이 발생한다. 저자들은 선행 연구 Jev(후보들에 대한 확률만 반환하는 인터페이스)에서 착안해, 선택형·수치형·포인팅형 세 가지 공간과제를 모두 "유한한 후보 집합에 대한 분류" 문제로 통일할 수 있다고 보았다.

핵심 기여

  1. 옵션 선택, 수치 추정(거리·각도·개수), 이미지 포인팅을 하나의 분류 프레임워크로 통합하는 System 1 패러다임 제안.
  2. 백본의 마지막 어텐션 층에 있는 사전학습된 Query/Key projection을 그대로 재사용해 후보를 채점하는 방식(추가 파라미터·예측head 없음)과, 모든 refinement 단계를 한 번의 forward pass로 teacher-forcing 학습하는 레시피 고안.
  3. 길이 기반 글로벌 배칭과 GPU 간 작업량 균형 조정으로 학습 처리량을 기존 대비 30.8% 향상.
  4. 12개 공간이해 벤치마크에서 8개 비교 모델 중 최고 평균 점수(65.64%), 7개 벤치마크 1위, 그리고 기반 모델(Qwen3.5-4B) 대비 전 벤치마크 성능 향상과 5.6배 속도 향상을 달성.

방법론

MJev-Spatial은 Qwen3.5-4B를 기반으로 한다. 각 질문 단계에서, 결정 컨트롤러가 현재 단계의 후보 집합(선택지, 혹은 coarse-to-fine 방식으로 세분화된 수치 구간/이미지 영역)을 텍스트로 구성한다. 각 후보는 끝에 "옵션-끝" 마커를 붙이고, 전체 후보 리스트 끝에는 "결정" 마커를 붙여 VLM에 입력한다. 31개 언어 레이어를 통과한 뒤, 마지막 전체-어텐션 레이어의 사전학습된 Query/Key projection을 재사용하여 결정 마커의 은닉상태(쿼리)와 각 후보 마커의 은닉상태(키) 간 내적으로 logit을 계산하고, 소프트맥스로 후보를 선택한다(식: 쿼리 16개 헤드가 키 4개 헤드를 그룹 공유). 수치 추정은 로그 간격의 coarse 구간을 고른 뒤 그 안의 fine cell을 다시 고르는 2단계 구조(길이는 최대 30개 coarse 구간+overflow/zero, 각도는 12개 구간)로, 포인팅은 이미지를 3x3 영역으로 3단계 재귀 분할(매 단계 crop을 다시 인코딩)하여 27x27 해상도 그리드를 얻는 구조다. 다중 포인트 예측은 여러 분기의 조건부 확률을 트리 형태로 전개해 추가 학습 없이 확장한다. 학습은 RefSpatial, SAT, SenseNova-SI, VSI-590K, VST-P 등 기존 공간 데이터셋을 변환한 1230만 개의 질문-답변 쌍을 사용하며, 모든 refinement 단계의 cross-entropy 손실을 질문당 평균 내어 한 번의 forward pass로 teacher-forcing 학습한다. 길이 기준 글로벌 그루핑과 GPU 간 작업량 균형 조정(longest-work-first 배정)으로 패딩과 동기화 지연을 줄인다.

실험 설정 및 결과

SAT, CV-Bench, RoboSpatial-VQA, BLINK, MMSI-Bench, RefSpatial-Bench, Where2Place, RoboSpatial-POI, Point-Bench, ERQA, EmbSpatial, VSI-Bench 등 12개 벤치마크에서 Qwen3.5-4B, Qwen3-VL-8B-Instruct, InternVL3.5-8B, Molmo2-ER, Spatial-SSRL, SenseNova-SI, SpatialThinker 등 7개 생성형 VLM과 비교했다. MJev-Spatial은 평균 65.64%로 1위(2위 Qwen3-VL-8B-Instruct 62.79%)를 기록했고, 12개 전 벤치마크에서 기반 모델 Qwen3.5-4B를 능가했으며(RoboSpatial-VQA +22.89%p, RefSpatial-Bench +12.50%p 등) NVIDIA B200 GPU 기준 평균 160.6ms의 지연시간으로 가장 빠른 생성형 베이스라인보다 2.5배, 기반 모델보다 5.6배 빨랐다. Ablation 연구에서는 사전학습된 Q/K 스코어링이 새로 학습한 선형분류기/KEV 포인터와 비교해 과제별로 비슷하거나 더 나은 성능을 보이면서도 추가 파라미터가 없다는 장점이 확인되었고, 수치 추정에서는 더 세밀한 구간(960개)보다 오히려 거친 구간(216개)이 더 낮은 오차(MAE 0.3202m)를 보였다. 포인팅에서는 crop 재인코딩이 원본 유지나 특징 재사용보다 우수했으며, 길이 그루핑과 GPU 균형 조정은 학습 처리량을 99.06에서 129.54 QA/s로(+30.78%) 끌어올렸다.

한계점

포인트 예측의 기하학적 오차 한계(27x27 그리드에서 셀 당 최대 1/54 오차)는 초기 단계 결정이 틀렸을 때 보장되지 않으며, crop 재인코딩은 포인트당 추가 이미지 인코딩 비용이 든다. 수치/각도/개수 코드북은 질문 유형별로 분리되어 있어 범용적 수치 표현은 아니다. 학습 처리량 측정은 짧은 실험(100 업데이트)에 기반해 수렴이나 전체 학습 시간, 다운스트림 품질을 검증하지 않았다. 또한 다중 포인트 디코딩은 완전 전개 시 91개 결정 노드·729개 셀이 필요해 계산비용이 크며, pruning으로 완화하지만 완전한 해결책은 아니다.

시사점

출력 공간이 본질적으로 작은 과제(선택, 분류, 좌표 예측 등)에서는 자유형 텍스트 생성 대신 사전학습된 표현을 그대로 재사용하는 분류 방식이 정확도와 지연시간을 동시에 개선할 수 있음을 보여준다. 이는 로봇·에이전트처럼 실시간 공간 판단이 필요한 응용에서 자기회귀 디코딩의 오버헤드를 줄이는 대안적 추론 패러다임으로 확장될 수 있다.
