ContextPilot: Teaching Agents for Proactive Context Management via Fine-grained RL

컨텍스트파일럿: 세밀한 강화학습을 통한 에이전트의 능동적 컨텍스트 관리 학습

에이전트가 스스로 자신의 작업 컨텍스트를 편집하는 "능동적 컨텍스트 관리"의 한계(제한된 도구, 비효율적 탐색, 거친 크레딧 할당)를 계획·장기기억·소프트 오프로딩 도구 확장과 세밀한 강화학습 기법으로 해결하는 ContextPilot 프레임워크를 제안한다.

한 줄 요약

에이전트가 스스로 자신의 작업 컨텍스트를 편집하는 "능동적 컨텍스트 관리"의 한계(제한된 도구, 비효율적 탐색, 거친 크레딧 할당)를 계획·장기기억·소프트 오프로딩 도구 확장과 세밀한 강화학습 기법으로 해결하는 ContextPilot 프레임워크를 제안한다.

배경 및 문제의식

장기 에이전틱 과제에서 LLM은 여러 턴에 걸쳐 정보를 검색·통합·유지해야 하는데, 모든 상호작용 이력을 그대로 보존하면 작업 컨텍스트가 계속 증가한다. 최근의 "능동적 컨텍스트 관리"는 모델이 전용 도구로 자신의 컨텍스트를 직접 편집하게 하지만 세 가지 한계가 있다: (1) 검색·삭제·요약에 국한된 좁은 도구 집합이라 전역 계획, 장기 기억, 적응적 압축을 지원하지 못하고, (2) 컨텍스트 관리 행동들이 최종 결과에 미치는 영향이 서로 크게 다름에도 이를 균일하게 탐색하며, (3) 강화학습에서 최종 궤적 단위 보상을 모든 중간 컨텍스트 편집 행동에 그대로 부여하는 거친 크레딧 할당을 사용한다. 저자들의 사전 실험에서, 특정 컨텍스트 관리 행동(readChunk, deleteContext 등)에서 분기한 궤적들의 최종 성공률 표준편차가 다른 행동보다 훨씬 크다는 것과, 정답 궤적이라도 컨텍스트 관리 품질이 나쁠 수 있고 그 반대도 가능하다는 것을 확인했다.

핵심 기여

  1. 확장된 도구 집합: 지각·계획(계획 수립, 예산 확인), 정보 검색(인덱스 구축, 검색, 청크 읽기), 장기 기억 관리(memorize, updateMemory, readMemory), 소프트 컨텍스트 오프로딩(요약, 경량 압축모델 기반 compressContext, 히스토리를 인덱스로 대체하는 foldHistory) 등 계획·장기기억·오프로딩 도구를 새로 추가했다.
  2. 컨텍스트 인지 부분 롤아웃(Context-Aware Partial Rollout): 컨텍스트 길이 변화량과 엔트로피 변화량을 결합한 민감도 점수로 영향력이 큰 컨텍스트 관리 결정을 식별해, 그 지점에서 추가 분기 샘플링을 수행함으로써 탐색 예산을 효율적으로 배분한다.
  3. 세밀한 크레딧 할당: 최종 궤적 보상을 모든 중간 스냅샷에 균일하게 부여하는 대신, 각 컨텍스트 편집 행동을 거친 모든 후속 분기 궤적들의 보상으로부터 해당 행동의 가치를 추정한다.

방법론

ReAct 스타일 에이전트는 매 스텝 컨텍스트 c_i로부터 사고와 도구 호출을 생성하고, 컨텍스트 편집 행동이 발생하면 컨텍스트 전이 함수 F로 인터랙션 이력이 갱신된다(식 2). 컨텍스트 편집 행동은 궤적을 여러 개의 독립적인 "스냅샷"으로 분절하며, 토큰 단위 손실 마스킹으로 중복 최적화를 방지한다. 학습은 먼저 하네스가 적절한 시점에 힌트·제약을 제공해 교사 모델의 궤적으로 SFT 데이터를 구성한 뒤, 강화학습 단계에서 (1) 컨텍스트 변화량 ΔC와 초기 엔트로피 대비 엔트로피 변화량 ΔH를 가중합한 민감도 점수 S(a^cm_t) = α·ΔC + β·ΔH로 각 컨텍스트 관리 행동의 영향력을 추정하고, 궤적 단위 롤아웃에서 나온 스냅샷이 목표 예산 N보다 적으면 민감도 점수가 높은 상위 행동들에서 추가로 부분 롤아웃을 수행한다. (2) 크레딧 할당에서는 결과 보상·형식 보상·페널티로 구성된 최종 보상 R(S_M) = R_out + R_fmt + R_pen을 정의하고(식 7), 중간 스냅샷의 가치는 그 스냅샷에서 파생된 모든 후속 분기 궤적들의 보상으로부터 추정해, 반복 검색처럼 정답으로 이어지는 합리적 행동과 비합리적 컨텍스트 관리 행동을 구분할 수 있는 세밀한 신호를 만든다.

실험 설정 및 결과

장문맥 QA(NovelQA 등)와 딥서치 과제에서 ContextPilot을 여러 베이스 모델(Qwen3-8B 등)과 벤치마크(BrowseComp+ 등)에 걸쳐 평가한 결과, 기존 베이스라인(StateLM 등) 대비 더 컴팩트한 작업 컨텍스트를 유지하면서도 일관되게 더 우수한 성능을 달성했다. 사전 실험(파일럿 스터디)에서는 readChunk, deleteContext, searchContext 등의 도구가 memorize, plan 등의 도구보다 최종 성공률의 표준편차가 훨씬 크다는 것을 정량적으로 보였으며(그림 2), StateLM-8B의 사례 분석에서는 반복적인 검색을 사용한 정답 궤적과 삭제·업데이트를 반복한 오답 궤적을 대조해 컨텍스트 관리 품질과 최종 정답 여부가 항상 일치하지 않음을 보였다(그림 3).

한계점

논문에 명시되지 않음.

시사점

컨텍스트 관리 행동을 균일하게 다루지 않고 그 영향력에 따라 차등적으로 탐색·보상을 배분해야 한다는 통찰은, 도구 사용 에이전트의 강화학습 설계에서 "어떤 행동에 더 많은 학습 신호를 투자할지"를 결정하는 일반적인 원칙을 제시한다. 계획·장기기억·소프트 오프로딩까지 아우르는 확장된 도구 집합은 향후 장기 에이전틱 시스템이 단순 요약·삭제를 넘어 더 정교하게 자신의 작업 상태를 관리하도록 설계하는 데 참고할 수 있는 청사진이 된다.
