LaLa-World: Scaling Latent World Models with Natural Language Actions

라라월드: 자연어 행동으로 확장하는 잠재 세계모델

자연어를 수치 행동(action)과 시각 변화(visual change)를 아우르는 공통 인터페이스로 사용해, 이질적인 시뮬레이션/로봇 제어 데이터와 이미지·비디오 데이터를 하나의 예측기로 함께 학습하는 언어 조건부 잠재 세계모델(latent world model) LaLa-World를 제안하고, 이를 행동예측기로 파인튜닝한 LaLa-Policy까지 확장한다.

한 줄 요약

자연어를 수치 행동(action)과 시각 변화(visual change)를 아우르는 공통 인터페이스로 사용해, 이질적인 시뮬레이션/로봇 제어 데이터와 이미지·비디오 데이터를 하나의 예측기로 함께 학습하는 언어 조건부 잠재 세계모델(latent world model) LaLa-World를 제안하고, 이를 행동예측기로 파인튜닝한 LaLa-Policy까지 확장한다.

배경 및 문제의식

세계모델(world model)은 주어진 행동에 대해 미래 상태를 예측함으로써 계획(planning)과 의사결정의 기반이 된다. JEPA 스타일의 잠재 세계모델(LWM, 예: V-JEPA 2-AC, DINO-WM)은 픽셀 수준 재구성 없이 잠재 표현 변화만 예측해 계산 효율이 높아 상상 기반 계획(imagination-based planning)에 유리하다. 그러나 기존 LWM의 행동조건부 예측기는 대개 특정 시뮬레이션/로봇 데이터셋 하나에 대해서만 학습되며, 데이터셋마다 수치 행동 벡터의 차원과 물리적 의미가 달라(예: 한 도메인에서는 수평/수직 변위, 다른 도메인에서는 힘) 여러 도메인을 아우르는 공유 동역학 학습이 어렵다. 또한 이미지·비디오 데이터는 수치 행동 주석이 없어 LWM 학습에 활용하기 힘들다. 반면 비디오 생성모델(생성적 세계모델)은 자연어를 조건으로 사용해 다양한 도메인의 시각 데이터로부터 학습할 수 있지만, 계획 시 매 후보 행동마다 픽셀 수준 영상을 합성해야 해 비용이 크다. 저자들은 "잠재 세계모델의 효율성과 생성모델의 유연한 언어 인터페이스를 결합할 수 있는가"라는 문제의식에서 출발한다.

핵심 기여

  • 언어를 공유 인터페이스로 사용해 제어 궤적 데이터와 더 폭넓은 이미지·비디오 데이터를 함께 학습하는 잠재 세계모델 LaLa-World 제안.
  • 여러 도메인에 걸쳐 단일 예측기로 학습한 LaLa-World가 도메인별로 개별 학습된 기존 LWM들을 MPC 계획 성능에서 능가함을 입증.
  • 동일 조건(언어 조건, 학습 데이터, 비전 인코더)에서 RAEv2 기반 생성적 세계모델과 비교, LaLa-World가 더 높은 계획 성능과 더 큰 학습·추론 효율성을 보임을 입증.
  • 사전학습된 LaLa-World를 행동 예측기로 파인튜닝한 LaLa-Policy를 제시, 기존 정책모델과 경쟁력 있는 성능을 더 빠른 추론 속도로 달성.

방법론

LaLa-World는 기존 LWM의 인코더-예측기 틀을 따르되, 수치 행동 조건 c 대신 언어 조건 z를 사용한다(ê_{t+1}=P_φ(e_{t-w+1:t}, z)).

  1. 언어 조건부 전이 데이터 구성:
  2. 제어 데이터의 언어화: Push-T, Point Maze, Wall, Meta-World, DROID 등 7개의 시뮬레이션·로봇 데이터셋에서 각 도메인 고유의 수치 행동 벡터(방향·크기 포함)를 고정 템플릿을 사용해 자연어 문장(예: "push the ball with force 0.50 left and 0.46 up")으로 변환한다. 이를 통해 차원과 물리적 의미가 다른 여러 도메인의 제어 데이터를 하나의 언어 형식으로 통합한다.
  3. 이미지·비디오 데이터 추가: 제어 데이터만으로는 언어 표현의 다양성이 제한되므로, OpenVid의 캡션 비디오, OmniEdit·ShareGPT의 이미지 편집 지시문 쌍을 추가해, 프레임 간 변화를 설명하는 캡션/편집 지시문 자체를 언어 조건으로 사용한다(수치 행동 주석 불필요).
  4. 모델 아키텍처: 관측 인코더는 고정된 자기지도 사전학습 비전 트랜스포머(DINOv2-S/14 또는 DINOv3-L/16)를 사용해 표현 붕괴를 방지한다. 예측기는 사전학습된 언어모델(기본값 Qwen3.5-0.8B)을 그대로 사용하여, 언어 조건을 텍스트로 토큰화해 시각 잠재 토큰과 함께 입력하고, 2층 MLP와 3D 위치 임베딩(시간+2D 공간)을 통해 시각 잠재를 임베딩 공간에 매핑한 뒤, 학습된 질의 토큰(query token)으로부터 미래 표현 ê_{t+1}을 읽어낸다. 학습 목표는 예측-타깃 표현 간 제곱오차(L=‖ê_{t+1}-e_{t+1}‖²)이며, 자기수용감각(proprioceptive state) 정보는 입력이나 타깃으로 사용하지 않는다(도메인 특이성을 피하기 위함). 디코더(미래 상태 시각화용)는 별도로 L1 재구성과 LPIPS 손실로 학습되며 세계모델 학습 자체에는 사용되지 않는다.
  5. MPC 계획: 교차엔트로피법(CEM)으로 후보 행동열을 샘플링하고, 각 후보를 자기회귀적으로 H스텝 적용한 뒤 목표 관측과의 잠재 거리(비용 C=‖ê_{t+H}-e_goal‖²)로 평가해 최적 행동을 선택한다. LaLa-World는 CEM이 샘플링한 수치 행동을 템플릿으로 언어화해 예측기에 입력한다.
  6. LaLa-Policy: 사전학습된 LaLa-World 예측기에 학습 가능한 행동 질의(action query)를 추가하고, Isaac-GR00T의 행동헤드 구조를 적용한 확산 트랜스포머 기반 행동 생성기 A_ψ를 결합해, 관측과 과제 지시문으로부터 행동 청크와 미래 잠재 표현을 동시에(반복적 디노이징으로) 예측하도록 파인튜닝한다.

실험 설정 및 결과

  • MPC 계획(표1): Wall, PointMaze, Push-T, MetaWorld-R(Reach), MetaWorld-RW(Reach-Wall) 등 5개 시뮬레이션 과제에서 LaLa-World는 평균 성공률 72.1%로 DreamerV3, TD-MPC2, IRIS, LeWorldModel, DINO-WM, JEPA-WMs 등 개별 도메인별로 학습된 기존 LWM 베이스라인을 모두 상회(JEPA-WMs 대비 +7.5%p, Push-T에서는 68.8%→81.2%로 가장 큰 향상). Rope, Granular, 그리고 학습에 포함되지 않은 RoboCasa(제로샷)·DROID 데이터셋에서도 LaLa-World가 평균 최고 성능(50.4%)을 기록.
  • 이미지·비디오 데이터의 효과: 제어 데이터만 사용할 때 평균 성능 59.3%에서, 이미지·비디오 데이터를 추가하면 61.6%로 향상. 또한 행동 템플릿을 다른 표현으로 바꿔 쓴("move the gripper"→"shift the robot hand" 등) 패러프레이즈 평가에서, 제어 데이터만 학습한 모델은 성능이 6.8점 하락하는 반면 전체 데이터로 학습한 LaLa-World는 견고함을 유지.
  • 수치 없는 질적 언어 행동: "move slightly down"과 같이 수치가 없는 질적 표현으로도 LaLa-World가 계획을 성공적으로 수행할 수 있음을 Wall, RoboCasa에서 정성적으로 확인.
  • 잠재 모델 vs 생성 모델 비교(매칭 조건): DINOv3-L/16 인코더, 동일 언어 조건, 동일 학습 데이터, 약 0.8B 파라미터로 맞춘 RAEv2(diffusion transformer) 기반 생성적 세계모델과 비교한 결과, LaLa-World는 RAEv2의 5-스텝 디노이징 12시간 학습 성능(59.4%)을 단 2시간 만에 달성했고, 동일 예측기 깊이 조건에서 RAEv2(1-step/5-step) 대비 각각 2.9배/13.9배 빠르게 계획을 수행하면서도 더 높은 평균 성능을 보임. 전체적으로 6배 적은 학습 비용과 13.9배 빠른 계획 속도로 비교 가능한 성능을 달성.
  • LaLa-Policy(표2, 3): LIBERO 벤치마크에서 LaLa-World로 초기화한 LaLa-Policy가 성공률 97.7%로 Dita, π0, UniVLA, OpenVLA-OFT, CogVLA, Cosmos Policy 등 기존 VLA/정책모델을 능가(랜덤 초기화 대비 +3.6%p, Qwen3.5 초기화 대비도 개선). RoboCasa에서는 데모 300개 기준 Cosmos Policy(66.4%)와 유사한 수준(66.4% vs 65.1%, 랜덤 초기화 대비는 우위), 데모 50개 기준에서는 57.3%로 Cosmos Policy(56.0%) 등을 상회. 추론 속도 면에서는 LIBERO 기준 평균 궤적당 추론시간이 Cosmos Policy 대비 5.2배, RoboCasa 기준 5.5배 빠름.

한계점

저자들은 'Future Directions'(향후 연구방향) 절에서 다음과 같은 제약을 스스로 명시한다: (1) 예측기 규모(0.8B)와 학습 데이터 양이 Wan과 같은 비디오 생성모델에 비해 여전히 작아, 더 큰 규모에서도 이점이 유지되는지는 확인되지 않음. (2) 표현 붕괴를 막기 위해 비전 인코더를 고정했기 때문에, 미래 예측에 유용한 표현으로 인코더 자체를 종단간 학습하지 못함. (3) 예측기가 다음 한 스텝의 잠재 상태만 지도학습되어, 비디오 생성모델처럼 여러 미래 프레임을 자기회귀적으로 길게 예측하는 능력은 검증되지 않음. (4) MPC 실험의 계획 호라이즌이 최대 6스텝으로 비교적 짧아, 더 먼 미래의 결과를 예측해야 하는 장기 과제에서의 성능은 평가되지 않음. (5) LaLa-Policy 평가가 시뮬레이터(LIBERO, RoboCasa)에 한정되어 있으며, 실제 로봇(real robot)에서의 검증은 이루어지지 않음.

시사점

이 연구는 자연어가 서로 다른 물리적 의미와 차원을 가진 다양한 제어 행동 공간을 통합하는 실용적 인터페이스가 될 수 있으며, 동시에 수치 행동 주석이 없는 방대한 이미지·비디오 데이터까지 세계모델 학습에 끌어들일 수 있음을 보여준다. 특히 잠재 표현만 예측하는 효율적인 JEPA 스타일 세계모델도 (픽셀 재구성을 목표로 하지 않고도) 생성적 세계모델에 필적하거나 더 나은 계획 성능을 훨씬 낮은 학습·추론 비용으로 달성할 수 있다는 결과는, 시각적으로 화려한 출력 없이도 잠재 세계모델이 계획과 정책학습에서 실질적 이점을 가질 수 있음을 시사하며, 향후 세계모델 연구가 반드시 고품질 영상 생성을 목표로 하지 않아도 됨을 뒷받침한다.
