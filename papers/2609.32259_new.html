Prefill-Free Cross-Family KV Cache Transfer for Heterogeneous Multi-Agent LLMs

이종 멀티 에이전트 LLM을 위한 프리필 없는 교차 패밀리 KV 캐시 전송

서로 다른 모델 패밀리(Llama, Qwen, Ministral 등)로 구성된 멀티 에이전트 LLM 시스템에서, 수신 측 모델의 재프리필(prefill) 없이도 송신 측의 KV 캐시를 토큰·레이어 정렬과 통계적 재보정을 통해 직접 재사용할 수 있게 하는 방법인 HeteroFold를 제안한다.

한 줄 요약

서로 다른 모델 패밀리(Llama, Qwen, Ministral 등)로 구성된 멀티 에이전트 LLM 시스템에서, 수신 측 모델의 재프리필(prefill) 없이도 송신 측의 KV 캐시를 토큰·레이어 정렬과 통계적 재보정을 통해 직접 재사용할 수 있게 하는 방법인 HeteroFold를 제안한다.

배경 및 문제의식

최근 멀티 에이전트 LLM 시스템은 서로 다른 모델 패밀리나 규모를 조합해 역할을 분담하는 "이종(heterogeneous) 멀티 에이전트 시스템"으로 발전하고 있다. 문제는 에이전트 간 텍스트 기반 통신이다. 한 에이전트(송신자)가 이미 처리한 공유 맥락을 다른 에이전트(수신자)에게 전달할 때, 수신자는 그 텍스트를 처음부터 다시 프리필하여 자신의 KV 캐시를 재구축해야 한다. 이는 맥락 길이가 길어질수록 중복 연산과 지연(latency)을 크게 늘린다. 같은 모델 패밀리 내에서는 KV 캐시를 직접 전달해 이 재프리필을 생략하는 선행 연구(Dense Latent, KV Ridge 등)가 있었지만, 이들은 토크나이저, 모델 깊이, KV 표현 구조가 모두 동일하다는 전제를 깔고 있어 서로 다른 모델 패밀리 간에는 적용할 수 없었다. 즉, 이종 모델 간에는 토크나이저 불일치, 레이어 수 차이, KV 표현 공간의 차이라는 세 가지 장벽이 "프리필 없는 캐시 재사용"을 가로막고 있었다.

핵심 기여

  • 이종 모델 패밀리 간 캐시 전송을 가로막는 핵심 장애물로 토크나이저 불일치를 지목하고, 공유 문자 경계를 기준으로 송수신 토큰을 정렬하는 토큰 정렬(Token Alignment, TA) 기법을 제안.
  • 모델 깊이·KV 구조·특징 분포 차이를 다루기 위해 다층 송신 특징 결합, 교차 헤드 믹싱, 그리고 분포 재정렬(Recolor)을 결합한 교차 패밀리 K/V 매핑을 개발.
  • 단순 캐시 값 재구성만으로는 수신자의 실제 행동(어텐션 패턴·출력)이 보존되지 않음을 보이고, 이를 수신자의 어텐션·출력에 직접 맞추는 출력 인지 보정(output-aware calibration)을 도입. 보정 결과는 고정 아핀(affine) 변환으로 접혀(fold) 들어가 추가 추론 모듈 없이 직접 디코딩이 가능.
  • Llama-3.1-8B, Qwen3-4B, Ministral-3-14B 세 모델 간 6가지 전송 방향 전부에서 기존 프리필-프리 기법(Dense Latent, KV Ridge) 대비 우수한 성능과, 32K 길이에서 원본 프리필 대비 최대 10.7배의 속도 향상을 실증.

방법론

HeteroFold는 송신자 모델 S와 수신자 모델 R을 모두 고정(frozen)한 채, 세 단계로 캐시를 변환한다. (1) 토큰 및 레이어 정렬: 서로 다른 토크나이저가 만든 토큰 경계를 문자 단위 경계로 맞추고(토큰 정렬, TA), 수신자 레이어 하나에 대응하는 정보가 송신자의 여러 레이어에 분산되어 있다는 관찰에 따라 매칭된 레이어 주변의 인접한 송신자 레이어 3개(-4, 0, +4 오프셋)를 결합해 입력 특징을 구성한다(레이어 정렬, LA). (2) 모멘트 매칭 기반 재정렬(Recolor): 단순 재구성 손실(토큰별 오차 최소화)만으로는 KV 값은 비슷해도 수신자의 실제 어텐션 분포는 어긋날 수 있다는 점을 실험으로 보이고, 대신 송신자 특징의 평균·공분산을 수신자 고유 통계에 맞춰 화이트닝(whitening) 및 프로크루스테스(Procrustes) 정렬로 일치시키는 방식을 사용한다. (3) 출력 인지 보정: Recolor까지 거쳐도 남는 어텐션-출력 오차를 줄이기 위해, 전송된 K가 유발하는 어텐션 패턴 변화와 전송된 V가 유발하는 값 변화를 분리하여 각각에 대해 저랭크(rank-ρ) 보정 행렬을 학습한다. K에 대해서는 실제 수신자 쿼리를 이용한 KL발산 기반 손실을, V에 대해서는 고정된 어텐션 가중치 하에서의 출력 오차 손실을 사용해 4 에폭 동안 학습한다. 학습이 끝나면 모든 보정 항은 하나의 고정 아핀 맵으로 "접혀(fold)" 들어가, 추론 시에는 레이어·역할(K/V)별로 하나의 고정 선형 변환만 적용하면 된다.

실험 설정 및 결과

Llama-3.1-8B-Instruct, Qwen3-4B, Ministral-3-14B-Instruct 세 모델 사이의 6가지 전송 방향에 대해, 장문 맥락 QA 벤치마크(Qasper, HotpotQA, LoCoMo, QuALITY)와 단문 맥락 벤치마크(ARC-Challenge, MMLU, WinoGrande, HellaSwag, GSM8K)로 평가했다. HeteroFold는 TA를 적용한 KV Ridge, Dense Latent 등 비교 기법들을 대부분의 설정, 특히 네 가지 장문 맥락 벤치마크 전부에서 능가했다. 멀티 에이전트 상황을 모사한 HiddenBench(숨겨진 개인정보를 교환해 정답을 찾는 과제)에서는, HeteroFold가 수신자 재프리필을 생략하면서도 텍스트 기반 통신(TextMas)과 비슷한 수준의 다수결 정확도(29.2% 대 27.7%)를 달성했으며 무효 응답 비율도 가장 낮았다. 지연시간 측정에서는 32K 토큰 길이의 Llama-3.1-8B→Ministral-3-14B 전송 기준으로 원본 프리필 대비 10.7배, 최신 프리필-프리 기법인 Dense Latent·KV Ridge 대비 1.18~1.47배 빨랐다. 구성요소 제거 실험에서는 토큰 정렬(TA)을 같은 인덱스 단순 매칭으로 바꿀 경우 성능 저하가 가장 컸고, 단일 레이어 매핑이나 헤드별 국소 매핑도 다층·교차 헤드 결합보다 성능이 낮아 각 구성요소의 기여가 확인되었다.

한계점

논문은 평가 대상을 Llama-3.1-8B, Qwen3-4B, Ministral-3-14B 세 모델과 이들 간 6가지 전송 방향으로 한정하고 있어, 더 다양한 모델 패밀리·규모 조합이나 더 많은 에이전트 수로 일반화되는지는 본문에서 별도로 다루지 않는다. 또한 보정(calibration) 과정에 1,600개의 학습 프롬프트와 400개의 held-out 프롬프트가 필요하며, 모델 쌍이 바뀔 때마다 이 보정을 다시 수행해야 한다는 점, 그리고 텍스트 기반 통신(TextMas)에 비해 멀티 에이전트 벤치마크에서는 근접하지만 완전히 동일한 성능에는 도달하지 못했다는 점이 보고되어 있다.

시사점

이 연구는 KV 캐시 재사용을 같은 모델 패밀리 내 최적화 기법에서 서로 다른 모델 패밀리 간에도 적용 가능한 기법으로 확장했다는 점에서, 다양한 전문화된 모델들을 역할별로 조합하는 이종 멀티 에이전트 시스템의 통신 효율을 크게 높일 수 있는 실용적 토대를 제공한다. 저자들은 이를 "모델 패밀리 경계를 넘나드는 보다 범용적인 KV 인터페이스"로 가는 한 걸음으로 자리매김하고 있다.
