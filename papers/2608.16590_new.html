Zetta ζ: An Efficient Closed-Loop Embodied Harness for Self-Evolving Physical Intelligence

제타 ζ: 자기진화형 물리 지능을 위한 효율적 폐루프 임바디드 하네스

Zetta는 기반이 되는 VLA/WAM 정책 모델은 동결한 채, 실행 중 온라인으로 진화하는 코드 기반 런타임 critic과 recovery 스킬만을 갱신함으로써 embodied agent의 폐루프(closed-loop) 실행과 자기진화(self-evolution)를 실현하는 하네스(harness)이다.

한 줄 요약

Zetta는 기반이 되는 VLA/WAM 정책 모델은 동결한 채, 실행 중 온라인으로 진화하는 코드 기반 런타임 critic과 recovery 스킬만을 갱신함으로써 embodied agent의 폐루프(closed-loop) 실행과 자기진화(self-evolution)를 실현하는 하네스(harness)이다.

배경 및 문제의식

물리 지능(physical intelligence) 확장은 크게 두 경로로 진행되어 왔다. 하나는 VLA(vision-language-action)나 WAM(world-action model) 같은 종단간(end-to-end) 정책 모델을 대규모 시연 데이터로 학습시키는 방향이고, 다른 하나는 LLM을 embodied agent로 활용해 정책 모델, 코드, 도구를 오케스트레이션하는 방향이다. 그러나 저자들은 후자의 기존 embodied agent 하네스들이 실제로는 학습을 실현하지 못한다고 지적한다. 실행이 시작되면 agent가 변화하는 로봇-환경 상태를 지속적으로 반영하지 못하고 고정된 스킬이나 사전 계획된 궤적을 따르며, 에피소드가 끝난 뒤에만 사후 반성(reflection)을 수행하는 open-loop 구조라는 것이다. 물리적 상호작용은 밀리초 단위로 변화하는 상태에 대응해야 하는데, 대형 agent 모델은 이런 빈도로 의사결정을 내릴 수 없다. 또한 사후 반성은 대안 행동을 온라인으로 검증할 수 없고, 궤적 전체에 대한 credit assignment가 어려우며, 실패 시점의 정밀한 상태에 접근하기 어렵다는 근본적 한계를 가진다.

핵심 기여

  1. 온라인으로 진화하는 코드 기반 critic과 recovery 스킬을 통해, action 빈도·rollout 배치·반복(iteration) 단위로 시간축이 분리된 세 가지 루프로 구성된 최초의 자기진화형 embodied agent 하네스를 제안.
  2. embodied agent의 자기진화를 지원하도록 설계된 최초의 rollout 인프라 Z-Infra를 제시하여, agent 로직을 이기종(heterogeneous) 실행 자원(CPU/GPU, 모델, 환경)으로부터 분리.
  3. rollout과 진화 반복이 늘어날수록 과제 성공률이 지속적으로 향상되는 스케일링 능력을 실증하고, LIBERO-Pro·RoboCasa 벤치마크에서 SOTA 성능을 달성.

방법론

Zetta는 이중 에이전트 거버넌스 구조를 취한다. 실행 중에는 고정된 다중모달 추론기인 온라인 Orchestrator Agent(A_orch)가 실시간 증거를 감사하고 모드 전환을 승인하며, 오프라인에서는 Evolutionary Agent(A_evo)가 실패 rollout 데이터를 분석해 하네스를 개선한다. 진화 대상인 하네스는 H = {Critic C, Recovery playbook R, Toolset T}로 정의되며, Critic이 궤적을 고빈도로 스캔해 실패 증거와 제안 모드를 담은 구조화된 proposal P_t를 생성하면, Orchestrator가 이를 근거로만 개입 여부를 결정한다(증거 기반 의사결정).

오프라인 진화는 3단계 파이프라인으로 이뤄진다. Phase I(Loop 1)에서는 대규모 rollout 샘플링으로 성공/실패 궤적을 수집하고, 성공 궤적을 마일스톤별로 색인화하는 한편 실패 궤적에서는 '첫 번째 결측 마일스톤(m)'을 찾아 실패 지점을 좁힌다. Phase II Stage 1에서는 성공 분포로부터의 최초 이탈 시점(Earliest Observable Divergence, EOD)을 기준으로 실패를 클러스터링하고, 대표(medoid) seed에 대해 Evaluation→Critic→State→Planning→Recovery→Parameter 순으로 계층을 top-down 탐색하는 인과 진단을 수행해 근본 원인 계층(L)을 특정한다. Phase II Stage 2에서는 해당 계층에 대한 최소한의 패치(C, R, T*)를 만들고, 실패 해소 여부와 접촉 안정성을 함께 요구하는 'VLA 재진입 계약' Ψ(s_t)을 통해 정책 복귀 시점을 안전하게 정의한 뒤, 진단 재현과 신규 rollout 검증을 거쳐 패치를 확정한다. Phase III에서는 여러 seed의 패치를 하나의 통합 하네스(H_merged)로 일반화하고, 원래 실패 클러스터에 대한 회귀 테스트(100% 성공)와 별도의 held-out 데이터셋 평가를 모두 통과해야 최종 반영되는 엄격한 검증 절차를 둔다. 산출물은 SKILL.md, tools/, plans/, params/ 등으로 구성된 버전화된 패키지로 관리된다.

이 진화 루프를 뒷받침하는 것이 Z-Infra다. Control Plane, Environment Worker Layer, Rollout Worker Layer의 3계층 구조로 agent 로직과 하드웨어 자원 관리를 분리하며, 독립적인 환경/모델 워커 풀, 배치 추론, 모델 파티셔닝, 비동기 스케줄링을 통해 동일한 agent 로직을 여러 머신·가속기·모델·환경으로 확장할 수 있게 한다.

실험 설정 및 결과

LIBERO-Pro와 RoboCasa 시뮬레이션 벤치마크에서 평가한 결과, Zetta는 현재 rollout 예산 하에서 각각 90.8%, 93.6%의 SOTA 성공률을 달성했다. 진화 반복이 거듭될수록 성공률은 LIBERO-Pro에서 34.5%→90.8%, RoboCasa에서 73.6%→93.6%로 지속 상승했다. 학습된 스킬의 제로샷 전이 능력도 확인되었는데, RoboCasa의 PnP-Stove 과제에서 학습한 pregrasp·regrasp·안정 배치 스킬이 별도 최적화 없이 PnP-Sink(58%→82%), PnP-Cabinet(62%→80%), PnP-Toaster(72%→90%)로 전이되었다. 또한 초기 진화 라운드에는 성공률이 낮다가 핵심 critic-recovery 메커니즘을 발견하는 순간 급격히 상승하는 '아하 모멘트(Aha Moment)'가 관찰되었다(예: Wine Bottle in Bowl 15%→95%, Put Cream Cheese on Bowl 5%→90%). 추론 속도 측면에서 Zetta는 RPent 대비 지연시간이 91% 감소(11.1배 가속)했으며, Z-Infra는 유효 rollout 처리량을 분당 1.7에서 35.1 에피소드로 20.6배 향상시켜 하네스 진화 루프 자체를 가속했다.

한계점

추출된 본문에는 Control Plane 설명 부분까지만 포함되어 있어 저자들이 명시한 한계점(Limitations) 서술은 논문에 명시되지 않음. 다만 본문에서 기존 접근법의 한계로 언급된 내용, 즉 대형 agent 모델이 물리 상호작용의 밀리초 단위 빈도를 따라가기 어렵다는 점, 저수준 파라미터를 임시방편으로 수정하면 VLA의 의미적 일반화 능력이 손상될 수 있다는 과잉적합 위험, 전문가가 매 실패를 수작업으로 디버깅하는 방식은 확장성이 없다는 점 등은 Zetta가 해결하고자 하는 기존 문제로 서술되어 있을 뿐, Zetta 자체의 한계로 명시되지는 않음.

시사점

기반 정책 모델의 파라미터는 건드리지 않고 코드 기반 critic·recovery·툴셋으로 구성된 하네스만을 온라인으로 진화시키는 접근은, 대규모 재학습 없이도 embodied agent의 물리적 신뢰성을 스케일링할 수 있는 실용적 경로를 제시한다. 또한 rollout 처리량을 지능 스케일링의 병목으로 규정하고 이를 해소하기 위한 전용 인프라(Z-Infra)를 알고리즘과 함께 공동 설계한 점은, 향후 자기진화형 물리 지능 연구에서 시스템과 알고리즘의 공동 설계가 중요함을 시사한다.
