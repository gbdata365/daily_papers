YANAMI: A Large-Scale Multimodal Dataset and Benchmark for Multiturn Stateful Interaction

야나미: 멀티턴 상태 유지 상호작용을 위한 대규모 멀티모달 데이터셋 및 벤치마크

멀티턴 대화에서 참조·제약·정정 등 '상태(state)'를 끝까지 추적·유지·갱신해야 하는 진짜 상태 유지형 멀티모달 상호작용을 학습·평가할 수 있도록, 40만 건의 대화로 이루어진 대규모 학습 데이터셋 YANAMI-400K와 사람이 검증한 평가 벤치마크 YANAMI-Bench를 함께 공개한 연구.

한 줄 요약

멀티턴 대화에서 참조·제약·정정 등 '상태(state)'를 끝까지 추적·유지·갱신해야 하는 진짜 상태 유지형 멀티모달 상호작용을 학습·평가할 수 있도록, 40만 건의 대화로 이루어진 대규모 학습 데이터셋 YANAMI-400K와 사람이 검증한 평가 벤치마크 YANAMI-Bench를 함께 공개한 연구.

배경 및 문제의식

통합 멀티모달 모델(UMM)은 이해·생성·편집을 하나의 모델로 통합하고 있지만, 기존 데이터셋과 벤치마크는 대부분 단일 턴 과제에 치우쳐 있다. 최근 등장한 멀티턴 데이터셋들도 각 턴을 이전 맥락과 무관하게 독립적으로 풀 수 있는 경우가 많아, 모델이 대화가 진행되는 동안 '현재 유효한 상태'(참조 대상, 이전에 걸어둔 제약, 사용자의 정정 등)를 계속 추적하고 반영하는 능력을 제대로 학습·평가하지 못한다는 한계가 있었다. 즉 실제 사용자-어시스턴트 이미지 생성/편집은 한 번에 끝나지 않고 여러 턴에 걸쳐 점진적으로 다듬어지는데, 이를 제대로 다루는 대규모 자원이 없었다는 문제의식에서 출발한다.

핵심 기여

  • 상태 유지형 멀티모달 상호작용을 위한 최초의 대규모 데이터셋·벤치마크 조합인 YANAMI(YANAMI-400K + YANAMI-Bench)를 제안.
  • YANAMI-400K: 40만 건 이상의 멀티턴 대화, 200만 장 이상의 이미지, 264만 턴 규모로, 참조 해결(Reference Resolution)·맥락 검색(Context Retrieval)·일관성 유지(Consistency Maintenance)·공간/물리적 일관성·제약 유지(Constraint Keeping)·정정 기반 상태 갱신(Correction-Based State Updating)이라는 6가지 핵심 능력을 명시적으로 포함하도록 구성.
  • 멀티이미지 융합(Multi-Image Fusion), 이미지 편집(Image Editing), 월드 모델링(World Modeling), 시각적 추론(Visual Reasoning) 4가지 대표 시나리오로 데이터를 구축.
  • 사람이 전수 검증한 400개 대화로 구성된 YANAMI-Bench를 제작하고, 대화 상태 이해(Dialogue State Understanding, DSU)와 시각적 구현(Visual Realization, VR)을 함께 평가하는 체계를 설계해 모델이 상태를 '이해'하는 능력과 이를 이미지로 '구현'하는 능력 사이의 격차를 드러냄.
  • BAGEL 모델을 YANAMI-400K로 파인튜닝해 이미지 편집·생성·상태 유지형 상호작용 성능을 각각 10.3%, 2.0%, 13.23% 끌어올리면서도 기존의 일반 시각 이해 능력은 유지됨을 확인.

방법론

YANAMI-400K는 기존 공개 데이터셋에서 가져온 원본 이미지를 4개 시나리오별 풀로 필터링한 뒤, GPT-5.6 Sol·Qwen3.7-Plus·Gemini 3.1 Pro 등의 LLM과 GPT-Image-2·Nano Banana 2 같은 이미지 생성 모델을 활용해 시나리오·능력별 프롬프트로 멀티턴 대화를 생성하는 파이프라인으로 구축된다. 생성된 대화는 텍스트 논리 검증과 이미지-텍스트 일치 검증을 자동으로 거치고, 실패한 샘플은 반복적으로 수정·재생성되어 최종 데이터셋을 구성한다. YANAMI-Bench는 LLM으로 후보를 만든 뒤 STEM 분야 대학원 수준 훈련을 받은 annotator 3명이 모든 샘플을 수작업으로 검증·수정했으며, 학습 데이터와의 중복을 막기 위해 SHA-256 해시로 두 데이터셋 간 이미지 중복이 없음을 확인했다. 평가는 VLM-as-a-Judge 방식을 채택해, DSU는 참조 해결·맥락 검색·제약 유지·정정 기반 갱신 4가지 유형의 질의응답으로, VR은 시각적 품질과 상태 일관성(State Consistency)으로 측정한다.

실험 설정 및 결과

닫힌 소스 모델 2개(GPT-Image-2, Nano Banana 2), 오픈소스 이미지 편집 모델 4개, 통합 멀티모달 모델 9개 등 총 15개 모델을 YANAMI-Bench로 평가한 결과, 오픈소스 UMM과 이미지 편집 모델의 최고 평균 점수는 각각 67.41점, 67.30점에 그쳤고, 닫힌 소스 모델(GPT-Image-2 83.05점, Nano Banana 2 80.93점)과 뚜렷한 격차가 있었다. 특히 시각적 추론 시나리오에서 대부분 모델의 점수가 가장 낮게 나타났다. 대화가 길어질수록(첫 턴 대비 마지막 턴) BAGEL·FLUX.2·InternVL-U의 성능이 각각 2%, 6%, 6% 하락했고, 모델이 생성한 과거 이미지를 다시 맥락으로 쓰는 Self-History 설정에서는 정답 이력을 쓰는 GT-History 대비 BAGEL·Qwen-Edit 성능이 각각 5.16%, 3.77% 추가로 하락했다. BAGEL을 YANAMI-400K로 파인튜닝하면 GenEval 2%, GEdit-Bench-EN 10.28%, YANAMI-Bench 13.23% 향상되었고, MMBench·POPE 등 일반 시각 이해 지표는 유지되거나 소폭 개선되었다. VLM 심판(Qwen-3.8-Flash-Next)과 인간 평가 간 피어슨 상관은 0.80 이상으로 평가 프레임워크의 신뢰성도 확인했다.

한계점

논문은 평가에서 GT-History(정답 이력 제공) 설정을 기본으로 사용했는데, 이는 실제 배포 환경에서 모델이 자기 생성 이미지를 이력으로 사용할 때 발생하는 오차 누적 문제(Self-History 설정에서 확인된 성능 저하)와는 차이가 있어 실제 사용 시나리오의 어려움을 과소평가할 수 있다. 또한 VLM-as-a-Judge 평가가 인간 평가와 높은 상관을 보이지만 완전히 동일하지는 않으며, 데이터와 벤치마크가 일부 기존 공개 데이터셋의 이미지를 재활용해 구축된 점에서 원천 데이터의 분포·편향에 영향을 받을 수 있다. 세부 한계는 논문에 명시되지 않음.

시사점

단순히 턴 수가 많은 대화가 아니라 참조·제약·정정을 명시적으로 추적해야 하는 '상태 유지형' 상호작용을 데이터 구축 단계에서부터 설계해야, 모델의 장기 멀티턴 멀티모달 능력을 제대로 학습·평가할 수 있음을 보여준다. 특히 '상태를 이해하는 능력'과 '그 이해를 이미지로 충실히 구현하는 능력' 사이의 격차를 분리해서 측정한 점은, 앞으로 통합 멀티모달 모델을 개선할 때 이해 모듈과 생성 모듈을 함께 정교화해야 한다는 방향을 제시한다.
