Deep Fusion Memory: A Chunk-Level Parametric Memory for Large Language Models

딥퓨전메모리: LLM을 위한 청크 단위 파라메트릭 메모리

청크 단위로 외부 지식을 예측해 디코더의 중간 은닉 상태에 게이트 교차주의(gated cross-attention)로 깊게 융합함으로써, 적은 검색 비용으로도 기존 파라메트릭 메모리보다 뛰어난 성능을 내는 LLM용 메모리 아키텍처 Deep Fusion Memory(DFM)를 제안한다.

한 줄 요약

청크 단위로 외부 지식을 예측해 디코더의 중간 은닉 상태에 게이트 교차주의(gated cross-attention)로 깊게 융합함으로써, 적은 검색 비용으로도 기존 파라메트릭 메모리보다 뛰어난 성능을 내는 LLM용 메모리 아키텍처 Deep Fusion Memory(DFM)를 제안한다.

배경 및 문제의식

LLM이 사전학습만으로 다루기 어려운 외부 지식을 활용하려면 지속적 사전학습(CPT)이나 LoRA 같은 파라미터 적응 방법, 혹은 RAG·RETRO 같은 비파라메트릭 검색 증강 방법을 쓸 수 있다. 그러나 전자는 치명적 망각(catastrophic forgetting) 위험이 있고, 후자는 추론 시점에 데이터스토어 검색과 증거 처리로 인한 지연이 크다. 이런 문제를 피하기 위해 MLP Memory, Memory Decoder 같은 '파라메트릭 메모리' 방법이 제안되었는데, 이들은 지식을 오프라인에서 학습해 두고 추론 시 검색 없이 사용할 수 있지만, (1) 토큰 단위로 학습 타깃을 만들기 위해 말뭉치 전체에 대한 방대한 검색이 필요해 데이터 구축 비용이 크고, (2) 예측된 메모리를 출력 확률에 보간(interpolation)하는 얕은 융합 방식만 사용해 디코더 내부 표현을 충분히 활용하지 못한다는 한계가 있다. 저자들은 이 두 가지 비효율(구축 비용과 얕은 융합)을 동시에 해결하고자 한다.

핵심 기여

  • 깊은 융합을 갖춘 파라메트릭 메모리 아키텍처 DFM 제안: 학습된 말뭉치 지식을 디코더의 중간 은닉 상태에 주입하여 이후 레이어들이 메모리와 진화하는 문맥을 함께 처리할 수 있게 하며, 추론 시 명시적 검색이 필요 없다.
  • 지도 신호 구축 및 메모리 학습 비용 절감: 청크 단위 지도(chunk-level supervision)와 백본을 고정한 종단간(end-to-end) 학습을 통해, 기존 토큰 단위 타깃 기반 파라메트릭 메모리 대비 검색 질의 수는 32배, 검색된 항목 수는 2048배 줄였다.
  • QA 성능 및 도메인 적응 성능 향상 입증: 6개 QA 태스크에서 Mistral-7B-v0.3 기준 최강 베이스라인 대비 12.71%, Qwen3-8B-Base 기준 11.19% 향상. 코드·수학·법률 도메인 적응에서도 Qwen3-4B-Base와 Qwen3-8B-Base 대비 각각 평균 6.51점, 4.38점 향상.

방법론

DFM은 크게 (a) 메모리 예측기(Memory Predictor), (b) LLM 백본, (c) 메모리 융합(Memory Fusion) 모듈로 구성된다.

  1. 학습 데이터 구축: 학습 시퀀스를 32토큰 단위의 비중첩 청크 X₀...X_{J-1}로 분할한다. 각 청크 X_j(j≥1)에 대해, 직전 청크 X_{j-1}을 오프라인 검색기로 인코딩하여 말뭉치 데이터스토어에서 top-K(기본 16개) 이웃 청크를 검색하고, 고정된 텍스트 인코더(Qwen3-Embedding-0.6B)로 얻은 임베딩들을 검색 순위대로 쌓아 타깃 메모리 V_j를 구성한다. 즉 토큰마다가 아니라 청크마다 한 번만 검색을 수행한다.
  2. 메모리 예측기: 인과적(causal) 트랜스포머로, 직전 청크들의 평균 풀링된 임베딩(C_j)을 입력받아 K개의 연속 벡터(예측 메모리 V̂_j)를 생성한다. K개의 출력 헤드가 각각 하나의 메모리 슬롯을 담당한다.
  3. 메모리 융합: 공유 프로젝터가 예측 메모리를 디코더 은닉 차원으로 투영한 뒤(M_j), 선택된 디코더 레이어(Mistral/Qwen3 기준 레이어 [9, 16, 24, 31])에서 게이트가 달린 교차주의(gated cross-attention)로 자기주의(self-attention)와 병렬로 적용된다. 토큰·헤드별 시그모이드 게이트가 메모리 기여도를 조절하며, 결과는 잔차 연결을 통해 은닉 상태에 더해진다.
  4. 학습 목표: 표준 언어모델링 손실(L_LM)과 예측 메모리-타깃 메모리 간 평균제곱오차(L_MSE)를 결합해(β=1) 예측기·프로젝터·융합 모듈을 공동 학습하며, 백본·검색 인코더·타깃 메모리는 모두 고정한다.
  5. 추론: 검색이나 외부 인코더 없이, 입력 시퀀스로부터 예측기가 직접 메모리를 생성해 선택된 레이어에 공급한다.

실험 설정 및 결과

  • 데이터/백본: 2018년 12월 영어 위키백과(약 4B 토큰)로 학습. QA 실험은 Mistral-7B-v0.3과 Qwen3-8B-Base를 백본으로 사용(추가 실험으로 OLMo-3-1025-7B도 평가). 도메인 적응은 Qwen3-4B-Base/8B-Base에 Swallow-Code, Swallow-Math, DISC-Law-SFT 데이터를 사용.
  • 비교 대상: 비파라메트릭(RAG, xRAG, RETRO), 파라메트릭(CPT, LoRA, MLP Memory).
  • QA 결과: 6개 벤치마크(NQ, WebQA, HotpotQA, 2Wiki, MuSiQue, Bamboogle) 평균에서 DFM이 두 백본 모두에서 최고 성능을 기록(Mistral 27.21점, Qwen3 26.46점). Mistral 기준 모든 6개 태스크, Qwen3 기준 5개 태스크에서 Base 대비 개선. OLMo-3-1025-7B에서도 평균 17.99→25.49로 개선.
  • 도메인 적응 결과: 코드(HumanEval/HumanEval+), 수학(GSM8K), 법률(LawBench)에서 DFM이 Qwen3-4B-Base 기준 평균 64.69점(Base 대비 +6.51), Qwen3-8B-Base 기준 67.52점(+4.38)으로 비교 방법 중 최고.
  • 효율성: 동일 4B 토큰 말뭉치 기준, MLP Memory 대비 추가 파라미터 50% 감소(0.75B vs 1.5B), 학습 시간 약 62.5% 감소(24시간 vs 64시간, A800 16장 기준), 검색 질의 수 96.88% 감소, 총 검색 항목 수 99.95% 감소(2B vs 4.096T).
  • 분석(Ablation): 청크 크기는 32토큰이 최적(16·64 대비). 융합 레이어는 중간~후반부에 4개 배치하는 것이 최종 레이어 근처에만 집중하는 것보다 우수. 메모리 슬롯 수(K)는 2~16 범위에서 성능 차이가 크지 않아 적은 슬롯으로도 유사 성능 달성 가능. 게이트 사용 및 초기 편향(bias) 0이 게이트 제거보다 우수한 성능을 보임.

한계점

논문은 별도의 '한계점' 절을 명시하지 않았으나, 본문 결과에서 드러나는 한계로: WebQA(Qwen3)에서는 DFM이 Base보다 오히려 낮은 점수를 보이는 등 메모리 적응이 모든 백본·태스크에서 균일하게 유익하지 않음을 저자들이 직접 언급한다. 또한 2Wiki, HotpotQA 등 일부 벤치마크에서는 명시적 검색 기반 방법(RAG, xRAG)이 여전히 DFM보다 우수한 경우가 존재해, 다중 증거가 필요한 태스크에서 검색의 이점이 완전히 대체되지는 않음을 시사한다.

시사점

DFM은 검색 기반 방법의 정확한 증거 접근과 파라메트릭 메모리의 추론 효율성 사이의 절충을 제시하며, 특히 지도 신호를 토큰이 아닌 청크 단위로 공유함으로써 대규모 지식 주입의 데이터 구축 비용을 획기적으로 낮출 수 있음을 보인다. 메모리를 출력 확률 보간이 아닌 디코더 내부 은닉 상태에 깊게 융합하는 설계가 성능 향상에 기여한다는 점은, 향후 파라메트릭 메모리 연구가 '어디에 지식을 주입할 것인가'라는 아키텍처적 문제에 더 주목해야 함을 시사한다.
