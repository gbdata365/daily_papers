Hy-Nomas: Towards Free-form Interactive World Generation

한 줄 요약

8B 파라미터 디퓨전 백본을 기반으로, 자유형식 텍스트 지시와 연속적인 카메라 제어를 여러 상호작용 턴에 걸쳐 결합해 과거 히스토리를 유지하면서 가변 길이 비디오 세그먼트를 생성하는 대화형 월드 생성 모델 Hy-Nomas를 제안한다.

배경 및 문제의식

대화형 월드 생성 모델은 사용자의 연속적인 명령을 따르면서도 이전 상호작용의 결과와 관련 히스토리를 유지해야 한다. 기존 비디오 생성은 고정된 프롬프트로 짧은 클립을 미리 생성하는 방식이었지만, 대화형 월드는 생성 중간에 들어오는 입력 명령을 수용하고, 행동에 따라 달라지는 동역학을 모델링하며, 이전 행동의 결과를 보존해야 한다는 점에서 근본적으로 다르다. 사전학습된 양방향(bidirectional) 디퓨전 트랜스포머를 단순히 인과적 마스크로 바꾸는 것만으로는 부족하며, 정보 누출 없이 과거 히스토리로부터 다음 세그먼트를 생성하고 캐시된 컨텍스트를 효율적으로 재사용해야 한다. 또한 각 생성 세그먼트가 다음 세그먼트의 근거가 되므로 작은 오류가 누적되어 외형 드리프트나 비현실적 동작, 장면 붕괴로 이어질 수 있고, 멀티턴 상호작용에서는 지속적인 장면 정보는 유지하되 특정 행동 지시는 의도된 시간 구간에만 영향을 미쳐야 하는 어려움이 추가된다.

핵심 기여

자유형식 텍스트 지시와 연속 카메라 제어를 하나의 생성 백본에서 다중 턴에 걸쳐 결합하는 8B 파라미터 월드 모델 Hy-Nomas를 제안한다. 핵심 설계는 구조화된 비디오 캡션과 "행동 인지(action-aware) 인과적 어텐션"을 정렬시킨 것으로, 서술적 맥락은 세그먼트 전체에서 접근 가능하게 유지하면서 행동 지시는 그 의도된 시간 구간에만 제한되도록 한다. 사용자의 요청과 멀티모달 상호작용 히스토리를 다음 세그먼트에 대한 구조화된 조건으로 변환하는 비전-언어 Prompt Enhancer(PE)를 도입했고, 인과적 생성·텍스트 상호작용·카메라 제어·모델 자신이 생성한 히스토리에 대한 학습을 순차적으로 도입하는 다단계 커리큘럼과 디퓨전 증류(distillation)로 모델을 학습시켰다. 또한 평가를 위해 280개 테스트 케이스로 구성된 Hy-Nomas-Bench를 공개하고, 모델 가중치·코드·경량 어댑테이션(LoRA) 워크플로우를 함께 공개했다.

방법론

Hy-Nomas는 "PLAN → GENERATE → CONTINUE"의 자기회귀적 루프로 동작한다. 사용자가 텍스트나 카메라 입력을 주면 Prompt Enhancer가 이를 다음 세그먼트의 구조화된 텍스트 프롬프트와 지속 시간으로 변환하고(PLAN), 오토리그레시브 DiT가 캐시된 KV와 함께 소수 단계(few-step) 디노이징으로 다음 세그먼트를 생성하며(GENERATE), 생성된 세그먼트가 다시 growing video prefix로 누적되어 다음 턴의 컨텍스트가 된다(CONTINUE). 핵심 아키텍처 요소는 세그먼트 단위 인과적 어텐션(segment-wise causal attention)으로, 서술적 캡션 정보는 여러 세그먼트에서 지속적으로 참조 가능하게 두면서도 행동 지시는 해당 시점 구간에만 영향을 주도록 제한해 인과성을 깨지 않도록 설계했다. 카메라 제어는 별도의 카메라-궤적 조건화(camera-trajectory conditioning) 메커니즘으로 처리되어 자유형식 텍스트 명령과 함께 인터리빙될 수 있다. 학습은 다단계 커리큘럼으로 진행되는데, 인과적 생성 → 텍스트 상호작용 → 카메라 제어 → 모델 자신이 생성한(합성) 히스토리에 대한 학습 순으로 점진적으로 난이도를 높이고, 마지막으로 디퓨전 증류를 적용해 추론 효율을 높였다. 로보틱스 등 다른 도메인으로의 적응을 위해 LoRA 기반의 경량 다운스트림 어댑테이션도 지원한다.

실험 설정 및 결과

평가를 위해 멀티턴 자유형식 텍스트 상호작용, 카메라 제어, 텍스트·카메라 인터리빙 상호작용, 공간 기억(spatial memory)을 각각 측정하는 네 개 벤치마크로 구성된 Hy-Nomas-Bench(총 280개 테스트 케이스)를 구축했고, Genie 3, HappyOyster(-Directing), LingBot-World v2 등 기존 월드 모델과 사람 평가자 기반의 쌍대 비교(pairwise human evaluation, net win rate = win rate - loss rate)로 비교했다. 멀티턴 텍스트 상호작용에서 Hy-Nomas는 프롬프트 충실도 기준으로 HappyOyster-Directing 대비 65.0%, LingBot-World v2 대비 75.0%의 승률을 보였고, 물리적 타당성 기준으로는 각각 45.0%와 68.3%의 승률을 기록했다. 카메라 제어에서도 세 비교 모델 대비 일관되게 승률이 패율보다 높았지만 텍스트 상호작용만큼 큰 격차는 아니었다. 다만 공간 기억(장기 장면 일관성 유지) 측면에서는 HappyOyster와는 비슷한 수준이지만 Genie 3에는 뒤처지는 것으로 나타났으며, 인터리빙된 텍스트·카메라 제어 상황에서는 일부 설정에서 성능 저하(19% 승률 대 37% 패율)가 관찰되었다.

한계점

공간 기억 능력, 특히 장기간 상호작용에서 이전에 관찰된 장면의 정체성·배치·상태 변화를 안정적으로 재현하는 능력은 Genie 3 대비 뒤처지는 것으로 나타나 개선이 필요한 영역으로 지적된다. 텍스트와 카메라 제어를 동시에 인터리빙하는 복합 상황에서는 단일 제어 신호 상황보다 성능이 저하되는 경우가 있다. 또한 전체 상호작용 히스토리를 GPU에 KV 캐시로 유지하는 방식은 롤아웃이 길어질수록 메모리 비용이 커지는 구조적 한계가 있으며, 로보틱스 제어로의 확장은 LoRA 기반의 초기 단계 실험에 그쳐 실제 로봇 행동과의 연계 평가는 이루어지지 않았다.

시사점

저자들은 8B라는 비교적 작은 파라미터 규모에도 불구하고 Hy-Nomas가 더 큰 비교 모델들보다 강한 텍스트 기반 제어 성능을 보인 것이, 구조화되고 상세한 비디오 캡션이 디퓨전 트랜스포머가 묘사되지 않은 내용을 "상상"해야 하는 부담을 줄여주기 때문이라는 가설을 제시한다. 이는 향후 시스템이 디퓨전 모델을 장면 내용과 시간적 전개를 정확히 "렌더링"하는 역할에 집중시키고, 캡션과 Prompt Enhancer의 품질·구체성을 핵심 과제로 삼아야 함을 시사한다. 또한 장기 상호작용에서의 기억 관리를 위해 기하·이미지·텍스트 등 서로 다른 정보 유형에 적합한 메모리 표현을 결합하는 에이전틱 월드 모델 설계가 향후 연구 방향으로 논의된다.
