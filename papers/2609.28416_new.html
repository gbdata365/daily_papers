Agent-Editing World Model: Rethinking World Modeling for LLM Agents

에이전트 편집 월드 모델: LLM 에이전트를 위한 월드 모델링 재고찰

환경의 관찰 결과를 그대로 예측하는 기존 월드 모델 대신, 에이전트의 추론과 행동이 향후 과업 진행 상황에 어떤 영향을 미치는지를 모델링하고 잘못된 상태를 직접 고쳐주는 새로운 방식의 월드 모델 AEWM을 제안한 연구.

한 줄 요약

환경의 관찰 결과를 그대로 예측하는 기존 월드 모델 대신, 에이전트의 추론과 행동이 향후 과업 진행 상황에 어떤 영향을 미치는지를 모델링하고 잘못된 상태를 직접 고쳐주는 새로운 방식의 월드 모델 AEWM을 제안한 연구.

배경 및 문제의식

기존의 언어 기반 월드 모델은 주로 환경의 관찰(도구 응답 등)을 예측하도록 설계되지만, 실제 도구 실행 결과를 이미 얻을 수 있는 상황에서는 높은 엔트로피를 가진 도구 응답을 다시 예측하는 것이 큰 가치를 주지 못한다. 동시에 에이전트는 근거 없는 가정이나 낡은 계획이 이력에 남아 이후 의사결정을 왜곡시키는 "과업-상태 오염(task-state contamination)" 문제를 겪는다.

핵심 기여

  1. 도구 응답을 시뮬레이션하는 대신 추론·행동이 과업 진행에 미치는 영향을 모델링하는 AEWM(Agent-Editing World Model) 제안.
  2. 결정을 CRITICAL·EXPLORATORY·NOISY로 구분하는 액션 판정기(Action Judge)와, 동일한 관찰 이력에서 잡음이 낀 추론-행동 연속체를 고쳐 쓰는 상태 수정(State Revision) 기법 결합.
  3. 이 두 기능을 실제 실행 결과와 통합해 비평만 제시하는 것이 아니라 이후 결정의 근거가 되는 상태 자체를 직접 바꾸는 EditAct 기법 제안.
  4. 검증된 EditAct 궤적으로 거부 샘플링 파인튜닝을 수행하는 AEWM-RFT 제시.

방법론

연구팀은 검색(Search), 터미널(Terminal), 소프트웨어 엔지니어링(SWE) 세 가지 영역에 걸쳐 중간학습(mid-training)과 지도 파인튜닝(SFT)으로 AEWM을 훈련시켰다. Action Judge는 각 결정이 이후 과업에 결정적인지, 탐색적인지, 잡음에 불과한지를 분류하고, State Revision은 잡음이 낀 추론-행동 이어붙이기를 동일한 관찰 이력을 바탕으로 다시 작성한다. EditAct는 이 두 요소를 실제 실행 피드백과 결합해 에이전트의 이후 의사결정에 사용될 상태를 실질적으로 교정한다.

실험 설정 및 결과

Qwen3.5-35B-A3B 등 세 가지 에이전트 백본과 여섯 개 벤치마크에 대한 실험에서, AEWM은 자체 Action Judge 벤치마크에서 70.5%의 매크로-F1을 기록해 가장 강력한 프론티어 베이스라인보다 10.6점 앞섰다. EditAct는 여섯 개 벤치마크 평균에서 최강 베이스라인 대비 3.2~6.7점의 성능 향상을 가져왔으며, 온라인 AEWM 안내 없이도 검증된 궤적만으로 파인튜닝한 AEWM-RFT는 Self-RFT 대비 세 도메인에서 2.2~2.6점 향상을 보였다.

시사점

월드 모델의 역할을 "환경을 그대로 재현하는 것"에서 "에이전트의 상태를 능동적으로 교정하는 것"으로 전환함으로써, 장기 호라이즌 과업에서 신뢰할 수 있는 추론과 전이 가능한 에이전트 학습을 위한 새로운 설계 방향을 제시한다.
