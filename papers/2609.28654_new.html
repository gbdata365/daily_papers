한 줄 요약

비디오 생성 모델이 아기도 갖고 있는 "물체 영속성(object permanence)"과 "물체 고형성(object solidity)"을 실제로 내재화했는지 평가하고, 이를 학습시킬 수 있는 데이터와 모델을 함께 제시한 연구.

배경 및 문제의식

Sora, Veo, Kling 등 최신 비디오 생성 모델은 사실적이고 시간적으로 일관된 영상을 만들어내며 "월드 모델"로 주목받고 있지만, 물체가 가림막 뒤로 사라졌다가 엉뚱한 위치에서 다시 나타나거나 단단한 장애물을 그대로 통과하는 등의 오류가 반복된다. 발달심리학에서는 생후 3.5개월 무렵부터 영아가 가려진 물체의 존재를 표상하고, 생후 6개월 이내에 고형성 위반을 감지한다고 알려져 있는데, 저자들은 이런 "핵심 지식(core knowledge)"이 비디오 생성 모델의 물리적 추론 능력의 토대가 되어야 한다고 본다. 기존 벤치마크들은 대부분 2차원 환경에 국한되거나, 학습용 데이터가 부족하고, VLM을 채점자로 사용해 신뢰성이 떨어지는 한계가 있었다.

핵심 기여

  1. Blender로 제작한 150개의 생성기(제너레이터)로 구성된 3차원 벤치마크 WROP(World Reasoning with Object Permanence)를 공개: 물체 영속성 3종·물체 고형성 3종, 총 6개 과제군.
  2. 과제당 1만 개 이상, 총 150만 개 샘플 규모의 학습 코퍼스와 300문항 고정 평가셋 공개.
  3. 이 데이터로 파인튜닝한 160억 파라미터 규모의 연속 생성(continuation) 모델 PWM-WROP 공개.
  4. VLM 채점 대신 20명의 인간 평가자를 동원한 블라인드 쌍대비교(페어와이즈) Elo 평가 체계 도입.

방법론

각 제너레이터는 물리적으로 중요한 사건(가림, 충돌, 지지대 제거 등)이 영상의 중간 지점 이후에 일어나도록 설계되며, 입력 절반(사건 이전 맥락)을 보고 사건과 그 결과가 담긴 목표 절반을 생성하는 "비디오-투-비디오(V2V)" 형식을 취한다. 구조적 파라미터(물체 수, 궤적, 가림 형태 등)는 과제 난이도를 결정하도록 체계적으로 바꾸고, 표면적 파라미터(색상, 재질, 조명, 카메라 시점)는 물리적 문제 자체를 바꾸지 않으면서 시각적 다양성만 높이도록 독립적으로 무작위화했다. PWM-WROP는 이 데이터로 사후학습(post-training)되었으며, AWS Trainium2 기반의 자체 PyTorch 학습 스택(PWM)으로 구현되었다.

실험 설정 및 결과

연속 생성 모델 4종, 참조-투-비디오 모델 3종, 편집 모델 7종 등 총 14개 비디오 모델을 300문항 평가셋으로 테스트했다. 20명의 평가자가 참여한 블라인드 쌍대비교(Bradley–Terry 기반 Elo, 평균 1500)에서 PWM-WROP는 연속 생성 모델 중 1위(Elo 1679.5)를 기록했으며, 전체 14개 모델 중에서는 통계적으로 동률인 두 상용 참조-투-비디오 모델(Elo 1723.6)에 이어 3위를 차지했다. 이는 PWM-WROP가 320×192라는 상대적으로 낮은 해상도(경쟁 모델은 720p·1080p)에서 달성한 결과이며, 동일 해상도 기준으로는 LPIPS·MS-SSIM 지표에서 최고 성능을 보였다.

한계점

논문에 구체적인 한계 섹션은 별도로 명시되지 않았으나, 결론부에서 이번 결과가 "인지과학 기반의 합성 데이터 학습이 비디오 생성 모델의 물리적 추론 능력을 향상시키는 유효한 경로일 수 있다는 예비적 증거"라고 조심스럽게 표현하고 있어, 저해상도 모델이라는 제약과 아직 초기 단계의 검증이라는 점이 암묵적 한계로 보인다.

시사점

물체 영속성·고형성처럼 발달심리학에서 정립된 핵심 인지 개념을 명시적인 학습 신호로 삼으면, 비디오 생성 모델의 물리적 타당성을 체계적으로 개선할 수 있음을 보여준다. 또한 VLM 채점의 한계를 지적하며 인간 평가 기반의 정밀한 벤치마크 설계가 물리적 추론 평가에 필수적이라는 점을 시사한다.
