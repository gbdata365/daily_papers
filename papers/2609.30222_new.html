TrackEverything: Long Horizon Dense Tracking via De-Duplicating 3D Scene Representations

트랙에브리씽: 중복 제거 3D 장면 표현을 통한 장기 지평선 밀집 추적

비디오를 2D 픽셀이 아닌 월드 좌표계의 지속적인(persistent) 3D 장면 표현으로 다루고, 동일한 물리적 표면을 반복 관찰할 때 생기는 중복 트랙을 복셀 기반으로 병합함으로써, 1000프레임이 넘는 긴 영상의 모든 지점을 40GB GPU 메모리 안에서 추적하는 최초의 3D 트래커 TrackEverything을 제안한다.

한 줄 요약

비디오를 2D 픽셀이 아닌 월드 좌표계의 지속적인(persistent) 3D 장면 표현으로 다루고, 동일한 물리적 표면을 반복 관찰할 때 생기는 중복 트랙을 복셀 기반으로 병합함으로써, 1000프레임이 넘는 긴 영상의 모든 지점을 40GB GPU 메모리 안에서 추적하는 최초의 3D 트래커 TrackEverything을 제안한다.

배경 및 문제의식

기존 포인트 트래킹은 두 극단 중 하나를 택해야 했다: 희소 트래커는 사용자가 지정한 소수의 점을 긴 시간 동안 추적할 수 있지만 장면 전체를 다루지 못하고, 밀집(dense) 트래커는 프레임 국소 픽셀 공간에서 동작해 프레임마다 새로운 시각 토큰을 처리해야 하므로 영상 길이가 길어질수록 계산·메모리가 폭발적으로 증가해 48~64프레임 정도의 짧은 클립에 머물거나 첫 프레임에 보이는 점만 추적하는 데 그쳤다.

핵심 기여

  • 슬라이딩 윈도우 경계에서 동일 위치로 수렴하는 트랙들을 복셀화 기반으로 병합하는 중복 제거 메커니즘을 도입해, 표현 복잡도가 영상 길이가 아닌 장면의 고유한 물리적 기하 구조에 맞춰 확장되도록 함.
  • 트래킹을 "각 점의 도착 지점과 정적/동적 여부를 예측하는 종점 정제기(endpoint refiner)"와 "동적 점에 대해서만 조밀한 궤적을 디코딩하는 경량 궤적 정제기(trajectory refiner)"로 분해.
  • 메모리를 많이 쓰는 4D 상관 볼륨 대신 장면 클라우드에서 효율적으로 특징을 샘플링하는 3D WAFT(warp-aligned feature transform의 3D 확장) 제안.

방법론

슬라이딩 윈도우 전략으로 영상을 처리하며, 윈도우 안에서는 카메라 포즈와 깊이(센서 또는 VGGT 같은 기성 추정기 사용)를 이용해 2D 시각 특징을 월드 좌표 특징 클라우드로 역투영(unproject)한다. 종점 정제기 트랜스포머가 3D WAFT 특징 샘플링을 이용해 각 점의 윈도우 종료 시점 3D 위치를 반복 갱신하면서 동시에 정적/동적 여부를 분류하고, 동적으로 분류된 점에 대해서만 궤적 정제기가 윈도우 내 조밀 궤적을 디코딩한다(정적 점은 위치를 그대로 유지). 각 윈도우 경계에서는 갱신된 위치 기준으로 3D 특징 클라우드를 복셀화해 동일 위치의 점들을 병합함으로써, 다음 윈도우로 넘어갈 때 새로 드러난 장면 내용과 함께 다뤄질 압축된 트랙 집합을 만든다.

실험 설정 및 결과

TAPVid-3D 벤치마크에서, 기존 밀집 3D 트래커들이 실행 가능한 짧은 클립 구간에서는 모든 오픈소스 전프레임(all-frame) 밀집 3D 트래커를 APD 기준 20% 이상 앞섰다. 기존 밀집 트래커들이 대략 96프레임을 넘으면 GPU 메모리가 소진되는 것과 달리, TrackEverething은 1000프레임이 넘는 영상에서도 40GB GPU 메모리 내에서 모든 가시점을 추적한 최초의 3D 트래커이며, 훨씬 많은 점을 추적하면서도 긴 시퀀스에서 최신 희소 트래커와 경쟁력 있는 성능을 유지했다.

한계점

복셀화 기반 중복 제거가 메모리 증가를 억제하지만, 영구적인(perpetual) 오픈월드 탐사 상황에서는 활성 메모리가 계속 늘어나므로 시간 단위(hour-long) 궤적을 위해서는 공간 캐시 축출(cache eviction) 같은 추가 기법이 자연스러운 다음 단계다. 또한 기존 3D 트래킹 모델들처럼 외부에서 제공되는 기하 정보(깊이·포인트맵)에 의존하므로 성능이 그 포인트맵 품질에 종속된다. 마지막으로 윈도우 경계에서의 복셀화 병합은 순전히 공간적 근접성에 기반하므로, 관련 오류가 발생할 수 있다(논문에 명시, 세부 내용은 이어지는 문장에서 논의되나 발췌 범위를 넘어감).

시사점

영상을 프레임 단위가 아닌 "고유한 물리적 장면 콘텐츠" 단위로 확장되는 3D 표현으로 다루는 접근이, 길이가 매우 긴 비디오를 다루는 비전-언어 모델, 로봇 조작 정책, 비디오 생성 모델 등 동적 실세계 환경을 다뤄야 하는 후속 파운데이션 모델들의 새로운 기반 표현이 될 수 있음을 보여준다.
