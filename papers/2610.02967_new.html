Post-Training Frontier Text-to-Image Models by Composing Preference and Rubric Rewards

선호도와 루브릭 보상을 결합한 최상위 텍스트-이미지 모델 후속학습

이미지 생성 모델의 후속학습(post-training)에서 대규모 인간 선호도 기반 보상(preference reward)과 프롬프트 충실도를 평가하는 루브릭 기반 보상(rubric reward)을 효과적으로 결합하는 방법을 제안하여, FLUX.2-dev와 Ideogram-4 등 최상위 텍스트-이미지 모델을 실제 사용자 블라인드 평가에서 큰 격차로 향상시킨다.

한 줄 요약

이미지 생성 모델의 후속학습(post-training)에서 대규모 인간 선호도 기반 보상(preference reward)과 프롬프트 충실도를 평가하는 루브릭 기반 보상(rubric reward)을 효과적으로 결합하는 방법을 제안하여, FLUX.2-dev와 Ideogram-4 등 최상위 텍스트-이미지 모델을 실제 사용자 블라인드 평가에서 큰 격차로 향상시킨다.

배경 및 문제의식

텍스트-이미지(T2I) 생성 모델이 시각적 품질에서 빠르게 발전해왔지만, 단일 보상 신호만으로는 사용자의 선호 전반을 포착하기 어려워 후속학습이 여전히 어렵다. PickScore, HPSv2/v3 같은 학습된 선호도 보상 모델은 미학적·전반적 선호를 폭넓게 반영하지만, 프롬프트가 요구하는 모든 객체를 충실히 포함하는지와 같이 쌍별 투표(pairwise vote)에서 드물게만 드러나는 속성에는 둔감하다. 실제로 FLUX.2-dev를 저자들이 독립적으로 학습한 Arena 보상 모델이나 공개된 PickScore에 직접 최적화하면, 보상 점수는 계속 증가하지만 실제 품질은 빠르게 정체되었다가 저하되는 "보상 해킹(reward hacking)" 현상이 관찰되었다.

핵심 기여

  • 약 500만 개의 쌍별 인간 선호도 투표(Arena 데이터)로 학습한 Bradley-Terry 기반 선호도 보상과, 프롬프트 충실도·의도 제약을 명시적으로 평가하는 개방형 루브릭 보상을 결합하는 후속학습 레시피 제안.
  • 단순 가중 평균 결합은 최적화 거동을 저해한다는 것을 보여주고, 이를 해결하는 보상 결합 전략(정규화, 해킹 탐지기를 통한 긍정 보상 억제, 보상 간 간섭을 줄이는 게이팅 메커니즘, LoRA 델타 가중치 공간 앙상블) 제안.
  • Arena 텍스트-이미지 리더보드에서 RL로 학습된 FLUX.2-dev가 기본 모델보다 Elo 69점 높은 점수를 달성; 후속학습된 Ideogram-4는 리더보드의 모든 오픈소스 모델을 능가하며 Elo 1223.5 기록.
  • 재현 가능한 연구를 위해 전체 학습 데이터의 1K 부분집합인 Arena-T2I-Training 데이터셋을 공개.

방법론

보상 시스템은 두 축으로 구성된다. (1) 선호도 보상: Qwen3.6-27B를 백본으로 사용하고 <|cls|> 토큰의 은닉 상태를 읽는 선형 헤드를 추가해 Bradley-Terry 로짓을 출력하도록, 2025년 4월부터 2026년 6월까지 수집된 100개 이상의 T2I 모델에 대한 약 500만 쌍의 투표 데이터로 학습(밝기·대비·채도 변형과 가우시안 노이즈로 저수준 통계에 대한 로버스트성 강화). (2) 루브릭 보상: 프롬프트를 의존성 기반의 예/아니오 질문 집합으로 분해하여 충실도를 평가하는 충실도 보상, 프롬프트에 없는 내용을 추가하는 것을 억제하는 의도 게이팅 제약 보상, 그리고 최적화 과정에서 나타나는 알려진 악용 행동을 식별하는 해킹 탐지기로 구성. 이 이질적인 보상들을 결합하기 위해 각 보상을 [0,1] 범위로 정규화하고, 해킹 탐지기의 출력은 추가 보상 항이 아니라 탐지된 악용에 연관된 긍정적 선호도 보상을 억제하는 데 사용하며, 서로 경쟁하는 보상 신호 간 간섭을 줄이는 게이팅 메커니즘을 적용하고, 독립적으로 최적화된 정책들의 LoRA 델타를 가중치 공간에서 평균하여 앙상블한다.

실험 설정 및 결과

  • Arena 리더보드 Elo 점수(2026년 9월 4일 스냅샷 기준): FLUX.2-dev 기본 모델 1132.8 → 후속학습 모델 1202 (69점 향상); Ideogram-4 기본 모델(최고 오픈소스) 1204 → 후속학습 모델 1224(본문 기준 1223.5), 모든 공개 오픈소스 모델을 능가.
  • 단계별 소거 실험: 선호도 보상만 사용한 최적화는 품질이 기준 미달 수준까지 저하되지만, 의도 게이팅 제약 보상을 추가하면 성능이 패리티(parity)를 넘어서는 핵심 전환점이 되었음(예: Ideogram-4의 승률이 0.4005에서 0.5526로 상승).
  • Ideogram-4 사례: 후속학습이 텍스트 렌더링 능력을 크게 저하시킬 수 있음을 발견하여 OCR 기반 보상을 추가로 포함시켜 대응.

한계점

저자들이 명시한 한계는 다음과 같다: 첫째, 단 두 개의 기반 모델(FLUX.2-dev, Ideogram-4)에서만 평가하여 다른 모델군이나 규모로의 일반화 가능성을 충분히 검증하지 못했다. 둘째, 다단계 상호작용과 도구 사용이 수반되는 에이전틱 워크플로우에서는 평가하지 않았다. 셋째, 충실도 평가에 쓰이는 분해된 질문들은 인간 평가자에 의해 검증(audit)되지 않아 분해 과정에서의 오류나 모호성이 남아있을 수 있다. 넷째, 계산 제약으로 인해 단일 무작위 시드(seed)로만 결과를 보고하였다.

시사점

대규모 선호도 학습과 명시적인 루브릭 기반 평가가 서로 경쟁하는 접근이 아니라 상호 보완적으로 결합될 수 있음을 실제 production 모델 규모에서 입증했다는 점에서, 향후 생성 모델의 RLHF 계열 후속학습 설계에 참고할 수 있는 실용적인 보상 설계 패턴을 제시한다. 특히 보상 해킹을 억제하는 메커니즘과 서로 다른 레시피로 학습된 정책을 가중치 공간에서 앙상블하는 기법은 다른 생성 모델링 영역의 후속학습에도 일반화될 수 있는 잠재력을 지닌다.
