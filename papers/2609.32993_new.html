X-Tree: Tokenizing Reusable Experience for Efficient Agent Generalization

X-Tree: 효율적인 에이전트 일반화를 위한 재사용 가능 경험의 토큰화

멀티스텝 에이전트 학습 데이터에서 반복되는 하위 절차(서브스킬)를 LLM 호출 없이 자동으로 찾아내 계층적 트리(X-Tree)로 묶고, 이를 오프라인 강화학습·온라인 RLVR·온폴리시 자기증류 세 가지 학습 방식에 각각 통합해 에이전트의 일반화 성능을 끌어올리는 방법을 제안한다.

한 줄 요약

멀티스텝 에이전트 학습 데이터에서 반복되는 하위 절차(서브스킬)를 LLM 호출 없이 자동으로 찾아내 계층적 트리(X-Tree)로 묶고, 이를 오프라인 강화학습·온라인 RLVR·온폴리시 자기증류 세 가지 학습 방식에 각각 통합해 에이전트의 일반화 성능을 끌어올리는 방법을 제안한다.

배경 및 문제의식

웹 탐색, 코드 저장소 수정, 장기 상호작용 환경 조작 등 멀티스텝 에이전트를 SFT나 RLVR로 학습할 때 기존 방식은 궤적을 "평평한(flat)" 행동 시퀀스로 간주하고 모든 토큰에 동일한 가중치를 부여한다. 그러나 사람은 과제를 수행할 때 반복적으로 등장하는 하위 절차(예: "날짜 범위를 입력하고 적용 버튼을 누른다")를 재사용 가능한 단위로 인식하고 이를 바탕으로 계획을 세운다. 이런 계층 구조가 데이터 안에는 존재하지만 균일 가중치 학습은 이를 전혀 활용하지 못해, 희소한 궤적 데이터를 충분히 활용하지 못하는 비효율이 발생한다. 최근 일부 에이전트 프레임워크는 LLM으로 과거 경험을 자연어 스킬로 요약해 프롬프트에 주입하지만, 이 지식은 모델 가중치에 압축되지 않아 검색(retrieval) 범위를 벗어나면 일반화되지 않는다는 한계가 있다.

핵심 기여

  • 텍스트 BPE 토크나이저처럼 행동 시퀀스에서 재사용 가능한 쌍을 반복적으로 병합해, LLM 호출 없이 결정적(deterministic)이고 감사 가능한 계층 구조인 X-Tree를 구축하는 방법을 제안.
  • 병합 기준으로 재사용성을 반영하는 새로운 지표인 X-Score(빈도, 길이, 성공률의 곱)를 도입.
  • X-Tree를 (1) 오프라인 RL의 학습 인스턴스, (2) 온라인 RLVR의 적응형 스킬 보너스, (3) 온폴리시 자기증류(OPSD)의 특권적 컨텍스트라는 세 가지 학습 설정에 통합하는 방법을 각각 설계.
  • WebArena, ScienceWorld, WebShop 세 환경과 세 가지 모델 규모(1.5B~7B)에 걸쳐 동일한 데이터·예산 조건에서 일관된 성능 향상을 실험적으로 검증.

방법론

X-Tree 마이닝은 먼저 각 원시 행동을 구체적 값(요소 ID 등)은 제거하고 동사⟨역할⟩ 형태로 정규화(canonicalization)한 뒤, 코퍼스 내에서 인접하게 등장하는 기호 쌍 u, v에 대해 X-Score = 빈도 × 길이^p_ℓ × (성공률+ε)^p_s 를 계산하여 가장 높은 점수를 가진 쌍을 반복적으로 병합한다. 병합은 코퍼스를 실제로 압축시킬 때만(비용 파라미터 η 기준 충족 시) 수행되며, 이 과정을 통해 리프 노드는 정규화된 개별 행동이고 내부 노드는 더 깊은 하위 스킬들의 조합인 트리가 만들어진다.

이 X-Tree는 세 가지 방식으로 학습에 투입된다. (1) 오프라인 RL(환경 없이 궤적만 있는 설정): 각 X-Tree 노드를 하나의 GRPO 학습 인스턴스로 사용해, 정답 궤적의 앞부분을 조건으로 정책이 노드 길이만큼 롤아웃하도록 하고, 스텝별 일치도 보상과 깊이에 비례한 완료 보너스를 결합한 보상 함수를 적용한다. (2) 온라인 RLVR: 환경과 검증기가 있는 설정에서, 롤아웃이 실행한 X-Tree 스킬 노드마다 추가 보너스를 주되, 그룹 내 성공률이 낮을 때(검증 신호가 희소할 때)는 보너스 비중을 높이고 신호가 충분해지면 점차 0으로 줄이는 적응형 가중치(λ_g)를 사용한다. (3) OPSD: 학생과 동일한 정책을 쓰는 교사 모델에게 검색된 X-Tree 스킬을 특권적 컨텍스트로 제공하고, 학생과 교사의 토큰별 로그확률 차이를 신뢰도 게이트로 활용한 증류 손실 항을 RL 목적함수에 추가해, 기존에 LLM이 직접 작성하던 스킬 라이브러리를 대체한다.

실험 설정 및 결과

  • 오프라인 RL(WebArena, Qwen2.5-7B): 동일한 궤적 풀과 추가 환경 상호작용 없이 X-Tree를 적용한 결과, 전체 데이터 SFT 대비 성공률(SR)이 최대 4.5%p 향상(22.9 대 18.4, 약 24% 상대 개선)했으며, 특히 절차 집약적인 admin(+6.4), gitlab(+5.2), shopping(+4.9) 사이트에서 개선폭이 컸다. 무작위 트리나 전체 궤적 학습으로 대체하는 어블레이션에서 성능이 하락해, 구조 자체와 제안된 RL 보상 설계 모두가 기여함을 확인했다.
  • 온라인 RLVR(ScienceWorld, WebShop; 1.5B/3B/7B): 결과 전용(outcome-only) GRPO 대비 ScienceWorld에서 최대 5.8%p(미학습 과제 기준), WebShop에서 성공률 최대 3.6%p·점수 최대 4.6%p 향상. 검증 신호가 희소한 구간(작은 롤아웃 수 등)에서 X-Tree 보너스의 효과가 더 두드러졌다.
  • OPSD(ScienceWorld, WebShop): LLM이 직접 작성한 스킬 뱅크와 비교해 X-Tree 기반 특권 컨텍스트가 LLM 호출 비용 없이 대등하거나 더 나은 성능(ScienceWorld +3.7, WebShop +1.7)을 보였고, 모델 규모가 커질수록(7B) 이득이 커졌다.
  • 추가로 X-Tree를 적은 수(약 50~100개)의 궤적만으로도 마이닝할 수 있음을 보여, 데이터 효율성 측면의 강건성도 확인했다.

한계점

저자들이 명시한 한계는 다음과 같다. X-Tree는 고정된 궤적 풀에서 한 번만 마이닝되며, 정책 자신이 생성한 궤적으로부터 반복적으로(루프 형태로) 구조와 정책을 함께 개선하는 방향은 다루지 않았다. 또한 세 가지 통합 방식(오프라인 RL, 온라인 RLVR, OPSD)을 각각 별도로 평가했을 뿐, 하나의 모델에 세 가지를 모두 결합하는 실험은 수행하지 않았다. 아울러 X-Tree는 이미 존재하는 경험을 재구성할 뿐이며, 데이터 자체가 희박한 영역을 보완해 새로운 궤적을 합성하는 기능은 제공하지 않는다.

시사점

이 연구는 LLM 호출 없이 결정적 알고리즘만으로 에이전트 궤적의 반복 구조를 추출해 학습에 투입할 수 있음을 보이며, 값비싼 LLM 기반 스킬 요약 없이도 OPSD 수준의 성능을 낼 수 있다는 점에서 비용 효율적인 에이전트 학습 파이프라인 설계에 시사점을 준다. 또한 오프라인 RL, 온라인 RLVR, 자기증류라는 서로 다른 학습 패러다임에 공통된 구조(X-Tree)를 재사용 가능한 형태로 통합했다는 점에서, 향후 다양한 에이전트 학습 프레임워크에 폭넓게 적용 가능한 범용 전처리 기법으로 확장될 가능성을 제시한다.
