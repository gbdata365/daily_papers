한 줄 요약

StepAudio 3 Realtime은 "듣기-대화-생각-행동(listen-converse-think-act)"이 하나의 연속 루프로 통합된 오디오-언어 파운데이션 모델로, 말하면서 동시에 추론하는 Think-While-Speaking 기법을 통해 깊은 추론과 실시간 저지연 음성 대화 사이의 근본적 긴장을 해소한다.

배경 및 문제의식

실시간 음성 대화 시스템은 사용자의 발화 흐름을 따라가면서 동시에 자신의 응답을 관리해야 한다는 근본적 어려움을 안고 있다. 예를 들어 사용자의 말이 잠시 멈춘 것이 문장이 끝난 것인지 아니면 생각 중인 것인지 구분해야 하고, 모델이 말하는 도중 사용자가 끼어드는 발화가 단순한 맞장구(backchannel)인지 실질적인 개입 요청인지 판단해야 한다. 여기에 더해 복잡한 요청에 대해서는 신중한 추론이 필요한데, 이 추론에 시간을 쓰면 응답이 늦어져 자연스러운 대화 흐름이 깨진다. 또한 외부 도구 호출이 필요한 작업은 음성 대화 자체보다 오래 걸릴 수 있어 대화의 지속성과 작업 완료를 동시에 관리해야 하는 문제가 있다. 기존 음성 인식·오디오 이해 모델들과 스트리밍/전이중(full-duplex) 시스템들은 이러한 요소들을 부분적으로 다뤄왔지만, 지각(perception)·추론(reasoning)·행동(action)을 하나의 대화 루프 안에서 유기적으로 조율하는 통합 시스템은 부족했다.

핵심 기여

  1. Realtime Conversational Loop: 사용자/모델 음성, 대화 이력, 추론 진행 상황, 도구 실행 상태를 공유 컨텍스트로 묶어 듣기·말하기·생각하기·행동하기가 동시에 진행될 수 있도록 하는 통합 대화 루프 구조를 제안.
  2. Deep Perception (StepAudio 3 ASR Max / 오디오 이해): 대규모 자동 오디오 큐레이션 파이프라인과 장문·희귀 고유명사 증강 데이터로 학습한 전사(ASR) 특화 모델과, 어휘·비언어적 단서·음향 이벤트·화자/시간 구조·음악·오디오 기반 추론을 아우르는 오디오 이해 모델을 구축.
  3. Seamless Duplex: 사용자와 모델의 두 오디오 스트림을 320ms 블록 단위로 상태 토큰과 교차 배치하는 이중 스트림(dual-stream) 아키텍처로, 일시정지·순서교대(turn-taking)·끼어들기·백채널을 문맥 기반으로 판단.
  4. Think-While-Speaking: Mind-Paced Speaking 구조를 확장하여 동일 모델을 이용한 두 개의 병렬 프로세스(Formulation Brain이 비공개 추론 트레이스 생성, Articulation Brain이 그 추론에 기반해 짧은 응답 세그먼트를 생성)로 추론과 발화를 동시 수행. 여기에 Adaptive Thinking(턴별로 명시적 추론이 필요한지 자동 판단)과 MTP(Multi-Token Prediction) 기반 추론 가속을 결합.
  5. Voice Agent(전이중 음성 에이전트): 요청을 직접 응답/경량 도구 호출/비동기 백엔드 실행 중 하나로 라우팅하고, 장시간 작업이 진행되는 동안에도 사용자가 계속 대화하거나 추가 요구를 반영할 수 있도록 함.
  6. 모델 가중치 병합(Weighted Model Merging): 서로 다른 데이터 조합으로 학습한 복수의 특화 teacher 모델을 파라미터 공간에서 가중 평균하여 재학습 없이 여러 역량을 통합하는 저비용 기법 제안.

방법론

StepAudio 3 Realtime은 약 1,960억 개의 총 파라미터, 토큰당 110억 개의 활성 파라미터를 갖는 MoE(mixture-of-experts) 아키텍처로, 언어 백본은 Step 3.7 Flash를 기반으로 하고 오디오 프론트엔드는 Qwen3-Omni의 Audio Transformer(AuT) 인코더를 어댑터로 연결한 구조다. 사전학습은 modality alignment(음향 표현과 언어모델 인터페이스 정립) → multimodal mixed training(대규모 오디오-텍스트 결합 학습) → cooldown(고품질 데이터 위주 정제)의 3단계로 진행되며, 시퀀스 길이 32K, 총 1.2T 토큰을 사용한다. 이후 미드트레이닝 단계에서 컨텍스트 길이를 128K로 확장하고 오디오 이해·에이전트 상호작용 데이터 비중을 늘린다.

ASR 특화 모델(StepAudio 3 ASR Max)은 사전학습·미드트레이닝은 공유하되 지도미세조정(SFT) 단계에서만 전사에 특화되며, 짧은 라벨 데이터와 장문 의사라벨(pseudo-label) 데이터를 ROVER(다중 인식 결과 융합)로 정제하고, 희귀 고유명사에 대한 합성 학습 데이터를 별도로 구축한다. 오디오 이해 데이터는 샘플링→설명→역량 태깅→질의 생성→다중 모델 라벨링의 파이프라인을 거쳐 품질 관리되며, "less is more" 실험에서 약 200만 개의 무작위 샘플보다 품질 관리를 거친 약 10만 개(20분의 1 규모)의 데이터가 오히려 더 높은 성능을 보였다.

Seamless Duplex는 320ms 오디오 블록마다 상태/텍스트 토큰을 삽입하는 시간 교차(time-interleaved) 표현을 사용해 전이중 상호작용 상태를 점진적으로 추적하며, 10,000시간 이상의 합성 전이중 상호작용 데이터로 미드트레이닝을 수행한다. Think-While-Speaking에서 Adaptive Thinking은 각 턴에 대해 원본 추론 트레이스와 무추론(no-think) 상태의 답변을 블라인드 판정 모델로 비교하여 추론이 실제로 답변 품질을 개선하는 턴만 선별적으로 추론을 유지하도록 학습 데이터를 구성한다. MTP는 예측 헤드(3개 또는 5개)를 이용해 여러 미래 토큰을 동시에 드래프트하는 추측적 디코딩 방식으로 비공개 추론 스트림의 디코딩을 가속하며, 발화 응답 자체는 엄격한(strict) 검증을 유지하되 내부 추론에는 완화된 typical acceptance와 반복 패널티를 적용한다. Voice Agent는 요청 라우팅·명확화·비공개 컨텍스트 조회·실행 전 확인·진행 상황 업데이트·결과 보고를 다루는 목표형 대화와, 실제 다단계 에이전트 궤적(trajectory)을 결합해 학습된다. 마지막으로 서로 다른 데이터 조합으로 학습된 4개의 teacher 모델을 3:1:1:1 비율로 파라미터 가중 평균(weighted merging)하여 최종 모델을 구성한다.

실험 설정 및 결과

평가는 음성인식(ASR), 오디오 이해, 대화·추론, 전이중 상호작용, 에이전트형 작업 완료, 일반 텍스트의 6개 영역에서 이루어졌다. - ASR: LibriSpeech, AISHELL-1, WenetSpeech, ContextASR-Bench에서 StepAudio 3 ASR Max가 Doubao 2.0 ASR, Seed 2.0 Lite, HY3.0 ASR Preview 대비 대부분의 벤치마크에서 최저(최고) 오류율을 기록 (예: LibriSpeech test-clean WER 1.18). - 오디오 이해: 8개 벤치마크(BigBench Audio, AudioMultiChallenge, MMSU, MMAU, WildSpeech, MMAR, Step-Caption, MTalk-Bench) 매크로 평균 81.3으로 Doubao 2.0 Lite(77.7), Gemini 3 Flash(77.1)를 앞서고 Gemini 3.1 Pro(81.8)에 근접. MMSU(90.6), MMAR(86.5)에서 가장 큰 격차로 선두를 차지했으나 AudioMultiChallenge에서는 Gemini 3.1 Pro에 17.7점 뒤처짐. - 대화·추론(StepAudioChat): 추론 모드 매크로 평균 73.0으로 Doubao 2.0 Lite(70.5), DeepSeek-V4-Flash(71.4)를 앞섰지만 Kimi K3(77.1)에는 못 미침. 실시간(Think-While-Speaking 적용) 상태에서도 70.41의 매크로 평균을 유지해, 말하면서도 전용 추론 모델에 필적하는 대화·추론 성능을 보임. - 전이중 상호작용(Artificial Analysis Full-Duplex Bench): Overall 98.9점으로 1위(Qwen Audio 3.0 Realtime Plus 98.4, GPT-realtime-2 95.3, Grok Voice Think Fast 2.0 95.1), turn-taking 100.0, 사용자 끼어들기 처리 99.0 기록. - 에이전트형 작업 완료(τ-Voice): 항공/소매/통신 3개 도메인 평균 56.0%로 Grok(56.5%)에 근접한 2위. 통신 도메인에서 70.2%로 1위, 소매 도메인은 37.7%로 상대적으로 약함(Grok 49.7%). - 일반 텍스트: HMMT 2026 Feb에서 86.8로 1위였으나 GPQA Diamond와 MultiChallenge에서는 Gemini 3 Flash에 뒤처짐. - Adaptive Thinking / MTP 소거 실험: Adaptive Thinking은 카테고리별로 51.5%~82.0%의 추론 발동률을 보이며 무추론 대비 추론(Reasoning) 항목에서 최대 11.37점 개선을 얻었으나, 항상 추론이 가장 도움되는 항목에 정확히 할당되지는 않음을 확인. MTP3/MTP5는 조건에 따라 최대 2.05배의 디코딩 가속(wall-clock speedup)을 제공. - 모델 병합: 4개 teacher를 병합한 모델이 오디오 이해에서 최고 teacher와 동률(81.3), 일반 텍스트에서 전체 최고(76.5)를 기록했지만, 대화 영역에서는 최강 teacher(74.2)보다 낮은 73.0을 보여 병합이 모든 지표에서 균일한 향상을 보장하지는 않음을 시사.

한계점

논문이 스스로 명시한 한계는 다음과 같다. 첫째, AudioMultiChallenge와 같은 다중턴 오디오 대화에서 제약 조건을 유지·갱신하는 능력이 최고 경쟁 모델(Gemini 3.1 Pro) 대비 뚜렷하게 뒤처진다. 둘째, τ-Voice의 소매(retail) 도메인 작업 성공률이 상대적으로 낮아 개선 여지가 있다. 셋째, Adaptive Thinking의 추론 선택 정책이 실제로 추론이 가장 이득이 되는 턴에 정확히 할당되지는 못하며(예: Reasoning 영역은 낮은 발동률에도 큰 이득을 보지만, Faithfulness 영역은 발동률이 높아도 이득이 작음), 개별 턴 단위의 최적 의사결정을 보장하지 못한다. 넷째, MTP 가속의 수용률(acceptance rate)은 예측 헤드 깊이가 늘어날수록 감소하여 추가 헤드의 효율 이득이 체감하며, 엄격한 검증을 발화 응답에 유지해도 불완전한 비공개 추론에서 비롯된 오류를 완전히 제거하지는 못한다. 다섯째, 모델 병합은 특정 teacher의 최고 성능을 모든 지표에서 재현하지 못하고 균형점(trade-off)을 제공하는 수준에 그친다. 전반적으로 일반 텍스트 벤치마크(GPQA Diamond, MultiChallenge)에서는 경쟁 모델(Gemini 3 Flash)에 뒤처지는 부분도 존재한다.

시사점

이 연구는 실시간 음성 상호작용에서 "깊은 추론"과 "즉각적 응답"이 상충한다는 오래된 트레이드오프를, 별도의 두 프로세스(Formulation/Articulation Brain)를 병렬 실행하는 Think-While-Speaking 구조로 완화할 수 있음을 보여준다. 이는 향후 음성 에이전트가 저지연 대화형 인터페이스를 유지하면서도 복잡한 추론이 필요한 작업(도구 호출, 다단계 계획)을 함께 처리하는 설계의 방향성을 제시한다. 또한 "less is more" 실험 결과는 오디오-언어 모델의 SFT 단계에서 데이터 품질 관리가 데이터 양보다 훨씬 중요할 수 있음을 시사하며, 가중 파라미터 병합을 통한 역량 통합은 여러 특화 모델을 재학습 없이 결합하는 실용적 전략으로 향후 대규모 음성/멀티모달 모델 개발에 참고할 만하다. 다만 다중턴 제약 준수와 특정 에이전트 도메인(소매)에서의 격차는 실시간 음성 에이전트가 실제 상용 환경에 배치되기 위해 아직 해결해야 할 과제로 남아 있다.
