A Broader Look into MLLM's Retrieval Heads

MLLM 검색 헤드에 대한 더 넓은 시각

멀티모달 대형 언어모델(MLLM)이 긴 입력에서 정답 근거를 찾아내는 데 관여하는 소수의 "검색 헤드(retrieval heads)"가 음성·영상 등 새로운 모달리티로 확장되어도 모달리티 간에 공유되고 백본에서 그대로 보존됨을 밝히고, 이 헤드의 어텐션을 직접 학습시켜 문서 검색 성능을 끌어올리는 방법을 제시한 연구이다.

한 줄 요약

멀티모달 대형 언어모델(MLLM)이 긴 입력에서 정답 근거를 찾아내는 데 관여하는 소수의 "검색 헤드(retrieval heads)"가 음성·영상 등 새로운 모달리티로 확장되어도 모달리티 간에 공유되고 백본에서 그대로 보존됨을 밝히고, 이 헤드의 어텐션을 직접 학습시켜 문서 검색 성능을 끌어올리는 방법을 제시한 연구이다.

배경 및 문제의식

긴 입력 속에서 질문에 답하는 데 필요한 근거(evidence)는 전체 맥락 중 일부에만 존재하며, 이를 정확히 찾아내는 능력은 멀티모달 이해의 핵심이다. 기존 언어모델 연구는 이러한 근거-추적 역할을 담당하는 소수의 어텐션 헤드인 "검색 헤드"를 밝혀냈고, 이후 비전-언어모델(VLM)로도 분석이 확장되어 시각적 검색 역시 일부 헤드에 의존함이 알려졌다. 그러나 이러한 분석은 제한된 모달리티(텍스트, 이미지)와 모델에 한정되어 있었고, 모델이 오디오·비디오 같은 새로운 모달리티로 확장될 때도 동일한 메커니즘이 유지되는지, 그리고 이 메커니즘을 실제 성능 개선에 활용할 수 있는지는 밝혀지지 않았다. 저자들은 두 가지 질문을 던진다: (1) 검색 헤드 메커니즘이 모델이 지원하는 모달리티가 늘어남에 따라 함께 확장되는가, (2) 이 메커니즘을 모델 개선의 토대로 활용할 수 있는가.

핵심 기여

논문은 세 가지로 기여를 요약한다. - 음성·시각 등 다양한 근거 모달리티와 관련 모델 체크포인트에 걸쳐 검색 헤드를 짝지어(paired) 분석하여, 희소성(sparsity), 모달리티 간 공유, 입력 모달리티 확장 시 보존 양상을 규명했다. - 검색 헤드가 오디오-비주얼 검색을 지지한다는 인과적 증거를 제시하고, 모달리티 간에 공유되는 작은 부분집합이 더 넓은 멀티모달 추론 과제에도 기여함을 보였다. - 검색 헤드의 어텐션을 랭킹(ranking) 목적함수로 직접 최적화하는 방법을 제안하여, 여러 모델 계열에서 멀티모달 문서 검색 성능을 향상시켰다.

방법론

저자들은 질문 토큰에서 근거(evidence) 토큰으로 향하는 어텐션을 측정해 헤드별 "검색 점수(retrieval score)"를 정의한다. 각 헤드에 대해 질문 위치에서 근거 위치로의 평균 어텐션을 구하고, 같은 맥락에 대해 질문을 의미 없는 내용으로 바꾼 베이스라인 어텐션을 빼서 보정(calibration)한 뒤 여러 예제에 대해 평균한다. 이 점수로 헤드를 순위화하며, 기본적으로 상위 5%를 "검색 헤드"로 정의한다.

분석 대상은 텍스트(LongMemEval, Natural Questions), 이미지-텍스트가 섞인 긴 맥락(MM-NIAH), 그리고 저자들이 새로 구성한 오디오-비주얼 "AV-NIAH" 데이터셋이다. AV-NIAH는 MLVU의 배경 영상에 6자리 비밀번호를 음성(합성 음성으로 읽어줌)으로 삽입하거나 화면에 1초간 배너로 표시하는 두 조건으로 구성되어, 배경·질문·정답은 고정하고 오직 근거가 제시되는 모달리티만 달리한다. 이를 통해 동일 정보가 음성/시각으로 제시될 때 같은 헤드가 반응하는지 비교할 수 있다. 분석에는 언어모델(Qwen2.5, Qwen3), 비전-언어모델(Qwen2.5-VL, Qwen3-VL, MiniCPM-V), 통합모델(BAGEL), 음성-영상-텍스트를 모두 다루는 오미니모달 모델(Qwen2.5-Omni, MiniCPM-o, SALMONN 2+/Pro) 등 18개 체크포인트가 사용되었다.

헤드 간 비교에는 스피어만 상관계수(Spearman's ρ)와 상위 헤드 집합의 중첩도(우연히 겹칠 확률 대비)를 사용했고, 헤드의 실제 필요성은 어태블레이션(ablation, 특정 헤드의 출력을 0으로 만듦)으로 검증했다. 대조군으로는 같은 수의 헤드를 각 레이어에서 무작위로 뽑은 "매칭 랜덤 헤드"를 사용했으며, 검색 헤드 제거로 인한 추가적인 성능 저하(E = 랜덤 제거 평균 점수 − 검색헤드 제거 점수)를 계산해 통계적으로 검증했다(클러스터 부트스트랩, Holm 보정).

마지막으로 검색 헤드의 어텐션을 활용한 문서 랭킹 기법을 제안한다. MMDocIR 데이터셋에서 질문과 후보 페이지(또는 레이아웃 영역) 간 선택된 검색 헤드들의 어텐션 합을 후보의 관련성 점수로 삼고, 예제별로 점수를 정규화한 뒤 정답 후보와 어려운 네거티브(hard negative) 간의 대조 손실(랭킹 손실, 식 6)로 LoRA 어댑터를 학습시켜 검색 헤드의 어텐션 자체를 미세조정한다.

실험 설정 및 결과

희소성(Finding 1): 오미니모달 모델 8종 모두에서, 전체 헤드 중 10% 미만이 전체 양의 점수 절반 이상을 차지할 정도로 검색 헤드는 소수에 집중되며, 이는 음성 근거에서도 텍스트·이미지 근거와 마찬가지로 성립했다.

모달리티 간 공유(Finding 2): 같은 정보가 음성으로 제시되든 화면에 표시되든, 상위 5% 검색 헤드의 69~83%가 양쪽 조건에서 공통으로 선택되었으며(무작위라면 3개 미만 중첩), 전체 순위의 스피어만 상관도 0.88~0.92로 높았다. 반면 음성 숫자열과 자연 이미지 근거(MM-NIAH) 간 비교에서는 상관도가 낮아, 헤드의 재사용은 모달리티보다 근거의 "종류(검색 대상)"에 더 의존함을 시사했다.

보존(Finding 3): 오미니모달 모델은 자신의 언어모델/VLM 백본이 가진 검색 헤드를 대부분 그대로 유지했다(SALMONN은 백본과 ρ≥0.97로 거의 동일).

인과적 역할(Finding 4): 상위 5% 검색 헤드를 제거하면 4개 모델 모두에서 오디오 검색이 거의 완전히 사라지고(예: Qwen2.5-Omni-7B에서 정확도 98.3%→0%, 매칭 랜덤 제거는 96.9% 유지), 시각 검색도 대부분 사라졌다. 효과는 상위 20개 헤드만 제거해도 나타나며, 두 모달리티에 공통으로 선택된 "AV-공유 헤드"(전체의 2% 미만)만 제거해도 문서 이해, 공간 지각, 시각 수학 등 8개 하위 과제 중 다수(16개 모델-과제 조합 중 15개)에서 자연 이미지 검색 헤드보다 더 큰 성능 저하를 유발했다.

검색 헤드 기반 학습(5장): MMDocIR 벤치마크에서 Qwen3-VL-8B 기준, 학습 전에도 검색 헤드 기반 점수는 무작위 헤드보다 훨씬 우수했고, 랭킹 손실로 학습한 뒤에는 페이지 Recall@1이 기존 미학습 검색헤드 대비 6.03점 향상(Micro 56.45%→62.48%)했으며, 레이아웃 수준 지도 없이도 레이아웃 Recall@1이 1.46점 향상되었다. Qwen2.5-VL-7B, Gemma3-12B에도 동일 기법을 적용해 각각 5.69점, 2.17점의 페이지 Recall@1 향상을 확인했다. MMMU, MathVista 등 4개 아웃오브도메인 벤치마크에서는 성능 변화가 1점 이내로 미미했다. 헤드 집합 크기(k)를 바꿔도 검색 헤드 기반 스코어러가 동일 크기의 무작위 헤드보다 항상 우수했다.

한계점

논문에 "한계점" 절이 별도로 명시되지는 않았으나, 본문에서 다음과 같은 제약이 언급된다. 오디오-비주얼 분석은 MLVU 영상에 숫자를 삽입한 합성 AV-NIAH 과제에 기반하므로 실제 자연스러운 음성-영상 질의응답 환경과는 차이가 있을 수 있다. 검색 헤드 학습(5장)은 페이지 수준 지도만으로 이루어져 레이아웃 수준 지도가 없으며, 아웃오브도메인 일반 벤치마크(MMMU, MathVista 등)에서는 개선 효과가 거의 없어(1점 이내) 학습 효과가 해당 검색 과제에 비교적 특화되어 있음을 시사한다. 또한 분석 대상 모델은 Qwen, MiniCPM, SALMONN, BAGEL, Gemma 계열 등으로 한정되어 있다.

시사점

이 연구는 검색 헤드가 텍스트·이미지뿐 아니라 음성·영상까지 포함하는 더 넓은 모달리티 범위에서도 일관되게 존재하는 보편적 메커니즘임을 보여주며, 모델이 새로운 모달리티를 학습하는 과정에서도 이미 확립된 근거-추적 회로를 재사용·확장한다는 관점을 제시한다. 나아가 이러한 "기능적 어텐션 헤드"를 모델 해석의 렌즈로만이 아니라 직접적인 최적화 대상으로 삼을 수 있음을 실증하여, 소수 헤드의 어텐션만 미세조정하는 경량 학습으로도 멀티모달 문서 검색과 같은 실용적 과제의 성능을 여러 모델 계열에 걸쳐 끌어올릴 수 있다는 가능성을 제시한다.
