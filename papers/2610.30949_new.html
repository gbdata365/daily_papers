IQuest-Q1: Advancing Foundation Capabilities for Agentic CLI Systems

IQuest-Q1: 에이전틱 CLI 시스템을 위한 기반 역량 강화

한 줄 요약

총 3,200억 개(활성 150억 개) 파라미터의 희소 MoE 모델 IQuest-Q1을 3단계(사전학습-중간학습-후처리) 파이프라인으로 학습시켜, 명령줄 인터페이스(CLI) 기반 에이전트 작업에서 코딩·범용 추론·사이버보안 전반에 걸쳐 강력한 성능을 보이는 오픈소스 에이전틱 파운데이션 모델을 공개한 연구.

배경 및 문제의식

LLM 기반 에이전트는 단순 응답 생성이 아니라 반복적인 추론·행동·외부 환경과의 상호작용을 통해 작업을 수행하며, 이때 CLI(명령줄 인터페이스)는 모델이 파일에 접근하고 코드를 실행하며 도구를 사용하는 가장 범용적인 통로 중 하나로 자리잡았다. 따라서 더 유능한 에이전트 모델을 만들려면 CLI 환경에서의 기초 역량 자체를 강화해야 한다는 문제의식에서 출발한다. 저자들은 코딩, 범용 에이전트 작업 실행, 장기 추론, 사이버보안 등 폭넓은 영역에서 신뢰성 있는 도구 사용과 견고한 성능을 갖춘 모델을 목표로 삼았다.

핵심 기여

  • CLI 역량에 최적화된 오픈 가중치 에이전트 모델: 총 3,200억 파라미터(토큰당 활성 150억) 규모의 희소 MoE 모델을 가중치 공개 형태로 제공.
  • CLI 중심의 학습 파이프라인: 사전학습 단계부터 다운스트림 에이전틱 상호작용에 필요한 능력을 단계적 데이터 구성으로 키우고, 후처리 단계에서는 작업·환경 합성과 멀티스캐폴드 강화학습, 다중 교사 온폴리시 증류(MOPD)로 여러 모델의 역량을 하나로 통합.
  • 휴먼인더루프 기반 반복적 모델 개발(RSI): IQuest-Q1을 내부 인프라에 통합해 모델 스스로 자신의 약점을 진단하고 개선안을 제안하도록 하되, 사람이 핵심 의사결정과 고비용 실험을 감독하는 재귀적 자기개선 파이프라인을 실제로 시연.

방법론

학습은 5단계로 구성된다: (1) 사전학습 – Stable SplitNorm(어텐션 서브레이어만 정규화하고 FFN 입력은 비정규화 상태로 유지하는 하이브리드 정규화), Muon 옵티마이저, μP 파라미터화를 결합해 2단계 커리큘럼(코드 비중을 40%→70%로 점진 확대)으로 안정적이고 효율적인 스케일링을 달성. 아키텍처는 GQA와 Sliding Window Attention을 혼합(3:1 비율)하고, 쿼리-인식 싱크 토큰, QKNorm(+클리핑), 부분 RoPE, 추측 디코딩을 위한 재귀적 멀티토큰 예측(MTP) 등을 포함. (2) 중간학습(Mid-training) – 자연어 코퍼스·QA·에이전트 궤적 데이터를 혼합하고 컨텍스트 길이를 32K→128K→512K로 점진 확장. (3) SFT – 중간학습 체크포인트에서 2단계로 지도 미세조정. (4) 환경 중심 강화학습 및 MOPD – Claude Code, Codex 등 다양한 에이전트 하네스·버전에서 수집한 궤적으로 GRPO 기반 RL을 수행하고, 터미널 상호작용·멀티하네스·장기추론·범용 에이전트 등 4개의 전문가(teacher) 모델로부터 역-KL 기반 온폴리시 증류를 수행. (5) 모델 병합 – 여러 단계·전문가 체크포인트의 파라미터 델타를 기준 체크포인트에 더해 역량을 통합. 또한 리워드 해킹(검증기 취약점 악용)을 막기 위해 환경 준비, 실행 시점 접근 제한, 궤적 감사의 3중 안전장치를 적용했다.

실험 설정 및 결과

코딩(DeepSWE, SWE-bench Multilingual/Pro, NL2Repo-Bench, ProgramBench, CyberGym, Terminal-Bench 2.1/3.0/4.0, PaperBench, LiveCodeBench v6, 자체 IQuest-CLIBench 등)과 범용 역량(GPQA Diamond, Humanity's Last Exam, JobBench, Agents' Last Exam, BrowseComp, WideSearch 등) 두 축에 걸친 다수 벤치마크에서 Claude Opus 5, GPT-5.6 Sol, GLM-5.3-Flash, DeepSeek-V4-Flash, Hy3, MiniMax M3 등과 비교 평가했다. DeepSWE v1.1 64.6점, NL2Repo-Bench 63.0점, CyberGym 84.5점, Terminal-Bench 2.1 83.2점, JobBench 55.7점, Agents' Last Exam 29.6점 등에서 비교 모델 대비 우수하거나 상위권 성능을 보였고, GPQA Diamond 93.3점·IMOAnswerBench-Verified 93.0점 등 과학·수학 추론에서도 높은 점수를 기록했다. 반면 Humanity's Last Exam(툴 미사용 39.2점)처럼 전문가 수준 추론에서는 개선 여지가 남아있다고 밝혔다. 또한 Qwen3-MoE 스타일 베이스라인 대비 동일 학습 데이터·FLOPs 조건에서 약 1.93배 높은 스케일링 효율을 보였으며, 안정 학습률과 최적 학습률 간 격차를 정의하는 자체 지표(Critical Model Size)로 추가 스케일업 여지도 분석했다. 실제 사이버보안 활용 사례로, 3일간 전문가들이 IQuest-Q1의 지원을 받아 30건의 취약점 리포트를 작성해 검증·공개한 사례도 제시했다.

한계점

  • 텍스트 입력만 지원하며, 이미지·오디오·비디오 등 네이티브 멀티모달 입력 능력이 없음.
  • 생성된 설명이나 코드가 부정확할 수 있어, 코드 변경 시 작업에 맞는 테스트로 검증이 필요함.
  • 도구 호출 형식이 IQuest 고유 포맷에 맞춰져 있어, 호환되는 서빙 파서와 에이전트 하네스가 있어야 구조화된 도구 실행과 추론 추출이 가능함.
  • 실제 CLI 작업에서는 반복 디버깅·검증이 필요한데, 모델이 제약을 놓치거나 실패한 시도를 반복하거나 문제를 해결하지 못한 채 남겨두는 경우가 있어 사람의 검토·감독이 필요함.
  • 여전히 역량과 신뢰성 면에서 개선이 진행 중인 단계임을 저자들도 인정.

시사점

대규모 MoE 아키텍처와 정교한 사전/중간학습 안정화 기법(Stable SplitNorm, Muon, μP), 다중 하네스·다중 교사 증류를 결합한 CLI 특화 후처리가 실제 에이전틱 코딩·보안·범용 작업 성능으로 이어질 수 있음을 보여준다. 특히 모델이 스스로 실패를 진단하고 개선안을 제안하면 사람이 검토·승인하는 '휴먼인더루프 재귀적 자기개선' 워크플로우는, 완전 자동화된 자기개선보다 더 실용적이고 통제 가능한 모델 개발 경로로서 향후 에이전트 파운데이션 모델 개발 방식론에 시사점을 준다.
