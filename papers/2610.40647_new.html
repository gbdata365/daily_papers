Read, Allocate, Route: Role-Coupled Tokenization for Pixel-Space Generative Transformers

읽기, 할당, 라우팅: 픽셀 공간 생성 Transformer를 위한 역할-결합 토큰화

픽셀 공간(pixel-space) 생성 Transformer에서 "하나의 패치 = 하나의 토큰"이라는 고정된 설계를 깨고, 각 공간 앵커(anchor)를 여러 개의 주파수별 슬롯(slot)으로 확장한 뒤 가장 저주파인 슬롯만 전역(global) 어텐션에 참여시킴으로써, 출력 디테일을 늘려도 전역 어텐션 비용은 거의 그대로 유지하는 토큰화·라우팅 기법 SpecSlot을 제안한다.

한 줄 요약

픽셀 공간(pixel-space) 생성 Transformer에서 "하나의 패치 = 하나의 토큰"이라는 고정된 설계를 깨고, 각 공간 앵커(anchor)를 여러 개의 주파수별 슬롯(slot)으로 확장한 뒤 가장 저주파인 슬롯만 전역(global) 어텐션에 참여시킴으로써, 출력 디테일을 늘려도 전역 어텐션 비용은 거의 그대로 유지하는 토큰화·라우팅 기법 SpecSlot을 제안한다.

배경 및 문제의식

픽셀 공간 생성 모델은 별도로 학습된 오토인코더(VAE) 없이 노이즈에서 픽셀을 직접 생성하므로 압축에 의한 정보 손실이 없다는 장점이 있지만, 이미지를 그대로 Transformer 토큰으로 표현해야 하므로 연산 비용이 크다. 기존 방식들은 패치 하나당 토큰 하나를 쓰기 때문에, 패치 크기를 8×8로 줄여 디테일을 높이면(256×256 이미지 기준 토큰 수가 256개에서 1,024개로 증가) 전역 어텐션의 2차 비용이 16배로 폭증한다. JiT, 멀티스케일 디테일러 헤드, 효율적 어텐션(윈도우·희소화) 등 선행 연구들은 이 비용을 줄이려 했지만 "출력 디테일"과 "전역 통신량"이 같은 공간 패치 격자에 묶여 있다는 근본 구조는 그대로 두었다. 저자들은 저주파 성분(전체적인 구조)은 이미지 전역과 교환할 가치가 크지만 고주파 성분(세부 디테일)은 국소적으로만 처리해도 충분하다는 관찰에서, "토큰이 무엇을 출력하는가(역할)"가 "그 토큰이 어떻게 통신해야 하는가"를 결정하도록 설계를 바꿀 수 있는지를 질문한다.

핵심 기여

  • 공간 앵커가 입력 정보를 모으고, 각 앵커를 K개의 슬롯으로 확장해 슬롯마다 서로 겹치지 않는(disjoint) DCT(이산 코사인 변환) 계수 그룹을 할당하는 인덱스 기반 W×K 표현을 제안. 앵커 밀도(W)와 스펙트럼 세분화(K)를 독립적인 할당 변수로 분리했다.
  • 슬롯 인덱스로부터 통신 그래프를 결정하는 carrier-routed GGLL(Global-Global-Local-Local) 어텐션 스케줄을 정의: 각 앵커의 최저 주파수 슬롯(carrier) 1개만 전역 블록에 들어가고, 나머지 모든 슬롯은 앵커 내부 로컬 블록에서만 상호작용하여 전역 시퀀스 길이를 W×K가 아닌 W로 유지.
  • ImageNet-256/512 및 텍스트-이미지 생성에서 FLOPs가 비슷한 JiT 대비 더 나은 FID, 또는 JiT-B/16에 근접한 품질을 더 낮은 비용으로 달성하는 두 개의 새로운 품질-비용 균형점을 제시.

방법론

SpecSlot은 전체 과정을 Read-Allocate-Route 세 단계로 구성한다. 1. Read(읽기): 입력 잠재 상태 z_t를 s×s 크기의 겹치지 않는 셀로 나누고, 공유 프로젝션으로 각 셀을 앵커 벡터로 인코딩한다. 제로 초기화된 깊이별(depthwise) 3×3 컨볼루션(input mixer)으로 인접 앵커 간 정보를 섞은 뒤, 공유 1×1 프로젝션으로 하나의 앵커 벡터를 K개의 슬롯 히든 상태로 확장한다. 역할은 입력이 아니라 슬롯의 위치 인덱스·출력 헤드·라우팅 규칙에서 비롯된다. 2. Allocate(할당): 출력 윈도우(L=2s) 안의 DCT-II 계수를 반경(저주파→고주파) 순으로 정렬해 K개의 동일한 그룹으로 나누고, 슬롯 k가 그룹 k를 전담하도록 고정 배정한다. 공유된 선형 헤드가 각 슬롯이 맡은 계수를 예측하며, 디코딩은 50% 겹치는(lapped) DCT 프레임의 역변환·Hann 윈도우·정규화된 overlap-add로 수행해 윈도우 경계에서의 블록 아티팩트를 방지한다. 추가로 동일한 슬롯 상태를 재사용해 공간(픽셀) 영역에서 국소 보정항을 더하는 두 번째 헤드를 두어, 스펙트럼 기반 예측과 공간 보정을 합산한 최종 예측을 만든다. 3. Route(라우팅): 저주파 그룹을 담당하는 슬롯(슬롯 0, carrier)만 클래스/텍스트 컨텍스트 토큰과 함께 전역 어텐션 블록에 들어가고, 나머지 슬롯들은 각자의 앵커 내부에서 로컬 블록으로만 상호작용한다. 전역·로컬 블록을 2개씩 번갈아 쌓는 GGLL 패턴을 3번 반복해 총 6개의 전역 블록과 6개의 로컬 블록을 구성한다. 이 구조로 전역 시퀀스 길이는 W+C(앵커 수+컨텍스트 토큰 수)로 고정되어, K를 늘려도 전역 어텐션 비용이 커지지 않는다.

학습 목적함수는 JiT와 동일한 픽셀 공간 rectified-flow(직선 경로 보간 및 속도 MSE) 손실을 그대로 사용한다.

실험 설정 및 결과

클래스 조건 ImageNet-1K(256×256, 512×512) 및 텍스트-이미지(256×256, BLIP3o·JourneyDB 혼합 데이터) 생성 실험을 수행했으며, 비교 대상은 JiT-B/16, JiT-B/8, Spectral Forcing(SF) 베이스라인, 그리고 저자들이 직접 구성한 FLOPs 매칭 JiT 컨트롤(JiT-CM)이다. 평가는 50스텝 Heun 샘플러, EMA 가중치, FID/Inception Score(5개 독립 시드 평균) 기준이다. - ImageNet-256: SpecSlot-K2/K4는 JiT-B/16과 JiT-B/8 사이에서 두 개의 새로운(nondominated) 품질-비용 지점을 제공한다. SpecSlot-K4는 FLOPs·처리량이 거의 동일한 JiT-CM과 FID가 통계적으로 비슷한 수준이면서 학습 초반에 더 빠르게 수렴한다. - ImageNet-512: SpecSlot-K4가 JiT-CM보다 FID를 2.84 개선하면서 GFLOPs는 3.9% 더 적고, JiT-B/16과는 FID 0.69 차이에 불과하면서 비용은 38.2% 낮고 처리량은 1.6배 높다. - 텍스트-이미지 생성: SpecSlot(W256/K4)이 DPG-Bench에서 JiT-B/8보다 1.06점 높은 점수(62.21 vs 61.15)를 기록하면서 전방 연산 비용은 40.6% 낮다. GenEval에서는 JiT-B/16을 능가하지만 JiT-B/8에는 못 미친다. - 분석/ablation: 앵커 밀도(W)를 늘리는 것이 슬롯 수(K)를 늘리는 것보다 품질 개선에 더 효과적이며, K를 키울수록 슬롯의 "유효 활용률"(엔트로피 기반 effective rank)은 감소한다. 스펙트럼 기반 출력과 공간 보정 헤드를 함께 쓰는 이중 기반(dual-basis) 방식이 단일 기반보다 FID가 더 낮다. 전역 라우팅을 모든 슬롯으로 확장한 Full-global/Dense-global 컨트롤과 비교하면, GGLL은 비슷한 FLOPs에서 더 낫거나(Dense-global 대비), 더 적은 비용으로 근접한 품질(Full-global 대비)을 보여 "저주파 슬롯만 전역 통신"하는 설계가 합리적임을 뒷받침한다. 메커니즘 분석에서는 가장 저주파인 슬롯(carrier)이 학습 과정에서 가장 먼저 신호를 신호-대-잡음 임계값 이상으로 회복한다는 점을 확인해, 이 슬롯을 전역 경로로 지정한 설계 선택을 뒷받침한다.

한계점

논문에 별도의 "한계점" 절은 없으나 본문에서 다음과 같은 제약이 언급된다. - K는 출력 윈도우의 계수 수(L²)를 정확히 나눌 수 있어야 하는 등(K | L²) 구조적 제약이 있다. - 앵커 밀도(W) 증가가 품질 개선에 더 유리하다는 경향은 측정된 N=2,048 범위 내에서만 확인되었으며, 저자들은 이 경향이 더 넓은 범위로 일반화된다고 주장하지 않는다. - 가장 고비용의 JiT-B/8(ImageNet-256) 및 GenEval 벤치마크에서는 SpecSlot이 여전히 JiT-B/8보다 품질이 낮다. 즉 SpecSlot은 JiT의 저비용·고비용 설정 사이의 중간 지점을 제공하는 것이며 모든 지표에서 최고 성능을 달성하는 것은 아니다. - 모든 비교는 단일 H800 GPU, BF16, TorchInductor 컴파일 기준의 FLOPs·처리량 측정에 기반하며, 다른 하드웨어·배치 설정에서의 일반화는 논문에 명시되지 않음. - 평가는 ImageNet 클래스 조건 생성과 제한된 텍스트-이미지 데이터(BLIP3o, JourneyDB)에 한정되어 있으며, 더 높은 해상도나 더 다양한 텍스트-이미지 벤치마크에 대한 결과는 논문에 명시되지 않음.

시사점

SpecSlot은 "토큰화를 패치 크기 하나로 결정하는 단일 선택"에서 "앵커 밀도와 스펙트럼 세분화라는 두 개의 독립적인 할당 변수를 조정하는 문제"로 재구성함으로써, 픽셀 공간 생성 Transformer에서 출력 디테일과 전역 통신 비용을 분리할 수 있음을 보여준다. 이는 토큰의 "역할"(출력에서 담당하는 역할)에 따라 통신 패턴을 결정한다는 아이디어로, 향후 더 높은 해상도의 오토인코더-프리(autoencoder-free) 생성 모델이나 다른 모달리티(비디오 등)의 효율적인 토큰화 설계에도 적용될 수 있는 일반적인 원리를 제시한다. 또한 저주파 정보가 학습 중 가장 먼저 회복된다는 관찰은, 주파수 기반 라우팅이나 커리큘럼 설계에 추가적인 단서를 제공할 수 있다.
