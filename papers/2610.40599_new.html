HairDeck: Animation-Ready Stylized Hair Cards from a Single Image

헤어덱: 한 장의 이미지로 만드는 애니메이션용 스타일 헤어카드

게임·아바타 캐릭터의 헤어 카드(hair card)를 한 장의 이미지로부터 "세트(set)"로 한 번에 생성하고, 이를 움직이게 하는 스프링 본(spring-bone) 체인까지 함께 만들어내는 diffusion transformer 기반 생성 모델이다.

한 줄 요약

게임·아바타 캐릭터의 헤어 카드(hair card)를 한 장의 이미지로부터 "세트(set)"로 한 번에 생성하고, 이를 움직이게 하는 스프링 본(spring-bone) 체인까지 함께 만들어내는 diffusion transformer 기반 생성 모델이다.

배경 및 문제의식

게임이나 아바타 같은 스타일화 캐릭터의 헤어는 아티스트가 하나하나 배치한 리본 형태의 "헤어 카드"로 구성되며, 각 카드는 마름모 또는 삼각형 단면을 가지고 스프링 본으로 애니메이션된다. 기존 이미지 기반 헤어 생성 방법들은 사실적인 스트랜드(strand)나 하나로 합쳐진 메시를 출력할 뿐, 아티스트가 실제로 사용하는 카드 구조를 만들어내지 못한다. 유일하게 스타일화 헤어 카드를 생성하는 기존 방법인 CHARM은 헤어스타일을 수백~수천 개의 control point 토큰으로 이루어진 시퀀스로 보고 자기회귀(autoregressive) 방식으로 한 점씩 생성하기 때문에 느리고 정확도에 한계가 있다. 저자들은 카드로 이루어진 헤어스타일이 본질적으로 순서가 없는 아티스트 정의 프리미티브의 "집합(set)"이라는 점에 주목하여, 이를 집합으로서 한 번에 생성하는 접근을 제안한다.

핵심 기여

  • 카드 토큰화: 가변 길이의 control point들을 하나의 연속 latent로 인코딩하고 호 길이(arc length) 기준으로 디코딩하는 카드 VAE를 설계하여, 각 카드를 단면 타입과 루트 노멀(root normal)까지 포함한 고정 크기의 단일 토큰으로 표현.
  • 세트 디퓨전 트랜스포머(Set DiT): 위치 임베딩이 없는 순열 등변(permutation-equivariant) 구조로 헤어스타일의 모든 카드 토큰을 동시에 denoise하며, 각 토큰의 존재 플래그(existence flag)로 카드 개수를 자연스럽게 결정.
  • 단일 이미지 기반 생성: 얼굴에 고정된 head frame, 합성 스타일 증강(synthetic style augmentation), 이미지 편집 모델로 재스타일링한 렌더링 데이터를 활용해 다양한 그림 스타일의 입력에 대응.
  • 스프링 본 체인 생성: 카드 토큰을 조건으로 하는 두 번째 Set DiT(Chain DiT)가 체인(경로, 관절 수, 강성)을 역시 집합으로 생성하여, 고정된 기하학적 스키닝과 결합해 바로 애니메이션 가능한 애셋을 완성.

방법론

각 헤어 카드는 (루트 위치, 루트 노멀, 카드 VAE latent z, 단면 타입, 존재 플래그)로 구성된 40차원 토큰으로 표현된다. 카드 VAE 인코더는 control point들을 호 길이 비율과 함께 트랜스포머로 처리하고 학습된 요약 토큰([CLS])에서 평균과 로그분산을 얻어 32차원 latent z를 샘플링하며, 디코더는 z로 변조(adaLN-Zero)된 트랜스포머로 점의 개수를 예측하고 균일한 호 길이 위치에서 카드를 복원한다.

Set DiT는 192개의 토큰 슬롯(빈 슬롯은 존재 플래그 -1)을 flow matching으로 학습하며, 조건은 포인트 클라우드(frozen Dora 인코더)이거나 이미지(frozen DINOv3 ViT-L/16, SAM 3로 얼굴·헤어 마스크 추출)이다. 위치 임베딩이 없어 카드 순서에 무관하게 작동한다. 단일 이미지의 경우 얼굴 폭과 얼굴 상단 위치를 기준으로 정규화한 head frame에서 카드를 예측해, 데이터셋 프레임(캐릭터 키를 1로 통일)이 가진 머리 크기·위치 왜곡 문제를 해결한다. 학습 데이터는 Blender로 8개 시점에서 렌더링하며, halftone·XDoG 선화·단색·페인터리 필터 등의 합성 스타일 증강과 이미지 편집 모델(Qwen-Image 계열)로 재스타일링한 렌더링을 섞어 다양한 화풍에 대한 견고성을 높인다.

카드 생성 이후, Chain DiT가 카드 토큰을 조건으로 받아 48개 체인 슬롯(경로 8점, 관절 수, 강성, 존재 플래그로 구성된 27차원 토큰)을 동일한 flow matching 방식으로 생성한다. 생성된 카드와 체인은 거리 기반 규칙(카드 중심선과 체인의 평균 거리, 세그먼트별 블렌딩 가중치)으로 고정 스키닝되며, VRM 스프링 본 규격의 업데이트 식으로 시뮬레이션된다.

실험 설정 및 결과

CHARM이 공개한 VRoid 기반 데이터셋(학습 36,440개 헤어스타일, 테스트 100개)과 그 벤치마크 프로토콜을 사용했다. 포인트 클라우드 입력 기준으로 HairDeck은 Chamfer distance를 CHARM의 0.0117에서 0.0066으로(약 44% 개선), 카드 방향 오차를 40.0°에서 16.8°로 절반 이상 줄이면서도 처리 시간은 33.7초에서 1.01초로 약 33배 빨라졌다. 메시 생성 계열 방법(MeshAnything V2, DeepMesh, BPT)은 카드 구조 없는 큰 쉘이나 삼각형 파편을 출력해 비교에서 밀렸다.

단일 이미지 입력 실험에서는 76개의 렌더링 테스트 캐릭터와 40개의 실제(in-the-wild) 애니메 일러스트에 대해, HairDeck이 가장 낮은 aligned Chamfer distance(0.0089)와 가장 낮은 실패율(테스트 캐릭터 3.5%, in-the-wild 10%)을 보였으며, CHARM, TRELLIS.2, Hunyuan3D-2.1, DiffLocks(스트랜드를 카드로 변환) 등 비교 대상보다 우수했고 처리 시간도 1.33초로 가장 짧았다. 어블레이션 실험에서는 카드 VAE latent 표현, 루트 노멀, 존재 플래그, head frame, 스타일 증강 각각이 성능에 기여함을 확인했다. 스프링 본 체인 평가(아티스트 체인과 비교)에서도 Chain DiT가 규칙 기반 절차적 리깅이나 검색 기반 방법보다 위치·움직임 유사도에서 더 우수했다.

한계점

HairDeck은 스타일화된 VRoid 헤어스타일로만 학습되어, 매우 짧은 머리나 사실적인 헤어의 알파 텍스처 카드는 학습 데이터 범위 밖에 있다. 카드의 지오메트리와 UV 좌표는 생성하지만 텍스처는 생성하지 않는다. 일부 VRoid 캐릭터는 리본이나 모자를 헤어 카드로 모델링하고 있어, 입력 이미지에 그런 요소가 있으면 HairDeck이 이를 머리카락 카드로 잘못 생성할 수 있다(학습 데이터에서 걸러내면 해결 가능). 또한 Chain DiT는 VRoid 캐릭터에서 흔한 체인 배치 패턴을 따르므로, 정수리에서 여러 체인이 방사형으로 뻗는 등 특이한 구조에서는 체인 수를 적게 생성하는 경향이 있다.

시사점

헤어스타일을 "아티스트가 정의한 프리미티브의 순서 없는 집합"으로 바라보고, 프리미티브당 하나의 토큰을 할당해 집합 전체를 동시에 생성하는 방식이 자기회귀 방식보다 정확하고 훨씬 빠르다는 것을 보여준다. 저자들은 이 원칙이 헤어 카드뿐 아니라 패널로 재봉된 의상이나 스트로크로 이루어진 그림처럼, 아티스트가 정의한 다른 프리미티브 기반 애셋 생성에도 동일하게 적용될 수 있다고 제안한다.
