Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agent

게이머: 장기 호라이즌 실시간 게임 에이전트를 위한 범용 VLA 파운데이션 모델

한 줄 요약

키보드·마우스 입력만으로 2D 게임부터 복잡한 3D 오픈월드 게임까지 두루 플레이할 수 있는 범용 비전-언어-행동(VLA) 게임 에이전트 "Gamer"를 제안하고, 장기 호라이즌 과제 수행과 실시간 상호작용을 모두 만족시키는 학습·서빙 파이프라인을 구축.

배경 및 문제의식

실제 물리 환경에서 VLA 에이전트를 학습·평가하는 것은 시행착오 비용이 크고 환경 통제가 어렵다. 반면 현대 대형 게임은 현실적인 복잡성과 엄격한 실험 통제를 동시에 제공하는 이상적인 테스트베드다. 그러나 기존 게임 에이전트(VPT, SIMA 2 등)는 특권적 내부 상태나 전용 API, 특정 게임에 특화된 행동 공간에 의존해 범용성이 떨어지고, 사람처럼 화면 픽셀만 보고 표준 키보드·마우스로 조작하면서 장기 호라이즌 의사결정과 실시간 반응성을 동시에 만족하는 범용 모델은 아직 해결되지 않은 과제였다.

핵심 기여

  • 2D 인터페이스와 복잡한 3D 시뮬레이션 월드 모두에서 동작하는 단일 화면-투-액션(screen-to-action) 범용 에이전트 프레임워크 Gamer 제안.
  • 수만 시간 규모의 디바이스 레벨 키보드·마우스 상호작용 데이터로 지속적 사전학습(CPT)을 수행해 물리·가상 도메인 모두에서 환경 역학을 학습.
  • 중복 연산을 줄이면서 복잡한 의사결정에 필요한 추론은 유지하는 "sparse-thinking instruction tuning" 기법.
  • 유한한 컨텍스트 윈도우, 누적 롤아웃 오차, 희소 보상 문제를 다루는 안정적인 멀티턴 강화학습(Temporal-Aware GRPO) 방법으로 장기 호라이즌 상호작용 정책 학습.
  • 다수의 시뮬레이션 게임 환경을 동시에 서빙하고 무제한 컨텍스트 실행과 낮은 추론 지연을 지원하는 클라우드-엣지 추론 엔진 "Streaming-vLLM".

방법론

Gamer는 Qwen3.5/Qwen3-VL 백본에 지속적 사전학습(CPT) → 과제 조건부 지도 미세조정(SFT) → 시간 인지형 강화학습(RL) 순으로 학습된다. 각 스텝에서 에이전트는 현재 화면, 과제 지시문, 단기 상호작용 히스토리, 장기 메모리, 추론 결과를 바탕으로 네이티브 키보드·마우스 행동을 생성하는 폐루프 구조로 동작한다. 실시간 상호작용을 위해 Streaming-vLLM이 훈련과 배포 양쪽에서 활용되며, 지연 시간으로 인한 RL 편향을 줄이는 역할도 한다. 환경 측에서 과제 완수 여부를 자동 검증해 온라인 RL 보상으로 사용한다.

실험 설정 및 결과

MCU, ViZDoom, OmniGameArena, GameWorld 등 공개 게임 벤치마크와, 훈련에서 제외한 Honkai: Star Rail(HSR)의 사이드 퀘스트 2종(30개·55개 마일스톤) 및 미니게임 7종(40개 인스턴스)으로 구성된 자체 평가셋에서 성능을 측정했다. 비교 대상으로 GPT-6.1-Sol, Gemini-3.8-Flash, Claude-Opus-5.0, GLM-5.3-Flash, DeepSeek-V4-Flash-Vision 등 강력한 멀티모달 베이스라인을 사용했다. 모델 크기·게임플레이 예산·데이터 구성 조합 120개를 비교한 GameScaling 연구 결과를 바탕으로, Gamer는 여러 3D 오픈월드 게임에서 숙련된 플레이어에 준하는 일반화 성능과 실행 효율을 보였고 전통적인 2D 게임 벤치마크에서도 경쟁력 있는 결과를 얻었다.

한계점

평가 범위가 선정된 일부 환경·과제 구조에 한정되어 있어 더 넓은 상호작용 환경으로의 확장이 필요하다. Streaming-vLLM은 평가에 사용된 GPU 플랫폼에서는 실시간 상호작용을 지원하지만, 자원이 제한된 환경에 적용하려면 추가적인 서빙 비용 절감이 필요하다. 또한 응답 지연과 과제 성능 사이의 트레이드오프를 개선했음에도, 깊은 숙고가 필요한 환경에서는 추론 능력이 여전히 병목이 될 수 있다.

시사점

반복적으로 보이는 키보드·마우스 궤적 데이터만으로도 데이터와 학습 알고리즘 스케일링에 따라 상당한 성능 향상이 가능함을 보였다. 저자들은 느린 숙고형 추론을 담당하는 대형 모델(System 2)과 빠른 반응형 실행을 담당하는 소형 모델(System 1)을 결합하는 계층적 게임 에이전트가 향후 유망한 방향이라고 제안하며, 이는 디지털·물리 세계를 넘나드는 범용 에이전트로 가는 경로를 제시한다.
