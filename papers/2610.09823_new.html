UltraTextBench: A Comprehensive Bilingual Benchmark for Evaluating Visual Text Rendering in Image Generation

울트라텍스트벤치: 이미지 생성의 시각적 텍스트 렌더링을 평가하는 이중언어 벤치마크

짧은 문자열 렌더링을 넘어, 하나의 장면 안에 4~12개 영역에 걸쳐 수백~수천 자의 영어/중국어 텍스트를 밀집 배치해야 하는 상황에서 이미지 생성 모델의 텍스트 충실도·가독성·배치·장면 통합을 영역별 구조화 참조와 VLM 심사자로 평가하는 이중언어 벤치마크 UltraText Bench를 제안한다.

한 줄 요약

짧은 문자열 렌더링을 넘어, 하나의 장면 안에 4~12개 영역에 걸쳐 수백~수천 자의 영어/중국어 텍스트를 밀집 배치해야 하는 상황에서 이미지 생성 모델의 텍스트 충실도·가독성·배치·장면 통합을 영역별 구조화 참조와 VLM 심사자로 평가하는 이중언어 벤치마크 UltraText Bench를 제안한다.

배경 및 문제의식

최근 Text-to-Image(T2I) 모델은 전반적인 이미지 품질이 크게 향상되었고 짧은 문자열 렌더링 능력도 개선되었지만, 포스터·제품 포장·문서·영수증·양식·인터페이스처럼 제목·본문·소규모 보조 텍스트가 동시에 정확해야 하는 실제 응용에서는 수백~수천 자에 걸친 "밀집 텍스트"를 여러 영역에서 동시에 정확히 유지해야 한다. 가격 하나, 영업시간 하나가 틀려도 전달되는 정보 자체가 달라지므로, 전체적으로 그림이 그럴듯해 보여도 특정 영역의 텍스트가 누락·오류·판독불가·배치오류·통합불량 상태일 수 있다(Figure 2의 "Local success, whole-scene failure" 예시). 기존 벤치마크(MARIO-Eval, AnyText-Bench, CVTG-2K, LongText-Bench, STRICT, OCRGenBench, InfoTextBench 등)는 짧은 문자열 정확도, 긴 텍스트, 다중 텍스트 매칭 등 과제의 일부만을 다루며, 평가 방식(OCR 매칭, PNED, VLM 텍스트 추출 등)도 제각각이라 서로 다른 벤치마크 점수를 하나의 척도로 비교하기 어렵다. 가장 근접한 선행 연구인 InfoTextBench도 목표 문자열 목록 기반 OCR/VLM 평가에 그쳐, 영역별 위치·크기·종류·캐리어(텍스트가 올라간 물리적/디지털 표면)·중요도를 포괄하는 통일된 참조와 전체 장면 단위 평가는 제공하지 못한다.

핵심 기여

  • UltraText Bench 데이터셋: 24개 실세계 장면 범주(6개 도메인) × 3단계 난이도(L1 Hard, L2 Very Hard, L3 Extreme) × 영어/중국어로 구성된 총 432개 프롬프트(카테고리×레벨×언어 셀마다 3개). 각 프롬프트는 4~12개 텍스트 영역에 대해 정확한 목표 문자열과 위치(3×3 그리드)·상대적 크기·텍스트 유형·캐리어·중요도를 담은 구조화된 Ground Truth를 제공(전체 407,918 GT 문자, 2,926개 영역).
  • 전체 장면 단위 평가 프로토콜: Qwen-Image-Bench에서 가져온 VLM 심사자 Q-Judger가 생성 이미지와 완전한 구조화 참조를 함께 받아 6개 원시 점수(TA 정확도, TC 완전성, TR 가독성, PC 위치 정확도, LQ 레이아웃 품질, SI 장면 통합)를 산출하고, 이를 4개 보고 차원(Fidelity, Clarity, Spatial, Scene)과 가중 합성 점수(Composite)로 통합하는 공통 루브릭을 제시.
  • 24개 모델 구성에 대한 대규모 실험 분석: 난이도·언어·Base/Turbo 변형에 따른 체계적 성능 비교를 제공하고, 10명이 참여한 사람 평가로 자동 점수의 질적 해석을 보완.

방법론

UltraText Bench는 텍스트 생성을 "텍스트 재현 과제"로 정의한다: 모델 M은 모든 목표 문자열이 포함된 자연어 프롬프트 p만 입력으로 받아 이미지 I=M(p)를 생성하며, 구조화 참조 R={r1,...,rK}(각 영역의 텍스트·위치·크기·유형·캐리어·중요도)는 오직 평가에만 사용된다. 24개 범주는 Signage & Labels(Sign, Label, Poster, Billboard), Documents & Print(Article, Newspaper, Letter, Resume), Commercial(Menu, Receipt, Invoice, Packaging), Digital Interfaces(Webpage, Slide, Social media, Dashboard), Structured Data(Schedule, Form, Certificate, Code), Creative & Special(Caption, Dialogue, Comic, Infographic) 6개 도메인으로 그룹화된다. 난이도는 GT 문자 수와 영역 수가 함께 증가하도록 설계되었으며(영어 L1 250~600자, L2 600~1200자, L3 1200자 이상; 중국어 L1 350~600자, L2 550~900자, L3 600자 이상), 영어와 중국어 프롬프트는 독립적으로 작성·현지화되어 문화적 맥락(상호명, 가격, 어휘, 순서 관행)을 반영한다. 모든 432개 프롬프트는 수동 검토를 거쳐 목표 문자열 포함 여부, 주석 완전성, 난이도 밴드 준수 여부를 확인했다.

평가 시 Q-Judger는 이미지와 전체 참조를 받아 0~100 범위의 6개 원시 점수를 반환하며, Fidelity=(TA+TC)/2, Clarity=TR, Spatial=(PC+LQ)/2, Scene=SI로 집계한 뒤 Composite = 0.60·Fidelity + 0.30·Clarity + 0.05·Spatial + 0.05·Scene로 최종 점수를 산출한다(콘텐츠 보존과 가독성에 가중치 90%를 부여). 무효 응답(파싱/스키마/API/안전성 실패, 컨텍스트 오버플로 등)은 점수에서 제외되고 커버리지 지표에만 반영된다. 프롬프트별로 유효 이미지 점수를 평균한 뒤(prompt-macro 집계), 영어/중국어 평균을 동일 가중으로 합산해 양방향 결과를 산출한다.

실험 설정 및 결과

FLUX, Stable Diffusion(SD3.5), Hunyuan, HiDream, Qwen-Image, Z-Image, Boogu-Image, WAN, Nano Banana, GPT Image, LLaDA, Seedream 계열을 포함한 24개 모델 구성(오픈 웨이트 및 API 전용 모델)을 평가했다. 각 모델은 프롬프트당 4개 샘플을 생성해 언어당 864장, 모델당 1,728장의 이미지를 생성했다.

주요 결과: GPT Image 2 [Low]가 Composite 99.35로 1위를 차지했고(유효 이미지 1,723장 중 83.6%가 6개 원시 차원 모두 100점), Nano Banana 2(97.00), Seedream 5.0 Pro(91.45) 등 API 전용 모델이 전반적으로 강세를 보였다. 오픈 웨이트 모델 중에서는 Boogu-Image-0.1-Base(77.89)가 최상위였다. Turbo/가속 변형은 일관되게 Fidelity가 Base보다 낮았으나(Z-Image -14.76점, LLaDA-Image -7.62점, Boogu-Image-0.1 -9.50점), Clarity는 모델별로 다르게 변화했다(Z-Image·LLaDA-Image는 상승, Boogu-Image-0.1은 -13.45로 하락) — 예컨대 Z-Image-Turbo는 Base보다 Clarity가 3.81점 높지만 Fidelity는 14.76점 낮다. 난이도가 오를수록 성능이 급격히 저하되는 경향이 뚜렷했는데, Qwen-Image-2512의 Composite는 영어 기준 L1 86.50에서 L3 42.86으로, 중국어 기준 89.47에서 49.90으로 하락했다(단, Boogu-Image-0.1-Base의 중국어 점수는 L2 78.11에서 L3 83.23으로 오히려 상승하는 등 보편적 경향은 아님). 언어 간 격차도 모델에 따라 상반되게 나타나(Boogu-Image-0.1-Base는 L3에서 영어 57.67/중국어 83.23, GPT Image 1.5 [High]는 영어 77.21/중국어 18.22), 언어·콘텐츠·텍스트 로드가 복합적으로 작용함을 보였다. 합성 가중치를 등가중·Fidelity 단독·40/30/15/15 등으로 바꿔도 오픈 웨이트 1위(Boogu-Image-0.1-Base)는 유지되었으나, 근접한 순위(Qwen-Image-2512 대 Boogu-Image-0.1-Turbo)는 가중치에 따라 뒤바뀔 수 있었다.

한계점

  • 모델별로 표준 생성 설정(해상도, 종횡비, API 동작 등)이 달라 통제된 비교가 아니며, 이는 향후 과제로 남겨짐.
  • 셀당 프롬프트 수가 3개로 적어 개별 셀 수준의 통계적 정밀도가 제한적이고, 신뢰구간 없이 서술적 평균만 보고함.
  • 평가는 이미지 전체 단위 점수만 반환하며, 영역별(region-level) 점수나 텍스트 전사(transcription)는 제공하지 않음.
  • 단일 VLM 심사자(Q-Judger)에 의존하며, 정량적 평가자 간 일치도 및 사람 평가와의 정량적 정합성 통계는 보고하지 않음(사람 평가 10명은 질적 해석 보완 목적).
  • 영어/중국어 분할은 독립적으로 작성되었고 문자 로드 밴드도 다르기 때문에, 언어 효과만을 분리해 비교할 수 없음. 난이도 레벨도 텍스트 로드와 영역 수가 함께 변하므로 두 요인을 독립적으로 분리하지 못함.
  • 최고 점수(100점)가 실제 "정확한 문자 비율"을 의미하는 측정값이 아니라 VLM 루브릭상의 상한일 뿐이며, 최고 점수를 받은 이미지에도 국소적 결함(예: 저해상도로 흐려진 작은 글자)이 존재하는 사례가 보고됨.

시사점

UltraText Bench는 밀집·다영역·이중언어라는 세 축을 모두 포괄하는 구조화된 평가 체계를 제시함으로써, 단순히 "텍스트가 그려지는가"를 넘어 "모든 요청된 텍스트가 정확하고 가독성 있게, 올바른 위치에, 장면과 자연스럽게 통합되어 있는가"를 종합적으로 진단할 수 있게 한다. Turbo(가속) 모델들이 Clarity는 높이면서 Fidelity를 희생하는 경향, 난이도 상승 시 성능이 급락하는 경향은 향후 모델 개발 시 속도-정확도 트레이드오프와 긴 텍스트 로드에 대한 강건성을 별도로 측정·개선해야 함을 시사한다. 저자들은 구조화된 영역별 주석이 향후 영역 수준 진단 및 보상 기반 학습(DDPO, Diffusion-DPO 등)의 피드백 신호로 활용될 수 있음을 제안하며, 비디오 생성·편집 모델로 벤치마크를 확장하는 것을 향후 과제로 제시한다.
