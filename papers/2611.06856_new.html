LongBanana: An Expert-Verified Benchmark for Long-Context Multi-Reference Image Synthesis

롱바나나: 장문맥 다중 참조 이미지 합성을 위한 전문가 검증 벤치마크

다수의 참조 이미지에 흩어진 시각적 근거를 올바르게 검색·결합하여 하나의 이미지를 생성하는 능력을 정밀하게 측정하기 위한, 전문가가 설계하고 검증한 벤치마크 롱바나나(LongBanana)를 제안한다.

한 줄 요약

다수의 참조 이미지에 흩어진 시각적 근거를 올바르게 검색·결합하여 하나의 이미지를 생성하는 능력을 정밀하게 측정하기 위한, 전문가가 설계하고 검증한 벤치마크 롱바나나(LongBanana)를 제안한다.

배경 및 문제의식

에이전트 기반 이미지 생성 시스템이 발전하면서, 여러 장의 참조 이미지에서 필요한 정보만 고르고 유사하지만 관련 없는 방해 요소(하드 네거티브)를 걸러내며, 요구된 관계와 제약을 만족하는 하나의 이미지를 합성하는 과제가 중요해졌다. 그러나 기존 이미지 생성·편집 벤치마크는 지시 기반 편집이나 소수 참조 이미지 상황에 집중되어 있어, 참조 근거가 올바르게 사용되었는지(즉 올바른 객체를 선택했는지, 잘못된 참조에서 속성을 베끼지 않았는지, 금지된 콘텐츠를 포함하지 않았는지)를 세밀하게 측정하기 어렵다. 저자들은 이러한 오류를 렌더링 오류가 아닌 "근거 귀속(provenance)" 오류로 규정하고, 이를 측정 가능하게 만드는 벤치마크의 필요성을 제기한다.

핵심 기여

논문은 네 가지를 기여한다. 첫째, 장문맥·다중참조 이미지 합성을 위한 벤치마크 데이터셋 롱바나나-벤치(LongBanana-Bench)로, 90개의 전문가 설계 케이스와 조밀한 참조 세트, 하드 네거티브, 미지원 콘텐츠 규칙, 3×3 분류 체계를 포함한다. 둘째, 엔티티-관계 그래프를 원자적 체크리스트 항목으로 변환하여 콘텐츠 충실도, 관계적 바인딩, 전역 제약 만족이라는 세 차원에서 평가하는 그래프 기반 평가 체계 롱바나나-이벨(LongBanana-Eval)이다. 셋째, 전문가가 검토한 체크리스트 라벨과 평가자 간 합의 통계, 근거 추적을 제공하는 검증 프로토콜이다. 넷째, 직접 생성·에이전트 하네스·RPR(ReAct–Plan–Exec–Reflect) 워크플로를 비교하는 에이전트 기반 이미지 생성 연구이다.

방법론

각 케이스는 시나리오 설명에서 출발해 LLM이 엔티티·속성·관계·전역 제약을 담은 엔티티-관계 그래프로 구조화하고, 이 그래프를 바탕으로 목표 지시문과 참조 이미지(사례당 평균 약 32장)를 생성한 뒤, 그래프의 각 노드·엣지·전역 제약을 하나씩 원자적 체크리스트 항목(총 4,670개)으로 변환하는 4단계 파이프라인으로 구축된다. 평가 시에는 '롱바나나이벨'이라는 에이전틱 체크리스트 판정자가 각 항목을 해당 평가 차원(콘텐츠 충실도/관계적 바인딩/전역 제약 만족)의 전문 비평자에게 배정하고, 필요 시 OCR, 개수 세기, 레이아웃 분석, 동일성 매칭 같은 검증 도구를 호출하여 0~2점의 라벨을 매기고 근거 추적을 기록한다. 생성 성능은 Hermes-Agent, OpenCode, OpenClaw 등 서로 다른 에이전트 하네스에 Nano Banana 2, Seedream 4, GPT Image 1 같은 이미지 생성 백엔드를 결합하고, 다이렉트 생성 대비 RPR(ReAct 기반 근거 수집 → Plan–Exec 분해 실행 → Reflect 기반 수정) 워크플로의 효과를 비교하는 방식으로 연구한다.

실험 설정 및 결과

900개 생성 결과(90케이스 × 10가지 생성 조건)에 대해 46,700개의 체크리스트 항목을 사람이 라벨링했으며, 이 중 15%(7,005개)를 이중 라벨링해 89.4%의 정확 일치율과 0.83의 가중 카파 값을 확보했다. 자동 판정자 롱바나나이벨은 단일 패스 VLM 심판 기준보다 사람 평가와의 상관관계(Pearson 0.8707, Spearman 0.8602, Kendall 0.6727)가 더 높았다. 생성 실험에서는 그래프 정보를 직접 활용하는 비에이전트 베이스라인(PD-Direct)이 강력한 기준선을 형성했지만, 대부분의 에이전트 하네스가 이를 상회했으며, 특히 OpenClaw+RPR+Nano Banana 2 조합이 전체 평균에서 가장 높은 점수(78.4)와 과제 통과율(P@70% 47.8%)을 기록해 적응적 근거 검색·계획·반성 워크플로의 가치를 보여주었다. 이미지 생성 백엔드 비교에서는 Nano Banana 2가 9개 모든 하위 범주에서 Seedream 4, GPT Image 1보다 우수했다.

한계점

논문 본문에는 구체적 한계 목록이 명시적으로 드러나지 않았으나(부록 E에 "책임 있는 공개와 안전장치" 및 한계·영향 관련 논의가 있다고 언급되지만 본문에서 상세 내용은 확인되지 않음), 벤치마크가 90개 케이스로 상대적으로 제한된 규모이며 평가 파이프라인이 특정 VLM(Gemini 3 Flash)에 기반한다는 점, 그리고 모든 생성 조건이 폐쇄형 또는 제한된 이미지 생성 백엔드 조합에 한정되어 있다는 점은 본문 설계에서 드러나는 한계로 볼 수 있다. 논문에 명시되지 않음.

시사점

롱바나나는 다중참조 이미지 생성에서 "그럴듯해 보이지만 틀린" 결과, 즉 근거 귀속 오류를 체계적으로 진단할 수 있는 감사 가능한(auditable) 평가 틀을 제공한다. 이는 향후 에이전트형 이미지 생성 시스템이 단순히 시각적 품질을 넘어 참조 근거를 정확히 추적하고 활용하는 능력을 기르는 데 공유 목표와 측정 도구로 활용될 수 있으며, 계획 수립과 생성 중 적응적 근거 검증·수정을 결합하는 방향이 향후 에이전트 설계의 핵심 과제임을 시사한다.
