Sage-A1.5: From Long-Horizon Execution to Scientific Exploration with Capability Composition

한 줄 요약

35B 규모의 Mixture-of-Experts 에이전트 모델 Sage-A1.5는 전작 Agents-A1에 "에이전트 오케스트레이션"과 "에이전트 검증" 능력을 더해, 단일 과업 해결을 넘어 작업을 조직하고 스스로 점검하며 장기적 과학 탐구까지 수행하도록 설계되었다.

배경 및 문제의식

저자들의 이전 모델 Agents-A1은 모델 파라미터 대신 에이전트의 실행 지평(horizon)을 확장해 장기 과업 성능을 끌어올렸지만, 단일 에이전트가 순차적으로 작업을 수행할 경우 맥락이 비대해지고 탐색이 느려지며 검증되지 않은 가정 위에 추론을 쌓아 오류가 누적되는 한계가 있었다. 소프트웨어 공학, 머신러닝 최적화, 과학 연구처럼 복잡한 과업은 하위 작업을 관리하고 접근법을 비교하며 새로운 증거에 따라 결정을 수정하는 능력을 요구하는데, 기존 접근은 이런 작업 조직화와 전략 수정을 외부 프레임워크의 고정 규칙에 의존해 왔다. 저자들은 과업 위임, 병렬 협업, 증거 검토, 전략 수정이 외부 규칙이 아니라 모델 스스로 학습하는 능력이 되어야 한다고 주장한다.

핵심 기여

Sage-A1.5는 Agents-A1을 기반으로 두 가지 핵심 능력을 추가한다. 1) 에이전트 오케스트레이션(Agentic Orchestration): 작업을 분해해 독립된 맥락을 가진 하위 에이전트(subagent)들에 위임하고 그 결과를 통합하는 능력. 2) 에이전트 검증(Agentic Verification): 진행이 정체되거나 중요한 결론에 도달했을 때 스스로 증거와 가정을 재검토하고 탐색 전략을 수정하는 능력으로, 외부 감독자나 별도 검증 도구 없이 모델 자신의 추론·도구 사용 과정 안에서 수행된다. 이 두 능력을 다영역 지도 미세조정과 혼합 보상 강화학습을 결합한 통합 학습 파이프라인으로 학습시켜, 코딩·머신러닝 엔지니어링·과학 연구·장문 추론·실세계 워크플로 등 여러 도메인과 추론 모드, 에이전트 하네스를 하나의 모델로 융합했다. 또한 복잡한 에이전트 과업과 다학제 과학 응용 사례 연구를 통해 개방형 과학적 발견 역량을 시연했다.

방법론

오케스트레이션 능력은 모델이 동일 질문에 서로 다른 가설/해법을 할당하는 "탐색적 구성(Exploratory Composition)"과 전체 과업을 상호 보완적인 하위 문제로 나누는 "구성적 구성(Constructive Composition)" 두 패턴으로 학습된다. 학습 데이터는 하나의 정답 개체를 중심으로 여러 관계 체인을 별 모양(starlike) 그래프로 엮어 병렬 조사가 필요한 제약 중심 질의를 만드는 방식과, 여러 출처의 증거를 통합하는 멀티소스 연구 종합 과제로 구성된다. 검증 능력은 실행 모델이 실시간 검색·웹 읽기를 수행하는 동안 감독 모델이 반복적 탐색, 정체, 핵심 결론 확인 시점에 개입해 "검증" 사례를 삽입한 완전한 연구 궤적을 구축해 학습시키며, 추론 시에는 시스템 프롬프트의 조건부 마커(Verification protocol: enabled)로 이 능력을 활성화한다. 이외에도 Kaggle 경진대회를 과업화하는 Kaggle-MLE Factory, SWE-bench 형식의 레포지토리 수준 이슈 해결 데이터, 세계모델 기반 난이도 예측으로 과학 문제를 선별하고 탐색·시각화·학술검색 도구를 갖춘 하네스로 과학 교사 모델을 증류하는 3단계 파이프라인, 장문 맥락 추론을 위한 재귀적 과업 진화(Recursive Task Evolution), 경제적으로 가치 있는 실세계 워크플로(Agents' Last Exam) 등 다양한 도메인별 학습 데이터를 구축했다. 최종적으로 outcome 기반 강화학습과 다중 교사 모델의 온폴리시 증류(OPD)를 샘플 단위로 가중 결합하는 통합 outcome-process 사후학습으로 여러 도메인 교사 모델을 하나의 모델로 합친다.

실험 설정 및 결과

GAIA, BrowseComp, DeepResearch Bench II, XBench-DS-2510(검색), SWE-Bench Pro/Multilingual, SciCode, MLE-Bench-Lite(엔지니어링), FrontierScience-Olympiad/Research, HLE w/ tools, HiPhO, CMT-Benchmark, CritPt(과학 연구), IFBench, AA-LCR, ALE-CLI, PinchBench(범용/실세계 에이전트), ChemCoTBench, MatTools, OmniDocBench(과학 에이전트 과업) 등 20여 개 벤치마크로 평가했다. 35B 규모의 동급 모델인 Agents-A1, Ornith-1.5 대비 12개 벤치마크 전반에서 동등하거나 앞섰고, Kimi-K3, GLM-5.3, GPT-5.6-sol 같은 훨씬 큰 규모 모델과 비교해도 FrontierScience-Olympiad(81.0), CMT(80.0), PinchBench(90.0), IFBench(81.6) 등에서 우위를 보였다. 에이전트 오케스트레이션을 켜면 BrowseComp 정확도가 81.7에서 82.8로, DeepResearch Bench II 점수가 43.7에서 47.5로 상승했고, 에이전트 검증을 활성화하면 BrowseComp 정확도가 81.0에서 85.5로 오르면서 오히려 평균 출력 토큰 수와 턴 수가 줄어 검증이 불필요한 탐색을 줄이는 효과도 확인됐다. 과학 특화 교사 모델은 Qwen3.5-35B-A3B 베이스 대비 CritPt 0.9→25.7, FS-R 2.5→70.0 등 연구형 과업에서 큰 향상을 보였고, MLE 교사 모델은 MLE-Bench-Lite 금메달률을 22.7%에서 50.0%로 두 배 이상 끌어올렸다.

한계점

현재의 오케스트레이션·검증 학습은 주로 검색과 연구 종합 과업에 집중되어 있고, 초장기 궤적에서는 여전히 맥락 오버헤드가 누적되는 문제가 남아 있다. 또한 여러 도메인 교사 모델을 하나로 통합한 최종 모델이 개별 교사 모델 각각의 최고 성능을 모든 도메인에서 완전히 유지하지는 못한다. 과학적 응용 사례도 아직 계산 시뮬레이션과 과거 데이터 재현 범위에 머물러 있으며, 실제 물리적 실험과의 연계는 이루어지지 않았다.

시사점

이 연구는 에이전트의 성능 향상이 더 큰 모델이나 더 긴 실행만이 아니라, 작업을 어떻게 나누고 언제 스스로를 점검할지를 학습된 능력으로 내재화하는 "능력 조합"을 통해서도 가능함을 보여준다. 35B라는 비교적 작은 규모에서도 오케스트레이션과 검증을 통해 훨씬 큰 모델과 경쟁할 수 있다는 점은 효율적인 에이전트 설계에 실용적 시사점을 주며, 로컬 배포를 지원한다는 점에서 개방형 과학 탐구를 위한 접근 가능한 기반 모델을 지향한다는 저자들의 목표와도 맞닿아 있다.
