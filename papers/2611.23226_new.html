FastFrames: Video Generation at Interactive Latency

패스트프레임즈: 인터랙티브 지연 수준의 비디오 생성

자기회귀(autoregressive) 비디오 디퓨전 모델의 추론 파이프라인에서 VAE 디코딩과 KV 캐시 갱신이 전체 지연의 절반 이상을 차지한다는 점을 밝히고, 이를 경량 네트워크로 대체하여 품질을 유지하면서도 프레임당 50ms 이하(실시간 상호작용 가능 수준)의 지연을 달성하는 FastFrames 모델군을 제안한다.

한 줄 요약

자기회귀(autoregressive) 비디오 디퓨전 모델의 추론 파이프라인에서 VAE 디코딩과 KV 캐시 갱신이 전체 지연의 절반 이상을 차지한다는 점을 밝히고, 이를 경량 네트워크로 대체하여 품질을 유지하면서도 프레임당 50ms 이하(실시간 상호작용 가능 수준)의 지연을 달성하는 FastFrames 모델군을 제안한다.

배경 및 문제의식

자기회귀 비디오 디퓨전 모델은 새로운 입력(조작 신호 등)에 반응하며 프레임을 순차적으로 생성할 수 있어 월드 시뮬레이션, 게임, 로봇용 예측 모델 등 인터랙티브 응용에 유망하다. 그러나 기존 모델들은 "초당 프레임 수(FPS)"는 높아 보여도, 사용자의 입력이 들어온 뒤 그 효과가 반영된 첫 프레임이 나오기까지의 실제 지연(latency)은 여전히 수백 ms에 달해 인간-컴퓨터 상호작용 연구에서 제시하는 지연 감지 임계값(약 50~60ms)을 크게 초과했다. 즉 FPS만으로는 모델이 실시간으로 사용자 입력에 반응할 수 있는지 알 수 없다는 문제의식에서 출발한다.

핵심 기여

  • 기준(1.3B) 모델의 추론 파이프라인을 프로파일링하여, 디노이징(디퓨전 샘플링) 단계가 아니라 VAE 디코딩과 KV 캐시 갱신용 추가 DiT 연산이 전체 지연의 절반 이상을 차지함을 규명.
  • VAE 디코더를 저해상도에서만 동작하는 ConvNeXt 기반 헤드와 단일 선형층(업샘플링)으로 교체하여 디코딩 지연을 147배 줄이면서도 품질을 유지.
  • KV 캐시 갱신용 DiT 평가를 경량 네트워크로 대체하여 캐시 갱신 지연을 10배 줄임.
  • 이러한 경량화와 시스템 수준 최적화를 결합해, 프레임당 지연 50ms(초당 20회 응답, RPS) 이하를 달성한 최초의 자기회귀 비디오 디퓨전 모델군 FastFrames를 제시.

방법론

기존 자기회귀 비디오 디퓨전 모델은 매 프레임 생성 시 이전 프레임의 디노이즈된 잠재표현으로 KV 캐시를 갱신하는 DiT 연산, 다단계 디노이징 샘플링, VAE 디코딩을 순차적으로 수행한다. FastFrames는 (1) VAE 디코더를 동결된 DiT에 특화된 경량 "픽셀 헤드"(저해상도 ConvNeXt + 선형 언패치/업샘플링)로 대체하여 픽셀 공간에서 지각손실(perceptual loss)과 GAN 손실로 종단간 학습이 가능하게 하고, (2) 캐시 갱신용 DiT 평가를 경량 네트워크로 교체하며, (3) 종단간 프레임당 임계 경로(critical path)를 겨냥한 하드웨어 인지 시스템 최적화를 추가로 수행한다. 이 구성요소들은 백본 아키텍처(하이브리드 트랜스포머)나 증류(distillation) 기법 개선과도 상호 보완적으로 결합 가능하다.

실험 설정 및 결과

단일 B200 GPU 기준 1.3B 모델(FastFrames-S)은 480p(832×480) 해상도에서 프레임당 36ms(초당 28회 응답)를 달성하며, 약 7.6~8배 느린 최신 베이스라인(Causal Forcing++)과 동등한 VBench 생성 품질을 보였다. 8×B200 GPU 노드에서 14B 모델(FastFrames-L)은 프레임당 45ms(초당 22회 응답)로 더 높은 시각적 품질과 사실성을 보였다. 세부 프로파일링(Table 2)에 따르면 기존 VAE 디코딩이 480p에서 147ms 걸리던 것을 자체 픽셀 디코더는 1ms로 줄였으며, 720p에서는 VAE가 327ms인 반면 제안 디코더는 2ms에 불과했다. 카메라 조건·물리 조건 비디오 생성 응용에서도 FastFrames가 유연한 실시간 상호작용을 가능케 함을 시연했다.

한계점

현재 결과는 대부분 480p 해상도에 맞춰져 있으며, 720p나 4K 같은 고해상도로 가면 지연이 크게 증가해 추가적인 최적화가 필요하다. 지연 측정에 사용한 B200 GPU는 고성능 하드웨어이며, 온디바이스 등 더 접근성 높은 하드웨어에서의 실시간 구동은 향후 과제로 남아있다. 또한 카메라 조건 등 제어 신호를 채널 차원이 아닌 시퀀스 차원에 이어붙이는 기존 설계를 그대로 사용했는데, 저지연을 염두에 둔 베이스 모델 설계(채널 차원 결합 등)가 추가로 필요하다.

시사점

비디오 디퓨전 모델의 지연을 줄이는 노력이 주로 디노이징 스텝 수 감소에 집중되어 왔으나, 실제로는 "고정된 구현 세부사항"으로 취급되던 VAE 디코딩·캐시 갱신이 더 큰 병목이었음을 보여준다. 이는 향후 인터랙티브 비디오 생성 모델 설계에서 디노이징 외 보조 구성요소의 경량화가 독립적으로 중요한 최적화 축임을 시사하며, 실시간 게임·시뮬레이션·로보틱스 응용에 비디오 생성 모델을 실용적으로 적용할 수 있는 가능성을 연다.
