Video-Coder: Reinforcing Agentic Coding for Video Generation

비디오코더: 비디오 생성을 위한 에이전틱 코딩 강화학습

텍스트 프롬프트를 바로 영상으로 바꾸는 대신, 코드를 작성·실행해 3D 장면을 만들고 이를 바탕으로 영상 생성기를 유도하는 "코드 기반 영상 생성 에이전트" 비디오코더(Video-Coder)를 제안한다.

한 줄 요약

텍스트 프롬프트를 바로 영상으로 바꾸는 대신, 코드를 작성·실행해 3D 장면을 만들고 이를 바탕으로 영상 생성기를 유도하는 "코드 기반 영상 생성 에이전트" 비디오코더(Video-Coder)를 제안한다.

배경 및 문제의식

기존 영상 생성 모델(디퓨전, 자기회귀 모델 등)은 시각 품질과 단기적 시간 일관성은 높였지만, 물체 개수·공간 배치·물리적으로 타당한 운동 같은 3D적 구조를 명시적으로 모델링하지 않는다. 그 결과 프롬프트에 "세 개의 정육면체"처럼 정확한 개수나 공간 관계가 포함되면 생성 결과가 틀리거나, 생성된 영상을 수정하려면 프롬프트를 다시 써서 시행착오를 반복해야 하는 문제가 있다. 저자들은 코드가 장면의 기하학적 구조, 물체 움직임, 카메라 경로를 명확하고 조합 가능하게 표현할 수 있다는 점에 착안했다.

핵심 기여

  • 영상 생성을 위한 코딩 에이전트를 학습시킨 최초의 시도인 비디오코더(Video-Coder)를 제안: 에이전트가 Blender 파이썬 코드를 작성·실행해 질감 없는 "초안 영상(Draft Video)"을 만들고, 이를 구조·모션 신호로 삼아 하위 영상 생성 모델을 유도한다.
  • 전용 데이터 구축 파이프라인을 설계해 Video-Coder-SFT-6k(지도학습용)와 Video-Coder-RL-2k(강화학습용) 두 데이터셋을 구축.
  • 코드 실행, 3D 장면 렌더링, 실행 피드백을 통합한 상호작용 환경인 Video-Coder Harness를 제안.
  • 실행 기반 보상과 영상 기반 보상을 결합하고, 학습이 진행될수록 실행 보상의 비중을 줄여가는 "어닐링(annealing)" 전략을 적용한 강화학습(GRPO 기반)으로 모델을 학습.

방법론

먼저 다양한 공개 영상 데이터셋의 캡션을 LLM으로 재작성해 물체·개수·공간 배치·모션을 명시한 "장면 중심" 프롬프트를 만든다. 이 프롬프트를 바탕으로 Gemini 3.8 Flash가 Video-Coder Harness 안에서 Blender 코드를 반복적으로 작성·실행·수정하며 초안 영상을 생성하는 다회차(multi-turn) 에이전트 궤적을 기록한다. 이 프롬프트와 초안 영상을 MiniMax-H3에 입력해 질감과 외형이 입혀진 정답(ground-truth) 영상을 합성하고, 실행 유효성·초안 영상 품질·프롬프트 일치도 기준으로 데이터를 정제한다. 학습은 2단계로 진행되는데, Qwen3.5-9B를 기반으로 먼저 SFT로 장면 프로그래밍과 도구 호출 능력을 가르친 뒤, 실행 성공 여부를 평가하는 실행 보상과 VLM(Qwen3.8-omni-flash)이 평가하는 영상 품질 보상을 결합한 GRPO 기반 강화학습을 수행한다. 이때 학습 진행에 따라 실행 보상의 가중치를 지수적으로 감쇠시켜, 초반에는 코드가 안정적으로 실행되도록, 후반에는 영상 품질이 최적화되도록 유도한다.

실험 설정 및 결과

물리적 타당성을 평가하는 PhyGenBench와 VBench-2.0의 물리 관련 차원(역학·열역학·재질)에서 Minimax-H3를 하위 생성기로 사용해 평가했다. Video-Coder-9B + Minimax-H3는 PhyGenBench 평균 0.67점으로 모든 비교 대상(Gen-3 0.51, Kling 0.49, Wan2.2-TI2V-5B 0.54 등)을 능가했으며, Minimax-H3 단독 대비 약 7점, VBench-2.0에서는 약 24점(78.19% vs 54.58%) 향상되었다. 학습에 쓰이지 않은 다른 영상 생성기(OmniWeaving)에도 적용했을 때 0.48에서 0.51로 성능이 올라 일반화 가능성을 보였다. 어블레이션 결과, 실행 보상과 영상 보상 중 하나라도 제거하면 성능이 떨어지고, 어닐링 전략을 빼면 모델이 지나치게 보수적인(실행은 잘 되지만 단조로운) 코드만 생성하는 경향이 나타났다.

한계점

초안 영상은 질감·외형 정보 없이 구조와 모션만 담기 때문에, 재질(Material) 관련 지표는 CogVideoX-1.5 등 외형 묘사에 특화된 모델보다 낮은 경향을 보였다(저자들은 이를 "구조와 모션만 인코딩하는 초안 영상의 의도된 한계"로 설명). 그 외 세부 실패 사례나 데이터 편향에 대한 논의는 논문에 명시되지 않음.

시사점

영상 생성 품질 향상을 "더 큰 생성 모델"이 아니라 "장면을 코드로 명시적으로 설계하는 에이전트"라는 방향에서 접근했다는 점에서, 코딩 에이전트와 멀티모달 생성 모델을 결합하는 새로운 연구 흐름을 제시한다. 특히 데이터셋·환경·모델을 모두 공개한다고 밝혀, 코드 기반 영상 생성 에이전트 연구의 기반이 될 것으로 기대된다.
