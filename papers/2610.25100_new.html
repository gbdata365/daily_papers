Deep Fusion Memory: A Chunk-Level Parametric Memory for Large Language Models

딥 퓨전 메모리: 대규모 언어모델을 위한 청크 단위 파라메트릭 메모리

대규모 언어모델(LLM)에 외부 지식을 주입할 때, 청크(chunk) 단위로 학습 타깃을 구성하고 예측된 메모리를 디코더의 중간 은닉 상태에 게이트형 교차어텐션으로 깊게 융합함으로써, 기존 토큰 단위 파라메트릭 메모리 방식보다 훨씬 적은 검색 비용으로 더 높은 QA 및 도메인 적응 성능을 얻는 방법(DFM)을 제안한다.

한 줄 요약

대규모 언어모델(LLM)에 외부 지식을 주입할 때, 청크(chunk) 단위로 학습 타깃을 구성하고 예측된 메모리를 디코더의 중간 은닉 상태에 게이트형 교차어텐션으로 깊게 융합함으로써, 기존 토큰 단위 파라메트릭 메모리 방식보다 훨씬 적은 검색 비용으로 더 높은 QA 및 도메인 적응 성능을 얻는 방법(DFM)을 제안한다.

배경 및 문제의식

LLM은 사전학습 단계에서 습득하지 못했거나 오래되어 낡은 지식을 보완하기 위해 외부 코퍼스의 지식을 주입할 필요가 있다. 기존 접근법들은 다음과 같은 트레이드오프를 갖는다. - 지속적 사전학습(CPT)/LoRA: 추가 코퍼스로 모델을 적응시키지만, 기존에 학습된 능력을 잊어버리는 "치명적 망각(catastrophic forgetting)" 문제가 있다. - 비파라메트릭 검색(RAG, RETRO 등): 생성 시점에 외부 근거를 직접 조회하므로 모델 파라미터에 지식을 먼저 학습시킬 필요가 없지만, 데이터스토어 탐색과 근거 처리로 인해 추론 시 지연(latency)이 크게 늘어난다. - 기존 파라메트릭 메모리(MLP Memory, Memory Decoder 등): 검색으로 얻은 지식을 오프라인에서 미리 학습해두어 추론 시 별도 검색이 필요 없다는 장점이 있다. 그러나 토큰 단위로 학습 타깃(target)을 구성하려면 코퍼스의 모든 토큰 위치마다 검색을 수행해야 하므로 오프라인 데이터 구축 비용이 막대하고, 메모리를 출력 확률 수준에서만 보간(interpolation)하는 "얕은 융합(shallow fusion)"에 그쳐 모델의 중간 표현을 활용하지 못한다.

이 논문은 "외부 지식을 효율적으로 획득하면서도 효과적으로 활용"하는 두 목표를 동시에 달성하는 것을 핵심 문제로 삼는다.

핵심 기여

  1. 깊은 융합(Deep Fusion) 아키텍처 제안: 학습된 코퍼스 지식을 디코더의 중간 은닉 상태에 주입하여 이후 레이어들이 문맥과 함께 메모리를 처리할 수 있도록 하는 파라메트릭 메모리 구조(DFM)를 제시한다. 추론 시 별도의 검색이 전혀 필요 없다.
  2. 청크 단위 지도학습으로 구축 비용 절감: 토큰 단위가 아닌 청크(여러 토큰 묶음) 단위로 학습 타깃을 공유함으로써, 기존 토큰 단위 방식 대비 검색 질의(query) 수를 32배, 검색된 항목 수를 2048배 줄인다.
  3. QA 및 도메인 적응 성능 개선: 6개 QA 태스크에서 가장 강력한 베이스라인 대비 Mistral-7B-v0.3에서 12.71%, Qwen3-8B-Base에서 11.19% 상대 성능 향상을 달성했다. 코드·수학·법률 분야 적응에서도 Qwen3-4B-Base와 Qwen3-8B-Base 대비 평균 6.51점, 4.38점의 성능 향상을 보였다.

방법론

DFM은 크게 (1) 학습 데이터 구축, (2) 메모리 예측기(predictor)와 융합(fusion) 모듈의 동시 학습, (3) 검색이 필요 없는 추론의 세 단계로 구성된다.

  • 학습 데이터 구축: 학습 시퀀스를 겹치지 않는 C토큰 크기의 청크들로 분할한다. 각 청크 X_j(j≥1)에 대해, 바로 앞 청크 X_(j-1)을 오프라인 검색기로 인코딩하여 코퍼스 데이터스토어에서 top-K 이웃 청크를 검색하고, 이들의 고정된 임베딩을 순위대로 쌓아 "타깃 메모리" V_j를 만든다. 즉 하나의 타깃 메모리가 청크 내 모든 토큰 예측에 공유되어, 토큰마다 검색할 필요가 없어진다.
  • 메모리 예측기(Memory Predictor): 인과적(causal) 트랜스포머 구조로, 직전까지의 청크 임베딩들(C_≤j)을 입력받아 K개의 연속적인 메모리 벡터를 예측한다. 각 메모리 슬롯은 별도의 선형 출력 헤드를 가진다.
  • 메모리 융합(Memory Fusion): 예측된 메모리는 공유 프로젝터(LayerNorm + 2개의 선형층 + GELU)를 거쳐 디코더의 은닉 차원으로 변환된 뒤, 선택된 디코더 레이어들(논문 기본 설정: [9, 16, 24, 31]번째 레이어)에서 게이트형 교차어텐션(gated cross-attention)을 통해 자기어텐션(self-attention)과 병렬로 적용된다. 각 어텐션 헤드마다 토큰별 시그모이드 게이트가 학습되어, 메모리가 은닉 상태 업데이트에 얼마나 기여할지를 조절한다. 두 분기(자기어텐션 + 메모리어텐션)의 출력은 동일한 residual 업데이트에 합산된다.
  • 학습 목표: 백본(backbone)은 동결(frozen)한 채, 추가된 예측기·프로젝터·융합 모듈만을 다음 토큰 예측을 위한 교차 엔트로피 손실과, 예측된 메모리와 타깃 메모리 간의 평균제곱오차(MSE) 손실을 결합하여 end-to-end로 공동 학습한다.
  • 추론: 추론 시에는 타깃 메모리를 구성할 필요 없이, 입력 시퀀스로부터 메모리 예측기가 직접 메모리를 생성하여 선택된 레이어에 공급한다. 데이터스토어 검색, 검색된 텍스트, 외부 임베딩 인코더가 전혀 필요하지 않다.

실험 설정 및 결과

  • 데이터셋: QA 실험은 약 40억 토큰 규모의 2018년 12월 영문 위키피디아로 학습하며, 단일홉 QA(NQ, WebQA)와 다중홉 QA(HotpotQA, 2WikiMultiHopQA, MuSiQue, Bamboogle) 총 6개 태스크로 평가한다. 도메인 적응은 코드(Swallow-Code), 수학(Swallow-Math), 법률(DISC-Law-SFT) 데이터로 학습 후 HumanEval/HumanEval+, GSM8K, LawBench로 평가한다.
  • 백본 모델: QA 실험은 Mistral-7B-v0.3과 Qwen3-8B-Base(부록에서는 OLMo-3-1025-7B도 추가), 도메인 적응은 Qwen3-4B-Base와 Qwen3-8B-Base를 사용한다. 청크 크기는 32토큰, 메모리 슬롯 수(top-K)는 16, 임베딩은 Qwen3-Embedding-0.6B로 생성한다. 추가되는 모듈 파라미터는 QA 백본 기준 약 7.5억 개(0.75B) 수준이다.
  • 베이스라인: 비파라메트릭(RAG, xRAG, RETRO)과 파라메트릭(CPT, LoRA, MLP Memory) 방식들과 비교한다.
  • QA 결과: DFM은 두 백본 모두에서 온라인 검색 없이 6개 태스크 평균 최고 점수를 기록했다. Mistral에서는 최강 베이스라인(xRAG, 24.14)보다 27.21로 12.71% 향상, Qwen3-8B-Base에서는 MLP Memory(23.80)보다 26.46으로 11.19% 향상되었다. 다만 WebQA처럼 일부 태스크·백본 조합에서는 메모리 적응이 항상 유익하지는 않았다(Qwen3 WebQA는 Base보다 소폭 하락).
  • 도메인 적응 결과: 코드·수학·법률 전반에서 DFM은 Base 모델 대비 모든 벤치마크에서 성능이 향상되었고, 4B/8B 모델에서 평균 6.51점, 4.38점의 이득을 얻어 비교 방법들 중 최고 평균을 기록했다.
  • 효율성: 동일한 40억 토큰 코퍼스 기준으로, 토큰 단위 MLP Memory는 40억 개의 검색 질의와 40.96조(4.096T) 개의 검색 항목이 필요한 반면, DFM(32토큰 청크)은 1.25억 개의 질의(96.88% 감소)와 20억 개의 검색 항목(99.95% 감소)만 필요했다. 학습 시간도 16×A800 GPU 기준 MLP Memory 64시간 대비 DFM 24시간으로 약 62.5% 단축되었다.
  • 분석(Ablation): 청크 크기(16/32/64), 융합 레이어 위치·개수, 메모리 슬롯 수(K)에 대한 민감도는 비교적 낮았으며(32토큰·중간~후반 레이어·K=16이 기본값이자 최적에 가까운 설정), 게이트 메커니즘과 그 초기화(바이어스 -2 또는 0)가 성능에 의미 있는 영향을 주는 것으로 나타났다(게이트 제거 시 평균 점수 하락).

한계점

  • 논문이 명시한 바로는, 메모리 적응의 효과가 모든 태스크·백본 조합에서 일관적이지 않다(예: Qwen3 백본에서 WebQA 성능이 Base보다 하락, 일부 다중홉 QA 태스크에서는 명시적 검색 기반 방법(RAG, xRAG)이 여전히 더 우수함).
  • 추론 시 메모리 쿼리는 보이는 프롬프트(가시적 입력)로부터만 구성되고 답변 생성 중에는 고정되며, 새로 생성된 답변 토큰에 대해서는 메모리가 갱신되지 않는 등 생성 과정 중 동적 갱신에 한계가 있다.
  • 코드는 "추후 공개"라고만 언급되어 있어 현재 시점에는 공개 저장소나 재현 자료가 없다(논문에 명시되지 않음: 구체적 공개 일정).
  • 본 연구는 특정 규모(7B~8B급, 그리고 4B)의 모델과 특정 코퍼스(위키피디아, 코드/수학/법률 서브셋)에서 검증되었으며, 더 큰 모델이나 다른 도메인으로의 일반화 가능성은 논문에 명시되지 않음.

시사점

DFM은 "검색은 비싸고, 파라메트릭 메모리는 구축 비용이 크며 얕은 융합만 가능하다"는 기존 트레이드오프를 동시에 완화하는 방향을 보여준다. 토큰 단위가 아닌 청크 단위로 지도학습 타깃을 공유하는 아이디어는 외부 지식 주입의 오프라인 비용을 극적으로 낮출 수 있음을 시사하며, 예측된 메모리를 중간 은닉 상태에 게이트형 교차어텐션으로 주입하는 방식은 출력 확률 보간 방식보다 더 풍부한 정보 활용이 가능함을 보여준다. 이는 향후 LLM에 외부 지식·장기 기억을 효율적으로 결합하는 "파라메트릭 메모리" 연구 방향(지속적 학습, 검색 증강 생성, 도메인 특화 적응 등)에 실용적인 설계 지침(청크 크기, 융합 레이어 배치, 게이트 초기화 등)을 제공한다.
