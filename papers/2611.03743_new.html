EvoMemState: Evolving Memory State for Personal Agents

EvoMemState: 개인화 에이전트를 위한 진화하는 메모리 상태

개인화 에이전트의 장기 기억을 "사실(fact)의 집합"이 아니라 "사실 + 관계 상태 + 추론 상태"로 모델링하여, 기억 간의 갱신·충돌 관계와 현재 요청에 대한 적용 방식까지 명시적으로 다루는 상태 중심(state-centric) 메모리 프레임워크 EvoMemState를 제안한 논문.

한 줄 요약

개인화 에이전트의 장기 기억을 "사실(fact)의 집합"이 아니라 "사실 + 관계 상태 + 추론 상태"로 모델링하여, 기억 간의 갱신·충돌 관계와 현재 요청에 대한 적용 방식까지 명시적으로 다루는 상태 중심(state-centric) 메모리 프레임워크 EvoMemState를 제안한 논문.

배경 및 문제의식

LLM 기반 개인 에이전트는 대화가 누적될수록 사용자 선호, 경험, 제약 등을 장기간 유지해야 한다. 기존 메모리 시스템(MemoryBank, MemGPT, LightMem, Mem0, A-MEM, Supermemory 등)은 사실을 추출·정리·갱신·검색하는 "사실 중심(fact-centric)" 패러다임을 따르지만, 개별 사실을 독립적인 레코드로 취급하다 보니 새로운 사실이 기존 사실을 어떻게 갱신·제약·충돌시키는지, 그리고 현재 요청에서 그 사실이 얼마나 적용 가능하고 어떤 우선순위를 갖는지가 암묵적으로만 남는다.

저자들은 MemSyco-Bench의 Valid Memory Selection 하위셋을 이용한 사전 연구를 통해 두 가지 한계를 확인했다. (1) 기존 사실 중심 시스템들(MemoryBank, LightMem, Supermemory 등)은 관련된 기억을 함께 완전히 검색하지 못하는 경우가 58.9~61.8%에 달했고, 모든 필요한 기억이 검색된 경우와 일부가 누락된 경우 사이의 정답 정확도 차이가 시스템 대부분에서 5.9~33.3%p에 이르렀다. (2) 모든 관련 기억이 검색되어도 에이전트가 이를 적절히 사용하는 것은 보장되지 않는다. 고정된 자기반성(self-reflection) 프롬프트를 추가했을 때 오히려 평균 정확도가 50.5%에서 48.9%로 떨어지는 경우도 있었다. 이는 완전한 검색만으로는 올바른 기억 사용을 보장할 수 없고, 기억의 적용 가능성·역할·우선순위를 다루는 별도의 메커니즘이 필요함을 시사한다.

핵심 기여

  • 사실 중심 개인 메모리의 한계를 규명: 개별적으로 유지되는 사실들은 해석에 필요한 관계적 맥락을 결여하며, 완전한 검색조차 적절한 사용을 보장하지 않음을 실증적으로 보임.
  • 상태 중심(state-centric) 장기 메모리 프레임워크 EvoMemState 제안: 개인 메모리를 Persistent Facts(지속적 사실), Relational States(관계 상태), Reasoning State(추론 상태)로 표현.
  • 이를 구현하는 세 가지 구성 요소 제시: (i) Ontology-Guided Memory State Induction, (ii) RL-Based State Evolution, (iii) State-Aware Reasoning.
  • 장기 대화 및 메모리 사용 벤치마크에서 검색 완전성과 메모리 근거 응답 정확도 측면에서 기존 메모리 시스템 대비 일관된 성능 향상을 입증.

방법론

EvoMemState는 누적된 Persistent Facts $F_t$와 이들의 관계를 표현하는 Relational States $R_t = {(f_i, a_i^t, \rho_i^t)}$(각 사실의 현재 유효성·범위 $a_i^t$, 다른 사실과의 갱신·충돌·제약 관계 $\rho_i^t$), 그리고 특정 요청 $q_t$에 대해 생성되는 Reasoning State $Z_{q_t} = \Psi(q_t, F_t, R_t)$(기억의 적용 가능성·역할·우선순위를 지정)로 메모리 상태를 정의한다.

  1. Ontology-Guided Memory State Induction: 대화 기록에서 시간순으로 Persistent Facts(사용자 선호·경험·신념·상황·제약에 대한 단일 명제, 출처와 시점 포함)를 추출하고, 빈 온톨로지에서 시작해 각 사실을 순서대로 통합하며 개인 메모리 온톨로지(그래프)를 구축한다. 그래프는 개념 노드와 사실 노드로 구성되며, PARENT_OF/CONTAINS로 개념 계층을 구성(CREATE·MERGE·SPLIT 연산으로 갱신)하고, SUPERSEDES(갱신)·CONFLICTS_WITH(미해결 충돌) 관계 엣지로 사실 간 관계를 표현한다. 이 온톨로지 구조로부터 각 사실의 Relational State가 유도된다.

  2. RL-Based State Evolution: Relational State만으로는 특정 요청에서 기억을 어떻게 활용해야 하는지 결정할 수 없으므로, Memory State Evolution Policy $\pi_\theta$를 학습해 요청별 Reasoning State를 생성한다. 후보 Reasoning State가 고정된(frozen) 개인 에이전트의 응답 품질을 기준 답변 없이 받은 경우와 비교해 얼마나 개선시키는지로 보상을 계산하고(참조 답변 대비 점수 차이), GRPO(Group Relative Policy Optimization, Shao et al. 2024)를 이용해 정책을 학습한다. 정책은 Qwen3-4B-Instruct-2507로 초기화된다.

  3. State-Aware Reasoning: 추론 시점에 요청과 의미적으로 유사한 K개의 Persistent Facts를 시드로 검색한 뒤, 저장된 메모리 관계를 양방향으로 순회(traverse)하여 갱신·제약·충돌로 연결된 모든 사실을 포함시킨다. 학습된 정책이 요청, 검색된 사실, 관계 상태로부터 Reasoning State를 생성하고, 개인 에이전트는 이 두 상태를 모두 활용해 최종 응답을 생성한다.

오프라인 메모리 구축에는 DeepSeek-V4-Flash를, 온라인 응답 생성 모델로는 Qwen3-8B와 GPT-4o-mini를 사용했다.

실험 설정 및 결과

데이터셋: MemSyco-Bench, MemTrapBench(개인 에이전트의 과거 기억 사용 평가), LoCoMo 및 LoCoMo-Refined(장기 대화 회상·추론 평가) 4개 벤치마크를 사용.

베이스라인: NaiveRAG, MemGPT, MemoryBank, Mem0, A-MEM, LightMem, Supermemory, SimpleMem, PGMem 등 9개 비교 시스템.

주요 결과(Table 1): Qwen3-8B 기준 MemSyco-Bench에서 EvoMemState는 평균 정확도 57.6%로 최강 베이스라인 대비 12.2%p 높았고, GPT-4o-mini 기준으로는 58.9%로 5.9%p 높았다. When-to-Use/How-to-Use 정확도 최고, Sycophancy(영합) 비율 최저, Correct Use 최고를 기록했다. LoCoMo-Refined에서는 LLM-judge 점수와 토큰 F1 모두 최고 성능을 보였으며(최강 베이스라인 대비 judge 점수 6.1%p, 7.0%p 향상), MemTrapBench에서도 Safety·Task Boundary 항목에서 최고 점수를 달성했다.

메모리 상태 효과성(Q2, Figure 5): EvoMemState는 완전 검색률(Complete Retrieval Rate) 85.6%로 최고 베이스라인과 비슷한 수준을 달성했으나, Acc@complete(완전 검색 시 정확도)는 LoCoMo-Refined 70.8%, MemSyco-Bench 68.5%로 최강 베이스라인 대비 각각 11.5%p, 31.2%p 높아, 완전한 증거 확보 자체보다 이를 올바르게 사용하는 능력이 성능 차이를 만든다는 것을 보였다.

일반화(Q3, Figure 6): 학습된 Memory State Evolution Policy를 다른 메모리 시스템(NaiveRAG, Mem0, A-MEM, MemoryBank, MemGPT, LightMem)에 적용했을 때도 모두 0.2~4.9%p 성능이 향상되어, 정책이 특정 메모리 시스템에 종속되지 않고 전이됨을 확인했다.

Ablation(Q4, Table 2): Relational State를 제거하면 MemSyco-Bench와 MemTrapBench 점수가 8.9%p, 6.4%p 하락했고, Reasoning State 생성(RL 기반 정책) 없이 규칙 생성만 유지하거나 제거하면 MemSyco-Bench 정확도와 MemTrapBench 점수가 각각 최대 15.0%p까지 하락하여, 두 상태 모두가 성능에 필수적임을 보였다.

한계점

저자들은 본 연구가 텍스트 기반 상호작용 기록에만 초점을 맞추고 있음을 명시했다. 실제 개인 메모리 시스템은 문서, 이미지 등 멀티모달 정보도 다루어야 하며, 메모리 구조를 여러 모달리티에 걸쳐 표현·연결·적용하도록 확장하는 것은 향후 과제로 남겨두었다.

시사점

이 논문은 장기 개인화 메모리를 설계할 때 "무엇을 저장하느냐"뿐 아니라 "저장된 사실들이 서로 어떻게 관계되고, 현재 요청에 어떻게 적용되어야 하는가"를 명시적으로 모델링하는 것이 중요하다는 점을 보여준다. 특히 선호 변경이나 상충하는 정보가 누적되는 실제 개인 에이전트 환경에서, 단순한 사실 검색-합성 파이프라인은 일관성 없는 응답(영합, 오래된 정보 사용 등)을 유발할 수 있으며, 관계형 상태 구축과 강화학습 기반의 사용 경험 내재화를 결합하는 접근이 신뢰할 수 있는 개인화 응답에 기여할 수 있음을 시사한다. 또한 학습된 추론 상태 생성 정책이 다른 메모리 백엔드에도 전이 가능하다는 결과는, 이러한 "추론 상태 생성기"를 기존 메모리 시스템에 모듈처럼 추가하는 실용적 적용 가능성을 제시한다.
