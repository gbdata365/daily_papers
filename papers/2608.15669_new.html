Large Discovery Models: Empirically-Grounded Model-Based Open-Ended Search

대형 발견 모델: 경험적으로 근거한 모델 기반 개방형 탐색

LLM의 생성적 사전지식과 베이지안 비모수 서로게이트(가우시안 프로세스) 기반 불확실성 인지 보상 신호를 결합한 "Large Discovery Model(LDM)"을 제안하여, 값비싼 블랙박스 평가만 가능한 개방형(open-ended) 과학적 설계 공간(신경망 학습 프로그램·항체 서열·분자)에서 탐색(exploit)-탐구(explore)-발견(discover) 3단계를 하나의 재귀적 루프로 통합했다.

한 줄 요약

LLM의 생성적 사전지식과 베이지안 비모수 서로게이트(가우시안 프로세스) 기반 불확실성 인지 보상 신호를 결합한 "Large Discovery Model(LDM)"을 제안하여, 값비싼 블랙박스 평가만 가능한 개방형(open-ended) 과학적 설계 공간(신경망 학습 프로그램·항체 서열·분자)에서 탐색(exploit)-탐구(explore)-발견(discover) 3단계를 하나의 재귀적 루프로 통합했다.

배경 및 문제의식

  • LLM 추론(reasoning)은 수학·코딩·게임처럼 "값싸고 반복 가능한 검증자(verifier)"가 있는 영역에서는 크게 발전했지만, 과학적 발견은 후보 공간이 방대·구조적·부분적으로만 특정되어 있고, 피드백이 시뮬레이션·가속기 실험·물리적 어세이처럼 비싸고 지연되고 노이즈가 섞여 있어 근본적으로 더 어려움 (p.1-2)
  • 논문은 "경험적 과학적 발견(Empirical Scientific Discovery, Definition 1, p.2-3)"을 정의: 에이전트가 가설/설계를 생성하고, 제한된 수만 평가하고, 그 관측으로 믿음을 갱신하며 다음 탐색을 이끄는 순차 과정. 여기서 핵심 차이는 (1) 개방형(open-ended) — 관련 후보가 현재 모델/탐색 연산자 바깥에 있을 수 있음, (2) 예산 제약 — 극소수만 평가 가능
  • 기존 두 접근의 상호보완적 한계 (p.3-4): LLM은 구조화된 후보를 생성/수정할 수 있지만 그 후보의 외부적 과학적 가치를 신뢰성 있게 추정하지 못함(우도/자기평가가 실제 목표와 상관관계가 약함). 베이지안 최적화(BO)는 관측에 기반해 경험적으로 근거 있는 후보 선택을 하지만, 그 대표성/탐색 범위가 자신의 표현·탐색 연산자에 의해 노출된 후보로 제한됨
  • "예측 불확실성(predictive uncertainty)"과 "탐색 인지(search awareness)"를 구분(p.4)하고, Rumsfeld Matrix를 과학적 설계에 맞게 변형한 4분면(known knowns/known unknowns/unknown knowns/unknown unknowns, Figure 3, p.4)으로 개념화 — 이로부터 exploitation(활용)/exploration(탐구)/discovery(발견)라는 3분법을 제시

핵심 기여 (저자 명시, p.5)

  1. 과학적 발견을 "동적·구조적 설계 공간에 대한 추론시점(inference-time) 탐색" 문제로 정식화하고, 경험적 관측에 기반한 불확실성 인지 가치 모델로 안내되는 프레임워크 제안
  2. LLM의 구조적 사전지식과 추론시점 연산·순차적 실험 피드백을 결합한 "acquisition-tilted search policy(획득함수 기반 틸트 탐색 정책)" 도입
  3. 서로게이트 모델 오차와 LLM 기반 탐색 프로세스의 준최적성(suboptimality)을 분리하는 후회(regret) 분석 제공
  4. 컴퓨터 프로그램·생물학적 서열·분자라는 3개의 이질적 과학적 대상에 걸쳐 프레임워크를 실증

방법론

핵심 구성요소 3가지 (Section 3, p.7-8) - 생성 기반모델: p_θ,α(x|C_t) — LLM 파라미터 θ와 추론 설정(프롬프팅/샘플링온도/추론절차/보정 등) α에 의존하는 제안 분포. 구조화된 사전지식(prior) 제공, 실제 공간 X를 명시적으로 열거할 필요 없이 후보 생성 - 확률적 서로게이트: 가우시안 프로세스(GP)로 보상함수 R을 모델링(p.10, Eq.6). 관측 데이터 D_t로 조건화해 예측평균 μ_t(x)와 예측분산 σ_t(x)를 산출, 이를 통해 UCB 등 획득함수 구성(Eq.7) - 모델 기반 획득함수(acquisition function): 보상 예측이 아니라 "추가 계산/실험을 이 후보에 투자할 결정적 가치"를 측정하는 스칼라. 단순 보상모델 점수와 구분되는 LDM의 핵심 참신점(p.8)

핵심 수식 (p.8-9): KL 정규화된 변분 목적함수로 탐색 정책 π_t를 정의(Eq.2) — 기대 획득값을 최대화하면서 LLM 사전분포에서 크게 벗어나지 않도록 제약. 이 문제의 닫힌형 해(Proposition 1, p.9)는 "acquisition-tilted distribution": π_t(x) ∝ p_θ,α(x|C_t)·exp(η·a_t(x)). η→0이면 순수 LLM 생성, α→0(균등분포화)이고 η가 커지면 고전적 BO로 수렴 — LDM은 그 사이의 영역을 차지

추론시점 탐색 근사 (Section 3.3, p.11-12): 정규화 상수를 계산할 수 없으므로, LLM이 유한한 후보 풀(N개)을 제안하고 획득함수로 재가중(소프트맥스 재샘플링, Eq.8) 또는 top-b 결정론적 선택(best-of-N, Eq.9)으로 근사

미세조정을 통한 정책 증류 (Section 3.4, p.12-15): 고예산 추론시점 탐색에서 축적된 (상태, 후보, 획득값) 경험을 "LDM-TTS 데이터셋"으로 기록하고, 획득값 기반 가중치로 재가중된 지도학습(Eq.11)을 통해 탐색 정책을 모델 파라미터 θ에 amortize(분할상환). 선택적으로 "추론 증강(reasoning augmentation)" — 왜 이 행동이 탐색에 유리한지 서술하는 근거(rationale) z를 함께 학습해 discovery 전용 CoT를 형성

알고리즘 (Algorithm 1/2, p.15): 매 라운드 (1) 활성 탐색영역 A_t=supp(p_θ,α) 갱신 → (2) GP 서로게이트 적합 → (3) 획득함수 구성 → (4) 획득함수 기반 정책에서 배치 B_t 샘플링 → (5) 블랙박스 평가 → (6) 데이터셋/컨텍스트 갱신(정체 시 reflection 피드백 추가)

이론적 분석 (Section 5, p.17-19): 단순 후회(simple regret)를 3가지 항으로 분해(Theorem 1, p.18-19): (1) discovery gap — 현재 reservoir 지지영역이 전역 최적점에 도달하지 못해 생기는 손실, (2) 표준 GP-UCB 최적화 오차, (3) LDM sampling shortfall — 정확한 획득함수 최대화 대신 틸트된 분포에서 샘플링해 생기는 손실. LLM은 reservoir의 커버리지(r^cov_t)와 근사-최적 질량(κ_t)을 개선함으로써 이 후회를 줄이는 역할을 함

실험 설정 및 결과

세 가지 이질적 도메인에서 평가(Section 6, p.19-33), 모두 in-silico/디지털 오라클 벤치마크 사용.

(1) AutoResearch — 신경망 학습 프로그램 자동 개선 (Karpathy 2026 기반, p.20-22) - train.py를 반복 수정하며 5분 고정 예산 학습 후 validation bits-per-byte(val_bpb, 낮을수록 좋음) 평가. 간접 파라미터화(하이퍼파라미터 탐색공간 정의) + GP(RBF 커널) + Expected Improvement 사용 - 결과(p.27, Figure 7): no-discover 베이스라인은 약 255회 실행 후 val_bpb≈0.9767에서 정체, LDM은 0.93421까지 지속 개선 — 공유 시작점(1.0069) 대비 LDM 감소폭 0.0727 vs 베이스라인 0.0301 = 2.4배 더 큰 절대 감소폭 - B200 매칭 하드웨어 리더보드 실행에서 59회 만에 val_bpb=0.902291 달성, 기존 리더보드 최고 기록(forge 0.9264, overmind 0.9274)을 능가(p.27) - 정체 후 재도약 패턴이 "discovery(탐색공간 확장)" 메커니즘 작동의 증거이며(p.21), Table 1(p.22)은 유지된 7가지 물리적 개선(n-gram 해시 메모리, QK-norm, 폭 축소, 윈도우 어텐션 등)과 각각의 val_bpb 기여도를 정리

(2) 항체 CDRH3 서열 설계 (known-unknown 영역, p.21-23) - Absolut! 시뮬레이터로 결합에너지(ΔG, 낮을수록 강한 결합) 평가, 5개 항원 타겟(1ADQ_A, 1FBI_X, 1H0D_C, 1NSN_S, 1OB1_C)에 각 200회 평가 예산 - 4가지 LDM 변형(Direct/Policy × Max/Softmax, Table 2 p.22) 비교. 대표 결과(Figure 8, p.23, 1FBI_X): 8단계의 탐색-정체-재도약 사이클을 거쳐 최종 -115.03까지 개선 - 베이스라인 비교(Figure 13, p.28, 5개 항원 평균): Pure LLM(약 -91.1), TURBO(-100.9), COMBO(-93.8), 도메인 특화 AntBO(-107.7), LDM_Policy_Max가 -110.8 등 AntBO에 필적하는 수준까지 도달(예: 1NSN_S에서는 -104.7로 AntBO -104.6을 근소하게 능가). Policy 방식이 Direct 방식보다 일관되게 우세 — 서열 공간이 sparse·rugged하여 소규모 직접 생성 배치로는 유망 후보를 못 찾기 때문

(3) 다목적 소분자 최적화 (KRAS G12D 표적, unknown-unknown 영역, p.23-24) - AutoDock Vina 도킹 점수와 신경망 결합활성 두 목표의 파레토 초부피(hypervolume)로 평가, 80회 평가 예산 - 결과(Figure 14, p.29): Pure LLM 16.826±3.085, MOBO 16.751±2.562, Random Search 13.794±3.054 대비 LDM(Direct-Softmax) 27.325±5.475로 최고 성능 — LLM-only 대비 62.4%, 전통 BO(MOBO) 대비 63.1% 초부피 개선 (초록 인용치, p.4/29) - ReaSyn-Softmax 변형(21.707±3.676)은 Direct-Softmax보다 낮음 — 국소 유사체 생성이 다양성을 제한하는 breadth-synthesizability 트레이드오프(p.29)

Ablation 연구 (Section 6.2, p.25-27) - 테스트시점 탐색 예산 확대(N4H4→N8H8)가 성능 개선에 기여, discovery 메커니즘 제거 시 더 높은(나쁜) 정체점에서 수렴, UCB/EI 같은 불확실성 인지 획득함수가 순수 사후평균(mean-only) 선택보다 일관되게 우수(Figure 11, p.25-26) - 순수 LLM 루프(η=0 극한, surrogate/acquisition 없음)는 875회 실험 후에도 val_bpb≈0.956에서 정체 — LDM의 0.93421보다 명백히 열등, "병목은 제안 표현력이 아니라 가치(value) 신호 부재"라고 해석(p.26) - 분자 설계에서 LLM 샘플링 온도와 획득 온도 η 모두 증가할수록 최종 초부피 개선(Figure 12, p.26)

미세조정(Fine-tuning) 실험 (Section 6.4, p.29-32) - AutoResearch: 추론증강 미세조정 Qwen3.5-9B가 val_bpb=0.9788로 최고(기준 모델 Qwen3-Coder-30B의 0.9801보다도 낮음), CoT 없는 미세조정 0.9829, 미세조정 없는 base+CoT 0.9825, base 무CoT 0.9965로 정체(p.30, Figure 15) - 항체 설계: 미세조정된 두 변형이 base보다 모두 개선, 추론증강 버전이 최저 결합에너지 달성(p.30, Figure 16) - 분자 설계 교차과제 전이: 추론증강 미세조정 Qwen3.5-9B 26.660±2.608로 최고, DeepSeek V4 Flash 교사 모델(24.548/23.582)보다도 우수, 미세조정 안 한 base(16.489±5.867) 대비 크게 개선(p.31, Figure 17) - OOD 일반화(p.31-32): 항원 2개(1FBI_X, 1H0D_C)를 학습에서 제외해도 out-of-distribution 모델이 in-distribution 모델과 동등 이상 성능(Figure 18); 항체 태스크 전체를 학습에서 제외(nanoGPT+분자 궤적만 학습)해도 5개 항원 중 4개에서 in-distribution 모델에 필적(Figure 19) — 유일한 예외 1H0D_C는 "de novo 모티프 설계가 필요한 좁은 최적점"이라 도메인 지식이 필요하다고 분석(p.32)

한계점 (저자 명시, §6.5 및 §8, p.34/37-38)

  • 정확한 가우시안 프로세스는 관측 수에 대해 3차(cubic) 계산 복잡도를 가져 대규모 실험 예산으로의 확장성이 제한됨
  • 테스트시점 탐색이 배치 후보 샘플링에 의존해 LLM 추론 오버헤드가 상당함
  • 서로게이트의 커널 함수·특징 표현이 도메인별로 수동 커스터마이징이 필요해, 범도메인 자동화가 부족함
  • 프레임워크 성능이 LLM의 사전학습 도메인 지식 범위에 의해 제한됨 — 사전지식이 약한 도메인(예: 항체 설계에서 오픈소스 LLM)에서는 특화 방법(AntBO) 대비 뚜렷한 우위를 보이기 어려움
  • 현재 폐루프는 오직 진행 중인 실험 관측에만 기반해 갱신되며, 기존 외부 지식·데이터(unknown knowns)를 아직 체계적으로 통합하지 않음 — 메모리 검색/연합 발견(federated discovery)은 향후 과제로 남김
  • 모든 실험이 in-silico/디지털 오라클 기반이며, 저자 스스로 실제 습식실험(wet-lab) 검증은 향후 방향이라고 명시(p.19)
  • 논문 자체가 "v0.1 초기 릴리스"로 명명되어 있어 저자들도 완성된 시스템이 아님을 인정

시사점

  • "발견(discovery)"을 단순 미평가 후보 탐색(exploration)과 구분하여, "탐색이 표현/도달 가능한 범위 자체를 확장하는 것"으로 개념화한 프레임(Section 2, Figure 3)은, LLM 에이전트가 정체(plateau)에 빠졌을 때 파라미터/표현공간 자체를 재구성하도록 유도하는 실무적 설계 원칙으로 일반화할 수 있음(자기 회고를 통한 탐색공간 재정의)
  • "획득함수(acquisition value)"를 보상모델 점수와 분리해, 계산/실험 자원 배분의 결정 가치로 활용하는 방식은, 비용이 큰 평가(예: 실제 API 호출, 물리 실험, 장시간 학습)를 다루는 임의의 에이전틱 시스템에 확장 가능한 아이디어임
  • 미세조정 실험에서 나타난 "distilled acquisition policy가 태스크 수준 OOD로 일반화된다"는 결과는, 도메인 특화 데이터가 아니라 "탐색 전략 자체"를 학습시키는 것이 전이 가능한 일반 역량을 만든다는 시사점을 제공 — 다른 도메인의 에이전트 사전학습/미세조정 설계에도 참고할 만함
  • 다만 GP 서로게이트의 3차 복잡도, 도메인별 커널 수작업, 순수 in-silico 검증이라는 한계는 실제 대규모/실세계 적용 전에 추가 검증이 필요함을 시사
