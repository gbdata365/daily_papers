WeVisOne-VL: Unified Visual Perception from Objects to Pixels

위비즈원-VL: 객체부터 픽셀까지 통합하는 시각 인지 모델

Tencent WeChat Vision이 공개한 WeVisOne-VL은 객체 탐지·개수 세기·OCR 같은 "객체 수준" 과제와 분할·매팅 같은 "픽셀 수준" 과제를 하나의 비전-언어 모델(VLM)과 경량 픽셀 디코더로 통합해, 구조화된 다음 토큰 예측만으로 박스부터 알파 매트까지 모두 생성하는 범용 시각 인지 모델이다.

한 줄 요약

Tencent WeChat Vision이 공개한 WeVisOne-VL은 객체 탐지·개수 세기·OCR 같은 "객체 수준" 과제와 분할·매팅 같은 "픽셀 수준" 과제를 하나의 비전-언어 모델(VLM)과 경량 픽셀 디코더로 통합해, 구조화된 다음 토큰 예측만으로 박스부터 알파 매트까지 모두 생성하는 범용 시각 인지 모델이다.

배경 및 문제의식

기존 VLM들은 자연어 지시를 폭넓게 따를 수 있지만 세밀한 시각 인지(fine-grained visual perception)에는 여전히 신뢰성이 떨어진다. 저자들은 현재 모델들이 ① 존재하지 않는 객체를 환각하거나, ② 익숙하지 않은 객체 표현을 만났을 때 사용자 의도를 오해하거나, ③ 두드러지지 않는(non-salient) 인스턴스를 누락해 재현율이 떨어지는 세 가지 고질적 문제를 겪는다고 지적한다. 또한 YOLO·DETR 같은 전통적 탐지/분할 모델, Grounding-DINO·SAM 같은 오픈월드 인지 모델들은 각자 특정 과제에 특화되어 있어, 객체 단위 인지(박스·카운팅·OCR 등)와 픽셀 단위 인지(분할·매팅)를 하나의 자연어 인터페이스로 동시에 다루는 신뢰성 높은 통합 모델이 부재했다는 점을 문제의식으로 삼는다.

핵심 기여

  1. 통합 데이터 엔진(WeVisOne-VL Data Engine, WDE): 지식 그래프를 바탕으로 카테고리 개념과 지시적(referring) 표현을 조직화하고, 탐지→분할→매팅까지 인스턴스 정체성을 유지한 채 약 1억 장 이미지·36억 개 바운딩박스 수준의 대규모 주석을 구축하는 파이프라인.
  2. 통합 모델 설계: Qwen3-VL을 백본으로, 좌표를 <0>~<1000> 토큰으로 양자화해 박스/포인트를 시퀀스로 생성하고, 각 예측 박스 뒤에 특수 <OBJ> 토큰을 붙여 그 은닉 상태를 경량 픽셀 디코더에 넘겨 마스크·알파 매트까지 생성하는 구조(약 9.6M 파라미터의 디코더로 대형 세그멘테이션 모델 불필요).
  3. 3단계 커리큘럼 SFT + 혼합 과제 강화학습(RL): 과제 정렬 → 고해상도/고밀도 인지 → 토큰-픽셀 교대 학습의 지도 미세조정 이후, 불확실성 기반 샘플 선택과 IoU 기반 "그라운딩 보상"을 사용하는 GRPO 강화학습을 추가 적용.
  4. 2B/4B 두 가지 규모로 모델을 오픈소스 공개하고, 30개 이상 벤치마크에서 객체/픽셀 수준 양쪽 모두 최고 수준 성능과 부재 객체에 대한 견고한 거부(rejection) 능력을 입증.

방법론

  • 과제 정식화: 탐지, 지시 지역화(referring), 카운팅, 포인팅, OCR, 분할, 매팅 등 모든 시각 과제를 "구조화된 다음 토큰 예측"으로 통일한다. 좌표는 전용 토큰(<0>~<1000>)으로 정규화해 표현하며, 박스는 [x0,y0,x1,y1], 포인트는 [x0,y0] 형태로 생성한다. 대상이 이미지에 없으면 좌표 자리에 None을 출력해 거부를 표현한다.
  • 모델 구조: (1) 비전 인코더의 다층 특징을 받아 정렬하는 시각 특징 어댑터, (2) Deformable DETR 스타일의 "박스-가이드 쿼리 디코더"—각 <OBJ> 토큰의 은닉 상태를 콘텐츠 쿼리로, 예측 박스를 위치 쿼리로 사용, (3) 멀티레벨 픽셀 융합과 동적 마스크 헤드로 전체 해상도 마스크를 생성하고, coarse-to-fine 방식으로 3단계에 걸쳐 경계를 정교화하는 인스턴스 조건부 밀집 예측 모듈로 구성된다.
  • 데이터 엔진(WDE): 지식 그래프 기반으로 카테고리/지시 표현을 발굴하고(semantic discovery), SAM3와 자체 개방어휘 탐지기의 후보를 Qwen3-VL로 검증해 박스 주석을 만든 뒤 SAM2로 가시 영역 마스크를 생성한다. 매팅을 위해서는 BiRefNet·MatAnyone2 등 전문가 모델의 결과를 교차 검증해 알파 레이블을 만들고, SAM2.1 기반의 경량 알파 정제 헤드를 가진 전담 매팅 주석기를 학습시켜 전체 코퍼스에 알파 의사 레이블(pseudo-label)을 재주석한다. 학습 라운드마다 모델 오류를 분석해 데이터 수집·주석을 지속적으로 피드백·개선한다.
  • 학습 파이프라인: Stage1(과제 정렬, 비전 인코더 동결), Stage2(해상도·밀도 확장, 비전 인코더 해제), Stage3(세그멘테이션 워밍업 후 토큰-픽셀 교대 학습, 포컬+Dice 손실)로 구성된 SFT 이후, 매팅 전용 미세조정(L1·그래디언트·라플라시안 손실)을 거친다. 이어서 불확실성 점수(U(x)=4μ(1-μ)σ)로 어려운 샘플을 선별해 GRPO 기반 RL을 수행하며, 예측·정답 박스 간 매칭된 IoU³ 평균으로 정의된 그라운딩 보상을 사용한다.

실험 설정 및 결과

  • 2B/4B 두 스케일로 학습했으며, COCO·LVIS·Dense200·VisDrone(탐지), RefCOCOg·WeRef-Bench·PR-Bench 등(지시 지역화), CountQA·PixMo-Count·CLOC·KubriCount·MixCount(카운팅), PointBench·PixMo-Points(포인팅), HierText·ICDAR2015·TotalText·SROIE(OCR), RefCOCO 계열·ReasonSeg·Ref-ZOM(지시 분할), P3M-500-NP·AM-2K·PPM-100·자체 WeRefMat(매팅) 등 30개 이상 벤치마크로 평가했다.
  • Qwen3-VL/Qwen3.5, Rex-Omni, LocateAnything 등과 비교해 전 영역에서 동급 모델 대비 최고 성능을 기록했다. 예를 들어 Dense200/VisDrone 같은 밀집·소형 객체 탐지에서 특히 큰 격차를 보였고, 카운팅에서는 PixMo-Count val/test 93.7%/89.6%의 정확한 일치율(exact-match)을, 지시 분할(RefCOCO val)에서 84.5 cIoU를 달성했다. OCR, 포인팅 벤치마크에서도 특화 모델(PP-OCRv5, GroundingDINO 등)과 기존 VLM 기반 그라운딩 모델을 능가했다.
  • 박스/텍스트 프롬프트 기반 매팅에서도 전문 매팅 모델(SAM2-Matting, Matte Anything) 대비 MAD·MSE·SAD 등 다수 지표에서 우위를 보였으며, 특히 WeRefMat(자체 벤치마크)에서 언어 조건부 타깃 선택과 경계 민감 투명도 추정을 단일 모델 안에서 효과적으로 처리함을 보였다.
  • 정성적 비교(Figure 5~13)에서 혼잡 장면의 개별 인스턴스 구분, 다중 객체를 포함한 복잡한 지시 표현 처리, 대상이 없을 때의 정확한 거부(absent-target rejection) 등을 베이스라인 대비 우수하게 수행함을 보여준다.

한계점

  • 범용 학습 데이터 비중이 상대적으로 적어, 기반 모델(Qwen3-VL) 대비 일반적인 대화·추론 능력이 저하될 수 있다.
  • 추론 효율성을 위해 사고 과정(chain-of-thought) 없이 구조화된 출력을 바로 생성하도록 학습해, 복잡한 추론이 필요한 과제에서는 한계가 있을 수 있다.
  • 현재 접근은 단일 턴(single-turn) 예측에 국한되며, 에이전트 프레임워크와 결합한 다중 턴 상호작용을 통한 점진적 개선은 향후 과제로 남아 있다.
  • 벤치마크의 질의는 명확하고 잘 구성된 반면, 실제 사용자 지시는 모호하거나 주저하는 표현이 많아 실제 환경에서는 강력한 의도 추론(intent reasoning)이 더 중요할 수 있다는 점을 저자들도 인정한다.

시사점

객체 수준(박스·카운트·OCR)과 픽셀 수준(분할·매팅) 인지를 하나의 자연어 인터페이스와 단일 모델로 묶어내고, 대형 세그멘테이션 모델(SAM 등) 없이도 경량 디코더만으로 경쟁력 있는 분할·매팅 성능을 낼 수 있음을 보여준다. 데이터 엔진을 통한 지속적 오류 피드백-재주석 루프와 불확실성 기반 RL 샘플링 전략은 향후 "탐지/분할/매팅을 분리된 전문가 모델로 조합하는 방식"에서 "하나의 언어 기반 모델이 임의 세분화 수준(점·박스부터 마스크·알파 매트까지)을 직접 생성하는 방식"으로 비전 시스템 설계가 이동할 가능성을 시사한다.
