Editing Images into Reusable Layers via Compositional Edit-Prior Distillation

합성적 편집-사전 증류를 통해 이미지를 재사용 가능한 레이어로 편집하기

명령어 기반 이미지 편집과 재사용 가능한 RGBA 레이어 생성을 하나의 모델로 통합하여, 편집 품질을 유지하면서도 바로 재활용 가능한 레이어 구조를 동시에 출력하는 LayerEditor를 제안한다.

한 줄 요약

명령어 기반 이미지 편집과 재사용 가능한 RGBA 레이어 생성을 하나의 모델로 통합하여, 편집 품질을 유지하면서도 바로 재활용 가능한 레이어 구조를 동시에 출력하는 LayerEditor를 제안한다.

배경 및 문제의식

기존 명령어 기반 이미지 편집 모델(Qwen-Image, FireRed-Image-Edit 등)은 텍스트·객체·배경이 하나로 합쳐진(flattened) 단일 캔버스를 생성한다. 이런 출력은 세부 요소만 다시 고치거나 사용자가 제공한 소재를 끼워 넣는 작업(전자상거래 상품 이미지, 광고 디자인 등)에는 적합하지 않아, 수정할 때마다 전체를 다시 생성해야 하고 의도치 않은 영역 변형이나 경계 아티팩트가 발생하기 쉽다. 이를 보완하기 위한 이미지 분해(decomposition) 기법들이 존재하지만, 편집과 분해가 서로 다른 목표로 별도 단계에서 최적화되기 때문에 시각적으로는 그럴듯해도 레이어 구조가 불완전하거나 재사용하기 어려운 경우가 많다. 즉, "편집"과 "레이어 복원"을 동시에 고려하는 통합 프레임워크가 필요하다는 것이 이 논문의 출발점이다.

핵심 기여

  • LayerEditor: 명령어 기반 편집과 재사용 가능한 순서 있는 RGBA 레이어 생성을 하나의 모델로 결합한 통합 프레임워크로, 가변 레이어 개수와 사용자가 지정한 레이어별 내용(텍스트 줄, 객체 등)을 동시에 지원한다.
  • In-Context RGB–Alpha Token Modeling: 편집된 최종 캔버스와 순서가 있는 RGB–Alpha 레이어 스택을 하나의 토큰 시퀀스 안에서 공동으로 표현하는 방법.
  • Compositional Edit-Prior Distillation (C-EPD): 사전학습된 편집 모델이 가진 "편집 능력(prior)"을 레이어 출력으로 전이시켜, 레이어화 적응 과정에서 편집 품질이 떨어지는 문제를 완화하는 온폴리시(on-policy) 증류 기법.
  • LayerEditor-100K 데이터셋과 Crello-Testset / ScaleEdit-Testset 두 벤치마크를 새로 구축해, 순서가 있는 RGBA 레이어 주석이 달린 대규모 학습·평가 자원을 제공.

방법론

LayerEditor는 소스 이미지, 편집 명령어, 요청 레이어 개수를 입력받아 편집된 캔버스 D와 N개의 RGBA 레이어 스택 S(배경→전경 순서)를 동시에 출력한다. 모델 구조는 사전학습된 편집용 MMDiT(FireRed-Image-Edit-1.1)를 LoRA(rank-256)로 확장한 것으로, 캔버스 토큰과 각 레이어의 RGB·Alpha 토큰을 하나의 시퀀스에 배치하고, 레이어 식별과 쌓임 순서를 나타내는 별도의 "슬롯" 좌표를 로터리 위치 인코딩에 추가해 레이어 수가 달라져도 같은 구조로 처리할 수 있게 했다. 또한 사전학습된 RGB 디코더와 분리된 전용 Alpha 디코더를 두어 세밀한 경계나 반투명 영역의 불투명도를 더 정확히 복원한다.

레이어화에 맞춰 모델을 미세조정하면 원래의 편집 능력이 저하되는 현상(텍스트 손상, 구조 왜곡 등)이 관찰되었는데, 이를 막기 위해 C-EPD를 도입했다. C-EPD는 학생 모델(student)의 디노이징 경로 중간 상태를 그대로 사용해, 동결된 원본 편집 모델(teacher)에게 같은 상태에서의 결과를 묻고, (1) 학생의 "직접 캔버스" 속도 벡터를 교사의 것과 맞추는 항과 (2) 학생이 예측한 레이어들을 합성(compose)한 이미지를 교사가 디코딩한 타깃 이미지와 픽셀 단위로 맞추는 항을 함께 학습시킨다. 학습은 먼저 2 에포크 동안 순수 flow-matching으로 워밍업한 뒤, C-EPD 손실을 추가로 결합하는 2단계로 진행된다. 추론 시에는 교사 모델 호출 없이 한 번의 디노이징 경로로 캔버스와 레이어 스택을 동시에 생성한다.

LayerEditor-100K는 Crello, PrismLayersPro(네이티브 레이어 디자인)와 ScaleEdit(원래는 레이어가 없는 평면 편집쌍)으로부터 두 가지 경로로 구축한 10만 건의 학습 데이터로, 소스 이미지·편집 명령·편집 결과·순서 있는 RGBA 레이어 스택(2~10개 레이어)이 짝지어져 있으며 텍스트/객체/포스터 수준 외형 편집을 포괄한다.

실험 설정 및 결과

평가는 Crello-Testset(2,994건)과 ScaleEdit-Testset(1,000건) 두 벤치마크에서 이루어졌으며, Direct/Composite SSIM·FID, RGBA L1, Alpha IoU 같은 참조 기반 지표와 VLM(Gemini) 기반 5개 항목 루브릭 평가(편집 일관성, 시각 품질, 레이어 분할, 레이어 합성, Alpha 정확도)를 함께 사용했다. 비교 대상은 Seedream5-Pro(순차/통합 API), FireRed-Image-Edit과 Qwen-Image-Layered 등을 조합한 캐스케이드 베이스라인, 그리고 LayerEditor-100K로 미세조정한 QIL 계열 등이다.

LayerEditor는 두 벤치마크 모두에서 Composite SSIM/FID와 Alpha IoU 기준 최고 성능을 보였다. 예를 들어 Crello-Testset에서 Seedream5-Pro(Joint) 대비 Composite SSIM을 5.7% 향상, Composite FID를 38.8% 감소시켰으며, ScaleEdit-Testset에서도 Composite SSIM 0.8365→0.8839, Alpha IoU 0.6583→0.6802로 개선되었다. 직접 캔버스 대비 합성 이미지의 품질 저하 폭(타깃 유사도 감소율)도 LayerEditor가 가장 작아(약 1.0%), 레이어화로 인한 품질 손실이 가장 적었다. 레이어 개수를 다르게 요청하는 "레이어 구조 제어" 실험과 특정 콘텐츠를 특정 레이어에 배치하도록 요청하는 "콘텐츠 제어" 실험에서도 가장 높은 Alpha IoU와 루브릭 점수를 기록했다. 순수 이미지-레이어 분해(I2L) 과제에서도 전용 미세조정 없이 QIL 등 기존 분해 모델을 능가했다. 어블레이션 결과, C-EPD의 두 항(직접 속도 매칭, 합성 이미지 픽셀 매칭)을 모두 사용할 때만 편집 일관성과 레이어 분할 품질이 동시에 개선되었고, 전용 Alpha 디코더 역시 레이어 복원 오차(RGBA L1)를 크게 낮추는 데 기여했다.

한계점

논문에 별도의 "한계점" 절은 없으나 본문 및 실험 설계에서 다음과 같은 제약이 드러난다. (1) 모델이 사전학습된 편집 모델(FireRed-Image-Edit-1.1)의 LoRA 적응에 기반하므로 그 원본 모델의 편집 능력 범위를 벗어나기 어렵다. (2) ScaleEdit 기반 학습/평가 데이터의 일부는 플래너와 기존 분해 모델(QIL, Seedream5-Pro)로 생성한 뒤 반복 보정·검증한 레이어이므로 완전히 사람이 만든 정답은 아니다. (3) RGBA L1 지표는 완전 투명 영역의 RGB 값 차이에 민감해 시각적으로 동일한 레이어도 다르게 평가될 수 있다. (4) 레이어 개수는 최대 10개로 제한된 설정에서만 검증되었다. (5) 정량 평가의 상당 부분이 VLM(Gemini) 기반 루브릭 점수에 의존하며, 이는 사람 평가와의 일치도를 별도로 검증한 것은 아니다.

시사점

편집과 레이어 복원을 별도 단계로 처리하던 기존 워크플로를 하나의 모델로 통합함으로써, 전자상거래·광고 디자인처럼 반복적인 국소 수정이 필요한 실무 환경에서 재생성 횟수와 수작업 보정을 크게 줄일 수 있는 가능성을 보여준다. 또한 "사전학습된 생성 능력을 유지하면서 새로운 출력 구조(레이어)로 확장"하는 On-Policy Distillation 기반 접근(C-EPD)은 diffusion/flow 기반 생성 모델을 레이어, 멀티뷰, 다중 해상도 등 구조화된 출력으로 확장할 때 일반적으로 적용 가능한 설계 패턴으로 볼 수 있다.
