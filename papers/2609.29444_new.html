IterSynth: Rethinking Deep Search Agents via Role-Decoupled Iterative Synthesis

이터신스: 역할 분리 반복 합성을 통한 딥서치 에이전트 재고찰

한 줄 요약

계획 수립과 근거 통합 역할을 하나의 정책이 모두 떠맡아 발생하는 문제를 해결하기 위해, 계획자(Planner)와 종합자(Synthesizer) 역할을 분리하고 요약 상태를 지속 유지하는 새로운 딥서치 에이전트 패러다임.

배경 및 문제의식

딥서치는 LLM 에이전트가 복잡한 질의를 분해하고 근거를 검색해 답을 종합하는 과업이지만, 기존 ReAct 스타일 에이전트는 두 가지 한계를 갖는다. 첫째는 "역할 결합(role coupling)"으로, 계획·근거 활용·종합을 하나의 정책이 모두 담당해야 한다는 점이고, 둘째는 "맥락 누적(context accumulation)"으로, 검색 이력이 길어질수록 잡음이 늘고 유용한 정보가 묻힌다는 점이다. 실제로 저자들은 64K 토큰 컨텍스트에서도 ReAct 궤적의 59% 이상이 BrowseComp에서 컨텍스트 소진 전에 종료하지 못한다는 것을 관찰했다.

핵심 기여

  1. 계획자와 종합자 역할을 분리하고 진화하는 요약 상태를 검색의 지속 상태로 사용하는 역할분리·요약기반 패러다임 IterSynth 제안.
  2. 결과 보상과 턴 단위 루브릭 평가를 결합하고 역할별 어드밴티지를 계산하는 역할분리 정책 최적화(RDPO) 기법 제안.
  3. IterSynth-8B가 BrowseComp, Xbench-DS 등 다섯 개 장기 호라이즌 딥서치 벤치마크에서 우수한 성능을 보임을 실증.
  4. 별도 학습 없이 모델에 상관없이 적용 가능한 프롬프팅 기법으로도 ReAct 대비 큰 성능 향상을 보임.

방법론

IterSynth는 하나의 공유된 LLM 정책 안에서 계획자와 종합자 역할을 번갈아 수행한다. 계획자는 정보 필요를 파악해 검색을 이끌고, 종합자는 새로 얻은 근거를 진화하는 요약 상태에 통합한다. 이 요약 상태가 검색의 지속적인 "기억" 역할을 하기 때문에 원본 검색 이력을 그대로 누적할 필요가 없어 맥락 잡음이 줄어든다. RDPO는 최종 결과에 대한 보상뿐 아니라 각 턴에 대한 루브릭 기반 평가를 결합하고, 계획자와 종합자 각각에 대해 역할별 어드밴티지를 계산해 더 정밀한 신용 할당(credit assignment)을 수행한다.

실험 설정 및 결과

BrowseComp, Xbench-DS를 포함한 다섯 개 장기 호라이즌 딥서치 벤치마크에서 IterSynth-8B는 평균 50.7점을 기록해, 8B 이하 규모에서 가장 강력했던 기존 에이전트보다 4.2%포인트 앞섰다. 또한 IterSynth는 모델에 무관하게 적용 가능한 프롬프팅 방식으로도 프론티어 상용 모델에서 ReAct 및 유사 프롬프팅 방식 대비 상당한 제로샷 성능 향상을 보였다.

한계점

논문에 명시되지 않음.

시사점

에이전트의 여러 능력(계획, 근거 활용, 종합)을 하나의 정책에 억지로 몰아넣기보다 역할을 명확히 분리하고, 역할별로 학습 신호를 정교하게 설계하는 것이 장기 호라이즌 에이전트의 신뢰성과 효율성을 동시에 높이는 유효한 전략임을 보여준다.
