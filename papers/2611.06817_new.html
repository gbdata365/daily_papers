Open-HumanScale: An Open Recipe for Scaling Human and Robot Experience for Embodied Foundation Models

Open-HumanScale: 체화 파운데이션 모델을 위한 인간·로봇 경험 확장 공개 레시피

한 줄 요약

5만 시간 규모의 1인칭(에고센트릭) 인간 조작 영상만으로 사전학습한 월드-액션 모델이 로봇 후속학습(post-training) 뒤 강력한 분포 외(out-of-distribution) 일반화 성능을 보이고, 사전학습 시간에 따라 로그-선형(log-linear) 스케일링 법칙을 따른다는 것을 실증했으며, 더 나아가 인간-로봇 하이브리드 데이터와 시각적 목표(goal-image) 조건화를 결합해 제로샷 로봇 실행과 파라미터 업데이트 없는 "체화된 인컨텍스트 러닝"을 구현한, 데이터·코드·체크포인트를 모두 공개한 로봇 파운데이션 모델 레시피 연구이다.

배경 및 문제의식

로봇 파운데이션 모델은 과업과 환경을 넘나드는 전이 가능한 조작 능력을 얻기 위해 다양한 조작 경험이 필요하지만, 원격조작(teleoperation)으로 로봇 데이터를 수집하는 것은 비용이 매우 크다. 반면 손동작·언어 주석이 달린 1인칭(에고센트릭) 인간 비디오는 다양한 장면·과업에 걸친 풍부한 인간-물체 상호작용 기록을 저비용으로 제공할 수 있다. 그러나 이러한 인간 데이터를 단순히 규모만 늘렸을 때 실제로 다운스트림 로봇 성능이 일관되게 개선되는 큐레이션·정렬·학습 레시피는 아직 충분히 검증되지 않았다. EgoScale, Being-H0.8, HumanScale, Dyna-2 등 선행 연구들이 에고센트릭 사전학습의 가치를 보였지만, 데이터 다양성의 역할이나 로봇 쪽 supervision이 얼마나 필요한지에 대한 체계적 분석은 부족했다. 이 논문은 이러한 공백을 메우기 위해 100시간~5만 시간 규모로 통제된 스케일링 실험을 수행하는 "완전 공개형(open)" 레시피를 제시한다.

핵심 기여

  • Open-HumanWAM-50K 코퍼스 공개: HumanNet, EgoSuite-Open100K, EgoDex, Gen-HumanEgo, EgoVerse의 5개 공개 소스를 손동작 시각성(hand visibility), 동작/카메라 안정성, 유휴(idle) 구간 필터링으로 큐레이션하여 구축한 5만 시간·3,590만 클립 규모의 코퍼스와, 서로 다른 소스 간 카메라 프레임·손목 축·그리퍼 개방도를 정렬한 통합 양손(bimanual) end-effector 액션 표현을 공개.
  • 순수 에고센트릭 사전학습의 로그-선형 스케일링 법칙 규명: 100시간부터 5만 시간까지 사전학습 데이터를 늘릴 때 다운스트림 로봇 성공률이 SR = a + b·log10(H) 형태로 일관되게 증가함을 isolated attention과 IDM(inverse-dynamics) attention 두 구조 모두에서 확인(R²=0.87~0.97). 또한 데이터 다양성(과업·장면 커버리지) 확장이 단순히 시간만 늘리는 것보다 더 가파른 스케일링 곡선을 만든다는 것, cross-source action alignment와 인간 동작 예측(human motion prediction) supervision이 성능에 기여한다는 것을 7개 연구 질문(Q1~Q7)에 대한 통제 실험으로 체계적으로 분석.
  • HumanWAM-Vanilla 모델: 5만 시간 에고센트릭 데이터만으로 사전학습한 world-action 모델로, 로봇 후속학습 후 RoboTwin 2.0 Clean2Clean 92.08%·Clean2Random 68.88%, RoboDojo 평균 성공률 14.17%·진행도 점수 19.00을 달성. 실로봇 4과업에서 평균 성공률이 분포 내(ID) 57.5%→87.5%, 분포 외(OOD) 2.5%→67.5%로 개선.
  • HumanWAM-Goal 모델(인간-로봇 하이브리드 + 시각적 목표 조건화): 약 1.46만 시간의 로봇 사전학습 데이터에 최대 4.59만 시간의 인간 에고센트릭 데이터를 더한 하이브리드 코트레이닝 모델로, 제로샷 평균 성공률 13.94%(RoboTwin 2.0), 후속학습 후 Clean2Clean 92.70%·Clean2Random 84.60%(평균 88.65%, SOTA)를 달성. 실로봇 20개 과업 제로샷 성공률도 인간데이터 추가에 따라 20.0%→30.5%로 상승하며, 파라미터 업데이트 없이 시각 목표 이미지만 바꿔 다른 조작 결과를 유도하는 "체화된 인컨텍스트 러닝(embodied in-context learning)"을 보임.
  • 전체 스택 오픈소스 공개: 코퍼스, 데이터 큐레이션·사전학습 파이프라인, 사전학습/후속학습 체크포인트, 추론 코드, 시뮬레이션 평가 스위트를 모두 공개하여 재현 가능한 스케일링 연구를 지원.

방법론

데이터 구축 및 통합 액션 표현. 5개 공개 에고센트릭 데이터셋(HumanNet 서브셋, EgoSuite-Open100K, EgoDex, Gen-HumanEgo, EgoVerse)을 모아 손동작 시각성, 동작/카메라 안정성(가속도·저크 체크), 유휴 구간(32프레임 슬라이딩 윈도우) 필터링의 3단계 큐레이션을 거쳐 3,139만 개 에피소드에서 3,590만 개의 연속 클립, 총 5만 시간을 확보했다. 서로 다른 소스의 손목 포즈·카메라 좌표·그리퍼 개방도를 통일하기 위해, 카메라 프레임 변환, 정준(canonical) 손목 축으로의 회전 정렬(Procrustes 정렬), 엄지-인덱스 핑거팁 거리를 이용한 그리퍼 개방도 정규화를 적용하여 16차원(좌/우 각각 위치3+쿼터니언4+개방도1) 통합 양손 EEF 액션 공간을 구성했다.

모델 아키텍처. Wan2.2-TI2V-5B 비디오 백본을 확장한 Mixture-of-Transformers 구조로, 비디오 전문가(video expert)와 액션 전문가(action expert)가 조건부 교차 어텐션과 공동 마스킹 self-attention으로 상호작용한다. 액션 토큰이 현재 프레임만 볼 수 있는 isolated attention, 서로 모든 토큰을 참조하는 mutual attention, 미래 비디오를 먼저 생성한 뒤 액션을 예측하는 inverse-dynamics(IDM) attention, 두 방식을 확률적으로 섞는 optional-IDM을 비교했으며, IDM 방식과 절대 카메라 프레임 액션 표현의 조합이 가장 우수한 일반화 성능을 보였다.

사전학습·후속학습 프로토콜. 코퍼스 규모(100~50,000시간)에 따라 글로벌 배치 크기와 학습 스텝을 조정한 AdamW 코사인 스케줄로 사전학습한 뒤, RoboTwin 2.0(50개 양손 조작 과업, Aloha-AgileX 임보디먼트)에서 과업당 50개의 깨끗한(clean) 시연으로 후속학습하고, clean/scene-ood/random 세 조건에서 성공률을 측정해 스케일링 법칙을 피팅했다.

HumanWAM-Goal의 하이브리드 확장. 다중 임보디먼트와 모바일 조작을 아우르기 위해 액션 공간을 49차원(관절 23 + 섀시 3 + EEF·헤드 23)으로 확장하고, 그리퍼 개방도를 미터 단위 절대 물리량으로, EEF 위치·자세를 현재 관측 기준의 청크 상대(chunk-relative) 좌표로 표현하여 임보디먼트에 무관한 전이가 가능하도록 설계했다. Cosmos3-Nano-16B를 백본으로 사용하며(언어 인코딩을 담당하는 고정된 Qwen3-VL 기반 Reasoner + 공유 비디오-액션 Generator), 언어 지시와 함께 시각적 목표 이미지를 조건으로 입력받아 미래 비디오와 액션 청크를 UniPC 기반 joint rectified-flow로 한 번에(단일 단계) 디노이즈한다. 목표 이미지는 궤적 내 미래 관측(2~8초 후 40%, 에피소드 종료 프레임 20%, 서브태스크 종료 프레임 20%, 목표 없음 20%)에서 온라인 샘플링되며, 후속학습 시에는 일부를 GPT Image 2.5로 합성하고 ChatGPT Astra High로 시각적·지시적 일치성을 자동 검증했다. 로봇 사전학습 데이터는 8개 실로봇 도메인에서 110만 개 이상의 에피소드, 약 1.46만 시간 규모로 구성됐다.

실험 설정 및 결과

  • 순수 에고센트릭 스케일링(RoboTwin 2.0, 50 tasks): isolated attention 기준 100→10,000시간으로 늘릴 때 clean 성공률 71.2%→80.0%, scene-ood 25.2%→58.1%, random 8.4%→28.7%로 증가(로그-선형 피팅 R²=0.88~0.97). IDM attention 기준 100→50,000시간에서는 clean이 87~89%로 포화되지만 scene-ood는 49.1%→73.2%, random은 21.5%→42.9%로 계속 개선.
  • 데이터 다양성 vs 시간: EgoSuite-Open100K에서 과업·장면 커버리지를 함께 늘린 scaled-diversity 코퍼스가 동일 시간의 matched-diversity 코퍼스보다 scene-ood·random에서 각각 +4.73, +4.50의 스케일링 기울기 증가를 보임.
  • 로봇 적응 샘플 효율성: 5,000시간 사전학습 모델은 25개 시연만으로 500시간 모델이 50개 시연으로 달성한 성능(scene-ood 42.0% vs 37.9%, random 21.8% vs 16.2%)을 상회.
  • cross-source action alignment / human motion supervision 효과: 정렬된(Aligned) 액션 표현이 정렬 안 된(Raw) 표현보다 clean +5.5pp, scene-ood +9.0pp, random +8.4pp 개선. 인간 동작 예측을 50% 포함하면 video-only 대비 scene-ood 13.0%→34.8%, random 3.6%→16.3%로 크게 개선.
  • 에고센트릭 vs 로봇 사전학습: 500~5,000시간 구간에서 동일 시간의 에고센트릭 사전학습이 로봇 사전학습보다 모든 조건(clean/scene-ood/random)에서 우수(5,000시간 기준 scene-ood 52.3% vs 45.6%, random 27.6% vs 22.4%).
  • HumanWAM-Vanilla 최종 성능: RoboTwin 2.0 Clean2Clean 92.08%·Clean2Random 68.88%(평균 80.48%, Table 7 기준 VLA 베이스라인 전부 상회, 일부 최신 WAM보다 OOD에서 다소 낮음). RoboDojo 평균 SR 14.17%/진행도 19.00(Table 8). 실로봇 4과업(종이컵 쌓기, 수건 접기, 서랍 정리, 책상 정리)에서 테이블보/조명 변화 조건까지 포함해 평균 성공률 ID 57.5%→87.5%, OOD 2.5%→67.5%로 개선(Table 9).
  • HumanWAM-Goal 제로샷/후속학습 성능: 제로샷 평균 성공률이 로봇 전용 11.48%→하이브리드(인간 4.59만 시간 추가) 13.94%로 상승, 단일 체크포인트 과업 커버리지(≥2% 성공)도 18→22개 과업으로 확대(Table 13, Figure 17). 후속학습 후 RoboTwin 2.0 Clean2Clean 92.70%·Clean2Random 84.60%(평균 88.65%)로 SOTA 달성(Table 14). 실로봇 20개 과업 제로샷 성공률은 로봇데이터 고정(1.46만 시간) 상태에서 인간데이터를 +1.59만/+4.59만 시간 추가함에 따라 20.0%→26.0%→30.5%로 상승.
  • 어블레이션: IDM attention + 절대 카메라프레임 액션 조합이 isolated attention + 상대 액션보다 모든 조건에서 우수(Table 10). 액션 전문가를 사전학습된 비디오 가중치에서 초기화하는 것은 랜덤 초기화보다 이득이 없었음(Table 11). 로봇 후속학습에 손목 카메라 뷰를 직접 추가하면 scene-ood/random 일반화가 오히려 저하되지만, EgoPro를 이용한 멀티뷰 중간학습(mid-training)을 거치면 이 손실을 완화할 수 있었음(Table 5).

한계점

  • 논문에서 직접 언급: HumanWAM-Vanilla는 기본적인 world-action 아키텍처만 사용하고 별도의 특화 모듈이 없어, RoboTwin 2.0 Clean2Random에서 GO-3 Nano Preview(81.48%) 등 특화 모듈을 갖춘 최신 WAM보다 다소 낮은 68.88%를 기록(남은 격차는 이러한 아키텍처 차이에서 기인한다고 추정).
  • RoboDojo의 메모리·산술 추론이 필요한 과업에서는 전용 memory/reasoning 모듈이 없어 DM0.5, Galaxea G0.5 등 최신 모델/에이전트 시스템에 비해 전체적으로 뒤처짐.
  • 순수 인간 데이터만으로는 로봇의 물리적 형태·제어 동역학에 노출되지 않는 임보디먼트 갭(embodiment gap)이 존재하여, 바로 배포할 수 없고 매 목표 과업마다 시연 기반 미세조정이 필요한 파인튜닝 패러다임에 머문다는 점을 명시.
  • 순수 teleoperation 로봇 데이터만 확장할 경우 장면 다양성의 한계로 OOD(Random) 성능이 약 8,000시간 이상에서 정체(plateau)됨.
  • 액션 공간이 양손 조작(bimanual manipulation)에 한정되어 있으며, 이동(locomotion) 관련 차원은 포함하지 않음(에고센트릭 데이터의 신체/머리 움직임이 과업과 무관하고 불규칙하기 때문).
  • 후속학습 시 사용한 합성 목표 이미지 검증은 시각적·지시적 일관성만 보장하며 물리적 실현가능성은 보장하지 않음.

시사점

이 연구는 로봇 파운데이션 모델 스케일링에서 단순한 데이터 "양"보다 과업·장면 "다양성"이 더 중요한 축일 수 있음을 실증적으로 보여주며, 완전히 공개된 코퍼스·파이프라인·체크포인트가 재현 가능한 스케일링 연구의 기반이 될 수 있음을 제시한다. 또한 시각적 목표(goal-image) 조건화는 언어 지시만으로는 모호한 과업 의도를 명확히 하면서, 파라미터 업데이트 없이 다양한 조작 결과를 유도하는 새로운 체화된 인컨텍스트 러닝 인터페이스로서의 가능성을 보여준다. 인간 비디오와 로봇 데이터를 하나의 임보디먼트-무관(embodiment-agnostic) 액션 공간으로 통합하는 설계가, 서로 다른 로봇·인간 소스를 아우르는 제로샷 전이의 핵심 요소로 제시되어, 이후 인간-로봇 공동 사전학습 기반 범용 조작 정책 연구에 실용적 지침을 제공한다.
