Ovis-Embedding: Pushing the Frontiers of Universal Omni-Modal Embeddings

오비스 임베딩: 범용 옴니모달 임베딩의 한계 확장

텍스트·이미지·비디오·오디오를 하나의 사전학습된 옴니모달 백본(Qwen-Omni, Qwen3.5)으로 직접 인코딩하는 범용 임베딩 모델 Ovis-Embedding을 제안하고, 데이터 구축·훈련·추론 전 과정을 최적화하여 MMEB-v3, MMEB-v2, MAEB, MVEB, RTEB 등 다수 벤치마크에서 최고 성능을 달성했다.

한 줄 요약

텍스트·이미지·비디오·오디오를 하나의 사전학습된 옴니모달 백본(Qwen-Omni, Qwen3.5)으로 직접 인코딩하는 범용 임베딩 모델 Ovis-Embedding을 제안하고, 데이터 구축·훈련·추론 전 과정을 최적화하여 MMEB-v3, MMEB-v2, MAEB, MVEB, RTEB 등 다수 벤치마크에서 최고 성능을 달성했다.

배경 및 문제의식

검색, RAG, 추천, 에이전트 시스템의 핵심 계층인 밀집 임베딩은 텍스트-이미지 등 소수의 정해진 모달리티 쌍을 넘어, 텍스트·이미지·비디오·오디오·시각 문서 등이 뒤섞인 "any-to-any 검색"을 지원해야 하는 상황에 직면해 있다. 그러나 기존 비전-언어 특화 임베더는 오디오를 지원하지 않고, 기존 옴니모달 임베딩 시스템들은 대개 사전학습된 텍스트-비전 임베더에 오디오 경로를 사후적으로 덧붙이거나 별도로 학습된 오디오 인코더를 기존 임베딩 공간에 정렬시키는 방식을 취한다. 이 경우 음향 입력이 애초에 그 모달리티 없이 학습된 기하 구조에 뒤늦게 맞춰지므로 세밀한 교차 모달 정렬에 한계가 있다는 것이 저자들의 문제의식이다.

핵심 기여

논문은 세 가지 축의 기여를 제시한다. 1. 네이티브 옴니모달 초기화: 별도 학습된 오디오 타워를 덧붙이는 대신, 텍스트·비전·오디오·비디오가 이미 하나의 공유 Transformer로 정렬되어 있는 사전학습된 이해 모델(Qwen2.5-Omni, Qwen3.5)을 그대로 임베딩 백본으로 사용한다. 별도의 모달리티별 프로젝션 헤드 없이 마지막 레이어의 마지막 유효 토큰 은닉 상태를 임베딩으로 사용하는 파라미터 없는(parameter-free) 변환만 적용한다. 2. 데이터 중심 옴니모달 훈련: 텍스트, 이미지·문서, 비디오, 오디오, 인터리브드 멀티모달, 에이전트(툴/GUI/지식 검색) 데이터를 아우르는 약 5천만 개(query, target) 쌍 규모의 코퍼스를 구축하고, "동종 소스 샘플링(homogeneous-source sampling)"으로 태스크 일관적인 하드 네거티브를 형성해 모달리티 지름길(shortcut) 학습을 방지한다. 3. 임베딩 특화 훈련·추론 최적화: 난이도 인식 포컬 손실(focal loss)로 어려운 예시에 학습을 집중시키고, 유사도 기반 임베딩 증류(Embedding Distillation)로 보완적 전문가 모델의 세밀한 유사도 구조를 하나의 인코더로 전이한다. 추론 시에는 저랭크 특징 분해로 성능 손실을 최소화하면서 유연한 차원의 압축 임베딩을 지원한다.

방법론

Ovis-Embedding은 두 계열의 백본으로 구성된다. (a) Ovis-Embedding-Omni-3B는 Qwen2.5-Omni-3B의 Thinker(공유 인과 Transformer)를 사용하며, 음성 생성을 담당하는 Talker는 제거하고 텍스트·비전·오디오 인코더와 TMRoPE(시간 정렬 멀티모달 회전 위치 임베딩)를 유지해 텍스트·이미지·비디오·오디오를 지원한다. (b) Ovis-Embedding-VL-2B/9B는 Gated DeltaNet과 게이트형 전체 어텐션을 혼합한 Qwen3.5 백본을 사용해 텍스트·이미지·비디오를 지원한다. 두 계열 모두 언어모델링 출력 헤드를 제거하고, 마지막 비패딩 토큰의 최종 레이어 은닉 상태를 코사인 유사도 기반 임베딩으로 사용한다.

훈련은 4단계로 구성된다. 1단계(저랭크 사전학습): 전체 모달리티를 뒤섞은 배치에서 LoRA로 대조학습을 수행하며, 포컬 가중 대조 손실(어려운 쿼리에 가중치 집중)과 교사 모델의 전체 유사도 분포를 증류하는 임베딩 증류 손실(forward KL)을 결합한다. 초기 임베딩 공간이 혼란스러운 상태에서 전체 파라미터를 업데이트하면 사전학습된 의미 구조가 붕괴되므로, LoRA로 업데이트 폭을 제한해 이를 방지한다. 2단계(전체 파라미터 동종 샘플링 미세조정): 더 고품질의 소규모 데이터셋으로 미세조정하되, 각 마이크로배치를 하나의 데이터셋으로 제한하는 동종 소스 샘플링을 적용해 배치 내 네거티브가 모달리티·문체 등 표면적 단서가 아닌 세밀한 의미 차이에 기반하도록 한다. 3단계(어닐링 임베딩 증류): 더 강력한 교사 모델이 정답을 맞히고 학생이 틀리는 사례를 업샘플링하여, 학생의 자신감(확신도)에 따라 적응적으로 조절되는 KL 증류 가중치로 추가 지식을 전이한다. 4단계(탄력적 임베딩 추론): 동결된 2048차원 인코더 위에 모달리티별 후보 풀의 2차 모멘트를 혼합해 얻은 공유 PCA 기저와, 비지도 방식(Matryoshka-Adaptor 목적함수 기반)으로 학습한 경량 잔차 어댑터를 결합해 128~2048의 다중 임베딩 차원을 하나의 인코더에서 지원한다.

실험 설정 및 결과

평가는 MMEB-v3(190개 태스크, 옴니모달 종합), MMEB-v2(비전-언어), MAEB(오디오 30개 태스크), MVEB(비디오 23개 태스크), RTEB(법률·금융·코드·의료 등 전문 도메인 텍스트 검색) 5개 벤치마크에서 이루어졌다. 모든 모델은 바이인코더 방식으로 독립 인코딩 후 코사인 유사도로 순위를 매기는 동일한 프로토콜로 평가되었다.

  • MMEB-v3: Ovis-Embedding-Omni-3B(3B)가 전체 점수 58.46으로, 최강 베이스라인 Tianmu-Emb-Uni(8B, 53.27)를 5.19점, e5-omni-7B(47.14)를 11.32점 앞서며 이미지·비디오·시각문서·텍스트·오디오·에이전트 6개 그룹 전부에서 1위를 차지했다.
  • MAEB/MVEB: Ovis-Embedding-Omni-3B가 두 벤치마크 모두에서 1위(MAEB Mean(Task) 57.29, MVEB Mean(Task) 61.77)를 기록했다.
  • RTEB/MMEB-Text: RTEB 67.35, MMEB-Text 47.15로, 텍스트 임베딩 전용의 더 큰 모델인 Qwen3-Embedding-4B(RTEB 67.27)도 근소하게 앞섰다.
  • MMEB-v2: Ovis-Embedding-VL-9B가 전체 81.13으로 1위(2위 Octen-VL-Embedding-Large 80.09), Ovis-Embedding-VL-2B가 77.46으로 동급 비교군 1위를 기록했다.
  • 탄력적 임베딩: 2048차원을 1024차원으로 줄여도 성능 유지(100.1%), 128차원(16배 압축)까지 줄여도 평균 93.2% 성능을 보존했으며, 단순 절단(naive truncation) 대비 모든 차원에서 우위를 보였다(128차원에서 +4.30점).

한계점

  • 다중 조건을 동시에 만족해야 하는 텍스트 검색(MultiConIR)에서는 Omni-Embed-Nemotron-3B에 7.94점 뒤처지는 등, 다중 조건 검색은 여전히 개선 여지가 남아 있다.
  • 장기 기억(memory) 검색 태스크에서는 2위(Omni-Embed-Nemotron-3B 대비 2.79점 뒤짐)에 그쳤다.
  • 임베딩 차원을 128까지 줄이면 시각문서(VisDoc)와 에이전트 태스크에서 상대적으로 큰 성능 손실(각각 6.97, 6.18점)이 발생하는데, 이는 페이지 내 특정 요소를 세밀하게 구분해야 하는 태스크는 낮은 차원의 벡터로는 표현 용량이 부족하기 때문으로 분석된다.
  • 훈련 데이터 규모(약 50M 쌍)로 보고된 수치는 논문 자체에 "현재 데이터 프리즈 기준의 잠정치이며 카메라 레디 버전에서 갱신될 것"이라고 명시되어 있어, 최종 수치가 확정되지 않았다.
  • MAEB/MVEB는 아직 공식 리더보드에 제출되지 않아, 순위는 로컬 평가 결과를 기존 리더보드 스냅샷에 삽입해 추정한 것이다.
  • 비디오 클러스터링(MVEB) 태스크에서는 최고 성능에 2.00점 못 미쳐 비지도 카테고리 구조화 측면에서 개선 여지가 있다.

시사점

이 연구는 오디오 경로를 기존 비전-언어 임베더에 사후적으로 부착하는 기존 접근과 달리, 텍스트·비전·오디오·비디오가 애초에 하나의 Transformer에서 공동 학습된 네이티브 옴니모달 이해 모델을 그대로 임베딩 백본으로 재활용하는 것이 모달리티 파편화를 극복하는 데 효과적임을 보여준다. 또한 동종 소스 샘플링, 포컬 손실, 증류, 탄력적 차원 축소라는 임베딩 특화 훈련·배포 기법들이 서로 보완적으로 작동해, 비교적 작은 3B 모델로도 훨씬 큰 모델들을 능가하는 성능을 낼 수 있음을 시사한다. 저자들은 모델 체크포인트, 훈련·데이터 구축 레시피, 추론 코드, 통합 평가 툴킷을 공개할 계획이라고 밝혀, 향후 범용 임베딩 및 any-to-any 검색 연구의 기반이 될 것으로 기대된다.
