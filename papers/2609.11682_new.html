COBRA-Skills: Contextual Bandit-Guided Evolution for Agent Skill Optimization

코브라-스킬즈: 맥락적 밴딧 기반 에이전트 스킬 진화 최적화

COBRA-Skills는 문맥적 밴딧(contextual bandit)으로 어떤 에이전트 스킬을 평가할지 우선순위화하고, 실행 근거 기반의 진화 연산으로 스킬 후보군을 갱신함으로써 적은 비용으로도 LLM 에이전트의 재사용 가능한 스킬을 효율적으로 최적화하는 프레임워크다.

한 줄 요약

COBRA-Skills는 문맥적 밴딧(contextual bandit)으로 어떤 에이전트 스킬을 평가할지 우선순위화하고, 실행 근거 기반의 진화 연산으로 스킬 후보군을 갱신함으로써 적은 비용으로도 LLM 에이전트의 재사용 가능한 스킬을 효율적으로 최적화하는 프레임워크다.

배경 및 문제의식

LLM 에이전트는 반복되는 목표·절차·도구 사용 패턴을 "스킬"이라는 재사용 가능한 지침 형태로 축적해 새로운 과제에 주입하면 성능을 높일 수 있다. 그러나 사람이 직접 스킬을 작성하는 것은 비용이 크고, LLM의 파라메트릭 지식만으로 생성한 스킬은 실제 성능 향상으로 이어지지 않는 경우가 많다. 최근 연구들은 실제 실행 궤적(trajectory)과 피드백에 근거해 스킬을 생성·정제하는 방향으로 나아갔지만, 두 가지 비효율 문제가 있다: (1) 후보 스킬의 유용성을 확인하려면 매번 실제 과제에 실행해 평가해야 하므로 비용이 크고, (2) 스킬을 정제할 때마다 LLM이 실행 궤적을 다시 분석·진단·재작성해야 해 추가 비용이 발생한다. 즉 저품질 후보를 미리 걸러내지 못한 채 평가 예산을 낭비하고, 정제 자체도 반복적으로 비싼 LLM 호출을 요구하는 것이 핵심 병목이다.

핵심 기여

  • 에이전트 스킬 최적화를 "동적으로 변화하는 후보 공간 위에서 제한된 예산으로 순차적으로 최적화하는 문제"로 정식화했다 (스킬의 실제 유용성은 비용이 큰 에이전트 실행을 통해서만 확인 가능하다는 불확실성을 반영).
  • 문맥적 밴딧 기반 우선순위화(어떤 후보를 평가·유지할지 결정)와 근거 기반(evidence-grounded) 집단 진화(어떤 새 후보를 생성할지 결정)를 하나의 폐루프로 결합한 COBRA-Skills를 제안했다.
  • 6개의 이질적인 에이전트 벤치마크와 3개의 타깃 모델, 여러 실행 하네스(harness)에 걸쳐 광범위한 실험을 수행해, COBRA-Skills가 기존 방법 대비 성능과 비용 효율을 동시에 개선함을 보였다.

방법론

COBRA-Skills는 스킬 후보들의 "개체군(population)" P_t를 유지하며 T번의 라운드를 반복한다.

  1. 밴딧 기반 스킬 탐색 (우선순위 스코어링): 각 후보 스킬 s를 고정된 임베딩 모델 φ로 벡터화(z_s)한 뒤, 경량 2층 MLP 보상 예측기 f_θ로 기대 보상(성능)을 예측한다. 여기에 LinearUCB 스타일의 탐색 보너스 b_t(z_s) = ν√(z_sᵀA⁻¹z_s)를 더해 우선순위 점수 U_t(s) = f_θ(z_s) + b_t(z_s)를 계산한다(A는 이전에 평가된 임베딩들로 구성된 정칙화 설계행렬). 매 라운드마다 점수가 가장 높은 스킬 하나만 실제 타깃 에이전트로 평가하여 보상 r_t와 궤적을 얻고, 이 정보로 예측기와 A를 갱신한다. 이렇게 하면 "유망하거나(exploit) 아직 충분히 탐색되지 않은(explore)" 후보에 한정된 평가 예산을 집중시킨다.
  2. 근거 기반 스킬 진화: 매 라운드가 아니라 일정 주기로만 개체군을 갱신한다. 현재 점수가 가장 낮은 m개의 스킬을 제거(pruning)하고, 세 가지 연산으로 빈 자리를 채운다.
  3. Regeneration(재생성): 초기 무스킬(no-skill) 실행 궤적 T_0로부터 독립적인 새 후보를 생성해 탐색 다양성을 유지.
  4. Rollout mutation(롤아웃 변이): 방금 평가된 스킬의 성공/실패 궤적을 근거로 그 스킬 자체를 국소적으로 개선.
  5. Crossover(교차): 누적 이력에서 고성능 스킬을 뼈대로, 다른 고성능 스킬의 전략은 긍정적 근거로, 저성능 스킬은 부정적 근거로 삼아 새 스킬을 합성.

스킬을 생성·정제하는 역할은 "교사 모델"(M_teach, 기본적으로 GPT-5.5)이 맡고, 실제 성능 평가와 스코어 산정은 항상 타깃 에이전트의 실행 결과로만 결정된다. 이 구조 덕분에 값비싼 LLM 기반 궤적 분석·재작성은 전체 라운드가 아니라 예정된 진화 시점에만 호출되어 비용이 크게 줄어든다.

실험 설정 및 결과

SearchQA, SpreadsheetBench, DocVQA, LiveMathematicianBench, SocialMaze(HRD), ALFWorld 등 질의응답·스프레드시트 조작·문서 이해·수학 추론·사회적 추론·구현적 의사결정을 아우르는 6개 벤치마크에서, Qwen3.6-35B-A3B, GPT-5.4-Nano, Gemma4-26B-A4B-it 세 타깃 모델을 대상으로 평가했다. 비교 대상은 No-Skill 베이스라인, LLM Skill(무평가 초기 생성만), Trace2Skill, SkillOpt(선행 최고 성능 기법)이다.

  • COBRA-Skills는 모든 타깃 모델에서 최고 평균 성능을 기록했으며, 무스킬 베이스라인 대비 각각 13.1, 26.9, 22.5%p 향상(Qwen/GPT-Nano/Gemma)시켰다.
  • SkillOpt와 비교해 총 최적화 비용을 55~58% 절감했고, 성능 향상 1점당 비용(Cost/ΔScore)도 60~69% 줄였으며, 벤치마크당 단 50개의 고유 최적화 예시만 사용했다(SkillOpt/Trace2Skill보다 훨씬 적은 데이터).
  • Claude Code, Codex 등 외부 에이전트 하네스로 바꿔도 COBRA-Skills가 최고 성능(평균 68.2/72.4)을 유지해 특정 실행 인터페이스에 종속되지 않음을 확인했다.
  • 제거 실험(ablation)에서 밴딧 우선순위화 또는 진화 중 하나만 제거해도 평균 2.2~2.4점 하락했고, 단순히 후보를 30개로 늘려 최고값을 선택하는 Best-of-30보다도 2.5점 높아, 두 구성요소가 상호보완적으로 기여함을 보였다.
  • 타깃 모델 자신을 교사 모델로 쓰는 "자가 교습(self-teaching)" 설정에서도 성능이 73.5→72.5로 소폭만 하락하면서 비용은 절반 가까이 줄어, 강력한 외부 교사 모델 없이도 방법이 유효함을 시사했다.
  • 서로 다른 타깃 모델 간 교차 전이 실험에서 36개 조합 중 34개에서 최적화된 스킬이 다른 모델에도 성능 향상을 가져와, 스킬이 특정 모델에 과적합되지 않고 과제 수준의 재사용 가능한 전략을 포착함을 보였다.
  • LinearUCB 탐색 계수 ν에 대한 민감도 분석에서 ν=0.1 부근에서 성능이 최고였고, 너무 작거나 크면 성능이 저하되어 탐색-활용 균형의 중요성을 확인했다.

한계점

논문에 별도의 "한계점" 절은 명시되어 있지 않다. 다만 본문에서 확인 가능한 제약은 다음과 같다: (1) 스킬 후보의 우선순위화가 고정된 임베딩 모델(Qwen3-Embedding-4B)의 표현 품질에 의존하며, 이 임베딩이 스킬의 실제 유용성을 얼마나 잘 반영하는지는 별도로 검증되지 않았다. (2) 스킬 생성·정제 자체는 여전히 교사 모델(LLM) 호출에 의존하므로, 교사 모델의 품질과 비용이 전체 성능에 영향을 준다(다만 자가 교습 실험으로 이 의존성이 일부 완화됨을 보였다). (3) 평가는 6개 벤치마크·3개 타깃 모델이라는 제한된 범위에서 이루어졌으며, 더 크거나 다른 유형의 과제 분포로 일반화되는지는 추가 검증이 필요하다. (4) 개체군 크기(K=10), 진화 주기, pruning 개수 등 여러 하이퍼파라미터가 고정되어 있어 이에 대한 민감도는 탐색 계수 ν 외에는 충분히 분석되지 않았다.

시사점

COBRA-Skills는 "어떤 후보를 평가할지"와 "어떤 후보를 새로 만들지"를 분리해 각각 문맥적 밴딧과 근거 기반 진화 연산으로 다루는 접근이, 비용이 큰 실행 기반 평가에 의존하는 에이전트 스킬 최적화 문제에서 실질적인 효율 개선을 가져올 수 있음을 보여준다. 특히 적은 수의 최적화 예시와 낮은 비용으로도 강력한 스킬을 얻을 수 있고, 얻어진 스킬이 하네스와 모델 전반에 어느 정도 전이 가능하다는 점은 프롬프트/스킬 라이브러리를 지속적으로 구축·관리해야 하는 실무형 에이전트 시스템에 바로 적용할 만한 실용적 시사점을 제공한다. 또한 자가 교습 설정의 성공은 향후 외부의 더 강력한 모델 없이도 에이전트가 스스로 스킬을 개선해 나가는 자기 진화형 시스템으로 확장될 가능성을 시사한다.
