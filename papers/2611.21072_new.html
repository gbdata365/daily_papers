Sage S2.1 Flash Technical Report

세이지 S2.1 플래시: 과학 인지 멀티모달 에이전트 모델

과학적 증거(분자 구조, 생물 서열, 스펙트럼 등)를 직접 인식하고 검증 가능한 환경에서 도구 사용·코딩·탐색 등 에이전트 작업을 수행할 수 있는 3,200억 파라미터 규모의 범용 MoE(Mixture-of-Experts) 모델 Sage S2.1 Flash를 소개한다.

한 줄 요약

과학적 증거(분자 구조, 생물 서열, 스펙트럼 등)를 직접 인식하고 검증 가능한 환경에서 도구 사용·코딩·탐색 등 에이전트 작업을 수행할 수 있는 3,200억 파라미터 규모의 범용 MoE(Mixture-of-Experts) 모델 Sage S2.1 Flash를 소개한다.

배경 및 문제의식

최근 멀티모달 에이전트는 시각 정보 검색·이해, 시각 피드백 기반 코딩, 컴퓨터 사용 등으로 영역을 넓히고 있다. 그러나 과학 연구에서는 분자 그래프, 생물학적 서열, 실험 스펙트럼처럼 텍스트·이미지 형태로 환원되지 않는 고유한 증거 형식이 많고, 과학 소프트웨어 조작처럼 시각적 상태 변화를 해석해야 하는 작업도 많다. 저자들은 이런 과학 특화 입력과 범용 에이전트 능력을 하나의 모델 안에서 통합하는 것을 목표로 삼았다.

핵심 기여

  • Sage Sci-Perception: 분자 그래프, 단백질/DNA/RNA 서열, 스펙트럼 등 이질적인 과학 데이터를 과학 전용 인코더와 수치 패칭(numerical patching)으로 처리하고, 모달리티별 프로젝터(projector)로 언어모델의 임베딩 공간에 매핑하는 통합 인터페이스를 제안했다.
  • 320억이 아닌 3,200억 파라미터(320B) 규모의 MoE 백본을 기반으로, 텍스트·이미지·과학 표현을 하나의 공유된 멀티모달 컨텍스트에서 함께 처리하도록 설계했다.
  • ToolSpace라는 도구 중심(tool-centric) 프레임워크를 제안해, 실제 실행 트레이스에서 도구 간 구성 관계(tool-composition graph)를 복원하고, 이를 바탕으로 장기 호라이즌(long-horizon) 에이전트 작업을 교차 환경(cross-environment)으로 합성한다.
  • 도구 사용, 검색, 코딩, 머신러닝 실험, 과학 소프트웨어 조작, 사이버보안(취약점 재현/악용) 등 다양한 영역에 걸친 대규모 검증 가능 환경(verifiable environment)을 구축해 후속 학습(post-training)에 활용했다.

방법론

모델은 공유 언어 백본이 네이티브 텍스트·이미지와 과학 표현을 함께 처리하는 구조다. 과학 인코더(분자 그래프용 MoleculeSTM, 단백질용 ESM-2, DNA용 DNABERT-2, RNA용 RNA-FM 등)가 입력을 지역 표현(local representation)으로 변환하면, 모달리티별 프로젝터가 이를 식별자 임베딩과 결합해 백본의 입력 임베딩 공간으로 매핑한다(수식 상으로는 레이어 정규화 후 두 번의 선형 변환과 GELU 활성화로 구성).

후속 학습 단계에서는 ToolSpace 프레임워크를 통해 (1) 실제 MCP 실행 기록과 웹 기반 트레이스에서 도구 호출 패턴을 수집해 도구 그래프를 구성하고, (2) 상태를 고려한 랜덤 워크로 여러 환경을 넘나드는 작업을 생성한 뒤, (3) 역방향으로 자연어 과제 설명과 검증 스크립트를 합성하고 재현(replay) 검증을 통과한 궤적만 남긴다. 이 과정으로 77,760개의 도구 호출 노드, 2,042개의 고유 도구, 804개 환경이 구성되었다고 보고한다. 검색 작업은 지식 그래프 기반의 정방향 합성과 시드 질의 기반의 역방향 합성을 병행해 구성했고, 코딩 작업은 소프트웨어 공학(SWE), 터미널 사용, 웹 개발로 나누어 공개 데이터셋과 GitHub 커밋 마이닝 등을 통해 수집했다. 머신러닝 코딩 작업은 Kaggle, Hugging Face 등에서 실데이터와 코드를 짝지어 구성하고, 일부 구현을 의도적으로 제거(controlled degradation)해 과제를 만들었다. 사이버보안 작업은 취약점 재현과 취약점 악용 두 유형으로 구성했으며, 세부적인 공격 기법이나 취약점 악용 절차는 본 요약에서 다루지 않는다(안전상 구체적 재현 내용은 생략).

실험 설정 및 결과

DeepSeek-V4.1-Flash, Qwen3.8-Max, GLM-5.3-Flash, GPT-5.6 Sol, Claude Opus 5 등 5개 베이스라인과 비교해 총 33개 벤치마크(7개 도메인)에서 평가했다. 대표적으로 OfficeQA Pro(72.2), MLE-bench Lite(90.3 HumanRank), Harvey LAB, SpreadsheetBench 2에서 1위를 기록했고, OSWorld-Verified(85.2), WebArena-Verified(67.6), DeepResearch Bench II(54.2)에서는 2위를 기록했다. 특히 문서 증거 활용, 검증 가능한 워크북(스프레드시트) 생성, 머신러닝 실험 수행에서 강점을 보였으며, 시각 피드백을 바탕으로 동작해야 하는 데스크톱·브라우저 작업에서도 경쟁력 있는 성능을 보였다. 또한 현미경 영상(Fiji), EEG 신호(EEGLAB), 위성영상(QGIS) 등 과학 소프트웨어를 다루는 워크플로와, 양자 메모리 실험 문헌을 분석해 인터랙티브 HTML 데모를 생성하는 과학 딥리서치 사례도 시연했다.

한계점

저자들은 저장소 수준(repository-level) 코딩과 웹 검색 영역에서는 개선의 여지가 있다고 밝혔다. 또한 탐색적 궤적 분석에서, 동일한 작업 점수를 받아도 출력 검증 방식과 보고 방식에 차이가 있을 수 있음을 지적했다. 과학 워크플로 전체를 통합적으로 평가해 모델이 관련 증거를 선택하고 피드백에 따라 행동을 조정하며 과학적으로 올바른 결과를 내는지를 검증하는 것은 다음 과제로 남겼다. 그 외 세부 실패 사례나 정량적 오류율은 논문에 명시되지 않음.

시사점

이 연구는 범용 LLM/에이전트 모델에 과학 데이터 특유의 모달리티(분자, 서열, 스펙트럼 등)를 네이티브하게 통합하고, 검증 가능한 실행 환경을 통해 에이전트 능력을 함께 학습시키는 접근이 실제로 과학 연구 보조(문헌 분석, ML 실험, 과학 소프트웨어 조작 등)에서 유의미한 성능을 낼 수 있음을 보여준다. ToolSpace처럼 도구 간 구성 관계를 그래프로 복원해 장기 호라이즌 작업을 자동으로 합성하는 방식은, 에이전트 학습 데이터 확보의 병목을 완화하는 일반적인 방법론으로 확장될 수 있다.
