The Missing Temporal Link: Temporal Context Routing for Script-Driven Audio-Video Generation

누락된 시간적 연결고리: 대본 기반 오디오-비디오 생성을 위한 템포럴 컨텍스트 라우팅

스크립트에 명시된 샷 전환·대사 타이밍을 비디오와 오디오의 공유 시간축에 명시적으로 정렬시키는 Temporal Context Routing(TCR)을 제안하여, 대본 기반 오디오-비디오 동시 생성에서 샷 경계 오차를 96% 줄이고 대사 타이밍 정확도를 3배 가까이 끌어올린다.

한 줄 요약

스크립트에 명시된 샷 전환·대사 타이밍을 비디오와 오디오의 공유 시간축에 명시적으로 정렬시키는 Temporal Context Routing(TCR)을 제안하여, 대본 기반 오디오-비디오 동시 생성에서 샷 경계 오차를 96% 줄이고 대사 타이밍 정확도를 3배 가까이 끌어올린다.

배경 및 문제의식

기존 오디오-비디오 동시 생성 모델은 비디오와 오디오 표현을 공유 시간축 위에서 서로 정렬시키지만, 구조화된 프롬프트(스크립트)에 명시된 샷과 대사의 정확한 타이밍은 오직 텍스트 표현에만 인코딩되어 있어 어느 모달리티의 시간 좌표와도 정렬되지 않는다. 그 결과 비디오와 오디오는 서로 동기화되어 있으면서도 둘 다 스크립트의 타임라인 자체를 따르지 못해, 짧은 드라마나 광고 같은 대본 기반 콘텐츠 제작에서 내러티브 일관성을 해치는 타이밍 오류가 발생한다.

핵심 기여

  • 비디오-오디오 정렬을 구조화된 스크립트까지 확장해야 한다는 문제의식을 제시하고, 각 프롬프트(샷·대사)의 지정된 타이밍을 두 모달리티 모두에 대한 명시적 제어 신호로 규정
  • 스크립트 타이밍을 비디오·오디오 공유 시간축에 매핑해 각 프롬프트의 가이던스를 해당 위치로 라우팅하는 Temporal Context Routing(TCR) 제안 — 학습 가능한 파라미터 없이 크로스 어텐션 로짓에 지속시간 정규화된 라우팅 점수를 더하는 방식
  • Gemini의 대략적 주석을 시각 컷 탐지(PySceneDetect)와 단어 단위 음성 정렬(WhisperX)로 정제하는 coarse-to-fine 데이터 구축 파이프라인 개발
  • 200개 테스트 스크립트에서 Shot Boundary MAE를 1.11초→0.042초(96% 감소), Dialogue Acc@0.5s를 28.3%→84.1%로 향상시키면서도 시각 품질과 오디오-비디오 동기화는 유지

방법론

구조화된 스크립트는 Reference(등장인물·장면·사물), Shot(샷 내용·카메라 속성), Event(대사 등 국소적 오디오 이벤트), Global(전체 맥락) 네 가지 프롬프트 유형으로 구성되며, 각 프롬프트는 라우팅용 시간 구간이 할당된다. TCR은 토큰 j의 구간 [s_j, e_j]의 중심 c_j와 반경 r_j를 계산해, 모달리티 m의 잠재 쿼리 시간좌표 t^m_i에 대한 라우팅 점수 B^m_ij = -β(t^m_i - c_j)²/(2r_j²)를 정의하고, 이를 비디오-텍스트 및 오디오-텍스트 크로스 어텐션 로짓에 가산적으로 더한다. 이 방식은 원래의 텍스트·쿼리·키 표현을 전혀 수정하지 않으면서 로짓에 가법적으로 작용해 어텐션 가중치를 승법적으로 재조정하므로, 겹치는 샷·대사 프롬프트를 서로 독립적으로 제어할 수 있다. LTX-2.3(22B 파라미터 조인트 오디오-비디오 생성기) 위에 LoRA로 적용되며, 학습 데이터는 발화 없는 구간에 클립 경계를 두는 방식으로 다중 샷 클립을 구성한 뒤 Gemini가 초벌 주석을 달고 PySceneDetect·WhisperX로 0.1초 단위까지 정제해 만들어진다.

실험 설정 및 결과

200개 테스트 스크립트(640개 샷, 441개 대사 프롬프트)에서 TCR은 가장 강력한 오픈소스 베이스라인 LTX-2.3 대비 Shot Boundary MAE를 1.11초에서 0.042초로(96% 감소), Shot IoU를 0.532에서 0.957로, 정확한 샷 개수 일치율을 36.0%에서 93.0%로, Dialogue Acc@0.5s를 28.3%에서 84.1%로 향상시켰고, 시각 품질(IQ)과 음성 인식 오류율(WER), 립싱크(Sync-C) 지표에서도 최고 또는 상위권을 기록했다. 동일 백본에서 하드 인터벌 마스크, 가우시안 인터벌 RoPE 등 다른 시간 연산자와 통제 비교한 결과 TCR이 모든 샷 타이밍 지표에서 최고 성능을 보였으며(두 대안 대비 MAE 60% 이상 감소), 정제되지 않은 초벌 주석으로 학습하면 MAE가 0.042초에서 0.375초로 크게 악화되어 coarse-to-fine 데이터 파이프라인의 중요성을 확인했다. 28명이 참여한 블라인드 사용자 평가에서도 TCR은 샷 타이밍, 대사 타이밍, 스크립트 충실도, 오디오-비디오 동기화, 전체 선호도 등 5개 항목 모두에서 우위를 보였다(LTX-2.3 대비 전체 선호도 72.3%, JoyAI-Echo 대비 83.9%).

한계점

논문에 명시되지 않음 (본문에서는 구체적 한계점 절 없이, 샷·대사 프롬프트가 서로 다른 시간 구간을 가지므로 단일 시간 분할을 강제할 수 없다는 점과, 미세한 타이밍 학습에는 정교한 주석이 필요하다는 점을 방법론적 도전과제로만 언급함).

시사점

비디오-오디오 간 상호 동기화만으로는 대본 기반 생성에서 충분하지 않으며, 구조화된 스크립트 자체를 시간 정렬의 대상으로 명시적으로 포함시켜야 함을 보여준다. 학습 가능한 파라미터 없이 어텐션 로짓에 가산적 편향만 추가하는 경량 설계로도 큰 정확도 향상이 가능함을 시사하며, 이는 대본 기반 콘텐츠 제작 파이프라인에 즉시 적용 가능한 실용적 해법을 제공한다.
