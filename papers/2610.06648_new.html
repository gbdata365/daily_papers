Representation-Space MMD for Diffusion Language Models

확산 언어 모델을 위한 표현 공간 MMD

사전학습된 확산 언어 모델(DLM)의 내부 표현 공간에서 생성 샘플과 참조 샘플 간 MMD(Maximum Mean Discrepancy)를 토큰 단위로 최소화함으로써, 별도의 교사 모델이나 보조 판별 모델 없이도 이산·연속 확산 언어 모델 모두의 샘플링 효율과 생성 품질을 동시에 개선하는 후처리(post-training) 기법을 제안한다.

한 줄 요약

사전학습된 확산 언어 모델(DLM)의 내부 표현 공간에서 생성 샘플과 참조 샘플 간 MMD(Maximum Mean Discrepancy)를 토큰 단위로 최소화함으로써, 별도의 교사 모델이나 보조 판별 모델 없이도 이산·연속 확산 언어 모델 모두의 샘플링 효율과 생성 품질을 동시에 개선하는 후처리(post-training) 기법을 제안한다.

배경 및 문제의식

확산 언어 모델(DLM)은 이산 토큰 공간 또는 연속 잠재 공간에서 노이즈를 반복적으로 제거해 텍스트를 생성한다. 적은 스텝으로 고품질 샘플을 얻기 위한 기존의 증류(distillation) 기법들은 여러 디노이징 스텝에 걸친 교사(teacher) 신호를 모사하거나, 생성 분포를 맞추기 위해 별도로 공동 학습되는 보조 모델(판별기 등)을 필요로 한다는 한계가 있다. 저자들은 "생성 샘플과 참조 샘플만으로 직접 계산 가능한 분포 매칭 학습 신호가 있는가"라는 질문을 던지고, 커널 기반 분포 거리 지표인 MMD에 주목한다. 다만 MMD의 효과는 비교가 이루어지는 표현 공간에 크게 좌우되며, 단순한 입력 공간 거리로는 의미 있는 차이를 포착하기 어렵다는 점이 알려져 있다. 영상 생성 분야에서는 학습된(사전학습) 특징 공간에서의 MMD가 고품질 소수-스텝 생성에 효과적이었다는 선행 연구들이 이 접근의 동기가 되었다.

핵심 기여

  • 사전학습된 프리즌(frozen) DLM을 특징 추출기로 사용하여, 토큰 단위(개별 위치별)의 문맥 특징을 뽑아 MMD를 계산하는 표현 공간 MMD(Representation-Space MMD) 프레임워크를 제안했다. 특징을 하나로 풀링하지 않고 위치별로 유지함으로써 한 번의 순전파(forward pass)에서 여러 개의 관측치를 얻어 MMD 추정에 활용한다.
  • 이 손실을 이산 모델에는 정책 그래디언트(REINFORCE, leave-one-out 베이스라인)로, 연속 모델에는 생성된 잠재값을 통한 직접 미분으로 최적화하는 두 갈래의 구체적 구현을 제시했다: 마스크 확산용 MDLM-MMD, 마스크-균등 혼합 확산용 DMax-MMD, 연속 잠재 확산(ELF 기반)용 ELF-MMD.
  • 교사-학생 증류나 공동 학습되는 보조 판별 모델 없이, 프리즌 DLM의 특징만으로 효율적인 후처리 학습 신호를 구성할 수 있음을 보였다.
  • 16B 규모의 산업급 모델(DMax-Math, DMax-Coder)에 적용하여 짧은 추가 학습(수백 스텝, 수십 분)만으로 디코딩 병렬성(tokens per forward, TPF)과 정확도의 트레이드오프를 개선할 수 있음을 실증했다.

방법론

표현 공간을 정의하기 위해 프리즌 사전학습 DLM의 중간 은닉 상태 φ(x) = (φ₁(x), ..., φ_L(x))를 특징으로 사용한다. 실제 샘플과 생성 샘플 모두 동일한 방식(클린 샘플에 대해, 노이즈 중간 단계에서는 성능 향상이 없었음)으로 이 추출기를 통과시킨다. 평가 위치 집합 S(비조건부 생성은 전체 위치, 프롬프트 기반 생성은 응답 위치, 마스크 모델은 마스크 위치)의 토큰별 특징들을 모아, 두 시퀀스 간 평균 RBF 커널 유사도 κ_φ(x, x')를 정의하고, 이를 기반으로 배치 내 실제-생성 항(끌림)과 생성-생성 항(밀어냄)으로 구성된 불편(unbiased) MMD 추정량을 사용한다(B≥2 필요, B=1인 끌림만 있는 경우 성능 저하/붕괴 관찰).

이산 DLM에서는 범주형 샘플링이 미분 불가능하므로, 동일한 조건에서 독립적으로 뽑은 G개의 배치에 대해 negative MMD를 보상으로 하는 grouped REINFORCE(leave-one-out 베이스라인)로 정책 그래디언트를 계산한다. MDLM-MMD는 마스크 위치만, DMax-MMD는 마스크 손실과 모델 자신의 토큰 예측에 대한 정제 손실 모두에 MMD를 적용한다.

연속 DLM에서는 ELF(Embedded Language Flows) 모델을 초기화 지점으로 삼아, 가우시안 노이즈에서 클린 잠재값으로 매핑하는 1-스텝 생성기를 학습한다. MMD 그래디언트가 프리즌 ELF 특징 추출기와 생성된 잠재값을 통해 직접 역전파된다. 추론 시에는 self-conditioning을 이용해 이전 예측을 다시 입력으로 넣는 방식으로 다중 스텝 반복 정제를 수행하며, 필요 시 반복 정제 증류(IRD)로 추론 스텝 수를 더 줄인다.

실험 설정 및 결과

비조건부 생성(OpenWebText): GPT-2 Large로 측정한 생성 perplexity와 엔트로피로 평가. 이산 모델(MDLM-MMD)은 DiDi-Instruct, IDLM, IDLM-REINFORCE 대비 동일 엔트로피 기준 약 17~21% 낮은 생성 perplexity를 달성했다. 연속 모델(ELF-MMD, ELF-MMD+IRD)은 ELF, ELF, ELF-PD, FMLM 대비 대부분의 스텝 예산에서 더 낮은 perplexity를 보였으며, IRD는 4-스텝 설정에서 perplexity를 크게 추가 개선했다.

조건부 생성(GSM8K, TinyGSM으로 학습): 이산 모델은 중간~높은 스텝 예산에서 약 49스텝에 약 54% 정확도로 베이스라인들을 상회했다. 연속 모델(ELF-MMD)은 모든 스텝 예산에서 ELF 대비, 대부분에서 ELF-PD 대비 정확도가 향상되었고, IRD가 추가 개선을 가져왔다(64스텝 기준 ELF-MMD+IRD 36.3% vs ELF-MMD 35.2% vs ELF 31.6%). Pass@k 측정에서도 이산 모델은 적은 스텝(4~8)에서 특히 큰 우위를 보였다.

16B 규모 확장(DMax-Math/Coder): GSM8K, MATH500, Minerva-Algebra, ASDIV(수학) 및 HumanEval-Instruct, MBPP-Instruct(코드)에서 평가. DMax-Math-MMD는 기존 DMax-Math 대비 비슷하거나 더 높은 정확도를 유지하면서 TPF(토큰 생성 병렬성)를 10.3~16.5% 향상시켰다. DMax-Coder-MMD는 HumanEval-Instruct에서 2.4%p, MBPP-Instruct에서 3.8%p 정확도를 높이면서 TPF도 함께 개선했다. 학습은 8×H100 GPU에서 400스텝, 약 13~19분 소요되었다.

손실 함수 어블레이션(GSM8K): 제안된 토큰 단위 RBF MMD가 시퀀스 단위 RBF, 선형 커널(평균 매칭), 특징 회귀(MSE), 끌림만 있는 변형 대비 가장 우수한 정확도-계산량 트레이드오프를 보였으며, 특히 이산 모델에서 효과가 컸다.

한계점

RBF 커널의 대역폭이나 특징 추출에 사용할 표현 공간(어떤 모델, 어떤 레이어)의 선택에 성능이 민감하여 표현 설계가 추가 탐구가 필요한 영역으로 남아 있다. 본 연구는 단일 레이어, 클린 입력에서 얻은 특징만 사용했으며, 여러 레이어나 노이즈 수준을 결합하거나 여러 추출기를 앙상블하는 방안은 다루지 않았다. 또한 주입적(injective) 특징 사상을 전제로 한 MMD의 분포 식별 가능성은 이론적으로 엄밀히 증명되지 않았고 최근의 관련 결과에서 동기를 얻은 수준이다. 생성 샘플 수 B=1(끌림 항만 존재)인 경우 이산 모델 성능이 저하되고 연속 모델은 빠르게 붕괴하는 현상이 관찰되었다. 이산 DLM에 대해 MMD를 다른 학습 목적함수와 결합하는 방향은 본 논문에서 다루지 않고 향후 과제로 남겨두었다.

시사점

이 연구는 교사 모델 증류나 별도의 공동 학습 보조 모델 없이도, 프리즌 사전학습 모델의 표현 공간에서 계산한 MMD만으로 이산·연속 확산 언어 모델 모두의 샘플링 효율-정확도 트레이드오프를 개선할 수 있음을 보여준다. 특히 16B 규모 모델에 수십 분 내 적용 가능하다는 점에서, 기존에 배포된 대규모 확산 언어 모델에 손쉽게 덧붙일 수 있는 경량 후처리 단계로서의 실용적 가능성을 시사한다. 또한 특징 공간(어떤 레이어·어떤 모델을 추출기로 쓸지)의 설계가 향후 성능을 좌우할 중요한 연구 방향이며, MMD를 다른 학습 목적함수와 결합하는 시도도 추가적인 개선 여지를 제공할 수 있음을 시사한다.
