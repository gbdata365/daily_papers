CUA-Master: Scaling Computer-use Agents through Open-World Recursive Improvements

씨유에이마스터: 오픈월드 재귀적 개선을 통한 컴퓨터 사용 에이전트 확장

한 줄 요약

개방형 세계(open-world) 영상에서 수집한 실제 작업 흐름과 모델이 자가 생성한 데이터를 이중 순환 구조로 결합해, 27B 규모 모델만으로도 컴퓨터 사용 에이전트(CUA)의 성능을 대형 모델 수준으로 끌어올린 연구.

배경 및 문제의식

기존 컴퓨터 사용 에이전트 학습 파이프라인은 데이터 생성과 모델 학습이 단방향으로 연결되어 있어, 모델의 약점을 반영해 재귀적으로 데이터를 보강하기 어렵다. 또한 최근의 재귀적 자기개선 기법들은 모델 스스로 생성한 데이터에만 의존하는 '폐쇄형 세계(closed-world)' 방식이라, 기존 능력의 한계 안에서만 맴돌며 데이터 편향을 재생산하고 성능 향상이 점차 둔화되는 한계가 있다. 아울러 실제 환경의 다양성과 복잡성을 담은 고품질 궤적(trajectory) 데이터는 사람이 직접 주석을 달기에는 비용이 크고, 합성 데이터는 다양성·제어 가능성·신뢰성(실행 성공률) 측면에서 동시에 한계를 보인다.

핵심 기여

  • 외부(실제 세계)와 모델 학습을 연결하는 '월드-데이터-모델 플라이휠'과, 데이터 수준에서 작동하는 '오픈월드 시딩 + 자동 촉매적 전파(autocatalytic propagation)' 이중 루프로 구성된 재귀 개선 프레임워크 CUA-Master를 제안.
  • YouTube·TikTok·Bilibili 등 실제 튜토리얼 영상에서 시각-의미 이중 경로(dual-path) 방식으로 작업(task)과 실행 궤적을 자동 추출하는 '오픈월드 시딩' 기법 제시.
  • 추출된 작업을 재사용 가능한 능력 단위(primitive)로 추상화한 뒤 조합해, 난이도와 적용 애플리케이션 수를 명시적으로 제어하며 새로운 작업을 합성하는 '구성형 작업 합성' 기법 제시.
  • 실패가 발생해도 처음부터 다시 수행하지 않고, 유효했던 실행 구간까지는 스냅샷으로 보존한 뒤 실패 지점부터 피드백을 반영해 재시도하는 '스냅샷-롤백' 메커니즘으로 대규모 롤아웃의 성공률과 효율을 높임.
  • 27B 파라미터의 CUA-Master 모델이 OSWorld Verified, OSWorld 2.0, WeaveBench, Agents' Last Exam 네 개 벤치마크에서 훨씬 큰 모델들과 경쟁하거나 능가하는 성능을 달성.

방법론

작업은 지시문, 상호작용 환경, 검증기(verifier)로 정의되며, 에이전트는 GUI 조작(클릭·스크롤 등)과 CLI 명령(셸 실행)을 함께 쓰는 하이브리드 행동 공간에서 동작한다. 100개 이상의 CUA 실행 환경과 2,000개 이상의 동시 VM을 지원하는 인프라 위에서, (1) 오픈월드 시딩 단계는 영상에서 CUA 적합도 점수를 매겨 후보를 거르고, 발화 전사와 영상 프레임 변화의 겹침을 기준으로 조작 경계를 탐지해 작업과 궤적을 복원한다. (2) 자동 촉매적 전파 단계는 복원된 작업/궤적을 애플리케이션·능력·사전조건·환경요구사항·검증식으로 이루어진 '프리미티브'로 분해하고, 이를 원하는 복잡도(K개의 프리미티브, N개의 애플리케이션)에 맞춰 조합해 새 작업을 합성한다. 실행 중 실패나 비효율이 감지되면 검증기 잔차와 궤적을 분석해 실패 직전의 안정적 스냅샷으로 되돌려 재시도한다. 모델 학습은 여러 차례의 지도 미세조정(SFT) 이후 마지막 단계에서 검증 가능한 보상 기반 강화학습(RL)을 적용하는 방식으로, Qwen-3.5-27B를 기반으로 수행되었다.

실험 설정 및 결과

16개 노드(노드당 NVIDIA H200 141GB GPU 8개)에서 학습을 진행했으며, SFT 단계에서 누적된 약 11.5만 개의 작업, RL 단계에서 약 1.2만 개의 고품질 작업을 사용했다. OSWorld Verified, OSWorld 2.0, WeaveBench(GUI+CLI 하이브리드), Agents' Last Exam(GUI+CLI 하이브리드) 네 벤치마크와 WindowsAgentArena·MacOSWorld·MacAgentBench 교차 플랫폼 벤치마크에서 Qwen·Kimi·GPT·Claude 계열 범용 모델 및 OpenCUA·UI-Mate 등 전문 CUA 모델과 비교 평가했다. CUA-Master-27B는 OSWorld Verified 80.2점, OSWorld 2.0 36.9점, WeaveBench 43.9점, Agents' Last Exam 25.0점을 기록했으며, 비슷한 규모의 전문 모델 UI-Mate-27B 대비 네 벤치마크에서 각각 2.6, 12.9, 25.6, 11.8점 높은 성능을 보였다. 또한 실행 단계 수·토큰 사용량·실행 시간 측면에서도 더 적은 자원으로 비슷하거나 더 나은 점수를 달성해 효율성 우위를 보였고, GUI 전용·CLI 전용 모드보다 하이브리드 모드에서 WeaveBench 기준 큰 폭(최대 37점 이상)의 성능 향상을 확인했다.

한계점

논문에 명시된 한계점 서술은 제공된 범위 내에서 뚜렷이 드러나지 않음(논문에 명시되지 않음). 다만 본문 내용상 오픈월드 영상 기반 작업 추출과 합성 작업 생성, 재시도 메커니즘 모두 별도의 '주석자(annotator)' 모델에 의존하므로, 해당 모델의 성능에 따라 생성되는 데이터 품질과 최종 학습 결과가 영향을 받을 수 있음을 자체 분석(annotator 모델 비교 실험)을 통해 시사하고 있다.

시사점

실제 세계에서 수집한 다양하고 통제되지 않은 데이터(오픈월드)와 모델이 스스로 생성하는 통제된 합성 데이터(폐쇄형)를 재귀적으로 결합하면, 상대적으로 작은 모델로도 에이전트의 장기 과제 수행 능력을 지속적으로 확장할 수 있음을 보여준다. 이는 향후 컴퓨터 사용 에이전트뿐 아니라 다른 장기 horizon 에이전트 학습 전반에서, 데이터 다양성 확보와 모델 약점 기반 재탐색을 결합하는 설계 방향이 유효할 수 있음을 시사한다.
