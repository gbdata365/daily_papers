Fast Weight Attention for Continual Learning

지속학습을 위한 패스트웨이트 어텐션

순환형 패스트웨이트/선형 어텐션 모델의 상태 갱신 규칙을 "읽은 후 쓰기(read-after-write)" 자기회귀 시맨틱 아래에서 재해석해, 실제로 예측 시점에 사용 가능했던 정보만으로 학습하는 시간 정렬 문제를 바로잡고, 이로부터 정규화된 1차 갱신 규칙(Falcon) 계열을 유도한다.

한 줄 요약

순환형 패스트웨이트/선형 어텐션 모델의 상태 갱신 규칙을 "읽은 후 쓰기(read-after-write)" 자기회귀 시맨틱 아래에서 재해석해, 실제로 예측 시점에 사용 가능했던 정보만으로 학습하는 시간 정렬 문제를 바로잡고, 이로부터 정규화된 1차 갱신 규칙(Falcon) 계열을 유도한다.

배경 및 문제의식

트랜스포머의 셀프 어텐션은 시퀀스 길이에 대해 이차적으로 비용이 증가하며, 이를 완화하기 위한 선형 어텐션·상태공간모델(SSM)·패스트웨이트 프로그래머 등은 확장하는 컨텍스트를 고정 크기의 순환 상태로 압축한다. 이때 상태 갱신 규칙은 사실상 "온라인 학습 규칙"으로 작동하는데, 그 시간 정렬(temporal alignment)이 예측 시점에 실제로 사용 가능했던 정보만을 학습에 쓰는지 결정한다. 저자들은 많은 기존 순환 구조가 동일 스텝의 쌍 (ϕ(k_t), v_t)을 학습에 사용하는 반면, 접두사 예측(prefix-prediction) 목적함수 하에서 진짜로 스텝 t에 드러나는 국소적 패스트메모리 예시는 접두사에 정렬된 쌍 (ϕ(k_{t-1}), v_t)라는 관례 불일치를 지적한다. 동일 스텝 쌍도 인과적이기는 하지만, 이는 다른 내부 목적함수를 최적화하는 것이라는 점이 핵심 문제의식이다.

핵심 기여

  1. 패스트메모리 학습 쌍의 재정의: 읽은 후 쓰기 자기회귀 모델링이 유도하는 진짜 패스트메모리 학습 쌍을 동일 스텝 연관관계와 구분해 명시적으로 식별한다.
  2. Falcon 계열 회귀 갱신 규칙: 제곱오차 회귀 목적함수에 대한 정규화된 1차(온라인 경사하강) 갱신으로 Falcon-1(스칼라 NLMS 갱신), Falcon-2(채널별 확장), Falcon-3(슬라이딩 윈도우 미니배치 갱신)을 유도한다.
  3. Falcon-A 계열 내적 갱신 규칙: 동일한 가소성/망각 시맨틱을 유지하되 분모를 곡률 정규화가 아닌 쓰기 크기(write-magnitude) 정규화로 해석하는 내적(inner-product) 목적함수 기반의 Falcon-1A/2A/3A를 유도한다.
  4. 순환·마스크 병렬·청크 병렬 구현: 유도된 모든 갱신 규칙에 대해 순환형(recurrent), 마스크 병렬(masked-parallel), 청크 병렬(chunk-parallel, SSD 스타일) 형태를 제공하고, 수치적으로 안정적인 양의 감쇠(positive-decay) 재정규화 기법을 함께 제시한다.

방법론

Falcon 프레임워크는 순환 상태 S_t를 접두사 쓰기 특징 x_t := ϕ(k_{t-1})로부터 새로 드러난 타깃 v_t로 가는 온라인 선형 예측기로 취급하고, 순간 릿지 회귀 손실 ℓ_t(S) = ½‖S^⊤x_t − v_t‖² + (λ_t/2)‖S‖²_F(식 3.1)의 온라인 경사하강(OGD)으로 상태를 갱신한다. Falcon-1은 모든 값 채널에 공유되는 스칼라 학습률 η_t를 쓰는 정규화된 최소평균제곱(NLMS) 갱신이며, Falcon-2는 값 채널마다 서로 다른 학습률 벡터 η_t∈R^{d_v}를 쓰는 채널별 확장이고, Falcon-3은 최근 B개 인과적 쌍으로 구성된 슬라이딩 윈도우에 대한 미니배치 경사 스텝을 취해 국소적 잡음 누적을 줄인다. 내적(inner-product) 목적함수 ℓ^ip_t(S) = −⟨S^⊤x_t, y_t⟩ + (λ_t/2)‖S‖²_F(식 4.5)에 대해서도 동일한 논리로 Falcon-1A/2A/3A를 유도하며, 이들은 잔차를 빼는 대신 타깃을 직접 쓰고, 망각은 캐리(carry) 항에만 스칼라 또는 채널별 계수로 작용한다. 모든 변형에 대해 WY/Gram 분해를 이용한 청크 단위 병렬 훈련 알고리즘(예: Falcon-2의 청크별 배치 삼각시스템 해법, Falcon-3의 3단계 ParallelFlow tensorInv 알고리즘)을 구체적으로 제시하며, 로그 공간에서의 양의 감쇠 재정규화로 수치 안정성을 확보한다.

실험 설정 및 결과

논문 초록에 따르면, 대표적인 Falcon 변형들은 언어모델링 과제에서 경쟁력 있는 성능을 유지하며, 가변 자릿수 덧셈(variable-digit addition) 과제에서는 길이 외삽(length extrapolation) 성능을 개선한다. 다만 발췌된 본문 범위(주로 방법론적 유도와 알고리즘 설명에 집중된 전반부)에서는 구체적인 벤치마크 수치나 비교 테이블은 확인되지 않았다(논문에 명시되지 않음).

한계점

논문에 명시되지 않음(발췌된 범위 내에서 확인되지 않음).

시사점

이 프레임워크는 시간 정렬(temporal alignment), 가소성(plasticity), 망각(forgetting), 제한된 리허설(bounded rehearsal)이라는 순환 시퀀스 모델의 서로 다른 설계 축을 명확히 분리해서 다룰 수 있게 해준다. 특히 "동일 스텝 쌍"과 "접두사 정렬 쌍"의 구분은 Linear Attention, Delta Network, Mamba-2류의 SSM 등 다양한 순환 아키텍처가 실제로 어떤 온라인 학습 목적함수를 암묵적으로 최적화하고 있는지를 재조명하게 하며, 장문맥·지속학습 상황에서 패스트웨이트 메모리의 학습 규칙을 원칙에 입각해 설계하는 데 실용적인 지침을 제공한다.
