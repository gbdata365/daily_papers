Grouped Value Attention: Efficient KV Caching via On-Demand Key Reconstruction

그룹화 값 어텐션: 온디맨드 키 재구성을 통한 효율적 KV 캐싱

Grouped Value Attention(GVA)은 KV 캐시에서 키(key)를 따로 저장하지 않고, 캐시된 값(value)으로부터 학습된 선형 변환을 통해 필요할 때 키를 재구성함으로써, GQA(Grouped-Query Attention) 대비 캐시 저장량을 약 45~47% 줄이면서도 거의 동일한 다운스트림 정확도를 유지하는 어텐션 설계이다.

한 줄 요약

Grouped Value Attention(GVA)은 KV 캐시에서 키(key)를 따로 저장하지 않고, 캐시된 값(value)으로부터 학습된 선형 변환을 통해 필요할 때 키를 재구성함으로써, GQA(Grouped-Query Attention) 대비 캐시 저장량을 약 45~47% 줄이면서도 거의 동일한 다운스트림 정확도를 유지하는 어텐션 설계이다.

배경 및 문제의식

Transformer의 자기회귀적(autoregressive) 디코딩에서는 매 스텝마다 이전 토큰들의 키와 값을 다시 읽어야 하므로 KV 캐시의 메모리 용량과 대역폭이 긴 문맥 서빙의 주요 병목이 된다. 이를 줄이기 위해 GQA는 여러 쿼리 헤드가 하나의 키-값 헤드를 공유하도록 하여 캐시를 줄였지만, 여전히 키와 값 두 스트림을 모두 저장해야 한다. MLA(Multi-head Latent Attention)는 키와 값을 하나의 저차원 잠재 벡터로 압축해 캐시를 더 줄이지만, 추가적인 투영 연산과 더 복잡한 디코딩 경로가 필요하다. 저자들은 "값과 키는 결국 같은 콘텐츠에 대한 서로 다른 표현이므로, 값으로부터 키를 유도할 수 있다"는 가설에서 출발하여, 별도의 콘텐츠 키 캐시 자체를 없애는 방법을 모색한다.

핵심 기여

논문의 기여는 크게 세 가지다. 첫째, 그룹화된 값만을 캐시하고 학습된 선형 사상 K=VM으로 콘텐츠 키를 재구성하는 GVA를 제안하며, 이 사상은 추론 시 쿼리 쪽으로 흡수(absorb)될 수 있어 실제 디코딩 경로에서 키 텐서를 물리적으로 만들 필요가 없다. 둘째, DeepSeek MLA의 방식을 따라 위치 정보를 유지하기 위한 작고 헤드 간 공유되는 분리형(decoupled) RoPE 채널을 도입해, 이 흡수 성질을 깨지 않으면서도 위치 인코딩을 보존한다. 셋째, 350M 파라미터급 모델·FineWeb-Edu 30B 토큰 실험에서 제안 방식(16차원 위치 슬라이스)이 캐시 스칼라 수를 약 45~47% 줄이면서도 5개 벤치마크 평균 정확도 44.35%를 달성해 GQA(44.36%), MLA(43.88%)와 대등한 성능을 보임을 실증했다.

방법론

GVA는 GQA와 동일한 그룹 구조를 사용하되(H개의 쿼리 헤드가 G개의 값 헤드를 공유), 키 프로젝션을 없애고 각 쿼리 헤드마다 하나의 재구성 행렬 Mh를 두어 Kh = V_g(h) * Mh로 콘텐츠 키를 만든다. 처음에는 단순히 K=V로 두는 "Shared KV" 방식을 시도했으나, 하나의 벡터가 스코어링과 값 전달을 동시에 담당해야 해 학습 손실이 GQA 수준으로 수렴하지 않았다. 이에 전용 값을 유지하면서 선형 사상으로 키를 재구성하는 방식으로 전환했다. Mh가 추론 시 고정되어 있으므로 쿼리에 미리 곱해 흡수시킬 수 있어(qtM^T), 콘텐츠 어텐션 스코어링이 값 캐시만으로 계산 가능하다(수식 8). 다만 표준 RoPE를 재구성된 키에 그대로 적용하면 회전 행렬이 쿼리-키 위치 쌍에 의존해 흡수가 깨지므로, 콘텐츠 슬라이스(비회전)와 헤드 간 공유되는 짧은 위치 슬라이스(회전, RoPE 적용)로 쿼리/키를 분리하는 decoupled RoPE 구조를 채택했다. 또한 초기화 시 값의 분산과 폭에 맞춰 M의 초기 스케일을 조정하는 방법(σM = σQ/(σV·√din))을 제시해, 재구성된 키가 초기부터 쿼리와 비슷한 크기를 갖도록 하여 학습 초반의 성능 저하를 방지했다.

실험 설정 및 결과

실험은 약 350M 파라미터의 디코더 전용 Transformer를 FineWeb-Edu 30B 토큰으로 처음부터 학습시키는 방식으로 진행되었으며, 동일한 데이터 순서·토큰 예산·옵티마이저·문맥 길이 하에서 GQA, MLA, 여러 GVA 변형(Shared KV, 기본 GVA, 스케일 매칭 GVA, decoupled RoPE 적용 GVA 등)을 비교했다. 평가는 HellaSwag, WinoGrande, OpenBookQA, ARC-Easy/Challenge의 5개 제로샷 과제에 대해 서로 다른 시드로 3회씩 반복 측정한 평균 정확도로 이루어졌다. 그 결과 Shared KV는 캐시를 정확히 절반으로 줄였지만 손실이 GQA 수준까지 회복되지 않았다. 반면 값-키 분리 재구성을 적용한 GVA는 스케일 매칭 초기화를 적용할 경우 GQA와 비슷한 학습 궤적을 보였고, decoupled RoPE 적용 버전(위치 차원 dr=16)은 평균 정확도 44.35%로 GQA(44.36%)와 0.01%p 차이에 불과했으며 MLA(43.88%)보다 근소하게 높았다. 캐시 크기 측면에서는 GQA 대비 약 45~47%(위치 차원 dr에 따라 47%@dr=16, 45%@dr=24)의 캐시 스칼라 절감이 이론적으로 산출되었다.

한계점

저자들은 스스로 여러 한계를 명시한다. 보고된 45~47% 절감은 "의도된 디코딩 상태"(그룹화된 값 + 공유 위치 키)의 이론적 스칼라 수 계산일 뿐, 실제 서빙 메모리 사용량이나 지연시간, 디코딩 처리량(throughput) 측정치는 아니다. 논문 작성 시점 기준 커스텀 디코딩 커널을 개발 중이며 엔드투엔드 추론 성능 평가는 아직 완료되지 않았고, 오픈소스 공개도 예정 상태로 남아 있다. 또한 모든 비교 실험이 약 350M 파라미터, 단일 데이터 혼합(FineWeb-Edu 30B 토큰), 제한된 문맥 길이라는 한 가지 스케일에서만 수행되어 더 큰 모델이나 더 긴 문맥에서의 일반화는 검증되지 않았다. RoPE 위치 차원 폭(dr)에 대한 체계적인 스윕도 수행되지 않았으며, dr=24 설정은 GQA보다 평균 정확도가 낮게 나왔다. Shared KV는 실패한 초기 시도로, 권장되는 베이스라인이 아니라고 명시하고 있다.

시사점

GVA는 캐시를 압축하기 위해 별도의 저차원 잠재 공간을 학습하는 MLA와 달리, 값 자체를 콘텐츠 상태로 그대로 유지하면서 값에서 키를 선형적으로 유도하는 더 단순한 경로를 제시한다는 점에서 실용적 절충안으로 볼 수 있다. 특히 재구성 사상을 쿼리 쪽으로 흡수시켜 디코딩 시 키를 명시적으로 생성하지 않아도 된다는 아이디어는, 향후 커스텀 커널 구현이 뒷받침될 경우 긴 문맥 서빙에서 메모리 대역폭 병목을 실질적으로 완화할 잠재력이 있다. 다만 현재는 캐시 크기 절감 효과가 이론적 수준에 머물러 있어, 실제 추론 속도·메모리 이득이 검증되기 전까지는 GQA/MLA를 대체하기보다는 유망한 대안 설계로 평가하는 것이 적절해 보인다.
