LLaDA-Image: Building Strong Image Generators with Fully Open Training Recipes

라다이미지: 완전 공개형 학습 레시피로 강력한 이미지 생성기 구축하기

페어드 이미지-텍스트 데이터 없이 이미지 전용 사전학습으로 강력한 시각적 사전지식을 먼저 구축한 뒤, 동결된 diffusion 언어모델 기반 이해 모듈과 결합해 사진급 화질의 생성·편집을 지원하는 완전 공개형 6B 규모 통합 이미지 생성 모델을 제시한다.

한 줄 요약

페어드 이미지-텍스트 데이터 없이 이미지 전용 사전학습으로 강력한 시각적 사전지식을 먼저 구축한 뒤, 동결된 diffusion 언어모델 기반 이해 모듈과 결합해 사진급 화질의 생성·편집을 지원하는 완전 공개형 6B 규모 통합 이미지 생성 모델을 제시한다.

배경 및 문제의식

기존 이미지 생성 파이프라인은 학습 초기부터 캡션이 있는 이미지-텍스트 쌍에 의존하는데, 캡션은 비용이 크고 정보 손실이 있으며 저해상도로 다운샘플링하면 캡션이 언급한 세부사항이 사라질 수 있다. 또한 합성 이미지 위주의 데이터 믹스는 초기 수렴은 빠르지만 장기적인 사실성(realism)을 제한할 수 있다. 오픈소스 모델은 성능뿐 아니라 데이터 예산, 학습 안정성, 배포 효율성까지 함께 달성해야 하는 과제를 안고 있다.

핵심 기여

  • 캡션 없이 이미지 자체에서 조건을 추출하는 이미지 전용 사전학습/중간학습으로 시각적 사전지식을 구축하는 데이터 효율적 레시피 제안
  • dLLM 기반 이해 모듈(LLaDA2.0-Mini)과 단일 스트림 DiT를 연결하는 Residual Query Adapter와 Transformer 커넥터로 이해·생성·편집을 하나의 체크포인트에 통합
  • 파라미터 프리 RMSNorm과 Muon 옵티마이저로 대규모 학습 안정성 확보, TwinFlow 증류로 2~4스텝 고속 추론이 가능한 Turbo 버전 제공
  • 모델 가중치, 학습 코드, 상세 레시피를 모두 공개

방법론

전체 파이프라인은 약 2억 2천만 개의 생성학습 샘플 중 98%가 실제 이미지로 구성되며, 90% 이상이 이미지 전용(캡션 없는) 데이터다. 256² 해상도의 이미지 전용 사전학습에서는 SigLIP-VQ로 추출한 이미지 패치 특징을 일부 마스킹해 조건으로 사용하고, flow matching 목적함수로 디퓨전 트랜스포머(DiT)를 학습시켜 사소한 항등 매핑을 방지한다. 이후 512² 해상도로 이미지 전용 중간학습을 거치고, 페어드 이미지-텍스트 데이터를 이용한 지도 미세조정(SFT)에서 512²→1024²로 점진적으로 해상도를 높이며, 텍스트 및 인물 중심 데이터 비중을 늘려 텍스트 렌더링과 인물 생성 품질을 강화한다. 편집 작업에서는 참조 이미지가 이해 모듈(VLM)을 우회해 SigLIP-VQ 의미 특징과 깨끗한 VAE 잠재값 형태로 DiT에 직접 주입되어, 편집되지 않아야 할 영역의 정체성·구조·질감을 보존한다. 최종적으로 TwinFlow 기반 증류를 통해 2~4스텝만으로 추론 가능한 Turbo 버전을 생성한다.

실험 설정 및 결과

Qwen-Image-Bench에서 LLaDA-Image는 영어 트랙 53.53점, 중국어 트랙 53.38점을 기록하며 두 트랙 모두 오픈소스 모델 중 최고 성능(SOTA)을 달성했다. LongText-Bench, CVTG-2K, GEdit-Bench 등에서도 균형 잡힌 중-영 텍스트 렌더링과 경쟁력 있는 지시 기반 편집 성능을 보였다. 논문은 실제 이미지 비중이 높은(합성 데이터 위주보다 느리게 수렴하지만) 학습 레시피가 최종적으로 더 높은 사실성과 성능 상한을 제공한다고 보고한다.

한계점

논문에 명시되지 않음 (본문에서는 모든 설계 선택이 보편적으로 최적이라 주장하지 않으며, 모든 아키텍처·데이터 믹스에 대한 총망라적 비교는 시도하지 않았다고 밝힘).

시사점

대규모 페어드 캡션 데이터 없이도 이미지 전용 데이터만으로 강력한 시각 생성 사전지식을 구축할 수 있음을 보여주며, 완전히 공개된 데이터/모델/학습 레시피를 통해 통합 생성-편집 모델 연구의 재현성과 후속 연구 기반을 제공한다.
