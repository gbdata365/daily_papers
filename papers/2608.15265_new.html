VibeWorlding: Can Multimodal Agents Construct 3D Open Worlds End-to-End?

바이브월딩: 멀티모달 에이전트는 3D 오픈월드를 처음부터 끝까지 구성할 수 있는가?

사용자 쿼리로부터 3D 오픈월드를 처음부터 끝까지(end-to-end) 구성하는 "vibe worlding" 에이전트를 벤치마킹·학습시키는 통합 프레임워크(벤치마크 + RL 훈련 짐)를 제안하고, RL 후처리로 오픈소스 MLLM이 최고 수준 폐쇄형 모델을 능가할 수 있음을 보였다.

한 줄 요약

사용자 쿼리로부터 3D 오픈월드를 처음부터 끝까지(end-to-end) 구성하는 "vibe worlding" 에이전트를 벤치마킹·학습시키는 통합 프레임워크(벤치마크 + RL 훈련 짐)를 제안하고, RL 후처리로 오픈소스 MLLM이 최고 수준 폐쇄형 모델을 능가할 수 있음을 보였다.

배경 및 문제의식

  • 기존 3D 월드 구성 연구는 이상적이고 단순한 쿼리에서만 평가되어, 에이전트가 사용자 의도 파악·3D 도구 사용·시각/텍스트 정보 추론을 실제로 얼마나 잘 하는지 체계적으로 비교하기 어려웠음.
  • 기존 프레임워크는 대부분 비공개(closed-source)라 학습(특히 에이전틱 RL) 효과를 검증할 공개 인프라가 없었음.
  • 두 가지 근본적 난제: (1) 고품질·물리적으로 일관된 3D 에셋과 조작 도구가 파편화되어 통합 샌드박스가 부재, (2) 물리적 타당성(충돌 없음, 높이)과 사용자 의도 충족을 동시에 검증하기 어려움.

핵심 기여

  1. VWE-Bench: 2,616개 고품질 3D 에셋, 323개 인간 주석 시드 3D 월드, 6,828개 역합성(reverse-synthesized) 멀티모달 쿼리로 구성된 벤치마크(검증 가능 쿼리 1,710개 + 검증 불가 쿼리 5,118개)
  2. VibeWorlding-Gym: 에셋 검색/편집/렌더링을 MCP 도구로 통합한 샌드박스 + 물리적 타당성과 의도 충족을 함께 검증하는 이중 제약(dual-constraint) 검증기 + SFT/RL 통합 학습 파이프라인
  3. 6가지 능력 분석: 충돌 회피, 높이 적합성, 생태적 타당성, 3D 이해, 3D 추론, 검색 적합성으로 세분화해 병목 지점 규명
  4. SOTA 결과: VibeWorlder-8B(Qwen3-VL-8B 기반 RL 후학습)가 Gemini 3.1-pro와 동급, 플래그십 VibeWorlder-30B-A3B가 GPT-5.5·Qwen3.8-Max를 능가하는 전체 최고 Pass@1 달성

방법론

  • 태스크 정의: 멀티모달 쿼리(텍스트만 or 기존 월드+수정 지시) → 에이전트가 5개 3D 도구(asset_retrieve/add/rotate/translate/delete)를 여러 턴에 걸쳐 호출 → 최종 3D 월드(텍스트 맵 + 5개 시점 렌더 이미지) 산출
  • 벤치마크 구축: 아티스트-MLLM 협업 3단계 파이프라인 — 에셋 합성(Gemini 이미지 생성 → Hunyuan3D 3.1로 3D 메시화 → 필터링) → 시드 월드 주석 → 역방향 쿼리 합성(테마만/테마+요소/전체 청사진/방해 쿼리, 그리고 정밀/모호 편집·씬 비평/유도/재진술/복합 설명)
  • 검증기: 물리적 타당성(충돌·높이, 파이썬 기하 검사) → 통과 시 의도 충족(생태적 타당성/3D 이해/3D 추론/검색 적합성, MLLM 심판)을 순차 적용
  • 학습: Gemini 3.1-pro로 콜드스타트 SFT 궤적 합성 → GRPO 기반 멀티모달 RL(텍스트 전용 구성 쿼리 + 멀티모달 수정 쿼리를 함께 학습), outcome-based 이진/연속 보상

실험 설정 및 결과

  • 8B~2.8T 규모의 프론티어 MLLM(GPT-5.5, Gemini 3.1-pro/3.5-flash, Claude-Opus-4.8, Kimi-K3, Qwen3.8-Max)과 3개 기존 에이전트 스캐폴드(SceneWeaver, SAGE, SceneAssistant), 오픈소스 백본(Qwen3-VL-8B/30B-A3B) 비교
  • 주요 결과: 최강 프론티어 모델도 전체 Pass@1 60% 미만(p.9). Qwen3-VL-8B/30B-A3B는 각 5.3%/13.6%에 불과했으나, SFT+RL 후 각각 41.4%/59.3%로 상승 — VibeWorlder-30B-A3B가 GPT-5.5(57.3%), Qwen3.8-Max(56.9%)를 능가하는 전체 1위 달성 (p.9-10, Table 4)
  • 병목 지점: 6가지 능력 중 "충돌 회피(collision)"가 RL 후에도 59-68%로 가장 취약. 반면 3D 추론은 RL로 6-20% → 56-85%까지 크게 개선 (p.10, Figure 5)
  • SFT vs RL 역할 분리: SFT는 물리/생태적 기초 역량과 3D 이해(0.02→0.17)에 기여, RL은 3D 이해(0.17→0.80)와 3D 추론(0.04→0.69)을 실질적으로 끌어올림 (p.11)
  • 검증-불가(unverified) 쿼리는 MLLM 심판 기반이라 RL 보상이 상대적으로 불안정 — 검증 신뢰도가 RL 개선폭을 제한
  • 자동-인간 평가 일치도: 시스템 수준 Spearman ρ=0.88로 높은 상관 확인 (p.9)
  • 실패 사례 분석(p.12): (1) 부정확한 3D 거리 편집(방향 반전 등 좌표계 오해), (2) 오버에디팅(요청하지 않은 삭제 등 범위 위반)이 주요 실패 패턴

한계점 (저자 명시, p.14-15)

  • 도구 세트가 최소 단위(원자적) 조작에 그쳐, 축구장 생성·숲 산포 같은 고수준·재사용 가능한 "스킬"이 부재
  • 최대 규모 시드 월드가 258개 에셋에 그쳐, 진정한 대규모 오픈월드 구성에는 한계
  • 보상이 궤적 전체에 대한 outcome-based sparse reward라 장기 호라이즌 학습에 비효율적일 수 있음(턴별 크레딧 할당 필요)
  • 데이터가 Tencent 내부 크라우드소싱 기반이며 카툰 아트 스타일에 한정, 이미지-투-3D/비디오-투-3D 등 멀티모달 입력 형태는 미포함
  • 근본적으로 에이전트의 3D 공간 추론(거리·각도 관계) 능력이 아직 부족함이 재확인됨

시사점

  • "정밀하게 검증 가능한 보상(verifiable reward)"이 있는 태스크일수록 RL 후학습 효과가 크고 안정적이라는 점은, 유사한 도구-사용/장기 호라이즌 에이전트 설계 시 참고할 만한 원칙임(가능하면 규칙 기반 검증 신호를 확보하라는 시사점)
  • 공개된 MCP 기반 샌드박스·검증기·데이터셋은 3D 에이전트 연구뿐 아니라, "도구 호출 + 멀티모달 피드백 루프" 패턴을 요구하는 다른 에이전틱 RL 연구에도 재사용 가능한 참고 아키텍처로 볼 수 있음
