AutoGUIWorld: Image Generators as Visual World Models for GUI Agent

오토지유아이월드: GUI 에이전트를 위한 이미지 생성 모델 기반 시각적 세계 모델

소프트웨어를 실제로 설치·실행하지 않고도, 사전학습된 이미지 생성 모델(Image2)을 GUI의 시각적 세계 모델로 활용해 플래너가 지정한 행동에 따라 화면 전이를 합성함으로써 GUI 에이전트 학습용 궤적 데이터를 대량 생성하는 프레임워크 AutoGUIWorld를 제안한다.

한 줄 요약

소프트웨어를 실제로 설치·실행하지 않고도, 사전학습된 이미지 생성 모델(Image2)을 GUI의 시각적 세계 모델로 활용해 플래너가 지정한 행동에 따라 화면 전이를 합성함으로써 GUI 에이전트 학습용 궤적 데이터를 대량 생성하는 프레임워크 AutoGUIWorld를 제안한다.

배경 및 문제의식

GUI 에이전트는 스크린샷, 마우스/키보드 입력을 통해 소프트웨어 작업을 자동화하는데, 이를 잘 학습하려면 행동이 화면 상태를 어떻게 바꾸는지, 무엇이 유지되고 무엇이 변화하는지를 보여주는 고품질 상호작용 궤적이 필요하다. 그러나 이러한 궤적의 다양성은 실제로 수집 가능한 환경(접근 가능한 애플리케이션, 인터페이스 상태, 워크플로우)의 범위에 제약된다. 특히 과학·CAD·전자설계 소프트웨어처럼 특수한 상태와 연산을 요구하는 분야는 설치·설정·라이선스 등 비용이 크다. 기존 방법들(사람 시연, 자동 탐색, 튜토리얼/영상 추출)은 모두 실행 가능한 환경이나 기존 기록에 범위가 묶여 있다는 한계가 있다. 저자들은 사전학습된 이미지 생성 모델이 가진 시각적 사전지식을 활용하면 소프트웨어를 구동하지 않고도 훈련 경험을 생성할 수 있을 것이라는 가설에서 출발했으며, 이를 위해서는 생성된 화면이 (1) 의도한 행동 결과를 충실히 반영하고 (2) 이전 맥락(배경 문서, 무관한 내용 등)을 보존해야 한다는 두 가지 요건을 제시한다.

핵심 기여

  • 환경 비의존적 GUI 궤적 생성: 과업 계획(planning)과 이미지 생성(image generation)을 결합해, 대응하는 소프트웨어를 배포·실행하지 않고도 스크린샷-행동-스크린샷 형태의 궤적을 합성.
  • 대규모 정제 데이터셋 구축: Ubuntu, Windows, macOS, Chrome 네 가지 환경에 걸쳐 공간적으로 주석된(grounded) 79,266개의 스텝 단위 학습 샘플을 구축하고, 그 커버리지와 전이(transition) 결함을 분석.
  • 실제 환경으로의 전이 입증: Qwen3.5-35B-A3B를 이 데이터로 파인튜닝하여 OSWorld(33.0%→40.8%), Windows Agent Arena, macOSWorld, ScienceBoard(14.0%→32.2%) 등 네 벤치마크 전부에서 성능 향상을 확인.

방법론

AutoGUIWorld는 GUI 상호작용을 부분관측 마르코프결정과정(POMDP)으로 정식화하고, 에이전트가 실제 잠재 상태(s_t)가 아니라 화면 수준의 시각적 관측(관측-행동 전이 분포 P)만을 사용한다는 점에 착안해, 이 관측 수준 전이 분포 자체를 시각적 세계 모델로 직접 모델링한다("interaction fidelity" 개념). 전체 파이프라인은 다음 단계로 구성된다.

  1. GUI 월드 샘플링 공간: OS 기반(운영체제 종류, 화면 해상도, 행동 공간, UI 관례, 앱 생태계), 시각적 외형(테마, 색상, 배경화면, 타이포그래피 등), 초기 GUI 상태(창/탭 개수, 레이아웃, 앱/페이지 콘텐츠 등) 세 요소로 구조화된 공간에서 초기 상태를 샘플링한다.
  2. 시드 실현(Seed Realization): 샘플링된 구조적 상태를 상세한 시각 묘사로 변환하고, 이미지 생성 모델(Image2)이 이를 렌더링해 초기 스크린샷을 만든다.
  3. 시드 조건부 과업 생성: 고정된 시드(화면)에 맞춰 수행 가능한 구체적 과업 지시문을 생성한다.
  4. 플래너 기반 궤적 롤아웃: 메타 플래너(Meta Planner)가 과업과 시드로부터 원자적 행동 시퀀스와 각 행동의 "의도된 시각적 변화"를 미리 계획한다. 이후 Voyager라는 에이전트가 현재 스크린샷, 계획된 행동, 롤아웃 맥락을 바탕으로 1인칭 사고, 행동 요약, 렌더링 프롬프트를 생성하면, Image2가 이 프롬프트로 현재 화면을 이미지 편집(image-to-image)해 다음 깨끗한 화면을 생성한다. 이 과정이 반복되며 시간적으로 일관된 궤적이 만들어진다.
  5. 행동 타겟 주석: 클릭 등 포인팅 행동에 대해 LocateAnything으로 대상 요소의 좌표를 찾아 공간적 레이블(스폿)을 부여한다.
  6. 학습 인스턴스 구성: 각 궤적을 (이전 화면, 과업 지시, 이력) → (계획된 행동, 좌표) 형태의 단일 스텝 지도학습 샘플로 변환한다.

실험 설정 및 결과

데이터 특성 분석: Qwen 임베딩 기반 MMD(최대평균불일치) 분석 결과, 합성 데이터와 실제 데이터(ScaleCUA) 간 거리 비율(ρ)이 0.59~1.24로, 독립적으로 수집된 실제 데이터셋들 간 변동 폭과 비슷한 수준임을 보였다(Web·Ubuntu는 실제 교차-소스 중앙값보다 14~24% 높았고, macOS·Windows는 더 낮았음). C2ST(분류기 기반 two-sample test)는 합성-실제 쌍을 거의 완벽히(AUC≈1.00) 구별했으나, 이는 실제 데이터셋들 간에도 나타나는 소스 특이적 신호였다. OmniParser 기반 UI 탐지에서는 합성 데이터가 ScaleCUA보다 12개 도메인-임계값 조합 전부에서 더 넓은 인터페이스 커버리지를 보였다.

실제 환경 전이 평가: Qwen3.5-35B-A3B를 AutoGUIWorld 데이터(약 8만 샘플)로 파인튜닝한 AGW-35B 모델을 5개 벤치마크에서 평가했다. - OSWorld: 평균 과업 점수 33.0% → 40.8% (+7.8pt) - Windows Agent Arena: 19.4% → 27.9% (+8.5pt) - macOSWorld: 28.1% → 45.0% (+16.9pt) - ScienceBoard: 14.0% → 32.2% (+18.2pt), 특히 KAlgebra가 6.5%→48.4%로 크게 개선 - ScreenSpot-Pro(전문 인터페이스 그라운딩): 전체 정확도 31.7%→57.1% (+25.4pt)

특히 35개 세부 과업 도메인 중 25개가 개선, 7개는 변화 없음, 3개(예: Chrome 관련 일부 과업)는 오히려 하락했다. 동일하게 Qwen3.5-35B-A3B에서 출발했지만 사람이 시연한 실제 데이터 35만 건으로 학습한 AgentNet 비교군보다, AGW-35B(합성 데이터 8만 건)가 네 벤치마크 전부에서 더 높은 성능을 보였다(ScienceBoard에서 32.2% vs 16.8%로 격차가 가장 큼).

한계점

저자들이 명시한 한계는 다음과 같다. Image2가 시각적으로는 그럴듯하지만 실제 행동 결과를 충실히 반영하지 못하는 화면을 생성할 수 있다. 42,526개의 평가 가능한 데스크톱 전이 중 VLM 감사(audit)로 1,293건(3.04%)의 행동-이미지 불일치가 발견되었고, 잘못된 행동/부재 타겟/오탐 그라운딩을 제거한 뒤에도 39,351건 중 818건(2.08%)이 여전히 불일치했다. 오류는 텍스트 입력, 드래그, 스크롤, 키보드 상호작용에 집중되었으며, 명령 대체, 가상의 문서 내용 생성, 조기 서식 적용, 행동 효과 누락, 의도치 않은 영구적 콘텐츠 변경 등의 형태로 나타났다. 이 때문에 전이 수준의 품질 관리(필터링)가 추가로 필요했다. 또한 궤적이 길어지고 상호작용이 복잡해질수록 생성 오류가 누적되어 환각적 인터페이스 상태가 나타날 수 있다는 점, Chrome 등 일부 도메인에서는 학습 후 오히려 성능이 하락한 점도 한계로 언급된다.

시사점

사전학습된 이미지 생성 모델이 단순한 이미지 합성 도구를 넘어, 행동 조건부 "시각적 세계 모델"로서 실제 소프트웨어를 구동하지 않고도 유의미한 GUI 에이전트 학습 데이터를 만들어낼 수 있음을 보여준다. 이는 특히 설치·설정 비용이 큰 전문/과학 소프트웨어 영역에서 데이터 수집 장벽을 낮출 수 있는 잠재력을 시사하며, 저자들은 향후 특정 도메인에 특화된(domain-specific) 수직적 GUI 세계 모델을 학습시켜 장기 궤적의 일관성을 높이는 방향을 향후 과제로 제안한다.
