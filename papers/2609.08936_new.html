AuK Technical Report: An Open-Source Foundational Model for Speech Generation and Editing

AuK 기술 보고서: 음성 생성과 편집을 위한 오픈소스 파운데이션 모델

한 줄 요약

자연어 지시문과 오디오 컨텍스트라는 하나의 인터페이스로 음성 생성과 다섯 가지 편집(음향·파라링구얼·콘텐츠·향상/분리) 작업을 통합한 오픈소스 파운데이션 모델 AuK와, 이를 4단계 추론으로 4.5배 가속한 경량 버전 AuK-Flash를 제시한 기술 보고서.

배경 및 문제의식

최근 음성 생성 기술은 제로샷 보이스 클로닝, 지시문 기반 합성, 유연한 음성 편집으로 각각 발전해왔지만, 실제 사용자는 이런 기능들을 따로따로가 아니라 한 번의 요청 안에서 함께 요구하는 경우가 많다(예: 특정 스타일로 합성하면서 일부 단어를 교체하거나 감정을 바꾸는 식). 작업별로 별도 모델을 두면 사용자 경험이 파편화되고 개발 비용도 커진다. 그러나 이를 하나의 모델로 통합하기는 어렵다. ① 생성은 새로운 음성을 만들지만 편집은 원본의 특정 부분만 바꿔야 하는 등 출력 제약이 작업마다 다르고, ② 어떤 작업은 텍스트만으로 조건화되고 어떤 작업은 텍스트와 참조 오디오를 함께 조건화해야 하는 등 입력 방식이 다르며, ③ 생성은 인식 정확도·화자 유사도 같은 정량 지표로 평가 가능하지만, 편집은 자연스러움·변형 정도·맥락 적합성 같은 주관적 판단에 의존해 평가와 지도학습 신호를 구성하기가 훨씬 어렵다.

핵심 기여

  • 자연어 지시문과 (선택적) 오디오 컨텍스트를 목표 파형으로 매핑하는 단일 인터페이스로 음성 생성, 음향 편집, 파라링구얼 편집, 콘텐츠 편집, 향상/분리라는 5개 작업군을 통합.
  • 약 30.3억 개의 지시문-오디오 인스턴스, 195만 시간 분량의 유효 학습 데이터를 구축하는 대규모 데이터 파이프라인 설계.
  • 멀티모달 LLM 기반 시맨틱 조건화, 음성·오디오·음악에 공동 학습된 VAE 기반 음향 조건화, 이중 스트림 MMDiT와 단일 스트림 DiT를 결합한 하이브리드 rectified-flow 트랜스포머 아키텍처.
  • 생성 전용 웜업 → 생성-편집 결합 사전학습 → (편집용) 인간 선호 기반 preference optimization과 (생성용) 보상 기반 강화학습으로 이어지는 단계적 학습 커리큘럼.
  • consistency distillation과 task-routed Decoupled DMD를 결합해 4단계, classifier-free guidance 없는 추론으로 4.5배 가속한 AuK-Flash 제안.
  • 소스 코드와 모델 가중치를 모두 공개하여 재현성과 후속 연구를 지원.

방법론

AuK는 세 가지 구성 요소로 이루어진다. (1) MLLM(Qwen2.5-Omni)이 텍스트 지시문과 참조 오디오를 함께 처리해 레이어별 hidden state를 학습 가능한 가중합으로 결합한 "시맨틱 조건"을 생성한다. (2) 음성·범용 오디오·음악에 공동 학습된 VAE가 24kHz 파형을 64차원, 50Hz 잠재 공간으로 인코딩해 참조 오디오 조건과 파형 복원에 공통으로 사용되는 잠재 공간을 제공한다. (3) FLUX 스타일의 하이브리드 트랜스포머 백본이 먼저 이중 스트림 MMDiT 블록으로 시맨틱-음향 스트림 간 정보를 교환한 뒤, 단일 스트림 DiT 블록으로 융합된 시퀀스를 정제해 rectified-flow 속도를 예측한다. 참조 오디오가 있는 작업(제로샷 TTS, 콘텐츠 편집, 향상/분리)과 없는 작업(지시문 기반 TTS)을 구조적으로 구분해 처리한다.

학습은 생성 전용 워밍업(5만 스텝) 이후 생성과 편집을 함께 다루는 결합 사전학습(60만 스텝)으로 이어진다. 이 단계에서는 계층적 조건 드롭아웃으로 classifier-free guidance를 지원하고, 제로샷 TTS의 참조 오디오 길이 편차에 대비해 참조 구간을 랜덤하게 자르는 증강을 적용한다. 사후학습은 두 갈래로 나뉜다. 편집 과제는 정답이 열려 있어 기존 보상 모델이 없으므로, 후보 출력에 대해 사람이 3단계 등급(실패/부분 성공/성공)을 매긴 데이터를 모아 Diffusion-DPO 방식의 flow 기반 선호 점수와 LiPO의 listwise 목적함수로 최적화한다. 생성 과제는 Flow-GRPO를 적용해 ASR 기반 콘텐츠 정확도, 화자 유사도, 스타일 일치도(전용 멀티모달 판별 모델)를 보상으로 사용하는 강화학습으로 개선한다. 마지막으로 consistency distillation으로 few-step 초기화를 만들고, 이어 Decoupled DMD(및 adaptive projected guidance)로 분포를 정합시키되, 다중화자/보컬 분리 과제만 별도의 supervised clean-latent 목표로 라우팅해 분리 능력 저하를 방지하는 "task-routed Decoupled DMD"로 4단계, CFG-불필요 경량 모델 AuK-Flash를 얻는다.

실험 설정 및 결과

평가는 VAE 복원 품질, 음성 생성, 음성 편집, 향상/분리라는 세 축에서 이루어졌다. Seed-TTS-Eval(영어/중국어/중국어-hard) 기준 AuK는 WER 평균 2.65, SIM 0.795로 Qwen3-TTS, Seed-TTS, VoxCPM2 등 기존 최고 성능 모델들을 능가했고, InstructTTSEval에서도 지시문 스타일 일치도(ACC)가 경쟁 모델과 비슷하거나 더 나은 수준을 보였다. 일반 음성 편집 벤치마크(MMAE-Speech, SpeechEditBench, Ming-Freeform-Audio-Edit)에서도 EMR·ACC·WER 등 대부분의 지표에서 Step-Audio-EditX, Ming-UniAudio 같은 기존 편집 특화 모델을 앞섰다. 신호 수준 복원 과제(DNS Challenge, CHiME-4, Libri2Mix, VCTKSR 등 향상/분리/초해상)에서는 DNSMOS, UTMOS, WER, SIM 지표상 전용 특화 모델들과 경쟁력 있는 수준을 유지했다(항상 최고는 아니지만 대체로 상위권). VAE 자체 재구성 품질도 음성/오디오/음악 세 도메인 모두에서 비교 대상 VAE들보다 PESQ, STOI, Mel Distance 등에서 우수했다. 가속 모델 AuK-Flash는 4단계 추론으로 원본 대비 4.5배 빠르면서도 대부분의 벤치마크에서 원본 AuK와 근접하거나 지각 품질 지표(UTMOS 등)에서 오히려 더 나은 결과를 보였다.

또한 저자들은 부수적인 관찰로 (1) 같은 화자의 서로 다른 발화를 프롬프트-타깃으로 사용하는 cross-utterance 학습이 표현력과 화자 유사도를 높이고 transcript-free 인터페이스를 가능하게 했다는 점, (2) 위스퍼 변환이나 억양 제거처럼 편집 데이터로만 학습한 능력이 생성이나 다른 언어(영어 억양 제거 등)로 전이되는 현상을 관찰했다고 보고한다.

한계점

논문은 자유형식 사용자 요청을 모델이 스스로 이해해 처리하는 능력이 아직 불완전하다고 명시한다. Audio-Oscar 기반의 에이전트형 데이터 파이프라인으로 자유형식 편집 지시문 데이터를 늘려봤지만 임의 요청에 대한 견고한 일반화로 이어지지 않았고, 실제로는 별도의 Prompt Enhancer가 작업 종류를 식별하고 파라미터를 정규화하며 요청을 학습 분포에 맞게 재작성해야 모델의 성능 한계에 도달할 수 있었다. 즉 "능력을 보유하는 것"과 "제약 없는 언어로 그 능력을 안정적으로 호출하는 것" 사이에 간극이 남아 있으며, 이는 이미지·비디오·오디오-비주얼 생성 시스템에서도 공통적으로 관찰되는 문제라고 저자들은 지적한다. 또한 신호 수준 향상/분리 과제에서는 항상 최고 성능이 아니라 "경쟁력 있는" 수준에 머무는 경우가 있다.

시사점

AuK는 생성과 편집을 하나의 조건화 인터페이스와 백본으로 통합하면서도 각 작업군의 서로 다른 지도학습·평가 요구(정량적 자동 보상 vs. 사람 선호 기반 학습)에 맞춘 이원화된 post-training 전략을 제시함으로써, 이질적인 오디오 처리 작업들을 하나의 파운데이션 모델로 묶는 실용적 청사진을 보여준다. 특히 사람이 매긴 3단계 등급을 flow-matching 기반 DPO/LiPO로 결합한 방식과, 특정 작업(분리)만 별도 손실로 라우팅해 지식 증류 시 성능 저하를 막는 task-routed Decoupled DMD는 다른 통합 생성 모델의 경량화·가속화에도 응용 가능한 일반적 기법으로 평가할 수 있다. 코드와 가중치 공개는 통합 음성 생성-편집 연구의 재현성과 후속 벤치마킹에 기여할 것으로 보인다.
