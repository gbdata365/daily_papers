EvoMemState: Evolving Memory State for Personal Agents

에보멤스테이트: 개인 에이전트를 위한 진화형 메모리 상태

한 줄 요약

개인화 LLM 에이전트의 장기 기억을 개별 사실(fact)이 아니라 "사실 간 관계"와 "현재 요청에 대한 적용 방식"까지 함께 상태(state)로 관리하도록 설계한 상태 중심(state-centric) 메모리 프레임워크.

배경 및 문제의식

기존 장기 기억 시스템(MemGPT, MemoryBank, Mem0, LightMem 등)은 사실 중심(fact-centric) 패러다임을 따라 사실을 추출·저장·갱신·검색하는 데 집중한다. 그러나 새로운 사실이 기존 사실을 갱신, 제약, 또는 모순시키는 관계를 개별 기록만으로는 포착하기 어렵고, 설사 관련 기억을 모두 검색하더라도 에이전트가 해당 기억을 현재 요청에 얼마나, 어떻게 적용해야 할지는 암묵적으로 남는다. 저자들은 예비 실험을 통해 (1) 기존 시스템 다수가 관련 기억을 함께 검색하지 못하며(최대 61.8% 불완전 검색), (2) 모든 관련 기억이 검색되어도 단순 자기성찰(self-reflection) 프롬프트만으로는 정답률이 오히려 떨어짐(평균 50.5%→48.9%)을 확인하며 문제를 구체화한다.

핵심 기여

  • 기존 사실 중심 메모리의 한계(관계 정보 부재, 완전 검색이 적절한 활용을 보장하지 않음)를 실증적으로 규명
  • Persistent Facts(불변 원본 사실), Relational States(사실 간 유효성·범위·관계), Reasoning State(현재 요청에 대한 적용성·역할·우선순위)라는 세 가지 요소로 개인 기억을 표현하는 EvoMemState 프레임워크 제안
  • Ontology-Guided Memory State Induction, RL-Based State Evolution, State-Aware Reasoning의 3단계로 이를 구현
  • MemSyco-Bench, MemTrapBench, LoCoMo, LoCoMo-Refined 네 개 벤치마크에서 기존 메모리 시스템 대비 검색 완전성과 메모리 근거 응답 정확도에서 일관된 개선을 입증

방법론

1) Ontology-Guided Memory State Induction: 대화 이력에서 시간순 Persistent Facts를 추출하고, 이를 빈 온톨로지에 순차적으로 통합(Induce)하여 개념 계층(PARENT_OF, CONTAINS)과 사실 간 관계(SUPERSEDES=갱신, CONFLICTS_WITH=미해결 모순)로 구성된 개인 기억 온톨로지를 점진적으로 구축한다. 각 사실의 Relational State는 현재 유효성(validity)·범위(scope)·관계(relation) 정보를 담되, 원본 사실 자체는 덮어쓰지 않고 보존한다. 2) RL-Based State Evolution: 요청 q, 관련 사실, Relational State를 입력받아 요청별 Reasoning State(적용성·역할·우선순위)를 생성하는 정책 π_θ를 GRPO(Group Relative Policy Optimization)로 학습한다. 보상은 동일 메모리 증거를 받은 고정된(frozen) 개인 에이전트가 Reasoning State를 사용했을 때와 사용하지 않았을 때의 정답 점수 차이로 정의되며, 여러 후보 Reasoning State를 샘플링해 상대적 우위(advantage)를 계산한다. 3) State-Aware Reasoning: 추론 시 요청과 의미적으로 유사한 K개의 Persistent Facts를 시드로 검색한 뒤, 저장된 관계를 양방향으로 순회(Traverse)하여 갱신·모순·제약으로 연결된 사실까지 확장 수집한다. 학습된 정책이 이 증거로부터 Reasoning State를 생성하고, 개인 에이전트는 사실·Relational State·Reasoning State를 모두 활용해 최종 응답을 생성한다.

실험 설정 및 결과

Qwen3-8B와 GPT-4o-mini를 응답 모델로, MemSyco-Bench·MemTrapBench(메모리 활용 양상 평가)와 LoCoMo·LoCoMo-Refined(장기 대화 회상 평가) 네 벤치마크에서 NaiveRAG, MemGPT, MemoryBank, Mem0, A-MEM, LightMem, Supermemory, SimpleMem, PGMem 등 9개 베이스라인과 비교했다. EvoMemState는 MemSyco-Bench에서 두 백본 모두 최고 정확도(57.6%, 58.9%)를 기록해 최강 베이스라인을 각각 12.2%p, 5.9%p 앞섰고, When/How to Use 정확도 최고, Syco. Rate(부적절한 과거 기억 의존) 최저, Correct Use 최고를 달성했다. LoCoMo-Refined에서도 LLM-judge·토큰 F1 점수 모두 최고(최강 베이스라인 대비 +6.1%, +7.0%)였으며, 완전 검색 비율(85.6%)과 완전 증거 확보 시 정확도(Acc@complete, LoCoMo-Refined 70.8%/MemSyco-Bench 68.5%)에서도 베이스라인 대비 각각 11.5%p, 31.2%p 앞섰다. 제거 실험(ablation)에서는 Relational State 제거 시 MemSyco-Bench·MemTrapBench 점수가 각각 8.9%, 6.4% 하락했고, RL 기반 상태 진화를 제거(규칙 생성만 유지)해도 유사한 폭(7.9%, 16.4%)으로 하락해 두 구성요소 모두 핵심적임을 보였다. 또한 학습된 정책을 다른 메모리 시스템(NaiveRAG, Mem0, A-MEM, MemoryBank 등)에 결합해도 평균 0.2~4.9%p의 일관된 성능 향상이 전이됨을 확인했다.

한계점

연구는 텍스트 기반 상호작용 이력에만 초점을 맞추고 있으며, 문서·이미지 등 실제 개인 기억 시스템이 다뤄야 할 멀티모달 정보는 다루지 않는다. 멀티모달 정보를 표현·연결·활용하도록 기억 구조를 확장하는 것은 향후 과제로 남겨두었다.

시사점

개별 사실의 정확한 저장·검색만으로는 개인화 에이전트의 신뢰할 수 있는 기억 활용을 보장할 수 없으며, 사실 간 관계(갱신·모순·제약)를 명시적으로 모델링하고 메모리 활용 경험 자체를 강화학습으로 내재화하는 것이 응답 품질 향상에 중요하다는 점을 시사한다. 이는 향후 장기 메모리 기반 개인 비서·에이전트 설계에서 검색 완전성(retrieval completeness)과 사용 적절성(use appropriateness)을 분리해 다루어야 함을 보여주는 사례로 볼 수 있다.
