SAGE: Mitigating Long-Horizon Reasoning Biases via Topological Guidance

세이지: 토폴로지 가이던스를 통한 장기 추론 편향 완화

희소 보상 환경에서 LLM의 장기 추론이 실패하는 원인을 "탐색 편향"과 "복합 편향" 두 가지로 이론적으로 규명하고, 대수적 희소화와 쌍곡(hyperbolic) 구조 가이던스를 결합한 SAGE 프레임워크로 이를 완화해, Andrews-Curtis 문제 등에서 최대 8배의 성능 향상을 달성한다.

한 줄 요약

희소 보상 환경에서 LLM의 장기 추론이 실패하는 원인을 "탐색 편향"과 "복합 편향" 두 가지로 이론적으로 규명하고, 대수적 희소화와 쌍곡(hyperbolic) 구조 가이던스를 결합한 SAGE 프레임워크로 이를 완화해, Andrews-Curtis 문제 등에서 최대 8배의 성능 향상을 달성한다.

배경 및 문제의식

장기 추론에서는 성공적인 경로가 도달 가능한 공간 중 극히 일부만 차지하는 반면, 국소적으로는 그럴듯하지만 구조적으로 불안정한 가지가 훨씬 많다(탐색 편향). 또한 보상이 경로 끝에서만 주어지는 희소 보상 환경에서는 초반의 작은 국소적 일탈이 깊이가 깊어질수록 누적되어 희귀한 보상을 억눌러버린다(복합 편향). 기존 완화책은 각각 하나의 축만 다뤘다: 밀집한 단계별 검증(과정 감독)은 확장하기에 구조적으로 비싸고, 보조 휴리스틱을 더한 강화학습은 추론 공간의 구조 자체를 모델링하지 않는다.

핵심 기여

  • 기호적 폐쇄 분석(Symbolic Closure Analysis, SCA): 분기 구조와 희소 보상이 어떻게 두 편향을 유발하는지를 국소 허용성(local admissibility) 관점에서 특성화하는 이론적 틀 제시.
  • SAGE(구조적 허용성 기반 탐색) 프레임워크: 국소적으로 허용 가능한 후보들을 연산자 인덱스 대수 부분공간에 투영해 잘못된 분기를 억제하는 대수적 희소화(탐색 편향 완화)와, 추론 상태를 음의 곡률 쌍곡 공간에 임베딩해 깊이별 조밀한 신호를 제공하는 쌍곡 구조 가이던스(복합 편향 완화)를 결합.
  • 12개 벤치마크, 7개 모델군에 걸친 광범위한 검증과, 실제 오픈 문제인 Andrews-Curtis(AC) 사소화 과제에서 최대 8배 성능 향상 실증.

방법론

추론을 국소 허용성 술어 Adm_S를 가진 기호 인터페이스 위의 순차적 의사결정 과정(유한지평 MDP)으로 정식화한다. 구조적 복잡도(도달 가능한 공간이 평균 분기계수의 지수로 커짐)와 희소 결과 피드백(성공 궤적에만 보상이 주어짐)이라는 두 성질이 각각 탐색 편향과 복합 편향을 유발한다는 것을 SCA로 분석한 뒤, 정책 최적화 과정에 두 가지 구조적 가이던스를 주입해 정책이 구조화된 추론 공간의 유용한 성질을 내재화하도록 학습시킨다.

실험 설정 및 결과

폐쇄형 수학 추론, 자유형 자연어 추론, 오픈형 장기 추론 과제를 아우르는 12개 벤치마크와 7개 모델군에서 SAGE는 경쟁 기준선들을 일관되게 능가했으며, 실제 오픈 문제인 Andrews-Curtis 사소화 과제에서 최대 8배의 성능 향상을 달성했다.

한계점

논문에 명시되지 않음(제공된 발췌 범위에서는 별도의 한계 섹션 내용이 확인되지 않음).

시사점

장기 추론 실패를 단일 원인이 아니라 "탐색"과 "보상 전파"라는 서로 다른 두 축의 편향으로 분해해 각각에 맞는 구조적 유도 신호(대수적 희소화·쌍곡 임베딩)를 설계한다는 접근은, 희소 보상 하에서의 LLM 강화학습 전반에 적용 가능한 일반적 설계 원칙을 제시한다.
