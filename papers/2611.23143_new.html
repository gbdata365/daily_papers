TCP4D: A Unified Tool-Center-Point Tracking and Generation Model for Robot Manipulation

TCP4D: 로봇 조작을 위한 통합 도구중심점(TCP) 추적·생성 모델

한 줄 요약

단일 RGB 비디오에서 로봇의 도구 중심점(Tool-Center-Point, TCP) 포즈와 그리퍼 상태를 추적하고, 같은 4D 장면 표현을 이용해 미래의 TCP 궤적까지 생성하는 통합 모델 TCP4D를 제안하여, 로봇 조작 정책과 이형 로봇(cross-embodiment) 데이터 증강에 활용한다.

배경 및 문제의식

대규모 로봇 조작 비디오는 풍부한 시각 경험을 제공하지만, 비전-언어-행동(VLA) 모델이나 월드 액션 모델을 학습시키려면 행동(액션) 라벨이 필요한데, 실제 영상에는 동기화된 액션 주석이 없는 경우가 많다. 로봇 플랫폼에 무관하게 동일한 작업 공간 목표를 표현할 수 있는 도구 중심점(TCP) 포즈를 행동 공간으로 활용하면 이 문제를 해결할 수 있지만, 기존 4D 포인트 추적 기법은 TCP가 그리퍼 손가락 사이의 빈 공간(가상의 지점)에 위치해 이미지상 대응하는 실제 표면 점이 없고, 위치만 추정할 뿐 방향(orientation)은 구하지 못해 로봇 특화 사전 지식과 다단계 후처리가 필요했으며 이 과정에서 오차가 누적되는 한계가 있었다.

핵심 기여

  • 모노큘러 RGB 비디오와 초기 2D TCP 쿼리만으로 TCP의 SE(3) 포즈, 그리퍼 상태, 장면 기하 구조, 카메라 파라미터를 추가적인 로봇 사전 지식이나 후처리 없이 직접 복원하는 통합 추적기(Tracker)를 제안.
  • 추적된 동일한 4D 장면 표현에서 지역 특징을 추출해 로봇 관측값·언어 지시와 결합한 뒤 디퓨전 트랜스포머(DiT)로 미래 TCP 궤적과 그리퍼 상태를 예측하는 생성기(Generator)를 제안, 이것이 조작 정책(policy) 역할을 수행.
  • 기록된 소스 로봇 상태 없이도 RGB 비디오에서 복원한 TCP 궤적을 역기구학(IK)으로 리타기팅하고 세그멘테이션·인페인팅으로 소스 로봇을 지우고 타깃 로봇을 합성 렌더링하는 "크로스-임보디먼트(이형 로봇) 데이터 증강" 파이프라인 제시.

방법론

TCP4D 추적기는 DINOv2 기반 트랜스포머 백본으로 비디오를 패치 토큰화하고 카메라/시간 토큰을 추가한 뒤, 프레임 단위 자기주의(self-attention)와 전역 자기주의를 교차 수행해 4D 장면 표현을 구성한다. 이 표현에서 깊이 맵과 카메라 레이 맵을 디코딩하는 지오메트리 헤드와, 2D TCP 쿼리를 입력받아 교차주의(cross-attention)로 TCP의 XYZ·RPY(회전) 및 그리퍼 상태를 디코딩하는 TCP 추적 헤드가 함께 동작한다. 생성기는 추적된 TCP 궤적을 따라 지역 시각 특징을 쿼리로 추출하고, 현재 로봇 상태·손목 카메라 영상·언어 지시를 결합한 뒤, 노이즈에서 시작하는 디퓨전 트랜스포머(DiT) 블록을 거쳐 향후 h-스텝 동안의 TCP 포즈 및 그리퍼 상태를 생성한다. 학습은 2단계로 진행되며(추적기 사전학습 후 생성기 학습), 크로스-임보디먼트 증강 시에는 복원된 TCP 모션을 URDF 기반 IK로 타깃 로봇에 리타기팅해 새로운 데모를 합성한다.

실험 설정 및 결과

추적 성능은 DROID와 RoboLab 데이터셋에서 각각 7.60mm, 16.07mm의 절대 궤적 오차(ATE)를 달성했으며, 단 10개의 시연만으로 UR5 로봇(새로운 임보디먼트)에 적응해 8.85mm의 오차를 보였다. 조작 정책으로서는 RoboTwin 시뮬레이션 벤치마크에서 평균 69.19%의 성공률을 보였고, 두 가지 실제(real-world) 과제에서 평균 78.33%의 성공률로 기존에 잘 알려진 정책 모델들을 능가했다. 소스 데모와 증강된 데모를 함께 학습(joint training)했을 때, 증강 데이터만 사용한 경우보다 타깃 로봇 성공률이 41.5% 향상되었다.

한계점

현재 학습 데이터가 Franka와 Robotiq 그리퍼를 쓰는 임보디먼트에 집중되어 있어 다른 로봇 임보디먼트에 대한 데이터는 제한적이다(다만 소수 시연만으로도 UR5-WSG 등 새로운 임보디먼트에 적응 가능함을 보임). 또한 생성기는 비교적 적은 양의 "깨끗한(clean)" 시연으로 학습되어 대규모 정책 사전학습 없이는 환경이 랜덤화된(clean-to-random) 평가 상황에서 성능이 제한적이다.

시사점

TCP를 임보디먼트에 무관한 공통 행동 표현으로 삼아 추적과 생성을 하나의 4D 표현 안에서 통합함으로써, 액션 라벨이 없는 기존의 방대한 로봇 조작 영상 자산을 효율적으로 활용할 수 있는 길을 제시한다. 특히 기록된 로봇 상태가 없어도 영상만으로 이형 로봇용 학습 데이터를 합성할 수 있다는 점은 로봇 학습 데이터 수집 비용을 크게 낮출 잠재력을 보여준다.
