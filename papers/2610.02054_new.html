UniWAM: Unified World-Action Model

유니왐: 통합 월드-액션 모델

물리적 추론기(physical reasoner), 세계 생성기(world generator), 행동 예측기(action predictor)를 하나의 Mixture-of-Transformers 구조로 통합하고, 사람의 1인칭(egocentric) 영상과 로봇 시연 데이터를 엄격하게 정제·주석(annotation)하는 파이프라인을 결합해, 의미 이해·미래 영상 생성·행동 예측을 동시에 학습하는 범용 로봇 조작 모델 UniWAM을 제안한 연구.

한 줄 요약

물리적 추론기(physical reasoner), 세계 생성기(world generator), 행동 예측기(action predictor)를 하나의 Mixture-of-Transformers 구조로 통합하고, 사람의 1인칭(egocentric) 영상과 로봇 시연 데이터를 엄격하게 정제·주석(annotation)하는 파이프라인을 결합해, 의미 이해·미래 영상 생성·행동 예측을 동시에 학습하는 범용 로봇 조작 모델 UniWAM을 제안한 연구.

배경 및 문제의식

Vision-Language-Action(VLA) 모델은 사전학습된 비전-언어모델(VLM)의 의미 이해·추론 능력을 물려받지만, 행동(action)만을 감독 신호로 사용하기 때문에 세계의 동역학(world dynamics)에 대한 grounding이 약하다. 반대로 World-Action Model(WAM)은 대규모 비디오 생성모델(VGM)에서 물려받은 시공간적 사전지식(spatiotemporal prior)을 통해 다음 프레임 예측 기반으로 동역학 이해를 강화하지만, 분포 밖(OOD) 상황에 대한 이해나 복잡한 과업에 대한 추론 능력은 제한적이다. 즉 VLA는 "이해는 강하지만 동역학에 약하고", WAM은 "동역학에는 강하지만 의미 이해·추론에 약한" 상호 보완적 한계를 가진다. 저자들은 이 두 계열의 장점을 하나의 아키텍처로 결합해 진정한 범용(generalist) 로봇을 만들 수 있는지를 질문한다.

핵심 기여

  • Mixture-of-Transformer(MoT) 구조에서 영감을 받아, VLM 기반 물리적 추론기, VGM 기반 세계 생성기, 행동 예측기를 공동 어텐션(joint multimodal attention)으로 상호작용시키는 통합 아키텍처 제안.
  • 로봇 저수준 행동을 자연어(physical language)로 표현해 VLM의 사전학습 분포와 호환되게 만들고, VQA·사람 1인칭 데이터·로봇 데이터를 각 전문가(expert)에 맞게 차등적으로 감독(supervision)하는 사전학습 레시피 설계.
  • 사람 1인칭 데이터와 로봇 데이터 각각에 대한 엄격한 데이터 정제 파이프라인, 그리고 긴 비분할 1인칭 영상을 원자적(atomic) 하위작업 단위로 자동 분할·주석하는 VLM 기반 파이프라인 EgoANT 개발.
  • 사후학습(post-training) 단계에서 미래 시각 노이즈 증강(future-frame noise augmentation)과 히스토리 조건부 플로우 매칭(history-conditioned flow matching)을 도입해 디노이징 스텝 수를 크게 줄이면서도 성능을 유지.
  • 다수의 시뮬레이션·실환경 평가에서 SOTA 성능을 달성했고, 사람-로봇 데이터를 함께 사용한 대규모 사전학습에서 로그-선형(log-linear) 스케일링 법칙을 발견.

방법론

UniWAM은 현재 관측 ot, 자기수용 상태(proprioceptive state) st, 작업 지시 I를 입력으로 받아 언어 출력, 미래 관측, 행동의 결합분포를 학습한다. 세 전문가는 각각 Qwen3-VL-2B-Instruct 기반 물리적 추론기(언어 토큰 생성), Wan2.2-TI2V-5B 기반 세계 생성기(고정된 VAE의 latent 공간에서 미래 시각 flow 예측), 행동 예측기(행동 청크를 flow matching으로 생성)로 구성되며, 매 레이어에서 각 모달리티의 토큰을 공통 어텐션 공간으로 projection한 뒤 하나의 시퀀스로 concat해 공동 어텐션을 수행하고 다시 모달리티별로 분리해 FFN을 통과시킨다.

사전학습 시 로봇 저수준 end-effector 동작을 고정된 좌표 규약과 구조화된 템플릿을 사용해 자연어(physical language, LAP 방식)로 기술함으로써 VLM이 임베디드(embodied) 지식을 획득하면서도 사전학습된 언어 능력을 보존하도록 한다. 세 데이터 소스(로봇, 사람 1인칭, VQA)는 서로 다른 전문가에 차등 감독되는데, VQA는 물리적 추론기만, 사람 데이터는 물리적 추론기와 세계 생성기(부정확한 행동 레이블로 인한 오감독을 피함), 로봇 데이터는 물리적 추론기·세계 생성기·행동 예측기 모두를 감독한다. 전체 목적함수는 행동 flow matching 손실, 영상 flow matching 손실, 언어(자기회귀) 손실의 가중합이다.

데이터 처리 측면에서, 로봇 데이터는 시간적·통계적 궤적 스크리닝(급격한 이상치 검출, 상태-행동 시간 정합성, 분포 기반 이상치 제거), 기하학적 일관성 검증(순기구학 기반 joint-EEF 일치, 좌표계 정합), 시각적 유효성 검사(블랙/손상/정적 프레임 제거)를 거친다. 사람 1인칭 데이터(EgoDex, EgoVerse, VITRA)는 EgoANT라는 VLM 기반 2단계 파이프라인으로 처리되는데, 0.5초 간격으로 샘플링한 타임스탬프 콘택트시트를 이용한 전역 조대(coarse) 분할 후 지역 정제(refine)로 하위작업의 시작·종료 시점을 찾고, 다중 후보(원본 프레임 주석, FFmpeg 재샘플링 경로, seed/prior 조건 재주석)를 생성한 뒤 텍스트만 보는 선택기(selector)가 최종 설명을 고른다.

사후학습에서는 (1) 미래 프레임 latent를 확률 0.5로 부분 노이즈화하는 future-frame noise augmentation으로 행동 예측이 완벽하지 않은 미래 시각 표현에도 견고해지도록 하고, (2) 행동 생성의 소스(source)를 가우시안 노이즈 대신 직전 수행한 행동 히스토리(약간의 교란 포함)로 대체하는 history-conditioned flow matching을 도입해, 적은 디노이징 스텝으로도 시간적 일관성을 갖는 행동을 생성하도록 했다.

실험 설정 및 결과

시뮬레이션에서는 LIBERO(표준 4개 스위트), RoboTwin 2.0 Clean2Clean(C2C, in-distribution)와 Clean2Rand(C2R, 도메인 랜덤화 OOD), 그리고 LIBERO-Plus(카메라/로봇/언어/조명/배경/노이즈/배치 등 7개 축의 OOD 변형)로 평가했다. 표준 LIBERO에서 평균 성공률 99.2%로 기존 최고 성능(Xiaomi-Robotics-0, 98.7%)을 상회했다. RoboTwin 2.0 50-task 평가에서 C2C 75.14%, C2R 68.32%, 평균 71.73%로 비교된 VLA·WAM 계열 방법 중 최고 평균을 기록했으며, C2C→C2R 성능 하락이 6.82%p에 불과해(π0.5는 24.70%p, Spatial Forcing은 50.46%p 하락) 강한 OOD 견고성을 보였다. LIBERO-Plus에서는 전체 성공률 92.6%로 비교 방법 중 최고치였고, 특히 로봇 초기상태(89.5%), 언어(92.2%), 조명(97.9%), 배경(97.6%) 차원에서 1위를 기록했다.

실제 로봇 실험은 AgileX Piper 양팔 플랫폼에서 수행되었고, π0.5·Motus와 비교했다. 지시 따르기(instruction-following) 4개 과업(Pick-Anything, Diverse-Interaction, Place-Relative, Drawer-Storage) 평균에서 작업 성공률(SR) 67.5%, 지시 이행률(IFR) 82.5%로 π0.5보다 각각 13.1%p, 21.9%p 높았다(특히 Diverse-Interaction에서 SR 40.0%→72.5%, IFR 50.0%→80.0%로 큰 개선). 장기 과업(책상 정리, 6단계 마일스톤의 Task Progress 척도)에서는 평균 5.0점으로 π0.5(4.8점), Motus(3.2점)보다 우수했다.

추가 분석에서는 로봇 데이터 250시간~5,000시간 범위에서 OOD 과업 완수율이 0.35→0.67로 단조 증가했고, 소규모 데이터에서는 사람 데이터 추가가 오히려 성능을 저해하지만 1,000시간 이상에서는 이득으로 전환됨을 확인했다. 검증 손실과 데이터 규모 사이에 L(D) ≈ 0.03205 − 0.00302·ln(D) (R²≈0.983)의 로그-선형 스케일링 법칙이 관측되었다. t-SNE 분석에서는 physical language 감독이 있을 때 로봇·사람 데이터의 표현이 더 많이 겹쳐, 도메인 간 격차 감소를 지지했다. Ablation에서는 로봇 단독(46.23%→사람 데이터 추가 시 71.34%, VQA 포함 시 추가 개선), VLM 미동결(unfreezing)·physical language 감독·사전학습 누적 적용(평균 SR 42.61%→46.49%→51.74%→71.34%), 그리고 히스토리 기반 행동 초기화와 미래 시각 증강(평균 SR 64.80%→69.73%→71.34%)이 각각 성능에 기여함을 보였다.

한계점

논문 본문과 결론에 별도의 "한계" 섹션은 명시되어 있지 않다. 다만 실험 결과 안에서 다음과 같은 제약이 암시된다. - 소규모 데이터(로봇 1,000시간 미만) 환경에서는 사람 1인칭 데이터와 로봇 데이터 간 시각적·물리적 분포 차이로 인해 혼합 학습이 오히려 성능을 저하시키는 것으로 나타나, 데이터 규모가 충분히 커야 사람-로봇 전이 효과가 발현된다. - 사람 egocentric 데이터는 정확한 행동 레이블이 없어 물리적 추론기와 세계 생성기에만 감독을 제공하며, 행동 예측기 학습에는 직접 활용되지 않는다는 설계상 제약이 있다.

시사점

UniWAM은 VLA 계열의 강한 의미 이해·추론 능력과 WAM 계열의 강한 동역학 이해 능력을 하나의 아키텍처에서 공동 학습함으로써, 두 계열이 가진 상호 보완적 한계를 동시에 완화할 수 있음을 보여준다. 로봇 저수준 행동을 자연어로 표현해 VLM의 사전학습 분포와 호환시키는 physical language 감독은 이질적인(heterogeneous) 데이터 소스 간 의미 공유를 가능하게 하는 효과적 수단으로 제시되며, 사람 1인칭 데이터·로봇 데이터·VQA 데이터를 전문가별로 차등 감독하는 전략은 대규모 멀티소스 사전학습에서 데이터 충돌을 줄이는 실용적 설계 지침이 된다. 또한 관측된 로그-선형 스케일링 법칙은 사람-로봇 혼합 데이터를 이용한 대규모 사전학습이 범용 로봇 파운데이션 모델로 가는 유망한 경로임을 뒷받침하며, 데이터 정제·자동 주석 파이프라인(EgoANT)의 중요성은 향후 대규모 임베디드 AI 데이터셋 구축에 참고할 만한 방법론을 제공한다.
