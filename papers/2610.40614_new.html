L3G-World: Real-Time Infinite World Generation with Latent 3D Gaussian Memory

L3G-World: Latent 3D Gaussian 메모리를 이용한 실시간 무한 월드 생성

하나의 이미지와 카메라 경로만으로, 장면을 "latent 3D Gaussian" 형태의 압축된 메모리에 저장하고 갱신하면서 실시간(9 FPS)으로 공간적으로 일관된 무한한 가상 세계를 생성하는 월드 모델이다.

한 줄 요약

하나의 이미지와 카메라 경로만으로, 장면을 "latent 3D Gaussian" 형태의 압축된 메모리에 저장하고 갱신하면서 실시간(9 FPS)으로 공간적으로 일관된 무한한 가상 세계를 생성하는 월드 모델이다.

배경 및 문제의식

상호작용형 비디오 월드 모델은 사용자의 행동(카메라 이동 등)에 따라 다음 장면을 생성하는데, 긴 시간 동안 탐험해도 이전에 본 장면과 공간적으로 일치하는 결과를 유지하면서도 실시간으로 동작해야 한다는 두 가지 요구가 충돌한다. 기존 방법은 크게 두 갈래로 나뉜다. 하나는 이전 프레임이나 어텐션의 KV 캐시 같은 "시간적 컨텍스트"를 활용하는 방식인데, 메모리와 연산량이 생성된 영상 길이에 비례해 계속 늘어나 결국 메모리 부족(OOM)에 빠진다. 다른 하나는 포인트클라우드나 3D Gaussian 같은 명시적 3D 메모리를 사용하는 방식인데, feed-forward 방식은 매 프레임마다 조밀한 3D 표현을 누적시켜 중복이 쌓이고 렌더링이 느려지며, 한 번 잘못 재구성된 영역은 계속 틀린 채로 남는다. 반대로 최적화 기반 방식은 메모리는 장면 규모에만 비례해 콤팩트하지만 반복적인 최적화 때문에 느려서 실시간 생성에 쓸 수 없다. 또한 기존 3D 메모리들은 RGB로 렌더링한 뒤 다시 VAE로 인코딩해야 비디오 생성 모델에 조건을 줄 수 있어, 이 재인코딩 과정 자체도 실시간성을 해친다.

핵심 기여

  • 장면의 공간적 범위에 비례해서만 커지고, 생성된 영상 길이와는 무관하게 유지되는 압축된 "Latent 3D Gaussian Memory(L3G)"를 제안했다.
  • 메모리를 다루는 L3G-Mem과 비디오를 생성하는 L3G-Gen이라는 두 모듈이 서로 번갈아 작동하며 세계를 생성하는 L3G-World 프레임워크를 제시했다.
  • 각 3D Gaussian이 RGB뿐 아니라 VAE latent feature까지 저장하도록 하여, 메모리를 비디오 생성 모델의 latent space에 직접 렌더링함으로써 VAE 재인코딩 과정을 없앴다.
  • 가장 효율적인 기존 명시적 3D 메모리 기법과 비교해 3D 프리미티브 수를 26.7~38.9배, 메모리 재구성 속도를 3.0~3.2배, VAE latent 렌더링 처리량을 349~359배 향상시키며 H100 GPU 한 대에서 9.02 FPS의 실시간 생성을 달성했다.

방법론

L3G-World는 두 모듈이 자기회귀적으로(autoregressive) 교대하는 루프로 동작한다.

  1. L3G-Mem (메모리 갱신기): 입력 영상 윈도우와 이전 메모리를 받아, 이전 메모리를 현재 카메라 시점으로 렌더링해 얻은 opacity(가림 정도)와 RGB 오차를 이용해 "아직 제대로 표현되지 못한" 영역을 찾아 spawn mask를 만든다. 이 마스크 영역에서만 geometry feature를 K-means로 군집화해 새로운 Gaussian을 추가(spawn)하고, 이미 존재하지만 보이는 Gaussian들은 refinement 토큰으로 뽑아 residual 업데이트로 보정(refine)한다. 두 종류의 토큰은 하나의 transformer에서 cross-attention과 self-attention을 거쳐 함께 처리되며, 동시에 VAE latent를 별도 브랜치에서 끌어와 각 Gaussian에 공간적으로 대응되는 latent feature도 부여한다. 즉 메모리는 단순히 쌓이는 버퍼가 아니라 지속적으로 갱신되는 장면 표현이다.
  2. L3G-Gen (메모리 조건부 비디오 생성기): 이전 메모리의 VAE latent와 opacity를 목표 카메라 시점으로 렌더링해 얻은 값을 노이즈가 섞인 latent와 채널 방향으로 이어붙여 diffusion transformer(DiT)의 조건으로 사용한다. 이 과정에서 RGB 렌더링 후 VAE 재인코딩이 필요 없다. 카메라 포즈는 RayRoPE로, 시간 정보는 시간축 RoPE로 인코딩하며, rectified flow 방식으로 학습한다. 실시간 추론을 위해 AnyFlow 기법으로 few-step distillation을 적용해 'L3G-World Fast'라는 경량 버전도 만들었다.
  3. 두 모듈이 반복되며 L3G-Gen이 생성한 다음 청크를 L3G-Mem이 다시 메모리에 반영하는 구조로, 메모리를 계속 읽고 쓰면서 세계를 확장·보정한다.

구현에는 geometry backbone으로 Depth Anything 3, 비디오 생성 백본으로 Cosmos-Predict2.5를 사용했고, DL3DV와 RealEstate10K 데이터셋으로 각각 L3G-Mem과 L3G-Gen을 학습했다.

실험 설정 및 결과

DL3DV와 RealEstate10K 데이터셋에서 481프레임짜리 루프 클로저(출발점으로 되돌아오는) 경로를 이용해 장시간 탐험 후에도 장면이 일관되게 유지되는지 평가했다. 비교 대상은 시간적 컨텍스트 기반 모델(Yume 1.5, Matrix-Game 3.0)과 명시적 3D 메모리 기반 모델(GEN3C, Spatia, SPMem, Lyra 2.0, 3DScenePrompt, NeoVerse) 등이다.

  • 메모리 효율성: Gaussian 기반 방법인 NeoVerse와 비교해 프리미티브 수는 266~417배, 메모리 사용량은 42~67배 줄었고, RGB 렌더링은 8.3~10.4배, VAE 조건화 처리량은 349~359배 빨라졌다. 효율적인 포인트클라우드 기반 방법인 Lyra 2.0과 비교해도 메모리 재구성 8.9~9.5배, 메모리 사용량 7.8~10.4배, VAE 렌더링 처리량 643~648배의 우위를 보였다.
  • 일관성 및 생성 품질: 두 데이터셋 모두에서 PSNR, LPIPS 등 self-consistency 지표와 FID, SC(Subject Consistency), BC(Background Consistency) 등 생성 품질 지표에서 최고 또는 차순위 성능을 기록했다. 특히 루프 클로저 비교 영상에서, 시간적 컨텍스트 기반 모델들은 복귀 시 외형/기하 드리프트를 보였고, Spatia·NeoVerse는 블러와 렌더링 아티팩트가 누적된 반면 L3G-World는 장면 구조를 안정적으로 유지했다.
  • 카메라 포즈 정확도: DL3DV에서는 가장 낮은 translation error와 두 번째로 낮은 rotation error를 보였으나, RealEstate10K에서는 일부 기존 방법이 포즈·MEt3R(기하 일관성) 지표에서 더 낮은 오차를 보였다.
  • Ablation: adaptive spawning을 제거하면 Gaussian 수가 약 1.8배 늘고 품질도 떨어졌고, refinement를 제거하면 품질이 크게 하락했다. VAE latent lifting을 빼고 RGB 렌더링 후 VAE 인코딩으로 대체하면 렌더링 속도가 크게 느려지고 latent 품질도 저하되어, 두 핵심 설계(선택적 spawn/refine, 직접 latent 렌더링)가 모두 성능에 기여함을 확인했다.

한계점

저자들이 직접 명시한 한계는 다음과 같다. 첫째, latent 3D Gaussian 메모리는 정적인 장면을 가정해 설계되어, 독립적으로 움직이는 동적 객체를 명시적으로 모델링하지 못한다. 둘째, 메모리 크기가 생성 길이와는 무관하지만 탐험 범위가 매우 커지면 여전히 메모리가 증가할 수 있어, 적응적 가지치기(pruning)나 계층적 메모리 구조 같은 추가 방안이 필요하다. 셋째, refinement 메커니즘이 점진적으로 오류를 보정하지만, 장시간 자기회귀 생성 과정에서 발생한 오류가 완전히 제거되지 못하고 이후 메모리 갱신에 전파될 수 있다.

시사점

이 연구는 월드 모델의 메모리를 "쌓이기만 하는 버퍼"가 아니라 "지속적으로 갱신되는 압축된 장면 표현"으로 재정의했다는 점에서 의미가 있다. 특히 3D 메모리에 RGB뿐 아니라 VAE latent feature까지 저장해 생성 모델의 latent space에 직접 렌더링한다는 아이디어는, 3D 표현과 latent 비디오 생성 모델 사이의 비효율적인 인코딩/디코딩 변환을 없애는 실용적인 해법으로, 향후 실시간 상호작용형 시뮬레이션(게임, 로보틱스, 자율주행 시뮬레이션 등)의 메모리 설계에 참고할 만한 방향을 제시한다.
