SLA: Scaling Spatial-Language-Action Model via Continual Pre-training

SLA: 지속적 사전학습을 통한 공간-언어-행동 모델 확장

한 줄 요약

사전학습된 2D 비전-언어-행동(VLA) 모델에 외부 3D 인식 모델의 공간 표현을 지속적 사전학습(continual pre-training) 단계에서 정렬시켜, 추가 센서나 구조 변경 없이도 3차원 공간 이해 능력을 갖춘 로봇 조작 파운데이션 모델 SLA를 제안한다.

배경 및 문제의식

기존 VLA 모델은 2D 이미지-텍스트 쌍으로 사전학습된 시각-언어 모델(VLM)의 표현을 그대로 상속받기 때문에, 3차원 공간에서의 정밀한 제어에 필요한 공간적 이해가 부족하다. 깊이 카메라나 포인트 클라우드 등 3D 센서 데이터를 후처리(post-training) 단계에서 추가하는 접근은 (1) 신뢰할 수 있는 3D 센서 데이터 확보의 어려움, (2) 로봇마다 다른 센서 종류·위치·캘리브레이션 상태로 인한 이질성, (3) 대규모 공개 로봇 데이터셋 상당수가 깊이 정보를 포함하지 않는다는 한계가 있다. 저자들은 공간 이해를 과업별 부가 기능이 아니라 파운데이션 모델 단계에서부터 확장 가능한 능력으로 만들고자 한다.

핵심 기여

  • VLA의 중간 시각 임베딩을 외부 공간 표현과 암묵적으로 정렬시키는 로봇 파운데이션 모델 SLA를 제안.
  • 이질적인 공개 로봇 데이터셋(6개, 약 170만 에피소드, 14,330시간)을 통일된 좌표계·행동 표현으로 정제해 지속적 사전학습 코퍼스를 구축.
  • 지속적 사전학습과 후속 post-training 모두에서 동일한 공간 정렬 원리를 적용해, RoboDojo-Real, RoboTwin 2.0, RoboCasa-Panda, LIBERO-Plus 등에서 최신 수준 성능과 강한 일반화·데이터 효율성을 달성.

방법론

사전학습된 π0.5 정책에서 시작해, 멀티뷰 이미지를 입력받는 고정(frozen) 외부 3D 인식 모델(OmniVGGT, VGGT 기반)로부터 픽셀 단위 3D 표현을 추출한다. VLA의 여러 트랜스포머 레이어에서 나온 시각 토큰을 레이어·채널별 게이트(adaptive layer selection, 수식 7)로 가중합하여 하나의 표현으로 융합한 뒤, 이를 외부 3D 표현과 코사인 유사도 기반 정렬 손실(alignment loss, 수식 5)로 학습시킨다. 최종 손실은 행동 예측 손실과 정렬 손실의 가중합(수식 6)이다. 또한 로봇 상태(state) 토큰을 학습 중 확률적으로 제거하는 state dropout을 적용해 모델이 시각 단서에 더 의존하도록 유도한다. 데이터 처리 단계에서는 서로 다른 로봇의 조인트 상태 대신 엔드이펙터(EEF) 포즈 기준의 통일된 좌표계를 사용하고, 회전 표현은 오일러 각 직접 차분 대신 회전 벡터와 SO(3) 합성을 사용해 각도 래핑으로 인한 이상치를 방지한다. 교사 모델, 정렬 프로젝터, 레이어 선택 게이트는 학습 시에만 사용되고 추론 시에는 원래 VLA 아키텍처와 동일하게 동작해 추가 연산 비용이 없다.

실험 설정 및 결과

LIBERO-Plus(7가지 perturbation), RoboTwin 2.0(50개 양팔 조작 과제, Clean2Clean/Clean2Random), RoboCasa-Panda(24개 주방 조작 과제), RoboDojo-Real(ARX X5·Piper·Piper X 3개 실제 로봇 플랫폼), 그리고 8가지 실제 배포 조건(A~H)에서 평가했다. LIBERO-Plus에서 가중 성공률 87.4%로 π0.5 대비 3.0%p, 기존 방법인 Spatial Forcing 대비 2.3%p 향상. RoboTwin 2.0에서는 Clean2Clean 86.0%, Clean2Random 72.3%(평균 79.2%)로 π0.5 대비 평균 20.9%p 향상. RoboCasa-Panda에서는 과제당 50개의 적은 시연만으로 68.4%를 달성해, 300~3,000개 시연을 사용한 비교 모델들을 능가했다. RoboDojo-Real에서는 세 로봇 임베디먼트에 공통 적용된 단일 정책이 33.9% 성공률로 π0.5(12.8%)를 크게 상회했다. 8개 실측 배포 조건 평균에서도 83.8%로 π0.5 대비 24.0%p 향상. 데이터 스케일링 실험에서는 사전학습과 후처리 두 단계 모두에 공간 정렬을 적용한 경우가 모든 데이터 비율에서 가장 우수했으며, 적응형 레이어 선택이 단일 레이어 정렬보다, 25% state dropout이 dropout 없는 경우보다, 회전 벡터 표현이 오일러 각·Rot6D·쿼터니언보다 더 나은 성능을 보였다.

한계점

논문에 명시되지 않음 (저자들은 명시적 한계 섹션을 두지 않았으며, 결론에서는 성과 중심으로 서술함). 다만 본문에서 드러나는 제약으로는, 외부 3D 교사 모델(OmniVGGT)의 품질에 공간 정렬 성능이 의존적이며, ARX X5 임베디먼트에서는 InternW0-Δ보다 낮은 성능(2위)을 보이는 등 모든 조건에서 최고 성능을 보이지는 못했다.

시사점

이 연구는 3D 센서나 깊이 입력을 추론 시점에 추가하지 않고도, 학습 단계에서만 공간 표현 정렬을 수행함으로써 기존 2D VLA 파운데이션 모델의 아키텍처를 그대로 유지한 채 공간 이해 능력을 이식할 수 있음을 보여준다. 이는 다양한 로봇 임베디먼트와 이기종 센서 환경에서 데이터 효율적인 파운데이션 모델 확장 전략으로서, 향후 로봇 조작 모델의 사전학습 설계에 참고할 수 있는 접근법을 제시한다.
