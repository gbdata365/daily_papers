Reasoning-Informed Visual Editing

추론 기반 시각적 편집

텍스트 지시에 따른 추론 기반 이미지 편집(Reasoning-Informed viSual Editing, RISE) 능력을 체계적으로 평가하기 위해 6개 추론 범주·65개 세분화된 과제 유형으로 구성된 벤치마크 RISEBench++를 구축하고, 58개의 편집 모델·방법을 평가한 결과 최상위 모델조차 56.6%의 정확도에 그친다는 것을 보인 뒤, 이를 보완하는 학습 불필요 에이전트 프레임워크 RISE-Agent를 제안한다.

한 줄 요약

텍스트 지시에 따른 추론 기반 이미지 편집(Reasoning-Informed viSual Editing, RISE) 능력을 체계적으로 평가하기 위해 6개 추론 범주·65개 세분화된 과제 유형으로 구성된 벤치마크 RISEBench++를 구축하고, 58개의 편집 모델·방법을 평가한 결과 최상위 모델조차 56.6%의 정확도에 그친다는 것을 보인 뒤, 이를 보완하는 학습 불필요 에이전트 프레임워크 RISE-Agent를 제안한다.

배경 및 문제의식

대형 멀티모달 모델(LMM)은 시각적 이해와 생성 모두에서 빠르게 발전했지만, 일반적인 시각 편집(텍스트 지시에 따라 입력 이미지를 변형하는 작업)에서는 (1) 복잡한 편집 지시를 정확히 따르는 것, (2) 원본 이미지의 외형 일관성을 유지하는 것, (3) 단일/다중 이미지 등 유연한 입력 형식을 지원하는 것에서 여전히 한계가 있다. GPT-image 시리즈나 Nano Banana 시리즈 같은 독점 모델들은 맥락 이해와 논리적 추론에 기반해 지능적인 시각적 변형을 수행하는 RISE 능력을 보여주었지만, 이를 체계적으로 평가할 확립된 벤치마크가 없어 정량적 비교와 후속 연구가 어려웠다.

핵심 기여

  • 시간적(Temporal), 인과적(Causal), 공간적(Spatial), 논리적(Logical), 반사실적(Counterfactual) 추론과, 다중 턴 편집에서 여러 추론 유형을 결합하는 혼합(Hybrid) 추론까지 6개 범주의 계층적 분류 체계를 갖춘 RISEBench++ 제안, 이를 12개 하위 범주와 65개 세분화된 과제 유형으로 더 세밀하게 분해.
  • 다중 이미지 조건을 지원하도록 입력 형식을 확장하고, 영어·중국어 양방향으로 공개되는 1,000개의 정교하게 사람이 주석한 테스트 사례로 벤치마크 규모 확장.
  • 지시 추론(Instruction Reasoning), 외형 일관성(Appearance Consistency), 시각적 타당성(Visual Plausibility)을 인간 평가자와 LMM-as-a-judge 방식으로 함께 평가하는 개선된 평가 프레임워크 구축.
  • 추론 기반 계획, 도구 증강 실행, 검증자 기반 정제를 결합한 학습 불필요 에이전트 프레임워크 RISE-Agent 제안, 대부분의 기존 강력한 접근법을 능가.
  • 오픈소스 34개, 폐쇄형 19개, 에이전트 기반 5개를 포함한 총 58개 시각 편집 방법에 대한 대규모 평가 수행, 최상위 모델(GPT-Image-2.5 Sunburst)조차 56.6% 정확도에 그침을 확인.

방법론

RISEBench++는 6개 주요 추론 범주(시간·인과·공간·논리·반사실·혼합)별로 대표적인 질의 예시를 구성한다(예: "코인을 산화구리 용액에 10분간 담갔다가 뺀 후의 모습을 그려라"는 인과 추론, "두 강아지가 서로 마주보도록 그려라"는 공간 추론). 평가는 세 가지 축(지시 추론, 외형 일관성, 시각적 타당성)으로 이루어지며, 사람 평가자의 판단과 LMM-as-a-judge 방식을 함께 활용해 더 신뢰할 수 있고 잘 보정된 평가를 수행한다. RISE-Agent는 별도의 모델 재학습 없이, 추론 기반으로 편집 계획을 세우고 외부 도구를 활용해 실행한 뒤 검증자(verifier)의 피드백으로 결과를 정제하는 반복적 파이프라인을 통해 복잡한 RISE 과제를 해결한다.

실험 설정 및 결과

  • 58개 시각 편집 방법(오픈소스 34개, 폐쇄형 19개, 에이전트 5개) 평가 결과, 최고 성능 모델인 GPT-Image-2.5 Sunburst도 정확도 56.6%에 그쳐 추론 기반 편집이 여전히 매우 어려운 과제임을 확인.
  • 정성적 분석: 비교적 직관적인 경우(예: 10초 후 장면, 고양이가 서로 등을 맞댄 모습)는 강력한 모델들이 잘 처리하지만, 반응물 추가 결과 예측이나 지도에서 현 위치 파악처럼 추론 부담이 큰 사례에서는 모델 간 차이가 뚜렷하게 나타남. 규칙 기반 변환(예: 격자의 특정 칸만 상태를 바꾸는 "조명 스위치" 예제)에서는 다수 모델이 전체 격자를 바꾸거나 잘못된 칸 상태를 생성한 반면 RISE-Agent는 해당 칸에만 정밀하게 연산을 적용.
  • 혼합(Hybrid) 추론 사례: 시계를 1시간 전진시키고 전체를 180도 회전한 뒤 분침을 3600도 회전시키는 등 다단계 순차 편집에서, 일부 모델(Qwen-Image-Edit-2509, HunyuanImage-3.0)은 회차가 진행될수록 구조적 완전성과 시각적 충실도가 누적적으로 저하되는 현상이 나타나, 다중 라운드 편집에서는 추론 오류뿐 아니라 다단계 재생성 과정에서도 오류가 누적될 수 있음을 시사.

한계점

저자들이 명시한 바에 따르면, 암묵적 시각 규칙을 추론하는 것, 추론에 의존하는 변환을 정밀하게 실행하는 것, 연속적인 편집에 걸쳐 일관성을 유지하는 것이 여전히 핵심 병목으로 남아있다. 특히 혼합 추론(다단계 순차 편집) 상황에서는 장기적 일관성(long-horizon consistency)이 개별 편집을 올바르게 수행하는 것과는 별개의 추가적인 난제로 드러났다.

시사점

RISEBench++는 "생성 품질"과 "추론 기반 편집 능력"이 서로 다른 축임을 체계적으로 드러내며, 향후 시각 편집 모델의 발전이 단순히 더 강력한 생성 능력뿐 아니라 견고한 시각적 지각, 정교한 멀티모달 추론, 정밀한 실행 능력을 모두 요구한다는 점을 시사한다. 또한 RISE-Agent가 보여준 성과는, 모델 자체의 재학습보다 추론-실행-검증을 명시적으로 분리한 에이전트형 접근이 복잡한 추론 기반 편집 과제를 다루는 데 유효한 전략이 될 수 있음을 보여준다.
