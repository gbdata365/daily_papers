Posterior Matching Distillation

사후분포 매칭 증류

기존 역-KL 기반 증류 방법들이 다양성을 희생해 소수의 지배적 모드만 재현하는 문제를 해결하기 위해, 지수 기울임(exponential tilting)으로 얻은 교사 모델의 조건부 사후분포(posterior) 평균들을 직접 맞추도록 학습해, 교사의 전체 조건부 분포(다중 모드 구조 포함)를 보존하는 새로운 증류 기법 Posterior Matching Distillation(PMD)을 제안한다.

한 줄 요약

기존 역-KL 기반 증류 방법들이 다양성을 희생해 소수의 지배적 모드만 재현하는 문제를 해결하기 위해, 지수 기울임(exponential tilting)으로 얻은 교사 모델의 조건부 사후분포(posterior) 평균들을 직접 맞추도록 학습해, 교사의 전체 조건부 분포(다중 모드 구조 포함)를 보존하는 새로운 증류 기법 Posterior Matching Distillation(PMD)을 제안한다.

배경 및 문제의식

확산(diffusion)·플로우 모델은 다단계 반복 샘플링을 거쳐 고품질 이미지를 생성하지만 연산 비용이 크며, 증류(distillation) 기법은 이 과정을 소수의 신경망 평가로 압축하는 학생 모델을 학습시켜 이를 가속한다. 그러나 노이즈가 섞인 하나의 상태(noisy state)는 여러 그럴듯한 깨끗한 이미지(clean image)에 대응될 수 있는데, 기존의 Distribution Matching Distillation(DMD) 등 분포 기반 증류 방법은 역-KL(reverse-KL) 목적함수를 사용하며, 이 목적함수는 모드 추구(mode-seeking) 성질 때문에 교사 분포의 지배적인 모드만 선호하고 샘플 간 조건부 다양성을 손실시키는 한계가 있다. 또한 Moment Matching(MM) 같은 조건부 평균 매칭 기법은 학생의 예측에서 재노이즈된 새 상태를 기준으로 비교하기 때문에 원래 입력에서의 교사 분포를 직접 보존하지 못한다.

핵심 기여

  • 가우시안 오염(Gaussian corruption) 하에서 "사후분포를 지수적으로 기울이는 것(exponential tilting)이 노이즈 레벨을 고정한 채 입력을 이동시키는 것과 수학적으로 동치"임을 보이는 Tilt=Shift Identity를 증명하여, 비용이 큰 몬테카를로 샘플링 없이 단 한 번의 고정된 교사 모델 평가만으로 기울어진 사후분포 평균을 얻을 수 있게 함
  • 열린 근방(open neighborhood) 내 모든 기울임 방향에 대해 기울어진 평균을 맞추는 것이 교사의 전체 조건부 사후분포(다중 모드 구조와 모드 확률 포함)를 유일하게 결정한다는 Posterior Identification Theorem을 제시
  • 보조 학생 점수망(auxiliary student-score network) 없이, 고정된 노이즈 상태에 조건화된 확률적(stochastic) 학생의 지수가중 평균 예측을 교사의 기울어진 평균과 맞추는 PMD 손실을 설계
  • 학습된 타임스텝 격자 내에서 재학습 없이 임의의 샘플링 단계 수(any-step sampling)를 지원하는 확률적 학생 구조를 구현
  • SDXL과 FLUX.2 [klein] 4B 양쪽에서 4단계 증류 방법 중 최고 FID를 달성하면서 조건부 다양성에서 경쟁 방법들을 일관되게 능가함을 실험으로 입증

방법론

확산 과정에서 노이즈 상태 z_t는 깨끗한 이미지 x에 가우시안 노이즈를 더해 생성되며, 교사의 노이즈 제거기(denoiser) D_t(z_t)는 트위디 공식(Tweedie's formula)에 의해 사후분포 q(x|z_t)의 평균을 추정한다. 저자들은 기울임 벡터 λ로 사후분포에 지수 가중치 e^(λᵀx)를 곱한 "기울어진 사후분포" q_λ(x|z_t)를 정의하고, 이 기울어진 사후분포가 원래 노이즈 입력을 z_t+ρ_tλ (ρ_t=σ_t²/α_t)로 이동시킨 것과 동일함을 증명했다(Tilt=Shift Identity). 이에 따라 기울어진 사후분포의 평균은 고정된 교사 모델을 이동된 입력에서 단 한 번 평가하는 것만으로 얻어진다. PMD는 학생 G_θ(z_t,u,t)(u는 독립 랜덤 노이즈)가 여러 개의 독립적 예측을 생성하게 하고, 이를 지수가중 평균으로 결합한 값이 교사의 기울어진 사후분포 평균 D_t(z_t+ρ_tλ)와 일치하도록 기댓값 제곱오차 손실 L_PMD를 최소화한다. 학습 중에는 학생의 역확산(backward) 시뮬레이션으로 얻은 노이즈 상태 z_t에서 노이즈 레벨 t와 기울임 방향 λ를 샘플링하고, 독립 노이즈 입력 u^(1)...u^(M)으로 M개의 학생 예측을 뽑아 소프트맥스 가중 평균을 계산한 뒤 이를 교사 타깃과 비교한다. DMD2 방식을 따라 보조 적대적(GAN) 손실도 함께 사용해 시각적 사실성을 보강한다. 학습된 노이즈 레벨 격자 내에서는 재학습 없이 원하는 단계 수만큼 노이즈 제거-재노이즈를 반복해 임의 단계 샘플링이 가능하다.

실험 설정 및 결과

8개의 NVIDIA L40 GPU에서 2000회 학생 업데이트로 SDXL과 FLUX.2 [klein] 4B 두 모델군에 PMD를 적용했으며, 주 평가는 4단계 샘플링 기준이다. MS-COCO 2014 1만 개 프롬프트로 측정한 결과, PMD는 SDXL에서 FID 19.14로 비교 대상(DMD2 19.20, PCM 27.02 등) 중 최고를 기록했고, OneIG-EN과 PickScore에서도 최고 성능을 보였다. FLUX.2 [klein] 4B에서도 FID 24.12로 추가 보상 지도(reward supervision)를 사용하는 RTDMD(FID 31.57)보다 크게 우수했고, HPSv3·PickScore·CLIP-S에서도 선두를 차지했다. PartiPrompts 1,632개 프롬프트·시드 8개로 측정한 조건부 다양성(Vendi, LPIPS, DINOv2, DreamSim)에서는 PMD가 두 모델 모두에서 모든 베이스라인을 능가했으며(SDXL에서 DINOv2 48.6%, DreamSim 45.9%, Vendi 38.6%, LPIPS 6.9% 개선), 50명 대상 사용자 연구에서도 FLUX.2 기준 PMD가 RTDMD 대비 85% 선호를 받았다. 추가 소거 실험에서는 학생 예측 샘플 수(4/8/16)를 늘릴수록 다양성 지표가 향상되는 경향과, 등방성(isotropic) 기울임보다 저해상도에서 샘플링 후 업샘플링하는 "coarse" 기울임 전략이 더 높은 다양성(Vendi, DreamSim)을 보임을 확인했다.

한계점

저자들은 결론에서 PMD가 직접적인 사후분포 지도(direct posterior supervision)를 제공하지만, 학습 중 다중(stochastic) 학생 예측 추출이 필요해 연산 비용이 늘어나며, 시각적 사실성을 충분히 끌어올리기 위해서는 여전히 보조 적대적(GAN) 손실에 의존해야 한다는 한계를 명시했다.

시사점

PMD는 소수 단계 생성 모델 증류에서 "다양성-충실도" trade-off 문제에 대해, 교사의 평균 하나만이 아니라 지수 기울임을 통한 전체 사후분포 구조를 보존하는 새로운 이론적·실용적 해법을 제시한다. 이는 소수 단계로도 교사 모델에 준하는 생성 다양성을 유지해야 하는 실시간/저비용 이미지·비디오 생성 응용에 직접 적용 가능하며, 추가 학습 없이 샘플링 단계 수를 유연하게 조절할 수 있다는 점에서 실용적 배포 이점도 크다.
