UniEvo-VL: An On-policy Self-Distillation Training Recipe for Multimodal Model Self-improvement

유니에보VL: 멀티모달 모델 자기개선을 위한 온폴리시 자기증류 훈련법

생성과 이해 능력을 동시에 갖춘 통합 멀티모달 모델이 스스로 만든 이미지를 비평(critique)하고, 그 비평을 "교사(teacher)"만 볼 수 있는 특권 정보로 활용해 "학생(student)"이 원본 프롬프트만으로도 더 나은 이미지를 생성하도록 학습시키는 on-policy self-distillation(OPSD) 기반 자기개선 프레임워크 UniEvo-VL을 제안한다.

한 줄 요약

생성과 이해 능력을 동시에 갖춘 통합 멀티모달 모델이 스스로 만든 이미지를 비평(critique)하고, 그 비평을 "교사(teacher)"만 볼 수 있는 특권 정보로 활용해 "학생(student)"이 원본 프롬프트만으로도 더 나은 이미지를 생성하도록 학습시키는 on-policy self-distillation(OPSD) 기반 자기개선 프레임워크 UniEvo-VL을 제안한다.

배경 및 문제의식

최근의 통합 멀티모달 모델(생성+이해를 한 모델에 담은 MMM)은 자신이 생성한 이미지와 지시문 사이의 불일치를 스스로 탐지할 수 있어, 외부 감독 없이도 자기개선(self-evolve)할 잠재력을 지닌다. 기존 연구들은 자기생성 결과를 선별해 지도 미세조정이나 선호 최적화에 사용하거나, 자기생성 상호작용을 캡셔닝·판단·반성 과제로 재구성하거나, 명시적 반성(reflection) 조건부로 이미지를 재생성하거나, 여러 평가를 모아 테스트타임 보상으로 활용하는 방식을 취해 왔다. 그러나 이런 접근들은 "무엇이 잘못되었는지"를 알려주는 비평 정보를 "생성 모델의 중간 디노이징 과정을 어떻게 바꿔야 하는지"로 직접 전이(distill)하지 못한다는 한계가 있었다. 즉 비평 자체는 교정 방향을 설명할 뿐, 생성 정책의 내부 샘플링 궤적을 바꾸는 방법까지 알려주지는 않는다는 간극이 존재했다.

핵심 기여

  • 비평 조건부 on-policy self-distillation: 시각적 비평에서 나온 교정 정보를 student 자신의 샘플링 궤적 위에서 teacher 예측 형태로 변환해 supervision으로 사용하는 UniEvo-VL을 제안. student는 원본 프롬프트만 보고 학습하며, 교정된 이미지 타깃이나 보상 기반 정책 최적화를 필요로 하지 않는다.
  • 학습된 개선과 추론 시점 교정의 분리: 학습 전/후, 그리고 direct generation과 reflection(1회 피드백 허용) 조건을 짝지어(paired) 비교함으로써, 모델이 '내재화한 능력'과 '추론 시점 피드백의 추가 이득'을 구분해 측정하는 평가 방법을 제시.
  • 실증 검증과 분석: GenEval, GenEval2, OCR(텍스트 렌더링) 과제에서 성능 향상을 확인하고, critic(비평자) 모델의 선택 및 post-revision verification 적용 여부가 학습 결과에 미치는 영향을 분석.

방법론

모델 Mθ는 생성 모드(M^gen_θ: 프롬프트 p와 노이즈 ε로부터 이미지 I 생성)와 이해 모드(M^und_θ: 이미지 I를 프롬프트 p에 대해 평가해 비평 c와 수락여부 a를 산출)를 모두 가진 하나의 통합 모델이다.

학습 루프는 다음과 같이 진행된다. 1. 프롬프트 p로 초안 이미지 I를 생성한다. 2. 이해 모드가 I를 평가해 비평 c와 수락 여부 a(수락=1, 교정 필요=0)를 산출한다. 3. a=0(교정 필요)인 경우, 이해 모드가 원본 p와 비평 c를 결합해 수정 프롬프트 p̃를 합성한다. 이 p̃는 "특권 정보(privileged information)"로서 오직 teacher 정책만 조건으로 사용할 수 있다. 4. (선택적) post-revision verification: p̃로 동일한 노이즈 ε를 사용해 새 이미지 I′을 생성하고, 이를 다시 원본 p에 대해 평가한다. 이 2차 평가가 통과된 경우에만 (p, p̃, ε) 쌍이 최종 학습 데이터로 채택된다. I′ 자체는 학습 타깃으로는 쓰이지 않고 오직 필터링 용도로만 사용된다. 5. On-policy self-distillation: student 정책(Mθ, 원본 프롬프트 p 기반)이 만든 디노이징 궤적 τ 위의 각 중간 상태 s_j에서, student의 로컬 예측 M^gen_θ(s_j, p)이 teacher(= Mθ의 EMA 버전, p̃를 조건으로 하는 M^gen_θ̄(s_j, p̃))의 예측(stop-gradient 처리됨)에 가까워지도록 각 transition 단위로 발산(KL/JS, flow 구현에서는 가중 MSE)을 최소화한다. 그래디언트는 오직 student의 generator LoRA 파라미터에만 흐르며, 기반 생성 가중치·텍스트 인코더·VAE·critic은 고정된다. teacher는 EMA(decay=0.999)로 갱신된다.

구현은 오픈소스 flow 기반 모델 Qwen-Image-2512(생성)와 Qwen-VL(이해/비평)을 사용했으며, LoRA(rank/alpha=16/16)만 학습하고, 20 스텝의 생성 과정 중 노이즈가 가장 높은 상위 30%(6 스텝)만 학습 손실 계산에 사용한다.

실험 설정 및 결과

GenEval(구성적 이미지 생성), GenEval2(Soft-TIFA 지표), OCR(텍스트 렌더링) 세 과제에서 direct generation과 1회 reflection 허용 조건을 모두 평가했다.

  • 직접 생성 성능: GenEval native 점수가 Base 0.747 → UniEvo-VL(verification) 0.818, 더 강력한 외부 critic인 GPT-5.6-Luna 사용 시 0.882까지 상승. GenEval2 Soft-TIFA는 32.58 → 35.07(verification), Luna 사용 시 35.53까지 향상.
  • 텍스트 렌더링(OCR): verification을 적용한 구성만 Base(0.771) 대비 개선(0.790)되었고, verification 없이 학습한 구성은 오히려 Base보다 낮은 점수를 보여, 과제별로 자기개선 효과가 균일하지 않음을 확인.
  • 난이도별 분석: 학습 전 기준으로 점수가 낮았던(Hard) 프롬프트에서 큰 폭의 개선(GenEval +67%, GenEval2 +19%, OCR +38%, 정규화 점수 기준)을 보인 반면, 이미 잘 수행되던(Easy) 프롬프트에서는 1~4점 정도의 소폭 하락이 나타났다. 이는 학습 데이터 수집 과정에서 이미 만족스러운 초안은 건너뛰고 교정이 필요한 사례 위주로 학습 신호가 구성되기 때문으로 분석된다.
  • Reflection과의 관계: 학습 후에도 reflection(1회 피드백)은 추가적인 성능 향상을 가져왔으며, '학습 + reflection'을 결합한 설정이 세 벤치마크 모두에서 가장 높은 native 점수를 기록했다. 즉 학습을 통해 얻은 능력은 단순히 추론 시점의 프롬프트 수정 효과로 환원되지 않는, 모델 파라미터에 내재화된 별도의 개선으로 해석된다.
  • Critic 성능의 영향: 더 강력한 외부 critic(GPT-5.6-Luna)을 사용하면 자기개선의 상한이 더 높아지는 경향이 확인됐다(특히 position, counting, color 카테고리에서 Qwen-VL critic 대비 큰 격차). 다만 카테고리별 개선 폭은 일관되지 않았다(position·attribute는 개선 폭이 작음).

한계점

  • 텍스트 렌더링(OCR)과 같은 일부 과제에서는 verification 없이 학습할 경우 오히려 성능이 Base보다 하락하는 등, 자기개선 효과가 모든 과제에서 일관되게 나타나지 않는다.
  • 이미 base 모델이 잘 처리하던(Easy) 프롬프트에서는 소폭의 성능 저하(regression)가 관찰되어, 학습이 '기존 역량 보존'보다 '약점 교정'에 치우치는 한계가 있다.
  • post-revision verification을 적용하면 전체 시도 중 10~21%만 학습 데이터로 채택되어, 상당한 계산 오버헤드가 발생한다.
  • 외부 critic의 품질에 따라 자기개선 상한이 좌우되며(약한 critic일수록 개선 폭이 작음), 완전히 외부 감독 없이 자기개선만으로 도달 가능한 성능에는 한계가 있을 수 있다.
  • 실험은 flow 기반 생성 아키텍처(Qwen-Image)에 한정되어 있으며, autoregressive 등 다른 아키텍처로의 일반화는 검증되지 않았다.
  • HumanPref 등 일부 평가 지표는 자동화된 시각 품질 proxy이며 학습 보상으로 직접 사용되지 않아, 평가지표와 실제 학습 목표 사이의 완전한 정합성은 보장되지 않는다.

시사점

이 연구는 별도의 대형 teacher 모델이나 명시적 보상 모델 없이도, 하나의 통합 멀티모달 모델이 가진 생성-이해 양방향 능력만으로 self-improvement가 가능함을 보여준다. "검증(비평)이 생성보다 쉽다"는 가설에 기반해, 비평을 teacher에게만 주어지는 특권 정보로 활용하여 student의 실제 샘플링 궤적 위에 조밀한 state-wise distillation 신호를 제공하는 방식이 효과적임을 실증했다. 다만 과제별 불균일한 개선, 외부 critic 품질에 대한 의존성, 쉬운 샘플에서의 소폭 regression 등은 향후 recursive self-improvement 연구에서 추가로 해결해야 할 과제로 남는다.
