한 줄 요약

컴퓨터 사용(computer-use) 에이전트의 행동 공간을 게임에 필요한 상대 포인터 이동·지속 입력·복합 입력으로 확장하고, 16개의 합성 2D/3D 환경에서 검증 가능한 보상으로 강화학습을 수행해, 시범(demonstration)만으로는 닿지 못한 게임 제어 능력을 얻는 Player-1 프레임워크를 제시한다.

배경 및 문제의식

컴퓨터 사용 에이전트는 화면을 해석하고 키보드·마우스 행동을 실행하는 데 강점을 보여왔지만, 시각적으로 복잡하고 다양한 메커니즘을 가진 게임은 정밀하고 지속적이며 동시적인 제어를 요구하는 더 어려운 다음 단계다. 기존 게임 에이전트 학습 파이프라인은 대규모 시범 데이터에 의존하지만, 이는 개방형(open-ended) 과제에서 에이전트가 마주칠 수 있는 동적 상태의 일부만 다루며, 상호작용 학습을 위한 확장 가능한 환경을 구하기도 어렵다. 저자들은 외형과 규칙은 다르지만 많은 게임이 정밀 조준, 지속적 이동, 협응 입력 같은 공통된 제어 요구를 공유한다는 점에 주목했다.

핵심 기여

  • 컴퓨터 사용 행동 공간을 상대 포인터 이동(정규화된 Δx, Δy), 여러 제어 스텝에 걸친 지속 입력, 한 스텝에 여러 입력을 결합하는 복합 행동으로 확장.
  • 6,044개의 선별된 게임플레이 궤적(공개 데이터셋+자체 녹화)을 행동·과제 지시·시각적 추론과 함께 정렬하여 지도학습 초기화(SFT)에 사용.
  • 조준, 전투, 주행, 내비게이션, UI 상호작용 등 공유된 제어 요구를 중심으로 설계된 16개의 합성 2D/3D 환경 'Player-1-Gym'을 구축하고, 프로그래밍적으로 검증 가능한 보상과 관찰/제어 동역학 무작위화를 통해 다중 환경 PPO 강화학습(RLVR)을 지원.
  • Player-1-9B와 Player-1-35B-A3B 모델이 MineDojo-300에서 SFT 정책 대비 각각 27.8%p, 17.7%p의 성공률 향상을 달성했고, 훈련에 사용되지 않은 ViZDoom-10, GameWorld로도 이득이 일반화됨을 입증.

방법론

전체 파이프라인은 세 단계로 구성된다. 첫째, 서로 다른 입력 규약과 시간 해상도로 녹화된 게임플레이 시범(마인크래프트, GTA V, 사이버펑크 2077 등)을 행동 표준화·시간 정렬·마우스 보정을 거쳐 공유 행동 공간으로 변환하고, 과제 지시 및 시각적 추론 주석을 붙여 SFT로 컴퓨터 사용 모델을 게임 제어용으로 초기화한다. 둘째, Player-1-Gym의 16개 합성 환경(2D 슈팅/플랫포밍/서킷 주행, 3D 조준/도로 주행/추격 등)에서 외형(색상·조명), 카메라(시점·투영), 장면(배치·스폰), 제어(반응 민감도) 등을 무작위화하여 다양한 상태 분포를 생성한다. 셋째, 각 환경에서 프로그래밍적으로 검증 가능한 게임 상태 보상을 정의하고, 정책이 직접 생성한 경험(스크린샷+실행 행동+보상)에 대해 PPO 기반의 다중 환경 강화학습을 수행해 SFT 모델을 추가로 개선한다.

실험 설정 및 결과

평가는 in-suite(16개 환경×128 시드), MineDojo-300(마인크래프트 100개 과제×3회), ViZDoom-10(10개 맵×10 에피소드), GameWorld(170개 과제×1회) 네 가지로 이루어졌다. Player-1-9B는 MineDojo-300에서 SFT 이후 10.54%였던 성공률을 RL 이후 38.33%까지 끌어올려, 평가된 최강 외부 베이스라인(12.63%)을 크게 앞질렀다. ViZDoom-10에서는 scaled return이 SFT 대비 +0.271(35B-A3B 모델 기준 전후 비교), GameWorld에서는 진행률(progress)이 RL 이후 45% 전후까지 상승(+9.2%p, 또 다른 모델 기준 +5.0%p)했다. 추가 분석에서는 더 넓은 합성 환경 커버리지가 전이 성능을 높이며, 강화학습이 진행될수록 여러 키보드·마우스 입력을 한 번에 결합하는 복합 행동의 사용 비율이 늘어나는 경향을 확인했다.

한계점

논문 본문에 별도의 '한계점' 절은 없으나, 접근법이 16개의 설계된 합성 환경과 그 제어 요구 범위에 기반한다는 점, 그리고 RL이 상용 게임 각각에 대해 온라인으로 직접 이루어지는 것이 아니라 합성 환경에서의 전이에 의존한다는 점이 방법론적 범위로 드러난다. 또한 결과는 주로 소수의 평가 스위트(MineDojo, ViZDoom, GameWorld)에 한정되어 보고되었다.

시사점

시범 데이터의 한계를 넘어, 공유된 제어 구조를 가진 다양한 합성 환경에서 검증 가능한 보상으로 강화학습을 하는 방식이 실제 상용 게임으로 전이 가능한 범용 게임 제어 능력을 만드는 데 효과적임을 보여준다. 이는 온라인 학습이 어려운 실제 게임 전반에 적용 가능한 저비용 사전훈련 전략으로 활용될 수 있다.
