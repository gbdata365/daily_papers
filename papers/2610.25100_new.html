Deep Fusion Memory: A Chunk-Level Parametric Memory for Large Language Models

딥퓨전 메모리: LLM을 위한 청크 단위 파라메트릭 메모리

LLM 디코더 내부의 은닉 상태에 외부 지식을 깊게 주입하면서도, 청크 단위로 학습 데이터를 구성해 기존 파라메트릭 메모리 기법보다 훨씬 적은 검색 비용으로 학습할 수 있는 새로운 파라메트릭 메모리 구조 DFM을 제안한다.

한 줄 요약

LLM 디코더 내부의 은닉 상태에 외부 지식을 깊게 주입하면서도, 청크 단위로 학습 데이터를 구성해 기존 파라메트릭 메모리 기법보다 훨씬 적은 검색 비용으로 학습할 수 있는 새로운 파라메트릭 메모리 구조 DFM을 제안한다.

배경 및 문제의식

LLM이 사전학습 때 습득하지 못했거나 오래된 지식을 보완하려면 외부 지식을 주입해야 한다. 지속적 사전학습(CPT)이나 LoRA 같은 파라미터 적응 방식은 추론 비용이 적지만 기존 능력을 잊어버리는 파국적 망각(catastrophic forgetting) 문제가 있다. RAG, RETRO 같은 비파라메트릭 검색 증강 방식은 모델 파라미터를 바꾸지 않고 외부 근거를 제공하지만, 추론 시점마다 데이터스토어 검색과 증거 처리에 상당한 지연이 발생한다. 최근 제안된 MLP Memory, Memory Decoder 같은 파라메트릭 메모리는 검색으로 얻은 지식을 미리 모델 파라미터(메모리 모듈)에 학습시켜 추론 시 검색을 생략할 수 있게 하지만, 토큰 단위로 학습 타깃을 구성해야 해서 말뭉치 전체에 대해 토큰마다 검색을 수행해야 하므로 오프라인 데이터 구축 비용이 매우 크다. 또한 이런 방법들은 메모리가 예측한 다음 토큰 확률 분포를 모델 출력 확률과 보간(interpolation)하는 "얕은 융합(shallow fusion)"에 그쳐, 메모리 정보가 디코더의 중간 표현 처리에는 전혀 관여하지 못한다는 한계가 있다.

핵심 기여

  • 깊은 융합을 갖춘 파라메트릭 메모리 구조 DFM 제안: 학습된 말뭉치 지식을 디코더의 중간 은닉 상태에 직접 융합시켜, 이후 레이어들이 메모리와 문맥을 함께 처리할 수 있도록 한다. 추론 시 별도의 검색이 필요 없다.
  • 학습 데이터 구축 및 메모리 학습 비용 대폭 절감: 청크 단위 지도(supervision)와 백본을 고정한 채 진행하는 종단간(end-to-end) 학습을 통해, 기존 토큰 단위 파라메트릭 메모리 대비 검색 질의 수는 32배, 검색된 항목 수는 2048배 줄였다.
  • QA 성능 및 도메인 적응 성능 향상 입증: 6개 QA 과제에서 가장 강력한 베이스라인 대비 Mistral-7B-v0.3에서 12.71%, Qwen3-8B-Base에서 11.19% 상대적 성능 향상을 보였고, 코드·수학·법률 도메인 적응에서도 Qwen3-4B-Base와 Qwen3-8B-Base 대비 각각 평균 6.51점, 4.38점 향상을 달성했다.

방법론

DFM은 크게 (1) 인과적(causal) 청크 단위 메모리 예측기(memory predictor)와 (2) 선택된 디코더 레이어에 삽입되는 메모리 교차 어텐션(cross-attention) 융합 모듈로 구성된다.

학습 데이터 구성: 학습 시퀀스를 C토큰 단위의 겹치지 않는 청크 X0, X1, ..., X(J-1)로 나눈다. 각 청크 Xj(j≥1)에 대해, 오프라인 검색기가 바로 앞 청크 X(j-1)을 인코딩해 말뭉치 데이터스토어에서 top-K개의 이웃 청크를 검색하고, 고정된 텍스트 인코더로 얻은 각 이웃의 임베딩을 검색 순위대로 쌓아 타깃 메모리 Vj를 만든다. 즉 토큰마다가 아니라 청크 단위로 한 번씩만 검색을 수행하므로 구축 비용이 크게 줄어든다.

메모리 예측기: 인과적 트랜스포머 구조로, 직전까지의 청크 임베딩들(평균 풀링된 토큰 임베딩)을 입력받아 K개의 연속 메모리 벡터(예측 메모리)를 생성한다. K개의 선형 출력 헤드가 각각 하나의 메모리 슬롯을 담당한다.

메모리 융합: 공유 메모리 프로젝터가 예측 메모리를 디코더의 은닉 차원으로 투영한 뒤(projected memory), 선택된 디코더 레이어마다 있는 메모리 교차 어텐션 모듈이 토큰의 정규화된 은닉 상태를 쿼리로, 투영된 메모리를 키·값으로 사용해 크로스 어텐션을 수행한다. 헤드별로 시그모이드 게이트를 두어 각 헤드가 메모리 정보를 얼마나 반영할지 토큰·레이어별로 조절하며, 이 메모리 분기 출력은 기존 셀프 어텐션 출력과 함께 같은 잔차 경로에 더해진다.

학습 목적함수: 표준 다음 토큰 예측 교차 엔트로피 손실(L_LM)과, 예측 메모리와 L2 정규화된 타깃 메모리 간의 평균제곱오차(L_MSE)를 결합해(β=1) 종단간으로 학습한다. 백본, 검색 인코더, 타깃 메모리는 모두 고정하고 예측기·프로젝터·크로스 어텐션·게이트 파라미터만 학습한다.

추론: 별도 검색 없이, 입력 시퀀스 자체에서 청크 쿼리를 구성해 예측기가 메모리를 바로 생성하고 선택된 레이어에서 융합한다.

실험 설정 및 결과

  • 백본 및 데이터: Mistral-7B-v0.3, Qwen3-8B-Base를 QA 실험에, Qwen3-4B/8B-Base를 도메인 적응 실험에 사용. 2018년 12월 영어 위키백과(약 4B 토큰)로 학습하며, 32토큰 청크, Qwen3-Embedding-0.6B로 검색한 top-16 청크 임베딩을 타깃 메모리로 사용하고 [9,16,24,31] 레이어에 메모리 융합을 배치했다.
  • QA 성능: NQ, WebQA(단일 홉)와 HotpotQA, 2WikiMultiHopQA, MuSiQue, Bamboogle(멀티 홉) 등 6개 QA 벤치마크에서, DFM은 RAG·xRAG·RETRO(비파라메트릭)와 CPT·LoRA·MLP Memory(파라메트릭) 베이스라인을 능가하는 평균 점수를 두 백본 모두에서 기록했다(Mistral 27.21점, Qwen3 26.46점). 특히 NQ, HotpotQA, Bamboogle 등에서 큰 폭의 향상을 보였으나, WebQA에서는 Qwen3 기준 MLP Memory가 더 높았고 2Wiki·HotpotQA 일부에서는 RAG/xRAG가 더 우수해, 명시적 검색이 유리한 영역도 있음을 확인했다.
  • 도메인 적응: Swallow-Code/Math, DISC-Law-SFT 데이터를 활용해 코드(HumanEval, HumanEval+), 수학(GSM8K), 법률(LawBench) 과제에서 평가한 결과, DFM이 Qwen3-4B/8B-Base 모두에서 CPT·LoRA·RAG보다 높은 평균 점수를 기록했다(4B: 64.69점, 8B: 67.52점).
  • 효율성 분석: 동일한 4B 토큰 말뭉치 기준, DFM은 MLP Memory 대비 추가 파라미터가 50%(1.5B→0.75B), 학습 시간이 약 62.5%(64시간→24시간) 줄었고, 검색 질의 수는 96.88%, 총 검색 항목 수는 99.95% 감소했다(4.096T개 → 2B개).
  • 어블레이션: 청크 크기는 32토큰이 최적(16·64토큰 대비 근소하게 우수), 메모리 융합은 레이어를 2~8개로 중간~후반부에 분산 배치할 때 가장 효과적이며 마지막 레이어에만 집중하면 성능이 크게 떨어졌다(21.11점). 메모리 슬롯 수(top-K)는 2~16 사이에서 성능 차이가 크지 않아(26.88~27.21), 더 적은 슬롯으로도 비슷한 성능을 낼 수 있다. 게이트 유무 및 초기화 방식도 성능에 영향을 주며, 게이트 바이어스를 0으로 초기화했을 때 가장 높은 평균(27.90)을 보였지만, 저자들은 사전학습 가중치에 대한 교란을 줄이기 위해 보수적인 -2를 기본값으로 채택했다.

한계점

논문에 별도의 "한계점" 절은 없으나 본문에서 다음과 같은 제약이 언급된다. WebQA(Qwen3)와 일부 멀티홉 과제(2Wiki, HotpotQA)에서는 명시적 검색 기반 방법(RAG, xRAG)이나 토큰 단위 MLP Memory가 DFM보다 더 나은 성능을 보여, 메모리 적응이 모든 백본·과제에 균일하게 이롭지는 않다. 또한 법률 도메인(LawBench) 4B 모델에서는 CPT가 DFM보다 다소 높은 점수를 기록해, 일부 특화 도메인에서는 전체 파라미터를 업데이트하는 방식이 여전히 유리할 수 있음을 시사한다. 코드 구현은 논문 발표 시점에 아직 공개되지 않았고 추후 공개 예정이라고만 밝히고 있다.

시사점

DFM은 지식 주입을 위한 파라메트릭 메모리 설계에서 "학습 데이터 구축 비용"과 "메모리와 문맥의 융합 깊이"라는 두 축을 동시에 개선할 수 있음을 보여준다. 청크 단위로 지도 신호를 공유하는 전략은 토큰 단위 지도보다 훨씬 적은 오프라인 검색으로도 비슷하거나 더 나은 성능을 낼 수 있다는 점에서, 대규모 말뭉치를 활용한 지식 주입의 실용성을 크게 높인다. 또한 출력 확률 보간이 아닌 중간 은닉 상태로의 게이트 크로스 어텐션 융합이 더 효과적이라는 결과는, 향후 파라메트릭 메모리 연구가 "얕은 융합"에서 "깊은 융합"으로 나아가야 함을 시사한다. 백본을 고정한 채 모듈만 추가·학습하는 구조는 파국적 망각 없이 여러 도메인(QA, 코드, 수학, 법률)에 유연하게 적용할 수 있어, 지속적으로 지식을 갱신해야 하는 실서비스 LLM에 적용 가능성이 크다.
