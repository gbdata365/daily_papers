Behind Video Generation: Observations and Insights on Multimodal Understanding from Kling

비디오 생성의 이면: 클링(Kling)에서 얻은 멀티모달 이해에 대한 관찰과 통찰

비디오 생성 품질을 "데이터-조건화-정렬-평가"라는 하나의 연쇄 과정으로 보고, 캡셔닝·참조기반 캡셔닝·프롬프트 강화(PE)·텍스트 인코더·보상 모델·자동 평가라는 각 단계를 Kling-MLLM이라는 공유 멀티모달 기반 모델로부터 특화시켜 온 Kling 팀의 실전 경험과 설계 원칙을 정리한 기술 보고서.

한 줄 요약

비디오 생성 품질을 "데이터-조건화-정렬-평가"라는 하나의 연쇄 과정으로 보고, 캡셔닝·참조기반 캡셔닝·프롬프트 강화(PE)·텍스트 인코더·보상 모델·자동 평가라는 각 단계를 Kling-MLLM이라는 공유 멀티모달 기반 모델로부터 특화시켜 온 Kling 팀의 실전 경험과 설계 원칙을 정리한 기술 보고서.

배경 및 문제의식

비디오 생성은 프레임·클립 단위 품질 평가를 넘어, 여러 샷과 인물·카메라 언어·대사·음악이 어우러진 완성된 시퀀스 단위로 평가되는 단계로 발전했다. 이 수준에서는 제약들이 서로 상호작용하고 오류가 시간에 걸쳐 누적되기 때문에, 생성 실패의 원인을 단일 모델의 점수가 아니라 캡션 작성 → 조건화 → 정렬 학습 → 평가라는 전체 체인 중 어디서 발생했는지로 진단해야 한다는 문제의식에서 출발한다. 또한 범용 멀티모달 벤치마크(VQA 등)의 높은 점수가 카메라 언어, 좌우 관계, 조명, 샷 경계, 정체성 결속 같은 생성에 직결되는 세부 능력을 보장하지 않는다는 점도 핵심 동기다.

핵심 기여

  • "비디오 생성 품질은 데이터-조건화-정렬-평가 체인 전체를 통과한 멀티모달 이해의 투영"이라는 중심 명제를 제시하고, 이 체인을 모듈별로 분해해 분석.
  • 이미지·비디오·오디오·동기화된 오디오-비디오·인터리브 입력을 하나의 자기회귀 인터페이스로 통합하는 공유 기반 모델 Kling-MLLM(27B 밀집 모델, 35B-A3B/397B-A17B MoE 모델)을 제시하고, 4단계 학습 커리큘럼(음향 초기화 → 멀티모달 공동학습 → 시간 용량 확장 → 장문맥 통합)으로 학습.
  • 캡션을 "학습 가능한 의미 계약(semantic contract)"으로 재정의해, 생성 지향적 캡셔닝과, 참조 자산(이미지·비디오·음성)과 타깃 영상 간의 결속을 명시하는 참조 기반 캡셔닝(RGC)을 설계.
  • 프롬프트 강화(PE)를 "기본 PE"(캡션 어휘로 다시 쓰는 학습된 리라이터)와 "에이전틱 PE"(스토리 정합성 보정 및 우수 영상 캡션 검색)로 이원화해, 충실성·합리성·생동감을 텍스트 단계에서 먼저 검증.
  • 지각적으로 그라운딩된 텍스트 인코더, 설명 가능한 범용 보상 모델과 빠른 다차원 평가용 결정형 보상 모델, 태스크별 자동 평가 프로토콜을 제안.

방법론

Kling-MLLM은 ViT 기반 시각 경로와 스케일에 따라 다른 오디오 타워(소형: Mel 스펙트로그램 기반, 대형: Mel+웨이브폼 VAE 이중 분기)를 통해 모든 모달리티를 하나의 시퀀스로 변환하고, 모달리티 경계 토큰과 물리적 타임스탬프 앵커를 삽입해 LLM이 사건 순서와 시간 위치를 추론하도록 한다. 이 기반 모델은 공개 데이터(AutoResearch → Auto Data Process → Auto Revise 3단계 파이프라인으로 수집·정제), Kling 특화 태스크 데이터, 에이전트 데이터를 혼합해 학습된다. 캡셔닝은 주체·행동, 공간·구도, 촬영·조명, 시간·샷, 시청각 텍스트, 미학이라는 6가지 정보군을 다루는 명세와, 개체명 일관성·샷 타임스탬프·시각 텍스트 정확 전사·시청각 시간 정렬이라는 작성 규칙으로 구성되며, 다단계 전문가 파이프라인(분류·라우팅 → 지각 증거 보존 → 전문가 주장 → 충돌 해소 → 결합 품질 게이팅)으로 생성된 뒤 단일 패스 학생 모델(Kling-Captioner)로 증류된다. RGC는 여기에 스코프가 명시된 결속(scoped binding), 잔여 충분성(residual sufficiency), 권한 일관성(authority consistency)이라는 3대 원칙을 추가해 참조-타깃 간 혼동을 방지한다(Kling-RGC). PE는 우수 영상의 캡션으로부터 역방향으로 사용자 프롬프트를 합성해 기본 PE를 SFT하고, 텍스트만으로 충실성·합리성·생동감을 GRPO로 강화학습한 뒤, 마지막으로 고정된 텍스트 인코더·DiT를 통해 비디오 수준 보상으로 미세조정하는 3단계 학습을 거친다. 에이전틱 PE는 스토리 정합성 보정과 우수 캡션 검색(Top-5)을 기본 PE 앞단에서 수행한다. 텍스트 인코더는 일반 QA나 단일 벡터 검색이 아닌, DiT가 실제로 소비하는 프리필 은닉 상태 시퀀스를 직접 평가·적응시키는 방식으로 지각적 그라운딩을 강화한다.

실험 설정 및 결과

Kling-MLLM(27B/35B-A3B/397B-A17B)은 LibriSpeech, WorldSense, TREA, LATBench 등 오디오 벤치마크, OmniBench·video-SALMONN 등 오디오-비디오/인터리빙 벤치마크, MMBench·OCRBench 등 이미지 벤치마크, LongVideoBench·VSI-Bench·Event-Bench 등 비디오 벤치마크에서 Qwen3-Omni, Doubao2.0-Lite, Qwen3.5-Omni-Plus 등과 비교됐으며, 397B-A17B가 비디오 지각·시간 이해, 오디오 시간 그라운딩, 오디오-비디오 캡셔닝에서 가장 뚜렷한 우위를 보였다(예: Event-Bench 78.58, VidCapBench 커버리지 93.81). 이 기반 모델에서 파생된 Kling-Captioner는 VidCapBench·UGC-VideoCap·내부 벤치마크 전 항목에서 Gemini-4-Argon, Doubao2.1-Lite를 상회했고(예: VidCapBench 정밀도 60.51), Kling-RGC도 ViDiC 전 지표와 MRVBench 키포인트 커버리지·참조 결속 정밀도에서 최고 또는 Gemini-4-Argon과 대등한 성능을 보였다. PE 구성요소에 대한 누적 기여 실험(표13)에서는 우수 영상 소스 선택, F/R/V(충실성/합리성/생동감) 데이터 검증, 텍스트 단계 RL, DiT-인-더-루프 RL을 차례로 추가할 때마다 StoryEval·T2AV-Compass·AVE-Compass·MultiRef-Compass 점수가 개선되었고, 에이전틱 PE(스토리 보정+검색)를 추가하면 합리성·생동감이 더욱 향상됐다.

한계점

저자들은 다음을 향후 과제로 명시한다: (1) 매우 동적인 세부사항을 포착하려면 제한된 컨텍스트 용량 안에서 시간적·공간적 충실도 간 균형이 필요하고, 장편 영상에서는 캡션 길이와 서술 밀도, 긴 시간 범위에서의 지시 일관성 사이에 트레이드오프가 남아 있음(캡셔닝). (2) 참조 콘텐츠의 형태(영역 선택, 스케치, 궤적 등) 확장과 더 정교한 시간적 결속, 실제 서비스에서 결속 구조를 명시하지 않는 불완전한 사용자 요청의 번역 문제가 미해결(RGC). (3) DiT-인-더-루프 RL은 실패를 줄이는 대신 가장 인상적인 결과물의 생동감(복잡한 연출, 큰 카메라 무브먼트)을 희생시키는 "바닥은 높이고 천장은 낮추는" 효과가 있으며, 야심찬 그러나 실행 가능한 콘텐츠에 보상을 주는 방법은 미해결 문제로 남음(PE). (4) 에이전틱 PE의 도구 호출, 저해상도 프리뷰, 3D 사전시각화, 생성 후 검증 등의 확장은 지연시간과 비용이 주요 병목이며 추론 효율 개선에 의존함.

시사점

생성 모델의 품질을 좌우하는 것은 렌더링 능력 자체보다, 캡션·프롬프트 강화·텍스트 인코더·보상·평가로 이어지는 "이해 스택"이 얼마나 정교하게 설계되었는가라는 점을 보여준다. 특히 각 모듈에서 발생하는 실패를 체인 전체 관점에서 역추적하고, 텍스트 단계에서 저렴하게 해결할 수 있는 문제(충실성·합리성·생동감)를 영상 렌더링 이전에 걸러내는 전략은, 대형 생성 모델의 실제 품질을 끌어올리는 데 있어 아키텍처 개선보다 데이터·정렬 파이프라인 설계가 갖는 비중이 크다는 점을 시사한다.
