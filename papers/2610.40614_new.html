L3G-World: Real-Time Infinite World Generation with Latent 3D Gaussian Memory

L3G-World: 잠재 3D 가우시안 메모리를 이용한 실시간 무한 월드 생성

단일 이미지와 카메라 경로만으로 실시간·장기간 탐험이 가능한 일관된 3D 월드를 생성하기 위해, VAE 잠재 특징을 직접 담은 "잠재 3D 가우시안 메모리(L3G)"를 제안하고 이를 비디오 디퓨전 트랜스포머와 번갈아 갱신·조건화함으로써 메모리 크기를 스트림 길이가 아닌 장면 범위에만 비례하게 만든 월드 생성 프레임워크 L3G-World를 제안한다.

한 줄 요약

단일 이미지와 카메라 경로만으로 실시간·장기간 탐험이 가능한 일관된 3D 월드를 생성하기 위해, VAE 잠재 특징을 직접 담은 "잠재 3D 가우시안 메모리(L3G)"를 제안하고 이를 비디오 디퓨전 트랜스포머와 번갈아 갱신·조건화함으로써 메모리 크기를 스트림 길이가 아닌 장면 범위에만 비례하게 만든 월드 생성 프레임워크 L3G-World를 제안한다.

배경 및 문제의식

인터랙티브 월드 모델은 사용자의 행동(카메라 이동 등)에 따라 시각 콘텐츠를 생성하지만, 실시간성을 유지하면서 장시간 탐험 중 공간적 일관성(동일 장소로 되돌아왔을 때 이전과 같은 모습을 재현하는 것)을 지키는 것이 어렵다. 기존 접근은 두 갈래로 나뉜다. 첫째, 어텐션의 KV 캐시나 과거 프레임을 참조하는 "시간적 컨텍스트" 방식은 생성 길이와 해상도에 비례해 메모리·연산량이 선형으로 증가해 결국 OOM(메모리 부족)에 이른다. 둘째, 포인트 클라우드나 3D 가우시안 같은 "명시적 3D 메모리"를 두는 방식은 생성된 프레임마다 조밀한 3D 표현을 누적하므로 같은 영역에 중복된 프리미티브가 쌓이고 렌더링이 느려지며, 저장된 내용이 갱신되지 않아 기하학적 오류가 그대로 지속된다. 또한 이런 명시적 3D 메모리는 RGB로 렌더링한 뒤 VAE로 다시 인코딩해야 비디오 생성기의 조건으로 쓸 수 있어 실시간 생성을 가로막는다. 최적화 기반 방법들은 메모리를 장면 범위에 비례하게 유지하지만, 반복적 최적화 때문에 지연이 크다는 트레이드오프가 있다.

핵심 기여

  • 스트림 길이가 아니라 탐험한 장면의 공간적 범위에 비례해서만 커지는 압축적 "잠재 3D 가우시안 메모리(L3G)"를 제안하고, 이를 온라인으로 지속적으로 읽고 갱신하는 구조를 설계했다.
  • 메모리 갱신기 L3G-Mem과 메모리 조건부 비디오 디퓨전 트랜스포머 L3G-Gen이 자기회귀적으로 번갈아 동작하는 L3G-World 프레임워크를 제안했다. L3G-Mem은 새로 관측된 영역에만 가우시안을 새로 생성(spawn)하고 기존 가우시안은 잔차로 보정(refine)해, 메모리가 버퍼처럼 무한히 누적되는 대신 지속적으로 수정되는 장면 표현이 되도록 했다.
  • 각 가우시안이 VAE 잠재 특징을 함께 저장하도록 하여, 메모리를 RGB로 렌더링 후 재인코딩할 필요 없이 비디오 생성기의 잠재 공간으로 바로 렌더링할 수 있게 했다. 여기에 few-step distillation을 결합해 실시간(약 9 FPS) 생성을 달성했다.
  • 가장 효율적인 기존 명시적 3D 메모리 베이스라인과 비교해 최대 38.6배 적은 3D 프리미티브, 3.2배 빠른 메모리 재구성, 359배 빠른 VAE 특징 렌더링을 보이면서도 생성 품질과 장기 일관성에서 최고 성능을 달성했다고 보고한다.

방법론

L3G-World는 영상 스트림을 윈도우(청크) 단위로 처리하며, 각 자기회귀 스텝에서 이전 메모리 M_{k-1}과 현재 입력 윈도우를 받아 메모리를 M_k로 갱신한다.

L3G-Mem(메모리 갱신기): 먼저 이전 메모리를 현재 카메라 시점으로 렌더링해 RGB와 불투명도(알파) 맵을 얻는다. 불투명도가 낮거나 실제 관측 영상과 RGB 오차가 큰 픽셀을 "충분히 표현되지 않은 영역"으로 표시하는 스폰 마스크(spawn mask)를 만든다. 이 마스크 안의 영역에서만 기하학 특징(Depth Anything 3 기반)을 K-means로 클러스터링해 새 가우시안을 만들 스폰 쿼리 토큰을 뽑는다(ZipSplat 방식 응용). 동시에 현재 시점에서 보이는 기존 가우시안들의 메모리 토큰을 리파인 토큰으로 가져와, 관측과 비교해 잔차 보정을 하도록 한다. 두 토큰 집합(스폰·리파인)은 하나의 트랜스포머에서 기하 특징에 대한 교차 어텐션, 스트림별 자기 어텐션, 그리고 전역 자기 어텐션을 거쳐 함께 처리된다. 별도의 "잠재 리프팅" 가지에서는 입력 영상의 VAE 잠재값으로부터 VAE 잠재 토큰을 뽑아 스폰 토큰과 채널 방향으로 결합한다. 최종적으로 MLP 기반 헤드가 스폰 토큰은 새 가우시안으로, 리파인 토큰은 기존 가우시안에 대한 잔차 업데이트로 디코딩한다. 학습은 여러 윈도우에 걸쳐 자기회귀적으로 진행되며 RGB L1, LPIPS, depth L1, VAE 잠재 MSE, 가시성 손실을 결합한 목적함수를 사용한다.

L3G-Gen(메모리 조건부 비디오 생성): 이전 메모리에 저장된 VAE 잠재와 알파 마스크를 목표 카메라 시점으로 렌더링해 공간적으로 정렬된 조건 잠재를 얻고, 이를 노이즈가 섞인 목표 잠재와 채널 방향으로 결합해 디퓨전 트랜스포머(Cosmos-Predict2.5 기반, LoRA로 미세조정)에 입력한다. 카메라 레이 기반 회전 위치 임베딩(RayRoPE)과 참조 프레임용 시간적 RoPE 오프셋을 적용하며, rectified flow 목적함수로 학습한다. 실시간 추론을 위해 AnyFlow 방식의 on-policy distillation으로 few-step 학생 모델을 만들어 "L3G-World Fast"로 부른다.

이 두 모듈이 반복적으로 메모리를 읽고 쓰며(생성된 청크 → 메모리 갱신 → 다음 청크 조건화) 루프를 형성해, 한 장의 입력 이미지와 카메라 경로, 텍스트 프롬프트로부터 무한히 탐험 가능한 월드를 생성한다.

실험 설정 및 결과

L3G-Mem은 ZipSplat 구조와 Depth Anything 3 백본을 바탕으로 DL3DV 데이터셋에서 학습했고, L3G-Gen은 Cosmos-Predict2.5를 기반으로 DL3DV와 RealEstate10K에서 학습했으며, A100 GPU 4장으로 학습, H100 GPU 1장으로 평가(400프레임 비디오 생성 기준)했다. 비교 대상은 점구름 기반(GEN3C, Spatia, SPMem, Lyra 2.0, 3DScenePrompt), 가우시안 기반(NeoVerse), 시간적 컨텍스트 기반(Yume 1.5, Matrix-Game 3.0) 월드 모델들이다.

DL3DV와 RealEstate10K 양쪽에서 L3G-World는 가장 적은 수의 3D 프리미티브(예: NeoVerse 대비 약 26~39배 적음)로 가장 빠른 메모리 재구성(3.0~3.2배)과 가장 빠른 VAE 공간 렌더링(349~359배)을 보였으며, 생성 품질(FID, IQ, AQ 등), 장기 자기일관성(PSNR/SSIM/LPIPS), 카메라 포즈 오차, 3D 일관성(MEt3R) 지표에서도 대체로 베이스라인들을 능가했다. few-step distillation을 적용한 L3G-World Fast는 품질을 일부 희생하는 대신 H100 한 장에서 9.02 FPS의 실시간 생성 속도를 달성했다. 반면 시간적 컨텍스트 방식(Yume 1.5, Matrix-Game 3.0)은 400프레임 생성에서 OOM이거나 낮은 FPS를 보였고, 명시적 3D 메모리 방식들은 메모리나 렌더링 비용이 크거나(3DScenePrompt는 수백만 단위 프리미티브) 실시간이 아니었다.

어블레이션에서는 적응적 스포닝을 제거하면 가우시안 수가 약 1.8배 늘고 품질이 떨어졌고, 리파인먼트 스트림이나 전역 자기 어텐션을 제거해도 성능이 저하되었다. RGB 손실을 빼면 VAE 조건부 생성에도 불구하고 3D 기하 학습 품질이 나빠졌으며, VAE 잠재를 직접 들어올리는 대신 RGB 렌더링 후 재인코딩하는 방식으로 바꾸면 렌더링이 느려지고 잠재 품질도 저하되었다. L3G-World 수준의 어블레이션에서도 메모리 리파인먼트를 끄면 자기일관성, 포즈 정확도, 3D 일관성이 모두 나빠져, 메모리를 단순히 누적하는 것이 아니라 지속적으로 보정하는 것이 중요함을 확인했다.

한계점

논문은 세 가지 한계를 명시한다. 첫째, 잠재 3D 가우시안 메모리는 주로 정적인 장면을 위해 설계되어 독립적으로 움직이는 객체를 명시적으로 모델링하지 않는다. 둘째, 메모리가 생성 길이가 아니라 탐험한 공간 범위에 비례해 커지긴 하지만, 극도로 넓은 영역을 탐험하면 여전히 메모리가 계속 증가할 수 있어 적응적 가지치기(pruning)나 계층적 메모리 구조가 필요할 수 있다. 셋째, 리파인먼트 메커니즘이 부정확한 가우시안을 점진적으로 보정할 수 있지만, 장기간 자기회귀 생성 중 발생한 오류가 이후 메모리 갱신에 전파될 가능성은 여전히 남아 있다.

시사점

이 논문은 월드 모델의 장기 일관성과 실시간성이라는 두 요구가 서로 충돌한다는 문제를, "메모리를 무조건 쌓는 것"이 아니라 "필요한 곳에만 추가하고 기존 내용을 지속적으로 고치는 것"으로 풀 수 있음을 보여준다. 특히 가우시안에 VAE 잠재 특징을 직접 저장해 RGB 재인코딩 과정을 없앤 설계는, 3D 장면 메모리와 잠재 비디오 디퓨전 모델 사이의 인터페이스를 효율화하는 일반적인 방향을 제시한다. 이는 게임·시뮬레이션·자율주행 등 장시간 인터랙티브 탐험이 필요한 월드 모델 전반에, 메모리를 장면 기하에 결속시키면서도 생성기의 잠재 공간과 직접 연동하는 설계 패턴으로 확장될 수 있음을 시사한다.
