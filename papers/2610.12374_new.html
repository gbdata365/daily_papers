AgentGarten: Code Worlds for Evolving Agents

에이전트가든: 진화하는 에이전트를 위한 코드 월드

시뮬레이터/게임 엔진의 명시적 상태·규칙과 신경망 렌더러의 실사풍 영상을 결합한 "코드 월드(code world)" 프레임워크로, 단 몇 라운드의 경험만으로 에이전트가 쉼터 짓기·램프 타기 같은 물리적 도구 사용 전략을 스스로 터득하도록 만든 연구이다.

한 줄 요약

시뮬레이터/게임 엔진의 명시적 상태·규칙과 신경망 렌더러의 실사풍 영상을 결합한 "코드 월드(code world)" 프레임워크로, 단 몇 라운드의 경험만으로 에이전트가 쉼터 짓기·램프 타기 같은 물리적 도구 사용 전략을 스스로 터득하도록 만든 연구이다.

배경 및 문제의식

에이전트가 학습할 수 있는 범위는 결국 그 에이전트가 연습하는 환경의 품질에 의해 제한된다. 기존 접근은 근본적인 트레이드오프를 가진다. - 시뮬레이터·게임 엔진(예: Habitat 2.0, ManiSkill2, ProcTHOR)은 명시적 상태와 프로그램 가능한 상호작용 규칙을 제공하지만, 시각적 다양성을 넓히려면 방대한 3D 에셋 제작과 복잡한 렌더링 파이프라인이 필요해 새로운 환경을 만들기 비싸다. - 비디오 월드 모델(Genie, GameNGen 계열 등)은 데이터로부터 풍부하고 상호작용 가능한 시각적 관찰을 합성하지만, 과업과 관련된 상태나 물리 전이 규칙이 생성된 히스토리와 학습된 표현 안에 암묵적으로만 존재하여 직접 점검·수정·검증이 불가능하다.

즉 "충실함(상태·규칙의 일관성)"과 "실감(실제 분포를 따르는 시각적 관찰)"을 동시에 확보하는 것이 병목이었다.

핵심 기여

논문은 세 가지를 주요 기여로 제시한다. 1. 코드 월드 프레임워크: 각 장면을 코드(scene program)로 정의해 시뮬레이터/게임 엔진이 지속적 상태(persistent state)와 명시적 상호작용 규칙을 관리하고, 구조화된 조건(깊이맵 또는 표면 법선)을 공유 인터페이스로 내보내 신경망 렌더러가 시각 관찰을 생성하도록 분리한 구조. 장면별 수작업 3D 에셋 없이 코딩 에이전트가 텍스트나 이미지로부터 새로운 세계를 작성·확장할 수 있다. 2. Adversarial Forcing: 몇 스텝만에 블록 단위(block-causal)로 동작하는 실시간 렌더러를 증류(distillation)하는 학습 기법. 자기 롤아웃에 대한 분포 매칭(distribution matching)에 "정확한 재현(exact replay)"과 "실데이터 적대적 학습(real-data adversarial objective)"을 결합했다. 3. 진화하는 에이전트에 대한 실증 연구: 사전학습된 파운데이션 모델 에이전트가 신경망 렌더러로만 세계를 관찰하면서, 각 라운드 경험을 "플레이북(playbook)"이라는 문서로 증류해 다음 라운드 에이전트에게 물려주는 방식으로 숨바꾸기(hide-and-seek)를 비롯한 여러 세계에서 성능을 빠르게 향상시킴을 보였다.

방법론

코드 월드 형식화: 장면 상태 $s_t$, 카메라 포즈 $\pi_t$, 행동 $a_t$에 대해 엔진이 상태 전이 $f_p$와 조건 추출 $h_p$를 수행하고($(s_{t+1}, \pi_{t+1}) = f_p(s_t, \pi_t, a_t)$, $c_t = h_p(s_t, \pi_t)$), 신경망 렌더러 $R_\theta$가 외형 참조 $x_0$, 텍스트 $y$, 시각 히스토리 $x_{<t}$, 조건 $c_{\le t}$로부터 관찰 $x_t$를 생성한다. 렌더링 오류가 상태 자체에 누적되지 않도록, 상태 전이는 렌더링된 관찰을 입력으로 받지 않는다. 구조화된 조건으로는 깊이(ViPE+Depth Anything 3)나 표면 법선(NormalCrafter)을 사용하며, 시뮬레이션 장면은 기하 정보로부터 이를 직접 얻는다.

코드 월드 제작: 코딩 에이전트가 단일 이미지나 텍스트로부터 장면 프로그램과 외형 참조를 생성한다. 이미지 기반 제작은 SAM 3(세그멘테이션), Depth Anything 3(깊이/카메라), WildDet3D(3D 박스), SAM 3D(메시 추출) 등을 도구로 호출해 장면을 구성하고, 다중 관찰 카메라로 롤아웃을 점검하며 접촉·충돌·가려짐 등을 검증해 반복적으로 수정한다.

실시간 신경망 렌더러 학습: NVIDIA Cosmos 3-Nano를 백본으로 하여 3단계로 학습한다. 1. 기하 조건화: 깊이/법선을 3채널 인코딩으로 넣고, RGB와 기하 토큰을 동일한 시퀀스에 이어붙여 같은 트랜스포머로 처리(채널 결합이나 별도 제어 분기 대신 조인트 어텐션 사용). 2. 교사 강제(teacher-forcing) 적응: 블록 단위 자기회귀 생성으로 전환. 클린 복사본(히스토리 역할)과 노이즈 복사본(디노이즈 대상)을 하나의 어텐션 마스크 안에서 함께 학습시켜 모든 타깃 블록을 병렬로 학습. 3. Adversarial Forcing: Self Forcing 방식의 분포 매칭 증류(DMD)를 기반으로, 다음 두 가지를 추가. - 정확한 재현(exact replay): Self Gradient Forcing(SGF)처럼 2단계(패스) 학습으로 롤아웃과 기울기 전파를 분리하되, 전체 시퀀스 FlexAttention 대신 블록 단위 SDPA(scaled dot-product attention)를 사용해 롤아웃과 재현 사이의 수치적 불일치를 완전히 제거(비트 단위로 동일한 재현)한다. 이를 통해 이후 손실이 히스토리 인코딩 파라미터까지 기울기를 전달할 수 있다. - 실데이터 적대적 학습: DMD2/R3GAN 스타일의 상대적(relativistic) GAN 손실을 추가해 장시간 롤아웃에서 발생하는 시각적 품질 저하를 방지한다. 또한 고정된(frozen) 판별자 백본에 대해 R1/R2 그래디언트 페널티를 더블 백워드 없이 정확히 계산하는 방법을 유도해, FlashAttention 등 퓨즈드 어텐션 커널의 한계를 우회했다.

실시간 추론: 싱크(sink) 프레임과 슬라이딩 윈도우로 구성된 바운디드 KV 캐시, 커스텀 Triton 커널, CUDA 그래프 캡처, 증류된 소형 VAE 디코더를 사용해 WebRTC로 스트리밍하는 실시간 서빙 파이프라인을 구현했다.

실험 설정 및 결과

모든 성능 측정은 NVIDIA H100 GPU 1장, BF16, 480×832 해상도, 4프레임 블록, 4스텝 샘플러 기준이다. - 렌더링 품질: 동일한 조건 궤적에서 Self Forcing으로 학습한 렌더러는 30초 롤아웃이 길어질수록 반복적인 표면 패턴이 생기고 디테일을 잃는 반면, Adversarial Forcing은 자연스러운 질감과 세부를 끝까지 유지했다. - 재현 정확도: 기존 SGF 방식(전체 시퀀스 FlexAttention)은 롤아웃과 재현 간 상대 L2 오차가 3.99%였으나, 제안한 블록 단위 SDPA 재현은 오차가 0%(비트 단위 동일)였고, 순전파 시간도 5.4% 감소했다(메모리 변화는 미미). - 추론 처리량: 조건 인코딩, 4단계 디노이징, 디코딩, 호스트 전송을 모두 포함해 초당 35프레임 이상(한 블록 16프레임, 약 438.8ms)의 실시간 생성을 달성했다. - 숨바꾸기(hide-and-seek) 재현 실험: 사전학습된 에이전트(OpenAI GPT 계열 모델)가 오직 신경망 렌더러가 생성한 1인칭 시점 영상만 보고, 짧은 파이썬 프로그램으로 행동을 수행했다. 각 역할(히더/시커)은 라운드마다 자신의 행동과 시각적 증거를 되돌아보며 스킬 파일(마크다운 플레이북)을 작성해 다음 라운드에 물려주었다. 그 결과 히더는 4라운드째에 패널을 옮겨 쉼터를 짓는 전략을, 시커는 10라운드째에 램프를 옮겨 벽을 넘는 전략을 보였다. 이는 2019년 Baker et al.의 자기대전 강화학습 연구에서 쉼터 구축에 약 2500만 에피소드, 램프 사용에 약 1억 에피소드가 필요했던 것과 대비되는 결과다(단, 두 설정은 학습 패러다임이 근본적으로 달라 직접적인 샘플 효율 비교는 아니라고 저자들은 강조한다. 전자는 좌표 상태를 직접 보고 처음부터 학습하지만, 후자는 사전학습된 지식을 시각 기반 폐루프 행동으로 "접지(grounding)"하는 문제이다). - 추가 4개 세계에서의 라운드별 개선: 동일한 "읽기→플레이→작성→보관" 루프를 (1) 반려견과 교감하는 "컴패니언 도그" 세계(참여도 점수 13→19), (2) 차 한 대만 지나는 다리에서 두 차가 자리를 바꾸는 "원레인 브리지"(교환 시간 71초→41초), (3) 두 마리 개가 양 네 마리를 몰아 우리에 가두는 "허딩"(1라운드 3/4마리 성공 후 이후 라운드 전부 4/4 성공), (4) 바위를 옮기고 주차하는 "쿼리 로더"(1라운드 일부 성공, 2라운드 실패, 4라운드에 360초 중 329초로 전 과정 완수)에 각각 4라운드씩 적용해 모두 유의미한 성능 향상을 확인했다.

한계점

저자들이 직접 밝힌 한계 및 향후 과제는 다음과 같다. - 깊이·법선 같은 기하 조건은 실용적이지만 중복이 많고(픽셀 단위로 같은 표면 정보를 반복), 공간 다운샘플링은 비용을 줄이지만 얇은 구조나 좁은 틈, 작은 접촉 변화 같은 정밀한 제어 정보를 잃을 수 있다. - 기하 정보만으로는 세계 상태 전체를 규정할 수 없다. 예를 들어 회전 대칭 물체는 표면(깊이/법선)이 바뀌지 않으므로 겉면에 그려진 표시의 회전을 표현할 수 없고, 재질·색상·물체 정체성도 기하로는 결정되지 않는다(시각 히스토리로 일부 보완되나 긴 가려짐이나 장시간 후 재방문 시 소실될 수 있음). - 세계를 만드는 작업 자체는 여전히 사람 또는 코딩 에이전트가 한 번에 한 세계씩 수작업으로 작성했으며, 이 논문에서는 "그 세계가 에이전트의 시간을 쓸 가치가 있는지"(관찰 가능성, 전략의 실패 가능성, 학습 가능성)를 자동으로 판별하는 체계는 아직 마련하지 못했다. - 플레이북(경험 기록)은 현재 세계 하나당 하나씩, 분량도 짧게 관리되는데, 세계 수가 늘어나면 어떤 교훈을 유지·병합·폐기할지 결정하는 문제가 아직 해결되지 않았다.

시사점

AgentGarten은 "상태·규칙은 코드(엔진)가 책임지고, 외형은 신경망 렌더러가 책임진다"는 분업 구조를 통해, 비싼 3D 에셋 제작 없이도 검증 가능하고 다양한 학습 환경을 빠르게 늘릴 수 있음을 보였다. 또한 사전학습된 파운데이션 모델 에이전트가 원시 상태 접근 없이 순수 시각 관찰과 텍스트 플레이북만으로도, 수백만 에피소드가 필요했던 강화학습 기반 전략(쉼터 짓기, 램프 사용)에 비견되는 행동을 단 몇 라운드 안에 학습할 수 있음을 실증했다. 이는 "환경을 코드로 작성하고 같은 렌더링 인터페이스로 보여줄 수 있다면, 에이전트의 연습 세계도 에이전트의 능력과 함께 수와 난이도 양쪽에서 확장될 수 있다"는 방향, 즉 지속적으로 상호작용을 통해 스스로 진화하는 에이전트 연구에 대한 구체적인 경로를 제시한다. 아울러 Adversarial Forcing(특히 비트 단위로 정확한 재현과 프로즌 백본에 대한 정확한 R1/R2 정규화)은 실시간 자기회귀 비디오 생성 증류 일반에도 적용 가능한 공학적 기여로 볼 수 있다.
