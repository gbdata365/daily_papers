Coda-DaVinci: Reimagining Video Generation with Code2Video

코다다빈치: Code2Video로 비디오 생성을 재구상하다

코딩 에이전트가 생성한 3D 프록시(proxy)로 비디오 생성을 유도하는 "Code2Video" 패러다임에서 프록시의 세밀도·물리 시뮬레이션·프롬프트 작성 전략이 품질에 미치는 영향을 체계적으로 분석하고, 과제에 따라 모델링 전략을 적응적으로 선택하는 에이전트 프레임워크 Coda-DaVinci를 제안한다.

한 줄 요약

코딩 에이전트가 생성한 3D 프록시(proxy)로 비디오 생성을 유도하는 "Code2Video" 패러다임에서 프록시의 세밀도·물리 시뮬레이션·프롬프트 작성 전략이 품질에 미치는 영향을 체계적으로 분석하고, 과제에 따라 모델링 전략을 적응적으로 선택하는 에이전트 프레임워크 Coda-DaVinci를 제안한다.

배경 및 문제의식

최근 비디오 생성 모델은 시각적 품질은 뛰어나지만, 복잡한 지시 이행, 장면 상태 보존, 물리적으로 타당한 상호작용 재현에는 한계가 있다. Code2Video 계열 연구(VideoCoCo, Code Video Model 등)는 코딩 에이전트가 만든 3D 프록시(장면의 구조와 동작을 명시적으로 표현하는 프로그램)로 비디오 모델을 유도해 이러한 문제를 완화하려 하지만, 프록시를 얼마나 세밀하게 만들어야 하는지, 물리 시뮬레이션을 언제 적용해야 하는지, 프롬프트를 어떻게 작성해야 최적의 결과를 내는지는 충분히 연구되지 않았다. 특히 과도하게 정교한 프록시는 오히려 동작의 어색함(경직성)을 유발해 자연스러움을 해칠 수 있다는 trade-off가 핵심 문제의식이다.

핵심 기여

  • 프록시 세밀도(G0/G1/G2), 물리 시뮬레이션 필요 여부(P0/P1), 프롬프트 보강 전략(PE0/PE1/PE2)이라는 세 축을 통제된 비교 실험과 블라인드 인간 평가로 체계적으로 분석해 과제별 최적 조합에 대한 실증적 지침을 도출
  • 과제 특성에 따라 3D 모델링 경로와 직접 생성 경로를 선택하는 과제 적응적(task-adaptive) 에이전트 프레임워크 Coda-DaVinci를 제안: 환경·구조물은 중간 세밀도(G1)로, 인간 피사체는 거친 세밀도(G0)로 모델링하여 신체 동작의 경직성을 피함
  • 장면 자산을 revision 간 유지하는 멀티에이전트 실행 하시니스를 구축해, 시각적 검수와 독립적 수용(acceptance) 에이전트를 통한 수정 루프를 지원
  • VTR, R2M, World Models' Last Exam in Physics, T2AV-Compass 등 다양한 벤치마크에서 지시 이행, 장면 일관성, 물리적 타당성, 긴 비디오 일관성을 종합 검증

방법론

Code2Video 파이프라인은 입력 프롬프트와 참조 매체를 받아 코딩 에이전트가 프록시 비디오를 생성하고, 이 프록시와 (원본 또는 보강된) 프롬프트를 조건으로 비디오 생성 모델이 최종 비디오를 합성하는 2단계 구조다(식 v~=A(x,r), v=G(v~,q,r)). 저자들은 프록시 세밀도(coarse/medium/fine geometry·motion), Blender 물리 시뮬레이션 적용 여부, 프롬프트 보강 방식(보강 없음/외부 텍스트 보강 모델/코딩 에이전트가 프록시 기반으로 피사체-색상 바인딩 및 외형 디테일을 직접 작성) 세 요인의 조합(G·P·PE 라벨)을 전문가의 블라인드 4지표(일관성, 지시 이행, 물리적 타당성, 자연스러움·시각적 사실성) 평가로 비교했다. 이 분석 결과를 바탕으로 Coda-DaVinci는 입력 지시와 참조에 따라 3D 모델링 경로 또는 직접 생성 경로를 라우팅하고, 환경/구조물에는 중간 세밀도, 사람에는 거친 세밀도로 모델링하며, 물리적으로 의미 있게 시뮬레이션 가능한 상호작용에는 Blender 시뮬레이션을 적용한다. 리드 에이전트가 생성된 프록시를 검수한 뒤 프록시 개체에 외형 참조를 연결하고 미세 동작을 지정하는 합성 프롬프트를 작성하며, 하시니스가 공유 Blender 작업공간을 유지해 수정·확장 과정에서 자산을 재사용할 수 있게 하고, 독립 수용 에이전트가 과제 요구사항 충족 여부를 검토해 미비점을 재작업하도록 한다.

실험 설정 및 결과

통제 실험에서는 Seedance 2.5를 직접 생성(direct generation) 기준선으로 두고 WorldMemBench(장면 재방문), VGIF-Bench(복잡한 동작·상호작용 지시 이행), Principia(물리 현상 시뮬레이션) 세 벤치마크에서 G/P/PE 조합을 비교했다. 그 결과 Code2Video는 일관성과 지시 이행에서 직접 생성보다 대체로 우수했으나, 사람·사물 동작이 많은 VGIF-Bench에서는 물리적 타당성·자연스러움·사실성이 떨어지는 약점을 보였다. 거친 프록시(G0)는 동작의 자연스러움과 물리적 타당성에서 우위를 보인 반면, 중간 세밀도 프록시(G1)는 전반적으로 가장 높거나 동률의 일관성을 유지했으며, 물리 시뮬레이션(P1)은 네 지표 평균을 전반적으로 향상시켰고, 에이전트가 직접 작성한 프롬프트 보강(PE2)은 외부 텍스트 보강(PE1)보다 전 지표에서 우수했다. 최적 조합인 G1/P1/PE2가 세 벤치마크 평균에서 가장 높은 점수를 기록했다. 본 벤치마크 평가에서 Coda-DaVinci는 VTR(체크리스트 충족도, 단어오류율 WER을 59.21%에서 11.08%로 대폭 감소)과 R2M(장면 일관성 지표)에서 비교 대상 중 최고 성능을, World Models' Last Exam in Physics에서는 직접 생성 대비 향상된 물리적 타당성을(단, Claude+Blender에는 근소하게 뒤짐), T2AV-Compass에서는 다른 Code2Video 기법보다 높은 시각적 사실성과 지시 이행 성능(직접 생성에 근접)을 보였다. 코딩 에이전트(Codex/Claude)와 렌더링 엔진(Blender/Three.js) 조합 전반에서도 견고한 성능을 유지했으며, Blender가 Three.js보다 품질은 높지만 토큰 비용이 약 2배 더 들었다. 25~90초 길이의 긴 비디오(LongAV-Compass, WBench)에서는 사건 완수도, 장기 구조, 상호작용 일관성에서 직접 생성 대비 개선을 보였으나, 전환 안정성과 장면 설정 준수에서는 직접 생성이 더 우수했다.

한계점

저자들은 장면 전환 안정성(transition stability)과 지정된 장면 설정에 대한 충실도(setting adherence)에서 Coda-DaVinci가 직접 생성에 뒤처진다고 명시했다. 또한 복잡한 사람·사물 동작이 요구되는 과제(VGIF-Bench)에서는 프록시 기반 접근이 물리적 타당성·자연스러움·사실성 면에서 여전히 약점을 보이며, 비디오 생성이 더 길고 복잡한 시나리오로 확장될수록 합성 과정에서의 명시적 제어를 더 정교하게 보존할 필요가 있다고 결론에서 지적한다.

시사점

이 연구는 Code2Video 패러다임에서 "코딩 에이전트는 핵심 구조와 동역학을, 비디오 생성 모델은 외형과 미세 동작을 각각 담당"하도록 역할을 분담하는 것이 최선임을 실증적으로 보여주며, 프록시 세밀도·물리 시뮬레이션·프롬프트 전략을 과제 특성에 맞춰 적응적으로 조합하는 설계 원칙을 제시한다. 이는 향후 비디오 생성 시스템이 장시간·고복잡도 시나리오에서 지시 이행과 장면 일관성을 유지하면서도 자연스러운 동작을 보존하는 방향으로 발전하는 데 실질적인 지침이 될 수 있다.
