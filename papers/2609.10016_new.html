MetroLLM-Bench: Evaluating Language Models as Transit Kiosk Runtimes

메트로LLM벤치: 교통 키오스크 런타임으로서의 언어모델 평가

지하철 등 대중교통 키오스크의 정책 로직을 언어모델로 대체할 수 있는지 평가하는 955개 사례 벤치마크로, 4B 크기의 경량 파인튜닝 모델이 GPT-5.6 등 대형 상용 모델과 동등하거나 더 나은 성능을 보인다는 것을 확인했다.

한 줄 요약

지하철 등 대중교통 키오스크의 정책 로직을 언어모델로 대체할 수 있는지 평가하는 955개 사례 벤치마크로, 4B 크기의 경량 파인튜닝 모델이 GPT-5.6 등 대형 상용 모델과 동등하거나 더 나은 성능을 보인다는 것을 확인했다.

배경 및 문제의식

지하철 키오스크는 요금 규정, 노선 구조, 장애 대응 등을 코드화된 상태 기계로 구현하는데, 규정이 바뀔 때마다 개발-패치-테스트-배포의 무거운 소프트웨어 릴리스 절차를 거쳐야 한다. 저자들은 이를 대신해 언어모델이 자연어로 된 시스템 설명(프레임북)을 읽고 구조화된 도구를 호출해 키오스크가 바로 표시할 수 있는 상태를 생성하는 방식이 가능한지 검증한다. 기존의 GTFS 이해 벤치마크나 범용 에이전트 벤치마크(τ-bench, GAIA)는 실제 운영 의사결정 능력, 특히 장애·다중턴·적대적 입력 상황에서의 대응력을 다루지 않는다는 공백이 있었다.

핵심 기여

1) MARTA, 도하 메트로, BART, 타이베이 MRT, CTA, 베이징 지하철 등 6개 실제 교통 시스템, 11개 카테고리(경로, 요금, 장애, 접근성, 적대적 입력 등)에 걸친 955개 사례로 구성된 벤치마크를 공개했다. 2) 결정론적 채점(Tier 1, 14개 항목)과 언어모델 심사 기반 의미 품질 채점(Tier 2, 8개 항목)을 분리해, Tier 1은 파인튜닝 보상 신호로도 재사용 가능하게 설계했다. 3) 26개 모델(6개 벤더)에 대한 리더보드와, Qwen 3.5 계열 2B~27B 4개 크기에 대한 QLoRA 파인튜닝 스윕(시드 2~3회)을 수행했다.

방법론

각 사례는 프레임북과 시나리오 이벤트를 프롬프트로 조립한 뒤, 모델이 ReAct 방식으로 최대 20라운드 동안 6개 도구(경로 계획, 요금 계산, 역 정보, 노선 정보, 장애 피드, 지식베이스)를 호출하고 최종적으로 렌더링 가능한 상태를 제출하는 구조다. 제출된 상태는 Pydantic으로 구조 검증되며, 오류 시 HTTP 422 응답을 받아 모델이 스스로 수정할 수 있다. 955개 사례 중 717개는 훈련 데이터 생성용, 238개는 홀드아웃 평가용으로 사전에 시스템별 층화 분할(seed=42)했다. Tier 2의 6개 항목은 Claude Haiku 4.5를 심사자로 사용했으며, 심사자-저자 간 일치도(가중 Cohen's κ=0.53)가 두 사람 평가자 간 일치도(κ=0.25)보다 높음을 확인해 심사 신뢰성을 검증했다. 파인튜닝은 27B/35B 교사 모델이 생성한 궤적 중 Tier 1 점수 90% 이상인 600개를 추려 QLoRA(rank 16, 3 epoch)로 2B·4B·9B·27B 학생 모델을 훈련했다.

실험 설정 및 결과

홀드아웃 파티션(238개 사례) 기준으로 Muse Glimmer 30B가 종합 1위(92.03)를 차지했고, 상위 11개 모델이 3.18점 이내에 몰려 뚜렷한 격차가 없었다. 특히 2.6GB 크기(Q4_K_M 양자화)의 Qwen3.5-4B PEFT 학생 모델이 Tier 1에서 91.3점을 기록해 GPT-5.6 두 등급(90.6, 90.0)을 넘어섰고 GPT-5.4 full(xhigh 추론 강도, 91.4)과 사실상 동률을 이뤘다. 흥미롭게도 파인튜닝 이득은 기반 모델 크기가 커질수록 줄어들어, 2B에서는 +7.03점이었지만 27B에서는 오히려 -0.91점으로 역전됐다(모든 시드에서 방향 일관). 규칙 기반 스크립트 에이전트는 Tier 1 84.6점을 기록했으며, 언어모델의 우위는 시간 추론·정책 변경·접근성·복합 시나리오처럼 판단이 필요한 영역에 집중됐다. 서빙 설정(출력 토큰 예산, 디코딩 방식)만으로도 Qwen3.8 계열 모델 점수가 최대 2.7점 변동해, 단일 서빙 설정을 모든 모델에 적용하면 설정 차이가 모델 성능 차이처럼 보일 수 있음을 보였다.

한계점

이 작업은 6개의 제한된 도구와 짧은 상호작용으로 이루어진 범위가 좁은 과제이며, 넓은 행동 공간이나 긴 호라이즌, 덜 제약된 출력을 요구하는 과제로 일반화하기는 어렵다. 비-PEFT 모델 대부분이 단일 실행 결과이며, 홀드아웃 파티션의 부트스트랩 신뢰구간 반폭이 약 2점에 달해 1점 미만의 차이는 유의미하다고 보기 어렵다. Tier 2 심사자 교차 검증(비-Anthropic 모델과의 비교)은 향후 과제로 남겨두었다.

시사점

특정 범위가 명확한 실무 과제에서는 소형 오픈 웨이트 모델을 적절히 파인튜닝하면 독점 프론티어 API 없이도 동등한 성능을 달성할 수 있음을 보여준다. 이는 온프레미스·엣지 배포가 필요한 산업 현장(교통, 키오스크 등)에서 비용과 통제권을 모두 확보하면서 성능을 유지할 수 있는 실용적 경로를 제시한다.
