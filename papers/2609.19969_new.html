DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression

DeepSeek-V4.1-Flash: KV 캐시 압축의 한계를 넘어서

장기 컨텍스트 에이전트 워크로드에서 병목이 되는 KV 캐시의 저장·연산·전송 비용을, 아키텍처·캐시 정밀도·배포 전략을 아우르는 종합 최적화로 대폭 줄인 5520억 파라미터 규모의 멀티모달 MoE 모델 DeepSeek-V4.1-Flash를 제안하며, 이전 세대인 DeepSeek-V4-Flash 대비 KV 캐시를 1/4~1/8 수준으로 줄이면서도 성능은 오히려 향상시켰다.

한 줄 요약

장기 컨텍스트 에이전트 워크로드에서 병목이 되는 KV 캐시의 저장·연산·전송 비용을, 아키텍처·캐시 정밀도·배포 전략을 아우르는 종합 최적화로 대폭 줄인 5520억 파라미터 규모의 멀티모달 MoE 모델 DeepSeek-V4.1-Flash를 제안하며, 이전 세대인 DeepSeek-V4-Flash 대비 KV 캐시를 1/4~1/8 수준으로 줄이면서도 성능은 오히려 향상시켰다.

배경 및 문제의식

장기 호라이즌(long-horizon) 에이전트가 널리 쓰이면서 모델 워크로드가 점점 더 "입력 위주(input-heavy)"로 바뀌고 있다. 희소 어텐션 등 선행 연구들이 긴 시퀀스 처리의 연산 비용을 크게 낮췄지만, 프리필(prefill) 연산은 여전히 비싸고, 컨텍스트가 길어질수록 커지는 KV 캐시는 GPU의 HBM 용량과 SSD/호스트 메모리 용량, 그리고 이들 사이의 데이터 전송 대역폭을 강하게 압박한다. 즉 연산·저장·통신이라는 세 가지 제약이 복합적으로 작용해 장기 컨텍스트 서빙의 처리량을 낮추고 배포 비용을 끌어올리는 핵심 병목이 되고 있다. 저자들은 기존 DeepSeek-V4가 전역(global) 어텐션과 슬라이딩 윈도우 어텐션(SWA)을 결합한 구조였음을 지적하며, 시퀀스가 충분히 길어지면 결국 전역 KV가 런타임 KV 사용량을 지배하고, 프리픽스 재사용을 위해 영구 저장되는 KV(persistent KV) 역시 SSD/호스트 메모리 용량의 제약을 받는다는 점을 문제의 출발점으로 삼는다.

핵심 기여

  • Causal Encoder-Decoder(CED) 구조: 40개 레이어를 인코더 20개·디코더 20개로 나누고, 디코더의 전역 KV를 인코더 마지막 레이어의 히든 상태로부터 직접 투영해 생성함으로써 프리필 시 토큰당 활성화 파라미터를 8B로, 디코드 시에는 16B로 분리한다. 이를 통해 프리필 연산량을 이론상 절반 가까이 줄인다.
  • Compressed Sparse Attention 2(CSA2): 레이어 간에 메인 KV·인덱서 K·Top-K 인덱스를 재사용하는 Full/Reindex/Reuse 세 가지 모드를 두어, 엔트리 크기·시퀀스 압축·레이어 간 재사용이라는 세 축을 동시에 활용해 캐시 저장량과 인덱싱 연산을 함께 줄인다.
  • 계층적 희소 인덱서(Hierarchical Sparse Indexer): 디코더의 첫 Full 모드 레이어가 만든 후보 풀(candidate pool)을 이후 레이어들이 공유해 재검색함으로써, 쿼리당 인덱싱 비용을 컨텍스트 길이에 무관하게 상수 수준으로 낮춘다.
  • FP4 메인 KV 캐시: 양자화 인식 학습(QAT)을 메인 KV 캐시까지 확장하여, OCP 표준 MXFP4(E2M1, 16채널당 스케일 1개) 포맷으로 캐시를 저장하면서도 성능 저하는 미미한 수준으로 억제했다.
  • SWA Bounded Replay: 슬라이딩 윈도우 KV를 SSD에 영구 저장하지 않고, 필요 시 최근 n_win개 토큰만 재계산(replay)해 근사 복원함으로써 영구 KV 캐시 공간을 크게 줄이는 배포 단 최적화.
  • 그 외에도 mHC 연산을 한 번의 패스로 처리하는 Single-Pass mHC(및 이를 구현한 Mega-mHC 커널), 조건부 메모리 모듈 Engram, 준자기회귀 드래프팅과 신뢰도 기반 검증을 결합한 추측 디코딩 모듈 DSpark 등 여러 아키텍처 확장을 통합했다.

방법론

DeepSeek-V4.1-Flash는 이미지와 텍스트를 함께 입력받아 텍스트를 자기회귀적으로 생성하는 멀티모달 MoE 트랜스포머로, 언어 백본은 40개 causal 레이어(인코더 20 + 디코더 20)로 구성되며 총 5520억 개의 백본 파라미터와 1960억 개의 Engram 파라미터를 갖는다. 처음 두 레이어를 제외한 모든 레이어가 전역 어텐션(CSA2)과 SWA를 함께 사용한다. CED 구조에서 디코더 레이어는 자신의 히든 상태 대신 인코더 마지막 레이어의 히든 상태로부터 레이어별 가중치를 이용해 전역 KV를 직접 투영받아, 프리필 복잡도를 O(NL)에서 대략 O(NL/2)로 낮춘다. CSA2는 각 레이어를 Full(자체 메인 KV·인덱서 생성 후 새 Top-K 산출)·Reindex(메인 KV·인덱서 K는 재사용하되 Top-K는 자체 쿼리로 재계산)·Reuse(메인 KV와 Top-K 인덱스를 모두 재사용) 모드로 정적으로 배정해, 캐시 공유와 인덱스 재사용을 서로 다른 축으로 분리 제어한다. 여기에 새 비전 인코더 DeepSeek-ViT(2D-RoPE, 선형 패치 임베딩, RMSNorm, SwiGLU 적용), 이미지·텍스트 모달리티별로 별도의 라우팅 보정 편향을 두는 로드밸런싱, 헤드별(head-wise) Muon 옵티마이저와 Engram·임베딩·예측헤드용 Sinkhorn 균형 모멘텀 업데이트 등 학습 최적화 기법도 함께 도입했다. 학습 인프라 측면에서는 비전 인코더와 LLM을 단계별로 분리 실행하는 구조, 대조 학습 단계의 통신-연산 오버랩, 긴 시퀀스 멀티모달 학습 최적화 등을 적용했고, 추론 시스템에서는 인코더/디코더용 SWA Bounded Replay 경로, 통신-연산 오버랩, 샤딩된 Engram 임베딩 테이블, 커널 퓨전(예: CSA2 Reuse 모드 레이어는 프리필 15개, 디코드 11개 커널만으로 실행) 등을 구현했다. 사전학습은 45조 토큰 규모의 멀티모달 코퍼스에서 이루어졌으며, 희소 어텐션을 처음부터(dense 워밍업 단계 없이) 64K 시퀀스 길이로 학습해 최대 100만 토큰 컨텍스트를 지원하도록 했다. 후속 학습(post-training)은 알고리즘적 새로움 없이 표준적인 SFT → 강화학습(RL) → 온폴리시 증류(OPD) 파이프라인을 그대로 따르되, 대규모 자동화된 에이전트 과제 합성과 환경 구축, RL 스케일업에 집중해 성능 향상의 대부분을 이 데이터·환경 파이프라인 개선에서 얻었다고 밝힌다.

실험 설정 및 결과

  • KV 캐시 절감: CSA2와 FP4 KV 캐싱을 결합해 토큰당 전역 KV 캐시 풋프린트(HBM 상주)를 890바이트로 줄였으며, 이는 DeepSeek-V4-Flash 대비 약 1/4, DeepSeek-V1 대비 약 437배 감소한 수치다. SWA Bounded Replay를 더하면 영구 KV 캐시(SSD/호스트 메모리) 풋프린트는 DeepSeek-V4-Flash의 약 1/8 수준까지 줄어든다. 컨텍스트 길이를 4K에서 1M으로 256배 늘려도 토큰당 디코드 FLOPs는 약 1/4만 증가해 거의 상수에 가깝게 유지된다.
  • 베이스 모델 비교(내부 평가 프레임워크 기준): DeepSeek-V4.1-Flash-Base(활성 파라미터 8B/16B, 백본 552B)는 활성 파라미터가 훨씬 큰 DeepSeek-V4-Pro-Base(활성 49B, 백본 1.6T)와 대등한 세계지식·추론·코딩 성능을 보였고, 내부 홀드아웃 평가(자체 문서·코드·학술 자료 기반 BPB 측정)에서는 DeepSeek-V4-Flash 대비 5~10%의 개선을 보였다(총 파라미터는 1/3, 활성 파라미터는 1/4 수준).
  • 후속학습 모델 비교: Opus-5, GPT-5.6 Sol, Kimi-K3, GLM-5.3, DeepSeek-V4-Pro/Flash 등과 비교한 결과, Codeforces 레이팅 3471(DeepSeek-V4-Pro 3348, V4-Flash 3289 상회), MathArena Apex Pass@1 65.6%(Kimi-K3와 동률 최고), GPQA Diamond 90.9% 등 추론 벤치마크에서 강한 성능을 보였다. 에이전트 벤치마크에서는 DeepSWE v1.1 74.2%(Opus-5 74.0%, GPT-5.6 Sol 73.0% 상회), Terminal-Bench 2.1 90.6%(Opus-5 89.1%, GLM-5.3 88.2% 상회), Automation-Bench 54.8%, Agents' Last Exam 31.8%로 오픈소스·비공개 모델을 통틀어 최상위권을 기록했다. 사이버보안 벤치마크(CyberGym, SEC-Bench Pro 등)에서도 오픈소스 모델 중 최고 성능을 보였다. 다만 전문 도메인 지식이 요구되는 Terminal-Bench 4.0 등 과학 지향 에이전트 과제에서는 초대형 모델과의 격차가 남아 있고, 멀티모달 시각 추론에서는 Kimi-K3를 능가하지만 최상위 비공개 모델과는 여전히 격차가 있다고 밝혔다.
  • 추론 노력(reasoning effort) 제어: 공개 API에서 low/high/max(스칼라 효과값 50/75/100에 대응)로 정확도-비용 트레이드오프를 조절할 수 있으며, 효과값을 25→100으로 올리면 추론 벤치마크 8종 평균 Pass@1이 67.1%→76.3%, DeepSWE v1.1이 66.0%→74.2%, Terminal-Bench 2.1이 82.4%→90.6%로 향상되지만 출력 토큰은 약 2.5배 늘어난다. 효과값 60~80 구간에서 이미 최대 성능의 상당 부분을 절반 이하의 토큰 비용으로 회복하는 것으로 나타났다.
  • 스캐폴드 강건성: Claude Code, Codex, OpenCode, Pi, mini-SWE, DeepSeek Harness 등 6개 계열·8개 구성의 에이전트 하네스에 걸쳐 성능이 일관되게 유지되어, 특정 하네스에 과적합되지 않았음을 보였다.

한계점

저자들은 다음을 스스로 명시한다. - CED, CSA2, SWA Bounded Replay 등 새로 도입한 아키텍처적 변경이 아직 완전히 규명되지 않은 "강건성 경계(robustness boundary)"를 만들어낼 수 있으며, 내부 평가에서는 체계적 성능 저하를 관찰하지 못했으나 유한한 테스트 스위트로 모든 극단적 입력·배포 조건을 다 커버할 수는 없다. - CSA2의 잠재적 선택 오류나 SWA Bounded Replay의 근사적 상태 복원이 아직 테스트되지 않은 경계 사례에서 성능 저하를 유발할 가능성이 있다. - 표준 벤치마크들이 점차 포화 상태에 이르고 있어, DeepSeek-V4.1-Flash가 Fable-5, GPT-6 Astra 같은 최상위 모델과 벤치마크 점수 차이가 좁더라도 이것이 복잡하고 고난도인 추론·엣지 케이스에서 프런티어 비공개 모델과 대등함을 의미하지는 않는다. - 과학 지향 에이전트 과제(예: 전문 도메인 지식이 필요한 Terminal-Bench 4.0)와, 최상위 비공개 모델 대비 멀티모달 시각 추론에서는 여전히 성능 격차가 남아 있다. - 사이버보안 벤치마크에서 최상위권 성능을 보인 것과 관련해, 저자들은 이러한 이중 용도(dual-use) 능력을 방어적 보안 연구, 취약점 완화 등 책임감 있는 방식으로 활용해야 한다고 커뮤니티에 당부한다.

시사점

이 논문은 모델 파라미터 규모를 단순히 키우는 방향이 아니라, 아키텍처·캐시 정밀도·배포 전략을 층위별로 함께 최적화해 KV 캐시라는 병목 자체를 정면으로 공략했다는 점에서 실질적인 서빙 비용 절감 사례를 제시한다. 특히 레이어 간 KV·인덱스 재사용(CSA2), 인코더-디코더 분리를 통한 프리필 절감(CED), FP4 양자화, SSD 저장을 우회하는 재계산 기반 복원(SWA Bounded Replay)이라는 서로 다른 층위의 기법들을 하나의 모델에 결합했다는 점은, 향후 장기 컨텍스트·에이전트 워크로드를 다루는 다른 모델 설계에도 참고할 수 있는 구체적인 청사진을 제공한다. 또한 후속학습 단계에서 알고리즘적 혁신보다 데이터·환경 합성 파이프라인의 규모와 품질이 성능 향상의 대부분을 설명한다는 저자들의 관찰은, 현재 시점에서 에이전트형 모델의 능력 향상이 실제로 어디에서 비롯되는지에 대한 실무적 시사점을 준다.
