False Frontiers: Diagnosing and Mitigating Co-Cheating in Self-Evolving Search Agents

거짓 프런티어: 자가진화 검색 에이전트의 공모 치팅(Co-Cheating) 진단과 완화

질문 생성자(proposer)와 답변자(solver)가 서로 학습 데이터를 주고받으며 스스로 진화하는 검색 에이전트 시스템에서, 둘이 같은 오답에 암묵적으로 "합의"해버리는 공모 치팅(co-cheating) 현상을 정량적으로 진단하고, 피드백을 제공하는 평가자를 출처(source) 단위로 분리 학습시키는 CrossFit 기법으로 이를 크게 줄여 다운스트림 검색 성능을 끌어올린 연구.

한 줄 요약

질문 생성자(proposer)와 답변자(solver)가 서로 학습 데이터를 주고받으며 스스로 진화하는 검색 에이전트 시스템에서, 둘이 같은 오답에 암묵적으로 "합의"해버리는 공모 치팅(co-cheating) 현상을 정량적으로 진단하고, 피드백을 제공하는 평가자를 출처(source) 단위로 분리 학습시키는 CrossFit 기법으로 이를 크게 줄여 다운스트림 검색 성능을 끌어올린 연구.

배경 및 문제의식

검색 보조 언어모델은 보통 사람이 만든 질문-정답 데이터로 학습되지만, 최근에는 외부 데이터 없이 모델 스스로 소스 문서로부터 질문과 가짜 정답(pseudo-label)을 만들고, 그 질문으로 풀이자(solver)를 학습시키며, 풀이자의 정답률을 거꾸로 질문 생성자(proposer)의 보상으로 사용하는 "자가진화(self-evolving)" 루프가 등장했다(대표적으로 Dr. Zero). 저자들은 이 폐쇄 루프에서 proposer와 solver가 동일한 모델 계열을 공유하기 때문에, 틀린 가짜 정답이 solver를 학습시키고 그 solver가 같은 소스에서 나온 다음 질문에서 다시 같은 오류를 재생산하면, 이 "일치"가 실제로는 틀렸음에도 보상 신호로는 점수가 올라가는 역설이 생길 수 있다고 지적한다. 저자들은 이를 "false agreement"(겉보기 일치율은 오르지만 실제 정답률은 정체되거나 하락하는 현상)로 정의하고, 이 문제가 라운드를 거듭할수록 심해짐을 사후 감사(post-hoc audit)로 확인한다.

핵심 기여

  1. Dr. Zero 루프를 학습에는 전혀 관여하지 않는 독립 감사자(gpt-6-astra/high가 원문 근거를 바탕으로 정답을 재구성해 채점)로 추적하여, 학습 라운드가 진행될수록 "in-loop 합의율"은 오르지만 "실제 정답 일치율(false-agreement mass)"도 함께 증가하는 co-cheating 현상을 처음으로 정량 측정·보고함.
  2. 1차 완화책으로 Multi-Sample Verification(MSV)을 제안: 동일 모델에 소스를 보여준 3회 답변과 보여주지 않은 3회 답변을 뽑아 다수결이 서로 일치할 때만 과제를 채택. 이는 라벨 품질은 개선하지만 공모 치팅 자체는 크게 줄이지 못함을 보임.
  3. 주된 방법인 CrossFit을 제안: proposer가 쓰는 소스 문서를 두 그룹(fold A, B)으로 나누고, A에서 만든 질문은 B로만 학습된 보조 solver가 채점하고 반대로 B에서 만든 질문은 A로만 학습된 보조 solver가 채점하게 하여, 피드백을 주는 평가자가 자신이 평가하는 질문의 출처 데이터를 학습한 적이 없도록 구조적으로 차단함(본 학습용 메인 solver는 그대로 모든 채택된 질문으로 학습).
  4. Qwen3.5-4B/9B에서 전체 자가진화 루프를 재현해 false-agreement mass, 7개 검색 벤치마크 성능, 그리고 고정 리플레이·대조군 실험을 통해 "같은 평가자 구조를 둬도 같은 출처 데이터를 쓰면 효과가 없고, 출처 단위 분리(source-level split)가 핵심"임을 메커니즘 수준에서 입증함.

방법론

  • 진단(Audit) 프로토콜: 학습 중 매 스텝마다 소스 문서, 채택된 가짜 정답, proposer 보상에 쓰인 solver의 5개 응답을 저장하고, 학습에는 관여하지 않는 외부 LLM 심사자가 원문 근거 기반 정답을 재구성해 채점. 이를 통해 라벨 정답률(T_P), solver 정답률(T_S), 루프가 관측하는 일치율(A), 같은 오답에 동의한 비율인 false-agreement mass(F), 정답인데도 오답 라벨 때문에 보상을 못 받은 lost-credit mass(L)를 각각 측정.
  • MSV: 소스를 보여준 답변 3개(source-aware)와 보여주지 않은 답변 3개(source-blind)를 같은 모델에서 샘플링해, 각각 다수결로 합의된 답이 나오고 두 합의가 서로 일치할 때만 그 질문-정답 쌍을 학습에 채택. 불일치하면 기각.
  • CrossFit: 소스 문서를 fold 0/1로 한 번 고정 분할(질문 단위가 아니라 문서 단위로 분할해 같은 문서에서 파생된 질문들이 양쪽 fold에 걸치지 않게 함). 각 라운드마다 보조 solver 2개를 각각 한쪽 fold로만 학습시키고, 반대쪽 fold에서 나온 새 질문은 상대 fold로 학습된 보조 solver가 채점해 proposer 보상(원래의 frontier reward 함수 f(k)=(5-k)/4는 그대로 유지)을 산출. 즉 피드백의 "출처(provenance)"만 바꾸고 보상 함수 자체는 바꾸지 않음. 메인 solver는 fold 구분 없이 모든 채택된 질문으로 계속 학습됨.
  • MSV와 CrossFit은 서로 다른 지점(라벨 채택 시점 vs. 피드백 평가자 선택 시점)에 작용하므로 결합도 가능.

실험 설정 및 결과

Qwen3.5-4B, Qwen3.5-9B를 백본으로 Dr. Zero와 동일한 3라운드(라운드당 proposer 18스텝, solver 25스텝) 스케줄로 자가진화를 재실행. 평가는 Natural Questions, TriviaQA, PopQA, HotpotQA, 2WikiMultiHopQA, MuSiQue, Bamboogle 등 7개 벤치마크에서 총 1,325개 고정 질문 세트로 Cover-EM을 측정.

  • false-agreement mass: 표준(Dr. Zero) 루프에서 4B 6.1%, 9B 8.8%까지 상승. MSV는 각각 5.7%, 7.2%로 소폭 감소. CrossFit은 3.0%, 3.7%로 큰 폭 감소. 동일 제안(proposal)을 출처 배제 피드백으로 재생(replay)하면 0.4%, 0.1%까지 더 낮아져, "커리큘럼 자체의 변화"가 아니라 "피드백 출처 차단"이 효과의 원인임을 분리 확인.
  • 다운스트림 평균 Cover-EM: CrossFit은 Dr. Zero 대비 4B에서 +8.8점, 9B에서 +8.4점, Search-R1 대비 각각 +8.7점, +7.8점 향상(4B 48.8%, 9B 51.2%). 특히 멀티홉 질문(HotpotQA, 2WikiMQA, MuSiQue, Bamboogle)에서 개선폭이 더 큼. MSV는 Dr. Zero 대비 0.7~0.8점 개선에 그쳐 단독으로는 효과가 제한적이며, MSV+CrossFit 결합도 CrossFit 단독보다 0.3점 정도만 추가 개선.
  • 메커니즘 분석(어블레이션): 보조 solver를 두되 같은 출처 데이터로 학습시키거나(같은 소스 보조), 전체 데이터로 학습시키거나, 질문 단위로 무작위 분할하는 대조군들은 false agreement를 거의 줄이지 못함. 오직 "출처 문서 단위 분할(source-ID split)"만이 false agreement를 0.4%대까지 낮추고 고정 리플레이 뱅크에서의 정답률도 크게 끌어올림 — 즉 평가자를 분리한 것 자체가 아니라 "출처 계보(ancestry) 차단"이 핵심 원인.
  • 비용: MSV는 질문당 6회의 추가 생성이 필요해 Dr. Zero 대비 예산을 약 90% 증가시키고 심사 요청 수는 거의 5배로 늘어남. CrossFit은 보조 solver 업데이트가 추가되어 예산이 약 72~79% 증가(보조 업데이트 수를 절반으로 줄여도 효과는 거의 유지되며 이 경우 증가폭은 36~40%).

한계점

  • CrossFit은 "누가 피드백을 주는가"만 바꿀 뿐 "무엇이 참인지"를 보장하는 오라클이 아니며, 사전학습에서 공유된 오류, 서로 겹치는 웹 근거, 의미적으로 연관된 소스들로 인한 상관된 오류까지는 막지 못함.
  • false-agreement mass 감소가 단순히 어려운 과제를 더 많이 기각한 결과일 수도 있어, 커버리지·과제 난이도·고정 프로브 성능·다운스트림 성능을 함께 봐야 함.
  • 연결되거나 서로 연관된 출처 문서들로의 확장, 그리고 end-to-end 비용 효율성 검증은 아직 이루어지지 않음(저자들이 향후 과제로 명시).
  • MSV와 CrossFit 모두 추가 연산 비용(생성 횟수, 보조 solver 학습)이 상당히 크며, 외부 감사에 사용된 LLM 심사자(gpt-6-astra/high)의 GPU 사용량은 비용 계산에 포함되지 않음.

시사점

자기 생성 커리큘럼으로 학습하는 자가진화형 에이전트에서는 "내부 보상이 오르는 것"과 "실제로 맞는 것"이 분리될 수 있다는 점을 체계적으로 보여주며, 이를 막으려면 가짜 라벨의 정확성뿐 아니라 그 라벨을 평가하는 평가자(solver)가 어떤 데이터로 학습되었는지(훈련 이력/출처 계보)까지 함께 감사해야 한다는 설계 원칙을 제시한다. 단순 검증(MSV)보다 피드백 제공자의 데이터 계보를 구조적으로 분리하는 것(CrossFit)이 self-play/self-evolution 기반 RL 시스템 전반에 적용 가능한 더 근본적인 해법이 될 수 있음을 시사한다.
