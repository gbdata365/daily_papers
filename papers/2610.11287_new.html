REMORY: Learning Residual Memory for Context Compaction

한 줄 요약

장기 실행 에이전트가 컨텍스트를 압축(summarize)할 때, 텍스트 요약만으로는 손실되는 세부 정보를 보완하기 위해 "잔차 메모리(residual memory)"라는 학습된 연속 토큰 시퀀스를 요약 뒤에 덧붙이는 방법을 제안한다.

배경 및 문제의식

Claude Code, Codex CLI 같은 코딩 에이전트는 컨텍스트 창이 꽉 차면 /compact 명령으로 이전 대화를 텍스트 요약으로 대체한다. 그러나 텍스트 요약 하나만으로는 이후의 모든 의사결정을 지원하기 어렵고, 작업이 진행되면서 어떤 과거 정보가 중요해질지는 사전에 알 수 없다. 인간의 작업 기억은 매우 제한적이지만 장기 기억과의 결합을 통해 수개월에 걸친 복잡한 작업을 수행할 수 있다는 인지과학적 통찰에서 착안하여, 저자들은 명시적 요약(체크포인트)과 학습된 신경 표현(장기 기억)을 결합하는 방법을 모색한다.

핵심 기여

  • 요약문에 조건화되어 생성되는 유한 개수의 "소프트 메모리 토큰"을 요약 뒤에 덧붙여, 고정된(frozen) LLM이 전체 히스토리를 사용했을 때의 다음 응답을 근사하도록 돕는 REMORY 네트워크를 제안.
  • 이 구조를 시퀀스 차원의 "잔차 연결(residual connection)"에 유비하여 설계: 요약은 읽을 수 있는 체크포인트를, 학습된 토큰은 그 보완 정보를 제공.
  • SummHay 벤치마크에서 원본 컨텍스트 위치의 5.2%만 사용하면서도 전체 컨텍스트에 준하는 결합 점수(joint score)에 근접.
  • BrowseComp, Terminal-Bench 2.1, AutomationBench, JobBench 등 다양한 장기 에이전트 벤치마크에서 Qwen3.8-27B, GLM-5.3-Flash 두 모델 모두 일관된 성능 향상과 반복 툴 출력·오류 감소를 보임.

방법론

압축 경계마다 메모리 네트워크 Cϕ는 이전 히스토리 Hi와 새로 생성된 요약 Si를 입력받아 최대 m개의 메모리 벡터 Mi를 생성한다. [Si; Mi]는 요약 뒤에 메모리가 이어지는 형태로, 다음 모델 호출의 입력이 된다. 학습은 2단계로 구성된다: (1) 재구성(reconstruction) 단계 - 교사 모델은 원문을 직접 받고 학생 모델은 소프트 메모리로 대체된 입력을 받아 동일한 원문을 예측하도록 학습, (2) 요약-조건화 지속(continuation) 단계 - 교사는 전체 히스토리를, 학생은 고정된 요약과 그로부터 생성된 메모리를 받아 동일한 다음 응답을 예측하도록 학생-교사 역방향 KL divergence로 학습. 이 과정에서 고정된 actor 모델의 파라미터는 변경하지 않고 메모리 네트워크 파라미터만 업데이트한다. Qwen3.8-27B에는 DFlash 아키텍처를, GLM-5.3-Flash에는 그룹 동적 컨볼루션을 사용하는 DFlash-2를 적용했으며, 각각 19.4억 개, 15.02억 개의 학습 파라미터를 가진다.

실험 설정 및 결과

  • SummHay: 10개 문서 집합의 92개 질의에 대해 원본 컨텍스트, 요약만, 요약+동일 예산의 텍스트 보충(Summary++), 요약+REMORY를 비교. REMORY는 커버리지(67.95)는 요약만 사용할 때(67.55)와 거의 동일하면서 인용 F1을 61.03으로 끌어올려(요약만일 때 56.98), 결합 점수 43.39로 원본 컨텍스트(43.41)에 근접.
  • End-to-end 에이전트 평가: Qwen은 AutomationBench에서 9.8점, JobBench에서 7.6점 향상; Terminal-Bench 2.1에서 4.5점, BrowseComp에서 3.0점 향상. GLM은 각각 3.3점, 4.1점 향상. 반복 툴 출력은 17.9~29.8%, 오류는 25.3~49.7% 감소.
  • 사례 연구: Live Trading(모의 투자) 실험에서 잔차 메모리 적용 시 ROI가 -11.86%에서 +5.11%로 개선되고 생성 비용도 감소; 셀 분할(cell segmentation) 작업에서는 메모리가 삭제된 헬퍼 함수 복구에 기여.

한계점

논문은 별도의 "한계점" 절을 명시하지 않았으나, 본문에서 다음과 같은 제약을 언급한다: 비용 추정치는 토큰 가격만을 반영하며 메모리 네트워크 실행이나 도구 호출 비용은 포함하지 않아 전체 실행 비용을 측정하지 못한다. 또한 Live Trading 사례의 두 계정은 시장 선택과 타이밍이 달라 수익률 직접 비교에는 한계가 있으며, 셀 분할 사례 분석은 어떤 세부 정보가 메모리에서 유래했는지 확정하지 못한다.

시사점

요약 기반 컨텍스트 압축이 일반화된 현재의 장기 실행 에이전트 설계에서, 텍스트 요약과 학습된 연속 표현을 결합하는 방식이 정보 손실을 줄이면서도 컨텍스트 효율을 유지할 수 있는 실용적 대안이 될 수 있음을 보여준다. 특히 에이전트의 actor 모델을 변경하지 않고도 외부 메모리 모듈만 학습시켜 성능을 높일 수 있다는 점에서, 기존 대형 모델에 플러그인 형태로 적용 가능한 메모리 증강 기법으로서의 확장 가능성을 시사한다.
