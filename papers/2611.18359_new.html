Envisioning Agentic Robotics: A New Era of Robotic Systems

에이전틱 로보틱스 전망: 로봇 시스템의 새로운 시대

범용 파운데이션 모델과 "임바디드 하네스(embodied harness)"가 결합된 "Embodied System 2"를 로봇 자율성의 의사결정 핵심으로 정의하고, 이를 평가하기 위한 프레임워크와 연구 로드맵을 제시하는 포지션(서베이) 논문.

한 줄 요약

범용 파운데이션 모델과 "임바디드 하네스(embodied harness)"가 결합된 "Embodied System 2"를 로봇 자율성의 의사결정 핵심으로 정의하고, 이를 평가하기 위한 프레임워크와 연구 로드맵을 제시하는 포지션(서베이) 논문.

배경 및 문제의식

기존 로봇은 과제별로 학습된 정책(VLA, World-Action Model 등)에 의존해 특정 작업·환경에는 강하지만 낯선 상황으로 일반화하기 어려웠다. 그런데 GPT-6 Astra와 같은 범용 파운데이션 모델이 과제별 미세조정 없이도 여러 임바디드(embodied) 벤치마크에서 전용 정책과 동등하거나 그 이상의 성능을 보이면서, "에이전틱 로보틱스"라는 새로운 패러다임이 급부상했다. 그러나 이 패러다임에 대한 공통된 정의, 신뢰할 수 있는 평가 프레임워크, 연구 로드맵이 아직 커뮤니티 내에 합의되어 있지 않다는 문제의식에서 출발한다.

핵심 기여

  • 로봇 시스템을 System 2(의사결정·추론), System 1(실행 가능한 스킬·툴), System 0(저수준 바디 제어)의 세 가지 기능적 역할로 구분하는 참조 아키텍처를 제안.
  • 파운데이션 모델과 임바디드 하네스가 결합된 "Embodied S2"를 에이전틱 로보틱스의 의사결정 핵심으로 정의.
  • 모델 역량과 폐루프(closed-loop) 시스템 성능을 구분하여 평가하는 9개 차원의 평가 프레임워크를 제시.
  • 디지털 에이전트에서 물리적 에이전트로 어떤 설계 원칙이 전이되고, 어떤 가정이 재검토되어야 하는지 분석.
  • "원시 동작 실행(L1) → 과제 완수(L2) → 워크플로 조율(L3) → 지속적 역할 수행(L4)"으로 이어지는 4단계 "위임 가능한 작업의 사다리(Ladder of Delegable Work)" 로드맵 제안.

방법론

이 논문은 새로운 모델이나 알고리즘을 제안하는 실증 연구가 아니라, 기존 문헌과 평가 결과를 종합·분석하는 포지션 페이퍼다. System 2는 의도 해석, 목표·제약 조건에 따른 추론, 스킬·툴 오케스트레이션, 결과 검증을 통해 이후 결정을 조정하는 폐루프 구조로 정의되며, System 1은 VLA·World-Action Model 등 호출 가능한 정책·스킬을, System 0은 모터 명령 등 실시간 제어를 담당한다. 평가 프레임워크는 모델 역량 평가(지식·추론)와 시스템 전체 성능 평가(독립적 결과 검증, 투명한 보고, 변화하는 환경에서의 평가 등)를 분리해서 다룬다.

실험 설정 및 결과

전통적 의미의 실험은 수행하지 않았으며, 기존 RoboDojo, Harness VLA 등 공개된 평가 결과와 벤치마크들을 재검토해 현재 에이전틱 로보틱스가 어디까지 왔는지를 정리한다. 예를 들어 동일한 플래너와 VLA를 고정했을 때 실행 메모리의 도입만으로 성능이 크게 향상된다는 기존 연구 결과 등을 근거로 제시한다. 다만 저자들은 현재까지의 증거가 지속적(sustained) 자율성, 즉 더 넓고 장기적인 책임 범위에서의 신뢰할 수 있는 자율성을 아직 입증하지 못했다고 평가한다.

한계점

서베이/포지션 논문이므로 자체적인 정량적 실험 결과가 없으며, 제시된 평가 프레임워크 역시 아직 실제로 광범위하게 검증되지 않았다. 또한 추론 시간이 길어질수록(테스트 타임 스케일링) 추론 품질은 좋아지지만 시간이 중요한 물리적 작업에서는 오히려 불리할 수 있다는 트레이드오프가 해결되지 않은 과제로 남아있다.

시사점

파운데이션 모델 기반의 에이전틱 접근은 로봇 일반화 문제에 대한 유망한 대안 경로로 제시되지만, 물리적 제약(반응 시간, 기계적 한계, 비가역적 결과 등) 하에서 검증 가능한 행동으로 변환하는 것이 핵심 과제로 남는다. 저자들은 커뮤니티가 (1) 실제 로봇 테스트를 포함한 신뢰성 있는 평가 프레임워크 개발, (2) 시간에 민감한 상황에서의 추론 효율성 개선, (3) 모델·하네스·평가 조건에 대한 표준화된 보고를 우선순위로 삼아야 한다고 제안한다.
