Editing Images into Reusable Layers via Compositional Edit-Prior Distillation

컴포지셔널 편집 사전 증류를 통해 이미지를 재사용 가능한 레이어로 편집하기

한 줄 요약

지시문 기반 이미지 편집과 재사용 가능한 RGBA 레이어 생성을 하나의 디퓨전 트랜스포머로 통합하고, 사전학습된 편집 모델의 능력을 유지시키는 온폴리시 증류 기법(C-EPD)을 더해 편집 품질과 레이어 분해 품질을 동시에 달성한 LayerEditor를 제안한다.

배경 및 문제의식

최근 Qwen-Image, FireRed-Image-Edit 같은 instruction 기반 이미지 편집 모델들은 텍스트·객체·배경을 하나로 "평탄화(flatten)"된 캔버스로 합성하기 때문에, 편집 이후 세부 요소만 다시 수정하거나 특정 요소를 재사용하려면 전체를 다시 생성해야 하고 의도치 않은 주변 영역 변형이나 경계 아티팩트가 발생하기 쉽다. 한편 이미지에서 레이어를 복원하는 "이미지 분해(decomposition)" 연구들은 편집과 별도의 단계로 최적화되어, 편집과 레이어 구조를 동시에 고려하지 못한다. Agent Banana와 같이 편집과 분해를 에이전트로 묶는 시도도 있었지만, 각 단계가 따로 학습되어 레이어 품질이 불안정하고 반복 호출·수작업 보정이 필요했다. 저자들은 "편집"과 "재사용 가능한 레이어 생성"을 하나의 통합된 생성 과정으로 다루는 것이 필요하다고 본다.

핵심 기여

  • LayerEditor: 편집된 캔버스(flattened edit)와 순서가 있는 RGBA 레이어 스택을 동시에 생성하는 통합 모델로, 레이어 개수와 레이어별 원하는 내용(사용자 지정)을 유연하게 지원한다.
  • In-Context RGB-Alpha Token Modeling: 편집 캔버스와 N개 레이어의 RGB·Alpha를 하나의 토큰 시퀀스 안에서 함께 모델링하고, 레이어 인식 회전위치인코딩(rotary coordinate)으로 동일 캔버스 좌표를 공유하면서도 레이어 식별·순서를 구분한다. 세밀한 구조와 반투명 경계를 위해 RGB 디코더와 별도로 학습된 전용 Alpha 디코더를 둔다.
  • Compositional Edit-Prior Distillation (C-EPD): 사전학습된 편집 모델(고정된 teacher)을 온폴리시로 활용해, 학생 모델의 디노이징 궤적에서 중간 상태를 샘플링하고 teacher가 같은 상태에서 다시 계산한 타깃으로 (1) 직접 편집 결과(Direct)와 (2) 예측된 레이어를 알파 합성하여 복원한 이미지(Composite) 둘 다를 지도한다. 이를 통해 레이어 출력으로 확장하는 과정에서 원래 모델이 가진 편집 충실도가 저하되는 문제를 완화한다.
  • LayerEditor-100K 데이터셋과 두 개의 벤치마크(Crello-Testset, ScaleEdit-Testset): 소스 이미지·편집 지시문·편집 결과·순서가 있는 RGBA 레이어 주석으로 구성된 대규모 페어 데이터셋과, 레이어 개수 제어·사용자 지정 레이어 콘텐츠를 체계적으로 평가하기 위한 전용 벤치마크를 구축했다.

방법론

소스 이미지 $I^{src}$, 편집 지시문 $u$, 요청 레이어 수 $N$이 주어지면 모델 $G$는 편집된 캔버스 $D$와 레이어 스택 $S={(R_i,A_i)}$를 함께 생성한다($D, S = G(I^{src}, u, N)$). 레이어들은 뒤에서 앞 순서로 알파 오버 합성되어 캔버스를 재구성한다. 구현은 FireRed-Image-Edit-1.1을 베이스로 rank-256 LoRA로 적응시키며, 모든 필드(Direct·각 레이어의 RGB·Alpha)는 가우시안 노이즈에서 함께 디노이징되는 하나의 토큰 시퀀스로 처리된다. 학습은 두 단계로 진행된다: 먼저 플로우 매칭(flow matching) 손실만으로 워밍업한 뒤, C-EPD를 결합한 손실(식 6, $L=L_{flow}+\lambda_C L_{C-EPD}$)로 공동 최적화한다. C-EPD 손실(식 4)은 학생의 Direct 속도장을 고정 teacher의 속도장에 맞추는 항과, 학생이 예측한 레이어를 합성한 이미지와 teacher가 생성한 타깃 이미지 간 차이를 맞추는 항으로 구성되며, 이 그래디언트는 디코딩·알파 합성 과정을 거쳐 레이어 예측 branch까지 전달된다.

실험 설정 및 결과

LayerEditor-100K는 Crello, PrismLayersPro, ScaleEdit 데이터를 조합해 만든 약 10만 건의 (소스, 지시문, 편집 결과, 순서 RGBA 레이어) 쌍으로, 텍스트 편집 48,329건, 객체 편집 36,858건, 포스터 전체 외형 편집 14,813건을 포함하고 레이어 수는 2~10개로 다양하다. 평가는 Crello-Testset(2,994건)과 ScaleEdit-Testset(1,000건) 두 벤치마크에서 Seedream5-Pro, FireRed+Qwen-Image-Layered 조합, QIL-Edit-SFT, RevealLayer 등과 비교해 이뤄졌다. LayerEditor는 두 벤치마크 모두에서 Composite SSIM/FID, RGBA L1, Alpha IoU 등 레이어 품질 지표와 VLM 기반 5개 항목 루브릭 점수(편집 일관성·시각 품질·레이어 분할·레이어 합성·알파 정확도)에서 대부분 최고 또는 상위권을 기록했다(예: Crello-Testset 루브릭 평균 6.00 vs. 최고 베이스라인 4.50). 레이어 수를 바꿔가며 동일 편집 내용을 다른 레이어 구조로 재구성하는 레이어-수 제어 실험과, 레이어별 내용(텍스트 줄, 개별 객체 등)을 지정하는 실험에서도 가장 우수한 제어 가능성을 보였다. 순수 이미지→레이어 분해(I2L) 과제에서도 전용 파인튜닝 없이 QIL, LayerD 등 기존 분해 전용 방법을 능가했다. Ablation에서는 C-EPD(특히 Direct 항과 Composite 항 모두)와 전용 Alpha 디코더가 각각 편집 일관성·레이어 분할·RGBA L1 개선에 기여함을 확인했다.

한계점

논문은 별도의 "한계점" 절을 명시하지 않았으나, 본문에서 드러난 제약은 다음과 같다. 비교 대상인 Seedream5-Pro가 일부 Crello-Testset 문서(5건)에서 사용 가능한 출력을 전혀 만들지 못해 해당 사례를 지표에서 제외해야 했을 만큼, 레이어드 편집 벤치마크 자체의 난이도가 높다. LayerEditor는 C-EPD 학습 과정에서 고정된 teacher 모델을 반복 호출(5 업데이트 간격)해야 해 학습 비용이 추가되며, 모델은 FireRed-Image-Edit-1.1이라는 특정 사전학습 편집 백본에 의존한다. 또한 레이어-구조 제어 실험(Table 2)에서 LayerEditor의 샘플당 추론 시간(41.5초)은 가장 빠른 FR+QIL-Control(80.0초)보다는 빠르지만 ReavealLayer(43.7초)와 비슷한 수준으로, 일부 경량 베이스라인 대비 뚜렷한 속도 우위는 아니다.

시사점

편집과 레이어 분해를 별도 단계로 다루던 기존 파이프라인과 달리, 하나의 토큰 시퀀스 안에서 편집 캔버스와 레이어를 동시에 모델링하고 온폴리시 증류로 편집 능력 저하를 방지하는 접근은, 전자상거래 콘텐츠 제작·광고 디자인처럼 생성 후에도 요소 단위로 반복 수정해야 하는 실무 워크플로우에 바로 적용 가능한 방향을 제시한다. 또한 C-EPD는 "플랫 출력 생성 모델을 구조화된(레이어드) 출력으로 확장하면서도 원래 생성 능력을 보존"하는 일반적인 문제에 대한 온폴리시 증류 적용 사례로서, 유사한 구조 확장 문제(예: 다른 구조화 출력으로의 모델 적응)에도 참고할 수 있는 설계다.
