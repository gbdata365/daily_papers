On the Design of Hyper-Connections: Simplification, Stability, and Scalability

한 줄 요약

Hyper-Connections(HC) 구조를 분해 분석하여 잔차 혼합(residual mixing)을 제거하고 메모리 접근을 공유하는 SimpleHC를 제안함으로써, 대형 언어모델 학습에서 품질은 유지하면서 학습 오버헤드를 7.0%에서 2.4%까지 줄인 연구이다.

배경 및 문제의식

Hyper-Connections는 여러 개의 잔차 스트림(residual stream)을 두고 학습 가능한 read/write 게이트와 믹싱(mixing) 연산으로 정보를 유연하게 라우팅하는 구조로, 최근 프런티어 언어모델들에 채택되고 있다. 그중 매니폴드 제약을 둔 변형인 mHC는 학습 안정성을 높였지만, 여전히 구성 요소의 역할이 충분히 규명되지 않았고 게이팅·믹싱 연산이 FLOPs로는 드러나지 않는 추가적인 메모리 트래픽 비용을 유발해 실제 학습 시간을 7~27%까지 늘리는 문제가 있었다. 저자들은 "더 단순한 설계로 학습 비용을 줄이면서 모델 품질과 안정성을 유지할 수 있는가"라는 질문을 던진다.

핵심 기여

  • HC의 세 구성 요소(read 게이트, write 게이트, 잔차 혼합)를 체계적으로 분해하여, 혼합 없이 학습된 read/write 게이팅만으로도 mHC에 필적하는 성능을 낼 수 있음을 보임.
  • 비제약(unconstrained) 혼합은 품질을 높이지만 Sinkhorn 제약을 걸면 그 이득이 크게 줄어든다는 것을 규명하고, 비제약 혼합이 누적 증폭 등 전파 위험을 동반함을 지적.
  • 잔차 혼합을 제거한 "항등 전이(identity transition)" 구조와, 서브레이어마다 반복적으로 전체 상태를 읽고 쓰는 비용을 줄이는 "공유 메모리 접근(shared memory access)" 기법을 결합한 SimpleHC 아키텍처를 제안.
  • 전용 Triton/DeepGEMM 커널을 구현해 실제 학습에서 오버헤드를 거의 제거함.

방법론

SimpleHC는 잔차 혼합 행렬 $H_l^{res}$를 항등행렬로 고정하여 구조를 단순화하고, read/write 게이트만 유지한 채 업데이트를 덧셈 형태로 누적한다. 이 경우 임의의 서브레이어 상태는 직전 출력들의 가중합(스칼라 보정, scalar correction)으로 정확히 재구성될 수 있어, 확장된 $nC$ 차원 상태를 중간에 저장할 필요가 없다. 여기에 더해 그룹(기본 $K=4$)으로 묶은 여러 서브레이어의 게이트를 공통의 "그룹 진입 상태(group-entry state)" 하나로부터 한 번에 계산하는 공유 메모리 접근 방식을 도입해, 상태 읽기/쓰기 횟수를 기존 대비 최대 4배까지 줄인다. 이론적 메모리 접근량 분석 결과 $K=4$일 때 서브레이어당 트래픽이 기존 mHC(융합 구현 기준 18C)의 절반 수준인 9C로 감소한다.

실험 설정 및 결과

15B(활성 파라미터 1B)·30B(활성 2B) MoE 모델(DeepSeek MoE + MLA 백본)을 시퀀스 길이 8192로 학습하며 MMLU, HellaSwag, MATH, MBPP, C3 등 다수의 지식·추론·수학·코드·중국어 벤치마크로 평가했다. SimpleHC는 15B·30B 모델 모두에서 mHC, identityHC와 비슷하거나 더 나은 평균 점수(30B에서 63.1 vs mHC 62.9)를 보였고, 폭(hidden size) 1024~6144 구간에서 효율적 구현 기준 학습 오버헤드가 최대 6.3%에서 최대 폭 기준 2.4%까지 낮아져 mHC(최대 폭 기준 약 7.0%)보다 훨씬 효율적이었다. 또한 230B급 MoE 모델을 10배 학습률로 스트레스 테스트한 결과 mHC는 그래디언트 노름이 약 1.9×10^6까지 치솟는 반면 SimpleHC와 identityHC는 안정적으로 유지되었으며, 활성화 저장 메모리도 mHC 대비 약 31% 절감되었다.

한계점

논문은 비제약 혼합이 이론적으로 더 높은 품질 이득을 줄 수 있음을 인정하면서도 SimpleHC에서는 안정성을 위해 이를 포기했다고 명시한다. 또한 공유 메모리 접근은 서브레이어별 독립 게이트 파라미터는 유지하되 게이트를 계산하는 입력 상태만 그룹 진입점으로 공유하는 근사이므로, 그룹 크기 $K$가 지나치게 커지면(예: $K=8$) 성능이 소폭 저하됨을 실험으로 보였다. 세부적인 안정성 실패 원인 분석이나 더 큰 스케일(230B 초과)에서의 전면적 검증 등은 논문에 명시되지 않음.

시사점

SimpleHC는 복잡한 잔차 혼합 없이도 핵심 성능을 유지할 수 있음을 보여주며, 아키텍처 단순화와 실행 효율화(커널·메모리 접근 최적화)가 함께 이루어질 때 실제 학습 비용을 크게 줄일 수 있다는 점을 시사한다. 이는 향후 파운데이션 모델 설계에서 복잡한 구조적 혁신보다 효율적인 실행 경로 설계가 실질적 이득을 가져올 수 있음을 보여주는 사례로 평가된다.
