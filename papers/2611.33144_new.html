PyRUA-Dex: Learning Programmatic Policies for Dexterous Bimanual Manipulation with Coding Agents

파이루아덱스: 코딩 에이전트를 통한 양손 손재주 조작을 위한 프로그래매틱 정책 학습

한 줄 요약

코딩 에이전트들이 시뮬레이션에서 탐색과 정제 두 단계를 거쳐 사람 시연 데이터 없이도 양손 다지(多指) 손 조작을 위한 '프로그램 형태의 정책(programmatic policy)'을 작성하게 하여, 피아노 연주·서예 등 실제 로봇 작업에서 기존 학습 기반 정책을 능가하는 프레임워크 PyRUA-Dex를 제안한다.

배경 및 문제의식

다지 로봇 손의 정교한 조작(dexterous manipulation) 학습은 고품질 시연 데이터 부족이라는 근본적 제약에 부딫힌다. 사람 영상에서의 리타게팅은 부정확하고, 원격조작(teleoperation)은 손끝 접촉에 대한 힘 피드백을 조작자에게 주지 못하며, 외골격 기반 수집은 확장성이 낮다. 또한 수집된 데이터는 특정 손 모델에 종속되어 새로운 손에는 재학습이 필요하다. 신경망 가중치 대신 프로그램으로 정책을 표현하는 '프로그래매틱 정책'은 검증과 해석이 쉽지만, 기존 연구들은 로봇 팔이나 평행 그리퍼 중심이었고, 다지 손의 경우 에이전트가 매 시행마다 직접 관찰·행동하며 막대한 토큰을 소비하면서도 성공률이 낮았다. 저자들은 '코딩 에이전트가 개발 단계에서 한 번만 학습하여, 이후에는 추가 비용 없이 안정적으로 동작하는 프로그램을 만들 수 있는가'라는 질문을 제기한다.

핵심 기여

  • 시연 없이 코딩 에이전트가 다지 양손 조작의 프로그래매틱 정책을 개발하도록 하는 에이전트 기반 프레임워크 제안. 결과물은 테스트 시 언어모델 호출 없이 동작하는 고정된(frozen) 코드임.
  • 손끝 촉각 피드백을 활용한 2단계(탐색→정제) 개발 절차: 여러 에이전트가 병렬로 작업 기술을 탐색·공유하고, 이후 무작위화된 배치(layout)들에 대해 견고성과 효율성을 높이는 정제를 수행.
  • Bench2Dex와 DexJoCo 두 시뮬레이션 벤치마크 및 22자유도(DoF) 양손 로봇 실제 실험을 통한 광범위한 검증. Bench2Dex에서 SOTA(72.9점) 달성.

방법론

전체 학습은 시뮬레이션에서 이뤄진다. 1단계(탐색)에서는 8개의 에이전트가 각자의 학습용 배치에서 상태 리셋(state reset)을 활용해 동일 과제를 병렬로 탐색하며 공유 메모리를 통해 진행 상황을 주고받는다. 이후 '증류(distilling) 에이전트'가 성공한 시도들을 작업 라이브러리와 하나의 프로그램으로 압축한다. 2단계(정제)에서는 한 에이전트가 단계별 실패 분석(stage-wise failure analysis)을 통해 프로그램에서 가장 신뢰도가 낮은 단계(병목)를 찾아 무작위화된 배치들에서 반복 개선하고, 보지 못한 배치에서 성능이 떨어지지 않을 때만 수정안을 채택한다. 모든 로봇 손은 '코드박스(codebox)'라는 동일한 손·팔·센싱 호출 계층을 통해 제어되므로 하나의 절차가 다양한 손 모델에 적용 가능하다. 최종 정책은 일반 Python 코드로, 보정된 카메라·관절 위치·손끝 촉각을 입력으로 받아 로봇의 제어 주기에 맞춰 동작하며, 매 에피소드마다 장면을 다시 측정하기 때문에 배치가 변해도 견고하다. 실제 로봇 적용 시에는 실제 장면으로부터 시뮬레이션을 구성(real-to-sim)하고, 고정된 프로그램을 로봇에 적용(sim-to-real)한 뒤, 로봇에서 얻은 피드백으로 다음 라운드의 정제를 위해 시뮬레이션을 갱신하는 과정을 반복한다.

실험 설정 및 결과

12종의 팔-손 조합을 평가하는 Bench2Dex 벤치마크에서 PyRUA-Dex는 72.9점으로 기존 모든 학습 기반 정책을 능가하는 SOTA를 기록했으며, 동일 모델(GPT-6 Astra)이 온라인으로 직접 행동하는 방식보다 동일한 스텝 예산 내에서 2.4배 높은 성공률을 보였다. Allegro 손 기반의 DexJoCo 벤치마크에서는 완전 무작위화 조건에서 81.0%의 성공률을 달성해 가장 강력한 학습 기반 정책(40.3%)을 크게 앞섰고, 모든 세부 과제에서 각 학습 기반 정책보다 우수했다. 22자유도 양손을 갖춘 실제 로봇 플랫폼에서는 피아노 연주, 서예, 물건 정리 등의 작업을 수행했으며, 악보로부터 새로운 피아노 곡을 익히는 데 약 30분이 걸렸다.

한계점

코딩 에이전트는 기하학적 순서나 타이밍이 중요한 동작은 잘 작성하지만, 힘과 미끌림을 지속적으로 제어해야 하는 작업(프라이팬 다루기, 손에서 손으로 따르기, 직소 퍼즐 등)에는 약하며, 이런 작업에서는 학습 기반 정책이 더 우수했다. 시뮬레이션의 촉각 센서가 접촉을 거칠게 렌더링하기 때문에 프로그램은 주로 관절 지연(joint lag)으로 접촉을 추론하는데, 이는 정밀한 접촉 제어의 한계로 이어진다. 또한 정제는 이미 일부 배치에서 성공하는 단계를 강화하는 데 효과적일 뿐, 전혀 성공하지 못하는 단계는 탐색 단계의 문제로 남는다. 각 작업은 개별적으로 학습되며, 실제 로봇에서의 신뢰도는 반복적인 하드웨어 시행이 아닌 보정된 시뮬레이션에서 측정되었다는 한계도 있다.

시사점

이 연구는 신경망 가중치 학습 없이도 코딩 에이전트가 검증 가능하고 해석 가능한 프로그램 형태로 복잡한 다지 손 조작 정책을 만들어낼 수 있음을 보여준다. 테스트 시 언어모델 호출이 필요 없어 토큰 비용과 지연을 없애면서도 기존 학습 기반 정책보다 높은 성공률과 견고성을 달성한 점은, 데이터가 부족한 로보틱스 분야에서 에이전트 기반 개발이 실용적 대안이 될 수 있음을 시사한다.
