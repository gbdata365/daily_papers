Recursive Code World Models: Building Complex Worlds through Recursive Scene Programs

재귀 코드 월드 모델: 재귀적 장면 프로그램을 통한 복잡한 세계 구축

단일 참조 이미지로부터 복잡한 3D 세계를 코드(실행 가능한 Three.js 프로그램)로 재구성할 때, "전체 확립 → 부분 재귀 해결 → 전체 재검토"라는 동일한 절차를 모든 깊이(depth)에서 재귀적으로 호출하는 Recursive Code World Models(RCWM)를 제안한다.

한 줄 요약

단일 참조 이미지로부터 복잡한 3D 세계를 코드(실행 가능한 Three.js 프로그램)로 재구성할 때, "전체 확립 → 부분 재귀 해결 → 전체 재검토"라는 동일한 절차를 모든 깊이(depth)에서 재귀적으로 호출하는 Recursive Code World Models(RCWM)를 제안한다.

배경 및 문제의식

최근 코드 월드 모델(code world model)은 세계를 픽셀이 아닌 실행 가능한 프로그램으로 표현하여, 구조와 상태를 직접 검사·편집할 수 있고 물리 시뮬레이션과의 결합도 용이하다는 장점을 갖는다. VIGA, Thinking in Blender(SEIG), img2threejs 같은 최근 비전-언어 코딩 에이전트들은 이미지-투-코드 장면 재구성을 프로그램 생성과 렌더 기반 시각적 검증을 반복하는 방식으로 수행해왔다.

그러나 표현력 있는 코드 표현만으로는 "복잡한 세계를 어떻게 구성할 것인가"라는 문제가 해결되지 않는다. 예를 들어 마을 하나를 재구성한다고 할 때, 거리와 지형이 전체 레이아웃을 정하고, 건물은 파사드를, 파사드는 창문·간판·장식을 포함하는 식으로 규모가 중첩된다. 전체 장면 단위로만 반복 검토하면 작은 구조를 놓치기 쉽고, 반대로 부분을 독립적으로만 세밀하게 편집하면 간판이 옆 창문을 가리거나 다리가 강둑과 어긋나는 등 부분 간 정합성이 깨지는 문제가 발생한다. 이 긴장 관계는 마을-건물 수준뿐 아니라 건물-파사드, 파사드-창문 등 모든 스케일에서 동일하게 나타난다. 저자들은 이 문제를 해결하려면 복잡한 세계의 구성 과정 자체가 재귀적이어야 한다고 주장한다.

핵심 기여

논문은 세 가지 기여를 제시한다. 1. Recursive Scene Programs (RSP): 명시적인 자식 참조(child reference), 편집 가능한 구조, 공유 의존성을 가진 중첩된 서브월드들의 합성 프로그램으로 복잡한 세계를 표현하는 실행 가능한 장면 표현. 2. 재귀적 코드 세계 구성 절차: 동일한 시각적 솔버가 각 서브월드를 확립하고, 미해결 부분에 대해 재귀적으로 자신을 호출해 재구성한 뒤, 복귀 시 전체 구성을 재검토·정제하는 완전한 재귀 프로세스. 카메라 투영을 상속하고, 시각적으로 유도된 재귀 호출과 부모 단계에서의 능동적 정제를 결합한다. 3. 참조 기반 재구성·평가: Three.js 기반의 파라미터화된 컴파일러로 프레임워크를 구현하고, 동일 베이스 모델을 사용하는 이미지-투-장면-프로그램 베이스라인들과 전체 장면·부분 재구성 성능을 비교·평가하며, 구성 순서·재귀 깊이·부모 재검토의 역할을 어블레이션으로 분석한다.

방법론

RCWM은 참조 이미지 $I^\star$로부터 실행 가능한 파라미터화된 장면 프로그램 $P$를 재구성하는 것을 목표로 한다. 프로그램을 실행(Exec)하면 3D 장면 $S$가 만들어지고, 카메라 설정 $\kappa$로 렌더링(R)하면 이미지 $\hat I$가 생성된다($S=\mathrm{Exec}(P)$, $\hat I = R(S;\kappa)$).

구성 구조: 세계 프로그램은 깊이 $k$에 위치한 노드 $u_i^{(k)}$들의 중첩 구조로 조직되며, 각 노드는 객체·상호작용 어셈블리·연속적인 지형 영역 등을 나타낼 수 있다. 부모 프로그램은 지역 생성 코드, 편집 가능한 파라미터, 자식 프로그램에 대한 참조와 배치 규칙을 포함하며, Compose 연산으로 선택된 자식 참조를 새 후보 프로그램으로 교체하면서 부모의 나머지 구조는 그대로 유지한다.

재귀적 구성 알고리즘은 동결된(frozen) 비전-언어 코딩 에이전트 $A$에 의해 구동되는 솔버 $F$로 정의되며, 각 호출은 세 단계로 이루어진다. 1. 전체 확립(Establish the whole): 현재 서브월드의 렌더링과 참조 이미지를 비교하여 레이아웃, 공유 구조, 구성요소 간 인터페이스를 정제한다. 2. 부분 준비 및 재귀적 구성(Prepare and recursively construct the parts): 미해결 자식들을 선택하고, 참조 이미지와 카메라를 부모 좌표계에 맞춰 잘라낸(crop) 후, 동일한 솔버 $F$를 각 자식에 재귀 호출한다. 이때 카메라 포즈는 상속되며 내부 파라미터 행렬만 크롭 윈도우와 배율에 맞게 변환된다(호모그래피 형태의 크롭 카메라 연산). 3. 합성·정제·복귀(Compose, refine, and return): 복귀한 자식 프로그램들을 부모 프로그램에 합성한 뒤, 합성된 전체 장면을 다시 렌더링하여 경계·공간 관계·공유 오류 등을 검토하고 정제한다. 더 이상 실행 가능한 불일치가 없으면 복귀(RETURN)하고, 그렇지 않으면 예산이 남는 한 같은 사이클을 반복한다.

이 세 단계는 트리의 모든 깊이(루트, 건물, 파사드, 창문 등)에서 동일하게 재사용되는 완전한 재귀 프로세스이며, 재귀가 어떤 하위 문제를 "완전히 풀 것인지"를 결정하고 병렬성은 단지 호환되는 branch들의 스케줄링만 바꾼다는 점을 구분한다. 구현체는 Codex 커맨드라인 에이전트를 사용해 재귀의 각 노드를 하나의 세션으로 실행하며, 결과물은 Three.js로 실행 가능한 프로그램이다.

실험 설정 및 결과

데이터: 전체 장면 참조 5개(city-full, snow-village, island-harbor, medieval-village, japan-island)와 지역 크롭 5개(school-block, police-corner, park-lake, shop-row, valley-village)를 사용했다. 이미지는 CC0 "Isometric city" 스프라이트 팩과 WorldClaw 데모 렌더링에서 가져왔으며, 재구성에는 원본 프롬프트·지형·에셋 없이 이미지만 사용했다.

비교 대상: SEIG(Thinking in Blender 재현), VIGA, img2threejs를 동일 베이스 모델(OpenAI GPT 계열, 높은 reasoning-effort의 Codex CLI 에이전트)로 비교했다.

평가지표: PSNR, SSIM, Canny 엣지 기반 Edge F1(3픽셀 허용오차), LPIPS(AlexNet 백본), CLIP ViT-B/32 임베딩 코사인 유사도를 사용했다.

결과: RCWM은 10개 참조 장면 전부에서 가장 높은 PSNR과 가장 낮은 LPIPS를 기록했고, 10개 중 9개에서 SSIM도 최고였다(valley-village에서만 VIGA가 근소하게 우세). 전체 장면과 지역 크롭 모두에서 일관된 개선을 보였다.

어블레이션: Flat+zoom(한 번의 편집 과정에서 크롭·줌 도구만 사용), Local→global, Global→local, Recursive fixed 2-level(루트와 직속 자식만 재귀), Recursive free-depth(자식도 추가로 재귀 호출 가능) 다섯 가지 구성 방식을 비교했다. medieval-village에서 free-depth 변형은 3단계 깊이·33개 노드까지 확장되며, fixed 2-level 대비 전체 PSNR이 16.8→19.0, 지역 SSIM이 0.52→0.60으로 향상되어 다섯 방식 중 최고 성능을 보였다. school-block에서는 두 재귀 변형이 비슷한 수준(자유 깊이도 실질적으로 2단계에 그침)이었다. 이는 더 깊은 재귀 호출이 세밀한 디테일과 전체 충실도를 함께 향상시킬 수 있음을 시사하지만, 그 효과는 장면에 따라 다르다.

추가로 논문은 전달된 프로그램을 회전·상승·근접 카메라로 재렌더링해 일관된 3D 구조를 보여주고, 실제 기록된 재귀 호출 트리(예: School Block은 깊이 2, 노드 9개, 세션 18개, 호출 8회)를 제시해 재귀 실행 과정을 시각적으로 뒷받침했다.

한계점

논문이 명시한 한계는 다음과 같다. - 단일 뷰 입력이기 때문에 가려진 형상(hidden geometry)과 절대 스케일이 모호하게 남으며, 시각적 검사만으로는 오류를 놓칠 수 있다. - 반복적인 정제와 구성요소 간 상호작용은 상당한 연산량을 요구하며, 수렴이 보장되지 않는다. - 평가 대상 장면 수가 제한적이고(전체 장면 5개, 크롭 5개), 단일 베이스 모델에 대한 단일 실행 결과이며, 어블레이션도 두 장면에 대해서만 수행되었다. 더 큰 규모의 벤치마크, 반복 실행, 공간 관계에 대한 사람 평가가 더 강건한 평가를 위해 필요하다고 밝히고 있다.

시사점

RCWM은 "복잡한 세계를 어떻게 단계적으로 구성할 것인가"라는 문제를, 표현(RSP)과 절차(재귀적 솔버)를 분리하지 않고 하나의 통일된 재귀 원리로 접근했다는 점에서 코드 기반 월드 모델링 연구에 새로운 설계 축을 제시한다. 특히 각 서브월드가 독립된 지각-편집 루프를 갖되 부모 재검토를 통해 경계·공간 관계·공유 오류를 사후에 바로잡는 global-local-global 패턴은, 3D 장면 재구성뿐 아니라 계층적 구조를 가진 다른 생성·편집 문제(예: UI 생성, 문서 구조화, 대규모 코드베이스 리팩토링)에도 일반화될 수 있는 아이디어로 보인다. 다만 저자들 스스로 인정하듯 연산 비용과 수렴 보장의 부재는 실용적 적용을 위해 해결해야 할 과제이며, 프론티어 코딩 에이전트의 성능에 크게 의존한다는 점도 향후 개선 방향을 시사한다.
