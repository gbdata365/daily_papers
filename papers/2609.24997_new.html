VideoGen-Agent: Reinforcing Video Generation Agents

비디오젠에이전트: 영상 생성 에이전트를 강화학습으로 훈련하기

텍스트-비디오 생성 모델이 전문 지식, 특정 정체성 보존, 물리 법칙, 사건 순서 등을 요구하는 프롬프트에서 취약하다는 점에 착안해, 검색·시뮬레이션·생성·검증 도구를 다중 턴으로 조율하는 멀티모달 에이전트를 멀티태스크 에이전틱 강화학습으로 훈련하여 자체 벤치마크 VABench에서 기저 생성 모델 대비 19.1점의 성능 향상을 달성했다.

한 줄 요약

텍스트-비디오 생성 모델이 전문 지식, 특정 정체성 보존, 물리 법칙, 사건 순서 등을 요구하는 프롬프트에서 취약하다는 점에 착안해, 검색·시뮬레이션·생성·검증 도구를 다중 턴으로 조율하는 멀티모달 에이전트를 멀티태스크 에이전틱 강화학습으로 훈련하여 자체 벤치마크 VABench에서 기저 생성 모델 대비 19.1점의 성능 향상을 달성했다.

배경 및 문제의식

최근 영상 생성 모델은 시각적 화질은 뛰어나지만, 사전 학습 이후 등장한 지식이나 사건을 반영하지 못하고, 인물의 시각적 정체성을 영상 전체에서 일관되게 유지하지 못하며, 충돌·낙하 등에서 물리 법칙을 위반하거나, 프롬프트가 지정한 순서대로 여러 단계를 묘사하지 못하는 한계가 있다. 기존 에이전틱 영상 생성 연구는 대개 단일 목적(특정 과제)에 특화되어 있어, 이질적인 과제들에 걸쳐 적절한 도구(정체성 보존을 위한 시각 참조, 물리 동작을 위한 시뮬레이션 등)를 스스로 선택하고 중간 관찰을 바탕으로 다음 행동을 결정하는 범용 에이전트가 부재했다.

핵심 기여

  1. 절차적 지식, 단일/다중 개체 정체성, 물리 시뮬레이션, 구성적 장면, 다중 샷(총 6개 과제 범주)에 걸쳐 증강·생성·검증 도구를 조율하는 멀티모달 에이전트 VideoGen-Agent 제안.
  2. 교사 증류 궤적으로 지도 미세조정(SFT) 후 GRPO 기반 멀티태스크 에이전틱 강화학습으로 정제하는 2단계 학습 파이프라인 구축.
  3. 6개 능력 범주, 600개 프롬프트로 구성된 held-out 벤치마크 VABench 공개.
  4. VABench에서 기저 T2V 생성기 대비 19.1점(56.5→75.6) 향상, 생성 도구만 업그레이드해도 추가 학습 없이 86.1점까지 향상됨을 입증하여 학습된 도구 사용 전략이 향후 생성 도구 발전과 상호 보완적임을 시사.

방법론

에이전트는 프롬프트와 과거 행동·관찰 이력을 바탕으로 추론-행동-관찰 루프를 반복하며 도구를 선택한다. 검색(텍스트/이미지), 시뮬레이션(물리 코드), 생성(T2V/I2V/R2V/M2V), 검증(객체 탐지, 깊이 추정) 도구를 갖춘 공통 인터페이스를 사용한다. 데이터는 Claude Opus 4.7로 6개 범주별 프롬프트를 생성하고, Gemini 3.1 Pro 또는 Claude Opus 4.7을 교사 에이전트로 사용해 도구 사용 궤적 24K개를 수집(16K는 SFT, 8K는 RL용)했다. SFT는 Qwen3-VL-8B-Instruct를 기반으로 다음 토큰 예측으로 학습하며, 실패한 행동 구간은 손실에서 제외하되 맥락에는 유지한다. RL 단계는 GRPO를 사용해, 형식 보상(도구 호출 유효성)·VLM 보상(범주별 루브릭 기반 영상 품질)·도구 사용 보상(적절한 도구 선택·출력 활용)을 가중합한 하이브리드 보상(0.1/0.5/0.4)으로 정책을 최적화하며, 그룹 상대 정규화에 이어 과제별 정규화(task advantage normalization)를 추가로 적용해 범주 간 학습 신호 균형을 맞춘다.

실험 설정 및 결과

VABench(범주당 100개, 총 600개 프롬프트)에서 Gemini 3.1 Pro를 심판으로 사용해 평가했다. 훈련에 사용된 Toolset 1 구성에서 VideoGen-Agent는 전체 75.6점으로 기저 T2V 생성기 Seedance 1.0(56.5점) 대비 19.1점 향상되었고, 최강 독립 베이스라인인 Seedance 2.0(73.2점)도 소폭 상회했다. 생성 도구만 Toolset 2(더 강력한 생성 모델)로 교체하면 에이전트 정책은 그대로인 채로 전체 점수가 86.1점까지 상승했으며 6개 범주 모두에서 최고 점수를 기록했다(다중 개체 정체성은 65.3→86.7점으로 최대 개선). 인간 평가에서는 VideoGen-Agent-Toolset 2가 Seedance 2.0 대비 84.3%의 비교에서 선호되었다. Ablation에서는 프롬프트 재작성(57.3)과 제로샷 도구 사용(59.5)만으로는 개선 효과가 제한적이며, SFT(69.2)와 RL(75.6)이 각각 유의미하게 기여함을 확인했고, VLM 보상 및 도구 보상 제거 시 각각 73.3, 71.2로 성능이 하락해 두 보상 요소의 기여도 검증되었다.

한계점

논문은 생성 도구의 품질과 지연시간, 검증 피드백의 커버리지, 그리고 훈련에 포함된 6개 과제로 범위가 제한되어 있다는 점을 한계로 명시한다. 향후 개선 방향으로는 에이전트 자신의 궤적에 대한 온-폴리시 증류, 더 정교한 영상 이해 모델을 통한 세밀한 피드백, 더 빠르고 고품질인 생성 도구 도입 등을 제시한다.

시사점

멀티태스크 에이전틱 강화학습으로 학습된 도구 사용 전략은 훈련 시 사용하지 않은 더 강력한 생성 도구로 교체해도 추가 학습 없이 성능이 향상되는 것을 보여주어, 에이전트의 도구 조율 능력과 개별 생성 모델의 발전이 상호 독립적으로 결합될 수 있음을 시사한다. 이는 향후 생성 모델이 계속 발전하더라도 한 번 학습된 에이전트 정책이 지속적으로 이득을 얻을 수 있는 구조를 제안한다는 점에서 실용적 가치가 크다.
