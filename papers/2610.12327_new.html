SparseDecoding: Decoding-Aware Pruning for Accurate and Efficient LLM Inference

스파스디코딩: 정확하고 효율적인 LLM 추론을 위한 디코딩 인지형 가지치기

기존 LLM 가지치기(pruning) 방법들이 고정된 텍스트로 보정(calibration)하는 것과 달리, 자기회귀적 디코딩 중 모델이 스스로 생성한 토큰으로 인한 활성값 분포의 변화(distribution shift)를 반영하여 보정함으로써 정확도와 추론 속도를 동시에 개선하는 디코딩 인지형(decoding-aware) 가지치기 프레임워크 SparseDecoding을 제안한다.

한 줄 요약

기존 LLM 가지치기(pruning) 방법들이 고정된 텍스트로 보정(calibration)하는 것과 달리, 자기회귀적 디코딩 중 모델이 스스로 생성한 토큰으로 인한 활성값 분포의 변화(distribution shift)를 반영하여 보정함으로써 정확도와 추론 속도를 동시에 개선하는 디코딩 인지형(decoding-aware) 가지치기 프레임워크 SparseDecoding을 제안한다.

배경 및 문제의식

LLM 추론의 디코딩 단계는 메모리 바운드(memory-bound) 특성으로 인해 지연시간을 크게 좌우한다. 헤시안(Hessian) 기반 레이어별 학습 불필요(training-free) 가지치기가 유력한 해법이지만, 기존 방법들은 교사 강제(teacher forcing) 방식으로 사전 수집된 자연 시퀀스에서 헤시안을 계산한다. 그러나 실제 디코딩 중에는 모델이 스스로 생성한 토큰이 입력에 계속 추가되므로, 초기 디코딩 단계의 가지치기 오류가 이후 예측과 컨텍스트를 바꾸어 활성값 분포가 보정 시점과 점점 달라지는 분포 변화가 발생한다. 또한 실제 속도 향상을 가져오는 기존 가지치기 방법들은 주로 희소 행렬-행렬 곱(SpMM)을 대상으로 하여, 디코딩을 지배하는 희소 행렬-벡터 곱(SpMV) 연산에 대한 지원이 제한적이다.

핵심 기여

  • 디코딩 단계에서 활성값 불일치(activation discrepancy)가 처음 12 디코딩 스텝 내에 플래토(plateau)의 90%까지 빠르게 도달한 뒤 안정화된다는 관찰(Figure 1a)과, 기존 2:4 희소 텐서 코어 커널이 prefill 단계에서는 1.31~1.46배 가속하지만 디코딩 단계에서는 오히려 밀집(dense) 연산보다 느린 0.85~0.87배의 속도를 보인다는 관찰(Figure 1b)을 제시.
  • 알고리즘 축에서, prefill을 제외한 밀집 모델의 자기회귀적 생성 과정에서 수집한 레이어별 활성값으로 보정 행렬을 구성하여 가지치기 목표를 실제 디코딩 활성값에 맞추는 방법 제안.
  • 시스템 축에서, 비트마스크 인덱싱과 고정-스텝 순회를 활용한 최적화된 N:M 희소 행렬-벡터 연산 커널 개발.
  • Llama-3.1-8B, Llama-3.3-70B, Qwen3-14B/32B 등 대표적인 LLM에서 장문 생성 벤치마크 상 기존 고정 텍스트 보정 방식을 일관되게 능가하며, A100 GPU에서 최대 1.48배의 종단간(end-to-end) 실측 디코딩 속도 향상을 달성.

방법론

SparseDecoding은 먼저 밀집 모델이 LongWriter와 같은 프롬프트에 대해 자기회귀적으로 생성한 토큰들로부터(prefill 단계는 제외) 레이어별 활성값을 수집하여 보정 행렬을 구성한다. 이렇게 구성된 보정 데이터는 Hessian 기반 OBS(Optimal Brain Surgeon) 계열의 학습 불필요 가지치기 틀에서 활용되어, 디코딩 시 실제로 나타나는 활성값 분포와 가지치기 목표 사이의 간극을 줄인다. 시스템 측면에서는 N:M 희소 패턴에 특화된 행렬-벡터 곱 커널을 설계하여, 0이 아닌 위치를 최하위 설정 비트(least significant set bit)를 찾는 비트 스캔 연산으로 복원하고, 행렬 형태와 희소 패턴에 따라 출력 타일 크기·워프 수·파이프라인 단계·축소(reduction) 전략을 자동 튜닝하며, 병렬성이 필요한 경우 축소 연산을 여러 프로그램으로 분할해 atomicAdd로 결합한다.

실험 설정 및 결과

  • WritingBench (Qwen3-14B/32B, 50% 및 8:16 구조적 희소성): SparseDecoding은 고정 텍스트(C4)로 보정한 기존 방식보다 전체 점수에서 일관되게 우수(예: Qwen3-14B 50% 희소성에서 SparseDecoding 5.35점 vs C4 4.62점, 밀집 기준 5.97점).
  • 보정 데이터 비교(Pile, RedPajama vs SparseDecoding): 2:4 희소성에서 격차가 특히 두드러져, Qwen3-14B의 경우 Pile(2.68점)·RedPajama(2.62점) 대비 SparseDecoding(4.18점)이 밀집 기준(5.97점)에 훨씬 근접.
  • 추론 속도: A100 GPU에서 종단간 실측 디코딩 속도 최대 1.48배 향상.

한계점

논문에 별도의 "한계점" 절은 명시되지 않았다. 다만 본문에서 드러나는 전제로, 보정 데이터 수집 자체가 밀집 모델의 자기회귀적 생성을 거쳐야 하므로 고정 텍스트 보정보다 준비 과정에 추가 연산이 필요하며, 2:4와 같은 매우 높은 구조적 희소성 수준에서는 여전히 밀집 모델 대비 성능 격차(예: Qwen3-14B 2:4에서 4.18점 vs 밀집 5.97점)가 남아있음을 결과 표에서 확인할 수 있다.

시사점

장문 생성이 일반화된 오늘날의 LLM 서비스 환경에서, 가지치기의 보정 단계를 실제 추론 조건(자기회귀적 디코딩)에 맞추는 것이 정확도 손실을 크게 줄일 수 있음을 보여준다. 이는 가지치기뿐 아니라 양자화(quantization) 등 다른 학습 불필요 압축 기법에서도 "보정 데이터와 실제 추론 시 입력 분포의 일치"라는 설계 원칙이 폭넓게 적용될 수 있음을 시사한다.
