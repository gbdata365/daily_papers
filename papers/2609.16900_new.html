RiskChainBench: A Benchmark for Obfuscated Platform Message Restoration and Evidence-Grounded Web Investigation

RiskChainBench: 난독화된 플랫폼 메시지 복원과 증거 기반 웹 조사를 위한 벤치마크

RiskChainBench는 이모지·동음이의어 치환·한자 분해 등으로 위장된 플랫폼 메시지의 "복원"과, 그 메시지가 가리키는 웹사이트에 대한 "증거 기반 위험 조사"를 하나의 사슬로 연결해 평가하는 벤치마크로, 두 단계를 따로 측정할 때는 드러나지 않는 '복원 오류가 웹 조사 결과로 전파되는 손실'을 정량화한다.

한 줄 요약

RiskChainBench는 이모지·동음이의어 치환·한자 분해 등으로 위장된 플랫폼 메시지의 "복원"과, 그 메시지가 가리키는 웹사이트에 대한 "증거 기반 위험 조사"를 하나의 사슬로 연결해 평가하는 벤치마크로, 두 단계를 따로 측정할 때는 드러나지 않는 '복원 오류가 웹 조사 결과로 전파되는 손실'을 정량화한다.

배경 및 문제의식

음란물·사기·도박·불법거래 등을 홍보하는 계정들은 검열을 피하기 위해 이모지 삽입, 동음이의어·유사 문자 치환, 한자 분해, 불필요한 기호 삽입 등으로 메시지를 위장하면서도 사람은 이해할 수 있게 만든다. 이런 메시지에는 변형된 도메인이나 접속 코드, 행동 지침이 담겨 사용자를 외부 웹페이지로 유도한다. 기존 연구는 (1) 난독화된 텍스트의 복원·분류를 다루는 벤치마크와 (2) 위험한 웹페이지에 대한 에이전트의 안전한 조사 행동을 다루는 벤치마크를 서로 독립적으로 발전시켜 왔다. 그러나 메시지 복원 단계에서 발생한 작은 오류가 이후 실제로 조사하게 되는 목적지 자체를 바꿔버릴 수 있음에도, 두 영역을 분리해서 평가하면 이러한 '단계 간 연쇄 손실'을 포착할 수 없다는 문제의식에서 이 연구가 출발한다.

핵심 기여

  1. 메시지 복원 → 목적지(진입점) 식별 → 웹 탐색 → 증거 기반 위험 판단으로 이어지는 과정을 하나의 "진입점으로 연결된(entry-linked)" 사슬로 정식화했다.
  2. 600개의 합성 소스 세션에서 파생된 3,600개의 토큰-텍스트 복원 입력과, 이에 대응하는 사람이 직접 라벨링한 600개의 로컬 웹 환경을 구축했다.
  3. 동일한 10개의 최신 모델을 텍스트 전용 복원(Task 1)과 VLM 기반 웹 에이전트(Task 2) 두 역할로 각각 평가한 뒤, 두 결과를 오프라인으로 결합함으로써 실패가 복원 단계에서 발생했는지 웹 조사 단계에서 발생했는지를 구분할 수 있게 했다.

방법론

  • 평가 단위: 웹사이트를 기본 단위로 삼고, 하나의 웹사이트에 여러 메시지 변형을 매핑한다. 각 사례는 로컬 웹 환경, 메시지 집합, 사람이 매긴 사이트 판정(위반/비위반/증거불충분 및 세부 위반 유형)으로 구성된다.
  • Task 1 (메시지 복원): 모델은 난독화된 메시지만 입력받아 원문 메시지, 행위 의도, 순위가 매겨진 진입점(목적지) 후보를 복원해야 하며, 이 단계에서는 웹페이지나 도메인 평판 정보에 접근할 수 없다. 복원 결과는 웹 관찰 이전에 고정(freeze)되어 이후 수정이 불가능하다.
  • 벤치마크 구축: 2,500개의 오프라인 웹사이트 풀에서 제시 형태·주제·언어 등의 비율을 맞추는 결정론적 최적화 기법으로 600개를 선정했다. 메시지는 실제 플랫폼에서 수집한 것이 아니라 전부 합성 생성했으며, 서로 다른 6가지 난독화 기법(음성·시각적 치환, 문자 분해, 불필요 토큰 삽입 등 복합 조합)을 각 소스 세션에 적용해 세션당 6개의 변형을 만들었다. 모든 변형은 가역적으로 기록되어 원문 복원 여부를 자동 검증할 수 있으며, 목적지는 실제 도메인이 아닌 예약된 테스트 네임스페이스 내 가상 주소를 사용해 안전성을 확보했다.
  • 로컬 웹 환경: 실제 웹페이지의 구조·콘텐츠·리다이렉트·상호작용 피드백을 오프라인으로 재현한 격리 네트워크 샌드박스로, 실제 서비스와의 연결은 제거했다. 4명의 훈련된 주석자가 이중 판정을 수행하고, 의견 불일치나 증거불충분 판정 시 블라인드 재검토와 조정자 중재를 거쳐 위반 여부(3지)와 위반 유형(9종)을 라벨링했다(1차 판정 일치율 82.5%, Krippendorff's α 약 0.66~0.74).
  • Task 2 (웹 조사): 웹 에이전트는 원본 메시지, 복원 결과, 도메인 평판 정보를 전혀 제공받지 못한 채, BrowserGym/Playwright 환경에서 고수준 탐색 가이드만 받고 웹사이트를 조사하여 위반/비위반/증거불충분 판정과 이를 뒷받침하는 근거(관찰 화면·인용)를 포함한 보고서를 생성한다(행동 횟수 30회, 시간 600초로 제한).
  • 오프라인 결합(entry-gated 평가): 복원 단계에서 얻은 1위 진입점 예측이 실제 웹사이트와 일치하는지를 '게이트'로 사용해, 이미 고정되어 있는 Task 2 결과를 브라우저 재실행 없이 성공/실패로 재분류한다. 이를 통해 복원 오류가 최종 성과에 미치는 손실을 별도로 계산할 수 있다.
  • 평가 지표: 복원 성능은 Entry Top-1 정확도, 전체 재구성 정확도, 문자 단위 오류율(CER)로, 웹 조사 성능은 3지 판정 정확도·매크로 F1·위반 유형 매크로 F1·계층적 완전일치(H-EM)로 측정한다. 또한 별도의 고정된 멀티모달 '증거 판정자(judge)'가 조사 궤적과 최종 결론 간의 충실성·충분성·완전성·일관성을 채점하지만, 이 점수는 과제 정답 여부를 결정하지 않는 보조 진단 지표로만 쓰인다.

실험 설정 및 결과

GPT-5.4, GPT-5.6 SOL, GPT-5.2, Claude Opus 4.8, Claude Sonnet 5, Kimi K2.5/K2.6/K3, Qwen3.6 Plus, Doubao Seed 2.0 등 10개 모델을 동일한 조건에서 평가했다(Gemini 3.6 Flash는 채점 배치 누락으로 Task 2 순위에서 제외).

  • 메시지 복원(Task 1): Entry Top-1 정확도는 모델에 따라 35.2%~95.2%로 큰 편차를 보였다. GPT-5.4가 Entry Top-1에서 1위, GPT-5.6 SOL이 전체 재구성 정확도와 최저 CER에서 1위를 차지했다. Kimi K3는 CER(문자 단위 오류율)은 낮지만 Entry Top-1은 상대적으로 낮게 나타나, 문자 수준의 복원 정확도가 실제 '행동으로 이어지는 목적지' 복원 능력을 대변하지 않음을 보여주었다.
  • 웹 조사(Task 2, 정상 라우팅 기준): 3지 판정 정확도는 26.3%~62.8%, 계층적 완전일치는 26.2%~61.0% 범위였다. GPT-5.6 SOL이 판정 정확도·판정 매크로 F1·H-EM에서 모두 1위를 차지했고, Kimi K2.5가 위반 유형 매크로 F1에서 1위였다.
  • 진입점 게이트 적용 엔드투엔드 성능: 16.7%~60.8% 범위였으며, 모델에 따라 정상 라우팅 대비 0.7~32.3%포인트의 손실이 발생했다. 복원 성능이 좋아도 웹 조사 성능이 낮거나 그 반대인 경우가 있어, 두 과제에서 최상위 모델이 서로 달랐다.
  • 실패 원인 분석: 전체 600회 실행 중 31.9%가 '탐색·실행 단계 실패'로 귀속된 반면, 올바른 판정을 내린 뒤 위반 유형만 잘못 분류하는 비율은 0.9%에 불과해, 안정적인 웹 탐색과 위험 판단이 주된 병목임을 확인했다.

한계점

논문이 스스로 밝힌 한계는 다음과 같다. (1) 모델-웹사이트 쌍마다 단 1회의 조사 궤적만 사용했기 때문에 재실행에 따른 성능 변동성은 측정하지 못했다. (2) 9개 위반 유형 중 일부는 표본 수가 적어(6개 유형만 유효 표본 확보) 세밀한 유형별 비교가 제한적이다. (3) 증거 판정자(judge) 점수는 판정자가 평가를 성공적으로 완료한 사례에 한해서만 산출되는 조건부 지표이며 전체 모델 순위를 결정하지 않는다. (4) 향후 과제로 재실행 변동성 측정, 표본이 적은 위험 유형·언어로의 확장, 사람이 직접 수행한 궤적 감사를 통한 증거 평가 기준의 검증이 필요하다고 제안한다.

시사점

이 벤치마크는 콘텐츠 검열 우회(난독화 메시지) 탐지와 웹 기반 위험 조사(에이전트)를 별개 문제로 다뤄온 기존 흐름을 하나의 사슬로 연결해, 실제 플랫폼 거버넌스에서 중요한 '복원 오류의 하류 전파' 문제를 처음으로 정량화했다는 의의가 있다. 특히 문자 단위 복원 정확도(CER)가 낮아도 실제 목적지 복원에는 실패할 수 있다는 결과는, 콘텐츠 모더레이션 시스템을 평가할 때 표면적 텍스트 유사도만으로는 충분하지 않으며 '행동으로 이어지는 정보'가 정확히 복원되었는지를 별도로 검증해야 함을 시사한다. 또한 탐색·실행 단계의 실패가 전체 실패의 대부분을 차지한다는 결과는, 현재의 LLM/VLM 기반 웹 에이전트가 위험을 판단하는 능력보다 안정적으로 웹을 탐색하고 증거를 수집하는 능력에서 더 큰 병목을 겪고 있음을 보여주며, 향후 안전 관련 에이전트 연구가 탐색 신뢰성 개선에 우선순위를 두어야 함을 시사한다.
