Data Unlearning via Inverse Distillation

역증류를 통한 데이터 언러닝

다단계 매칭 모델(확산/플로우 모델)을 원-스텝 생성기로 증류하는 과정에서, 특정 학습 데이터(forget set)의 생성을 동시에 억제하는 통합 프레임워크 Inverse Distillation Unlearning(IDU)을 제안한다.

한 줄 요약

다단계 매칭 모델(확산/플로우 모델)을 원-스텝 생성기로 증류하는 과정에서, 특정 학습 데이터(forget set)의 생성을 동시에 억제하는 통합 프레임워크 Inverse Distillation Unlearning(IDU)을 제안한다.

배경 및 문제의식

확산 모델이나 플로우 매칭 모델과 같은 다단계 매칭 모델은 고품질 샘플을 생성하지만 추론 비용이 크고, 대규모 웹 데이터셋으로 학습되는 과정에서 사생활 침해, 저작권, 법적·윤리적 문제가 되는 학습 데이터(특정 얼굴, 저작권 이미지, 유해 콘텐츠 등)를 기억하고 재생산할 위험이 있다. 이를 해결하는 머신 언러닝(machine unlearning)은 크게 "데이터 언러닝"(특정 샘플 단위로 영향 제거, 클래스나 프롬프트로 특정하기 어려움)과 "클래스 언러닝"(조건부 모델에서 특정 클래스/개념 전체 제거)으로 나뉜다. 그런데 기존 데이터 언러닝 연구는 대부분 다단계 매칭 모델을 대상으로 하며, 추론 속도가 빠른 원-스텝 생성기에 대한 효과적이고 범용적인 언러닝 방법은 거의 연구되지 않았다는 공백이 있다.

핵심 기여

  • 원-스텝 생성기에 대한 데이터 언러닝 공백을 메우기 위해 새로운 역증류(inverse distillation) 기반 방법 IDU를 제안.
  • IDU는 사전학습된 teacher 매칭 모델(확산 또는 플로우 모델)만 있으면, 원-스텝 생성기를 처음부터 학습시키거나 이미 증류된 원-스텝 모델을 추가로 언러닝시킬 수 있음.
  • 학습에 필요한 데이터는 teacher 모델과 forget set(삭제 대상 데이터)뿐이며, 보존해야 할 remaining 데이터나 별도의 특징 추출기·분류기가 전혀 필요 없음.
  • 방법론적으로 유일한 하이퍼파라미터는 forget 비율을 조절하는 ρ ∈ [0,1] 하나뿐이며, forgetting 특성을 보장하는 이론(Theorem 1)도 함께 제시.
  • MNIST·CIFAR-10에서 플로우 매칭(FM) 및 score 기반(SiD) 두 백본 모두에서 동작하는, 원-스텝/확산-플로우 통합 언러닝·증류 프레임워크로는 최초라고 주장.

방법론

표준 원-스텝 증류는 teacher 모델 f에서 얻은 데이터 분포 p0를 min-max 역증류(inverse distillation) 식으로 복원한다(trainable fake model f와 generator p0^θ 사이의 min-max 목적). IDU는 여기서 최적화 대상 분포를 p0^mix = ρ·p0^F + (1-ρ)·p0^θ로 재구성한다. 즉 forget 데이터 p0^F와 generator가 만든 분포 p0^θ를 ρ 비율로 섞은 혼합 분포를, teacher의 분포와 비교한다. ρ = π(실제 forget 데이터 비율)로 설정하면, 최적 generator는 forget 성분이 이미 혼합에 포함되어 있으므로 remaining 데이터 p0^R만을 재현하도록 학습된다는 것이 이론적으로 증명된다(Theorem 1).

학습은 두 단계를 번갈아 수행한다. (1) fake model f를 forget 데이터와 generator 출력 양쪽에 대한 UM(universal matching) 손실로 업데이트(식 7), (2) generator를 Score identity Distillation(SiD) 방식의 손실로 업데이트하여 teacher와 fake model의 차이를 이용, forget 샘플과 유사한 생성을 억제한다. forward noising은 생성 데이터와 forget 데이터 각각에 대해 수행되며 두 branch가 fake model의 파라미터를 공유한다(Figure 1, Algorithm 1 참조). 핵심 직관은 teacher를 "가이드"로 삼아, 혼합 분포(ρ·forget + (1-ρ)·generated)와 teacher 분포 간 차이를 최소화함으로써 생성기가 forget 데이터를 모사하는 출력에서 멀어지도록 유도하는 것이다.

실험 설정 및 결과

MNIST(숫자 3, 7 클래스 삭제)와 CIFAR-10(automobile/truck, 클래스 1, 9 삭제)에서 FM과 SiD(EDM-VP 기반) 두 백본으로 실험했다. 평가지표는 FID(원본/보존 데이터 기준)와 FGR(Forgotten-class Generation Rate: 분류기로 판별한 생성 이미지 중 forget 클래스 비율)이다.

  • 주요 결과(Table 1): IDU는 FM 실험에서 모든 설정에서 FGR을 0.56% 이하로, SiD 실험에서는 1.25% 이하로 낮추면서도, retrain-distillation 오라클과 비슷하거나(FM-MNIST에서는 더 나은) 수준의 Retain FID를 달성했다. Pretrain/순수 증류 모델의 FGR(약 8~13%)과 비교해 큰 폭으로 감소.
  • 단일 클래스 강건성(Table 2): MNIST 전체 10개 클래스, CIFAR-10 전체 10개 클래스 각각에 대해 단독으로 forget 실험을 수행, 평균 Retain FID/FGR은 FM-MNIST 4.54/0.16%, FM-CIFAR-10 7.73/0.84%, SiD-CIFAR-10 3.61/0.75%로 일관된 성능을 보임.
  • ρ(forget 혼합 비율) 민감도(Table 3): ρ가 너무 크면(예: FM에서 0.9) 학습이 발산하거나 FID가 크게 악화되고, 너무 작으면 forgetting 효과가 약해짐. FM-CIFAR-10은 ρ=0.6, MNIST는 ρ=0.4, SiD-CIFAR-10은 ρ=0.2가 각각 최적 균형점으로 선택됨.
  • 비교 대상: UOT-Unlearn(사전학습 원-스텝 모델 대상 비균형 최적수송 기반) 대비 Retain FID와 FGR 모두 우수. 클래스 언러닝 방법인 SFD와도 비슷한 수준의 성능을 보였으나(CIFAR-10 클래스 0 forgetting에서 Retain FID 3.54/FGR 0.58% vs SFD의 약 3.1/0.36%), IDU는 데이터 샘플만으로 동작하고 클래스 레이블/프롬프트가 필요 없다는 점에서 더 유연함.

한계점

  • FM 백본에서는 약 20,000 generator 업데이트 이후 억제했던 forget 클래스의 생성 빈도가 다시 상승하는 현상(reversal)이 관찰되었으며, 이는 IDU 목적함수 자체보다는 현재 FM 아키텍처의 안정성 한계로 추정됨(SiD에서는 평가한 학습 구간 내에서 이러한 역전 현상이 관찰되지 않음).
  • ρ 값은 이론적으로 forget 비율 π로 설정하는 것이 권장되지만, 실제로는 보존 데이터(retained data)에 대한 직접 접근 없이 적절한 ρ를 선택해야 하므로 데이터셋/백본별 튜닝이 필요함.
  • 실험이 MNIST와 CIFAR-10이라는 비교적 작은 데이터셋·저해상도 이미지에 국한되어 있으며, 대규모 실세계 데이터셋이나 텍스트-이미지 모델로의 확장성은 논문에 명시되지 않음.
  • UOT-Unlearn과의 비교 시 해당 방법의 공식 코드가 공개되지 않아 저자들이 재현한 수치로 비교했다는 한계가 있음.

시사점

IDU는 원-스텝 생성기의 "증류"와 "언러닝"을 하나의 min-max 목적함수로 통합함으로써, 별도의 forget/remain 손실을 결합하는 기존 방식과 달리 forget-generated 혼합 분포와 teacher 분포 간 비교라는 단일한 원리로 양쪽을 처리한다. retained 데이터나 외부 분류기·특징 추출기가 전혀 필요 없다는 점은, 저작권·개인정보 등의 이유로 원본 보존 데이터에 접근하기 어려운 실무 환경에서 특히 유용할 수 있다. 또한 이 접근이 효율적인 원-스텝 추론 모델에 직접 적용 가능하다는 점에서, 고비용 다단계 샘플링 모델 위주였던 기존 언러닝 연구를 저비용 생성기 영역으로 확장하는 실용적 의의가 있다.
