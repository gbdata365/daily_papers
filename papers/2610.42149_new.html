Latent Reasoning in Continuous Space for Unified Multimodal Models

LARC: 통합 멀티모달 모델을 위한 연속 공간 잠재 추론

통합 멀티모달 모델(UMM)이 이미지 생성 시 언어적 사고사슬(Chain-of-Thought) 대신 연속적인 잠재 공간에서 추론하도록 하여, LLM에서 보이던 테스트 타임 스케일링 효과를 이미지 생성에도 처음으로 구현한 프레임워크 LARC를 제안한다.

한 줄 요약

통합 멀티모달 모델(UMM)이 이미지 생성 시 언어적 사고사슬(Chain-of-Thought) 대신 연속적인 잠재 공간에서 추론하도록 하여, LLM에서 보이던 테스트 타임 스케일링 효과를 이미지 생성에도 처음으로 구현한 프레임워크 LARC를 제안한다.

배경 및 문제의식

기존의 추론 강화 UMM들은 추론을 이산적인(discrete) 토큰 공간에서 수행하는 반면 이미지 생성은 연속적인(continuous) 공간에서 이루어지는 "모달리티 불일치" 문제를 겪는다. 이 때문에 추론 예산을 늘려도 LLM처럼 매끄러운 성능 향상이 나타나지 않고, 추론이 표면적인 프롬프트 조작 수준에 머무른다고 저자들은 지적한다.

핵심 기여

  • 추론과 생성 사이의 이산-연속 모달리티 불일치를 성능 정체의 근본 원인으로 규명함
  • 통합 멀티모달 모델 내에서 이미지 생성과 동일한 연속 잠재 공간에서 추론을 수행하는 최초의 프레임워크 LARC를 제안, 테스트 타임 스케일링을 가능하게 함
  • Coconut 스타일의 잠재 추론을 확률적 요소(stochasticity)를 추가해 정책 경사(policy gradient) 학습이 가능하도록 확장하고, 정답 잠재 사슬이나 외부 평가자 없이 동작하는 정보이득(information-gain) 보상과 붕괴방지(collapse-prevention) 보상을 결합한 자가진화형 학습법을 설계함

방법론

LARC는 2단계로 학습된다. 1단계(커리큘럼 지도 미세조정)에서는 텍스트 구간과 연속 잠재 단계가 번갈아 나타나는 궤적 형식을 정의하고, <latent> 토큰이 등장하면 마지막 은닉 상태를 다음 입력 임베딩으로 재사용하는 방식으로, 토큰 단위 추론을 점진적으로 잠재 추론으로 전환하는 커리큘럼 학습을 수행한다. 2단계(자가진화 강화학습)에서는 GRPO를 최적화 알고리즘으로 사용하며, 고정된 참조 모델 대비 추론 궤적이 목표 이미지의 예측 분포를 얼마나 개선하는지를 측정하는 정보이득 보상과, 여러 잠재 단계가 동일한 벡터로 붕괴하는 것을 막는 다양성 정규화 보상을 결합해 정책을 업데이트한다. 실험에서는 BAGEL을 기반 모델로 삼아 FLUX-Reason, WEAVE, ScaleEdit에서 추출한 100만 개의 교차 사고사슬 데이터로 학습했다.

실험 설정 및 결과

GenEval, DPG-Bench, OneIG-Bench(텍스트-이미지 생성), CompBench(이미지 편집), MME·MMB·MMMU·MIRA(멀티모달 이해 및 시각 추론) 벤치마크에서 평가했다. LARC는 GenEval에서 기존 최고 수준 대비 약 7%p 향상된 점수(0.88)를 기록했고, DPG-Bench(+5.8%), OneIG-Bench(+10.2%p), CompBench의 LC-T 지표(20.434→22.509)에서도 기반 모델 BAGEL과 Uni-CoT를 모두 앞섰다. 또한 시각 추론 벤치마크 MIRA에서 7.5→11.7로 크게 향상되었으며, 잠재 추론 예산을 늘릴수록(테스트 타임 스케일링) 이미지 생성·편집·시각 추론 전반에서 단조롭게 성능이 향상되는 것을 확인했다. Best-of-N 샘플링 대비 동일 연산 예산에서도 일관되게 더 우수했다.

한계점

논문은 잠재 추론 RL 학습이 수십억 파라미터급 UMM 백본에 대해 비용이 크다는 점을 언급하며, 어댑터 기반·저랭크 방식 등 파라미터 효율적인 적응 방법이 향후 과제로 남아 있다고 밝힌다. 또한 추론 충실도가 향상될수록 적대적 프롬프트에 대한 생성 품질도 함께 좋아질 수 있어, 유해 콘텐츠 생성과 같은 이중 사용 위험이 커질 수 있다는 점도 한계이자 과제로 제시된다.

시사점

이 연구는 멀티모달 생성에서 추론 공간을 생성 공간과 일치시키는 것이 테스트 타임 스케일링을 가능케 하는 핵심 열쇠가 될 수 있음을 보여주며, 향후 통합 모델이 언어 모델 수준의 추론 확장성을 이미지·영상 등 다른 모달리티로 확장하는 설계 방향에 시사점을 준다.
