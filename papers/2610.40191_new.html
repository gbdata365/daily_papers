Video Generation Meets Agent Harness: Agentic Video Generation, Agentic World Modeling and Recursive Self-Improvement

비디오 생성과 에이전트 하네스의 만남: 에이전틱 비디오 생성, 에이전틱 세계 모델링, 재귀적 자기개선

비디오 생성 모델 자체가 아니라 그 주위에서 계획·도구 사용·상태 관리·피드백 라우팅을 담당하는 '에이전트 하네스(agent harness)'를 분석 단위로 삼아, 에이전틱 비디오 생성·에이전틱 세계 모델링·재귀적 자기개선(RSI)이라는 세 방향으로 비디오 생성 연구를 통합적으로 정리한 서베이.

한 줄 요약

비디오 생성 모델 자체가 아니라 그 주위에서 계획·도구 사용·상태 관리·피드백 라우팅을 담당하는 '에이전트 하네스(agent harness)'를 분석 단위로 삼아, 에이전틱 비디오 생성·에이전틱 세계 모델링·재귀적 자기개선(RSI)이라는 세 방향으로 비디오 생성 연구를 통합적으로 정리한 서베이.

배경 및 문제의식

비디오 생성 모델은 점점 더 사실적이고 제어 가능해지고 있지만, 창작 의도를 완성된 영상으로 바꾸려면 샷 계획, 레퍼런스 유지, 결과 검수, 부분 수정 등 생성 모델 혼자서는 처리할 수 없는 의사결정들이 추가로 필요하다. 또한 상호작용형 비디오(인터랙티브 월드 모델)는 완성된 클립이 아니라 관찰에 기반해 계속 이어지는 행동을 요구한다. 이러한 요구들은 비디오 생성이 '좋은 클립 생성'에서 실제 관측 결과에 따라 계획을 수정하고 도구를 선택하는 '에이전틱 비디오 생성'으로 전환되어야 함을 시사하지만, 기존 서베이들은 모델 개발, 생성 평가, 세계 모델, 자기개선 에이전트 등을 따로 다룰 뿐, 비디오 생성기를 둘러싼 '하네스'를 통일된 분석 단위로 다루지 않았다.

핵심 기여

  • 관찰·정책·메모리·도구·피드백으로 구성된 공통된 '에이전트-하네스 실행 루프'를 정의하고, 이를 비디오 생성의 세 가지 설정(제작, 상호작용, 개발)에 공통으로 적용하는 하네스 중심 프레임워크를 제시.
  • 에이전틱 비디오 생성(3장): 하네스가 대본·샷 계획, 자산 관리, 샷 제작, 편집·후반작업, 워터마킹·출처관리를 어떻게 조율하는지 분석하고 이러한 시스템 평가 시 분리해야 할 요소를 논의.
  • 에이전틱 세계 모델링(4장): 게임 엔진이나 코딩 에이전트가 작성한 프로그램이 세계 상태를 유지하고 비디오 모델이 이를 렌더링하는 설계를 포함해, 하네스가 관찰·제어·실행·상태를 어떻게 매개하는지, 그리고 에이전트와 세계 모델이 서로 테스트하고 개선하는 구조를 분석.
  • 비디오 모델 개발의 재귀적 자기개선(5장): 현재 결과물 수정과 하네스 상태·생성기 파라미터·평가자 업데이트를 구분하고, 개선이 다시 개발 과정에 재진입할 수 있는 4가지 경로를 식별하되, 현재까지 조사된 어떤 시스템도 생성기를 학습·검증하는 절차 자체를 아직 개정하지는 못했다고 지적.
  • 비디오가 에이전트에게 요구하는 공통 역량(시청각 지각, 장기 계획, 코드/컴퓨터 사용을 통한 상호작용, 메모리, 피드백 기반 제어, 숙련 재사용, 멀티에이전트 조직)을 범주화하고, 완전 자동화된 영상 제작, 평생 메모리, 프로그램-픽셀 하이브리드 생성, 사람 개입 없는 자율적 모델 개발, 효율성, 출처·안전성, 신규 과제 등 7가지 공개 과제를 제시.

방법론

저자들은 비디오를 조건부 시공간 생성 문제 x ~ p_θ(x|c,z)로 일반화한 뒤, 디퓨전/흐름매칭 기반 생성, 자기회귀 생성, 스트리밍 실행, 그리고 과거 관측과 제어 입력으로부터 미래 관측을 예측하는 '비디오 세계 모델'(x_{t+1:t+Δ} ~ p_θ(·|x_≤t, α_<t+Δ, c))을 모두 동일한 표기로 통합한다. 에이전트는 목표 g, 관찰 o_t, 행동 a_t, 피드백 f_t로 이루어진 목표지향적 의사결정 과정 π_φ(a_t|g,h_t,A_t)로 정의되며, 에이전트 하네스는 이 정책에 컨텍스트를 구성(C)하고, 행동을 실행(X)하며, 자원·권한 제약 하에서 허용 행동을 결정(R)하고, 메모리와 실행 상태를 갱신(M)하며, 피드백을 산출(F)하는 실행 시간 시스템 H=(O,C,T,X,M,F,R)으로 정의된다. 이 공통 표기를 바탕으로 세 가지 질문—① 하네스가 에이전틱 비디오 생성을 어떻게 가능하게 하는가, ② 하네스가 비디오 세계 모델과의 상호작용을 어떻게 지원하는가, ③ 비디오 생성 시스템이 어떻게 재귀적 자기개선으로 나아갈 수 있는가—을 각각 독립된 장(3~5장)으로 다루고, Figure 2에서 대표적인 기존 연구들을 '에이전트 미개입(No Agent)'부터 '자기개선(Self-Improvement)'까지의 단계로 배치해 분야의 발전 궤적을 시각화한다.

실험 설정 및 결과

본 논문은 새로운 모델이나 벤치마크를 제안하는 실증 연구가 아니라 서베이이므로 独자적 실험 결과는 없다. 대신 Table 1에서 비주얼 생성 모델링, 시각 편집·제어, 장기 비디오 생성, 생성 평가, 비주얼 제작 워크플로, 비디오 이해 에이전트, 일반/상호작용 세계 모델, 임바디드 세계 모델, 에이전트 하네스, 자기진화 시스템 등 기존 서베이·연구 40여 편을 비디오 생성·세계 모델 범위와 모델 개발·에이전틱 생성·에이전트-세계 상호작용·RSI·에이전트 설계라는 주제별 커버리지 기준으로 비교하며, 이 논문만이 모든 범주를 포괄적으로 다룬다는 점을 제시한다. 또한 Figure 2의 연표형 다이어그램을 통해 CineForge, VideoWeaver, VLAW, RoboEvolve, VC-Agent 등 RSI 단계 연구부터 PROWL, AesopAgent, GroundShot, FRAMEWORKERS 등 세계 모델링·생성 단계 연구까지 대표 시스템들을 에이전트 개입 정도에 따라 정리한다.

한계점

저자들은 7장에서 분야 전체의 미해결 과제를 다음과 같이 제시한다: (1) 완전한 종단간 영상 제작은 아직 장면 전환부 등 샷 경계 간 연속성 평가와 수용·중단 기준이 미비함(DirectorBench 평가에서 장면 전환부가 가장 낮은 점수를 받음). (2) 단일 시퀀스를 넘어서는 '평생 메모리'는 아직 프로젝트별 기록과 전이 가능한 경험을 구분하고, 오래되거나 신뢰할 수 없는 정보를 갱신·폐기하는 메커니즘이 부족함. (3) 코드 기반 명시적 상태와 픽셀 기반 생성을 결합하는 하이브리드 방식은 각기 하나의 구조적 표현에만 특화되어 있고 실시간으로 동작하지 않는 경우가 많음. (4) 사람 개입 없는 자율적 모델 개발(RSI)은 특정 개선의 효과를 정확히 귀속시키고, 생성된 지도학습 신호에 누적되는 오류를 방지하며, 평가자가 직접 데이터를 선택·수용하는 과정에서 시스템이 자신의 평가 신호에만 적응하지 않도록 독립적인 검증이 필요함. (5) 멀티 에이전트·도구 호출을 포함하는 파이프라인의 효율성(자원·시간 비용)이 공통된 회계 기준 없이 거의 보고되지 않음. (6) 생성·편집·합성이 여러 단계에 걸쳐 이루어지는 에이전틱 제작에서는 서명된 출처 기록과 신원(얼굴 등) 재사용 동의·안전 제약이 아직 체계화되지 않음. (7) 자동 게임 제작, 상호작용형 스토리텔링 등 새로운 과제들은 단일 비디오 품질이 아니라 완전한 시스템의 과제 완료도·일관성·개발 비용을 측정하는 벤치마크가 부족함.

시사점

비디오 생성의 발전을 모델 자체의 성능 향상으로만 보지 않고, 계획·도구·메모리·피드백을 관리하는 '하네스'의 설계 문제로 재구성하면, 단발성 생성과 지속적 상호작용(세계 모델), 그리고 개발 과정 자체의 자기개선(RSI)을 하나의 틀로 연결할 수 있다. 이는 향후 비디오 생성 연구가 생성기 자체의 품질 지표를 넘어, 에이전트가 실패를 진단하고 증거를 축적해 생성 파이프라인과 평가 절차 자체를 개선하는 능력을 체계적으로 측정하고 설계하는 방향으로 나아가야 함을 시사한다.
