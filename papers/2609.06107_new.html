DataFlex-RL: An Evaluation Platform for RLVR Data Policies

DataFlex-RL: RLVR 데이터 정책을 위한 평가 플랫폼

검증 가능한 보상 기반 강화학습(RLVR)에서 널리 쓰이는 데이터 선택·재가중·혼합(커리큘럼) 기법들을 동일한 GRPO 학습 레시피와 다수의 매칭된 시드로 공정하게 비교한 결과, 어떤 기법도 균일 샘플링 대비 재현 가능한 성능 향상을 보이지 못했다는 것을 대규모 실험으로 보여준 평가 플랫폼 논문이다.

한 줄 요약

검증 가능한 보상 기반 강화학습(RLVR)에서 널리 쓰이는 데이터 선택·재가중·혼합(커리큘럼) 기법들을 동일한 GRPO 학습 레시피와 다수의 매칭된 시드로 공정하게 비교한 결과, 어떤 기법도 균일 샘플링 대비 재현 가능한 성능 향상을 보이지 못했다는 것을 대규모 실험으로 보여준 평가 플랫폼 논문이다.

배경 및 문제의식

GRPO(Group Relative Policy Optimization) 같은 RLVR 학습에서는 매 스텝마다 어떤 프롬프트에 롤아웃 자원을 배정하고, 어떤 응답 그룹을 걸러내며, 각 응답의 손실 기여도를 얼마나 줄지를 결정하는 "데이터 정책"이 온라인으로 작동한다. 이에 착안해 DAPO의 solve-rate 필터링, PODS의 고분산 다운샘플링, Advantage Reweighting, PER(우선순위 경험 재생) 방식의 어드밴티지 가중, DUMP나 teacher-student curriculum 같은 적응형 도메인 커리큘럼 등 다양한 기법이 제안되어 왔다.

그러나 저자들은 이런 기법들의 "더 유용한 데이터에 학습을 집중시키면 성능이 오른다"는 전제가 실제로 충분히 검증되지 않았다고 지적한다. 문제는 세 가지다. 첫째, 각 기법이 서로 다른 베이스 모델·프롬프트 템플릿·검증기·롤아웃 예산과 함께 하나의 패키지로 발표되어 개별 기법의 순수 효과를 분리하기 어렵다. 둘째, on-policy 학습에서는 데이터의 유용성 신호 자체가 학습이 진행됨에 따라 변하는 잡음 섞인 내생적(endogenous) 값이며, 소규모 추론 벤치마크의 시드 간 변동성이 기법 간 보고된 격차만큼 크거나 그보다 클 수 있다. 셋째, 평가에 사용하는 벤치마크 구성(어떤 도메인을 포함·제외하는지)에 따라 "최고 성능 기법"이 바뀔 수 있어 비교 결과 자체의 신뢰성이 흔들린다.

핵심 기여

  1. 통제된 비교에서 균일 샘플링 대비 뚜렷한 우위 없음: Qwen2.5-7B-base에서 12개의 매칭된 시드로 13가지 설정(선택 4종, 재가중 4종, 혼합 적응 3종 + baseline/static)을 모두 평가한 결과, 균일 GRPO는 미학습 체크포인트 대비 7.76점 향상을 보였지만, 선택·재가중 8개 기법 중 어느 것도 균일 샘플링 대비 95% 신뢰구간이 0을 배제하지 못했고, 적응형 혼합 3개 기법도 고정 균등 혼합 대비 유의미한 이득을 보이지 못했다.
  2. 평가 요약 방식에 따른 민감도 정량화: 동일한 9개 Qwen2.5-7B-Instruct 실행을 수학 위주 6개 벤치마크 요약(Math-Heavy-6: 수학 5종 + GPQA-Diamond, 논리 벤치마크 없음)과 도메인 균형 12개 벤치마크 요약(DB-12)으로 각각 집계하면 순위가 음의 상관관계(ρ = -0.33)를 보인다. 반면 12개 벤치마크를 모두 포함하는 다른 집계 방식들(Macro-12, Item-12)은 DB-12와 강하게 상관(ρ = 0.88)한다. 즉 논리 도메인을 빼는 것만으로 "1등 기법"이 바뀔 수 있다.
  3. 재사용 가능한 평가 플랫폼 제공: 선택(selection)·재가중(reweighting)·혼합 적응(mixture adaptation)이라는 3가지 개입 지점을 분리하고, 이를 관통하는 신호(solve rate, reward, advantage, token probability 등)를 방법 범주와 별개로 기록하는 분류 체계를 제시했다. 동일한 롤아웃·검증·최적화·평가 스택, 매칭 시드, 공통 12-벤치마크 채점 포맷을 갖춘 공유 드라이버를 구축해 향후 새 정책도 동일 프로토콜로 비교할 수 있게 했다.

방법론

DataFlex-RL은 지도학습 데이터 중심 학습 프레임워크였던 기존 DataFlex의 선택-재가중-혼합 추상화를 온-폴리시 RL로 확장한 것이다. 기본 학습 스텝은 수학·논리·과학 프롬프트를 동일 비율로 샘플링하고, 프롬프트당 K=5개의 응답을 생성해 검증한 뒤 표준 GRPO 손실을 적용하는 구조다.

  • 선택(Selection): 롤아웃·보상 계산 후 응답(또는 그룹) 전체를 포함/제외하는 이진 마스크를 적용. difffilter(그룹 solve rate가 0.2~0.8 범위일 때만 유지, DAPO보다 엄격한 필터), maxvar(그룹 내 보상 분산을 최대화하는 부분집합 유지, PODS 방식), gfpo(그룹 내 5개 중 reward-per-token 상위 3개 유지), topk(배치 내 |advantage| 상위 50% 응답 유지)의 4종.
  • 재가중(Reweighting): 응답을 손실 계산에서 제외하지 않되, 토큰 또는 응답 단위로 연속적인 가중치를 부여. ar(저확률 토큰 완화, Advantage Reweighting), per(|advantage| 기반 PER식 가중), softmax(advantage에 softmax 적용, T=1), diffband(배치 보상 사분위수 사이 응답에 2배 가중)의 4종.
  • 혼합 적응(Mixture Adaptation): 다음 롤아웃에 사용할 도메인별 샘플링 비율 p_t(d)를 조정. static(1/3씩 고정), reward_gap(뒤처진 도메인 우대), dump_ucb(UCB 스타일 탐색-활용 균형, DUMP 기반), tscl(학습 진행/망각 속도 기반, Teacher-Student Curriculum Learning 기반)의 3종.

학습 코퍼스는 math_dapo·DeepScaler·GSM8K(수학, boxed-answer 검증), 절차적으로 생성한 Knights&Knaves 퍼즐(논리), SciQ 객관식(과학)으로 구성된 총 15,000개 프롬프트다. 모든 실험은 verl v0.5+ 기반 GRPO, 프롬프트당 5개 롤아웃, KL 계수 10⁻³, 300 옵티마이저 스텝 조건에서 진행되며, 평가 전 학습-평가 포맷 불일치를 점검하는 보정 스모크 테스트와 학습-평가 데이터 간 n-gram 중복 검사(13-gram Jaccard 유사도 0.5 이상 없음)를 수행했다. 평가는 수학 5종(MATH-500, AIME-2024, OlympiadBench, MinervaMath, GSM8K), 논리 4종(Knights&Knaves, BBH 2종, ZebraLogic), 과학 3종(MMLU-Pro 화학/물리, GPQA-Diamond) 총 12개 벤치마크로 이뤄지며, Overall 점수는 세 도메인 평균을 다시 평균해 도메인별 동일 가중치를 부여한다. 전체 실험 매트릭스는 591개 실행(run)으로 구성된다.

실험 설정 및 결과

  • 학습 여력(headroom) 확인: Qwen2.5-7B-base는 미학습 42.01점에서 균일 GRPO로 49.77점(+7.76, 95% CI [7.28, 8.25])으로, Llama-3.1-8B-base는 10.87점에서 21.12점(+10.25, 95% CI [7.75, 12.33])으로 향상되어 GRPO 자체는 뚜렷하게 효과적임을 확인했다.
  • 주 실험(Qwen2.5-7B-base, 12시드): 선택 4종·재가중 4종 모두 균일 샘플링(49.77점) 대비 paired 95% 신뢰구간이 0을 포함했다(예: difffilter +0.08 [-0.67, 0.82], gfpo -0.90 [-1.87, 0.08], per -0.86 [-3.28, 1.57] 등). 9개 정책(baseline 포함) 평균 점수의 전체 스프레드는 0.97점으로, GRPO 자체가 만든 7.76점 향상의 약 1/8에 불과했다. 또한 3시드 예비 실험에서는 topk가 선두였으나 12시드로 확장하자 difffilter가 가장 높고 topk는 오히려 baseline보다 낮아지는 등 시드 수에 따라 순위가 뒤집혔다. 혼합 적응 3종도 고정 균등 혼합(49.00점) 대비 모두 신뢰구간이 0을 포함했고 스프레드는 0.61점이었다.
  • Llama-3.1-8B-base 교차검증: 동일 프로토콜로 재실행한 결과(이전 버전의 14~16점대 결과는 지원되지 않는 수학 문제를 0점 처리하는 평가기 버그로 판명되어 폐기하고 수정), 원래의 3개 선택 기법 모두 baseline 대비 신뢰구간이 0을 포함했고, 추가로 확장한 9개 기법(18.66~21.98점 범위)도 baseline(21.12점)과 같은 스케일 안에서 뚜렷한 공통 승자를 보이지 못했다.
  • 모델 규모/계열 스윕: Qwen2.5 1.5B/3B/7B/14B 및 Llama-3.2-3B에서 difffilter, maxvar, softmax, tscl 등을 3시드로 비교한 결과, 예를 들어 difffilter는 소형 모델에서는 baseline보다 낮고 대형 모델에서는 약간 높아지는 등 부호가 모델마다 뒤바뀌어 일관된 승자가 없었다.
  • 평가 벤치마크 구성 민감도: Qwen2.5-7B-Instruct 9개 설정을 Math-Heavy-6(논리 배제)로 집계하면 topk·diffband가 1위였으나, DB-12(도메인 균형)로 집계하면 gfpo·difffilter가 1위로 바뀌었다(순위 상관 ρ=-0.33). 반면 12개 벤치마크를 모두 포함하는 다른 집계 방식(Macro-12, Item-12)은 DB-12와 ρ=0.88로 강하게 일치해, 순위 역전의 원인이 논리 도메인 배제 자체임을 확인했다.
  • 부가 진단(Appendix): 무작위로 같은 개수를 유지하는 매칭 랜덤, 업데이트 토큰 수를 맞춘 통제, 필터 강도를 바꾼 통제 등과 비교했을 때도 difffilter·maxvar·topk 각각이 서로 다른 방향으로 반응해, 특정 타겟팅 신호·업데이트량·강도 효과로 결과를 일관되게 설명할 수 없었다. 다만 gfpo는 baseline과 정확도는 거의 동일하면서 응답 길이를 줄이고(1568→1497자) 글자당 정답 효율을 높이는(0.461→0.482) 효과는 관찰되었다.

한계점

  • 본 연구는 "테스트된 통제 설정 범위 내"에서 균일 학습 대비 재현 가능한 개선이 없다는 결론이며, 더 긴 학습, 다른 하이퍼파라미터, 혹은 이 논문이 다루지 않은 다른 계열의 데이터 정책에서도 이득이 없다는 것을 증명하거나 방법들이 서로 동등하다는 것을 입증하지는 않는다(저자들이 명시).
  • 모델 규모/계열 확장 실험(1.5B, 3B, 14B, Llama-3.2-3B)은 3시드에 불과해 독립적인 통계적 유의성 검정으로 사용하지 않았고, 주된 추론 근거는 여전히 Qwen2.5-7B-base 12시드 실험에 한정된다.
  • gfpo, topk, ar, per, diffband, reward_gap, dump_ucb 등 일부 기법은 보조 모델 규모 스윕에는 포함되지 않아 전 모델·전 기법의 완전한 교차비교는 이뤄지지 않았다.
  • 초기 Llama 실험 결과가 평가기 버그(미지원 수학 문제를 0점 처리)로 잘못되었다가 수정된 사례가 있어, 평가 파이프라인의 구현 세부사항이 결과에 미치는 영향이 크다는 점을 스스로 보여준다.

시사점

이 논문은 RLVR 분야에서 개별적으로 발표되어 온 데이터 선택·재가중·커리큘럼 기법들이 통제된 동일 조건 하에서는 균일 샘플링을 능가한다는 근거가 약하다는 점을 대규모·다중 시드 실험으로 보여준 재현성(reproducibility) 검증 연구다. 이는 향후 RLVR 데이터 정책 연구가 (1) 충분한 시드 수와 paired confidence interval을 통한 통계적 엄밀성, (2) 평가 도메인을 누락하지 않는 벤치마크 구성, (3) 학습-평가 포맷 정합성 점검을 갖춰야 함을 시사한다. 또한 공개된 평가 플랫폼과 591개 실행 전체 기록, 재구성 스크립트는 향후 새로운 데이터 정책 제안이 동일한 공정한 프로토콜 위에서 검증받을 수 있는 기준선(baseline) 역할을 할 수 있다.
