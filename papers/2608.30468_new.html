Hi-Q: Hierarchical Evidence-guided Query Refinement for Multi-Hop Question Answering

Hi-Q: 멀티홉 질의응답을 위한 계층적 근거 기반 질의 정제

멀티홉 질의응답에서 질문이 표현되는 단위와 코퍼스에서 실제로 검색 가능한 근거 단위가 서로 다르다는 문제를, 검색된 증거가 현재 질의를 충분히 뒷받침하는지 검사한 뒤 부족할 때만 하위 질의로 분해하는 "증거 조건부 계층적 질의 정제" 프레임워크 Hi-Q로 해결한다.

한 줄 요약

멀티홉 질의응답에서 질문이 표현되는 단위와 코퍼스에서 실제로 검색 가능한 근거 단위가 서로 다르다는 문제를, 검색된 증거가 현재 질의를 충분히 뒷받침하는지 검사한 뒤 부족할 때만 하위 질의로 분해하는 "증거 조건부 계층적 질의 정제" 프레임워크 Hi-Q로 해결한다.

배경 및 문제의식

멀티홉 QA는 하나의 자연어 질문 안에 여러 개의 상호 의존적인 추론 단계가 압축되어 있다. 문제는 질문이 논리적으로 표현되는 문법적 단위와, 코퍼스에서 신뢰성 있게 검색 가능한 근거의 단위가 자주 어긋난다는 점이다. 저자들은 기존 접근의 세 가지 실패 양상을 지적한다. (1) 단일 검색은 질문이 여러 추론 요소를 한꺼번에 담고 있을 때 표층 단어만 일치하는 문서를 가져와 실패하고, (2) GraphRAG류 방법은 코퍼스 쪽에 미리 그래프 구조를 만들어두지만 이는 질의와 무관하게 고정된 입도(granularity)를 강제하며, (3) IRCoT 같은 반복 검색 기법은 질의를 점진적으로 바꾸지만 각 재정식화가 실제로 검색 가능한지 검증하지 않아 초기 오류가 후속 단계로 전파된다. 이에 따라 저자들은 "질문을 어떻게 논리적으로 분해할 것인가"가 아니라 "각 추론 단계가 실제로 검색되고 답변 가능한 입도를 어떻게 발견할 것인가"(retrievable granularity discovery)를 핵심 문제로 재정의한다.

핵심 기여

  • 검색 가능 입도 발견(retrievable granularity discovery)의 정식화: 멀티홉 RAG를 특정 코퍼스 하에서 각 추론 단계가 검색 가능하면서 동시에 답변 가능해지는 질의 단위를 찾는 문제로 새롭게 정의.
  • 실패 인지형 입도 제어(failure-aware granularity control): 해석 연산자(resolution operator)가 근거 부족을 탐지했을 때만 질의 노드를 확장하는 증거 조건부 정책을 제안하고, 이 결정이 비용에 민감한 임계값(threshold) 규칙으로 도출됨을 이론적으로 보임.
  • 의존성 보존 계층적 분해: 선행(bridge) 하위 질의를 먼저 해결하고 그 결과를 후속 질의로 전파하는 이진 확장 연산자를 도입해 정보 부족 검색과 오류 전파를 줄임.
  • 전체 코퍼스(full-corpus) 환경에서의 평가: 사전 구축 그래프나 과제별 파인튜닝 없이도 그래프 기반, 반복 검색, 코드 실행 에이전트 기반 베이스라인들을 능가함을 세 개 벤치마크에서 확인.

방법론

Hi-Q는 멀티홉 QA를 질의 입도에 대한 증거 조건부 탐색으로 정식화한다. 탐색 상태는 현재 질의 노드 q, 누적 상호작용 이력 H, 재귀 깊이 d로 구성된다(x = (q, H, d)).

  1. 해석 연산자(Resolution operator) G: 주어진 질의를 이력 H를 참고해 재정식화(참조 해소)한 뒤, 상위 k개 문서를 검색하고 리더(reader)가 그 문서로부터 답을 시도한다. 답이 나오면(a ≠ ⊥) RESOLVED로 간주해 해당 노드에서 탐색을 멈추고, 답을 내지 못하면(a = ⊥) UNRESOLVED로 판정해 확장 대상이 된다. 이 STOP/EXPAND 결정은 "해결 가능한 노드를 불필요하게 확장하는 비용"과 "미해결 노드에서 멈추는 비용"을 비교하는 기대비용 최소화 문제로 정식화되며, 그 해가 미해결 확률에 대한 임계값 규칙(threshold rule)임을 부록에서 증명한다. 실제 구현에서는 학습이 필요 없는(training-free) 방식으로, 리더의 답변 성공/실패 자체를 이 임계값 판정의 대리 신호로 사용한다.
  2. 이진 확장 연산자(Binary expansion operator) B: 미해결 노드를 정확히 두 개의 하위 질의(q_left, q_right)로 분해하되, (i) q_left가 선행 조건(bridge fact)이 되어 q_right보다 먼저 풀려야 한다는 의존성 제약과, (ii) 두 하위 질의를 순서대로 풀었을 때 원래 질의의 의도를 손실 없이 회복해야 한다는 의미 커버리지 제약을 만족해야 한다. 다지(N-ary) 분해 대신 이진 분해를 택한 이유는, 매 단계마다 충분한 문맥을 유지하며 추가 분해 필요성을 검증할 수 있기 때문이다.
  3. 의미 커버리지 검증기(Semantic coverage verifier) V: 제안된 분해가 원 질의의 의도를 왜곡·누락하지 않는지 검사하고, 문제가 있으면 최대 한 번 재작성(repair)을 시도한다. 재작성 후에도 부적절하면 해당 노드는 더 이상 분해하지 않는 것으로 표시한다.
  4. 재귀는 최대 깊이 d_max(실험에서는 4)로 제한되며, 좌측 가지가 먼저 해결되어 그 답변·근거·부분 문맥이 이력 H에 기록된 뒤 우측(의존) 가지가 풀린다. 양쪽 가지가 반환되면 합성(synthesis) 단계가 중간 답변들과 이력을 종합해 최종 답을 생성한다.

실험 설정 및 결과

MuSiQue, HotpotQA, 2WikiMultiHopQA 세 벤치마크에서 각각 1,000개의 검증 질문을 표본으로 두 가지 검색 환경(전체 코퍼스 / 정답·방해 문서로 구성된 제한된 풀)에서 평가했다. 리더는 기본적으로 GPT-4o-mini를 사용했고, 검색기는 NV-Embed-v2(k=5)를 사용했다. 비교 대상은 단일 검색(NV-Embed-v2), 그래프 기반 RAG(RAPTOR, GraphRAG, HippoRAG, HippoRAG 2, PropRAG), 반복/분해 기반 방법(Self-Ask, Least-to-Most, IRCoT), 코딩 에이전트, Recursive Language Model 등이다.

  • 전체 코퍼스 환경(주 평가): Hi-Q는 평균 52.3 EM / 64.0 F1을 기록해 IRCoT 대비 15.1 EM / 18.2 F1 앞섰고, 그래프 구축 없이도 PropRAG를 MuSiQue-full에서 11.5 EM / 12.0 F1 앞섰다.
  • 제한된(supporting/distractor) 환경: Hi-Q는 평균 57.9 EM / 69.3 F1로 최고 성능을 보였으며, PropRAG 대비 5.6 EM / 3.9 F1, IRCoT 대비 13.7 EM / 15.8 F1 앞섰다. 대부분의 성능 차이는 부트스트랩 검정에서 통계적으로 유의했다(p < 10⁻⁴ 수준이 다수).
  • 미해결 신호의 신뢰성 분석: 근거가 부족해 트리거된 사례를 사람이 직접 100개 표본 검토한 결과, 실제로 잘못된 트리거(false trigger)는 약 10%에 불과했다. 정상 질문에 대한 허위 거부율(FRR)은 11%, 적대적으로 구성된 답변 불가능 질문에 대한 허위 수용률(FAR)은 2%로, 신호가 보수적이면서도 실질적으로 작동함을 보였다.
  • 구성요소 제거 실험(ablation): 계층적 재정제를 제거(정적 1회 분해)하면 평균 성능이 57.9→51.5 EM으로 하락하고, 의존성 보존을 제거하면 47.1 EM으로 더 크게 하락했다. 실패 인지형 트리거 대신 항상 분해하는 정책은 이미 답변 가능한 질의까지 불필요하게 쪼개어 성능이 저하됨을 확인했다.
  • 추론 깊이(hop 수) 분석: hop 수가 늘어날수록 모든 방법의 성능이 하락하지만, Hi-Q는 3-hop과 4-hop에서 각각 55.2, 39.2 F1로 IRCoT(43.4, 35.4)와 PropRAG(43.1, 26.9)보다 더 완만하게 성능이 저하됨을 보였다.
  • 연산 비용: PropRAG보다 빠르고, IRCoT 대비 총 토큰 사용량은 70.5% 적지만 LLM 호출 수와 지연 시간은 다소 늘어난다. 재귀 깊이를 1로 제한한 "비용 매칭(cost-matched)" 설정에서는 IRCoT와 거의 동일한 LLM 호출 수로 입력 토큰 9.4배 절감, 25% 빠른 처리, API 비용 8.6배 절감을 달성하면서도 정확도는 평균 10.4 EM / 11.6 F1 더 높았다.

한계점

저자들이 명시한 한계는 다음과 같다. (1) 실험은 영어, 위키피디아 기반, 짧은 답변 형태의 멀티홉 QA에 국한되어 있어 장문 QA, 다국어 QA, 도메인 특화 QA, 표·텍스트 혼합 QA, 멀티모달 QA 등으로의 일반화는 검증되지 않았다. (2) 평가 대상 의존성 구조는 비순환적이며 가지별로 순차 해결이 가능한 경우로 한정되어 있어, 선행 조건들이 상호 의존적이거나 여러 가지를 동시에 최적화해야 하는 질문 유형은 현재의 상태 표현으로 다루지 못한다. (3) Hi-Q는 해석·분해·검증·합성을 모두 LLM 모듈에 의존하므로, 리더의 오류(허위 거부로 인한 과도한 재정제, 혹은 근거 없는 답변 생성으로 인한 조기 종료)가 정제 정책 전체에 영향을 줄 수 있다. 현재의 이진(resolved/unresolved) 신호는 부분적 근거, 상충하는 근거, 복수의 경쟁 브리지 엔티티 같은 더 세밀한 상태를 표현하지 못한다.

시사점

이 연구는 멀티홉 검색 증강 생성(RAG)의 핵심 병목이 "더 많은 문서를 찾는 것"이 아니라 "각 추론 단계가 실제로 검색 가능하고 답변 가능해지는 질의 입도를 찾는 것"이라는 관점을 제시한다. 질의 입도를 사전에 고정된 설계 선택이 아니라 검색 피드백에 따라 동적으로 조정되는 제어 변수로 다룸으로써, 코퍼스 전역에 걸친 그래프 사전 구축이나 과제별 파인튜닝 없이도 성능과 비용 효율을 동시에 개선할 수 있음을 보여준다. 이는 향후 검색 전략을 질문 자체만 보고 사전에 결정하는 방식(query-only routing)이 근본적으로 한계를 가진다는 점을 시사하며, 증거 상태를 관찰해 결정을 내리는 제어 인터페이스가 학습 기반 컨트롤러로도 확장 가능하다는 점에서 후속 연구의 방향을 제시한다.
