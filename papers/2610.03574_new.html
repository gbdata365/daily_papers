HyperBrowseComp: A Multilingual and Multimodal Stress Test for Web-Browsing Agents

웹 브라우징 에이전트를 위한 다국어·다중모달 스트레스 테스트 벤치마크

13개 언어, 8개 증거 양식에 걸쳐 423개의 사람이 직접 작성·검증한 극도로 어려운 질문으로 구성된 다국어·다중모달 웹 브라우징 벤치마크로, 최상위 모델조차 31.68% 정확도에 그쳐 현재 웹 에이전트의 한계를 드러낸다.

한 줄 요약

13개 언어, 8개 증거 양식에 걸쳐 423개의 사람이 직접 작성·검증한 극도로 어려운 질문으로 구성된 다국어·다중모달 웹 브라우징 벤치마크로, 최상위 모델조차 31.68% 정확도에 그쳐 현재 웹 에이전트의 한계를 드러낸다.

배경 및 문제의식

웹을 검색·탐색하며 증거 기반 답변을 생성하는 LLM 에이전트 평가를 위해 GAIA, WebArena, BrowseComp 등이 제안되었지만, 기존 BrowseComp는 영어 중심에 텍스트 위주이며 모델 성능 향상으로 점점 변별력이 떨어지고 있다. BrowseComp-ZH, K-BrowseComp 등 언어별 확장판이나 XBCP 같은 번역 기반 다국어 벤치마크, MMSearch·MM-BrowseComp 같은 다중모달 확장판이 등장했지만, 네이티브로 작성된 다국어 질문과 다중모달 증거(영상, 스캔 문서, 이미지, 지도 등)를 동시에 결합한 개방형 웹 벤치마크는 부재했다.

핵심 기여

  • 13개 언어의 원어민/숙련 화자가 직접 작성하고 교차 검증한 423개 질문으로 구성된 HyperBrowseComp를 공개했으며, 번역이 아닌 네이티브 작성 방식을 통해 언어·문화적 맥락을 보존했다.
  • 질문의 약 64.3%가 동영상, PDF/스캔 문서, 이미지, 오디오, 지도, 표 등 비텍스트 증거를 요구하도록 설계해, 단순 텍스트 검색을 넘어서는 멀티모달 탐색 능력을 평가한다.
  • 인터넷 접속 없는 7개 모델로 "쉬운" 질문을 걸러내는 난이도 검증 절차와, 모호성을 줄이기 위한 '지문(fingerprint)' 제약 추가 절차를 통해 파라메트릭 지식만으로 풀리지 않는 고난도 질문만 남겼다.
  • Gemini, GPT 계열 등 5개 프런티어 모델을 기본 검색·Exa·OWL 등 3가지 브라우징 하네스로 평가하고, 사람 평가와도 비교해 성능·비용·실패 양상을 폭넓게 분석했다.

방법론

질문은 각 언어의 원어민 또는 그에 준하는 숙련 화자가 작성하며, 공개적으로 검증 가능하지만 찾기 어려운 답을 가진 사실형 질문으로 한정했다. 1차 작성자가 정답, 근거 URL, 정확한 증거 위치(타임스탬프, 페이지 번호 등), 풀이 경로를 함께 제출하면 2차 검증자가 질문의 명확성·정답의 유일성·시간 민감성 등을 검토하고, 필요시 비유도적 '지문' 제약을 추가해 난이도와 특정성을 높였다. 이후 인터넷 접속이 차단된 7개 LLM(Gemini, GLM, GPT-OSS, Kimi K2, MiniMax-M2, DeepSeek-V3.2 등)으로 사전 풀이를 시도해, 2개 이상의 모델이 맞히거나 1개 모델이라도 매우 구체적인 답을 맞힌 질문(총 77개)을 제외함으로써 파라메트릭 지식만으로 풀리는 문항을 걸러냈다. 평가는 기본 제공 검색(built-in search), 표준 검색/가져오기 도구를 제공하는 Exa, 역할 분담형 멀티에이전트 프레임워크 OWL의 세 가지 하네스로 수행했으며, 최대 25단계의 ReAct 루프 또는 OWL의 작업관리자-조정자-연구자-종합자 역할 분담 구조를 사용했다. 정답 판정은 동일 모델을 LLM 심판으로 활용한 이진 채점 방식이다.

실험 설정 및 결과

Gemini 3.7 Flash가 기본 검색 설정에서 31.68%로 가장 높은 정확도를 기록했고, Gemini 3.1 Pro(25.53%), GPT-5.6 계열(11.58~19.15%)이 뒤를 이었다. 검색 하네스를 Exa로 바꾸면 GPT-5.6 Sol은 성능이 오르지만 두 Gemini 모델은 오히려 크게 하락해, 모델이 자사 검색 생태계에 강하게 특화되어 있음을 보여준다. OWL 하네스는 93건의 실행 실패(타임아웃, 호출 예산 초과 등)로 전체 정확도가 17.73%까지 떨어졌다. 인도네시아어·태국어·베트남어 30문항에 대한 사람 평가(30문항 중 15문항 정답)에서는 사람과 최고 성능 모델(Gemini 3.7 Flash)의 전체 정확도가 비슷했지만 정답이 겹치는 문항은 일부에 그쳤으며, 사람은 평균 89.5분이 소요됐다. 전체 423문항 중 244문항(57.68%)은 5개 모델 모두 틀렸고, 그래프/도표/이미지 등 시각적 증거와 독일어·인도네시아어 질문, "게임", "음식" 도메인에서 공통 실패가 두드러졌다.

한계점

저자들은 벤치마크가 일상적 검색 질의 분포를 대표하지 않는 의도적 스트레스 테스트라는 점, 실시간 웹을 대상으로 하여 검색 순위·페이지 내용·도구 동작이 시간에 따라 변할 수 있다는 점(트레이스 보존으로 일부 완화), 선정된 13개 언어가 전체 언어 공동체를 대표하지 못하며 언어별 온라인 정보량·품질 차이가 크다는 점, 높은 연산 비용으로 인해 5개 모델·2~3개 하네스 조합만 평가해 더 폭넓은 시스템 비교는 수행하지 못했다는 점을 한계로 명시했다.

시사점

현재 최상위 웹 브라우징 에이전트도 언어·문화적 맥락과 다중모달 증거가 얽힌 고난도 탐색 과제에서 절반 이상의 문항을 풀지 못한다는 사실을 보여주며, 모델 성능이 특정 검색 생태계(하네스)에 크게 좌우된다는 점에서 향후 다국어·다중모달 증거를 통합적으로 처리하고 하네스에 견고한 브라우징 에이전트 연구의 필요성을 제기한다.
