DuoMatching: Joint-Marginal Distribution Matching for Few-Step Video Generation

듀오매칭: 소수 스텝 비디오 생성을 위한 결합-주변 분포 매칭

비디오 프레임들의 결합분포(joint)만 맞추던 기존 분포매칭증류(DMD) 방식에, 이미지 생성모델을 교사로 활용한 프레임 단위 주변분포(marginal) 매칭을 추가하여, 소수 스텝(few-step) 비디오 생성의 화질·의미 정합성을 크게 개선한 프레임워크를 제안한다.

한 줄 요약

비디오 프레임들의 결합분포(joint)만 맞추던 기존 분포매칭증류(DMD) 방식에, 이미지 생성모델을 교사로 활용한 프레임 단위 주변분포(marginal) 매칭을 추가하여, 소수 스텝(few-step) 비디오 생성의 화질·의미 정합성을 크게 개선한 프레임워크를 제안한다.

배경 및 문제의식

최근 비디오 생성 모델은 화질과 시간적 일관성 면에서 크게 발전했지만, 다단계(iterative) 디노이징 때문에 연산 비용과 추론 지연이 커서 실시간 상호작용 시뮬레이션이나 디지털 엔터테인먼트 같은 응용에 제약이 된다. 이를 해결하기 위해 다단계 확산/플로우 모델을 소수 스텝 생성기로 증류하는 분포매칭증류(DMD, Distribution Matching Distillation)가 활용되어 왔고, 스트리밍 비디오 생성에서는 비디오 교사 모델의 결합분포를 학생 모델이 따라가도록 하는 "joint DMD" 방식이 자기회귀(autoregressive) 롤아웃에서 발생하는 드리프트(drift)를 완화해왔다.

그러나 저자들은 기존 joint DMD만으로 학습된 자기회귀 생성기에서도 여전히 화질과 의미 정합성(semantic alignment) 측면의 한계가 남아 있음을 관찰한다. joint DMD는 전체 시퀀스에 대해 비디오 교사의 결합분포를 근사하도록 학습되므로, 한 프레임만 개선하는 변화(예: 누락된 깃털 디테일을 추가)가 주변 프레임들과 상충되면 억제될 수 있다. 즉 기존 DMD는 개별 프레임의 주변분포를 직접적으로 모델링하는 전용 목표가 없다는 것이 핵심 문제의식이다.

핵심 기여

  • 비디오 생성을 결합(joint)-주변(marginal) 분포매칭의 통합 프레임워크로 재정식화한 DuoMatching을 제안했다. 비디오 교사를 결합분포 참조로, 사전학습된 이미지 생성모델(Qwen-Image 등)을 프레임 단위 주변분포 참조로 동시에 활용한다.
  • 비디오 학생 모델의 시간 압축 잠재표현(temporally compressed latent)과 이미지 교사의 프레임 단위 잠재표현 사이의 불일치를 해소하는 경량 모듈 LatentBridge를 도입했다.
  • 프레임 단위 지도(supervision)를 시간적으로 서로 다른 구간에 고르게 분배하여 중복 지도를 줄이고 동작(dynamics) 손실을 방지하는 Latent Variation Sampling(LVS) 기법을 제안했다.
  • 이론적으로, 이상적인 조건 하에서 결합-주변 최적점이 기존 joint-only 최적점보다 실제 비디오 분포 P*에 forward KL 측면에서 더 가까워질 수 있음을 증명했다(부록).
  • 자기회귀(causal) 생성과 양방향(bidirectional) 생성 모두에서 화질, 구도(composition), 의미 정합성을 개선하면서 모션 역동성을 대체로 유지함을 실험으로 입증했고, 모든 비교 대상 대비 80% 이상의 인간 선호도를 얻었다.

방법론

  1. 분포매칭 정식화: 생성기 G_θ의 출력분포 Q_θ를 실제 데이터분포 P에 맞추는 이상적 목표 D_KL(Q_θ‖P)는 직접 계산이 불가능하므로, 기존 방식은 사전학습된 비디오 교사 분포 P_v로 근사한 joint DMD(J_joint = D_KL(Q_θ‖P_v))를 사용한다. 이때 각 잠재 슬라이스의 score는 다른 슬라이스에 조건부로 계산되어(식 3), 프레임 간 상호 의존성에 묶이게 된다.
  2. DuoMatching 목표: 프레임 샘플링 연산자 M으로 추출한 프레임 단위 주변분포를, 비디오 교사의 주변분포(m_v = MP_v) 대신 이미지 생성모델의 분포 P_i로 직접 근사할 수 있다는 점에 착안해, 결합-주변 결합 목표 J_DM(θ) = D_KL(Q_θ‖P_v) + ω·D_KL(m_θ‖P_i) (ω>0)를 정의한다. 두 항은 각각 joint-DMD, marginal-DMD의 증류 손실로 구현된다(L_DuoMatching = L_joint-DMD + ω·L_marginal-DMD).
  3. LatentBridge: 비디오 VAE는 시간적으로 압축된 잠재(한 슬라이스가 여러 RGB 프레임에 대응)를 쓰는 반면 이미지 VAE는 프레임 하나당 하나의 잠재를 사용하므로, 두 공간이 호환되지 않는다. LatentBridge B_φ는 이전 잠재 슬라이스 z^(l-1), 현재 슬라이스 z^l, 로컬 프레임 인덱스 i를 입력받아 이미지 교사 잠재공간 상의 해당 프레임 표현 u^(l,i)를 예측하도록 ℓ1 재구성 손실로 사전학습된다. 이를 통해 두 VAE를 모두 거치는 디코드-재인코드 방식 대비 메모리 부담 없이 프레임 단위 매칭이 가능해진다.
  4. Latent Variation Sampling(LVS): 인접 잠재 슬라이스 간 평균제곱차 d_l을 계산해 변화가 큰 지점을 기준으로 시퀀스를 K개 구간으로 나누고, 각 구간에서 하나씩 슬라이스를 무작위 샘플링해 marginal DMD를 적용한다. 이는 정적인 구간에 지도가 몰려 동작을 억제하는 문제를 줄인다.
  5. 학습 설정: 자기회귀 모델은 Causal Forcing++ 체크포인트에서 초기화해 VidProM으로 1,000스텝, 양방향 모델은 CausVid 방식대로 Wan2.1-T2V-1.3B에서 초기화해 Mixkit으로 1,200스텝 DMD 학습을 수행했다. 기본 이미지 교사는 Qwen-Image, 기본 하이퍼파라미터는 ω=0.4, K=4이며, LatentBridge는 OpenVid 중 고화질·고동작 29,400개 비디오로 별도 학습했다.

실험 설정 및 결과

  • 벤치마크/지표: VBench 공식 프롬프트 스위트 외에, 세부 시각 요소와 복잡한 동작을 담은 400개 난이도 높은 프롬프트 테스트셋을 추가 구성했다. Semantic Score, Aesthetic Quality, Imaging Quality, Dynamic Degree, Motion Smoothness, 종합(Total) 점수를 보고한다.
  • 베이스라인: 자기회귀 생성에서는 Self Forcing, Reward Forcing, Causal Forcing++, One-Forcing(프레임/청크 단위 변형 포함)과 비교했고, 양방향 생성에서는 CausVid의 양방향 DMD 변형과 비교했다.
  • 정량 결과(VBench): 양방향 생성(NFE=4)에서 CausVid 대비 Total 80.63→81.45로 향상. 자기회귀 1스텝 설정에서 Causal Forcing++ 대비 Total 79.82→82.65, 2스텝에서 80.67→83.53, 4스텝(청크 단위)에서는 최고 성능 베이스라인(Causal Forcing++ 82.79) 대비 83.51로 전반적으로 우세했으며, 추가 추론 연산 없이 이러한 개선을 달성했다.
  • 인간 평가: 23명이 참여한 2지선다(2AFC) 평가에서 DuoMatching은 CausVid, Causal Forcing++, One-Forcing, Reward Forcing 대비 전체 선호도 80.87%~94.35%를 기록했다. 시각 품질·의미 정합성에서 특히 큰 우위를 보였고, 시간/모션 품질에서는 대체로 대등한 수준(50~91%)을 유지해 동작 역동성이 크게 훼손되지 않았음을 보였다.
  • 어블레이션: (1) 이미지 교사 종류 비교에서 더 강한 교사(Qwen-Image, HPSv3 점수 최고)일수록 Semantic/Aesthetic/Imaging 점수가 함께 향상되었고 Dynamic/Smoothness는 LatentBridge 덕분에 안정적으로 유지됐다. (2) marginal DMD를 압축 잠재에 직접 적용(Direct)하면 동작(Dynamic)이 크게 억제(94.44→76.94)되고, 디코드 후 재인코드(Decode-Encode) 방식은 메모리 초과(OOM)로 실패했으나, LatentBridge는 동작을 유지하면서(93.61) 시각/의미 품질도 함께 개선했다(Total 83.53). (3) 샘플 수 K는 4에서 최적이었고(K=8은 과도한 지도로 Dynamic·Total 모두 하락), LVS가 균등 무작위/시간 계층 샘플링보다 전반적으로 우수했다. (4) marginal 손실 가중치 ω는 0.4에서 최적이며, 0.8로 과도하게 키우면 Dynamic 점수가 크게 떨어져 시각 품질과 동작성 사이의 균형이 깨졌다.

한계점

논문에 별도의 "한계점" 절은 없으나, 본문과 어블레이션에서 다음과 같은 한계를 유추할 수 있다. - marginal DMD 가중치 ω나 샘플 수 K가 과도하면 동작 역동성(Dynamic Degree)이 뚜렷이 저하되는 트레이드오프가 존재하며, 최적값(ω=0.4, K=4)은 실험적으로 튜닝된 값이다. - 프레임 단위 매칭을 압축 잠재공간에 직접 적용하면 동작이 억제되고, 디코드-재인코드 방식은 메모리 초과로 실패하는 등, LatentBridge라는 별도의 경량 모듈을 추가로 사전학습해야 하는 구조적 복잡성이 추가된다. - 성능 향상은 사전학습된 이미지 교사(Qwen-Image 등)의 품질에 의존적이며(Table 3에서 교사 HPSv3 점수와 학생 성능이 비례), 더 약한 이미지 교사를 쓸 경우 개선 폭이 줄어든다. - 비디오 81프레임, 해상도 480×832 등 특정 설정에서 실험이 이루어졌으며, 더 긴 시퀀스나 다른 해상도·도메인에 대한 일반화는 논문에 명시되지 않음.

시사점

DuoMatching은 비디오 분포매칭증류를 "프레임 간 결합분포"와 "개별 프레임 주변분포"로 분리해 각각 별도의 교사(비디오 교사·이미지 교사)로 지도한다는 아이디어가 간결하면서도 효과적임을 보여준다. 특히 이미지 생성모델처럼 비디오보다 더 발전되고 다양한 사전학습 자원이 풍부한 모델을 "주변분포 교사"로 재활용할 수 있다는 점은, 비디오 생성 품질을 끌어올리는 데 있어 이미지 모델 생태계의 발전을 직접적으로 전이시킬 수 있는 실용적 경로를 제시한다. 또한 LatentBridge와 같은 잠재공간 변환 모듈은 서로 다른 모달리티/압축률을 가진 생성모델들을 결합해 상호 지도하는 일반적인 패턴으로도 확장 가능해 보인다. 실시간 상호작용 비디오 생성, 스트리밍 월드 모델 등 소수 스텝 생성이 필수적인 응용 분야에서 추가 추론 비용 없이 품질을 개선할 수 있다는 점에서 실용적 가치가 크다.
