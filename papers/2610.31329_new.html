WeVisOne-VL: Unified Visual Perception from Objects to Pixels

위비즈원-VL: 객체부터 픽셀까지 통합하는 시각 인식 모델

객체 검출·지칭(referring)·카운팅·OCR 같은 객체 수준 과제와 분할(segmentation)·매팅(matting) 같은 픽셀 수준 과제를 하나의 자연어 인터페이스와 구조화된 다음 토큰 예측(next-token prediction)으로 통합한 비전-언어 모델 WeVisOne-VL을 제안한 연구이다.

한 줄 요약

객체 검출·지칭(referring)·카운팅·OCR 같은 객체 수준 과제와 분할(segmentation)·매팅(matting) 같은 픽셀 수준 과제를 하나의 자연어 인터페이스와 구조화된 다음 토큰 예측(next-token prediction)으로 통합한 비전-언어 모델 WeVisOne-VL을 제안한 연구이다.

배경 및 문제의식

컴퓨터 비전은 전통적 검출·분할 모델에서 오픈월드 인식 모델, 그리고 최근의 대형 비전-언어 모델(VLM)로 발전해 왔지만, 실제 배포 관점에서는 여전히 만족스럽지 않다. 기존 모델들은 존재하지 않는 객체를 환각(hallucinate)하거나, 낯선 객체 표현을 만났을 때 사용자 의도를 잘못 해석하거나, 눈에 잘 띄지 않는 인스턴스를 놓쳐 재현율(recall)이 낮아지는 문제를 자주 보인다. 또한 객체 수준의 박스/점 예측과 픽셀 수준의 분할/매팅 예측은 대개 별도의 전문 모델이나 별도의 대형 분할 모델(SAM 등)에 의존해 구현되어 왔으며, 이를 단일 언어 인터페이스로 신뢰성 있게 통합하는 것은 미해결 과제였다.

핵심 기여

  1. 객체 검출, 지칭 로컬라이제이션, 카운팅, 포인팅, OCR 같은 객체 수준 인식과 분할·매팅 같은 픽셀 수준 인식을 하나의 구조화된 다음 토큰 예측 인터페이스로 통합한 VLM WeVisOne-VL(2B/4B)을 제시.
  2. <OBJ> 토큰을 매개로 VLM의 인스턴스 표현과 공유 ViT의 다단계(multi-level) 특징을 결합해, 별도의 대형 분할 모델 없이도 박스에서 마스크·알파 매트까지 인스턴스 단위 픽셀 출력을 생성하는 경량(약 9.6M 파라미터) 픽셀 디코더를 설계.
  3. 의미 발견(semantic discovery)부터 인스턴스 정합 지도(instance-aligned supervision), 매팅용 알파 지도까지 연결하는 통합 데이터 엔진(WeVisOne-VL Data Engine, WDE)을 구축하여 1억 장 이상의 이미지와 약 36억 개의 바운딩박스 주석을 확보하고, 모델 오류 피드백을 통해 데이터를 반복 정제.
  4. 3단계 지도 미세조정(SFT) 커리큘럼과 불확실성 기반 샘플 선택에 기반한 혼합 과제 강화학습(GRPO)을 결합한 학습 파이프라인을 제안하여, 객체 부재 질의에 대한 견고한 거부(rejection) 능력까지 함께 달성.

방법론

데이터 엔진(WDE). GRIT, CC3M, LAION, SA-1B 및 여러 과제별 데이터셋을 기반으로, (1) Wikipedia/WordNet 기반 지식 그래프로 카테고리 개념과 지칭 표현을 조직화하여 목표 지향적 수집을 수행하고, (2) SAM3와 자체 개방어휘 검출기의 제안을 Qwen3-VL로 검증하여 검출/지칭 주석을 생성하며, (3) SAM2로 이진 마스크를 확장하고, (4) BiRefNet·MatAnyone2 기반 전문가 보조 주석과 SAM2.1 기반 경량 알파 정제 헤드를 학습시켜 연속적인 알파 매트 지도를 생성한다. 이후 모델 학습 라운드마다 오류를 분석해(개념·도메인·규모·오클루전·과제·실패유형별 군집화) 추가 수집과 주석 보정에 반영하는 반복 정제 루프를 갖춘다. 또한 '빨간 차'를 '파란 차'로 바꾸는 식의 애매한 부정(negative) 질의를 전체 이미지 검증을 통해 걸러내어, 모델이 공백(empty) 타깃을 올바르게 거부하도록 가르치는 하드 네거티브를 구성한다.

모델 구조. Qwen3-VL을 백본으로 하여, 좌표를 <0>~<1000> 토큰으로 정규화해 인코딩하고 박스는 [x0,y0,x1,y1], 점은 [x0,y0]로 시퀀셜하게 생성한다(타깃 부재 시 None). 분할/매팅 등 픽셀 과제에서는 각 박스 예측 직후 <OBJ> 토큰을 생성하며, 이 토큰의 은닉상태가 경량 픽셀 디코더에 전달된다. 픽셀 디코더는 (1) ViT의 다단계 특징을 정제하는 시각 특징 어댑터, (2) VLM 출력에서 직접 인스턴스 쿼리를 초기화하는 Deformable DETR 스타일의 박스 가이드 쿼리 디코더, (3) 다단계 특징을 융합하고 동적 커널로 초기 마스크를 예측한 뒤 coarse-to-fine 방식으로 정제하는 인스턴스 조건부 밀집 예측 모듈로 구성되며, 총 파라미터는 약 9.6M에 불과하다.

학습 파이프라인. 3단계 SFT 후 혼합 과제 RL을 적용한다. Stage 1(과제 정렬)은 비전 인코더·프로젝터를 고정하고 언어모델만 약 9000만 예제로 학습해 구조화된 출력 형식을 익힌다. Stage 2(해상도·밀도 확장)는 비전 인코더까지 unfreeze하고 입력 해상도와 응답당 최대 박스/점 수를 늘려 소형·밀집 객체 인식을 개선한다. Stage 3(토큰-픽셀 교차 최적화)은 2억5천만 장의 분할 데이터로 픽셀 디코더를 먼저 워밍업한 뒤, VLM과 디코더를 함께 미세조정하여 <OBJ> 토큰을 VLM과 픽셀 디코더 사이의 다리로 확립하고, 이어서 1억3천만 매팅 샘플로 디코더를 추가 특화한다. 이후 RL 단계에서는 SFT 모델로 샘플링한 응답들의 보상 평균·분산으로 불확실성 점수를 계산해 학습하기 어려운(중간 난이도의) 샘플 약 14만 개를 선별하고, 이를 포함한 17.8만 예제에 대해 GRPO를 적용한다. 보상은 예측-정답 박스 간 매칭에 기반한 접지(grounding) 보상(IoU 세제곱 가중)을 사용하며, 지칭 분할은 <OBJ> 토큰 생성 여부까지, 부정 샘플은 '객체 없음' 예측 여부까지 반영한다.

실험 설정 및 결과

객체 검출(COCO/LVIS/Dense200/VisDrone), 지칭 검출(RefCOCOg, HumanRef, Ref-Adv, PR-Bench, DVGBench, Ref-L4, 자체 WeRef-Bench 등), 카운팅(CountQA, PixMo-Count, CLOC, KubriCount, MixCount), 포인팅(PointBench, PixMo-Points 등), OCR(HierText, ICDAR2015, TotalText, SROIE), 지칭 분할(RefCOCO/+/g, ReasonSeg, Ref-ZOM), 프롬프트 매팅(P3M-500-NP, AM-2K, PPM-100, 자체 WeRefMat) 등 30개 이상의 벤치마크에서 평가했다. Qwen3-VL/3.5 계열, Rex-Omni, LocateAnything 등 VLM 기반 모델 및 GroundingDINO-T 등 특화 모델과 비교한 결과, WeVisOne-VL(2B/4B)은 비교 가능한 규모의 VLM 대비 거의 모든 벤치마크에서 최고 또는 차순위 성능을 기록했다. 예를 들어 Dense200/VisDrone 같은 밀집·소형 객체 검출에서 개선폭이 특히 컸고(Mean F1 WeVisOne-VL-4B 71.3/44.7), RefCOCOg 등 지칭 검출과 WeRef-Bench의 거부율(Rej)에서도 기존 VLM을 상회했다. 카운팅에서는 PixMo-Count 검증/테스트에서 93.7%/89.6%의 정확 일치율로 모든 벤치마크·스플릿에서 최고 성능을 보였고, 지칭 분할(RefCOCO 계열 등)과 Ref-ZOM의 부재 타깃 거부에서도 기존 분할 특화 모델들을 능가했다. 매팅에서는 박스 프롬프트 기준 전문 매팅 모델과 경쟁력 있는 성능을, 자체 벤치마크 WeRefMat의 카테고리/지칭 프롬프트 기준으로는 SAM2-Matting 기반 베이스라인들을 큰 폭으로 상회했다. 정성적 비교(Fig. 5~13)에서도 먼지에 가려진 코끼리, 밀집한 과일, 커브 형태의 OCR 텍스트, 애매한 부재 타깃 거부 등에서 베이스라인 대비 우수한 사례를 다수 제시했다.

한계점

저자들은 논문에서 다음 한계를 직접 서술한다. 첫째, 근본적인 시각 인지에 집중하다 보니 범용 학습 데이터 비중이 상대적으로 적어 베이스 모델 대비 일반적 능력이 저하될 수 있다. 둘째, 추론 효율성을 위해 체인-오브-쏘트(CoT) 추론 없이 구조화된 출력을 직접 생성하도록 학습하여, 복잡한 추론이 필요한 과제에서는 능력이 제한될 수 있다. 셋째, 현재 방식은 단일 턴(single-turn) 예측에 한정되어 있으며, 다중 턴 도구 상호작용을 통한 점진적 시각 이해 정제로의 확장이 향후 과제로 남는다. 또한 벤치마크의 질의는 명확하고 잘 구성된 반면, 실제 사용자 지시는 모호하거나 주저하는 경우가 많아, 맥락이나 화법의 변화가 상당한 난이도를 유발할 수 있다는 실세계 복잡성과의 괴리도 지적한다.

시사점

이 연구는 좌표 토큰화와 <OBJ> 토큰이라는 비교적 단순한 설계만으로 객체 수준과 픽셀 수준 인식을 하나의 자기회귀 인터페이스에 통합할 수 있음을 보이며, 별도의 대형 분할 모델 없이도 경량 디코더로 고품질 마스크·매트를 생성할 수 있다는 점에서 실용적 VLM 설계에 시사점을 준다. 또한 지식 그래프 기반 데이터 엔진과 오류 피드백 기반 반복 정제, 불확실성 기반 RL 샘플 선택이 결합된 학습 파이프라인은, 환각과 거부 실패라는 VLM의 고질적 문제를 완화하면서 신뢰할 수 있는 실세계 시각 인식 시스템을 구축하는 방법론적 참고 사례를 제공한다.
