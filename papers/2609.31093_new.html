Block Sparse Attention with Log-Linear Complexity

로그선형 복잡도를 갖는 블록 희소 어텐션

블록 희소 어텐션에서 가장 비용이 큰 "블록 선택" 단계를 모든 쿼리-블록 쌍을 스캔하는 대신 피라미드 형태의 거친-미세(coarse-to-fine) 계층 구조로 좁혀나가는 PISA를 제안해, 선택 단계 복잡도를 O(N²/C)에서 O(N log N)으로 낮춘다.

한 줄 요약

블록 희소 어텐션에서 가장 비용이 큰 "블록 선택" 단계를 모든 쿼리-블록 쌍을 스캔하는 대신 피라미드 형태의 거친-미세(coarse-to-fine) 계층 구조로 좁혀나가는 PISA를 제안해, 선택 단계 복잡도를 O(N²/C)에서 O(N log N)으로 낮춘다.

배경 및 문제의식

블록 희소 어텐션은 키/밸류를 블록 단위로 묶어 각 쿼리가 상위 K개 블록만 계산하게 함으로써 어텐션 계산 자체는 시퀀스 길이에 선형적으로 만든다. 그러나 그 전에 어떤 블록이 상위 K개인지 정하는 "블록 선택" 단계는 모든 쿼리가 전체 N/C개 블록 요약과 점수를 계산해야 하므로 여전히 O(N²/C)로 이차적이며, 이것이 장문맥 모델링의 새로운 병목이 된다.

핵심 기여

  • 미세→거친 방향으로 키 블록의 풀링 계층(피라미드)을 구성하고, 선택은 반대로 거친 레벨에서 시작해 선택된 후보만 다음 미세 레벨로 확장하는 피라미드 Top-K 블록 선택 기법 제안.
  • 각 레벨에서 자식 블록 요약에 대해 LogSumExp(LSE) 점수를 적용해 후보를 좁혀가며, 최종 레벨에서는 원본 키에 대해 정확한 LSE로 채점.
  • 여러 계층의 라우팅과 LSE 채점을 하나의 커널로 융합해 쿼리-키 점수 행렬을 저장하지 않는 하드웨어 인식 Triton 커널을 학습·추론용으로 각각 구현.

방법론

레벨 0은 원본 키를 단일 블록으로 취급하고, 상위 레벨은 하위 레벨의 인접 블록을 평균 풀링해 구성해 O(log N) 개의 레벨을 만든다. 선택은 가장 거친 레벨부터 시작해 고정된 후보 집합에 대해 LSE 점수를 계산하고 Top-K만 남긴 뒤 다음 미세 레벨로 확장하며 나머지는 버린다. 고정된 Top-K 예산, 분기 계수, 리프 블록 크기 하에서 쿼리당 라우팅 비용이 O(log N)이 되어, 전체 시퀀스에 대해서는 O(N log N)의 블록 선택 복잡도를 달성한다.

실험 설정 및 결과

언어 모델링 과제에서 기존 블록 희소 어텐션 기준선(BSA) 대비, 상식 추론 벤치마크에서는 비슷한 성능을 유지하면서 검색(retrieval) 과제에서는 더 나은 결과를 보였다. 최대 256K 토큰 길이의 Top-K 선택 벤치마크에서도 계층적 라우팅이 단일 레벨 선택보다 긴 시퀀스에서 더 효율적임을 확인했다.

한계점

계산 자원의 제약으로 실험에 사용된 모델 크기와 사전학습 데이터 예산이 제한적이었으며, 이는 기준선 대비 성능 격차에 상당한 영향을 줄 수 있다. 다만 평가된 설정 내에서는 피라미드 블록 선택이 경쟁력 있는 모델 성능을 유지하면서 선택 복잡도를 줄인다는 핵심 결론은 유지된다(논문에 명시).

시사점

장문맥 언어모델의 실질적 병목이 어텐션 계산 자체보다 "어떤 블록을 볼지 정하는" 선택 단계로 옮겨가고 있음을 보여주며, 계층적/로그선형 라우팅이 학습 가능한 희소 어텐션 설계에서 실용적인 대안이 될 수 있음을 시사한다.
