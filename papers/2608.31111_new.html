Aspire: Can Models Self-Evolve from Vague Goals?

어스파이어: 모델은 모호한 목표로부터 스스로 진화할 수 있는가?

"수학 성능을 올려라"처럼 구체적인 과제 대신 "더 나은 물리학자가 되어라" 같은 모호한 목표만 주어졌을 때, LLM 에이전트가 스스로 무엇을 배워야 할지 정하고 실제로 능력을 키울 수 있는지를 검증하는 벤치마크 Aspire를 제안하고, 현재 에이전트들이 학습 루프는 잘 완수하지만 실제 역량 향상은 거의 이루지 못함을 보인다.

한 줄 요약

"수학 성능을 올려라"처럼 구체적인 과제 대신 "더 나은 물리학자가 되어라" 같은 모호한 목표만 주어졌을 때, LLM 에이전트가 스스로 무엇을 배워야 할지 정하고 실제로 능력을 키울 수 있는지를 검증하는 벤치마크 Aspire를 제안하고, 현재 에이전트들이 학습 루프는 잘 완수하지만 실제 역량 향상은 거의 이루지 못함을 보인다.

배경 및 문제의식

기존 LLM 자가진화(self-evolution) 연구는 대부분 사람이 이미 "AIME 점수를 올려라"처럼 과제와 평가 지표를 구체적으로 정해준 상태에서 시작한다. 이 경우 에이전트는 "어떻게 개선할지"만 탐색하면 되고, "무엇을 개선할지"는 이미 정해져 있다. 그러나 실제 인간의 학습(예: 더 나은 연구자가 되기)은 막연한 방향만 주어진 채 스스로 부족한 부분을 진단하고, 학습 방법을 정하고, 실제로 나아졌는지 검증까지 해야 한다. 저자들은 이를 산업 현장의 "포워드 디플로이드 엔지니어(FDE)" 역할에 비유하며, 모델이 모호한 목표를 실행 가능한 학습 목표로 전환하는 과정 자체가 자가진화 연구에서 빠져 있는 축이라고 지적한다.

핵심 기여

  1. 모호한 목표 기반 자가진화라는 문제를 공식화하고, 이를 "목표 구체화(target operationalization)"라는 자가 학습의 새로운 축으로 정의했다.
  2. 평가 항목과 기준을 에이전트에게 완전히 숨긴 채 진행되는 벤치마크 Aspire를 만들어, 모델 가중치 수준과 에이전트 하네스(런타임 프롬프트·도구 정책·워크플로 등) 수준 모두에서 자가진화를 지원하는 최소한의 상호작용 환경을 제공했다.
  3. 실행 결과와 궤적(trajectory)을 함께 기록·분석하여, 에이전트가 "학습 루프를 완수하는 것"과 "실제로 목표 역량을 향상시키는 것" 사이에 큰 간극이 있음을 증거로 제시했다.

방법론

Aspire는 자연어로 된 모호한 목표(G)만 제공하고, 실제 평가 문항·정답·루브릭은 컨트롤러 측에 숨겨둔 채 절대 노출하지 않는다. 에이전트는 데이터 검색·다운로드·합성, SFT/GRPO(LoRA 포함) 학습 실행, 자체 검증 데이터 구축, 체크포인트 분기·중단 등을 표준화된 도구 호출을 통해 수행하며, 백엔드의 자격증명·자원 관리·복구 등은 컨트롤러가 대신 처리한다. 평가는 과학·인문사회·의학·수학·논리 및 지시 따르기·학술 글쓰기의 여섯 개 목표에 걸친 총 520개의 전문가 제작 문항으로 구성되며, 프로토콜에 따라 중간 점수를 전혀 주지 않거나(최종 전용 프로토콜) 제한된 횟수만큼 총합 점수만 제공한다(적응형 피드백 프로토콜). 안전장치로서, 새 체크포인트의 점수가 기존 모델보다 높을 때만 채택하고 그렇지 않으면 롤백하는 방식을 채택해 "유지된 개선"이 실제로 기존보다 나빠지지 않도록 보장한다.

실험 설정 및 결과

연구질문(RQ)은 세 가지다. RQ1은 동일한 조건에서 명시적 과제 대신 모호한 목표를 줬을 때 무엇이 달라지는지를 본다. Claude Opus 4.8은 모호한 목표 하에서 27.07점을 받아 공식 참조치(32.90점)보다 낮았고, GPT-5.6도 29.58 대 36.23으로 낮았다. 모호한 목표 조건에서는 의사결정(사고) 시간과 GPU 유휴 시간이 늘고 실제 학습 시간은 줄어드는 경향이 관찰됐다.

RQ2는 명령어 튜닝된 체크포인트에서 시작해 실제로 가중치를 업데이트해 역량을 향상시킬 수 있는지를 본다. 최종 전용 프로토콜에서는 12개 모델-목표 조합 중 단 1개(Qwen3.5-9B의 "과학·학술 추론" 목표)만 기준 점수를 넘겼다. 적응형 피드백 프로토콜에서는 30개 설정-목표 조합 중 28개가 평가 가능한 체크포인트를 만들었지만, 최종적으로 롤백 후에도 기준선을 넘긴 경우는 단 1건(GPT-5.6 Terra가 수학 목표에서 17.86→20.10점)에 불과했다. 또한 다섯 개 체크포인트가 숫자 라벨로만 구성된 MMLU 데이터로 SFT되어 출력 형식이 한 자리 숫자로 붕괴하는 실패 사례도 발견됐다.

RQ3는 모델 가중치를 고정한 채 에이전트 하네스 자체를 진화시킬 수 있는지 본다. Qwen3.5-4B를 실행 모델로 고정하고 원본 Qwen-Agent를 기준선(작업별 매크로 28.64점)으로 삼았을 때, GPT-5.6 기반의 세 후속 하네스(Luna, Terra, Sol) 모두 기준선에 미치지 못했으며(각 19.32, 20.76, 27.22점), 가장 근접한 Sol도 1.42점 낮았다. 세부 사례 분석에서는 좁은 자체 검증 프롬프트에 과적합되거나, 도구 호출 실패 시 빈 응답을 그대로 제출하는 등의 구체적 실패 패턴이 확인됐다.

한계점

평가는 여섯 개 목표와 전문가 제작 문항의 범위 및 품질에 한정되며, 적응형 피드백 실험은 설정-목표 조합당 단 1회 실행만 이루어져 반복 재현성이 검증되지 않았다. 내용 수준의 원인 분석(예: 특정 실패의 정확한 트리거)은 통제된 접근 권한이 있는 원본 트레이스에서만 가능하다. 또한 재귀적으로 여러 라운드에 걸쳐 의사결정 모델 자체를 교체하며 진화시키는 실험은 다루지 않았다.

시사점

이 논문은 "학습 루프를 완수하는 것"과 "실제로 역량이 향상되는 것"이 다른 문제임을 명확히 보여준다. 현재 에이전트들은 데이터 수집, 학습 실행, 체크포인트 생성이라는 실행 절차는 능숙히 수행하지만, 잘못된 데이터를 학습하거나 좁은 자체 평가만 신뢰해 실제 숨겨진 평가에서는 개선을 보이지 못하는 경우가 많다. 향후 자가진화 시스템을 설계할 때는 진행 상황을 이전 체크포인트가 아니라 항상 기준 모델(base model) 대비로 평가해야 하며, 목표 해석과 검증 신호 구축 자체를 더 신뢰성 있게 만드는 연구가 필요함을 시사한다.
