CodeCap-Bench: Can Code Serve as a Good Video Caption?

CodeCap-Bench: 코드는 좋은 비디오 캡션이 될 수 있는가?

자연어 대신 실행 가능한 코드로 비디오를 캡셔닝하는 "Code as Video Caption" 패러다임을 제안하고, 이를 체계적으로 평가하기 위한 323개 영상 규모의 벤치마크 CodeCap-Bench를 공개하여 현재 멀티모달 대형언어모델(MLLM)들의 코드 캡셔닝 능력을 측정한다.

한 줄 요약

자연어 대신 실행 가능한 코드로 비디오를 캡셔닝하는 "Code as Video Caption" 패러다임을 제안하고, 이를 체계적으로 평가하기 위한 323개 영상 규모의 벤치마크 CodeCap-Bench를 공개하여 현재 멀티모달 대형언어모델(MLLM)들의 코드 캡셔닝 능력을 측정한다.

배경 및 문제의식

기존 비디오 캡셔닝은 대부분 자연어로 객체·속성·행동·사건을 기술하지만, 복잡한 레이아웃이나 다중 객체의 정밀한 공간 구조·시간적 동역학을 자연어로 표현하면 설명이 길어지고 모호해지기 쉽다. 저자들은 그래픽 기본 요소(primitive), 레이아웃 규칙, 시간 함수로 구성된 실행 가능한 코드가 이러한 정보를 더 명확하고 간결하게 표현할 수 있는 보완적 표현 방식이 될 수 있다고 보고, 코드 캡션이 실제로 비디오 정보를 얼마나 잘 보존하는지, 그리고 현재 MLLM이 충실한 코드 캡션을 생성할 수 있는지를 검증한다.

핵심 기여

1) 코드 캡션을 자연어 캡션과 비교하는 다운스트림 질의응답·비디오 재구성 실험을 통해 코드 캡션이 더 높은 추론 정확도와 재구성 충실도를 보임을 입증한다. 2) 5개 범주의 구조화된 2D 콘텐츠(데스크톱/앱 인터페이스, 2D 게임, 시각 디자인/미디어 애니메이션, 데이터/과학 시각화, 아이콘/추상 모션 그래픽)로 구성된 323개 영상 규모의 CodeCap-Bench를 구축하고, 정밀한 초점(focal-point) 주석과 다단계 평가 프레임워크를 제공한다. 3) 7개 MLLM을 에이전틱(agentic)·비에이전틱 설정에서 광범위하게 평가하여, 상위 비공개 모델도 복잡한 시간적 동역학 포착에는 한계가 있고 오픈소스 모델은 그 격차가 더 크다는 점을 보여준다.

방법론

코드 캡셔닝은 참조 비디오를 입력받아 이를 재현하는 실행 가능한 프로그램 C를 생성하는 과제로 정의되며, 참조 프레임이나 외부 시각 자산을 재사용하지 않는 "순수 코드" 설정을 사용한다. 평가는 세 층위로 구성된다: (1) 시각적 유사도 – V-JEPA 2.1 ViT-Gigantic-384로 추출한 특징 간 코사인 유사도, (2) 객체 단위 시공간 IoU – GPT-6-sol이 객체의 가시 구간과 대표 프레임을 식별하고 SAM 3.1으로 분할한 바운딩 박스 간 IoU, (3) 세밀한 시각 정보 보존도 – 정적/동적 초점 포인트에 대해 GPT-6-sol이 0~5점으로 충실도를 채점. 벤치마크는 Bilibili·YouTube·Behance·Vimeo에서 수집한 영상을 장면 기하/복잡도 기준으로 필터링하고, 초점 포인트 및 객체 단위 시공간 주석에 사람의 검토를 거쳐 구축했다.

실험 설정 및 결과

GPT-6-astra, GPT-6-sol, GPT-5.6-sol, Qwen3.8-max, DeepSeek-v4.1-flash, Opus-5, Gemini-3.8-flash 등 7개 MLLM을 Pi Agent·Codex·Claude Code 등의 에이전트 하네스와 함께, 그리고 비에이전틱 설정으로 평가했다. GPT-6-astra가 전반적으로 가장 높은 성능(비디오 제작 성공률 99%대, 세밀한 정보 보존 종합 점수 약 72~73점)을 보였고, 그다음으로 Opus-5가 뒤를 이었다. 별도의 캡션-투-비디오 재구성 비교 실험에서는 코드 렌더링 방식이 자연어 캡션 기반 생성 방식보다 외형·구조 유사도(AS, KSS 등 지표에서 0.18~0.23 포인트)와 모션 패턴 유사도 모두에서 일관되게 우수했다. 다만 에이전틱 워크플로우는 렌더링 성공률은 높였지만 캡션 충실도 자체를 일관되게 향상시키지는 못했다.

한계점

논문 본문에 별도의 "Limitations" 절은 명시되지 않았다. 다만 결과에서 드러난 한계로, 선두 비공개 모델조차 복잡한 시간적 동역학(동시다발적 상태 변화, 정밀한 타이밍 등)을 충실히 코드로 표현하는 데 어려움을 겪고, 오픈소스 모델은 이러한 격차가 훨씬 크게 나타난다는 점, 그리고 에이전틱 워크플로우가 렌더링 안정성은 높이지만 캡션의 실제 충실도 향상에는 기여하지 못한다는 점이 지적된다.

시사점

이 연구는 자연어 외에 "실행 가능한 코드"라는 새로운 축을 비디오 캡셔닝에 도입하여, 공간 구조와 시간적 규칙이 명시적인 콘텐츠에 대해서는 코드가 더 압축적이고 검증 가능한 표현이 될 수 있음을 실증적으로 보여준다. CodeCap-Bench는 이러한 코드 캡셔닝 능력을 측정할 표준화된 평가 도구를 제공함으로써, 향후 MLLM의 구조화된 시각 정보 이해·생성 능력을 발전시키는 기반이 될 것으로 보인다.
