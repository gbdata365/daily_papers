Code World Model 2.0: Towards Infinite Controllable Video Generation

코드 월드 모델 2.0: 무한 제어 가능 비디오 생성을 향하여

구조화된 "프록시"(레이아웃·깊이·포즈 등)와 외형 참조 이미지, 텍스트를 하나의 조건으로 받아, 오프라인 영상 제작용 양방향 생성과 실시간 4단계 인과적 스트리밍 렌더링을 동시에 지원하는 통합 비디오 렌더링 프레임워크 Invoker-Render를 제안한다.

한 줄 요약

구조화된 "프록시"(레이아웃·깊이·포즈 등)와 외형 참조 이미지, 텍스트를 하나의 조건으로 받아, 오프라인 영상 제작용 양방향 생성과 실시간 4단계 인과적 스트리밍 렌더링을 동시에 지원하는 통합 비디오 렌더링 프레임워크 Invoker-Render를 제안한다.

배경 및 문제의식

인터랙티브 비디오 월드 모델은 사용자의 행동에 따라 일관된 화면을 실시간으로 합성해야 한다. 최근에는 동역학과 외형을 하나의 네트워크가 전부 학습하는 대신, 상태(지오메트리, 카메라 경로, 엔티티 동작 등)를 담당하는 상류 엔진과 사실적 이미지를 합성하는 생성형 렌더러를 분리하는 접근이 각광받고 있다. 그러나 실제 상호작용에서 필요한 구조적 디테일의 수준은 상황마다 다르다. 넓은 범위 이동에는 거친 장면 지오메트리만 있어도 되지만, 근접 상호작용에는 관절이 있는 포즈나 세밀한 표면 구조가 필요하다. 세밀한 프록시는 강한 제약을 주지만 생성·전송 비용이 크고, 거친 프록시는 가볍지만 국소 기하와 모션이 불명확해진다. 기존 방법들은 이 두 체제를 동시에 신뢰성 있게 처리하지 못했고, 양방향(전체 클립을 한 번에 보는) 생성과 스트리밍(미래 상태가 아직 정해지지 않은 실시간) 렌더링을 분리된 모델로 다뤄야 했기에, 스텝 압축이나 자가 생성 히스토리 누적에 따른 오차(drift)가 발생하는 문제도 있었다.

핵심 기여

  • 다중 세밀도 프록시 조건화: 동일한 조건 인터페이스로 거친 프록시(전역 레이아웃, 카메라, 루트 모션)와 세밀한 프록시(관절 포즈, 국소 표면 구조)를 모두 받아들이는 체크포인트를 학습시켜, 추론 시 입력 디테일 수준을 자유롭게 선택할 수 있게 했다.
  • Progressive Forcing(ProForcing): 인과적 적응과 4단계 distribution matching distillation(DMD), GAN 감독을 단계적으로 결합한 뒤, 학습된 student·score model·discriminator를 연속적인 자가 생성 롤아웃으로 이어서 계속 학습시키는 커리큘럼을 제안했다.
  • 장시간 제어 가능 생성: 4단계 인과적 렌더러가 기존 스트리밍 베이스라인들을 능가하며, 약 30분 분량의 레이싱 롤아웃에서도 장면과 피사체의 외형을 안정적으로 유지한다.
  • 다중 세밀도 데이터셋과 서빙 스택: 약 200시간 분량의 정렬된 멀티그래뉼래리티 데이터셋을 구축하고, 저지연 분산 서빙 엔진을 설계했다.

방법론

Invoker-Render는 MiniMax-H3 백본을 기반으로, Guidance-Free Training(GFT)을 통해 구조 프록시 조건화에 맞게 적응시킨 양방향 생성 모델과, 이를 인과적(causal) 4단계 스트리밍 렌더러로 변환한 모델, 두 가지로 구성된다. 클린 비디오 잠재 변수를 시간적 블록들로 나누고, 외형 앵커·시스템 지시문·구조 프록시·텍스트 주석을 조건으로 받아 블록별로 조건부 분포를 인과적으로 모델링한다(식 1). 선형 흐름 매칭(flow matching) 파라미터화를 채택해 노이즈와 클린 잠재 변수 사이의 속도장을 학습한다.

ProForcing은 4단계로 진행된다. ① Teacher Forcing/Resampling Forcing으로 블록 인과적 어텐션을 적응시키며, 깨끗한 히스토리(TF)뿐 아니라 현재 모델이 직접 한 단계씩 정제해 만든 불완전한 히스토리(RF)로도 학습해 추론 시의 복원 오차에 대비한다. ② RF-DMD 단계에서는 distribution matching distillation과 teacher-feature 기반 상대론적(relativistic) GAN 손실을 결합해, 데이터로 고정된 히스토리 위에서 4단계 생성기로 증류한다. ③ 이 과정에서 학습된 student, fake score model, discriminator, 옵티마이저 상태를 그대로 이어받아 SF-DMD 단계로 전환해, 이번에는 모델이 스스로 생성한 연속적인 롤아웃 히스토리 위에서 학습을 계속한다. 이를 통해 콜드스타트 문제 없이 장시간 롤아웃에서 누적되는 오차를 완화한다.

서빙 측면에서는 비대칭 스트리밍 코덱(경량 Tiny AutoEncoder로 입력 프록시를 인코딩하고, 인과적 비디오 디코더로 출력 RGB를 복원), 윈도우 내 연산 재사용(레이어 간 구조 공유, AdaLN 투영 캐싱, KV 워크스페이스 재사용, prefill과 첫 디노이징 패스의 융합), 그리고 청크 간 코덱 파이프라이닝과 비동기 CPU 전달 등 세 단계의 최적화를 적용해 1344×768 해상도에서 청크당 처리 시간을 1770ms에서 930ms로 줄이고 처리량을 9.9FPS에서 18.0FPS로 끌어올렸다.

실험 설정 및 결과

140개의 held-out 테스트 시퀀스(다양한 3D 환경, 다중 엔티티 상호작용 포함)에서, SolarRenderer(인과적 4단계), StreamRender-H3(2단계), Streaming CWM(4단계) 세 가지 최근 스트리밍 프록시 조건부 렌더러와 비교했다. 평가는 동일한 구조 프록시 비디오와 외형 참조 이미지를 각 방법에 제공한 뒤, Gemini 3.8 Flash를 이용한 블라인드 쌍대 비교로 진행되었으며, Visual Quality, Structure & Motion, Reference Preservation, Overall Preference 네 축에서 Elo 점수(평균 1000 정규화)로 집계되었다.

Invoker-Render는 네 가지 기준 모두에서 1위를 기록했으며 Overall Elo는 1232.0이었다. Streaming CWM 대비 92.9% 승률(+539.6 Elo), StreamRender-H3 대비 82.9% 승률(+291.8 Elo), 가장 강력한 베이스라인인 SolarRenderer(Causal) 대비 62.9% 승률(+96.7 Elo)을 보였다. 정성적으로도 비교 대상들은 장시간 롤아웃에서 장면 기하 소실, 텍스처 아티팩트, 외형 참조로부터의 드리프트(예: 수중 장면이 밝은 하늘로 바뀌거나, 날개 달린 캐릭터가 날개를 잃는 등) 문제를 보인 반면, Invoker-Render는 7개 held-out 시퀀스 전반에서 구조 정합성과 참조 정체성을 모두 유지했다. 또한 다섯 가지 프록시 표현군(semantic map, sparse 3D box, subject mask, shaded geometry, box+skeleton)과 세 단계의 기하학적 세밀도, 여러 카메라 경로, 약 5분(298~299초)에 걸친 레이싱 시퀀스에서도 차량 외형과 궤적 추종이 안정적으로 유지됨을 보였다.

한계점

현재 구조는 고정된 prefix sink와 슬라이딩 KV 윈도우로 추론 비용을 제한하기 때문에, 활성 컨텍스트 범위를 벗어난 시각적 디테일은 결국 소실(eviction)된다는 한계가 있다. 저자들은 학습 가능한 메모리 압축, 시공간적 컨텍스트 검색, 영속적인 3D 인식 상태 캐시 등 명시적 장기 메모리 메커니즘을 인과적 학습과 증류 과정에 직접 결합하면 재방문 장면에서도 다중 엔티티 외형 일관성을 유지할 수 있을 것으로 전망한다. 또한 현재 학습은 롤아웃 윈도우 내에서 고정된 프록시 세밀도를 사용하므로, 스트리밍 중간에 동적으로 세밀도 수준(LOD)을 전환하는 것과 Invoker-Render를 인터랙티브 상태 엔진과 폐루프(closed loop)로 결합하는 것은 향후 과제로 남겨두었다.

시사점

이 연구는 '구조는 상류 엔진이 결정하고 외형은 생성 모델이 담당한다'는 분리형 패러다임에서, 조건의 세밀도(coarse vs. fine)를 단일 모델이 유연하게 처리하도록 통합함으로써 다양한 상호작용 상황(원거리 내비게이션부터 근접 캐릭터 상호작용까지)에 하나의 가중치로 대응할 수 있음을 보여준다. 또한 양방향 생성 모델을 few-step 인과적 스트리밍 렌더러로 전환하는 과정에서 발생하는 궤적 압축 오차와 자가 생성 히스토리에 대한 노출 편향 문제를 단계적 커리큘럼(ProForcing)으로 분리해 해결한 점은, 향후 실시간 인터랙티브 월드 모델을 상용 수준의 지연 시간과 길이로 확장하는 데 실질적인 엔지니어링 템플릿을 제공한다.
