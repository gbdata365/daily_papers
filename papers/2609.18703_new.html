RayOrch: Programming and Executing Lineage-Controlled Multi-Grain Dataflows for Foundation-Model Data Preparation

레이오크: 파운데이션 모델 데이터 준비를 위한 계보 제어 멀티그레인 데이터플로우 프로그래밍과 실행

파운데이션 모델용 대규모 데이터 준비 파이프라인에서, 문서·영상이 페이지·클립 등 여러 단위로 반복적으로 쪼개지는 구조(부모-자식 관계)를 실행 내내 유지하면서도 GPU 배치는 여러 부모의 작업을 섞어 처리할 수 있게 하는 프로그래밍 모델 겸 분산 실행 엔진 RayOrch를 제안한다.

한 줄 요약

파운데이션 모델용 대규모 데이터 준비 파이프라인에서, 문서·영상이 페이지·클립 등 여러 단위로 반복적으로 쪼개지는 구조(부모-자식 관계)를 실행 내내 유지하면서도 GPU 배치는 여러 부모의 작업을 섞어 처리할 수 있게 하는 프로그래밍 모델 겸 분산 실행 엔진 RayOrch를 제안한다.

배경 및 문제의식

PDF는 페이지→영역→표로, 영상은 클립→프레임→오디오로 반복해서 처리 단위가 바뀌며, 부모당 자식 개수 분포는 매우 편향(long-tailed)되어 있다. 기존 시스템은 두 가지 방식 중 하나를 택할 수밖에 없었다: (1) 문서/영상 전체를 하나의 불투명한 작업으로 다루는 방식은 내부 병렬성을 숨기고, (2) 개별 항목을 평평하게(flat) 노출하는 방식은 병렬성은 살리지만 애플리케이션이 직접 부모-자식 관계, 순서, 완료 시점을 추적하고 전역적으로 재조립해야 한다.

핵심 기여

  • 유한 비순환 도메인 트리 위에서 순서 있는 가변 카디널리티 확장(parent→children)과 이에 대응하는 부모 단위 수집(gather)을 선언적으로 표현하는 구조적 모델을 정식화.
  • 구조적 계보(lineage) 상태(구체적 자식 집합, 각 자식의 부모·순번, 종료 상태)를 실행 내내 유지하면서 물리적 배치는 일시적으로 유지하는 엔진 설계.
  • 부모 단위로 범위가 한정된 타입드 실패(failure) 격리 메커니즘과 세대 고정(generation-fenced) 커밋을 구현.

방법론

프로그램은 F.expand로 부모→자식 도메인 관계를 선언하고 F.reduce로 이에 대응하는 부모 단위 순서 있는 수집을 선언하며, 컴파일러가 이 둘의 짝을 검증한다. 실행 중에는 Call별 FIFO 준비 큐가 여러 부모의 준비된 작업(Grain)을 묶어 배치를 구성하지만, 불변 순번(ordinal)과 선언된 멤버십을 기준으로 수집이 이루어지므로 배치 경계나 완료 순서가 재구성 순서를 좌우하지 않는다. 완료된 부모는 모든 필요한 자식 결과가 종료되는 즉시 다음 단계로 넘어갈 수 있고, 특정 부모에 대해 타입 지정된 그룹 실패가 발생하면 해당 부모의 미배차 형제 작업들은 억제되지만 무관한 부모들의 처리는 계속된다.

실험 설정 및 결과

Ray 위에 파이썬 레이어로 구현하여 MinerU·Docling 문서 파이프라인과 Qwen2.5-VL-7B 영상 파이프라인에서 평가했다. NVIDIA H20 GPU에서 MinerU를 4→64 GPU로 확장 시 처리시간 15.14배, 영상 파이프라인을 8→64 GPU로 확장 시 7.82배의 속도 향상을 보였다. 종단 간 처리시간은 MinerU 기준 Ray Data 대비 13.1%, Daft 대비 29.0% 단축되었고, Docling에서는 Ray Data 대비 16.0% 단축되었다. FIFO 디스패치만으로 실행 시간이 634.1초에서 579.3초로(8.6%) 줄었으며, 실패 주입 실험에서는 23,514개 형제 계산 중 6,241개가 UDF 진입 전에 차단되어 평균 14.93%의 실행 시간이 단축되었다.

한계점

RayOrch는 각 소스 마이크로배치 내의 순서 있는 수집만 지원하며, 일반적인 조인, 마이크로배치를 넘나드는 윈도우, 피드백 루프는 지원하지 않는다(논문에 명시).

시사점

문서·영상 전처리처럼 처리 단위가 계속 바뀌는 대규모 데이터 파이프라인에서, 구조적 계보 정보를 실행 상태로 승격시키는 것이 스케줄링 효율성과 정확한 복원·실패 격리를 동시에 달성하는 핵심 설계 원칙이 될 수 있음을 보여준다.
