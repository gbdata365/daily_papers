MemOnce: A Scalable Memory Architecture for Large Language Models

멤온스: 대형 언어 모델을 위한 확장 가능한 메모리 아키텍처

MemOnce는 마지막 레이어의 은닉 상태 일부만을 압축된 메모리로 캐싱하고, 모든 레이어에 걸쳐 단 한 번만 관련 메모리를 검색해 KV 캐시로 복원하는 구조를 통해, 선형 시간 복잡도와 일정한 메모리 사용량을 유지하면서도 트랜스포머를 능가하는 성능을 달성한 최초의 네이티브 메모리 아키텍처다.

한 줄 요약

MemOnce는 마지막 레이어의 은닉 상태 일부만을 압축된 메모리로 캐싱하고, 모든 레이어에 걸쳐 단 한 번만 관련 메모리를 검색해 KV 캐시로 복원하는 구조를 통해, 선형 시간 복잡도와 일정한 메모리 사용량을 유지하면서도 트랜스포머를 능가하는 성능을 달성한 최초의 네이티브 메모리 아키텍처다.

배경 및 문제의식

LLM이 장시간·연속적인 상호작용에서 재사용 가능한 메모리 상태를 유지하려면 두 가지 극단 사이에서 트레이드오프가 발생한다. 표준 트랜스포머는 레이어마다 토큰 단위 KV 캐시를 누적해 컨텍스트가 길어질수록 GPU 메모리가 선형으로 증가하고 연산량은 제곱으로 증가한다. 반면 Mamba, RWKV, GDN 같은 선형 시간 아키텍처는 과거 정보를 고정 크기 상태로 압축하지만, 세밀한 정보가 손실되기 쉽다. 하이브리드 어텐션, 네이티브 메모리 모델(Titans, M+, Metis 등), 외부 메모리 시스템(Mem0 등) 등 기존 시도들도 각각 전역 캐시 유지 부담, 성능 저하·계층별 검색 오버헤드·치명적 망각, 비용이 큰 외부 저장소 구축 문제를 안고 있었다.

핵심 기여

  1. 정확한 회상, 선형 시간 추론, 일정한 GPU 메모리 사용량을 동시에 달성하는 기초 아키텍처 MemOnce를 제안했다.
  2. 메모리 인코더-디코더: 마지막 레이어 은닉 상태의 작은 부분집합(예: 1/8)만 압축된 메모리 표현으로 캐싱하고, 경량 MLP로 이를 다시 각 어텐션 레이어의 KV 캐시로 동적 복원한다.
  3. 메모리 희소 어텐션: 입력마다 관련성이 높은 상위-K개 메모리 표현을 적응적으로 검색하며, 이 희소 인덱스는 모든 레이어와 디코딩 단계에서 단 한 번만 계산되어 공유된다.
  4. 풀 컨텍스트 베이스라인을 능가한 최초의 네이티브 메모리 모델임을 입증했다.

방법론

MemOnce는 "메모리 상태 학습"이라는 통합 관점에서, 트랜스포머의 전체 토큰 KV 캐시, 선형 모델의 고정 크기 상태를 포함한 기존 방법들을 하나의 수식(현재 입력과 과거 맥락으로부터 활성 메모리 상태를 생성하는 함수)으로 재정의한다. MemOnce는 깊이·시간 두 차원에 걸쳐 압축을 수행해, 단일한 전역 캐시를 유지하면서 연속 추론 시 메모리를 온디맨드로 로드하고 디코딩한다. 두 설계(메모리 인코더-디코더, 메모리 희소 어텐션)를 결합함으로써 표현력, 선형 시간 복잡도, 일정한 활성 메모리 상태를 동시에 확보한다.

실험 설정 및 결과

150M~1B 파라미터 규모에서 트랜스포머, GDN, YOCO 등과 처음부터 함께 사전학습을 진행한 결과 MemOnce가 더 낮거나 비슷한 퍼플렉시티와 좋은 다운스트림 성능을 보였다. Qwen3.5-4B를 포스트트레이닝으로 적응시켜 4K~1M 토큰 범위의 5개 메모리 벤치마크에서 평가한 결과, MemOnce는 풀 컨텍스트 베이스라인을 능가한 최초의 네이티브 메모리 모델이 되었으며(4B 규모에서 +5.77%), M+보다 +18.68%, Metis보다 +32.27% 높은 성능을 기록했다. 1M 컨텍스트에서는 메모리 상태 캐시를 1313배, 프리필 지연시간을 6.9배 줄였고, 처리량은 3.5배 향상시켰다. 또한 추론 중 파라미터를 고정하고 무관한 디코딩 캐시를 자연스럽게 무시함으로써 치명적 망각을 방지했다. 마지막으로, 별도의 미세조정 없이도 학습된 메모리 표현이 검색·재순위화 등 다운스트림 표현 작업에서 특화 모델과 경쟁력 있는 성능을 보였다.

한계점

컴퓨팅 자원의 제약으로 처음부터 수행한 사전학습은 1B 파라미터 규모까지만 검증되었으며, 7B 이상의 더 큰 규모에서 파운데이션 스케일링 거동을 검증하는 것은 향후 과제로 남아있다. 또한 긴 호흡의 대화형 코딩이나 다단계 도구 사용과 같은 복잡한 다운스트림 에이전트 작업에서의 성능은 아직 충분히 검증되지 않았다.

시사점

MemOnce는 메모리 상태 학습을 하나의 통합 프레임워크로 재정의함으로써, 긴 컨텍스트·연속적 상호작용을 다루는 차세대 범용 LLM 아키텍처의 방향을 제시한다. 특히 네이티브 메모리 모델이 처음으로 풀 컨텍스트 성능을 넘어섰다는 결과는, 에이전트 및 장기 기억이 필요한 응용에서 메모리 효율성과 성능을 동시에 확보할 수 있는 길을 열어준다.
