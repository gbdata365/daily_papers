ScienceBuddy: Recursive-in-Recursive Self-Improvement for Interactive Scientific Agents

사이언스버디: 대화형 과학 에이전트를 위한 재귀 속 재귀 자기개선

연구자와의 실제 협업 대화를 학습 신호로 변환하여, 에이전트의 작업 절차(harness)와 모델 가중치를 번갈아 개선하는 "재귀 속 재귀(recursive-in-recursive)" 자기개선 프레임워크를 갖춘 대화형 과학 연구 워크스페이스 ScienceBuddy를 제안한다.

한 줄 요약

연구자와의 실제 협업 대화를 학습 신호로 변환하여, 에이전트의 작업 절차(harness)와 모델 가중치를 번갈아 개선하는 "재귀 속 재귀(recursive-in-recursive)" 자기개선 프레임워크를 갖춘 대화형 과학 연구 워크스페이스 ScienceBuddy를 제안한다.

배경 및 문제의식

언어모델 에이전트는 문헌 검색, 데이터베이스 조회, 계산 워크플로 실행 등 과학 연구를 보조할 수 있지만, 연구자가 대화 중 요청을 명확히 하거나 결과를 검증·수정하도록 요구해도 그 한 번의 대화 내 수정은 이후 작업으로 일반화되지 않는다는 한계가 있다. 즉 "연구자와의 협업 자체를 통해 에이전트가 작업 절차와 근본 역량을 지속적으로 개선하게 할 수 없는가"라는 문제를 다룬다. 기존 연구는 반사(reflection) 기반 harness 최적화, 상호작용 기반 정책 적응, 루브릭 기반 강화학습 등을 개별적으로 제시했지만, 협업 기록 자체가 과제 정의와 평가 기준을 동시에 제공하도록 연결한 사례는 드물었다.

핵심 기여

  • 연구 제품으로서의 과학 워크스페이스 공개: 224개 도구, 22개 기능 모듈(유전체학, 분자/암생물학, 약리학, 바이오이미징, 문헌 검색, 데이터베이스 질의 등)을 갖춘 대화형 워크스페이스 ScienceBuddy를 개발·공개.
  • 상호작용 기반 과제 및 감독 신호 구성: 연구자와의 대화(요청, 회신, 실행 로그, 산출물)로부터 실행 가능한 과제(Harbor task)와 과제별 평가 루브릭을 자동 구성하는 워크플로 제안.
  • 재귀 속 재귀 자기개선(Recursive-in-Recursive Self-Improvement, RinR): harness 개선(inner recursion)과 모델 강화학습(outer recursion)을 결합해 서로의 학습 조건을 계속 갱신하는 패러다임 제시.
  • 사례 연구를 통한 검증: 실제 연구자 상호작용, 모델 고정 상태의 harness 개선, harness 고정 상태의 모델 학습을 각각 분석하여 절차적 학습과 모델 학습의 개선 효과를 입증.

방법론

ScienceBuddy는 ReAct 스타일의 추론-행동-관찰 루프로 동작하며, 연구자 요청/데이터, 작업 이력, 관찰을 아우르는 대화 이력(history)을 바탕으로 harness가 모델의 맥락을 구성하고 모델(π_θ)이 행동을 생성한다. 연구자와의 협업 궤적(collaboration trajectory)으로부터 과제 지시문과 입력, 실행 환경, 그리고 평가 루브릭(요구되는 근거·산출물 기준)을 묶어 Harbor 형식의 과제로 패키징한다(과거 정답을 그대로 정답 레이블로 쓰지 않음).

RinR은 두 개의 중첩된 루프로 구성된다. - Inner recursion(harness 개선): 모델 파라미터 θ_k를 고정한 채, 별도의 고정 보조 모델(GPT-6 Astra)이 최근 궤적과 루브릭 평가를 검토하여 미충족 기준을 진단하고, 스킬 추가/제거/수정이나 지시문·맥락 설정 변경 등 범위가 제한된 harness 수정안을 제안한다. 부모(parent) harness와 후보(candidate) harness를 동일한 개발용 과제·시드·실행 예산으로 병행 평가(paired evaluation)하여, 제약을 만족하고 평균 정규화 루브릭 점수가 향상된 경우에만 후보를 채택한다(그렇지 않으면 부모 유지). 이 과정을 예산 한도까지 반복한다. - Outer recursion(모델 강화학습): 선택된 harness 하에서 현재 모델로 시범 실행해 과제 난이도를 보정하고, 입력 조건 변경 및 의존성 확장을 통해 환경을 증강한다. 과제별로 고정 루브릭 구성기가 중요도 가중치와 만족도 점수를 갖는 기준들을 산출하고, 이를 가중 평균한 루브릭 보상(R_x(τ))을 GRPO 알고리즘으로 최적화하여 θ_{k+1}을 얻는다. 이때 harness와 루브릭은 학습 중 고정된다. - 결합(coordination): 매 외부 사이클(outer cycle)마다 harness는 재평가된 뒤 갱신된 모델과 함께 배포되고, 이후 연구자와의 새로운 상호작용이 다음 사이클의 진단 근거를 제공한다. 모든 harness·환경 버전은 보존되어 이후 진화에 재사용될 수 있다(Algorithm 1).

실험 설정 및 결과

평가는 LAB-Bench와 Biomni-Eval1에서 가져온 문헌 독해, 데이터베이스 판단, 프로토콜 문제해결, 유전자/변이 평가의 4개 과제군을 사용한다.

  • 2사이클 RinR 동역학(4.2): Qwen3.5-4B와 초기 harness에서 시작해 3회의 사이클(각 사이클: harness 탐색 10회 + RL 업데이트 20회)을 수행. 검증 정확도는 harness 개선을 통해 38.9%→44.4%, 34.4%→46.7%, 61.1%→70.0%로 각 사이클마다 향상되었고, 학습 보상도 함께 상승했다. held-out 테스트에서 전체 단일 시도 정확도는 42.2%에서 73.3%로 상승했으며, 전체 문제의 33.3%가 오답→정답으로 전환(정답→오답 전환은 2.2%에 불과)되어 4개 과제군 전반에서 향상이 확인되었다.
  • 모델 고정, harness만 개선(4.3): 적응(adaptation) 세트에서 harness를 선택한 뒤 별도의 검증(validation) 세트로 평가한 결과, 초기 harness 대비 선택된 harness의 첫 응답 정확도가 31.1%→51.1%로 20%p 향상되었다(모델 가중치는 변경 없음). 선택된 harness는 4개의 지시문 항목과 9개의 범위가 제한된 스킬(파이썬 실행, 자원/스키마 점검, 유전자 세트 멤버십 확인, 사이토밴드 조회 등)을 갖추게 되었다.
  • harness 고정, 모델만 학습(4.4): 초기 harness를 고정한 채 약 2시간의 RL을 수행한 결과, 학습 정확도가 지속적으로 상승했고, 4회 시도 내 해결 가능한 문제 비율(pass@4로 측정한 problem coverage)은 48.3%에서 67.8%로 19.5%p 증가하여, 동일한 harness와 시도 예산 하에서도 모델 학습이 풀 수 있는 문제 범위를 넓힘을 보였다.

한계점

  • 보조 진단 모델(GPT-6 Astra)은 학습 과정에서 고정되어 있어, 과제 성능이 향상되어도 개선 메커니즘 자체(반사 모델)는 더 똑똑해지지 않는다는 점을 저자들이 스스로 지적한다.
  • Harness 개선 사례(4.3)에서는 개별 편집이나 피드백 소스에 어떤 기여를 했는지 정확히 귀속시키기 어렵다는 한계가 언급된다.
  • 논문에 제시된 사이클 수(3회)와 실험 규모(단일 소형 모델 Qwen3.5-4B 등)는 상대적으로 제한적이며, 장기간·대규모 반복 시의 안정성이나 포화 여부는 명시적으로 다뤄지지 않는다.
  • 현재 도구와 데이터는 생명의학(biomedicine) 분야에 특화되어 있어, 다른 과학 분야로의 일반화는 논문에 명시되지 않음.

시사점

ScienceBuddy는 연구자와의 일상적 협업 대화 자체를 지속적 학습 신호(과제 정의 + 평가 루브릭)로 전환함으로써, 별도의 전문가 주석 없이도 절차적 지식(harness)과 정책 가중치(모델)를 동시에, 그러나 서로 다른 루프에서 개선할 수 있음을 보여준다. Harness 개선과 모델 강화학습이 상호 되먹임 관계를 가지도록 설계함으로써(harness 변화가 학습 경험을 바꾸고, 모델 개선이 harness 적응의 새로운 여지를 만듦) 실제 서비스 운영과 병행하는 "백그라운드 자기개선" 파이프라인의 실현 가능성을 제시하며, 저자들은 이를 연구자와의 지속적 협업을 통해 진화하는 과학 AI, 즉 "discovery intelligence"로 나아가는 한 걸음으로 자리매김한다.
