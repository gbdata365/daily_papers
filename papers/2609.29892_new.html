한 줄 요약

AI가 스스로 데이터 생성·학습·배포 과정에 참여하는 "폐루프 AI-포-AI" 프레임워크를 실제 모바일 기기 조작이라는 어려운 과제에 적용해 만든 모바일 플래너 에이전트.

배경 및 문제의식

LLM의 발전은 단순 콘텐츠 생성을 넘어 엔지니어링과 과학적 발견 같은 능동적 워크플로로 확장되고 있다. 저자들은 "AI가 개발의 대상이면서 동시에 차세대 AI 시스템을 만드는 능동적 참여자가 될 수 있는가"라는 질문을 던진다. 모바일 플래닝은 복잡하고 장기적인 과업이 에이전트의 신뢰성을 시험하는 동시에, 실제 기기와의 상호작용 비용이 커서 개발 확장성이 제한된다는 점에서 이 질문을 검증하기에 적합한 영역이다.

핵심 기여

  1. 데이터 생산·모델 학습·배포를 하나의 행동-피드백-검증 계약으로 연결하는 폐루프 AI-포-AI 프레임워크 제안.
  2. "AI를 위한 데이터" 단계: 전문화된 에이전트들이 과업을 구성하고 상호작용 궤적을 수집하며, 학습 피드백으로 이후 데이터 생성을 조정하는 인간 검수 기반 에이전트 데이터 플라이휠 구축.
  3. "AI를 위한 학습" 단계: 지도학습 콜드스타트와 혼합 환경 온라인 강화학습을 결합하고, 추론·도구 사용 비용을 줄이면서 과업 성능은 유지하는 CARE(Competence-Aware Reward-and-Advantage Engineering) 기법 제안.
  4. 실행 근거 기반 루프를 통해 메모리·스킬·도구를 런타임에 조율하고, 구조화된 행동 피드백과 실패 흔적을 모델·하네스 공동 진화에 되먹임하는 메커니즘 구현.

방법론

프레임워크는 세 축으로 구성된다. AI-포-데이터는 특화된 에이전트가 과업 생성, 궤적 수집, 데이터 정제·균형을 수행하며 학습 결과 피드백을 다시 데이터 생성에 반영한다. AI-포-학습은 지도학습 기반 계획 콜드스타트 이후 혼합 환경(실제 기기+시뮬레이션 등) 온라인 에이전트 강화학습을 적용하며, CARE 기법으로 보상 강조점을 과업 성공도에 따라 동적으로 조정하고 어드밴티지를 보정해 사소한 효율성 차이가 학습을 지배하지 않도록 한다. 세 번째 축은 모델과 에이전트 하네스(메모리·스킬·도구 오케스트레이션)가 실행 피드백을 매개로 번갈아 개선되는 공진화 루프이다.

실험 설정 및 결과

Qwen-Planner-Agent는 자체 구축한 MobilePA-Bench에서 평가된 모든 모델·시스템 중 최고 종합 성능을 달성했으며, 기반 모델 대비 도구 사용, 메모리, 스킬, 하위 에이전트 조율 전 영역에서 향상을 보였다. 모바일 이외의 일반 에이전트 벤치마크에서도 성능 향상을 보이면서 범용 능력은 대체로 유지되었다.

한계점

시사점

AI 시스템이 자기 자신의 학습 데이터 생성과 하네스 설계에 능동적으로 참여하는 폐루프 구조가, 값비싼 실기기 상호작용이 필요한 실세계 에이전트 개발의 확장성 문제를 완화할 수 있는 실용적 방법론이 될 수 있음을 보여준다.
