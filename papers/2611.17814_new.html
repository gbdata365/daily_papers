G-CAST: Governed Continual Self-Training for E-Commerce Agents under Evolving Demands

G-CAST: 변화하는 수요 하의 이커머스 에이전트를 위한 통제형 지속 자기학습

사용자 수요와 에이전트 실행 하네스(도구·스킬·절차)가 끊임없이 변하는 실제 이커머스 환경에서, 체크포인트 전환 자체를 적응의 단위로 삼아 모델·학습 데이터·보상 함수를 함께 통제된 방식으로 진화시키는 지속학습 시스템 G-CAST를 제안.

한 줄 요약

사용자 수요와 에이전트 실행 하네스(도구·스킬·절차)가 끊임없이 변하는 실제 이커머스 환경에서, 체크포인트 전환 자체를 적응의 단위로 삼아 모델·학습 데이터·보상 함수를 함께 통제된 방식으로 진화시키는 지속학습 시스템 G-CAST를 제안.

배경 및 문제의식

배포된 LLM 기반 쇼핑 에이전트는 새로운 상품 카테고리, 조달 시나리오, 기능 요청이 등장하면서 사용자 수요가 지속적으로 변화("수요 드리프트")하고, 동시에 에이전트의 도구·스킬·운영 절차("하네스")도 계속 확장된다. 이 때 과거 하네스(계약, capability contract)에 맞춰 최적화된 모델은 (1) 새 기능을 언제·어떻게 올바르게 호출해야 하는지 모르는 "모델 불일치", (2) 과거 경로 데이터가 새 기능에 대한 증거를 충분히 담지 못하는 "데이터 불일치", (3) 과거 보상 함수가 확장된 계약 하의 행동을 제대로 평가하지 못하는 "보상 불일치"라는 세 가지가 서로 맞물린 문제에 직면한다. 주기적인 수동 재학습은 너무 늦고 노동 집약적이어서 이 문제를 해결하지 못한다.

핵심 기여

  • 모델, 현재 캐퍼빌리티 계약, 실행 가능한 보상, 학습 증거, 누적 평가 장부(ledger)를 함께 버전 관리하면서, 체크포인트 전환을 학습 작업의 완료가 아닌 적응의 단위로 다루는 거버넌스 체계 G-CAST 설계.
  • 보상-라우팅·엔트로피 우선순위 데이터 오케스트레이션: 매 라운드마다 수락된 체크포인트로 질의당 여러 롤아웃을 생성하고, 보상에 따라 학습 데이터를 라우팅하며 풀 내에서 엔트로피 기반으로 우선순위를 매김.
  • 캐퍼빌리티 계약 기반 보상 진화: 하네스가 확장될 때 보상 함수를 통제된 방식으로 갱신해 새 도구·절차에 대한 올바른 평가가 가능하게 함.
  • 누적 평가에 기반한 거버넌스된 체크포인트 전환으로, 새로 등장한 요구에 적응하면서도 이전에 수락된 행동을 보존.
  • 알리바바 1688의 B2B 조달 에이전트 "Yuancai"에 실제 배포되어 운영 효율을 크게 개선(보상 감사 인력 약 2인일 → 30분, 수요-수락 턴어라운드 약 1주 → 2일).

방법론

배포된 체크포인트는 롤아웃 풀의 각 질의에 대해 해당 시점의 하네스 버전으로 8개의 궤적을 생성한다(맥락당 라우팅 전 16,000개 궤적). 새 맥락(demand period)이 도입되면 수락된 체크포인트를 그 기간의 100개 질의 평가 슬라이스에서 먼저 평가하고, 이후의 모든 후보는 모든 활성 슬라이스를 누적한 평가 스위트(기간이 늘수록 100→400개 질의로 증가)에서 평가된다. 이는 새로 등장한 수요를 다루면서도 이전에 수락된 역량을 희생하지 않아야 한다는 실제 배포 요구사항과 일치한다. 평가 질의는 모든 학습·리플레이·합성·보상 개발 과정에서 제외되어 평가 유출을 방지한다.

실험 설정 및 결과

사전학습 모델로 Qwen3-4B-Thinking-2507을 사용하고, 실제 운영 중인 이커머스 에이전트에서 샘플링한 4개의 서로 다른 시간대(수요 기간)에서 평가했다. 먼저 체크포인트를 갱신하지 않고 방치했을 때 누적 보상이 Period 1~4 평가에서 0.9065→0.6354로 크게 떨어지고, 새로 등장한 Period 4에서의 보상은 0.1877까지 추락함을 보여 지속적 자기학습이 필수적임을 입증했다. G-CAST를 강력한 자율 사후학습 베이스라인(AutoTrainess)과 비교한 결과, G-CAST는 훨씬 적은 학습 데이터(예: Iter.4에서 122/859행 대 AutoTrainess의 –/247행 이상)로도 새로운 수요에 대한 적응력(New period reward)과 기존 역량의 보존력(Retained reward)에서 모두 더 우수했다. 예를 들어 Iter.4에서 G-CAST는 보존 보상 +0.012, 신규 보상 +0.183 향상을 보였다. 어블레이션 결과 보상-라우팅·엔트로피 우선순위 데이터 오케스트레이션과 거버넌스된 보상 진화 둘 다 성능 향상에 중요하게 기여함을 확인했다.

한계점

이 연구는 하나의 종단적(longitudinal) 실제 운영 애플리케이션과 하나의 주요 모델 계열(Qwen3-4B-Thinking)에 기반하고 있어, 관찰된 수요·캐퍼빌리티 진화 패턴이 다른 에이전트 환경에 그대로 전이될지는 확인되지 않았다.

시사점

배포된 에이전트의 지속적 적응은 고정된 목표 하에서의 반복 학습이 아니라, 모델·데이터·보상이 함께 맞물려 변화해야 하는 결합된 문제로 다뤄야 한다는 것을 실증했다. G-CAST는 실제 운영 환경에서 거버넌스 자체(후보 체크포인트 3개와 제안된 보상 버전 2개를 검증 실패로 거부)가 개별 학습 실행의 성능 향상과는 별개로 실질적인 가치를 지닌다는 것을 보여준다.
