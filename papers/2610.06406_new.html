What Did the Agent Actually Do? Evidence-Grounded Oversight for Long-Horizon Agents

에이전트는 실제로 무엇을 했는가? 장기 수행 에이전트를 위한 증거 기반 감독

장기 수행(long-horizon) 에이전트의 방대한 활동 중 사용자 검증이 필요한 "중요한 결정"을 식별하고 그 근거를 찾아주는 감독 벤치마크 AgentMonBench와, 이를 지원하는 학습 불필요 방법 증거-근거 행동 그래프(Evidence-Grounded Behavior Graph, EBG)를 제안한다.

한 줄 요약

장기 수행(long-horizon) 에이전트의 방대한 활동 중 사용자 검증이 필요한 "중요한 결정"을 식별하고 그 근거를 찾아주는 감독 벤치마크 AgentMonBench와, 이를 지원하는 학습 불필요 방법 증거-근거 행동 그래프(Evidence-Grounded Behavior Graph, EBG)를 제안한다.

배경 및 문제의식

코딩 능력의 발전으로 에이전트가 저장소 수정, 연구 복제, 데이터 분석 같은 장기 수행 과업을 맡게 되면서, 사용자의 역할은 개별 결정을 직접 내리는 것에서 에이전트의 실행을 감독하는 것으로 옮겨가고 있다. 그러나 위임해도 책임은 사라지지 않으며, 사용자는 여전히 에이전트의 선택이 자신의 목표에 부합하는지 판단해야 한다. 문제는 에이전트 활동의 양과 복잡성이 사용자가 따라가고 평가할 수 있는 역량을 넘어선다는 점이다. 예를 들어 평가 기준을 바꾸면 연구 결론이 달라지고, 불완전한 레코드를 제외하면 분석 대상 모집단이 바뀔 수 있는데, 이런 선택들은 합리적일 수 있지만 여전히 사용자의 판단이 필요하며 그 근거는 메시지·도구 결과·중간 산출물 전역에 흩어져 있어 식별이 어렵다.

핵심 기여

  • 소프트웨어 엔지니어링 영역에서 감독의 두 가지 상호보완적 차원(요구사항-행동 간 정합성, 중요한 자율적 결정에 대한 인지)을 다루는 3개 서브셋으로 구성된 벤치마크 AgentMonBench 제안: SpecGAP(불완전한 요구사항에서 명시되지 않은 중요한 저장소 행동 평가), SilentSwap(기존 테스트가 통과하더라도 문서화된 요구사항과의 의미적 이탈 평가), FeedbackTrace(실제 상호작용에서 사용자 검증이 필요한 자율적 선택을 모니터가 드러낼 수 있는지 평가, 실제 사용자 피드백에서 도출된 정답 레이블 사용).
  • 출처가 연결된 증거를 행동(behavior)으로 그룹화하고 그 관계를 그래프로 조직하는 학습 불필요 방법 EBG 제안, 과업 지향적 관점에서 모니터가 맥락 속에서 행동을 해석하도록 지원.
  • 8개 모델에 대한 실험에서 EBG가 원본 컨텍스트에 직접 접근하는 것보다 대부분의 설정에서 결정 식별과 증거 위치 파악을 향상시킴을 입증.
  • EBG의 증거 위치 파악 성능 향상이 입력 규모와 하이퍼파라미터 설정 전반에서 지속됨을 확인하고, 실제 연구 과업에 적용한 사례로 실용적 가치를 시연.

방법론

EBG는 결정론적인 구성과 제시 과정을 가지며, 의미 판단은 모니터(감독 모델)가 수행하도록 설계되었다. 코드 작업공간이나 실행 궤적에서 출처가 연결된 증거를 수집하여 행동·범위(scope)·명시적 관계로 조직하고, 이를 과업 지향적인 "증거 뷰(evidence view)"로 제시함으로써 모니터가 관찰된 행동을 맥락 속에서 평가할 수 있게 한다. 실제 적용 사례로, EBG는 후크(hook)·스킬(skill)·도구로 구성된 리뷰 하네스를 통해 Codex에 통합되었다: 후크가 리뷰를 트리거하고, 스킬이 리뷰 기준을 정의해 중요한 결정으로 Codex의 주의를 유도하며, 도구가 EBG를 이용해 증거를 검색하고 발견 사항을 기록한다. 이 워크플로우는 세 가지 리뷰 유형을 포함한다: (I) 모호성 리뷰 - 계획이나 사용자 프롬프트에 명시되지 않은 채 실행에 큰 영향을 미칠 수 있는 선택을 점검, (II) 조정 리뷰 - 계획된 접근 방식의 변경이 추가 검증·공개·사용자 승인을 필요로 하는지 점검, (III) 결과 리뷰 - 제시된 결론을 가용한 증거가 실제로 지지하는지 점검.

실험 설정 및 결과

  • 8개 모델 대상 전반적 평가: EBG가 AgentMonBench의 세 구성 요소 전반에서 원본 컨텍스트를 직접 활용하는 베이스라인보다 결정 식별과 증거 위치 파악 성능을 대부분의 설정에서 향상.
  • 입력 규모별 분석: 입력 토큰 수가 늘어날수록(Low→Medium→High) 베이스라인 성능은 일관되게 하락했으나(예: FeedbackTrace EHR 0.667→0.422, SilentSwap LS 0.557→0.429), EBG는 모든 입력 규모에서 베이스라인을 능가했으며, High 그룹에서도 SpecGAP LF1 +0.078, SilentSwap LS +0.115, FeedbackTrace EHR +0.108의 절대 성능 향상을 유지.
  • Codex 하네스 적용: 실제 연구 자동화 사례에서 각색한 5개 연구 과업에 하네스를 적용한 결과, EBG 없이는 Codex가 사용자 검증이 필요한 핵심 이슈를 드러내지 않았지만, EBG를 통합하면 해당 이슈들을 식별하고 공개함.

한계점

논문은 별도의 "한계점" 절을 명시하지 않았다. 다만 평가가 소프트웨어 엔지니어링 영역과 특정 벤치마크 구성(3개 서브셋)에 집중되어 있으며, 실제 사례 연구는 5개 연구 과업으로 제한된 소규모 시연이라는 점이 본문에서 드러나는 범위상의 제약으로 보인다.

시사점

에이전트에게 과업을 위임하는 것이 보편화되면서, "에이전트가 실제로 무엇을 했는가"를 사람이 효율적으로 검증할 수 있게 하는 감독 도구의 필요성이 커지고 있다. EBG처럼 추가 학습 없이 기존 에이전트 실행 궤적에서 증거를 구조화하는 접근은, 모델 자체를 재학습하지 않고도 다양한 에이전트 하네스(Codex 등)에 플러그인 형태로 통합해 인간 감독의 실효성을 높일 수 있는 실용적인 경로를 제시한다.
