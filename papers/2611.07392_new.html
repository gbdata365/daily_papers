WeLM-Image: A Unified Image Generation Model towards Visual Intelligence

웰엠이미지: 시각 지능을 향한 통합 이미지 생성 모델

한 줄 요약

WeChat(위챗) 서비스에 단일 GPU로 배포 가능하도록 설계된, 텍스트-이미지 생성·지시 기반 이미지 편집·다중 참조 합성을 하나의 백본으로 통합한 이미지 파운데이션 모델이다.

배경 및 문제의식

확산(diffusion) 및 플로우 기반 트랜스포머의 발전으로 이미지 생성 품질은 크게 향상되었지만, 실제 서비스에서는 긴 중국어·영어 혼용 프롬프트 이해, 정확한 텍스트 렌더링, 피사체 정체성을 보존한 편집, 여러 참조 이미지의 속성을 혼동 없이 결합하는 등 세밀한 제어 능력이 추가로 요구된다. 또한 WeChat처럼 대규모 소비자向 서비스에서는 단일 GPU 배포와 낮은 요청당 비용이라는 자원 효율성 제약이 모델 설계 단계부터 반드시 고려되어야 한다.

핵심 기여

  • 이해(understanding)와 생성(generation) 경로를 분리하되 어텐션은 공유하는 Mixture-of-Transformers(MoT) 구조에, 각 경로마다 독립적인 Mixture-of-Experts(MoE)를 결합한 'MoT-MoE' 백본을 제안(총 저장 파라미터 31.7B, 타깃 잠재 토큰당 생성 측 활성 파라미터 약 5.4B).
  • 텍스트와 비전 토큰이 하나의 어텐션 컨텍스트를 공유하면서도 사전학습된 1D RoPE와 완전히 호환되는 '텍스트 호환 통합 3D RoPE'를 설계.
  • 약 0.6B장의 정제된 이미지로 구성된, 지식 기반 시각 어휘와 대규모 시각 클러스터링을 결합한 생성 지향 데이터 엔진을 구축.
  • 생성·편집을 각각 루브릭/체크리스트 기반 보상으로 강화학습한 뒤, 노이즈 인지 온폴리시 증류(on-policy distillation)로 하나의 모델에 통합.
  • MeanFlow 기반 소수 스텝 증류로 8/4-스텝 가이던스 프리 추론이 가능한 경량 버전 WeLM-Image-Turbo를 제공.

방법론

WeLM-Image는 텍스트·참조 이미지·타깃 잠재(latent)를 하나의 인터리브(interleaved) 시퀀스로 직렬화해 처리한다. 이해 경로(UND)는 텍스트와 ViT 임베딩을, 생성 경로(GEN)는 VAE 임베딩을 담당하며, 두 경로는 각자의 projection과 전문가(expert)를 갖되 마스킹된 자기 어텐션을 통해 상호작용한다. 27개 디코더 레이어 중 1번째 층은 경로별 dense FFN을, 나머지 26개 층은 경로별로 64개의 라우팅 전문가(+2개의 공유 전문가)를 두는 MoE FFN을 사용한다(UND는 top-6, GEN은 top-20 라우팅). 공간 구조 보존을 위해 VAE 잠재 토큰에는 중심 기준 (Δh, Δw) 오프셋을 부여하는 3D RoPE를 적용하며, 재구성·의미 정렬·텍스트 중심 디코더 미세조정의 3단계로 학습된 전용 VAE(WeLM-Image-VAE)를 사용한다. 학습은 사전학습 및 SFT 이후, 텍스트-이미지 생성과 이미지 편집을 별도의 강화학습 가지로 최적화(각각 정합성·미학·텍스트 렌더링·자연스러움 보상, 체크리스트 기반 편집 보상)한 뒤, 노이즈 수준에 따라 다른 교사(teacher) 신호를 사용하는 온폴리시 증류로 두 전문가를 하나의 모델로 통합한다. 마지막으로 MeanFlow 기반 증류를 통해 가이던스 없이 8~4 스텝으로 추론 가능한 Turbo 버전을 생성한다.

실험 설정 및 결과

GenEval, PRISM-Bench, OneIG-Bench, Qwen-Image-Bench, WeGenBench, UnicBench, WeGenEditBench 등 다수의 생성·편집 벤치마크에서 평가했다. 1536 해상도 모델은 PRISM-Bench, Qwen-Image-Bench, UnicBench에서 평가된 오픈소스 모델 중 1위를 기록했으며, GenEval 단일 객체 생성에서는 WeLM-Image-Turbo-8step이 만점(1.0000, 공동 1위)을 달성했다. 단일 이미지 편집 벤치마크(WeGenEditBench-single)에서도 Edit Goal·Overall 지표에서 최고 점수를 기록했다. 효율성 측면에서는 NVIDIA H20 GPU 기준 50스텝 모델이 동일 스텝 수의 Qwen-Image-2512 대비 8~15% 빠르고, 입력 이미지가 늘어날수록 편집 지연 시간 격차가 더 커진다(4개 참조 이미지 기준 약 5.1배 빠름). 8스텝 Turbo 모델은 1024×1024 이미지를 4.98초에 생성하며, 50스텝 기본 모델 대비 11.4배의 속도 향상을 보인다.

한계점

논문에 별도의 '한계점' 섹션은 없다. 다만 결론부에서 저자들은 향후 연구 방향으로 더 강력한 시각적 추론 능력, 복잡한 지시에 대한 신뢰성 있는 제어, 추가적인 효율성 개선이 필요하다고 언급하여, 현재 모델이 이 부분에서 개선 여지가 있음을 시사한다.

시사점

이해와 생성을 분리하면서도 어텐션을 공유하는 MoT-MoE 구조와, 서비스 제약(단일 GPU 배포)을 설계 초기 단계부터 반영한 접근 방식은 실제 대규모 소비자 서비스에 통합 생성 모델을 적용하려는 다른 연구와 제품 개발에 참고할 만한 사례를 제공한다. 특히 루브릭/체크리스트 기반 보상 설계와 노이즈 인지 온폴리시 증류는 여러 전문화된 강화학습 정책을 단일 배포 모델로 합치는 실용적 방법론으로서 의의가 있다.
