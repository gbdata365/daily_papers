VideoJev: System One Model for Video Understanding and Interaction

비디오젭: 영상 이해와 상호작용을 위한 System One 모델

한 줄 요약

MLLM의 토큰 단위 자기회귀 답변 생성을 공유된 "후보 채점(scoring)" 헤드로 대체하여, 시간 구간 탐지(temporal grounding)와 객관식 비디오 질의응답(Video QA)을 하나의 구조로 통합하고, 영상 전처리 결과를 여러 질의에 재사용하는 추론 방식으로 속도를 크게 높인 비디오 전용 "System One" 모델 VideoJev를 제안한 논문.

배경 및 문제의식

시각 에이전트는 영상을 관찰하면서 다음 행동을 정하기 위해 반복적으로 빠른 판단을 내려야 한다. 그런데 기존 판별형(discriminative) 비전 모델은 효율적이지만 고정된 작업·라벨 체계에 묶여 있고, 비디오 MLLM은 언어적으로 유연하지만 타임스탬프나 답변 문장을 토큰 하나씩 생성하는 자기회귀 방식이라 느리고, 같은 영상에 대해 질의가 이어질 때마다 중복 계산이 발생한다. 저자들은 "System One" 패러다임(사전에 정의된 후보에 대해 확률적 판단만 빠르게 내리는 방식)을 비디오 영역으로 확장해, 자기회귀 생성 없이도 MLLM의 의미적 유연성을 유지한 채 효율적인 직접 판단을 내리는 것을 목표로 삼았다.

핵심 기여

  • 시간적 그라운딩과 객관식 비디오 QA를 "직접 후보 채점(direct candidate scoring)"이라는 하나의 틀로 통합하는 VideoJev 모델군 제시
  • 학습·추론 전반에서 영상 인코딩 결과를 재사용하는 두 가지 추론 모드 제안: 질의가 순차적으로 들어올 때 쓰는 Cached inference와, 여러 질의를 한 번의 forward pass로 동시에 처리하는 Joint inference
  • 4B 밀집 모델과 35B(A3B 활성 파라미터) MoE 모델을 7개 벤치마크에서 평가하고, 동일 데이터로 학습한 자기회귀 파인튜닝 대비 통제 비교 실험을 수행

방법론

사전학습된 MLLM(Qwen3.5-4B, Qwen3.6-35B-A3B 백본)의 마지막 MLP와 언어모델 출력 헤드를 제거하고, 그 자리에 공유 "채점기(scorer)"를 부착한다. 두 개의 새 토큰 <|option_end|>(후보 판독용)와 <|decide|>(질의 단위 판단 판독용)을 도입하며, 은닉 상태를 512차원으로 투영·정규화한 뒤 코사인 유사도 기반 점수(s_i = 10·uᵀv_i + b)로 각 후보의 적합도를 계산한다. 입력은 영상 토큰 → 과제 지시문 → 질의 → 후보 목록 순으로 배치되어, 시간적 그라운딩과 객관식 QA가 동일한 포맷을 공유한다.

시간적 그라운딩에서는 영상을 프레임 쌍 단위의 후보 구간 K개로 나누고, 각 구간이 정답 이벤트에 속하는지를 다중 라벨 이진 교차엔트로피(BCE)로, 이벤트 전체를 얼마나 잘 덮는지를 소프트 IoU 손실로 함께 학습한다. 추론 시에는 Kadane 알고리즘 방식으로 임계값(τ=0.25)을 적용해 점수 합이 최대인 연속 구간을 찾아 하나의 시간 구간으로 디코딩한다. 비디오 QA에서는 보기 후보들의 점수에 소프트맥스를 적용해 교차엔트로피로 학습하고, 위치 편향을 줄이기 위해 보기 순서를 재현 가능하게 섞는 기법을 사용한다. 학습은 고정된 특징으로 채점 헤드만 먼저 정렬하는 1단계와, 언어 백본·채점기를 함께 적응시키는 2단계로 구성된 2단계 방식이며, 영상 인코더와 머저는 전 과정에서 고정한다. 학습 데이터는 TimeLens-100K/93K(그라운딩)와 약 19K개 영상에서 추출한 약 24만 개 객관식 QA 쌍을 사용했다.

실험 설정 및 결과

그라운딩은 Charades-STA, ActivityNet Captions, QVHighlights(TimeLens-Bench 정제 주석)에서, QA는 LVBench, Video-MME, LongVideoBench, MLVU에서 평가했다. VideoJev-4B는 Qwen3.5-4B(Instruct) 대비 평균 그라운딩 mIoU를 6.7점, VideoJev-35B-A3B는 Qwen3.6-35B-A3B 대비 10.8점 끌어올렸으며, 측정된 추론 속도는 백본 대비 2.8~3.1배 빨랐다. QA에서도 각각 평균 점수를 8.0점, 5.7점 향상시켰고, Thinking(추론 모드) 백본과 비슷한 성능을 유지하면서 100배 이상의 속도 향상을 보였다. 동일 학습 데이터로 미세조정한 일반 자기회귀 모델과 비교했을 때도 VideoJev가 그라운딩 mIoU 1.3점, QA 점수 1.9점 더 높아, 아키텍처 자체의 이점을 확인했다. 소거 실험에서는 소프트 IoU 손실 추가 시 그라운딩 mIoU가 4.6점 상승했고, 그라운딩과 QA를 함께 학습하는 것이 각각 따로 학습하는 것보다 두 과제 모두에서 더 나은 성능을 보였으며, Joint inference가 질의 수가 늘어나도 지연시간 증가를 최소화(그라운딩 55ms, QA 31ms 추가)하면서 오히려 정확도가 소폭 향상되는 결과도 관찰되었다.

한계점

예측 확신도(confidence)가 실제 정확도보다 과도하게 높게 나타나는 보정(calibration) 문제가 있으며(기대 보정 오차 약 8~12퍼센트포인트), 별도의 보정 학습은 적용되지 않았다. 또한 현재 모델은 사전에 정의된 후보 집합에 대한 폐쇄형(closed-set) 판단만 가능해 완전히 열린 형태의 과제에는 직접 적용하기 어렵고, 스트리밍 입력(실시간 순차 인코딩)은 아직 지원하지 않는다. 평가 대상도 시간적 그라운딩과 객관식 QA 두 과제에 한정되어 있다.

시사점

자기회귀 생성을 거치지 않고 후보를 직접 채점하는 방식은, 반복적으로 같은 영상에 질의가 들어오는 상호작용형 비디오 에이전트에서 계산을 재사용할 수 있는 실용적인 설계로 보인다. 저자들은 향후 행동 인식, 이벤트 탐지, 장면 상태 분류 등 더 다양한 판단 과제로 후보 인터페이스를 확장하고, 상위 레벨의 에이전트(System Two)가 목표를 후보 판단으로 분해하면 VideoJev 같은 System One 모델이 이를 시각적 근거로 평가하는 계층적 구조로 발전시킬 수 있다고 제안한다. 다만 신뢰도 보정과 스트리밍 처리 능력의 보완이 실제 배포를 위한 다음 과제로 남아 있다.
