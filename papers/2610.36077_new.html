The Trinity: Capability-Driven Recursive Self-Improvement for Multimodal Agents

The Trinity: 멀티모달 에이전트를 위한 능력 기반 재귀적 자기개선

서로 다른 과업이라도 동일한 "능력(capability)" 요구를 공유한다는 관찰에 기반해, 과업 트리를 능력 트리로 재구성하고 Creator·Explorer·Evolver 세 역할이 세계 생성과 에이전트 하니스(Harness) 진화를 함께 수행하는 재귀적 자기개선 프레임워크 The Trinity를 제안, 28개 학습 벤치마크에서 평균 34점, 18개 미학습 벤치마크에서 평균 26점의 성능 향상을 달성했다.

한 줄 요약

서로 다른 과업이라도 동일한 "능력(capability)" 요구를 공유한다는 관찰에 기반해, 과업 트리를 능력 트리로 재구성하고 Creator·Explorer·Evolver 세 역할이 세계 생성과 에이전트 하니스(Harness) 진화를 함께 수행하는 재귀적 자기개선 프레임워크 The Trinity를 제안, 28개 학습 벤치마크에서 평균 34점, 18개 미학습 벤치마크에서 평균 26점의 성능 향상을 달성했다.

배경 및 문제의식

멀티모달 에이전트의 능력은 모델 자체보다도 지각·메모리·추론·계획 등을 조율하는 "하니스(Harness)" 구성에 크게 좌우되는데, 과업과 환경이 급격히 다양해지면서 수작업으로 하니스를 반복 개선하는 방식은 한계에 부딪힌다. 또한 이질적이고 검증 가능한 학습 환경을 대규모로 구축하는 것도 비용이 크다. 기존 재귀적 자기개선(RSI) 연구는 주로 텍스트 기반 과업(코딩, 수학)에 과업별로 특화된 하니스를 진화시켜, 과업 간 공유되는 요구사항을 무시한 채 과적합되거나, 반대로 하나의 전역 하니스로는 서로 충돌하는 과업 요구(예: 성능-효율 트레이드오프)를 만족시키지 못하는 문제가 있었다. 저자들은 ARC-AGI-3와 Micromouse처럼 표면적으로 다른 과업도 "지각 및 상태 추적"이라는 공통 능력을 요구한다는 점에 주목해, 능력 중심의 자기개선으로 전환할 것을 제안한다.

핵심 기여

The Trinity는 세 역할로 구성된다. Evolver는 검증된 실행 궤적을 바탕으로 과업들의 능력 요구를 식별하고, 원래의 과업 트리를 능력 기반의 계층적 트리로 재구성한다. Creator는 Capability-Driven Real2Sim2Real을 통해 같은 노드에 속한 이질적 과업들의 공통 요구를 단순화되고 검증 가능한 시뮬레이션 세계로 추상화하며, 원본 과업에 대한 평가로 전이(transfer)를 측정한다. Explorer는 능력 트리를 따라 선택적 상속(selective inheritance)과 지역적 개선을 반복하며 재사용 가능한 모듈로 구성된 하니스 트리를 축적해 나간다. 이렇게 특화된 여러 하니스를 과업에 맞게 고르기 위한 Capability-Aware Harness Router도 함께 제안된다.

방법론

하니스는 지각(Perception)·메모리(Memory)·추론(Inference)·계획(Planning)·오케스트레이션(Orchestration)·루프(Loop) 6개 제어 흐름 프로토콜로 구성되며, 모델 파라미터는 고정한 채 모듈 구성만 진화시킨다. 능력 트리는 학습 과업의 요구 집합을 정렬해 만든 트라이(Trie) 구조이며, 각 노드에서 Creator가 해당 노드의 공통 요구를 반영한 축소된 시뮬레이션 월드를 만들고 검증 풀로 난이도와 정합성을 확인한다. Explorer는 매 반복(iteration)마다 부모 노드의 갱신된 모듈과 자신의 로컬 모듈을 비교해, 검증 성능이 더 높을 때만 상속을 갱신하는 선택적 상속 규칙을 적용하며, Creator는 반복 종료 시 여러 노드에서 검증된 업데이트를 중복 제거·병합하여 새로운 Base Harness로 통합한다. 라우팅은 과거 실행 기록을 메모리에 저장해 두고 코사인 유사도 기반 검색으로 유사 사례를 참고해 적절한 하니스를 선택하는 컨텍스트-행동-피드백 루프로 구현된다.

실험 설정 및 결과

동일한 Base Harness(Prime Agent)와 고정된 Claude Opus 5 백본을 사용해 28개 학습 벤치마크와 18개 미학습 벤치마크(규칙 발견, 제약 문제 해결, 지각·제어, 멀티 에이전트, 장기 호라이즌 등 5개 영역)로 평가했다. 모듈 진화와 스킬(평가 시점에 준비되는 요약)을 모두 적용한 설정이 둘 중 하나만 적용한 경우보다 학습/미학습 성능(63.80/53.53)에서 가장 우수했다. 과업 기반 조직화 대비 능력 트리 기반 조직화가 더 높은 성능과 더 낮은 추론 비용을 보였으며, 특히 실제 과업 대신 Creator가 만든 시뮬레이션 세계로 학습한 Capability Tree(Sim) 설정이 가장 높은 모듈 전용 성능(56.95/47.26)과 가장 낮은 추론 비용을 기록했다. 또한 두 가지 실제 로봇 환경으로의 임베디드 전이 실험도 포함되어, 시뮬레이션에서 진화한 능력이 물리 환경으로도 이전됨을 보였다.

한계점

저자들은 두 가지 한계를 스스로 명시한다. 벤치마크 탐색에 웹 검색을 사용하기 때문에 검색 결과의 커버리지와 품질이 질의에 따라 달라질 수 있다는 점, 그리고 현재 연구는 주로 하니스 수준의 자기개선에 집중되어 있어 모델 파라미터 자체의 학습까지는 다루지 않는다는 점이다.

시사점

과업의 표면적 형태가 아니라 공유된 능력 요구를 조직 원리로 삼는 "능력 중심(capability-driven)" 자기개선이 과업 중심 접근보다 일반화와 효율성 모두에서 우월할 수 있음을 보여준다. 저자들은 향후 능력 트리를 동적으로 확장하고, 이 패러다임을 모델 파라미터 학습까지 확장해 능력 인식 라우팅과 RSI가 닫힌 루프를 이루는 방향을 전망한다.
