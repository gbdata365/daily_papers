TRIO: Task Refinement with Individual Optimization for Retrieval-Augmented Generation

TRIO: 검색-증강 생성을 위한 개별 최적화 기반 과제 정제

검색-증강 생성(RAG)의 질의 확장, 정보 충분성 판단, 답변 생성이라는 세 하위 작업을 각각 별도로 최적화된 전문 에이전트(query extension, judge, answer)에게 맡겨 서로 긴밀히 협력시킴으로써 검색 효율과 답변 정확도를 동시에 높인 다중 에이전트 RAG 프레임워크 TRIO를 제안한다.

한 줄 요약

검색-증강 생성(RAG)의 질의 확장, 정보 충분성 판단, 답변 생성이라는 세 하위 작업을 각각 별도로 최적화된 전문 에이전트(query extension, judge, answer)에게 맡겨 서로 긴밀히 협력시킴으로써 검색 효율과 답변 정확도를 동시에 높인 다중 에이전트 RAG 프레임워크 TRIO를 제안한다.

배경 및 문제의식

기존 RAG 시스템은 (1) 검색 단계에서 부정확하거나 모호한 질의로 인해 불필요하거나 편향된 문서를 가져오는 문제(Insufficient Context)와, (2) 생성 단계에서 관련 문서가 검색되었더라도 이를 제대로 활용하지 못해 환각(hallucination)이 발생하는 문제(Knowledge Underutilization)를 동시에 겪는다. 최근 다중 에이전트 RAG 연구들이 등장했지만, 여전히 모든 역할에 동일한 백본 모델을 공유하여 역할별 특화가 부족하고 성능 향상에 한계가 있었다.

핵심 기여

  1. 기존 RAG가 겪는 비효율적 지식 획득과 환각 문제를 질의 확장(query extension), 판단(judge), 답변 생성(answer)이라는 세 가지 특화 에이전트로 분해하여 해결.
  2. 제한된 지도학습 데이터를 세 하위 작업 전반에 걸쳐 정렬·확장하는 새로운 데이터 생성 방법과, 각 에이전트에 맞춘 적응형 미세조정(fine-tuning) 기법 제안.
  3. 최신 벤치마크 전반에서 TRIO가 다수의 경쟁 기법 대비 우수한 성능을 보이며, 다양한 RAG 시나리오로 쉽게 확장 가능함을 실험으로 검증.

방법론

TRIO는 검색기(retriever) ℛ와 말뭉치 C를 두고, (1) 질의 확장 에이전트가 기존 질의 풀과 검색된 문서를 보고 부족한 정보를 채울 새로운 키워드 질의(최대 8개 단어)를 1개씩 생성하고, (2) 판단 에이전트가 현재까지 모인 질의·문서가 질문에 답하기에 충분한지("Sufficient"/"Insufficient") 판정하여 반복 종료 여부를 결정하며, (3) 충분하다고 판단되면 답변 에이전트가 최종 답변을 생성하는 3단계 반복 루프로 구성된다.

  • 답변 에이전트: 정확 일치(EM)와 정밀도(PR) 기반 1단계 보상, 이후 EM과 F1 기반 2단계 보상을 사용한 GRPO 강화학습으로 학습하며, 길이가 지나치게 길면 페널티를 주는 형식 보상 L(y)을 추가해 불필요한 설명을 억제한다.
  • 질의 확장 에이전트: 질의 추가 전후 답변 품질(F1 점수) 변화량을 보상(R_q)으로 삼아 GRPO로 학습, 답변 품질에 실제로 기여하는 질의를 생성하도록 유도한다.
  • 판단 에이전트: 학습된 답변 에이전트로 각 샘플을 16회 반복 생성시켜, 전부 정답이면 "충분", 전부 오답이면 "불충분"으로 라벨링한 데이터로 지도 미세조정(SFT)한다.
  • 훈련 데이터는 HotpotQA와 2WikiMultiHopQA에서 수집한 8,148개 질문을 기반으로, 검색 디베이트(Proponent·Opponent·Moderator 역할극) 파이프라인을 통해 자동 구축했으며 별도의 인간 라벨링은 필요하지 않았다.

실험 설정 및 결과

HotpotQA, 2Wiki(도메인 내)와 NQ, Musique, Bamboogle(도메인 외) 5개 벤치마크에서 평가했으며, 백본으로는 Llama3.1-8B-Instruct(TRIO-8B)와 Qwen3-4B-Instruct(TRIO-4B)를 사용했다. TRIO-8B는 평균 EM 기준 차순위 방법 대비 6.45% 향상되었고, 다중 에이전트 베이스라인 DRAG 대비 72.45% 향상을 보였다. 또한 PubMedQA(의료 도메인, 완전히 미학습 영역)에서도 TRIO-8B가 0.766으로 최고 성능을 기록해 도메인 일반화 능력을 입증했다. Ablation 결과 답변 에이전트 최적화가 성능에 가장 크게 기여했으며, 질의 횟수를 고정하기보다 판단 에이전트가 유동적으로 종료 시점을 결정하는 것이 가장 우수했다. 추론 속도 면에서도 TRIO-8B/4B는 비슷하거나 더 적은 추론 시간으로 추론 기반 기법(Search-R1, R1-Searcher)과 동등하거나 더 나은 성능을 보였다.

한계점

논문은 짧은 정답형 QA에 주로 검증되었으며, 실시간 웹 검색이나 장문 생성 작업에는 아직 검증되지 않았다. 적응형 반복 루프가 매우 긴 응답이나 긴 검색 체인을 요구하는 작업에서는 오류와 불필요한 증거가 누적되어 답변 생성을 저해할 수 있다. 실시간 웹 검색 환경에서는 문서 가용성 변화나 이질적인 웹페이지 구조 등 추가적인 어려움이 있을 수 있다.

시사점

RAG 파이프라인의 각 하위 작업(질의 생성, 충분성 판단, 답변 생성)을 역할별로 분리하고 각기 다른 보상 설계(결과 기반 RL vs. 지도 미세조정)로 개별 최적화하는 접근이, 단일 백본을 공유하는 기존 다중 에이전트 방식보다 훈련 비용과 신뢰성 양면에서 더 효과적일 수 있음을 보여준다. 특히 인간 라벨링 없이 에이전트 자신의 답변 품질 변화를 지도 신호로 활용하는 자기지도적 데이터 생성 방식은 다른 다중 에이전트 시스템 설계에도 적용 가능한 실용적 아이디어다.
