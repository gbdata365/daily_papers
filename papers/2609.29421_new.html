Rufus-Air: An Open LLM Post-Training Recipe

루퍼스-에어: 오픈 LLM 포스트트레이닝 레시피

한 줄 요약

GLM-4.5-Air-Base(106B-A12B) 모델을 기반으로, SFT부터 RLHF까지 8단계로 이어지는 사후학습(post-training) 파이프라인 전체를 데이터·보상 설계·인프라까지 상세히 공개한 재현 가능한 오픈 레시피.

배경 및 문제의식

최신 LLM의 강력한 성능 뒤에는 복잡한 사후학습 파이프라인이 존재하지만, 이 과정의 데이터, 보상 설계, 단계 순서, 인프라 선택 등은 대개 공개되지 않아 재현이 어렵다. 저자들은 새로운 인간 주석이나 자체 증류(distillation) 교사 모델 없이, 공개된 구성요소와 공개 데이터만으로도 경쟁력 있는 사후학습 레시피를 재현 가능하게 구성할 수 있는지를 탐구한다.

핵심 기여

  1. SFT → 추론 RL → 코딩 RL → 지시 따르기 RL → 범용 에이전트 → 코딩 에이전트 → 검색 에이전트 → RLHF로 이어지는 직렬 파이프라인을 문서화.
  2. 각 단계의 데이터, 보상 설계, 인프라, 단계 순서, 단계별 성능 결과를 상세히 공개.
  3. 다양하고 고품질인 SFT가 강한 능력의 기반(capability floor)을 마련한다는 것, 난이도 필터링이 RL 프롬프트를 생산적인 학습 범위 안에 유지시킨다는 것, 보상의 신뢰도가 단계 순서를 정하는 실용적 원칙이 된다는 것, 인프라·엔지니어링 선택 자체가 레시피의 핵심 요소라는 것 등 네 가지 핵심 발견 제시.

방법론

Rufus-Air는 기본에서 고급 능력으로, 그리고 명확히 검증 가능한(hard, verifiable) 보상에서 보다 부드러운 심판 기반(judge-based) 보상으로 점진적으로 이동하는 8단계 직렬 파이프라인으로 구성된다: 지도 파인튜닝(SFT) → 추론 강화학습 → 코딩 강화학습 → 지시 따르기 강화학습 → 범용 에이전트 학습 → 코딩 에이전트 학습 → 검색 에이전트 학습 → 인간 피드백 기반 강화학습(RLHF). 전 과정은 오픈소스 구성요소와 공개 데이터를 그대로 또는 최소한의 가공만 거쳐 사용했으며, 별도의 인하우스 증류 교사 모델은 사용하지 않았다.

실험 설정 및 결과

IFEval, IFBench, Multi-Challenge, Arena-Hard, AIME 25, LiveCodeBench v6, Tau2-Telecom, MCP-Atlas, BrowseComp, Seal-0, SWE-bench Verified 등 다양한 벤치마크에서 Rufus-Air는 GLM-4.5-Air 공식 사후학습 릴리스보다 향상된 성능을 보였으며, INTELLECT-3, Nemotron-3-Super 등 비슷한 규모의 오픈 모델들과 경쟁력 있는 수준을 달성했다.

한계점

시사점

새로운 인간 주석이나 독자적 증류 교사 없이도 공개 데이터와 신중한 단계 설계·보상 신뢰도 원칙만으로 경쟁력 있는 사후학습 파이프라인을 재현할 수 있음을 보여주며, 인프라와 엔지니어링 선택이 레시피의 "구현 세부사항"이 아니라 핵심 구성요소임을 강조한다.
