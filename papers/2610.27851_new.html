LaLa-World: Scaling Latent World Models with Natural Language Actions

LaLa-World: 자연어 행동으로 확장하는 잠재 세계 모델

JEPA 스타일의 잠재 세계 모델(Latent World Model, LWM)에 자연어를 수치 행동과 시각적 변화를 아우르는 공통 인터페이스로 도입함으로써, 서로 다른 로봇·시뮬레이션 도메인과 이미지·비디오 데이터를 하나의 예측기로 함께 학습시키고, 이를 통해 더 높은 플래닝 성능과 훨씬 적은 학습·추론 비용을 동시에 달성한 모델이다.

한 줄 요약

JEPA 스타일의 잠재 세계 모델(Latent World Model, LWM)에 자연어를 수치 행동과 시각적 변화를 아우르는 공통 인터페이스로 도입함으로써, 서로 다른 로봇·시뮬레이션 도메인과 이미지·비디오 데이터를 하나의 예측기로 함께 학습시키고, 이를 통해 더 높은 플래닝 성능과 훨씬 적은 학습·추론 비용을 동시에 달성한 모델이다.

배경 및 문제의식

세계 모델(world model)은 행동에 따라 환경이 어떻게 변할지 예측함으로써 플래닝과 의사결정의 기반을 제공한다. 이 중 픽셀을 직접 복원하지 않고 잠재 표현의 변화만 예측하는 JEPA 스타일의 잠재 세계 모델(V-JEPA 2-AC, DINO-WM 등)은 계산 효율이 높아 여러 후보 행동을 반복적으로 시뮬레이션하는 상상 기반 플래닝(planning with imagination)에 특히 유리하다. 그러나 기존 LWM의 행동 조건부 예측기는 보통 도메인별로 따로 학습된다. 그 이유는 로봇·시뮬레이션 데이터셋마다 행동이 서로 다른 차원과 물리적 의미를 갖는 수치 벡터로 기록되기 때문이다(예: 한 도메인은 [2,4] 차원의 수평·수직 변위, 다른 도메인은 [4] 차원의 힘). 또한 세상에 대한 풍부한 관측을 담고 있는 일반 이미지·비디오 데이터는 이런 수치 행동 라벨이 없어 행동 조건부 예측기 학습에 활용하기 어렵다. 반면 비디오 생성 모델(생성적 세계 모델)은 언어 조건을 공통 인터페이스로 사용해 다양한 데이터에서 폭넓게 학습하지만, 픽셀 수준 생성을 목표로 하기 때문에 계산 비용이 크다. 저자들은 LWM의 효율성과 비디오 생성 모델의 유연한 언어 인터페이스를 결합할 수 있는지를 탐구한다.

핵심 기여

  • 언어를 수치 행동과 시각적 변화를 모두 표현하는 공유 인터페이스로 사용하여, 이질적인 제어 데이터와 폭넓은 이미지·비디오 데이터를 하나의 예측기로 공동 학습하는 언어 조건부 잠재 세계 모델 LaLa-World를 제안한다.
  • 단일 LaLa-World 예측기가 여러 도메인에 걸친 동역학을 학습하여 MPC 플래닝에서 기존 LWM들(도메인별로 따로 학습한 모델 포함)보다 높은 평균 성능을 보임을 입증한다.
  • 동일한 언어 조건·학습 데이터 조건에서 RAEv2 기반 생성적 세계 모델과 비교하여, 더 높은 플래닝 성능과 함께 훨씬 적은 학습·추론 비용을 보인다.
  • 사전학습된 LaLa-World를 행동과 미래 시각 표현을 동시에 예측하는 LaLa-Policy로 파인튜닝하여, 기존 정책 모델들과 경쁠한 성능 및 Cosmos Policy 대비 더 빠른 추론을 달성한다.

방법론

LaLa-World는 두 가지 설계를 통해 언어 기반 공동 학습을 구현한다.

  1. 언어 조건부 전이(transition) 데이터 구성: 7개의 시뮬레이션·로봇 데이터셋(Wall, PointMaze, Push-T, MetaWorld, Rope, Granular, DROID)의 수치 행동 벡터를 고정 템플릿을 이용해 "move the pusher 1.19 left and 0.68 up"과 같은 자연어 문장으로 변환한다. 이렇게 하면 서로 다른 차원·물리적 의미를 가진 행동들이 동일한 언어 형태로 표현되어 하나의 예측기가 학습할 수 있는 공통 데이터 풀을 이룬다. 여기에 더해 OpenVid(비디오 캡션)와 OmniEdit·ShareGPT(이미지 편집 지시문) 같은 수치 라벨이 없는 이미지/비디오 데이터도, 프레임 간 변화를 설명하는 캡션이나 편집 지시문 자체를 언어 조건으로 사용해 함께 학습시킨다.
  2. 모델 구조: 기존 LWM과 동일한 인코더-예측기 구조를 따르되, 관측 인코더로는 고정된(frozen) DINOv2-S/14 또는 DINOv3-L/16을 사용하고, 예측기는 사전학습된 언어모델(기본값 Qwen3.5-0.8B)을 그대로 사용한다. 즉 예측기가 텍스트로 표현된 언어 조건을 직접 읽고 과거 관측의 잠재 표현과 함께 처리하여 다음 시점의 잠재 표현을 예측한다. 시각 잠재 벡터는 2층 MLP로 언어모델의 임베딩 공간에 매핑되고 시간·공간 위치 임베딩이 추가되며, 예측 결과는 학습된 쿼리 토큰을 통해 읽어낸다. 학습 목표는 예측된 잠재 표현과 실제 미래 잠재 표현 간의 제곱오차(MSE)를 최소화하는 것이며, 특정 도메인에만 적용되는 고유 정보인 proprioception(자기수용 감각 상태)은 입력이나 예측 대상에서 제외한다. 플래닝 시각화를 위해 잠재 표현을 RGB 이미지로 복원하는 12층 트랜스포머 디코더도 별도로 학습하지만, 이는 세계 모델 학습 자체에는 사용되지 않는다.

플래닝에는 교차엔트로피법(CEM)을 이용한 모델예측제어(MPC)를 사용하며, 후보 행동열을 언어로 변환해 예측기에 입력하고, 예측된 최종 잠재 상태와 목표 관측의 잠재 표현 간 거리를 비용으로 삼아 최적 행동열을 선택한다.

LaLa-Policy는 사전학습된 LaLa-World 예측기에 행동 예측용 쿼리를 추가하고, Isaac-GR00T 스타일의 디퓨전 트랜스포머 기반 행동 생성기를 덧붙여 관측과 작업 지시문으로부터 행동 청크와 미래 잠재 표현을 함께 예측하도록 파인튜닝한 모델이다.

실험 설정 및 결과

  • MPC 플래닝: Wall, PointMaze, Push-T, MetaWorld, Rope, Granular 등 6개 시뮬레이션 과제와 실제 로봇 데이터셋 DROID, 그리고 학습에 포함되지 않은 RoboCasa(제로샷 평가)에서 DreamerV3, TD-MPC2, IRIS, DINO-WM, JEPA-WMs, V-JEPA 2-AC 등과 비교했다. 단일 예측기로 모든 도메인을 공동 학습한 LaLa-World는 두 벤치마크 그룹 모두에서 최고 평균 성공률(각각 72.1%, 50.5%)을 기록했으며, RoboCasa 제로샷에서도 가장 높은 성능을 보였다.
  • 이미지/비디오 데이터 추가 효과: 제어 데이터에 이미지·비디오 전이 데이터를 추가하면 평균 플래닝 성능이 59.3%에서 61.6%로 향상되고, 동일 행동을 다른 어휘로 표현(paraphrase)해도 성능 저하가 거의 없어(제어 데이터만 학습 시 6.8점 하락 대비) 행동 표현 방식에 대한 로버스트성이 크게 개선된다.
  • 수치 없는 질적(qualitative) 언어 행동: 수치 크기를 "slightly / (기본) / far"의 3단계 질적 수식어로 바꾸어도 LaLa-World가 성공적으로 플래닝할 수 있음을 보였다.
  • 잠재 모델 vs. 생성 모델 비교: 동일한 시각 인코더(DINOv3-L/16), 언어 조건, 학습 데이터, 유사한 파라미터 규모(~0.8B)로 RAEv2 기반 디퓨전 트랜스포머 생성 모델과 매칭 비교를 수행했다. LaLa-World는 RAEv2의 12시간 학습 성능(5-스텝 디노이징)을 2시간 만에 따라잡고 최종적으로 더 높은 성능(59.4% vs 48.0%)을 보였으며, 동일 깊이 모델 기준 1-스텝/5-스텝 RAEv2보다 각각 2.9배, 13.9배 빠르게 플래닝했다.
  • LaLa-Policy 정책 학습: LIBERO와 RoboCasa에서 π0, π0.5, OpenVLA-OFT, Cosmos Policy 등과 비교했을 때, LaLa-World로 초기화한 LaLa-Policy가 무작위 초기화나 Qwen3.5 단독 초기화보다 우수했고 Cosmos Policy와 경쟁력 있는 성공률을 보이면서 궤적당 평균 추론 시간은 LIBERO에서 5.2배, RoboCasa에서 5.5배 더 빨랐다.

한계점

  • 사용된 학습 데이터 규모가 Wan과 같은 비디오 생성 모델에 비해 작아, 데이터·모델 규모를 더 키울 때도 성능 향상이 계속되는지는 확인되지 않았다.
  • 표현 붕괴(collapse)를 막기 위해 시각 인코더를 고정(frozen)한 채 사용하므로, 인코더 표현이 미래 예측에 맞게 적응하지 못한다는 한계가 있다.
  • 예측기가 다음 한 스텝의 잠재 상태만 학습하도록 감독되어 있어, 비디오 생성 모델처럼 긴 시퀀스를 자기회귀적으로 생성하는 능력은 검증되지 않았다.
  • MPC 실험에서 사용한 플래닝 호라이즌이 최대 6스텝으로 비교적 짧아, 더 먼 미래를 내다보는 장기 플래닝 성능은 평가되지 않았다.
  • 모든 정책 평가가 LIBERO·RoboCasa 시뮬레이터에서만 이루어졌으며, 실제 로봇 환경에서의 검증은 수행되지 않았다.
  • LaLa-Policy는 가치(value) 함수 학습 없이 작동하여 Cosmos Policy가 지원하는 Best-of-N 플래닝 같은 확장은 아직 적용되지 않았다.

시사점

이 연구는 픽셀 수준 복원을 목표로 하지 않는 잠재 세계 모델도 언어를 공통 인터페이스로 사용하면 이질적인 도메인과 데이터 소스를 가로질러 효과적으로 확장(scaling)될 수 있음을 보여준다. 특히 시각적으로 화려한 생성 결과물 없이도 잠재 공간 예측만으로 생성적 세계 모델보다 더 적은 비용으로 더 나은 플래닝 및 정책 학습 성능을 낼 수 있다는 점은, 로봇 정책이나 제어 응용에서 무거운 비디오 생성 모델 대신 경량 잠재 세계 모델을 기반으로 삼는 방향에 대한 실질적 근거를 제공한다. 이는 세계 모델 연구의 초점을 "보기 좋은 생성 품질"에서 "효율적이고 실용적인 예측·플래닝 능력"으로 옮길 수 있는 가능성을 제시한다.
