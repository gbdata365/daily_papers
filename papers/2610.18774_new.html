GreenWAM: A World Foundation Model for Robotics

그린왐: 로보틱스를 위한 월드 파운데이션 모델

서로 다른 로봇 몸체(두 팔 매니퓰레이터부터 휴머노이드까지 20개 로봇 패밀리)를 하나의 "공유 해부학적 행동 공간"으로 통합해, 하나의 월드 파운데이션 모델이 영상 예측(월드 모델)과 로봇 제어(정책) 두 역할을 동시에 수행하도록 만든 연구.

한 줄 요약

서로 다른 로봇 몸체(두 팔 매니퓰레이터부터 휴머노이드까지 20개 로봇 패밀리)를 하나의 "공유 해부학적 행동 공간"으로 통합해, 하나의 월드 파운데이션 모델이 영상 예측(월드 모델)과 로봇 제어(정책) 두 역할을 동시에 수행하도록 만든 연구.

배경 및 문제의식

로봇 월드 모델은 보통 영상 예측용과 제어 정책용 중 한 가지 역할로만 만들어지고 평가된다. 그런데 로봇 데이터셋마다 관절 배치, 그리퍼·손 종류, 카메라 구성, 프레임레이트, 작업 경계 정의가 제각각이어서, 같은 텐서라도 로봇마다 의미하는 동작이 다르다. 기존 모델(Cosmos 3 Edge 등)은 임베디먼트(embodiment)마다 별도의 액션 프로젝션을 두거나 엔드이펙터 포즈 델타로만 행동을 표현해, 서로 다른 몸체의 팔·다리·몸통·손가락 간 대응 관계가 암묵적이거나 아예 없었다. 저자들은 "하나의 로봇 월드 모델이 월드 모델과 정책 양쪽 역할을 동시에 잘 수행할 수 있는가, 그리고 그것을 가능하게 하는 요인은 무엇인가"라는 질문을 던진다.

핵심 기여

  • 공유 해부학적 행동 공간(shared anatomical action space): 다리·몸통·팔·손 4개 블록, 총 79개 슬롯으로 구성된 공통 관절 좌표계를 정의하고, 각 로봇 레이아웃별 "코덱(codec)"이 고유 관절 채널을 이 슬롯에 매핑(선택·순서 변경·부호/영점 보정)하여 모든 로봇이 하나의 공유 입출력 프로젝터를 쓰도록 함.
  • 하나의 모델, 두 가지 역할: 영상 전용, 행동 조건부, 월드-액션(WAM) 등 7가지 학습 모드로 공동 학습시켜 하나의 생성기(generator)가 영상·로봇 동작을 모두 예측하게 하고, 여기서 액션 전문가(action expert)를 분리해 정책으로 전환.
  • 대규모 데이터 파이프라인: 20개 로봇 패밀리, 1,217개 데이터셋, 약 1,688.5시간(필터링 후 1,674.7시간)의 LeRobot 포맷 데이터를 서브태스크 단위(atom)로 정제하고 자동 캡션·명령어를 생성하는 큐레이션 체계 구축.
  • 실제 휴머노이드 로봇 적용 및 1-step 증류(distillation): Green 휴머노이드에 정책을 적응시키고, 실시간 제어를 위해 단일 스텝 정책으로 증류.

방법론

Cosmos 3 Edge의 4B 파라미터 mixture-of-transformers(추론기+생성기, 인과적 비디오 VAE, rectified-flow 학습)를 기반으로 시작한다. "로보틱스 단계"에서는 추론기와 VAE를 고정한 채, 생성기와 공유 액션 프로젝션, 액션-모달리티 임베딩만 20개 로봇 패밀리의 측정된 관절·카르테시안 상태로 재학습한다. 각 로봇 레이아웃의 코덱은 네이티브 관절 채널을 79개 해부학적 슬롯(다리 12, 몸통 23, 팔 18, 손 26)에 부호·영점 보정과 함께 매핑하며, 존재하지 않거나 불확실한 좌표는 손실 계산에서 마스킹한다. 학습은 텍스트→영상, 이미지→영상(+히스토리), 순방향 역학(forward dynamics, +히스토리), 역방향 역학(inverse dynamics), 월드-액션(WAM) 등 7개 모드를 혼합 샘플링하며, 모든 생성 스트림이 동일한 노이즈 레벨에서 rectified-flow 속도를 예측하도록 학습한다. 정책으로 전환할 때는 생성기 타워를 그대로 복제해 별도의 "액션 전문가" 트랜스포머를 만들고, 매 레이어에서 영상·행동 토큰이 공동 어텐션을 공유하되 각자의 피드포워드 블록을 갖도록 분리한다(파라미터 약 +8% 증가). 실시간 제어를 위해 Flash-WAM 방식을 참고한 일관성 증류(consistency distillation)로 다단계 샘플링을 1-step으로 압축한 학생 모델도 만든다.

실험 설정 및 결과

  • 월드 모델 평가(WorldArena 1.0): 궤적 정확도(56.0), 깊이 정확도(98.2), 3D 정확도(93.4) 등에서 비교 대상 월드-액션 모델·영상 생성기 중 최고 수준을 기록했고, 종합 EWMScore 63.31로 Motubrain(63.16), FlowWAM-FiveAges(62.99)를 상회함.
  • RoboTwin 2.0: 리더보드 프로토콜(태스크당 50개 클린 시연)에서 클린 86.98%, 랜덤화 48.10%, 평균 67.54%로 공개된 리더보드 항목 중 상위권.
  • CALVIN(ABC→D): 체인당 평균 4.64개 지시 성공(FLOWER의 4.53보다 우수).
  • LIBERO / LIBERO-plus: LIBERO 97.4%로 비교 모델들과 경쟁력 있는 수준이며, 제로샷 LIBERO-plus에서는 비교 대상 중 최고 성능(86.8).
  • 실제 휴머노이드(Green): 물건을 가방에 담아 들어올려 건네주는 패킹 과제에서 분포 내(ID) 95.6%, 분포 외(OOD) 84.0% 성공률로, Cosmos 3 Edge 기반 정책(88.9%/80.0%)과 π0.5(84.4%/76.0%)를 상회. 증류된 1-step 학생 모델은 RTX 4090에서 추론 지연을 435.9ms→28.3ms로 줄여 비증류 대비 약 12.3배 빨라짐(ID 91.1%, OOD 80.0% 성공률 유지).
  • 통제된 비교 실험: (1) GreenWAM에서 적응을 시작하는 "로봇 특화" 초기화가 월드 예측과 정책 성공률을 함께 끌어올리고, (2) 생성기에서 분리한 액션 전문가가 정책 성공률을 추가로 높이며, (3) 정책 적응 중에도 월드 모델 모드(순방향 역학·이미지→영상)를 일부 유지하는 것이 랜덤화된 장면에서의 견고성을 8.0%p 높임을 확인.

한계점

정책은 테이블 높이 변화 같은 과제 기하 구조 변화에 민감하며, 여기 사용된 외형 증강(appearance augmentation)은 관측만 바꿀 뿐 새로운 동작을 추가하지 않는다. 긴 롤아웃은 모델 자신이 생성한 프레임을 이어 붙여 진행되므로 블록이 거듭될수록 예측 오차가 누적된다. 각 벤치마크는 각기 다른 사후학습(post-training)을 거쳐야 도달 가능하며, 실제 로봇 평가는 휴머노이드 1종과 패킹 과제 1종에 국한된다.

시사점

서로 다른 로봇 몸체 간의 행동 표현을 공유 좌표계로 통일하면, 하나의 파운데이션 모델이 영상 예측(월드 모델)과 로봇 제어(정책) 역할을 모두 잘 수행할 수 있고, 두 역할이 서로의 성능을 강화할 수 있음을 보여준다. 로봇 특화 초기화, 액션 전문가 분리, 정책 적응 중 월드 모델 모드 유지라는 세 가지 설계 선택이 실질적인 성능 향상으로 이어진다는 점은 향후 범용 로봇 파운데이션 모델 설계에 실용적 지침을 제공한다. 또한 1-step 증류를 통한 실시간 제어 가능성은 대형 월드-액션 모델을 실제 로봇 하드웨어에 배포하는 데 중요한 실마리가 된다.
