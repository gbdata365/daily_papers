Think Less, Locally: Local Preference Learning for Reasoning Compression

생각은 적게, 지역적으로: 추론 압축을 위한 국소 선호 학습

대형 추론 모델(LRM)이 이미 충분한 정보를 얻은 뒤에도 불필요하게 사고를 이어가는 "과잉사고(overthinking)" 상태를 모델 스스로의 추론 흔적에서 탐지하고, 같은 지점에서 더 짧고 정답인 재생성 결과와 원래의 긴 결과를 비교하는 국소 선호 학습(DPO)으로 학습시켜, 수학 추론에서 41.7~45.4%, 코드 생성에서 23.4~36.3%의 토큰을 줄이면서 정확도는 유지하거나 개선한 연구.

한 줄 요약

대형 추론 모델(LRM)이 이미 충분한 정보를 얻은 뒤에도 불필요하게 사고를 이어가는 "과잉사고(overthinking)" 상태를 모델 스스로의 추론 흔적에서 탐지하고, 같은 지점에서 더 짧고 정답인 재생성 결과와 원래의 긴 결과를 비교하는 국소 선호 학습(DPO)으로 학습시켜, 수학 추론에서 41.7~45.4%, 코드 생성에서 23.4~36.3%의 토큰을 줄이면서 정확도는 유지하거나 개선한 연구.

배경 및 문제의식

DeepSeek-R1류의 대형 추론 모델은 긴 사고 사슬(chain-of-thought)로 높은 성능을 내지만, 정답에 이미 도달한 뒤에도 계속 사고를 이어가는 과잉사고로 추론 비용이 크게 늘어난다. 기존 압축 기법은 ①전체 궤적 수준에서 길이가 짧은 정답과 긴 정답을 비교해 전반적으로 짧은 쪽을 선호하도록 학습하거나, ②궤적 내 중복 토큰·문장·단계를 세밀하게 제거하는 방식이었다. 그러나 두 접근 모두 "궤적 자체"를 압축 대상으로 삼을 뿐, 특정 추론 상태에서 더 사고를 계속해야 하는지 아니면 멈춰야 하는지에 대한 상태별 판단을 직접 다루지 않는다는 한계가 있다.

핵심 기여

  • 효과적인 추론 압축은 궤적 전체를 짧게 만드는 것이 아니라, 각 추론 상태에서 "더 생각할 필요가 있는가"를 판단하는 상태 인식적 결정이 핵심이라는 점을 제시.
  • 모델 자신의 추론 흔적에서 과잉사고 상태를 탐지하고, 동일한 접두(prefix)를 공유하는 대안적 연속 추론들 사이의 "계속할지 멈출지" 선호를 학습하는 국소 선호 학습 프레임워크 LoCo(Local Compression)를 제안.
  • 수학 추론과 코드 생성 전반에서 효율-성능 트레이드오프를 일관되게 개선하고, 수학 데이터로만 학습했음에도 코드 영역으로 강하게 전이되는 범용성을 실험으로 입증.

방법론

LoCo는 세 단계로 구성된다. (1) 단계별 과잉사고 탐지: 모델이 자신의 사고 사슬을 다시 읽으며 각 추론 단계(문단 단위)의 평균 최상위 토큰 확률(신뢰도 c_i)과 인접 단계 간 신뢰도 변화(변동성 v_i)를 계산하고, 신뢰도가 하위 25%이면서 변동성이 상위 25%인 지점을 과잉사고 후보로 선별한 뒤, 더 강력한 판정 모델(Qwen3-30B)이 해당 다음 단계를 OVERTHINK/NORMAL/FINAL로 재확인한다. (2) 검증된 연속 추론 생성: 확정된 각 상태에서 추론 접두를 고정(freeze)한 채 모델로부터 k=8개의 연속 추론을 샘플링하고, 정답과 일치하면서 가장 짧은 것을 "선택된" 연속으로, 원래의 긴 연속을 "거부된" 연속으로 삼아 선택된 쪽이 실제로 더 짧은 경우만 남긴다. (3) 국소 선호 학습: 동일한 고정 상태를 공유하는 (짧은 정답, 원래 긴 답) 쌍을 DPO로 학습시켜, 모델이 특정 상태에 도달했을 때 "계속할지 결론낼지"를 학습하게 한다. 학습은 DeepSeek-R1-Distill-Qwen-7B에 LoRA(rank 256)를 적용해 수행했다.

실험 설정 및 결과

수학 14,027문항(Zhang et al. 2026b의 math14k)에서 자가 생성한 추론 흔적으로 학습 데이터를 구축하고, 수학 5종(MATH-500, AMC23, Olympiad, AIME24, AIME25)과 코드 3종(MBPP, LiveCodeBench, CodeContests) 벤치마크에서 평가했다. LoCo는 쉬운 벤치마크에서는 기존 성능을 유지하면서 완성 길이를 41.7~44.1% 줄였고, 어려운 벤치마크(Olympiad, AIME24/25)에서는 오히려 정확도·AUC를 모두 높이면서 44.6~45.4%를 감축했다. 수학만으로 학습했음에도 코드 벤치마크에서 23.4~36.3% 토큰 절감과 함께 정확도·AUC 개선을 보여 전이 성능을 입증했다. Ablation 결과, 궤적 전체 수준의 전역(Global) 선호 학습은 압축률이 5~16%에 불과했고, 외부 모델(GPT-5.4)이 생성한 대안보다 자가 생성 대안이 더 효과적이었으며, 무작위·균등 절단점 대신 탐지기로 선택한 절단점을 쓰는 것이 정확도 보존에 중요했다.

한계점

논문 본문에 별도의 "한계점" 절은 명시되어 있지 않다. 다만 ablation 및 방법론 설계에서 다음과 같은 제약이 드러난다: 학습 데이터가 수학 문제로만 구성되어 있고 7B 규모의 단일 모델(DeepSeek-R1-Distill-Qwen-7B)에 LoRA로만 검증되었으며, 과잉사고 판정에 별도의 강력한 판정 모델(Qwen3-30B)과 상태별 다중 샘플링(k=8)이 필요해 데이터 구축 비용이 추가로 발생한다. 그 외 세부 한계는 '논문에 명시되지 않음'.

시사점

추론 압축을 궤적 전체의 "길이 선호" 문제가 아니라 각 추론 상태에서의 "계속 대 결론" 국소 결정 문제로 재정의하면, 더 정교하게 과잉사고만을 골라 제거하면서도 어려운 문제에서 필요한 추론은 보존할 수 있음을 보여준다. 이는 향후 추론 모델의 효율화 연구가 전역적 길이 페널티보다 상태 조건부 선호 학습 쪽으로 발전할 수 있음을 시사한다.
