Programmable World Model

프로그램 가능한 세계 모델

Programmable World Model은 세계 상태의 진화(world-state evolution)와 시각적 관측 생성(visual observation generation)을 분리하여, 코딩 에이전트가 자연어 지시를 실행 가능한 프로그램으로 변환해 명시적이고 지속적인 전역 세계 상태를 관리하고, 이를 상태 증강 3D 지향 바운딩 박스(OBB)를 매개로 사전학습된 비디오 생성 모델에 픽셀 정렬된 조건 신호로 컴파일함으로써, 오프스크린 엔티티와 규칙 기반 게임 메커닉을 갖춘 플레이 가능한 지속적 세계를 구현한다.

한 줄 요약

Programmable World Model은 세계 상태의 진화(world-state evolution)와 시각적 관측 생성(visual observation generation)을 분리하여, 코딩 에이전트가 자연어 지시를 실행 가능한 프로그램으로 변환해 명시적이고 지속적인 전역 세계 상태를 관리하고, 이를 상태 증강 3D 지향 바운딩 박스(OBB)를 매개로 사전학습된 비디오 생성 모델에 픽셀 정렬된 조건 신호로 컴파일함으로써, 오프스크린 엔티티와 규칙 기반 게임 메커닉을 갖춘 플레이 가능한 지속적 세계를 구현한다.

배경 및 문제의식

최근 비디오 세계 모델은 점점 더 사실적이고 상호작용적인 시각 경험을 생성하지만, 이를 진정한 상호작용형 세계 엔진으로 발전시키기 위해서는 관측 생성 이상의 능력이 필요하다. 첫째, 기존 제어 인터페이스는 주로 카메라, 행동, 고수준 프롬프트만 지정할 뿐 개별 엔티티를 직접 지정하고 조작하는 기능이 제한적이다. 둘째, 기존 모델은 현재 시야와 독립적으로 접근·갱신 가능한 명시적이고 지속적인 전역 상태(오프스크린 엔티티, 인벤토리, 진행 상황 등 비시각적 정보 포함)를 일반적으로 갖추지 못한다. 셋째, 사용자가 세계 진화를 지배하는 규칙(예: 문이 열리는 조건, 상호작용이 다른 엔티티에 미치는 영향)을 프로그래밍하기 어렵다 — 원하는 결과를 프롬프트로 지시하는 것만으로는 이후 상호작용을 일관되게 지배하는 실행 가능한 규칙이 확립되지 않는다.

핵심 기여

  • 실행 가능한 세계 상태 진화를 생성적 렌더링으로부터 분리하여 엔티티 수준 제어, 지속적 상태 관리, 사용자 프로그래밍 가능한 규칙을 지원하는 Programmable World Model 프레임워크 제안. 상태 증강 3D OBB와 결정론적 상태 컴파일러가 이 편집 가능한 세계 상태를 뷰 일관적이고 픽셀 정렬된 시공간 조건 신호로 비디오 생성에 연결
  • 비디오에서 공간·의미 지도(supervision)를 자동 추출하는 데이터 큐레이션 파이프라인을 개발하여 프로그램 가능한 생성 세계를 위한 학습 데이터 확장 경로 제시
  • 생성 비디오와 엔진이 유지하는 세계 상태 간의 일관성(가시적 생존 캐릭터 수, 사망 상태의 시각적 구현)을 평가하는 벤치마크 CombatStateBench 도입

방법론

프레임워크는 세 단계로 구성된다. (1) 에이전트 주도 세계 프로그래밍: 초기 관측 이미지에서 오프더셸프 3D 검출기로 엔티티의 3D OBB와 지속적 식별자를 복원한 뒤, VLM 기반 코딩 에이전트가 사용자의 자연어 설명과 결합하여 엔티티의 초기 상태, 속성, 관계, 행동 규칙(트리거·목표 포함)을 담은 엔진이 읽을 수 있는 "월드 프로그램"을 생성한다. 경량 엔진은 매 스텝마다 플레이어 행동을 현재 규칙 집합에 따라 검증·적용하고 트리거된 이벤트를 해석하여 상태를 갱신한다(s_{t+1} = F(s_t, a_t)). (2) 제어 컴파일: 결정론적 상태 컴파일러가 갱신된 상태의 렌더링 관련 변수(엔티티 OBB, 정체성, 의미 범주, 객체 고유의 카메라 상대 이동 방향)를 목표 카메라 궤적 하에서 투영하여, 정체성 맵·의미 맵·방향 맵 세 가지의 공간 정렬 제어 신호를 구성한다. 방향 맵은 이미지 공간 변위가 아닌 세계 공간 속도에서 계산되어 카메라 이동과 객체 자체 이동을 구분한다. (3) 생성적 렌더링: 사전학습된 카메라 제어 비디오 생성 백본(LingBot-World-v1)에 학습 가능한 Structured Spatial ControlNet을 부착하여 제어 신호를 주입하고(백본은 동결), 청크 단위 자기회귀 방식으로 장기 생성을 지원한다. 이때 최근~장기 다중 스케일 시간 이력과, 완료된 프레임을 깊이 기반으로 세계 공간에 투영해 재조회하는 기하 정렬 공간 메모리(AlayaWorld 방식 차용)를 함께 조건으로 사용한다. 학습 데이터는 ViPE(카메라 파라미터·깊이 추정), Qwen3-VL(의미 범주 발굴), SAM3(인스턴스 분할·추적), WildDet3D(프레임별 3D OBB 추정)로 구성된 자동 파이프라인을 통해 라벨 없는 비디오로부터 구축된다.

실험 설정 및 결과

  • 학습 데이터: Cyberpunk 2077(1인칭), Forza Horizon 6, Grand Theft Auto V(3인칭)에서 수집한 HUD 없는 게임플레이 영상
  • CombatStateBench: 전투 시나리오 50개 클립으로 구성, 카메라·엔티티 모션 조합이 다양하며 AI 에이전트가 초기 레이아웃과 규칙으로부터 전체 상태 시퀀스를 자율적으로 진화시켜 생성, 자동 검증기로 기하·깊이·연속성 등을 확인한 것만 채택
  • 베이스라인: LingBot-World-V2, YUME(둘 다 명시적 인스턴스 상태 인터페이스가 없어 프롬프트 전환 방식으로 상태 전이를 전달)
  • Qwen3.6-27B를 VLM 심판으로 사용해 Count Accuracy(샘플 프레임의 생존 캐릭터 수 일치율)와 State Accuracy(사망 이벤트 이후 시각적 사망 구현 여부) 측정
  • Count Accuracy: 제안 방법 94.00% vs LingBot-World-V2 40.75%, YUME 32.00%
  • State Accuracy: 제안 방법 98.00% vs LingBot-World-V2 8.00%, YUME 58.00%
  • VBench 기반 영상 품질(Imaging Quality, Subject Consistency, Background Consistency, Temporal Stability) 네 지표 모두에서도 제안 방법이 최고 성능(예: Subject Consistency 94.74% vs 81.87%/92.35%)
  • 정성 결과: 897프레임에 달하는 장기 자기회귀 시퀀스에서 다수 NPC 등장, 대각도 카메라 회전 시 이전에 보이지 않던 캐릭터의 올바른 재현, 미노타우로스·레이싱 게임 등 미학습 장면·장르로의 일반화 등을 시연

한계점

논문에 명시된 바로는, Count/State Accuracy는 엔진이 유지하는 인스턴스 수준의 정확한 대응 관계를 직접 보상하지 않는 다소 거칠고(coarse) 관대한(permissive) 전역 지표이며, 베이스라인들이 인스턴스 수준 상태 인터페이스를 갖추지 않아 프롬프트 전환 방식으로만 비교가 이루어졌다는 점에서 비교의 엄밀성에 한계가 있을 수 있다. 또한 세밀한 기하·역학(신체 자세, 관절 움직임 등)은 명시적으로 표현하지 않고 생성 모델의 사전 지식에 맡기는 설계이므로, OBB로 포착되지 않는 정밀한 물리적 상호작용의 신뢹성은 생성 렌더러의 능력에 의존한다. 그 외 구체적인 실패 사례나 일반적 한계에 대한 별도의 논의는 본문에서 상세히 제공되지 않는다.

시사점

이 연구는 생성적 세계 모델이 세계에 대한 진실을 시각 생성 능력에만 의존해 "기억"해서는 안 된다는 문제의식에서 출발하여, 세계 상태를 명시적으로 유지하고 비디오 모델을 주로 "렌더러"로 활용하는 분리 설계가 지속적 상호작용의 신뢰성을 생성적 유연성의 희생 없이 크게 향상시킬 수 있음을 보여준다. 상태 증강 3D OBB라는 중간 수준 표현이 지나치게 가벼운(텍스트, 2D 박스) 표현과 지나치게 무거운(완전한 3D 씬, G-버퍼) 표현 사이에서 학습-추론 불일치를 줄이면서도 명시적 제어력을 확보하는 실용적 지점임을 시사하며, 이는 향후 상태가 실행 가능하고 검증 가능하면서도 외형은 여전히 생성적인 방식으로 남는 세계 모델 설계 방향을 제시한다.
