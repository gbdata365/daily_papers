PCBRouteAgent: How Close Are LLM Agents to Becoming PCB Routing Engineers?

한 줄 요약

PCB(인쇄회로기판) 배선(routing)을 보드 수준의 전략 수립과 세부 실행으로 분리해, LLM 에이전트가 KiCad의 네이티브 배선 엔진을 활용해 복잡한 실제 보드에서도 규칙 위반 없이 배선을 완성하도록 하는 멀티모달 에이전트 PCBRouteAgent를 제안한다.

배경 및 문제의식

PCB 배선은 부품 배치가 끝난 보드에서 각 전기적 넷(net)의 패드들을 구리 배선과 비아로 연결하는 작업으로, 설계 규칙(간격, 선폭, 비아 등)을 만족시키면서 배선 길이와 레이어 전환을 최소화해야 하는 결합된 물리적 설계 문제다. 기존 규칙 기반 자동 배선기나 강화학습 기반 방법들은 배선 결정 방식과 실행 연결 방식에 한계가 있고, PCBWorld와 같은 최근 환경에서 평가된 LLM 에이전트들도 복잡한 실제 보드에서는 여전히 규칙 기반 라우터에 비해 완성도가 떨어진다. 저자들은 에이전트가 어떤 연결을 우선할지, 제한된 배선 공간을 어떻게 넷들 간에 배분할지, 언제 레이어 전환이 필요한지 등 보드 수준의 조율 능력이 부족하다는 점을 핵심 문제로 지목한다.

핵심 기여

인간 배선 엔지니어가 전역 전략과 지역 실행을 함께 고려하는 방식을 모사하여, (1) 보드 이미지와 구조화된 전기·기하 정보를 결합해 연결 위상·배선 순서·공간/레이어 가이드를 생성하는 Global Routing Planner와, (2) KiCad의 네이티브 배선 엔진을 통해 실제 배선과 비아를 생성하고 국소적 복구를 수행하는 Detailed Routing Executor를 통합한 피드백 기반 계획-실행 루프를 제안한다. 실행 실패 시 구조화된 피드백을 계획자에게 전달해 기존에 완성된 배선은 보존하면서 가이드만 선택적으로 수정하는 점이 특징이다.

방법론

Global Routing Planner는 보드 이미지(전체 레이아웃, 전/후면 구리층, 미연결 수요)와 구조화된 텍스트(패드 좌표, 넷 할당, 연결 클러스터, 설계 규칙)를 함께 입력받는다. 각 넷에 대해 최소 신장 트리(MST)로 연결 위상을 구성하고, 넷별 예상 배선 길이를 기준으로 배선 순서를 초기화하며, 각 연결 엣지에 대해 사각형 모양의 배선 코리더와 레이어 전환이 필요한 경우 비아 전환 영역을 지정한다. Detailed Routing Executor는 이 가이드를 바탕으로 KiCad의 push-and-shove(PNS) 라우터를 호출해 실제 배선 경로를 단계적으로 완성하며, 장애물에 막히면 walkaround·shove·A* 탐색·앵커 전환 등 제한된 국소 복구를 시도한다. 복구가 실패하면 실패 경위, 마지막 도달 위치, 장애물 정보 등을 담은 구조화된 피드백을 Global Routing Planner에 전달해 가이드를 재계획(replanning)하도록 하며, 이 계획-실행 루프는 모든 목표 연결이 완료되거나 예산이 소진될 때까지 반복된다.

실험 설정 및 결과

PCBWorld-Bench의 247개 합성·실제 보드(D2, D3-A, D3-B, D3-C 네 분할)에서 Claude Opus 5.5 및 Haiku 5.5를 백본으로 평가했다. 완전 합성 보드인 D2에서는 Clean-Pass(규칙 위반 없이 전체 연결 완료) 비율 100%를 달성했고, 실제 보드 D3-A, D3-B, D3-C에서는 각각 94.9%, 100%, 40%를 기록하며 가장 강력한 평가 기준선인 Freerouting(75%, 64%, 30%) 대비 각각 19.9, 36, 10퍼센트포인트 향상되었다. 또한 D3-C에서 평균 설계 규칙 위반 건수를 Freerouting의 32.0건에서 6.3건으로 줄였다. 동일한 Haiku 5.5 백본으로 비교했을 때도 PCBRouteAgent는 PCBWorld 대화형 에이전트 대비 모델 호출 수를 약 131배, 토큰 사용량을 8.8배, API 비용을 4.3배, 누적 실행 시간을 14배 줄이면서도 모든 분할에서 더 높은 완성률을 보였다.

한계점

대형 보드(D3-C, 패드 수 100개 초과)에서는 평균 연결 완료율(라우터빌리티)이 94.9%로 높음에도 불구하고 10개 보드 중 6개가 완전히 끝까지 완성되지 못해 Clean-Pass 비율이 40%에 그쳤다. 즉 대부분의 목표를 연결하는 것과 보드 전체를 끝까지 완성하는 것 사이에 여전히 간극이 존재한다. 또한 완성도가 높아질수록 배선 길이가 다소 늘어나는 경향(D3-B에서 Freerouting 대비 10.9% 더 긴 배선)이 있어, 배선의 물리적 효율성(길이, 비아 수)을 더 개선할 여지가 남아 있다.

시사점

PCB 배선처럼 전역적 계획과 세밀한 물리적 실행이 긴밀하게 얽힌 공학 문제에서, LLM 에이전트를 계획자(Planner)와 실행자(Executor)로 역할 분리하고 실행 피드백을 통한 선택적 재계획 메커니즘을 결합하는 접근이 효과적일 수 있음을 보여준다. 이는 PCB 설계 자동화뿐 아니라 유사한 구조(전역 전략 수립 + 도구 기반 국소 실행 + 실패 피드백 반영)를 갖는 다른 물리적/공학적 에이전트 과제에도 적용 가능한 설계 패턴을 시사한다.
