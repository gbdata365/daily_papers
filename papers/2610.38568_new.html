A-RSI: Adaptive Task Refresh for Zero-Data Multimodal Self-Improvement

A-RSI: 제로데이터 멀티모달 자기개선을 위한 적응형 태스크 갱신

외부 데이터나 사람이 작성한 정답 없이, 모델이 직접 만든 프로그램으로 멀티모달 문제와 정답을 생성하고, 학습 로그만으로 "언제" 학습 데이터 풀을 새로 교체할지 판단하는 재귀적 자기개선(RSI) 프레임워크 A-RSI를 제안한다.

한 줄 요약

외부 데이터나 사람이 작성한 정답 없이, 모델이 직접 만든 프로그램으로 멀티모달 문제와 정답을 생성하고, 학습 로그만으로 "언제" 학습 데이터 풀을 새로 교체할지 판단하는 재귀적 자기개선(RSI) 프레임워크 A-RSI를 제안한다.

배경 및 문제의식

재귀적 자기개선(Recursive Self-Improvement, RSI)이 되기 위해서는 모델이 유용한 학습 경험을 계속 만들어내는 것뿐 아니라, 현재 사용 중인 학습 데이터(태스크 풀)가 더 이상 학습 신호를 주지 못하게 된 "시점"을 스스로 알아차려야 한다. 기존 연구들은 주로 "다음에 어떤 문제를 낼 것인가"(난이도 조정, 역량에 맞춘 문제 선별 등)에 집중했고, 데이터를 "언제" 교체해야 하는지는 상대적으로 소홀히 다뤘다. 또한 다수결(self-consistency, majority voting) 방식으로 정답을 만드는 기존 self-play/self-improvement 기법들은, 모델 자신의 불확실한 예측이 다음 학습의 정답(label)이 되어버리는 신뢰성 문제를 안고 있다. 저자들은 이 두 가지 문제, 즉 "언제 새 경험을 들여올지"와 "그 경험의 정답이 올바른지"를 분리하여 다루고자 한다.

핵심 기여

  • 학습 로그 기반 풀 교체 규칙: 그룹 단위 강화학습(GRPO)에서 그룹 내 보상이 모두 같아 정책 그래디언트 신호가 0이 되는 현상에 주목하여, 유의미한 어드밴티지를 가진 프롬프트 수(U_w)와 학습 정확도(a_w)의 변화를 모니터링해 검증/테스트 점수를 전혀 참조하지 않고 풀 교체 시점을 결정하는 규칙을 제안했다.
  • 프로그램 기반으로 검증된 학습 경험: 모델이 직접 작성한 고정 프로그램(템플릿) 라이브러리가 이미지·질문·정답을 동시에 생성하므로, 외부 학습 데이터나 사람이 작성한 정답 없이 학습 루프를 구동할 수 있다.
  • 정합된 비교 및 응답 단위 분석: 동일한 학습 진행 단계에서 여러 교체 정책을 비교하고, 점수 상승이 "응답을 끝까지 완성했기 때문"인지 "이미 완성된 응답의 정답이 교정되었기 때문"인지를 구분해 분석했다.

방법론

A-RSI는 크게 세 단계로 구성된다. 1. 사전 준비(Programmatic task construction): 기하, 차트, 표, 개수 세기 등 기본 유형에서 시작해 베이스 모델이 재사용 가능한 문제 구조와 매개변수화된 프로그램을 작성한다. 각 프로그램은 매개변수를 샘플링해 이미지(I), 질문(q), 그리고 동일한 내부 상태에서 계산된 정답(a)을 함께 만들어낸다(예: 차트에서 두 막대 값을 뽑아 질문을 만들고 그 차를 정답으로 계산). 생성된 후보는 구성 검증, 최신성/오염(benchmark 유출) 검사를 거쳐 저장되고, 미리 중복 없는 교체용 풀들로 나눠 준비된다. 2. 학습(Rewards and policy optimization): 활성 풀에서 Solver를 GRPO로 학습한다. 보상은 정답 일치 여부(정답 보상), 정해진 박스형 답안 포맷 준수 여부(포맷 보상), 정상 종료 여부(종료 보상, 토큰 한도에 걸려 중단되면 패널티)의 합으로 구성된다. 보조 보상(포맷·종료)의 범위는 정답 보상의 서열을 절대 뒤집지 못하도록 수식적으로 설계되어 있다. 3. 풀 포화 감지 및 교체(Detecting pool saturation / Fresh replacement): 각 윈도우(100회의 GRPO 업데이트) 종료 후, 그룹 내 어드밴티지가 0이 아닌 고유 프롬프트 수 U_w와 평균 정확도 a_w를 ℓ 윈도우 전 값과 비교한다. U_w가 임계 비율(ρ) 이하로 떨어지거나 정확도가 일정 폭(η) 이상 상승하면, 그리고 최소 관찰 기간(n_min)을 충족했으면 풀 전체를 미사용 태스크로 교체한다. 이때 모델 가중치는 그대로 이어지며 학습 템플릿이나 샘플링 비율은 바뀌지 않는다. 교체 풀은 고정된 태스크 패밀리 비율(기하/차트/표/개수) 하에서 무작위로 뽑는다.

실험 설정 및 결과

Qwen3-VL-8B-Instruct와 MiMo-VL-7B-SFT를 대상으로, 11개 전체 벤치마크(MathVerse, MathVision, MMMU(-Pro), ChartQA, PhyX, VisNumBench, MMSI, SCEMQA-MC 등)의 평균 정확도(Macro11)로 평가했다. A-RSI, Frontier(난이도 프런티어 선택), Periodic(2윈도우마다 교체), Continuous(매 윈도우 교체), No-Refresh(교체 없음) 등 5가지 전략을 비교했다. - Qwen에서 A-RSI는 초기화 체크포인트(St, 57.77)에서 8개 연속 윈도우와 800개의 신규 태스크만으로 61.05까지 향상시켰다. 매 윈도우마다 교체하는 Continuous는 3,200개 태스크를 쓰고도 60.64에 그쳤고, No-Refresh는 S31에서 학습 상태 점검(health gate)에 실패해 중단되었다. - 동일 업데이트 지점(S23)에서 A-RSI(60.40)는 기존 풀 계속 학습(58.35)보다 +2.05점 높았다. - MiMo에서도 S0(59.08)에서 60.71로 향상되었으며, 동일한 교체 규칙이 모델별·단계별로 "교체"와 "유지" 판단을 다르게 내리는 것이 확인되었다(MiMo는 두 번째 교체 풀에서 신호가 거의 유지되어 교체하지 않음). - 난이도 기반 선택(Frontier, 적응형 난이도 등)은 무작위 선택보다 더 좋지 않았고, 여러 실패우선·학습가능대역 등 대체 선택 규칙도 무작위 대비 성능이 낮았다(Table 5). - 출력 토큰 한도를 4096에서 8192로 늘렸을 때 A-RSI는 기존 성능 향상분의 80%를 유지했지만, 비교 대상인 MM-Zero v5는 59%만 유지했다 — 즉 A-RSI의 개선은 단순히 응답을 끝까지 완성시켜주는 효과(길이 편향)에 덜 의존한다는 분석이다. - 보상 설계에 대한 통제된 스트레스 테스트에서 정답 보상의 서열이 보조 보상으로 역전되지 않음을 확인했고, 1,000개 생성 태스크를 독립적으로 재계산해 정답/이미지 해시가 모두 일치함을 검증했다. 다만 정답 채커(answer checker)에서 선택형 문제의 일부 파싱 취약점(16,000건 중 220건)도 함께 보고했다.

한계점

  • 각 실험 arm은 1회씩만 학습되어 통계적 유의성 검증이 부족하며, No-Refresh는 S31에서 중단되어 예정된 S32 비교가 누락되었다.
  • 첫 교체 시점이 기존 로그를 참고해 설정되어, "학습 로그 기반 타이밍"의 효과와 "신선한 태스크 사용" 효과가 서로 뒤섞여 있어 완전히 분리되지 않는다(고정된 3윈도우 스케줄과의 무작위 대조군이 없음).
  • MiMo에 적용된 교체 풀은 Qwen의 난이도 기준으로 선택되었기 때문에, 모델 간 전이 가능성에 대한 결론은 제한적이다.
  • 고정된 프로그램 라이브러리는 기하·차트·표·개수 세기만 다루며 함수 그래프, 수치 추정, 공간 추론 등은 포함하지 않아 생성 가능한 태스크의 다양성이 제한적이다.

시사점

이 논문은 "자기개선 루프가 언제 멈추는가"라는, 상대적으로 덜 주목받은 질문에 초점을 맞춰 간단하지만 효과적인 해법(학습 로그 기반 신호 감지 + 무작위 풀 교체)을 제시했다는 점에서 의미가 있다. 복잡한 난이도 추정이나 적응형 커리큘럼보다 오히려 "언제 바꿀지"를 학습 로그로 판단하고 "무엇으로 바꿀지"는 단순 무작위로 처리하는 쪽이 더 적은 데이터로 더 좋은 성능을 냈다는 결과는, 제로데이터(zero-data) 자기개선 시스템 설계에서 데이터 생성의 정교함보다 교체 타이밍 감지와 정답 검증 가능성이 더 중요할 수 있음을 보여준다. 또한 평가 시 출력 길이 한도에 따라 겉보기 성능 향상이 과대평가될 수 있다는 점을 지적한 분석은, 향후 RSI 및 RLVR 계열 연구에서 벤치마크 평가 설계를 재검토할 필요성을 시사한다.
