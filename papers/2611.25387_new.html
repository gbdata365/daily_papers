TuringSpace: Grounding Spatial Intelligence in Action with Interactive CAPTCHAs

튜링스페이스: 상호작용형 캡차로 공간지능을 행동에 접지하기

클릭·드래그로 상호작용하며 풀어야 하는 125개의 합성 웹 CAPTCHA로 구성된 TuringSpace 벤치마크/학습 환경을 제안해, 멀티모달 대형언어모델(MLLM)의 공간지능을 "행동을 통한 루프"로 평가하고, 이 환경에서 생성한 궤적으로 파인튜닝하면 모델이 실제 CAPTCHA·공간이해·로봇 벤치마크로도 전이되는 공간 능력을 학습할 수 있음을 보였다.

한 줄 요약

클릭·드래그로 상호작용하며 풀어야 하는 125개의 합성 웹 CAPTCHA로 구성된 TuringSpace 벤치마크/학습 환경을 제안해, 멀티모달 대형언어모델(MLLM)의 공간지능을 "행동을 통한 루프"로 평가하고, 이 환경에서 생성한 궤적으로 파인튜닝하면 모델이 실제 CAPTCHA·공간이해·로봇 벤치마크로도 전이되는 공간 능력을 학습할 수 있음을 보였다.

배경 및 문제의식

사람은 2D 화면 뒤의 3D 구조를 추론하고, 행동이 장면을 어떻게 바꿀지 예측하며, 결과를 본 뒤 스스로 수정하는 방식으로 공간을 이해한다. 기존 공간 이해 벤치마크는 대부분 정적 이미지·영상에 대한 객관식 질문으로만 구성되어 있어 모델이 실제로 "행동"하도록 요구하지 않으며, 기존 CAPTCHA 벤치마크는 공간 추론을 거의 요구하지 않거나(단순 텍스트·슬라이더 조작), 행동을 허용하더라도 "좌회전"과 같은 텍스트 명령이나 DOM에 노출된 라벨을 고르는 방식이라 실제 화면 이해 능력을 측정하지 못한다.

핵심 기여

  • 다섯 가지 공간 능력(공간 관계 이해, 폐루프 시각 조작, 다단계 계획·시뮬레이션, 심적 변환, 시공간 추론)을 다루는 125개의 상호작용형 CAPTCHA로 구성된 TuringSpace-Bench 제안.
  • 각 과제가 체커(checker)와 오라클(oracle) 솔루션을 갖춘 프로그램으로 구현되어, 시드(seed)마다 새로운 인스턴스를 무한히 생성할 수 있는 학습용 환경 TuringSpace-Gym 구축.
  • TuringSpace-Gym에서 생성한 55,000개의 검증된 궤적으로 Qwen3.5-9B를 파인튜닝한 TuringSpace-9B가 벤치마크 성능뿐 아니라 CAPTCHA·공간이해·로봇 포인팅 등 7개의 분포 외(OOD) 벤치마크 전반에서도 성능 향상을 보임을 입증.
  • 프론티어 MLLM들의 실패를 심층 분석해, 대부분의 실패가 화면을 잘못 읽는 지각 오류에서 비롯되고, 모델이 길게 추론해도 오히려 잘못된 믿음을 뒷받침하는 환각적 근거를 만들어내는 경향이 있음을 규명.

방법론

각 과제는 시드와 자산 풀(에셋 풀)을 입력받아 초기 화면·지시문·체커·오라클 행동열을 생성하는 프로그램(생성기)으로 구현된다. Claude Code(코딩 에이전트)가 과제 프로그램을 작성하고, 100개 시드에 대한 자동 검증, 다른 모델의 플레이 검토, 두 명의 저자가 직접 플레이하는 3단계 리뷰를 거쳐 품질을 보증한다. 벤치마크와 학습 데이터는 서로 다른 시드와 서로 겹치지 않는 자산 풀을 사용해 데이터 누출을 방지했다. 오라클 솔루션을 재생해 얻은 (지시문, 관찰, 행동) 궤적으로 Qwen3.5-9B를 "생각 없이(thinking-off)" 설정에서 다음 토큰 예측 방식의 교차 엔트로피 손실로 파인튜닝해 TuringSpace-9B를 만들었으며, 모든 모델은 OSWorld 방식의 컴퓨터 사용 에이전트 프로토콜로 동일하게 평가되었다.

실험 설정 및 결과

16개의 MLLM(독점 모델 7종, 오픈웨이트 모델 4종, GUI 전용 에이전트 5종)과 사람(3명)을 TuringSpace-Bench에서 비교한 결과, 사람은 평균 94.1%를 풀었으나 최고 성능 모델인 GPT-6 Astra도 74.1%에 그쳤고, 최고 오픈웨이트 모델 Kimi K3는 32.0%에 머물렀다. 세 시드 모두를 맞혀야 하는 pass^3 기준에서는 격차가 더 커져 GPT-6 Astra도 58.4%로 떨어졌다(사람 84.8%). TuringSpace-Gym으로 파인튜닝한 TuringSpace-9B는 pass@1을 1.6%에서 33.1%로 끌어올려 Kimi K3(2.8조 파라미터)와 Qwen3.8-Max(32.0%)를 능가했으며, ReCAP·Open CaptchaWorld 등 기존 CAPTCHA 벤치마크(+17.2%p, +10.0%p), SpatialViz-Bench(+6.1%p), 실제 실내 영상 기반 VSI-Bench(+9.9%p), 로봇 조작 관련 RefSpatial-Bench·VABench-Point·RoboAfford-Eval(각각 +19.8%p, +7.4%p, +12.2%p)까지 7개 OOD 벤치마크 전부에서 성능이 향상되었다. 추가 분석에서는 추론 토큰을 늘리는 것 자체보다 "어디서 더 생각할지" 아는 능력이 모델 강도와 더 상관있었고(r=0.82), 실패 사례의 상당수가 초기 2턴 내에 형성된 잘못된 믿음이 이후 추론 내내 유지·정당화되는 패턴(관찰 환각, 사전 지식에 의존한 추측, 불확실한 상태에서의 맹목적 제출)으로 설명되었다.

한계점

프론티어 모델 중에서도 특히 시공간 추론(움직이는 객체·장면 추적) 범주가 가장 어려웠으며, 가장 강한 모델들도 이 범주에서는 서로 간의 성능 차이가 좁아지는 등 시간에 따라 변화하는 장면을 따라가는 능력은 전반적으로 미흡했다. 또한 학습 데이터가 합성 웹 환경에서 생성되므로, 실제 세계로의 전이가 입증되었다고는 해도 합성 데이터의 다양성과 실제 환경 간 간극(sim-to-real gap)에 대한 정량적 한계는 논문에 명시되지 않음.

시사점

정적 객관식 질문 대신 검증 가능한 행동(클릭·드래그) 루프로 공간 이해를 평가·학습시키는 방식이, 비용이 큰 실제 로봇 데이터 없이도 공간지능을 확장 가능하게(scalable) 가르칠 수 있는 대안이 될 수 있으며, 이렇게 학습된 능력이 실제 CAPTCHA·실내 영상·로봇 작업에도 전이된다는 점에서 GUI 상호작용 기반 학습이 임바디드 AI 일반화에 기여할 잠재력을 시사한다.
