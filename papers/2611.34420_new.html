DocSEAM: Bidirectional Cross-Page Encoding for Multi-Page Document Understanding

닥심: 멀티페이지 문서 이해를 위한 양방향 교차-페이지 인코딩

멀티페이지 문서 비전-언어 모델(VLM)이 각 페이지를 독립적으로 인코딩하면서 생기는 "페이지 경계 단절" 문제를, 인접 페이지 정보를 미리 섞어주는 경량 모듈 DocSEAM으로 해결해 10B급 이하 오픈웨이트 모델 중 최고 성능을 달성했다.

한 줄 요약

멀티페이지 문서 비전-언어 모델(VLM)이 각 페이지를 독립적으로 인코딩하면서 생기는 "페이지 경계 단절" 문제를, 인접 페이지 정보를 미리 섞어주는 경량 모듈 DocSEAM으로 해결해 10B급 이하 오픈웨이트 모델 중 최고 성능을 달성했다.

배경 및 문제의식

기존 멀티페이지 문서 VLM은 각 페이지를 비전 인코더로 독립적으로 인코딩한 뒤 시각 토큰을 이어 붙여 언어모델(LLM)에 넣는다. 그러나 표나 문단이 페이지 경계를 넘어 이어지는 경우가 흔해, 비전 인코더가 다음 페이지 내용을 보지 못한 채 표현을 확정해버리면 LLM이 이미 형성된(손실된) 토큰으로부터 불연속성을 뒤늦게 보완해야 한다. 저자들은 동일한 문서를 다시 페이지 분할(re-pagination)해 경계가 표·문단 중간을 자르도록 바꾸는 진단 실험을 설계했고, 이 경우 기존 페이지 단위 VLM의 성능이 의미 내용은 그대로임에도 뚜렷하게 하락함을 보였다(이를 "페이지 분할 민감성"이라 명명).

핵심 기여

  1. 페이지 분할 민감성을 기존 문서 VLM의 약점으로 규명하고, 이를 정량적으로 측정하는 통제된 재분할(re-pagination) 진단법을 설계했다.
  2. DocSEAM(Document Selective Enrichment via Anchored Masking)을 제안: 사전학습된 비전 인코더와 LLM 사이에 삽입되는 경량 모듈로, 중심-anchored 마스킹 셀프어텐션과 방향성 salience 게이트를 통해 인접 페이지 간 지역적 문맥을 시각 표현에 주입한다.
  3. DocSEAM을 먼저 지도학습 기반 cross-page warm-up으로 학습시킨 뒤 고정(freeze)하고 downstream 멀티페이지 파인튜닝을 진행하는 2단계 학습 전략을 설계했다.

방법론

각 페이지 p에 대해 이전 페이지(p-1), 자신(p), 다음 페이지(p+1)로 구성된 로컬 triplet을 구성하고, 이를 이어붙인 뒤 소수의 셀프어텐션 레이어를 적용한다. 이때 중심 페이지만 양쪽 이웃에 접근할 수 있고 이전·다음 페이지끼리는 직접 상호작용하지 못하도록 막는 "중심-anchored 어텐션 마스크"를 사용해, 모든 교차-페이지 정보가 중심 페이지를 거쳐 흐르게 하고 인접하지 않은 페이지 간 정보 누출을 방지한다. 또한 토큰별로 4개의 학습 가능한 "방향성 salience 게이트"를 두어 교차-페이지 어텐션이 유용한 지점을 모델이 스스로 학습하게 한다. 이 모듈은 약 2억3500만 개 파라미터(9B 백본의 약 2.6%)를 추가하며, 비전 인코더 자체나 시각 토큰 수는 바꾸지 않고, no-op으로 초기화되어 학습이 기존 사전학습 모델의 "안전한" 상태에서 시작되도록 한다.

실험 설정 및 결과

Qwen2.5-VL-7B, Qwen3.5-9B, Gemma3-4B 등 4B~9B 규모의 백본에 DocSEAM을 적용해 MMLongBench-Doc, DUDE, LongDocURL, SlideVQA, MP-DocVQA 등 5개 멀티페이지 문서 VQA 벤치마크에서 평가했다. 9B 파라미터 모델 기준 DocSEAM은 10B 이하 오픈웨이트 모델 중 최고 성능(SOTA)을 기록했으며, 교차-페이지 범위(span) 위치 추정 정확도를 SFT 베이스라인보다 20.8점 개선했다. 통제된 재분할 실험에서는 구조를 보존하는 분할과 구조를 깨는 분할 간 성능 차이를 MMLongBench-Doc과 LongDocURL에서 각각 0.8점, 0.7점까지 줄여 페이지 분할 민감성을 크게 완화했다. 다만 효과는 백본과 과제에 따라 차이가 있었는데, 예를 들어 Gemma3-4B 백본에서는 SlideVQA 성능이 SFT 대비 소폭 하락했고 MMLongBench-Doc에서는 제로샷 대비 개선이 미미했다.

한계점

백본 실험은 4B, 7B, 9B 규모로만 수행되었으며 더 큰 백본에는 적용·검증되지 않았다. 또한 DocSEAM의 효과는 백본과 과제 조합에 따라 편차가 있어, 일부 조합(예: 작은 백본 + 특정 벤치마크)에서는 개선이 제한적이거나 기존 SFT 대비 이점이 작았다.

시사점

비전 인코더 단계에서 인접 페이지 간 지역적 문맥을 미리 섞어주는 것이, 언어모델에만 교차-페이지 추론을 전적으로 의존하는 기존 방식보다 더 견고한 멀티페이지 문서 이해를 가능하게 한다는 점을 보여준다. 시각 토큰 수를 늘리지 않고도 적용 가능한 경량 모듈 설계는 실제 문서 이해 파이프라인에 비교적 쉽게 통합될 수 있는 실용적 방향을 제시한다.
