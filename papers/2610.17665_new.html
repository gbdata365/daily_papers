RoTA-Bench: Evaluating 3D Spatial Reasoning through Interactive Projection Alignment

RoTA-Bench: 인터랙티브 투영 정렬을 통한 3D 공간 추론 평가

한 줄 요약

목표 실루엣과 일치하도록 3D 객체를 반복적으로 회전시키는 인터랙티브 투영 정렬 과제를 통해, 시각-언어모델(VLM)이 2D 관측을 정밀한 3D 행동으로 전환할 수 있는지를 평가하는 RoTA-Bench를 제안한다.

배경 및 문제의식

공간 지각은 인지과학에서 핵심 능력으로 다뤄지며, 2D 투영에서 3D 형태를 복원하는 능력(정신적 회전 등)은 시각-언어모델이 임베디드 에이전트로 활용되는 데 필수적이다. 그러나 기존 벤치마크는 두 갈래로 나뉘어 한계가 있다: (1) 고정된 이미지에 대한 정적 질의응답 벤치마크는 행동 실행이나 폐루프 피드백이 전혀 없고, (2) 소프트웨어 인터페이스·미로·슬라이딩 퍼즐 등 기존 인터랙티브 벤치마크는 고수준 계획이나 2D 평면 내 경로 탐색에 치중해, 3차원 방향·자세를 시각적으로 추론해 행동으로 옮기는 능력을 직접 평가하지 못한다.

핵심 기여

  1. 2D 아이콘으로부터 실루엣을 보존하는 3D 객체를 자동 생성하고 가역적(reversible) 초기화로 풀이 가능성을 보장하는 파이프라인을 구축해, 674개 과제와 계층화된 100개 테스트셋을 만들었다.
  2. GPT-5.6-Sol이 과제의 17%만 해결하는 데 그친 반면 20명의 학부생 참가자는 테스트셋을 4회 수행하며 100% 성공률을 보여, 상당한 인간-모델 격차를 드러냈다.
  3. 이미지 공간(실루엣 중첩)에서의 개선과 실제 자세(pose) 공간에서의 개선이 어긋날 수 있음을 보이고(모델 19.4% vs 인간 10.9%), 상호작용 히스토리를 제거하면 모델 행동의 96.8%가 거친 30도 단위 회전으로 퇴화함을 밝혔다.

방법론

각 과제는 원점에 중심을 둔 3D 객체 G, 목표 자세(정면, R*=I3), 현재 자세 Rt로 정의된다. 에이전트는 매 스텝 목표 실루엣 I*, 깊이 음영 보조 뷰 Vt, 현재 투영 It를 관측하고, 3축(피치/요/롤)×2방향×4각도(1°,5°,10°,30°)로 구성된 24개의 이산 회전 행동 중 하나를 선택한다. 목표와의 일치 여부는 투영 IoU(It∩I*/It∪I*)가 0.90 이상인지로 판정한다. 과제 생성은 2D 벡터 아이콘(Game-icons 오픈소스 라이브러리)을 구형 외피 내에서 돌출(extrusion)시켜 3D화하고, 6~16회의 가역적 30도 회전으로 초기 자세를 만들어 역순으로 풀면 반드시 해가 존재함을 보장한다. 참조 경로는 포즈 기반 빔 탐색과 30도 제한 BFS로 구하며, 경로 길이별 계층화 샘플링으로 100개 테스트 과제를 선정한다.

실험 설정 및 결과

GPT-5.6-Sol, GPT-5.6-Terra/Luna, Gemini 3.6 Flash, Claude Opus 5/Sonnet 5, Qwen 3.7 Plus, GPT-6-Astra, SpatioLM 등 9개 VLM과 ReAct·Magentic 에이전트 프레임워크, 20명의 인간 참가자를 비교했다. 최고 성능 모델인 GPT-5.6-Sol의 성공률은 17.0%(최종 IoU 0.598)에 불과했고, Claude Sonnet 5/Opus 5·Qwen 3.7 Plus는 성공률 0%로 균일 무작위 탐색(0.473)과 큰 차이가 없었다. 반면 인간은 100% 성공률, 평균 최종 IoU 0.923을 기록했다. 방향 선택의 "유효 방향 비율"에서도 GPT-5.6-Sol은 58.75%로 인간(83.91%)보다 크게 낮았고, 각도 선택 오차(angle gap)도 인간(2.99°)의 두 배 이상(6.49°)이었다. 상호작용 히스토리를 제거하는 제거 실험에서는 성공 과제가 5/30에서 0/30으로 떨어졌고, 30도 회전 비율이 62.75%에서 96.76%로 급증했다.

한계점

3D 객체가 제한된 2D 아이콘 집합에서 돌출 생성되어 형태 다양성이 제약되며 복잡한 실제 3D 형태를 충분히 대표하지 못한다. 각 과제는 이산 회전만 있는 단일 목표로 구성되어, 연속적인 물리 환경에 비해 상호작용 동역학이 단순화되어 있다. 저자들은 생성 모델을 활용한 아이콘·메쉬 다양화, 연속 회전 제어, 외부 가림(occlusion), 다중 객체 정렬 과제로의 확장을 향후 과제로 제시했다.

시사점

현재 선도 VLM들은 이미지 공간의 즉각적 중첩 개선에만 치중하고 실제 3D 자세 오차를 함께 고려하는 데는 취약하며, 다중 턴 상호작용 히스토리를 세밀한 행동 조정에 제대로 활용하지 못한다. 이는 단일 이미지 인식·매칭을 넘어 "시각적 증거를 정밀한 3D 제어로 변환"하는 능력이 현재 VLM의 중요한 약점임을 보여주며, 체화 에이전트나 로봇 조작처럼 폐루프 시각 피드백이 필요한 응용에서 추가 개선이 필요함을 시사한다.
