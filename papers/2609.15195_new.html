HarnessVLN: Unifying Training-Free Embodied Navigation through an Agent Harness

하니스VLN: 에이전트 하니스를 통한 학습 불필요 임바디드 내비게이션 통합

사전 학습된 멀티모달 대형언어모델(MLLM)을 플래너로 쓰되, "Agent Harness(에이전트 하니스)"라는 통합 실행·검증 계층이 인지·검색·그라운딩·내비게이션·복구·종료를 조율함으로써, 별도의 내비게이션 학습 없이도 경로 지시 추종(instruction-following)과 목표 물체 탐색(object-goal navigation)을 하나의 프레임워크로 동시에 잘 해내는 학습 불필요(zero-shot, training-free) 임바디드 내비게이션 시스템이다.

한 줄 요약

사전 학습된 멀티모달 대형언어모델(MLLM)을 플래너로 쓰되, "Agent Harness(에이전트 하니스)"라는 통합 실행·검증 계층이 인지·검색·그라운딩·내비게이션·복구·종료를 조율함으로써, 별도의 내비게이션 학습 없이도 경로 지시 추종(instruction-following)과 목표 물체 탐색(object-goal navigation)을 하나의 프레임워크로 동시에 잘 해내는 학습 불필요(zero-shot, training-free) 임바디드 내비게이션 시스템이다.

배경 및 문제의식

  • 임바디드 내비게이션은 에이전트가 시각 관측을 해석하고, 공간 지식을 누적하며, 지시를 따르거나 목표 물체를 찾기 위한 행동을 실행해야 하는 과제이다.
  • 학습 기반(training-based) 방법은 특정 과제의 시연 데이터나 대규모 궤적 데이터로 학습되어 효과적이지만, 새로운 과제나 환경으로 확장하려면 추가 데이터와 재학습이 필요해 일반화에 한계가 있다.
  • MLLM을 활용한 학습 불필요(training-free) 방법들은 별도 학습 없이 의미론적 추론 능력을 활용할 수 있지만, 대부분 MLLM을 특정 과제 파이프라인 속의 "플래너" 역할로만 사용한다. 이 경우 플래너가 제안한 행동이 실제 공간적 증거, 과제 진행 상황, 실행 실패와 어떻게 맞물리는지를 관리하는 메커니즘이 부족하다.
  • 그 결과 오래된 관측, 도달 불가능한 목표, 실행 실패 등이 누적되면 플래닝이 실제 상태와 어긋나고, 반복 시도나 잘못된 종료(termination)로 이어지는 문제가 발생한다.

핵심 기여

  1. HarnessVLN 제안: 공유된 Agent Harness를 통해 도구(tool), 플래너 제안 검증, 실행 피드백을 조율하며, instruction-following과 object-goal navigation 두 과제 계열을 하나의 프로토콜로 지원하는 학습 불필요 내비게이션 프레임워크.
  2. 계층적 이벤트 메모리(Hierarchical Event Memory)와 영속적 시공간 그래프(Spatiotemporal Graph, ST Graph)의 통합: 제안 검증과 피드백 기반 상태 갱신을 지원하여, 증거에 기반한 실행, 실패 복구, 과제 완료 판정을 가능하게 함.
  3. 네 가지 벤치마크에서 기존 학습 불필요 방법 대비 성능 향상을 입증하고, 휴머노이드 로봇에 프레임워크를 배포하여 실세계 내비게이션 적용 가능성을 시연.

방법론

  • Agent Harness 구조: 매 의사결정 시점 t마다 상태 S_t = (과제 명세 x, 현재 RGB-D 관측 및 지역 지도 ω_t, 에이전트 자세 p_t, 과제 진행 상황 z_t, 계층적 이벤트 메모리 M_t, ST 그래프 G_t)를 유지한다. instruction-following에서는 z_t가 현재 경로 구간, 충족된 이동 제약, 관측된 랜드마크를 기록하고, object-goal navigation에서는 탐색된 영역, 후보 목표 가설, 검증 상태를 추적한다.
  • 통합 도구 인터페이스: observe(관측), observe_panorama(파노라마 관측), retrieve_memory(메모리·그래프 검색), ground_target(서브골을 후보 지점으로 그라운딩), query_depth(깊이 추정), navigate_to(검증된 목표로 이동 실행), backtrack(이전 방문 지점으로 복귀), request_stop(종료 검증) 등 8개 핵심 도구를 표준화된 입출력 규약으로 노출한다. Harness는 도구 호출 전에 근거(evidence)의 출처와 최신성, 목표의 기하학적 실현 가능성, 활성 서브골과의 일관성을 검증한다.
  • 계층적 이벤트 메모리: (1) 작업 메모리(working memory) - 현재 관측, 제한된 파노라마 이력, 활성 목표 가설, 최근 도구 피드백을 담아 단기 맥락만 유지; (2) 진행 메모리(progress memory) - 서브골을 pending/active/completed/blocked 네 상태로 관리하며 완료는 반드시 관측이나 도구 성공 결과로 뒷받침되어야 함; (3) 반성 메모리(reflection memory) - 도달 불가 목표, 그라운딩 불일치, 충돌, 진행 정체, 백트래킹 실패, 정지 요청 거부 등 완전한 실행 이벤트 기록을 저장.
  • ST 그래프: 장소(place) 노드와 개체(entity) 노드, 유형화된 공간 관계, 타임스탬프 및 실패 주석으로 구성된 영속적 그래프. 매 결정 전에 의미적 관련성 R, 최신성 C, 공간 현저성 A, 실패 패널티 P를 결합한 점수 함수(s(v_i|g_t) = R + λ_rec·C + λ_sal·A - λ_fail·P)로 장소 노드 순위를 매겨 검색 집합을 압축, 궤적이 길어져도 MLLM 컨텍스트 크기가 늘지 않도록 함.
  • 그라운딩된 실행과 증거 기반 종료: MLLM이 제안한 의미론적 명령(command)을 Harness가 현재 관측과 ST 그래프로부터 목표를 그라운딩하고, 교체 가능한 Navigation Executor(경로계획·저수준 제어 담당, FMM 플래너와 계단 등에서는 NavDP 사용)가 실제 이동을 수행한다. 정지(stop) 요청은 의미적(F_semantic)·기하학적(F_geometric)·진행(F_progress) 세 조건을 모두 충족해야 승인되며, 거부된 요청은 이벤트 메모리에 기록되어 추가 관측·목표 정교화·백트래킹을 유발한다.
  • 플래너로는 GPT-5.5(instruction-following) 및 GPT-5.6-luna(object-goal navigation)를 사용했고, 개방어휘 인지에는 GroundingDINO와 SAM을 활용했다.

실험 설정 및 결과

  • 평가 벤치마크: instruction-following은 MP3D 기반 VLN-CE R2R, RxR(NE, OSR, SR, SPL, nDTW 등 지표 사용), object-goal navigation은 HM3D-Semantics v0.2 기반 HM3D-v2(고정 물체 범주, 1,000 에피소드)와 HM3D-OVON(개방어휘 목표, 3,000 에피소드).
  • 주요 결과: HarnessVLN은 R2R 60.8% SR, RxR 53.9% SR, HM3D-v2 76.0% SR, HM3D-OVON 59.3% SR을 달성하여 기존 학습 불필요 최고 성능 대비 각각 5.8, 12.1, 1.6, 9.1 퍼센트포인트 향상되었다. 일부 지표에서는 학습 기반(supervised) 최신 방법들과도 견줄 만한 수준을 보였다.
  • 소거 실험(ablation): 이벤트 메모리, ST 그래프, 정지 검증(stop validation)을 순차적으로 추가하며 R2R과 HM3D-OVON 100개 에피소드 부분집합에서 평가한 결과, 세 구성요소를 모두 사용했을 때 기본 에이전트 대비 SR이 각각 18.0, 10.0 퍼센트포인트 향상되었고, 최종 성공률(SR)과 오라클 성공률(OSR) 간 격차도 크게 줄어들어 각 구성요소의 기여가 확인되었다.
  • 실세계 배포: AgiBot A3U 휴머노이드 로봇(신장 1.74m, 3D LiDAR·RGB-D·어안 카메라 장착, NVIDIA Thor 기반)에 Qwen-3.8-27B를 플래너로 사용해 배포하였고, 순차 지시 추종, 개방어휘 물체 탐색, 경로 추종과 물체 탐색이 결합된 복합 과제 세 가지 실세계 시나리오에서 동일한 Harness 프로토콜로 성공적으로 작동함을 시연했다.

한계점

  • 논문은 현재 Harness가 사전 정의된 오케스트레이션과 검증 규칙에 의존한다는 점을 명시적 한계로 언급하며, 향후에는 개방 환경에서의 상호작용을 통해 스스로 진화(self-evolving)하는 메커니즘을 탐구할 계획이라고 밝혔다.
  • HM3D-v2에서는 SPL(경로 효율성 지표)이 최고 성능은 아니었으며(37.9%), 일부 학습 기반 방법에 비해 경로 효율성 면에서는 열세를 보였다.
  • 정지 검증 강화가 HM3D-OVON에서는 OSR-SR 격차를 오히려 소폭 늘리고 SPL을 떨어뜨리는 등, 완료 판정 개선이 모든 과제·지표에서 균일하게 효율성이나 종료 행동을 향상시키지는 않았다고 저자들이 밝혔다.

시사점

  • MLLM을 단순 플래너로 쓰는 것을 넘어, 공간적 증거와 실행 이력을 명시적으로 검증·갱신하는 실행 계층(Harness)을 두는 것이 학습 없는 내비게이션 시스템의 신뢰성과 범용성을 크게 높일 수 있음을 보여준다.
  • 동일한 프로토콜로 instruction-following과 object-goal navigation처럼 서로 다른 과제 정의를 통합할 수 있다는 점은, 향후 범용 임바디드 에이전트 설계에서 과제별 전용 파이프라인 대신 공유 가능한 조율 계층을 채택하는 방향을 시사한다.
  • 시뮬레이션 벤치마크뿐 아니라 실제 휴머노이드 로봇에서도 동작이 검증되어, 학습 불필요 접근법이 실세계 로봇 배포에 실질적으로 적용 가능하다는 근거를 제공한다.
