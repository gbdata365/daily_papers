Vela: User Behavior as Supervision Sparks LLM Intelligence

벨라: 사용자 행동을 지도 신호로 활용한 LLM 지능 향상

실제 사용자의 행동 기록(조회, 검색, 구매, 게시, 팔로우, 비선호 표시 등)을 LLM 학습의 지도 신호로 변환하는 "user behavior as supervision" 패러다임을 제안하고, 이를 구현한 프레임워크 Vela로 Qwen3.6-35B-A3B를 파인튜닝해 사용자 이해 능력뿐 아니라 범용 추론·지시 따르기 능력까지 함께 끌어올렸다.

한 줄 요약

실제 사용자의 행동 기록(조회, 검색, 구매, 게시, 팔로우, 비선호 표시 등)을 LLM 학습의 지도 신호로 변환하는 "user behavior as supervision" 패러다임을 제안하고, 이를 구현한 프레임워크 Vela로 Qwen3.6-35B-A3B를 파인튜닝해 사용자 이해 능력뿐 아니라 범용 추론·지시 따르기 능력까지 함께 끌어올렸다.

배경 및 문제의식

개인 비서, 추천·광고 시스템처럼 실제 서비스에 배포되는 LLM은 한 사람의 수주~수년에 걸친 행동 이력에서 선호·의도·미래 행동을 추론하는 "사용자 차원의 지능"을 요구한다. 그러나 현재 LLM은 웹 문서, 코드, 합성 데이터 등 정적 텍스트로만 학습되어 사용자 행동이 시간에 따라 변하는 양상을 포착하지 못하며, 긴 이력이 주어져도 평균적 사용자상으로 수렴하거나 개인화에 취약하다는 한계가 보고되어 왔다. 반면 콘텐츠 플랫폼과 개인 비서 에이전트에는 이미 대규모의 실제 사용자 행동 기록이 존재하며, 이는 사용자가 실제로 취한 행동이라는 자연스러운 지도 신호를 제공한다. 저자들은 이 미활용 자원을 체계적으로 학습 신호로 전환하는 방법이 부재하다는 점을 문제로 제기한다.

핵심 기여

  1. 사용자의 관찰된 행동을 지도 신호로 삼아 LLM을 학습시키는 새로운 패러다임 "user behavior as supervision" 제안.
  2. 익명화된 10만 명의 실제 행동 기록을 91개의 과제 템플릿을 통해 10만 개의 학습 가능한 태스크·궤적으로 변환하는 프레임워크 Vela 공개.
  3. 난이도 기반 필터링과 궤적 채택 기준을 통해 약 7만 5천 개의 고품질 학습 샘플을 선별하고, 이를 통해 사용자 관련 과제와 일반 벤치마크 모두에서 성능 향상을 입증.
  4. 학습 데이터 규모를 늘릴수록 사용자 관련·일반 성능이 함께 개선됨을 보이고, 이 방식으로 학습한 모델이 이후 강화학습(RL)에서도 더 나은 출발점이 됨을 실험적으로 확인.

방법론

Vela는 대형 소셜 미디어 플랫폼에서 수집한 10만 명 사용자의 행동 이력(조회·검색·구매·게시·팔로우·비선호)을 이름·연락처·계정 ID 등 개인식별정보를 제거한 뒤 사용한다. 각 사용자의 이력을 시간순으로 나열하고 특정 시점을 기준으로 "보이는 과거(visible history)"와 "숨겨진 미래(hidden future)"로 분할한다. 91개의 질문 템플릿은 두 계열(Predictive: 정답이 숨겨진 미래 행동으로부터 결정적으로 추출되는 Objective/Open-prediction 질문, Rubric: 과제별 평가 기준으로 채점되는 Open/Attribution 질문)로 구성되며, 하나의 태스크는 여러 질문을 묶어 구성된다. LLM 기반 컴포저가 보이는 과거를 바탕으로 구체적 질문과 평가 기준(rubric)을 생성하고, 동일하거나 별도의 LLM 기반 스코어러가 모델의 답변을 숨겨진 미래(Predictive) 또는 과제별 기준(Rubric)과 대조해 0~1 점수를 매긴다. 이렇게 만들어진 10만 개의 후보 태스크에 대해 Qwen3.6-35B-A3B로 4회 응답을 생성해 평균 점수가 0.2~0.8인 중간 난이도 태스크만 남기고(난이도 기반 필터링), 각 태스크에 대해 생성된 여러 궤적 중 난이도 산정 시 평균 점수를 초과하는 최고점 궤적만 채택해 지도학습 코퍼스 Vela-Instruct(약 7만 5천 샘플)와 RL용 코퍼스 Vela-RFT(약 9,375 샘플)를 구성한다. 이를 Qwen3.6-35B-A3B에 파인튜닝하여 Vela-35B-A3B와 Vela-35B-A3B-RFT를 얻는다.

실험 설정 및 결과

평가는 세 그룹으로 나뉜다: (1) 동일한 91개 템플릿으로 구성된 982개의 미공개 태스크로 이루어진 VelaBench(인도메인), (2) PurchaseIntent, ProfileSummary, PersonaBench, AdRecommendation 등 사용자 관련 OOD(분포 외) 벤치마크 4종, (3) AIME 2026, GPQA-Diamond, IFBench, CL-bench, CL-bench Life 등 일반 OOD 벤치마크 5종이다. Vela-35B-A3B는 기반 모델(Qwen3.6-35B-A3B) 대비 VelaBench에서 11.5점, 사용자 관련 OOD 평균에서 6.2점, 일반 OOD 평균에서 4.0점 향상되었으며, 35B 규모임에도 더 큰 DeepSeek-V4-Flash나 Qwen3.8-2.4T-A95B를 VelaBench에서 능가했다. 학습 데이터를 4.7K에서 75K로 늘리는 스케일링 실험에서는 세 벤치마크 그룹 모두 일관되게 성능이 향상되었다. 또한 GSPO를 이용한 강화학습 실험에서, 기반 모델보다 Vela-35B-A3B(SFT 체크포인트)에서 시작한 RL이 VelaBench와 ProfileSummary에서 각각 최대 7.7점 더 높은 최종 성능을 보여, user behavior as supervision이 RL을 위한 더 나은 출발점을 제공함을 확인했다. 난이도 기반 필터링 유무를 비교한 제거 실험에서도 필터링 적용 시 사용자 관련 OOD 벤치마크에서 평균 1.1점의 추가 향상이 관찰되었다.

한계점

논문은 이 연구가 단일 대형 소셜 미디어 플랫폼의 익명화된 행동 데이터에 기반하고 있어 다른 도메인이나 플랫폼으로의 일반화 가능성은 추가 검증이 필요하다는 점, 그리고 결론부에서 "더 많은 실제 과제와 시나리오로 확장"하는 것을 향후 과제로 언급하고 있어 현재 다루는 행동 범주(조회·검색·구매·게시·팔로우·비선호)와 91개 템플릿이 실제 사용자 행동의 전체 스펙트럼을 포괄하지는 못함을 시사한다. 그 외 구체적인 한계(예: 편향, 실패 사례 분석 등)는 논문에 명시되지 않음.

시사점

이 연구는 정적인 텍스트나 합성 데이터에 의존하던 기존 LLM 학습 방식에서 벗어나, 실제 사용자의 관찰된 행동 자체를 대규모의 자연스러운 지도 신호로 활용할 수 있음을 보여준다. 이는 공개 텍스트 데이터가 고갈되어가는 상황에서 LLM 스케일링을 위한 새로운 데이터 소스가 될 수 있으며, 개인화된 추천·광고·개인비서 시스템의 성능을 높이는 동시에 수학·과학 추론, 지시 따르기 같은 범용 능력도 함께 향상시킬 수 있다는 점에서, 사용자 중심 응용과 범용 LLM 지능 개발이 상호 배타적이지 않다는 실증적 근거를 제공한다.
