HarnessEval-W: Agentifying the Evaluation of Visual Worlds

하네스이벨더블유: 시각적 세계 평가의 에이전트화

세계 모델(world model, 상호작용형 비디오 생성 모델)의 평가를 고정된 채점표(rubric) 방식이 아니라, LLM 에이전트 하네스(harness) 패러다임을 적용해 "케이스별로 스킬을 라우팅하고 하위 질문을 서브 에이전트에 위임해 근거를 수집·검증"하는 계층적 에이전틱 평가 파이프라인으로 전환한 벤치마크.

한 줄 요약

세계 모델(world model, 상호작용형 비디오 생성 모델)의 평가를 고정된 채점표(rubric) 방식이 아니라, LLM 에이전트 하네스(harness) 패러다임을 적용해 "케이스별로 스킬을 라우팅하고 하위 질문을 서브 에이전트에 위임해 근거를 수집·검증"하는 계층적 에이전틱 평가 파이프라인으로 전환한 벤치마크.

배경 및 문제의식

  • 기존 비디오/세계 모델 벤치마크(VBench, EvalCrafter, WorldScore 등)는 점수를 산출할 뿐, 왜 그런 점수가 나왔는지 설명하거나 검증할 수 있는 추론 체인을 제공하지 않음(브루트포스 방식 메트릭).
  • 사람은 롤아웃을 볼 때 객체를 추적하고, 물리적 인과관계와 기하학적 제약을 자연스럽게 검증하지만, 이런 워크플로우를 자동화한 벤치마크는 없었음.
  • 세계 모델 평가는 케이스마다 물리적 행위, 시간 구조, 관측 상태가 모두 달라 "하나의 고정 채점표"로는 대응 불가능 → 컨텍스트 의존적 평가가 필요.

핵심 기여

  1. HarnessEval-W 파이프라인: 상위 에이전트가 케이스 컨텍스트를 해석해 적절한 "스킬"로 라우팅 → 각 스킬이 하위 질문(sub-question)으로 분해 → 전용 서브 에이전트가 진단 도구로 근거 수집 → 상위 에이전트가 증거를 검증·집계해 최종 점수와 "증거 트리(evidence tree)"를 산출.
  2. 3개 평가축·8개 세부 항목: Observation Quality(Render Quality, Physical Observation), Transition Correctness(Exploratory/Intentional/Physical Transition), World Persistence(Drift Resistance, Revisit Consistency, Offscreen Evolution) (p.6, Table 1).
  3. 330개 케이스 벤치마크: 6축 구조화 씬 분류(Environment/Foreground/Midground/Scene Density/Appearance/Perspective) + 6개 프로브 패밀리를 기반으로 한 에이전틱 데이터 구축 파이프라인(이미지 생성 → 이미지 기반 액션 플래너 → 별도 검증 에이전트)으로 자동 생성(p.7-8).
  4. 18개 대표 세계 모델 평가: 프롬프트 기반 I2V 생성기, 네이티브 액션 기반, 카메라 포즈 기반 모델을 동일 케이스셋으로 비교하는 리더보드 구축.
  5. 평가자 자체의 신뢰성 검증: 사람 A/B 판단(Bradley-Terry) 대비 정합성, 기존 벤치마크(WBench) 대비 우수성, 반복 실행 안정성을 정량 검증.

방법론

  • 세계 모델 정식화: 과거 관측·행동으로부터 미래 관측 분포를 은닉 상태(hidden state)를 매개로 분해(관측 우도 S, 상태 전이 T, 초기 상태 분포)(p.5, 식 1).
  • 계층적 에이전틱 평가: (1) Case-specific Skill Routing — 케이스 컨텍스트(초기 이미지, 액션 프롬프트, 평가 설정)를 보고 스킬 라이브러리에서 적용 가능한 스킬을 선택하며, 선택/제외 이유를 근거와 함께 기록. 라우팅은 모델과 무관하게 케이스에만 의존해 공정성 보장. (2) Sub-agent Reasoning — 예: Intentional Change Verifier는 Target Visible, Target Specificity, No Extra Event, Final State, Anchor Preservation, Judgeable 등 8개 하위 질문으로 분해되고, 각각 전용 서브 에이전트가 이산 점수+진단을 반환, 상위 스킬 에이전트가 이를 집계(p.6-7, Figure 3).
  • 케이스 구축 파이프라인: 씬 taxonomy 샘플링 → 프로브 패밀리 할당 → 이미지 생성기 → 이미지 기반 LLM 플래너(액션 지시문·카메라 궤적·제어 시퀀스 산출, 이미지에 없는 개체 도입 불가) → 별도 검증 에이전트(타겟 가시성·행동 타당성·기대 결과 구체성 확인, 실패 시 리샘플링)(p.7-8, Figure 4).

실험 설정 및 결과

  • 평가 대상: 18개 세계 모델(텍스트 구동 범용 비디오 생성기, 네이티브 액션 기반, 카메라 포즈 기반). 동일한 330개 고정 케이스셋 사용, 모든 서브 에이전트는 동일 VLM 백엔드·온도·프레임 샘플링 사용(p.9).
  • 메인 리더보드 (p.10, Table 2): Seedance 2.0이 Overall 75.5로 1위, Wan 2.7(75.0), Kling 3.0(74.4), MiniMax H3(74.3) 順. 상위 4개 모두 텍스트 조건부 범용 비디오 생성기 — 대규모 텍스트 조건 학습이 Intentional/Physical Transition에 유리하다고 분석.
  • 메트릭별 최강자가 상이: Wan 2.7이 Intentional·Physical Transition에서 1위, Seedance 2.0/HY-WorldPlay 1.5/SANA-WM이 각각 Drift/Revisit/Offscreen에서 1위(p.10).
  • 사람 정합성 (p.11, Figure 6): 9개 모델에 대해 5000건 A/B 판단을 Bradley-Terry로 집계한 결과, HarnessEval-W는 Intentional Transition에서 Spearman ρ=0.93(Kendall τ=0.82), Physical Transition에서 ρ=0.87(τ=0.74).
  • 기존 벤치마크(WBench) 대비 우위 (p.11): 동일 GPT-5.5 백엔드로 재실행 비교 시, Physical 평가에서 pairwise accuracy 31.9%→71.7%, draw rate 52.2%→1.8%로 개선; Intentional에서 accuracy 60.2%→77.8%, draw rate 36.1%→11.1%로 개선. Brier score도 양쪽 모두 개선.
  • 평가 안정성 (p.11-12, Figure 8): 3회 반복 실행 시 HarnessEval-W 기울기 9.6-10.8(상관 0.928-0.964), 신뢰구간 폭 0.33 Bradley-Terry 단위로, WBench(기울기 11.2-21.0, 상관 0.646-0.780, 폭 1.61 — 4.9배 넓음) 대비 훨씬 안정적.
  • 평가축 간 상관 (p.12, Figure 9): Intentional-Physical Transition은 r=0.98로 강하게 결합, Exploratory Transition은 둘과 거의 무관(r=-0.15, -0.18) — 탐색적 연속성과 의미적/물리적 개입 수행 능력은 별개.
  • 파인튜닝에 따른 능력 이동 (p.12-13, Figure 10): Wan 2.2→DreamX-World, HunyuanVideo 1.5→HY-WorldPlay 1.5 비교 시, 두 경우 모두 Revisit/Exploratory/Offscreen은 개선되나 Intentional(-11.9~-24.2점)·Physical(-7.2~-11.7점)은 크게 하락 — 텍스트-to-비디오 모델을 액션 조건부로 파인튜닝하면 능력이 재분배될 뿐 균일하게 향상되지 않음을 시사.

한계점 (저자 명시 및 분석상 드러난 점)

  • 논문 자체가 "미래 방향(Future Work)"으로 자기 한계를 명시: 현재 스킬 라이브러리가 고정적이며, 프론티어 모델이 만들어내는 분포 외(out-of-distribution) 시나리오에서는 라우팅이 실패할 수 있음(p.13-14).
  • 검증-불가능한 판단은 여전히 VLM 심판(judge)에 의존하므로, 판단 근거의 신뢰도가 VLM 자체의 한계에 종속.
  • 이번 버전은 정적 스킬 라이브러리와 330개 케이스로 제한되며, 저자들은 "test-time scaling(스킬 분해 심화)", "스킬 라이브러리 확장", "재귀적 자기개선 벤치마크"를 향후 과제로 제시(p.13-14).
  • 파인튜닝 능력 이동 분석(Figure 10)은 "통제된 어블레이션이 아닌 공개된 두 모델 쌍의 기술(descriptive) 비교"라고 저자가 명시적으로 밝힘 — 인과적 결론으로 일반화하기는 조심스러움.

시사점

  • LLM 에이전트 생태계의 "하네스(harness)" 개념(계획→도구 위임→검증)을 비-LLM 도메인(비디오/세계 모델 평가)에도 적용 가능함을 실증 — 유사하게 "고정 채점표로는 대응 못하는 컨텍스트 의존적 평가" 문제를 가진 다른 생성 도메인(3D, 오디오 등)에도 참고할 만한 아키텍처.
  • "왜 낮은 점수를 받았는가"를 서브 질문 단위로 역추적 가능한 증거 트리 구조는, 모델 개발자가 실패 모드를 바로 디버깅할 수 있게 하는 실무적 가치가 큼.
  • 평가축 간 상관관계 분석(Intentional-Physical 강결합, Exploratory 독립)은 세계 모델 학습 데이터 설계 시 "어떤 능력이 함께 움직이는지"를 참고할 수 있는 데이터.
