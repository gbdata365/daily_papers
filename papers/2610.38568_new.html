A-RSI: Adaptive Task Refresh for Zero-Data Multimodal Self-Improvement

A-RSI: 제로데이터 멀티모달 자기개선을 위한 적응형 태스크 갱신

외부 데이터나 정답 라벨 없이, 모델 스스로 생성한 멀티모달 문제 풀(pool)에 대해 학습 로그 상의 신호 변화를 감지해 "언제" 새 문제로 교체할지를 결정함으로써, 재귀적 자기개선(RSI) 학습을 정체 없이 지속시키는 프레임워크.

한 줄 요약

외부 데이터나 정답 라벨 없이, 모델 스스로 생성한 멀티모달 문제 풀(pool)에 대해 학습 로그 상의 신호 변화를 감지해 "언제" 새 문제로 교체할지를 결정함으로써, 재귀적 자기개선(RSI) 학습을 정체 없이 지속시키는 프레임워크.

배경 및 문제의식

재귀적 자기개선(Recursive Self-Improvement, RSI)이 성공하려면 모델이 유용한 학습 경험을 만들어내는 것뿐 아니라, 현재 쓰고 있는 학습 데이터(풀)가 더 이상 학습 신호를 주지 못하게 된 시점을 스스로 알아채는 것도 필요하다. 기존 연구들은 주로 "다음에 어떤 문제를 생성할 것인가"(난이도, 역량에 맞는 문제 선택 등)에 집중했고, "언제 새 데이터를 투입해야 하는가"라는 타이밍 문제는 상대적으로 소홀히 다뤄졌다. 또한 많은 기존 방법은 자기일관성(self-consistency)이나 다수결 투표로 정답(학습 타깃)을 만들어내는데, 이는 모델 자신의 불확실한 예측에 감독 신호가 의존하게 되는 신뢰성 문제를 낳는다. 저자들은 이 두 문제, 즉 "언제 갱신할 것인가"와 "정답이 믿을 만한가"를 서로 독립적으로 분리해 다루고자 한다.

핵심 기여

논문은 세 가지 기여를 제시한다. 1. 학습 로그 기반 갱신 규칙: 검증/테스트 점수를 전혀 참조하지 않고, 그룹 내 보상 분산(advantage)을 갖는 프롬프트 수의 감소를 이용해 풀 교체 시점을 판단하는 규칙을 제안. 2. 프로그램으로 검증 가능한 학습 경험: 모델이 작성한 프로그램이 멀티모달 문제(이미지+질문)와 그 기준 정답을 함께 생성하여, 외부 학습 데이터나 사람이 작성한 정답 라벨 없이 학습 루프가 작동하도록 함. 3. 동일 조건 비교 및 응답 단위 분석: 동일한 학습 진행도에서 여러 갱신 정책을 비교하고, 성능 향상이 "응답이 출력 길이 제한 내에 완료되었는지"와 "이미 완료된 답이 교정되었는지"로 나누어 분석.

방법론

A-RSI(Adaptive Recursive Self-Improvement)는 세 단계로 구성된다.

  • 프로그램 기반 문제 생성 (사전 준비): 기하, 차트, 표, 개수 세기 등 시드 유형에서 출발해 베이스 모델이 재사용 가능한 문제 템플릿(파라미터화된 프로그램)을 직접 작성한다. 각 템플릿은 하나의 "기저 설정"(configuration)으로부터 이미지, 질문, 정답을 동시에 생성하므로(I, q, a = G_τ(z)), 정답이 모델의 투표가 아니라 프로그램 실행 결과로 결정된다. 생성된 후보는 구성 검증, 최신성/오염 검사, 중복 제거를 거쳐 고정된 가족별 할당량(quota)으로 미리 분리된 교체용 풀들로 조립된다.
  • 보상 설계와 정책 최적화: 응답은 정답 일치 보상(r_ans), 형식(박스 표기) 보상(r_fmt), 정상 종료 여부에 대한 보상(r_stop)의 합으로 채점되며, GRPO로 Solver 정책만 업데이트한다. 템플릿과 컨트롤러는 학습 중 고정.
  • 풀 포화 감지 (WHEN): 그룹 내 보상이 모두 같아 GRPO advantage가 0이 되는 프롬프트는 더 이상 정책 기울기 신호를 주지 못한다. 이에 따라 "advantage가 0이 아닌 고유 프롬프트 수"(U_w)와 "정답률"(a_w)을 window마다 집계하고, 최소 관찰 기간(n_min) 이후 U_w가 ℓ-window 전 대비 임계비율 ρ 이하로 떨어지거나 정답률이 η 이상 상승하면 교체를 발동한다(식 4). 이 판정은 검증/테스트 점수를 전혀 참조하지 않는 순수 학습 로그 기반 규칙이다.
  • 교체와 지속 학습: 교체가 결정되면 활성 풀 전체를 미사용 신규 태스크로 교체(가족별 고정 비율로 무작위 추출)하되, 모델 가중치는 그대로 이어받아 학습을 계속한다(옵티마이저/스케줄러만 새로 초기화). 학습 중 건강성 점검(health gate)에 실패하면 동일 풀·시드로 한 번 재시도하고, 재차 실패하면 학습을 중단한다.

주 실험은 Qwen3-VL-8B-Instruct를 기반으로, 초기 풀 학습 후 체크포인트 S_t에서 시작해 최대 8개의 연속 윈도우(윈도우당 100 GRPO 업데이트)를 거치며, 동일 방법을 MiMo-VL-7B-SFT에도 적용해 검증한다.

실험 설정 및 결과

11개 벤치마크(MMSI, MathVerse, MathVision, MMMU-Pro 등)로 구성된 Macro11 평균 정확도를 주요 지표로 사용하며, A-RSI를 포함해 다섯 가지 갱신 정책(A-RSI, Frontier, Periodic, Continuous, No-Refresh)과 여러 교체 선택 전략(난이도 프런티어, 학습 가능 구간, 항상 오답 등)을 비교했다.

  • Qwen에서 Macro11 평균이 St(57.77)에서 8개 윈도우·800개 신규 태스크 사용 후 61.05로 상승. MiMo는 S0(59.08)에서 60.71로 상승.
  • 동일한 학습 업데이트 수(매칭된 진행도) 기준, A-RSI는 Continuous(매 윈도우 교체, 적응적 난이도 선택, 신규 태스크 3,200개 사용)보다 신규 태스크를 1/4만 쓰면서도 0.40점 높은 점수(61.05 vs 60.64)를 기록. Periodic(1,200개 사용) 대비 +1.15점.
  • 기존 풀을 계속 재사용한 No-Refresh는 윈도우 6 시점에서 58.35점에 머물렀고, 이후 학습 건강성 점검에 반복 실패해 S31에서 학습이 중단되어 S32 결과 자체가 없음. 매칭된 윈도우 6 시점에서 A-RSI(60.40) 대비 2.05점 낮음.
  • 교체 선택 전략 비교에서는 난이도 기반(Frontier), 실패 우선, 학습가능 구간, 항상 오답 선택 등 다양한 "지능적" 선택 규칙들이 모두 무작위 선택(random) 대비 성능이 낮거나 비슷했다. 즉 테스트된 조건에서는 "언제 교체할지"가 중요하고, "무엇을 넣을지"는 무작위로 충분했다.
  • 추가 분석(7장)에서는 보상 해킹 가능성, 정답 체커의 취약점(선택형 문항 일부에서 파서 오류 발견, 16,000건 중 220건), 독립적 정답 재계산(1,000개 샘플 전부 일치) 등을 통해 파이프라인의 신뢰성을 점검했다. 또한 출력 토큰 한도를 4096에서 8192로 늘렸을 때 A-RSI의 성능 향상분은 80%가 유지된 반면 비교 대상 MM-Zero v5는 59%만 유지되어, A-RSI의 개선이 "단순히 답을 끝까지 완성하는 것"에 덜 의존함을 시사했다. 다만 성능 향상의 일부는 "응답을 완결 짓는 능력" 향상에서, 일부는 "이미 완결된 오답을 정답으로 교정"하는 데서 비롯됨을 사례 분석(8장)으로 구분해 보였다.
  • MiMo와 Qwen에 같은 임계값·규칙을 적용했을 때, 동일한 관찰 기간이라도 모델별 학습 신호 상태에 따라 서로 다른 교체 결정이 내려짐을 보여, 규칙이 고정 스케줄이 아니라 모델의 실제 학습 상태에 반응함을 확인했다.

한계점

  • 각 실험 arm은 단 1회만 학습되어 반복 실험이나 통계적 유의성 검증이 없으며, 8개 윈도우를 넘는 긴 horizon이나 16k 토큰 평가는 수행되지 않음. No-Refresh는 S31에서 중단되어 사전 계획된 S32 평가 지점 자체가 관측되지 않음.
  • 첫 교체 시점이 기존 로그를 보고 사후적으로 설정된 것이어서, 고정된 3-윈도우 스케줄과 비교하는 무작위 대조군이 없어 "타이밍 자체의 기여"와 "신규 태스크 투입 효과"가 서로 얽혀 있어 완전히 분리되지 않음.
  • MiMo에 대한 교체 풀은 Qwen의 난이도 프런티어 기준으로 선택되었기 때문에, 모델 간 전이 가능성에 대한 결론은 제한적임.
  • 고정된 프로그램 라이브러리는 기하, 차트, 표, 개수 세기에 한정되며 함수 그래프, 수치 추정, 공간 추론 과제는 다루지 않음. 과제 가족 비율이나 19개 주제어는 평가 벤치마크를 참고해 정해졌기 때문에 이 템플릿 범위를 넘어서는 다양성은 측정되지 않음.
  • 정답 체커(파서)에 선택형 문항 관련 취약점이 실제로 발견되었으며(16,000건 중 220건 오류), 완전히 결함 없는 보상/채점 체계임을 보장하지 않음.

시사점

이 연구는 "데이터를 더 많이, 더 똑똑하게 고르는 것"보다 "언제 데이터를 바꿀지"를 스스로 판단하는 능력이 제로데이터 자기개선 루프의 지속성에 더 결정적일 수 있음을 보여준다. 특히 검증/테스트 점수에 의존하지 않고 순수 학습 로그(그룹 내 보상 분산, 정답률)만으로 포화를 감지하는 방식은, 외부 평가 신호가 없는 완전한 자기주도 학습 시나리오에 적용 가능성을 제시한다. 또한 성능 향상의 원인을 "응답 완결" 대 "답 교정"으로 분해해 분석한 점은, 향후 RSI·자기개선 연구에서 보고되는 성능 향상치가 실제로 추론 능력 향상인지, 출력 예산 내 완결률 향상인지를 구분해서 보고해야 한다는 방법론적 시사점을 제공한다. 다만 무작위 선택이 다양한 지능적 선택 전략을 능가했다는 결과는 특정 생성기·모델·설정에 국한된 결과일 수 있어, 다른 도메인이나 더 다양한 태스크 생성기에서도 동일한 결론이 유지되는지는 추가 검증이 필요하다.
