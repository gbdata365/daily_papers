FrontierPhysics: Evaluating Agents for End-to-End Physics Research

프론티어피직스: 종단간 물리학 연구를 위한 에이전트 평가

한 줄 요약

물리학자 42명이 자신의 실제 연구를 바탕으로 만든 56개의 종단간(end-to-end) 과제로 AI 에이전트의 물리학 연구 수행 능력을 평가하는 벤치마크로, 22개 최신 모델 모두 46% 미만의 통과율을 기록했다.

배경 및 문제의식

기존 물리학 벤치마크들은 고정된 질문 풀이, 고립된 하위 과제, 또는 정답이 주어진 논문 재현에 그쳐 AI 에이전트가 문헌 조사부터 연구 계획 수립, 실험 수행, 논문 작성까지 이어지는 실제 연구 과정을 수행할 수 있는지, 그리고 그 결과물의 연구 품질(질적 완성도)까지 평가하지는 못했다는 한계가 있었다.

핵심 기여

  • 42명의 물리학자가 자신이 실제로 수행한 연구 프로젝트(평균 약 270일, 총 8,000시간 이상 투입)를 바탕으로 만든 56개 과제로 구성된 벤치마크 FRONTIERPHYSICS를 제안
  • 이론·계산·실험 물리학을 아우르는 9개 세부 분야를 포괄하며, 참조 논문 없이 개방형(open-ended)으로 설계되어 문제 유출을 방지
  • 결정론적 검증기(verifier)와 전문가가 작성한 루브릭을 결합해, 결과의 수치적 정확성뿐 아니라 출판 가능 수준의 연구 품질까지 평가
  • 일반 품질 검토, 분야별 동료 심사, 실패 모드 분석의 3단계 큐레이션 파이프라인으로 과제의 신뢰성을 확보(182건 제출 중 56건 최종 선정)

방법론

각 과제는 PI(지도교수)가 연구 시작 시 제공할 법한 상위 수준의 지시문(task.md)만 주어지며, 에이전트는 문헌 조사, 연구 계획 수립, 방법 선택, 실험/계산 수행, 결과 검증, 논문(paper.pdf) 작성까지 모두 독립적으로 수행해야 한다. 평가는 (1) 수치 출력값을 검사하는 결정론적 검증기와 (2) 리워드 해킹·환각·문헌 종합 등을 평가하는 에이전트 심사자(reviewer agent) 기반 루브릭을 결합하며, 루브릭 항목은 차단 기준(blocker, 통과 필수)과 비차단 기준(non-blocker, 0~2점 품질 점수)으로 구분된다. 22개 모델을 Codex CLI, Claude Code CLI, Grok Build, Antigravity CLI 등 4종의 에이전트 하네스에서 각 과제당 3회씩, 총 4,364회 롤아웃으로 실행했다.

실험 설정 및 결과

전체 모델의 통과율은 모두 30% 미만이었으며, Claude Opus 5.5가 Claude Code CLI 환경에서 27.4%로 가장 높은 통과율을 기록했고 GPT-6 Astra(23.2%), GPT-6.1 Sol(19.6%)이 뒤를 이었다. 비용이 증가할수록 통과율이 대체로 상승했으나 일부 Claude 모델은 비용 증가에도 통과율이 오히려 낮아지는 경향을 보였다. GPT-6 Astra의 실패 롤아웃 168건을 수작업으로 분석한 결과, 실패 원인의 48%가 '엄밀하지 못한 추론(순환적 자기검증 등)', 34%가 '전문가적 직관 부족', 27%가 '문헌 활용 미흡'으로 나타났으며, 실제 물리 지식 부족이나 계산 실수로 인한 실패는 상대적으로 적었다.

한계점

논문에 명시된 주요 한계는 다음과 같다: 실패 모드 분석은 GPT-6 Astra 모델에 집중되어 다른 모델·하네스 조합에는 동일한 분류가 그대로 적용되지 않을 수 있음, 검증기·루브릭 자체의 결함(거짓 음성 7%, 거짓 채점 3%)으로 실제 통과율이 과소평가될 가능성, 그리고 56개 과제가 42명 기여자의 연구 범위에 한정되어 물리학 전 분야를 균등하게 대표하지는 못한다는 점이다.

시사점

현재 최상위 AI 에이전트들도 물리 지식 자체보다 엄밀한 추론 능력과 연구자로서의 직관(가설 재검토, 엣지 케이스 고려, 문헌 기반 논증)에서 근본적인 한계를 보이며, 이는 AI가 단순 하위 과제 보조를 넘어 자율적인 과학 연구 주체로 발전하기 위해서는 개방형 탐구와 비판적 자기검증 능력을 기르는 새로운 학습·평가 체계가 필요함을 시사한다.
