VisSearch-Bench: Evaluating Long Horizon Visual Search in Multimodal Agents

VisSearch-Bench: 멀티모달 에이전트의 장기 시각 탐색 평가

멀티모달 에이전트가 여러 이미지와 검색 단계에 걸쳐 시각적 증거를 조직하고 연결하는 능력("visual context management")을 평가하기 위해, 204개의 사람이 직접 작성한 장기 시각 탐색 과제로 구성된 VisSearch-Bench를 제안하고, 16개 모델을 평가한 결과 검색 도구를 사용해도 최고 성능 시스템조차 과제의 26.47%만 완전히 해결함을 보였다.

한 줄 요약

멀티모달 에이전트가 여러 이미지와 검색 단계에 걸쳐 시각적 증거를 조직하고 연결하는 능력("visual context management")을 평가하기 위해, 204개의 사람이 직접 작성한 장기 시각 탐색 과제로 구성된 VisSearch-Bench를 제안하고, 16개 모델을 평가한 결과 검색 도구를 사용해도 최고 성능 시스템조차 과제의 26.47%만 완전히 해결함을 보였다.

배경 및 문제의식

멀티모달 대형언어모델(MLLM)은 단발성 시각 질의응답 시스템에서 벗어나 웹 검색, 이미지 검색, 웹페이지 탐색, 영역 단위 이미지 검사 등 도구를 사용해 여러 라운드에 걸쳐 상호작용하는 에이전트로 발전하고 있다. 그러나 기존의 멀티모달 검색 벤치마크(MMSearch-Plus, MM-BrowseComp, VisBrowse-Bench 등)는 대부분 "과제 수행 중 시각적 증거가 어느 시점에든 사용되는가"에만 초점을 맞춘다. 많은 기존 과제에서 이미지는 초기 개체(entity)를 식별하는 용도로만 쓰이고, 그 이후에는 텍스트 검색에 의존하기 때문에, 에이전트가 여러 이미지·객체를 어떻게 다루고 검색 단계 전반에 걸쳐 시각 정보를 어떻게 연결하는지에 대한 통찰을 거의 주지 못한다. 저자들은 실제 웹 기반 정보 탐색은 독립적인 이미지 인식 작업의 연속이 아니라, 초기 증거가 가설을 제시하고 이후 증거가 후보를 비교·배제·발견하며 때로는 이전 이미지의 해석 자체를 바꾸는 과정이라고 지적하며, 이 능력(visual context management)을 체계적으로 평가할 벤치마크의 부재를 문제로 제기한다.

핵심 기여

  • 개방형 웹 탐색에서 시각적 맥락 관리(visual context management)를 평가하는 과제 기반 관점을 제시: 에이전트가 여러 이미지에서 정보를 조직하고, 서로 다른 객체를 연결하며, 시각적 발견을 이후 검색에 활용하는 방식에 초점을 둔다.
  • VisSearch-Bench 구축: 7개 주요 도메인·25개 하위 도메인에 걸친 204개의 사람 작성 과제로, Set-wise Visual Search, Sequential Visual Search, Hybrid Wide–Deep Search, Competitive Visual Disambiguation, Visual-Structure-Guided Search의 5개 과제군으로 구성.
  • 사람이 주도하고 자동 검증이 보조하는 구축 프로세스를 설계: 각 과제는 추적 가능한 증거 소스, 기준 정답(reference answer), 채점 규칙을 포함하며, 전체 정답 정확도(Accuracy)와 개별 결과·하위 질문에 대한 정확성/완전성을 측정하는 Process Score를 함께 사용해 과제 전체 완료도와 부분 정답 품질을 모두 포착한다.

방법론

각 과제는 자연어 질문 q, (텍스트로 시작하는 과제의 경우 비어 있을 수 있는) 초기 이미지 집합 I0, 요구되는 출력 형식 σ로 구성된다. 에이전트는 텍스트 검색, 이미지 검색, 역방향 이미지 검색, 웹페이지 접근, 이미지 검사(크롭 등) 도구를 사용해 웹과 상호작용하며, 각 스텝에서 그동안의 행동-관찰 이력(history)을 바탕으로 다음 행동을 선택한다. 시각적 맥락(visual context)은 객체의 외형·세부 특징뿐 아니라 객체의 순서·위치·연결 관계까지 포함하며, 이를 조직·연결·활용하는 능력이 평가 대상이다.

5개 과제군은 각각 다른 요구사항을 강조한다. Set-wise Visual Search는 명확히 정의된 객체 집합 전체를 확인·비교·종합해야 하는 과제, Sequential Visual Search는 한 단계에서 찾은 단서가 이후 검색을 이끄는 연쇄적 과제, Hybrid Wide–Deep Search는 순차 탐색과 집합 단위 탐색을 결합한 과제(앞선 결과가 다음 단계의 후보 범위를 결정), Competitive Visual Disambiguation은 외형이 유사한 후보를 세부 시각 정보로 구별해야 하는 과제, Visual-Structure-Guided Search는 이미지 내 객체의 순서·공간적 위치·연결 구조를 외부 검색 결과와 결합해 목표를 찾는 과제이다.

데이터셋 구축은 5단계 파이프라인(Figure 3)을 따른다: (1) 공개적으로 검색 가능하고 경계가 명확한 소스 선정, (2) 개체-이미지 연결·사실·근거를 구조화한 증거 그래프 작성, (3) 과제군별 구조적 제약에 따라 질문 및 기준 정답 설계(중간 노드와 최종 답은 질문에 노출되지 않도록 숨김), (4) 정답과 골드 트래젝토리(gold trajectory) 고정, (5) 소스 접근성·필드 완전성·집합 커버리지·정답 재계산 등 결정적 무결성 검사(Deterministic Integrity Gates)와 LLM 기반 후처리 필터링, 마지막으로 사람 검토. 이 과정은 시각적 필수성(Visual Indispensability), 시각 증거 통합(Visual Evidence Integration), 공개적 해결 가능성 및 감사 가능성(Public Solvability and Auditability)이라는 세 원칙을 따른다.

평가 지표는 두 가지다. Accuracy는 예측 답변이 과제별 사전 정의 규칙(Eσ)에 따라 기준 답과 완전히 일치하는지(필요한 내용만 정확히 포함하는지)를 이진 판정해 과제 전체 성공률을 측정한다. Process Score(PS)는 각 과제에 라벨링된 mi개의 핵심 상태(critical state) 중 올바르게 복원한 비율(|Ri|/mi)의 평균으로, 개별 결과와 하위 질문 답변의 정확성·완전성을 측정한다.

실험 설정 및 결과

16개의 대표적 멀티모달 모델(오픈소스 13개 + GPT-5.5, Gemini 3.5 Flash, Claude Opus 4.8 등 상용 모델 3개)을 평가했다. 모델은 (a) 도구 없이 질문과 초기 이미지만으로 답하는 Direct Answer, (b) 웹 검색·웹페이지 읽기·텍스트 기반 이미지 검색·역방향 이미지 검색·이미지 크롭의 5가지 도구를 사용하는 ReAct, (c) DeerFlow 프레임워크로 평가되었다. 과제당 이미지 예산 20장, 최대 30회 ReAct 라운드, 최대 60회 도구 호출 등의 제한이 적용되었고, Pass@1로 1회씩 평가되었다.

주요 결과(Table 3): Direct Answer 설정에서는 어떤 모델도 6.37% 정확도를 넘지 못했다. 검색을 사용하면 ReAct+Kimi-K3가 26.47%로 최고 정확도를, ReAct+GPT-5.5가 25.49% 정확도와 최고 Process Score(49.52%)를 기록했다. 즉 정확도와 Process Score에서 최고 모델이 서로 다르며, 개별 항목 수행과 과제 전체 완결 사이에 간극이 있음을 보여준다. ReAct와 DeerFlow 모두 Direct Answer보다 정확도와 Process Score를 높였으나, 프레임워크 간 우열은 모델에 따라 달랐다(예: GPT-5.5·Qwen3.5-397B-A17B는 ReAct가 우세, Qwen3.6-35B-A3B는 DeerFlow가 우세).

과제군별 분석(Table 4)에서는 Set-wise Visual Search의 정확도가 전반적으로 가장 낮았다(ReAct+Kimi-K3가 11.76%로 최고). Competitive Visual Disambiguation에서는 모든 Direct Answer 모델이 0.00% 정확도를 기록했으나 ReAct+DeepSeek-V4.1-Flash와 ReAct+Qwen3.8-27B는 44.12%까지 상승했다. Visual-Structure-Guided Search에서는 ReAct+GPT-5.5가 50.00% 정확도와 70.61% Process Score로 가장 높았다.

Ablation(Table 5, 6)에서는 시각 접근 수준을 Direct Answer < Text(검색만) < Caption(이미지 검색 후 별도 비전모델로 캡션 생성) < Full(이미지 직접 검사 및 크롭)으로 나누어 비교했을 때 Full이 세 모델 모두에서 최고 정확도·Process Score를 기록했다. 다만 Full에서 Caption으로 전환 시 일부 과제는 오히려 정답으로 바뀌었지만(예: DeepSeek-V4.1-Flash 20개), 전체적으로는 Full이 더 많은 과제를 잃는 손실이 더 컸다. 추가 분석(Figure 5)에서는 시각 도구 호출이 검색 과정 초반 20%에 집중되지만(모델별 41.5%~69.2%) 이후 단계에서도 계속 사용되며, 도구 호출 수가 많다고 반드시 정확도가 높아지는 것은 아니었다.

한계점

논문에 명시적인 "Limitations" 절은 없으나, 본문에서 다음과 같은 한계 및 과제가 논의된다. 최종 답 정확도만으로는 오류가 잘못된 검색 범위, 놓친 시각적 후보, 잘못된 증거 결합 중 어디서 발생했는지 구분할 수 없다는 점(이를 보완하기 위해 Process Score를 도입). 또한 이미지 캡션으로 시각 정보를 텍스트화하는 방식은 일부 과제에서는 도움이 되지만 전체적으로는 세부 사항 손실로 인해 직접 이미지 검사(Full)보다 성능이 떨어진다는 점, 그리고 Set-wise Visual Search처럼 다수 객체를 모두 검증하고 일관된 최종 답으로 종합해야 하는 과제에서 부분 정답과 완전한 정답 사이의 간극이 크다는 점이 한계로 제시된다.

시사점

VisSearch-Bench는 멀티모달 에이전트가 단순히 더 많은 도구 호출이나 더 긴 컨텍스트 윈도우를 갖는 것만으로는 "시각적 맥락 관리" 능력을 보장받지 못한다는 점을 실증적으로 보여준다. 최고 성능 시스템도 과제의 약 1/4만 완전히 해결한다는 결과는, 에이전트가 여러 이미지·객체 간 정보를 연결하고, 객체를 검증하고, 검색 단계에 걸친 결과를 종합하는 능력에서 상당한 개선 여지가 있음을 시사한다. Accuracy와 Process Score를 함께 사용하는 평가 방식은 향후 에이전트 설계에서 "부분적으로 맞지만 전체 과제는 실패"하는 실패 양상을 구분하고 개선 방향을 진단하는 데 유용한 틀을 제공한다.
