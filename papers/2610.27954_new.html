Lost in Recovery: Demystifying Recovery Behavior of Computer-Use Agents via Goal-Oriented Action Replay

회복 속에서 길을 잃다: 목표지향적 행동 재생을 통한 컴퓨터 사용 에이전트의 회복 행동 해부

컴퓨터 사용 에이전트(CUA)가 오류 발생 후 이전의 정상 상태로 되돌아가는 '회복(recovery)' 능력을 "전이 일관적 회복(Transition-Consistent Recovery)"이라는 기준으로 정의하고 목표지향적 행동 재생(goal-oriented action replay)으로 체계적으로 측정하는 평가 프레임워크 ReTRACE를 제안해, 현재 에이전트들이 잠재적으로는 회복 능력을 갖고 있지만 이를 자발적으로 활용하지 못한다는 사실을 밝힌 연구.

한 줄 요약

컴퓨터 사용 에이전트(CUA)가 오류 발생 후 이전의 정상 상태로 되돌아가는 '회복(recovery)' 능력을 "전이 일관적 회복(Transition-Consistent Recovery)"이라는 기준으로 정의하고 목표지향적 행동 재생(goal-oriented action replay)으로 체계적으로 측정하는 평가 프레임워크 ReTRACE를 제안해, 현재 에이전트들이 잠재적으로는 회복 능력을 갖고 있지만 이를 자발적으로 활용하지 못한다는 사실을 밝힌 연구.

배경 및 문제의식

컴퓨터 사용 에이전트는 장기적이고 복잡한 작업에서 초기 실수가 누적·전파되고, 실행된 행동이 되돌리기 어려운 부작용(예: 사용자가 보존하려던 파일을 에이전트가 모르게 덮어씀)을 남길 수 있어, 환경을 이전의 온전한 상태로 되돌리는 능력이 신뢰성 있는 운영에 필수적이다. 그러나 기존 해결책은 불충분하다: 환경 전체 리셋은 상용 서비스 환경에서 대개 불가능하고, 행동 재생(action replay)은 장기 작업에서 비용이 지나치게 크며, API 기반 롤백(예: 브라우저의 '뒤로 가기')은 웹 환경에만 국한되어 더 넓은 데스크톱 환경에서는 적용할 수 없다. 이에 따라 에이전트 스스로 모델 수준에서 이전 상태를 복원하는 '자율적 모델 기반 회복' 능력이 중요한 미개척 과제로 남아 있다.

핵심 기여

  • 예측 상태 표현(predictive state representation) 이론에 기반해, 복원된 상태에서 동일한 후속 행동을 실행했을 때 원래 궤적과 동일한 결과가 나오면 회복이 성공한 것으로 정의하는 '전이 일관적 회복' 개념을 공식화.
  • 제어된 오류 주입 후 목표지향적 행동 재생을 통해 이 기준을 실제로 측정하는 확장 가능한 평가 파이프라인 ReTRACE를 설계(온폴리시 궤적 수집 → 섭동을 통한 궤적 이탈 생성 → 목표지향적 행동 재생의 3단계).
  • OSWorld와 WindowsAgentArena에서 폐쇄형 모델(Claude-Sonnet-4.6, GPT-5.4-CUA)과 오픈소스 모델(EvoCUA-32B, UI-TARS-1.5-7B, Qwen3.5-9B)을 대상으로 자율적 모델 기반 회복 행동의 첫 체계적 분석을 수행.
  • 이상적 회복(오라클이 이전 상태로 되돌려줌)은 동일한 재시도 예산 하에서 환경 전체 리셋보다 훨씬 효율적으로 작업 성공을 끌어낼 수 있음(Finding 1)을 보이고, 현재 에이전트들은 암묵적으로는 회복을 거의 시도하지 않지만(Finding 2) 명시적 회복 정책을 적용하면 회복 성공률이 한 자릿수 이상 뛰어올라(Finding 3) 회복 능력이 '부재'가 아니라 '잠재'해 있음을 입증.
  • 정확한 모델 기반 회복이 실제로 다운스트림 작업 성공률을 측정 가능할 만큼 높이는 반면(Finding 5), 약한 회복은 오히려 궤적을 더 어긋나게 만들 수 있음(Finding 6)을 end-to-end 평가로 확인.

방법론

컴퓨터 사용 작업을 부분관찰 마르코프 결정과정(POMDP) M=(S,A,O,E,T,Ω)으로 정의하고, 상태 s_t=(h_t,o_t)를 숨겨진 성분과 관측으로 분해한다. '전이 일관적 회복'은 제어된 환경 E의 결정적 전이 함수 T_E 하에서, 복원된 상태 f(s_t)로부터 원래 궤적의 후속 행동 a_{t-d}를 실행했을 때 다음 상태가 원래 궤적의 s_{t-d+1}과 일치하면 성공으로 판정하는 지표 R_TC와, 복원된 관측이 목표 관측과 일치하는지 보는 R_O를 결합해 R=R_TC∧R_O로 정의된다. 평가 파이프라인은 (A) 온폴리시 궤적 롤아웃: 평가 대상 정책 자체로 성공 궤적을 수집하고, 동일 행동열을 N회 재생해 일관되게 같은 결과가 나오는 경우만 남겨 전이 일관적 데이터셋을 구성; (B) 섭동을 통한 궤적 이탈: 성공 궤적의 한 시점을 목표 상태로 삼고, 거기서 섭동 정책으로 t_p 스텝을 더 진행시켜 오류 상태를 생성; (C) 목표지향적 행동 재생: 오류 상태에서 회복 정책 π^R_θ가 최대 r 스텝 내에 목표 상태를 복원하도록 한 뒤, 복원된 상태로부터 원래 궤적의 남은 행동들을 재생해 원래 작업 결과가 재현되는지 검증하는 방식으로 진행된다. 회복 정책은 전방 정책을 그대로 재사용하며 복구 전용 지시가 없는 '암묵적 회복'과, 목표 상태로 명시적으로 되돌리도록 지시받는 '명시적 회복' 두 가지로 구분해 비교한다.

실험 설정 및 결과

OSWorld와 WindowsAgentArena에서 Claude-Sonnet-4.6, GPT-5.4-CUA(폐쇄형), EvoCUA-32B, UI-TARS-1.5-7B, Qwen3.5-9B-Thinking(오픈소스)을 대상으로 회복 거리 d=1(단기)과 d=5(장기) 두 설정에서 평가했다. 이상적 회복 실험(EvoCUA-32B 기준)에서는 회복 스텝을 R=0(전체 리셋과 동일)부터 LLM 기반 회복 탐지기가 찾은 지점(R=R_LLM)까지 비교한 결과, 0이 아닌 모든 회복 전략이 전체 리셋보다 Success@K에서 더 높은 성능을 보여 동일 재시도 예산 하에서 회복이 재시작보다 훨씬 효율적임을 확인했다. 암묵적 회복 분석에서는 가장 강력한 에이전트인 Claude-Sonnet-4.6, GPT-5.4-CUA조차 회복 능력이 제한적이었고, 가장 강한 오픈소스 모델 EvoCUA-32B는 평균 회복률이 1% 미만으로 사실상 이전 상태를 복원하지 못했다. 반면 명시적 모델 기반 회복을 적용하면 평균 17.86%p의 회복 성공률 향상이 나타났으며, 특히 범용 에이전트(Claude-Sonnet-4.6, GPT-5.4-CUA, Qwen3.5-9B)에서 개선 폭이 컸던 반면, 특정 과제에 사후학습된 오픈소스 전문 모델은 개선 폭이 작아 단방향 작업 완료 궤적 위주의 집중적 사후학습이 오히려 내재된 회복 역량을 약화시킬 수 있음을 시사했다. End-to-end 평가에서는 모델 기반 회복이 모든 회복 설정에서 회복 미적용 기준선 대비 성능을 높였고(평균 +2.12%p), 회복 시도를 늘릴수록(1→3→5회) 회복 능력이 상대적으로 양호한 모델(Qwen3.5-9B, UI-TARS-1.5-7B)은 추가 이득을 얻었지만, 회복 성공률이 낮은 EvoCUA-32B는 반복 시도가 오히려 궤적을 점점 더 어긋나게 만들어 성능이 하락했다. ReTRACE의 신뢰도 검증을 위한 인간 평가에서는 ReTRACE의 회복 오라클이 세 가지 대안(R_O 제거, R_TC 제거, GPT-5.4 평가자)보다 인간 판단과 더 높은 일치율(최대 82.0% 승률)을 보였다.

한계점

저자들은 'Limitations' 절에서 다음을 명시한다: ReTRACE는 회복 능력을 측정·분석하도록 설계되었을 뿐 이를 직접 개선하지는 않는다. 명시적 회복 설정은 기반 모델에 이미 존재하는 능력만을 이끌어낼 수 있을 뿐, GUI 이해·상태 추적·행동 계획의 근본적 결함을 보완하지는 못한다. 따라서 회복 능력이 약한 전문가형 에이전트는 명시적 회복을 적용해도 추가적인 궤적 이탈을 유발해 작업 성공률을 오히려 낮출 수 있다. 이 격차를 메우려면 오류 상태·목표 상태·교정 행동 궤적에 대한 회복 인지형 사후학습이나, 잠재적 환경 상태를 추적하고 행동에 따른 전이를 예측하는 보조 목적함수 등이 필요할 수 있으나, 이러한 방법을 설계·검증하는 것은 본 논문의 범위를 벗어난다고 명시한다.

시사점

컴퓨터 사용 에이전트의 실패 처리 능력을 평가할 때, 단순히 '회복에 성공했는가'를 넘어 '복원된 상태가 실제로 원래 상태와 동등한 후속 결과를 내는가'라는 엄밀한 기준(전이 일관성)으로 측정해야 함을 보여준다. 또한 현재 모델들이 회복 능력을 '갖추지 못한 것'이 아니라 '갖고 있으면서도 활용하지 못하는 것'이라는 발견은, 향후 에이전트 학습이 전방 작업 수행 능력뿐 아니라 실패 인지와 자발적 회복 행동을 유도하는 방향으로 설계되어야 신뢰할 수 있는 장기 자동화가 가능함을 시사한다.
