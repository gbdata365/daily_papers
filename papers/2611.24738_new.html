Jeveration: System One Models Now Generate

제버레이션: 시스템 원 모델이 이제 생성한다

한 줄 요약

Jeveration은 고정된(frozen) 비전-언어 모델이 "시스템 원(System One)" 방식의 빠른 병렬 타입 결정(typed decision)만으로 텍스트-투-이미지 생성, 이미지-투-이미지 생성, 덴스 예측(분할·깊이·법선)까지 단 한 번의 순전파(forward pass)로 수행하게 만든 연구다.

배경 및 문제의식

기존 이미지 생성은 오토회귀 모델(토큰 단위 순차 생성)이나 확산 모델(반복적 디노이징)처럼 하나의 이미지를 만드는 데 여러 번의 순차적 모델 평가가 필요해 지연시간이 크다. 한편 "시스템 원" 모델(Jev 등)은 선택지 선택, 점수 매기기 등 빠른 병렬 응답을 내는 의사결정 모델로 다양한 과제에 쓰여 왔지만 이미지 자체를 생성하는 데는 활용된 적이 없었다. 저자들은 비전-언어 모델이 사전학습으로 축적한 시각·의미 지식이 이미지 합성에도 쓰일 수 있다고 보고, 시스템 원 모델이 직접 이미지를 생성할 수 있는지를 탐구한다. 핵심 난제는, 각 이미지 코드 위치를 독립적으로 병렬 선택하면 하나의 프롬프트에 대해 서로 다른 유효한 이미지들의 조각이 뒤섞여 전역적으로 일관성 없는 이미지가 만들어진다는 점이다.

핵심 기여

  • 시스템 원 모델이 단일 순전파로 텍스트-투-이미지 및 이미지-투-이미지 생성을 수행할 수 있음을 최초로 제시.
  • 모든 코드 위치를 하나의 공유 랜덤 상태(shared random state)에 조건화해 병렬 결정들이 하나의 일관된 이미지로 수렴하도록 학습시키는 방법 제안.
  • 하나의 체크포인트로 텍스트-투-이미지 생성, 이미지-투-이미지 생성, 덴스 예측(분할·깊이·법선)을 모두 수행.

방법론

Jeveration은 고정된 Qwen3.5-4B VLM에 LoRA 어댑터만 추가하고, 입력 뒤에 "결정 토큰(decision token)"을 덧붙여 이미지 생성을 위한 코드북 선택이나 덴스 예측을 위한 공간 쿼리로 사용한다. 이미지 생성 시 128개의 TA-TiTok 코드를 위치마다 하나씩 선택하는데, 모든 위치가 하나의 공유 랜덤 상태 ξ에서 함께 조건화되어 각 추출이 서로 다르지만 일관된 이미지를 만들도록 유도한다. 학습은 2단계로 진행된다. 1단계에서는 마스킹된 코드 예측으로 이미지 분포 자체를 학습하는 마스크드 모델을 만들고, 2단계에서는 이 1단계 모델을 교사로 삼아 분포 매칭(distribution matching)과 신뢰도 기반 보정(낮은 신뢰도의 코드를 재마스킹한 뒤 보정된 타깃으로 재학습)을 통해 병렬 결정들이 서로 조율되도록 학습한다. 덴스 예측(분할/깊이/법선)은 NYUv2 데이터로 지도학습한다.

실험 설정 및 결과

H200 GPU 1장에서 512×512 이미지를 78ms 만에 생성하며, 이는 비교 대상 중 가장 느린 Janus-Pro-7B 대비 122배 빠르다. GenEval 0.74를 달성해 Show-o Turbo, JanusFlow, MMaDA 등 기존 통합(unified) 모델들보다 품질과 속도 모두에서 우수했다. 이미지-투-이미지 생성에서는 HED 엣지 F1 0.880, 깊이 δ1 0.802, 색상화 엣지 F1 0.937을 기록했다. 덴스 예측(NYUv2)에서는 mIoU 67.7로 DeepLabV3+보다 14.2포인트 높고 깊이 오차는 약 32% 낮았다. 모든 과제를 함께 학습해도 텍스트-투-이미지 품질 저하는 거의 없었다(통합 학습 GenEval 0.74 대 텍스트-투-이미지 단독 학습 0.73).

한계점

공유 랜덤 상태 없이 직접 병렬 선택하면 코드들이 서로 다른 이미지에 속해 비일관적인 결과가 나오며(GenEval 0.32에 불과), 표면 법선(surface normal) 예측은 다른 덴스 예측 과제보다 성능이 다소 떨어졌는데, 저자들은 이를 세밀한 지역 기하 정보가 공유 용량 배분에 특히 민감하기 때문으로 추정한다. 또한 학습에는 1단계 마스크드 모델, 2단계 보조 모델, 보정 교사 모델이 별도로 필요하며, 이 구성 요소들은 추론 시에는 쓰이지 않고 단일 순전파 모델만 남는다.

시사점

이미지 생성을 "병렬 타입 결정"이라는 제3의 패러다임으로 재정의함으로써, 오토회귀나 확산 방식 없이도 고정된 VLM 하나로 생성과 이해(덴스 예측)를 통합할 수 있음을 보였다. 저자들은 이 패러다임이 다른 시각 과제와 모달리티로도 확장될 수 있을 것으로 기대한다.
