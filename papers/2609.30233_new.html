Coding Agents for Generalized Task and Motion Planning Problems

일반화된 과제 및 동작 계획 문제를 위한 코딩 에이전트

Claude Code, Codex 같은 코딩 에이전트가 로봇의 과업·동작 계획(TAMP) 문제를 위한 범용 프로그램을 직접 합성하도록 시켜본 결과, 사람이 직접 설계한 플래너보다도 더 뛰어난 성능을 보였다는 대규모 실증 연구.

한 줄 요약

Claude Code, Codex 같은 코딩 에이전트가 로봇의 과업·동작 계획(TAMP) 문제를 위한 범용 프로그램을 직접 합성하도록 시켜본 결과, 사람이 직접 설계한 플래너보다도 더 뛰어난 성능을 보였다는 대규모 실증 연구.

배경 및 문제의식

과업·동작 계획(TAMP)은 완전한 관측 가능성과 객체 중심 상태가 주어져도 이산적 결정이 기하학적·운동학적·동역학적 제약과 긴밀히 얽혀 있어 여전히 어렵다. 범용 TAMP는 문제 인스턴스 간의 규칙성을 활용해 새로운 인스턴스에서의 계획 부담을 줄이려 하지만, 기존 방법들은 TAMP 특화 엔지니어링을 대량으로 요구한다. 저자들은 코딩 에이전트가 이러한 엔지니어링 과정을 자동화해 인스턴스 전반에 일반화되는 프로그램을 합성할 수 있는지를 묻는다.

핵심 기여

  1. Claude Code(Opus 5)와 Codex(GPT-5.6 Sol, GPT-6 Astra)를 KinDER·PDDLStream의 28개 시뮬레이션 환경에서 평가하는 대규모 실증 연구 수행(생성된 프로그램 980개, 평가 에피소드 총 9만 8천 건).
  2. 코딩 에이전트가 손으로 설계한 플래너, 원샷 생성, LLM 기반 범용 계획 베이스라인을 모두 능가한다는 것을 확인.
  3. 에이전트가 상호작용을 통해 물리 모델을 보정하고 경계 사례를 시험하며 전략을 다듬는 과정을 로그로 분석.
  4. 에이전트에게 제공한 전체 프롬프트를 포함한 모든 코드를 공개.

방법론

각 에이전트는 과업 설명과 시뮬레이터 접근 권한을 받고, 정해진 합성 예산 내에서 환경과 어떻게 상호작용할지 스스로 선택하며 프로그램을 개발한다. 개발이 끝나면 프로그램은 고정(freeze)되어 훈련에 사용되지 않은(held-out) 새로운 인스턴스 100개에서 평가된다. 이 과정을 KinDER와 PDDLStream 데이터셋의 28개 환경에 대해 원 벤치마크보다 많은 객체 수를 포함한 조건으로 반복해, 세 가지 에이전트 구성으로 총 980개 프로그램을 생성하고 9만 8천 건의 평가 에피소드를 수행했다.

실험 설정 및 결과

플래너가 존재하는 16개 환경 기준으로, 세 에이전트 구성 모두 평균 성공률 56~95%를 기록해 손으로 설계한 플래너(47%), 원샷 생성, LLM 기반 범용 계획 베이스라인을 모두 앞질렀다. 객체 수가 늘어날수록 에이전트가 만든 프로그램은 플래너보다 높은 성공률을 유지했고, 인스턴스당 계산량은 평균적으로 한 자릿수 이상 적었다. 로그 분석 결과 에이전트들은 상호작용을 통해 물리 모델을 보정하고 경계 사례를 시험하며 전략을 정교화하는 모습을 보였다.

한계점

연구 설정은 완전히 관측된 객체 중심 상태와 합성 단계에서의 시뮬레이터 접근을 전제로 하므로, 지각 불확실성이 있는 환경에서의 성능은 검증되지 않았다. 또한 사용된 모델들의 학습 데이터가 공개되지 않아 벤치마크 코드에 대한 사전 노출 가능성을 완전히 배제할 수는 없지만, 합성 로그에 나타난 환경 탐색·시험·수정 과정과 예상치 못한 전략들은 단순 암기가 아니라는 정황 증거로 제시된다.

시사점

코딩 에이전트가 기하학적·운동학적·동역학적 제약이 얽힌 환경에서도 별도의 상징적 모델이나 스킬, 샘플러 없이 상호작용만으로 환경의 작동 방식과 해결 전략을 스스로 발견할 수 있음을 보여주며, 범용 TAMP를 위한 강력한 베이스라인으로서 코딩 에이전트의 가능성을 제시한다.
