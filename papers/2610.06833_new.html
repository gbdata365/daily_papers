Towards Looped Models Done Right, Part II: Rethinking at Fixed Points

한 줄 요약

루프드(looped) 언어 모델의 반복 상태가 고정점(fixed point)에 가까워진다는 성질을 체계적으로 활용하여, 학습·디코딩·프리필·강화학습(RL) 전 단계에서 반복 경로 전체를 계산하지 않고 종료 상태(endpoint)만으로 대체함으로써 비용을 크게 줄이는 방법을 제안한 연구이다.

배경 및 문제의식

루프드 언어 모델은 동일한 블록을 여러 번 반복 적용해 테스트 시점 연산량을 늘리는 구조이지만, 반복마다 학습 시 저장해야 할 활성화, 디코딩 시 키-값(KV) 캐시, 프리필 연산, RL 롤아웃 재생 비용이 함께 증가한다는 문제가 있다. 기존 연구는 고정점을 아예 배제하고 반복 횟수를 작게 고정하는 쪽과, 고정점을 적극적으로 형성하며 깊게 반복하는 쪽으로 나뉘어 왔으나, 고정점이 실제로 이러한 비용 절감에 어떻게 기여하는지는 명확히 규명되지 않았다. 저자들은 고정점 방정식이 경로가 아닌 종료 상태만을 포함한다는 점에 주목하여, 상태가 고정점 근방에 도달하면 전체 반복 경로 대신 종료 상태만으로 충분하다는 가설을 세운다.

핵심 기여

  • 고정점이 기존에 쓰이던 두 가지 효율화 기법(절단 역전파, 터미널 KV 공유)의 이론적 근거임을 규명하고, 고정점 개념으로부터 두 가지 새로운 단축 기법(증류 프리필, RL에서의 롤아웃 상태 재사용)을 추가로 제시한다.
  • 고정점의 형성을 좌우하는 두 요소인 깊이 사전분포(depth prior)와 입력 주입(input injection) 방식을 개선한다. 기존 Huginn의 고정 분포 대신 예측 피드백으로부터 학습되는 깊이 사전분포(learned depth prior)와, 상태의 캐리오버 성분 중 입력 방향 성분을 제거하는 직교 입력 주입(OrthoInj)을 제안한다.
  • 100M에서 1.6B 파라미터 규모까지 실험하여, 학습된 사전분포와 직교 주입이 모든 규모에서 기존 방식보다 낮은 perplexity와 더 나은 다운스트림 성능을 보임을 확인한다.

방법론

모델은 Huginn 스타일의 루프드 Llama 트랜스포머로, 비공유 prelude 블록, 공유되는 재귀 코어(recurrent core) 블록, 비공유 coda 블록으로 구성되며 재귀 코어가 입력을 매 반복마다 주입하며 R회 반복된다. 저자들은 먼저 토큰별 상태 변화율로 수렴을 측정해, 시퀀스 내 토큰들이 서로 다른 깊이에서 이질적으로(heterogeneous) 수렴함을 보인다. 이어 고정점 근방에서는 (1) 학습 시 마지막 b개 반복만 역전파하는 절단 BPTT가 전체 경로 역전파를 근사하고, (2) 디코딩 시 각 프리픽스 토큰의 터미널 KV 뱅크만 캐싱해도 손실이 거의 없으며, (3) RL 업데이트 시 저장된 롤아웃 종료 상태에 Neumann 급수 근사를 적용해 전체 경로 재생 없이 그래디언트를 계산할 수 있고, (4) 프리필 단계는 teacher의 반복 종료 상태를 직접 예측하는 경량 학생 네트워크로 증류될 수 있음을 이론(고정점 수렴에 대한 Lemma 1)과 실험으로 뒷받침한다. 이러한 혜택을 극대화하기 위해, 학습된 깊이 사전분포는 범주형 분포를 예측 품질(보상)에 대한 정책 경사 방식으로 학습하되 엔트로피 정규화 항으로 분포가 지나치게 좁아지는 것을 방지하고, 목표 평균 깊이를 유지하는 예산 제약 항을 추가한다. 직교 입력 주입(OrthoInj)은 상태의 캐리오버 성분에서 입력 벡터 방향의 성분을 투영 제거하여, 모든 반복이 동일한 세기로 입력을 받도록 한다.

실험 설정 및 결과

Llama 기반 루프드 모델을 S(100M), M(400M), L(1.6B) 세 규모로, 각각 21.5B~343.6B 토큰으로 학습하였고 TxT360 혼합 데이터셋과 Jais64k 토크나이저를 사용했다. 평가는 MixVal 및 WikiText-103 perplexity, LAMBADA/HellaSwag/PIQA/ARC/OpenBookQA/SciQ 등 다운스트림 분류 과제, GSM8K/DROP/MBPP+ 등 생성 과제로 이루어졌다. 주요 결과는 다음과 같다: (1) 고정 깊이 학습은 터미널 KV 공유와 양립하지 못해 GSM8K 정확도가 절반 이하로 떨어지는 반면, 학습된 사전분포는 공유를 유지하면서 Huginn의 고정 Poisson-log-normal 사전분포 대비 모든 규모에서 검증 perplexity를 낮춘다. 1.6B 규모에서는 KV 캐시를 3배 줄이면서도 전체 캐시를 쓰는 고정 깊이 학습과 비슷한 다운스트림 평균 성능을 달성한다. (2) OrthoInj는 DEQ-QKV, Huginn-Linear, Parcae-Decay 등 기존 입력 주입 방식보다 모든 규모에서 낮은 검증/학습 손실과 더 높은 다운스트림 평균을 기록한다. (3) RL(Dr. GRPO, GSM8K/MBPP+)에서 롤아웃 상태 재사용은 전체 역전파 대비 채점·역전파 시간을 약 2배 단축하면서 pass@1 성능은 오차범위 내로 유지된다. (4) 증류된 프리필 학생 모델은 teacher 대비 최대 1.79배 빠른 프리필을 제공하며 다운스트림 평균 점수 하락은 1.0~4.5점 수준에 그친다.

한계점

저자들은 최대 1.6B 파라미터, 시드 1개 구성까지만 실험했으며 더 큰 규모나 다른 모델 구성에 대해서는 검증하지 못했다고 명시한다. 또한 이러한 기법들이 실제 응용 환경에서 갖는 실용성은 추가 연구가 필요하다고 밝히고 있다.

시사점

이 연구는 루프드 모델의 설계를 "반복 횟수를 늘리는 것" 자체가 아니라 "고정점을 어떻게 형성하고 활용하는가"의 문제로 재구성한다. 깊이 사전분포와 입력 주입이라는 두 가지 학습 설계 선택이 고정점의 질을 좌우하며, 이를 잘 설계하면 학습·추론·후속 강화학습 전 과정에서 반복 깊이에 비례해 증가하던 비용을 종료 상태 기반 연산으로 대체할 수 있다는 점에서, 더 깊은 루프드 모델을 실용적으로 확장하는 데 중요한 방향을 제시한다.
