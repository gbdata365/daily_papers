TailSteer: Trajectory-Tail Steering for Drift-Resistant Multi-turn Image Editing

TailSteer: 드리프트에 강한 멀티턴 이미지 편집을 위한 궤적-테일 스티어링

TailSteer는 디노이징 궤적(denoising trajectory)의 마지막 구간(tail)에만 보존(preservation) 교정을 집중시키는 파인튜닝 기법으로, 모델 자신의 온폴리시(on-policy) 롤아웃에서 얻은 지도 신호만으로 기존 편집·생성 능력을 거의 그대로 유지하면서 15~20회에 걸친 멀티턴 이미지 편집에서의 누적 드리프트(cumulative drift)를 크게 줄인다.

한 줄 요약

TailSteer는 디노이징 궤적(denoising trajectory)의 마지막 구간(tail)에만 보존(preservation) 교정을 집중시키는 파인튜닝 기법으로, 모델 자신의 온폴리시(on-policy) 롤아웃에서 얻은 지도 신호만으로 기존 편집·생성 능력을 거의 그대로 유지하면서 15~20회에 걸친 멀티턴 이미지 편집에서의 누적 드리프트(cumulative drift)를 크게 줄인다.

배경 및 문제의식

최근 Nano Banana 2, ChatGPT Images, Reve, Muse Image 등 대화형·반복적 이미지 편집 워크플로우가 널리 쓰이면서, 사용자는 한 번에 완성된 결과를 요청하기보다 자연어 피드백으로 이미지를 여러 턴에 걸쳐 점진적으로 수정한다. 그런데 단일 턴(single-turn) 편집에 강한 모델도 편집 결과를 다시 입력으로 재사용하는 멀티턴 상황에서는 작은 오류가 턴마다 누적되어, 미세한 텍스처 손실, 비대상 객체·얼굴 디테일 변형, 배경 구조 왜곡 등 눈에 보이는 드리프트로 이어질 수 있다.

기존 해결책은 크게 세 갈래로 나뉜다. (1) 마스크 기반 공간 가이던스, LoRA 어댑터, 주파수 보정 등 보조 모듈/제약을 추가하는 방식은 사전학습된 생성 prior를 일부 희생시키며 적용 가능한 편집 범위가 제한된다. (2) VAE 표현 공간을 개선하거나 픽셀 디퓨전으로 VAE를 우회하는 방식은 단일 턴 오류는 줄이지만 반복 편집에서는 여전히 성능이 저하된다. (3) 과거 잠재 상태나 시각적 컨텍스트를 캐싱하는 메모리 기반 방식, 혹은 에이전트형 추론·계획 방식은 기반 모델 자체의 강건성을 직접 개선하지 못하고 추가 추론 오버헤드를 동반한다. 저자들은 이 세 방향 모두 보조 모듈, 대안 표현, 별도 모델을 필요로 한다는 공통된 한계를 지적하며, 기반 모델 자체를 직접 개선해 멀티턴 강건성을 내재화하는 접근을 제안한다.

핵심 기여

  • 디노이징 궤적에서 저주파 구조는 초반에 빠르게 자리잡고 고주파 디테일은 궤적 끝(tail) 부근에서 주로 결정된다는 관찰(coarse-to-fine 진행)에 기반하여, 궤적 tail이 멀티턴 편집 드리프트를 교정할 수 있는 핵심 개입 지점임을 제시함.
  • TailSteer라는 최종 단계(final-stage) 학습 프레임워크를 제안. 모델 자신의 온폴리시 디노이징 롤아웃에서 보존 지도 신호를 얻어, 초반 디노이징 동역학은 base 모델과 거의 동일하게 유지하면서 tail 부분만 점진적으로 보존 지향 엔드포인트로 스티어링함.
  • Add & Preserve라는 평가 벤치마크를 새로 도입해, 누적 시각적 드리프트와 편집 완료도(지시 수행 여부)를 분리하여 측정할 수 있도록 함. 이를 통해 FLUX, SenseNova, Qwen 계열 모델 전반에서 base 모델의 역량을 거의 유지한 채 장기 편집 보존 성능을 크게 향상시켰음을 입증.

방법론

TailSteer는 세 단계로 구성된다.

  1. 보존 지향 궤적 엔드포인트 구성(data-free): 사람이 직접 큐레이션한 source-target 편집 쌍 대신, (a) "변화 없음"을 요구하는 identity editing과 (b) 특정 영역만 바꾸는 local editing 두 가지 프롬프트로 frozen base 모델의 롤아웃을 생성한다. identity/locality 체크를 통과한 결과만 채택하고, local editing의 경우 원본과 결과의 차이로부터 이진 보존 마스크 M을 만들어 x_tgt = M⊙x_src + (1-M)⊙x_base로 보존 지향 엔드포인트를 구성한다(식 1). 즉 모델이 선택한 편집 실현(realization)은 그대로 두고, 바뀌지 않아야 할 영역만 원본으로 복원한 타깃을 만든다.
  2. 단일 스텝(one-step) 터미널 개입 검증: 가장 단순한 형태로, 마지막 샘플링 스텝에서만 base 모델을 이 엔드포인트로 향하도록 파인튜닝(식 2~3)해본 결과, FLUX.2 [klein] Base 9B에서 마지막 스텝에만 파인튜닝 모델을 적용했을 때 20턴까지도 드리프트가 뚜렷이 줄었다. 반면 전체 50스텝에 파인튜닝 모델을 적용하면 디테일이 뭉개지고 彩도(채도)가 떨어지는 trade-off가 나타나, 초반 동역학 보존이 필요함을 확인했다.
  3. TailSteer(전체 방법): steering onset k_s를 기준으로 궤적을 prior 영역(0~k_s, base 동역학 재현)과 transition 영역(k_s~τ, 점차 보존 쪽으로 전환)으로 나눈다. 캐시된 anchor 상태에서 refined 모델 자신이 롤아웃하여 도달한 상태 x_k에서, frozen base 모델의 속도 v_base와 엔드포인트 지향 속도 v_pres를 가중치 λ(k)로 블렌딩한 타깃 v*를 계산하고(식 4), 이를 MSE 손실(식 5)로 학습한다. 모든 지도 신호는 refined 모델 자신이 도달한 상태에서 온폴리시로 재계산되며, 추론 시에는 추가 모듈이나 모델 전환 없이 refined 모델 하나가 전체 샘플링을 수행한다.

학습 데이터는 Open Images와 MONET에서 추출한 11,947장의 후보 소스 이미지에 각각 local-edit 지시 3개와 identity-edit 지시 1개를 매칭해 생성했으며, 백본별로 독립적으로 트레일젝토리를 생성·필터링했다. 8×H100 GPU, BF16, 유효 배치 16으로 2,000 업데이트 학습했다.

실험 설정 및 결과

FLUX.1 Kontext dev, FLUX.2 [klein] Base 9B(50 steps), SenseNova-U1.5-8B-MoT(50 steps), Qwen-Image-2.1(40 steps) 4개 백본에 대해 각각 3가지 steering onset을 실험했다.

  • 단일 턴 역량 유지(Table 1): Qwen-Image-Bench, BizGenEval(텍스트-이미지 생성)과 GEdit-Bench, RISEBench, ImgEdit-Bench(단일 턴 편집)에서 TailSteer 적용 모델은 base 모델과 거의 동등한 점수를 유지했으며, FreqEdit·ConsLoRA 같은 비교 기법은 GEdit 등에서 더 큰 성능 하락을 보였다.
  • 일반 멀티턴 편집(Table 2): MSE-Bench(5턴), EdiVal-Bench 기준으로 TailSteer는 대부분 설정에서 EdiVal content consistency를 높이고 선택된 steering onset에서 MSE-Bench 성공률을 개선했으나, instruction-following 향상은 일관적이지 않았다.
  • Add & Preserve(저자 신규 벤치마크, 100장 이미지, 10턴 연속 추가/제거 편집): 박스 바깥 영역의 PSNR/SSIM/LPIPS로 드리프트를, 박스 안 Cumulative Object Accuracy(COA)로 편집 완료도를 분리 측정한 결과, TailSteer는 COA를 base 모델 수준으로 유지하면서도 드리프트를 크게 줄였다. 특히 TailSteer-Klein은 PSNR/SSIM/LPIPS 세 지표 모두에서 GPT-Image-2.5 Sunburst(API 호출)를 능가했고, TailSteer-SenseNova도 COA를 거의 유지하면서 드리프트를 줄였다.
  • 정성 비교(Fig. 6, 7): 20턴 비교에서 training-free MTC는 디테일을 잃고 VINCIE(비디오 데이터 학습)는 심한 저하를 보인 반면, TailSteer는 커피잔·라떼아트·쿠키 등 초기에 생성된 디테일과 테이블 색을 끝까지 유지했다. 멀티 이미지 입력(스켈레톤 가이드, 다중 객체/인물 합성)에서도 compositing 능력을 유지하며 배경 드리프트를 줄였다.
  • VAE 재구성 영향: 턴 사이 반복적인 VAE 인코딩/디코딩도 색 왜곡 등 드리프트 원인이 될 수 있음을 발견했고, Klein 백본에서 latent feedback(턴 간 VAE 우회)을 TailSteer와 결합하면 10턴 PSNR이 기존 방식의 5턴 수준에 도달하는 추가 개선을 확인했다.
  • 학습 전략 어블레이션(Table 3, Fig. 10): 동일 데이터로 비교했을 때, 표준 SFT는 드리프트는 줄이지만 instruction following이 약화되고(객체 제거 실패 등), tail만 학습하거나 last-step만 학습하는 변형은 각각 편집 능력 저하 또는 전체 궤적 추론 시 더 큰 성능 저하를 보였다. 온폴리시 학습을 제거하면 보존 성능은 유지되나 공간적 추론(치즈를 삼각형으로 배열하는 등)에 실패했다. 전체 TailSteer가 보존-편집 능력 균형에서 가장 우수했다.
  • 데이터 스케일/트레일젝토리 유형 어블레이션(Table 4): 데이터가 적을 때는 local-edit 트레일젝토리가 identity-edit보다 보존 효과가 더 크지만 데이터가 커질수록 그 차이는 줄어들며, identity+local(3:1) 혼합 및 데이터 규모 확대가 전반적으로 드리프트 저항을 개선함을 확인했다(최종 설정: 38,540개 트레일젝토리).

한계점

본문에서 명시적으로 언급된 한계로는: (1) MSE-Bench 등 일반 멀티턴 벤치마크에서 instruction-following 성능 향상이 steering onset이나 설정에 따라 일관되게 나타나지는 않는다는 점, (2) 집계된 멀티턴 성공률만으로는 "모델이 원래 못 푸는 지시"와 "이전 턴에서 누적된 시각적 저하로 인한 실패"를 구분하기 어렵다는 점(이 때문에 Add & Preserve 벤치마크를 별도로 설계함), (3) VAE 기반 편집기에서 턴 간 반복 인코딩/디코딩에서 오는 색상 변화(residual color shift)가 TailSteer 단독으로는 완전히 해결되지 않으며, latent feedback 등 추가 보완이 필요하다는 점이 제시됨. 그 외 계산 비용, 특정 편집 유형(식별 편집·로컬 편집 기반 데이터)에 한정된 학습 데이터 구성이 가질 수 있는 일반화 한계 등은 논문에 명시적으로 논의되지 않음.

시사점

TailSteer는 "멀티턴 강건성을 처음부터 다시 학습할 필요 없이, 기반 모델이 각 편집을 완성하는 방식을 정교화함으로써 풀어낼 수 있다"는 관점을 제시한다. 보조 모듈이나 외부 메모리, 모델 교체 없이 디노이징 궤적의 tail만 겨냥한 최종 단계 파인튜닝으로 FLUX·SenseNova·Qwen 등 서로 다른 아키텍처/표현 방식에 걸쳐 일관되게 적용 가능하다는 점에서, 오픈 웨이트 기반 모델이 특정 장기 편집 시나리오에서 GPT-Image-2.5 Sunburst 같은 상용 모델과 경쟁하거나 능가할 수 있음을 보여준다. 또한 사람이 큐레이션한 ground-truth 편집 쌍이나 cross-turn 학습 데이터 없이 모델 자신의 롤아웃만으로 지도 신호를 구성하는 "데이터-프리(data-free)" 패러다임은, 대규모 파운데이션 모델에 멀티턴 강건성을 이식하는 데 드는 데이터 큐레이션 비용을 크게 줄일 수 있는 실용적 방향을 제시한다.
