Questioning the Questions: Sustaining Self-Evolution in Reasoning Models

질문을 다시 묻다: 추론 모델의 자기진화를 지속시키는 방법

스스로 문제를 만들고 풀며 진화하는 추론모델(questioner-solver 자기진화)이 라운드를 거듭할수록 성능이 붕괴하는 원인을 "무효 질문 증가"와 "동일 과제의 변형 반복"으로 규명하고, 이를 해결하는 R-Quest 기법으로 10라운드까지 안정적인 성능 향상을 유지시켰다.

한 줄 요약

스스로 문제를 만들고 풀며 진화하는 추론모델(questioner-solver 자기진화)이 라운드를 거듭할수록 성능이 붕괴하는 원인을 "무효 질문 증가"와 "동일 과제의 변형 반복"으로 규명하고, 이를 해결하는 R-Quest 기법으로 10라운드까지 안정적인 성능 향상을 유지시켰다.

배경 및 문제의식

R-Zero와 같은 자기진화형(self-evolving) 추론모델은 questioner가 문제를 생성하고 solver가 이를 풀면서 GRPO로 번갈아 학습되는 구조를 취한다. 이 과정은 사람이 만든 데이터 없이도 모델이 스스로 학습 데이터를 조달할 수 있게 해주지만, 라운드가 반복되면 초반의 성능 향상이 역전되어 최종적으로는 기반 모델(base model)보다도 낮은 성능으로 붕괴하는 현상이 보고되어 왔다. 저자들은 이 붕괴의 실질적 원인을 자기생성 질문(self-generated question) 자체의 품질 문제에서 찾는다. R-Zero가 생성한 질문을 분석한 결과 두 가지 반복적 품질 문제를 발견했다: (1) 정의가 모호하거나 조건이 누락·모순되는 "무효 질문"이 라운드를 거칠수록 급격히 늘어나며, 기존의 답변 일치도(answer-consistency) 기반 필터링이 오히려 무효 질문의 비율을 더 높이는 역효과를 낸다. (2) questioner가 표현(단어, 표기, 수치)만 바꿔 동일한 수학적 과제를 반복 생성하는데, 기존의 BLEU 등 어휘적 유사도 기반 다양성 제어는 이런 "같은 문제, 다른 옷"을 서로 다른 클러스터로 분산시켜 반복 패널티를 무력화시킨다.

핵심 기여

  • R-Zero의 5라운드 데이터를 직접 분석하여, 유효 질문 비율이 1라운드 76.5%에서 5라운드 39.5%로 급락하고, 답변 일치도 필터링 후에는 27.64%까지 더 떨어진다는 것을 실증했다.
  • 무효 질문을 동일 조건에서 "복구(repair)"한 데이터로 학습했을 때 solver 성능이 46.54%→49.91%로 개선됨을 보여, 무효 질문이 성능 붕괴의 실질적 원인임을 입증했다.
  • BLEU 클러스터링이 동일한 수학적 과제를 최대 22개의 서로 다른 클러스터로 쪼개는 현상을 확인하여 어휘 기반 다양성 제어의 한계를 드러냈다.
  • 위 두 진단에 기반해 solver가 무효 질문을 스스로 판별·거부하도록 학습시키고, 고정된(frozen) 베이스 모델로 질문 쌍을 비교해 과제 수준의 참신성(novelty)을 판단하는 R-Quest를 제안, 외부의 더 강력한 모델 호출 없이 자기진화 중에 지속적으로 피드백을 생성한다.

방법론

R-Quest는 두 가지 피드백 신호로 questioner의 보상을 설계한다. 1) 유효성 인지 초기화(Validity-aware solver initialization): R-Zero 5라운드 데이터에서 중복 제거된 질문들을 GPT-5.6-Sol로 2단계 주석(유효성 판정 후 정답 생성)하여 2,240개 데이터셋(유효 923 / 무효 1,317)을 구축한다. 이 데이터로 solver를 GRPO로 사전 학습시켜, 질문이 유효하면 정답을, 질문 자체에 결함이 있으면 "INVALID"를 반환하도록 학습한다. 보상식은 정답 일치 시 +1, 유효한 질문을 잘못 거부(과도한 기각)할 경우 λ만큼 패널티를 부여하는 방식이다. 2) 표본 기반 쌍대비교로 참신성 평가: 매 GRPO 롤아웃 배치에서 각 후보 질문마다 다른 질문 K개(기본값 8개)를 무작위로 뽑아 고정된 베이스 모델에게 "동일한 수학적 과제인지"를 판정하게 한다. 전체 쌍(O(B²))을 다 비교하는 대신 O(BK)로 비용을 줄이면서도, 하나라도 동일 유형으로 판정되면 해당 질문을 참신하지 않다고 간주(거부)한다. 3) 질문자 보상 결합: 질문이 다수 응답 기준으로 무효(invalid 응답 비율 과반)로 판정되면 보상은 유효성 게이트 값만 반영하고, 유효로 판정되면 참신성 게이트(통과 시 1)와 불확실성 보상(답변 분산이 1/2에 가까울수록 높은 보상)의 곱으로 보상을 준다. solver 갱신 시에는 동일한 유효성 체크와 답변 일치도 필터링을 거친 데이터로 GRPO 학습을 하며, 초기화 데이터의 일부(10%)를 계속 리플레이하여 유효성 판별 능력이 퇴화하지 않도록 유지한다.

실험 설정 및 결과

Qwen3-4B-Base와 OctoThinker-3B-Hybrid-Base(Qwen 및 Llama 계열) 두 모델에 대해 base model, R-Zero, OCNR, R-Diverse와 비교했다. 수학 추론 7개(AMC, Minerva, MATH, GSM8K, OlympiadBench, AIME24/25), 범용 추론 3개(SuperGPQA, MMLU-Pro, BBEH), 코드 생성 2개(HumanEval+, MBPP+) 총 12개 벤치마크에서 평가했다. R-Quest는 두 모델 모두에서 전 영역 평균 최고 점수를 기록했으며(Qwen3-4B-Base 수학 평균 51.64%, 코드 62.69%, 범용 32.75%), R-Zero보다 수학에서 2.54점, 코드와 범용 추론에서도 모두 우세했다. 특히 10라운드까지 자기진화를 확장한 실험에서 R-Zero는 3라운드에 49.10%로 정점을 찍은 뒤 10라운드에 34.60%(기반 모델보다 11.57점 낮음)까지 붕괴했지만, R-Quest는 10라운드에 51.92%로 최고점을 기록하며 동일 라운드에서 R-Zero를 17.32점 앞섰다(기반 모델보다 5.75점 높음). 구성요소 제거 실험에서 유효성 피드백과 참신성 피드백 모두 성능에 기여했으며, 특히 유효성 피드백 제거 시 후반 라운드에서 급격한 붕괴가 나타나 유효성 피드백이 지속가능성에 더 critical했다. 추가 분석에서 R-Quest의 solver는 라운드가 진행될수록 무효 질문 탐지율(invalid recall)이 10.23%→86.36%로 크게 향상되었고, 자기생성 질문의 유효 비율도 88.0%→94.5~97.5%로 유지된 반면 R-Zero는 76.5%→49.0%로 떨어졌다. 다수결 정답 정확도 역시 R-Quest는 10라운드에 54.69%를 유지했지만 R-Zero는 2.06%까지 추락했다.

한계점

논문에 명시적인 "한계점" 절은 없으나, 본문 분석에서 드러난 제약으로는 참신성 게이트의 강도(K값)를 너무 높이면(K=16) 반복 패턴 억제는 강해지지만 오히려 수학 성능이 하락하여, 탐색(새로운 유형)과 기존 유형 내 난이도 향상 사이의 균형을 맞추는 것이 까다롭다는 점이 있다. 또한 유효성 인지 초기화 데이터 구축과 검증에는 GPT-5.6-Sol이라는 외부 강력 모델의 주석이 필요하며, 자기진화 과정 자체는 외부 모델 호출 없이 돌아가지만 초기 데이터셋 품질에 의존한다. 실험도 수학 중심 커리큘럼을 기반으로 하며 비교적 중소형 모델(3B~4B) 두 계열에 대해서만 검증되었다.

시사점

이 연구는 자기진화형 추론모델의 성능 붕괴가 단순한 과적합이나 보상 해킹이 아니라, 자기생성 데이터 자체의 "품질"(유효성과 과제 수준 다양성) 문제에서 기인할 수 있음을 구체적으로 보여준다. 외부의 더 강한 모델 호출 없이 모델 스스로 질문의 유효성과 참신성을 평가하도록 학습시키는 접근은, 데이터 큐레이션 비용 없이 자기진화를 장기간 지속시킬 수 있는 실용적 경로를 제시하며, 향후 자기개선(self-improvement) 및 self-play 기반 학습 파이프라인 설계에서 "생성된 과제 자체의 검증"을 핵심 구성요소로 고려해야 함을 시사한다.
