Inject, Align, Recover: Staged Post-Training for Retrieval-Free Document Knowledge Internalization

인젝트, 얼라인, 리커버: 검색 없는 문서 지식 내재화를 위한 단계별 사후학습

검색(retrieval) 없이 고정된 문서 집합의 지식을 LLM 파라미터에 내재화하기 위해, 문서 노출(Inject)·QA 정렬(Align)·모델 병합을 통한 일반 능력 복원(Recover)을 분리한 3단계 사후학습 프레임워크 IAR을 제안하고, Vanilla SFT 대비 도메인 정확도와 일반 능력을 동시에 개선하는 조작점(operating point)을 다수 설정에서 달성했다.

한 줄 요약

검색(retrieval) 없이 고정된 문서 집합의 지식을 LLM 파라미터에 내재화하기 위해, 문서 노출(Inject)·QA 정렬(Align)·모델 병합을 통한 일반 능력 복원(Recover)을 분리한 3단계 사후학습 프레임워크 IAR을 제안하고, Vanilla SFT 대비 도메인 정확도와 일반 능력을 동시에 개선하는 조작점(operating point)을 다수 설정에서 달성했다.

배경 및 문제의식

검색증강생성(RAG)은 문서 기반 질의응답의 표준 해법이지만, 실제 배포 환경에서는 지연시간·프라이버시 문제로 검색이 불가능하거나, 사후학습이 실제로 모델의 파라메트릭 지식을 바꾸었는지 검증하기 위해 검색을 의도적으로 제거해야 하는 경우가 있다. 저자들은 이를 "문서 지식 내재화(document knowledge internalization)"라는 과제로 정의한다. 단순 SFT는 QA 생성기가 선택한 사실만 학습 신호로 사용되어 문서 커버리지가 희소(sparse)하고, CPT(continued pretraining)는 문서 텍스트에 밀도 높게 노출되지만 질문에 답하는 방법 자체는 가르치지 않는다. 또한 두 접근 모두 도메인 적응이 일반 지시 수행 능력을 저하시키는 파국적 망각(catastrophic forgetting) 문제를 겪는다. 따라서 도메인 지식 습득과 일반 능력의 통제된 회복을 모두 요구하는 과제로 규정한다.

핵심 기여

  • 검색 없는 고정 코퍼스 QA를 도메인 정확도와 일반 능력을 함께 측정하는 "도메인-일반 조작점" 문제로 정식화.
  • Inject(구조화된 문서 노출), Align(QA 행동 정렬), Recover(사후 모델 병합을 통한 일반 능력 복원)를 분리한 3단계 프레임워크 IAR 제안.
  • Common Corpus(CC)와 CCI 두 코퍼스, Llama-3.2-3B·Phi-4-mini·Qwen3-4B·SmolLM3-3B 네 모델 계열에 대해 Vanilla SFT, BudgetMatch, SDFT, LoRA, Replay, Base 초기화 CPT+SFT, FAPM 등 다양한 베이스라인과 비교.
  • 대부분의 설정에서 도메인-일반 프론티어가 개선됨을 보이는 동시에, 개선이 일어나지 않거나 제한적인 경계 사례(boundary case)도 함께 투명하게 보고.

방법론

IAR은 세 단계로 구성된다. 1. Inject: 원문 문서를 세 가지 지도학습(supervised) 목표로 변환한다 — Continuation(주어진 프리픽스로부터 이어지는 내용을 예측), Rewrite(요약/개요/스켈레톤으로부터 전체 문서를 복원), Instruction-formatted reconstruction(짧은 읽기 지시문으로부터 전체 문서를 예측). 이는 프롬프트/타깃 경계가 없는 raw CPT와 달리, 시스템·사용자 프롬프트 토큰을 마스킹하고 assistant 타깃에만 손실을 적용하는 지도학습 방식이다. 2. Align: Inject로 만들어진 체크포인트를 시작점으로, 문서 기반 QA 쌍에 대해 answer-only SFT를 수행해 질문-응답 인터페이스에 지식을 연결한다. 3. Recover: 도메인 적응된 체크포인트(θ_IA)와 원본 instruct 모델(θ0)을 SLERP, Task Arithmetic, TIES, DARE 네 계열의 사후 병합(post-hoc merging) 연산자로 결합한다. 검증(validation) 분할에서 도메인 정확도를 1순위 기준, IFEval·MMLU·MSBench를 가드레일(guardrail)로 삼아 정해진 12개 후보 그리드 중 하나를 규칙 기반으로 선택하며, 이 선택은 held-out 테스트 세트를 보기 전에 확정된다.

실험 설정 및 결과

CC(학습 14,258 / 테스트 750 QA)와 CCI(학습 10,926 / 테스트 575 QA) 두 코퍼스, Llama-3.2-3B, Phi-4-mini, Qwen3-4B, SmolLM3-3B 네 모델에 대해 평가하며, Qwen3-8B/14B/32B로 스케일링 실험도 수행했다. 도메인 QA는 gpt-oss-120b, MiniMax-M2.5, DeepSeek-V3 계열로 구성된 적응형 LLM 심판 패널로 채점하고, 일반 능력은 IFEval, MMLU, MSBench로 측정했다.

주요 결과로, 8개 데이터셋-모델 조합 중 7개에서 IAR이 Vanilla SFT 대비 4개 지표 모두를 개선했으며, 평균적으로 도메인 QA 정확도 +3.6%p, 일반 성능 평균 +12.1%p의 향상을 보였다. Qwen3-4B/CC에서는 도메인 정확도가 42.4%→50.5%로 상승하면서 세 일반 지표도 모두 개선되는 가장 뚜렷한 사례를 보였다. 토큰 예산을 IAR과 동일하게 맞춘 QA 반복학습(BudgetMatch)과 비교했을 때도 16개 지표 비교 중 14개에서 IAR이 우세했다. 스케일링 실험에서는 Qwen3-8B/14B/32B 전 구간에서 IAR이 Best IA(회복 이전 체크포인트) 대비 도메인 정확도를 1.1%p 이내로만 희생하면서 일반 성능을 14.9~24.1%p 회복하는 일관된 패턴을 보였다.

한계점

  • 모든 설정에서 균일하게 우위를 보이는 것은 아니며, 도메인-일반 능력 간 트레이드오프가 남아있는 경계 사례가 존재한다(예: Phi/CCI는 IFEval·MSBench는 개선되나 도메인 정확도와 MMLU는 소폭 하락).
  • 최선의 Inject 목표 혼합 비율이 모델·코퍼스마다 달라 보편적으로 최적인 단일 레시피는 없다.
  • 도메인 QA 평가가 LLM 심판 기반이라 완벽한 정답 레이블이 아니며, 저자들도 이를 "감사 가능한 도구"로 취급한다고 명시(1·2번째 심판 간 이진 일치율 .848, Cohen's κ .691).
  • 학습·데이터 순서 시드는 고정했지만 도메인 생성(temperature .7)과 심판 API 호출에는 시드가 없어, 반복 실행에 대한 견고성은 확립되지 않았다고 명시.
  • Qwen3-4B/CCI는 원본 instruct 모델이 이미 70.6%라는 매우 높은 초기 도메인 정확도를 보여, 이 설정의 결과를 일반화하기보다 "이미 강한 사전 지식을 보존·회복하는 경계 사례"로 해석해야 한다고 밝힘.
  • CPT+SFT 비교는 대부분 Base 체크포인트에서 시작하여 IAR의 Instruct 초기화와 조건이 다르며, Phi-4-mini는 대응하는 Base 릴리즈가 없어 CPT+SFT 비교 자체가 불가능했다.
  • Qwen3-8B/14B/32B 스케일링 실험은 원본 학습 로그(학습률, 배치, 시퀀스 길이 등)가 보존되어 있지 않아 재현 정보가 불완전하다고 명시.

시사점

문서 지식 내재화를 하나의 fine-tuning 레시피로 뭉뚱그리지 않고 "노출(Inject)-정렬(Align)-회복(Recover)"으로 분해함으로써, 각 단계가 실제로 기여하는 바를 독립적으로 진단할 수 있다는 방법론적 시사점을 제공한다. 이는 검색이 불가능하거나 바람직하지 않은 프라이버시·레이턴시 제약 환경에서 도메인 특화 LLM을 배포하려는 실무에 직접적으로 적용 가능하며, 특히 모델 병합(model merging)을 파국적 망각 완화 수단으로 체계적으로 활용한 사례로서 다른 도메인 적응 파이프라인에도 참고할 수 있는 설계 패턴을 제시한다.
