Adaptive Reward Routing: Dynamic Multi-Reward Optimization for Joint Audio-Video Diffusion via Forward-Process RL

한 줄 요약

오디오-비디오 동시 생성 모델을 강화학습(RL)으로 후처리할 때, 어느 위치(토큰·레이어)를 업데이트할지와 여러 보상을 어떻게 조율할지를 모델 학습 과정에 맞춰 동적으로 조정하는 Adaptive Reward Routing을 제안해 품질·정합성·동기화를 모두 개선한다.

배경 및 문제의식

오디오와 비디오를 함께 생성하는 모델은 각 모달리티의 품질, 텍스트와의 정합성, 오디오-비디오 간 시간 동기화를 동시에 만족해야 하는데, 이를 하나의 지도학습 손실로 표현하기 어렵다. 보상 기반 RL(GRPO, DiffusionNFT 등)이 대안으로 제시되었지만, 기존 방법인 OmniNFT는 레이어 라우팅을 기반 모델 상태에서 고정해버려 학습이 진행되며 교차-모달 기능과 기울기 흐름이 변화해도 따라가지 못한다. 또한 GDPO는 보상 간 충돌을 고려하지 않고 고정 가중치로 결합하며, MARBLE은 기울기 기하학에만 의존해 보상 간 '중요도'나 '책임 모달리티'를 반영하지 못해 약한 보상(예: 동기화)을 소실시킬 위험이 있다.

핵심 기여

  1. Cross-Modal Influence-Guided Routing: 추가 모델 개입 없이 양방향 교차-어텐션의 사전 게이트 응답을 교차-모달 영향력의 효율적 대리 지표로 사용, 토큰별 손실 가중치와 레이어별 기울기 스케일을 동적으로 조정.
  2. Preference-Preserving Modality-Aware Reweighting: 사용자가 설정한 선호 가중치를 기본값(prior)으로 유지하면서, 워밍업 이후 분기(branch)별 보상-기울기 상호작용에서 얻은 보정치를 잔차로 더해 변화하는 보상 충돌에 적응.
  3. 두 구성요소를 결합한 전체 최적화 흐름을 LTX-2(19B), LTX-2.3(22B) 두 백본에서 검증하고, 기존 기법(GDPO, MARBLE, OmniNFT) 대비 10개 평가지표 중 9개에서 최고 성능 달성.

방법론

DiffusionNFT의 순방향 프로세스 RL 틀 안에서, 모델은 매 라운드 샘플을 생성하며 A2V(오디오→비디오)·V2A(비디오→오디오) 교차-어텐션의 게이트 이전 응답(pre-gate response)을 수집한다. 이 응답의 크기를 레이어·토큰 축으로 각각 집계해, (1) 토큰별 손실 가중치(λ)는 교차-모달적으로 영향력이 큰 토큰을 강조하도록 정규화하고, (2) 레이어별 라우팅 계수(α)는 중요한 레이어의 기울기는 더 많이 통과시키고 약한 레이어는 점점 분리(detach)시킨다. 보상 쪽에서는 각 보상(VideoAlign, HPSv3, AudioBox, CLAP, AV-DeSync)을 해당 모달리티 분기에서만 프로빙해 MARBLE 방식의 충돌-인지 계수를 구하고, 이를 사용자가 설정한 사전 가중치에 잔차로 더해(워밍업 이후) 최종 분기별 어드밴티지를 구성한다. 이 어드밴티지로 DiffusionNFT의 양성/음성 정책 손실을 계산하고, 라우팅된 교차-모달 경로로 역전파한다.

실험 설정 및 결과

JavisBench(10,140개 프롬프트)에서 LTX-2, LTX-2.3 두 백본에 대해 GDPO, MARBLE, OmniNFT와 비교 실험을 수행했다. 제안 방법은 LTX-2 기준 VQ 3.336, AQ 5.868, JavisScore 0.206, DeSync 0.341(낮을수록 좋음)로 모든 비교 방법을 능가했으며, LTX-2.3에서도 동일한 경향을 보였다. Ablation에서는 토큰 라우팅과 레이어 스케일을 각각 추가할 때마다 성능이 점진적으로 개선되었고(GDPO 대비), 분기-인지 가중치와 잔차 보정, 워밍업을 각각 추가해도 성능이 개선됨을 확인했다. 또한 레이어별 영향력 대리 지표(사전-게이트 응답)가 실제 개입(해당 레이어 비활성화) 기반 순위와 Spearman 상관 0.97~0.98로 일치했고, 학습 초기에 고정한 대리 지표는 상관이 0.56·0.38까지 떨어져 "고정 라우팅이 금방 낡아진다(stale)"는 주장을 뒷받침했다.

한계점

저자들이 직접 명시한 한계는 다음과 같다. (1) 모달리티 품질·정합성·동기화를 동시에 포착하는 통합 보상 모델이 아직 없어 여러 개별 보상에 의존해야 한다. (2) DiffusionNFT라는 특정 순방향 RL 알고리즘에 기반해 설계되었으며, 다른 디퓨전 목적함수로의 확장은 각 알고리즘의 토큰 손실·기울기 경로 구조에 따라 달라진다. (3) 모달리티 토큰이 식별 가능하고 방향성 있는 상호작용 응답을 분리할 수 있는 이중-스트림 구조에서만 검증되었으며, 모달리티 표현이 분리되지 않는 단일 스트림 구조(예: 통합 디퓨전 트랜스포머)로의 적용은 향후 과제로 남겨졌다.

시사점

이 연구는 멀티모달·멀티보상 후처리를 "어디를 업데이트할지"와 "보상을 어떻게 조율할지"라는 두 축의 동적 신용 할당(credit assignment) 문제로 재구성한다. 고정된 라우팅 규칙 대신 모델이 스스로 획득하는 신호(사전-게이트 응답)를 재활용함으로써 추가 연산 없이 적응형 최적화가 가능함을 보여주며, 이는 향후 멀티모달 생성 모델의 RL 후처리 설계에 일반적인 지침을 제공할 수 있다.
