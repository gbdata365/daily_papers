MJev-Spatial: System One Spatial Intelligence via Native Attention Matching

MJev-Spatial: 네이티브 어텐션 매칭을 통한 시스템원 공간지능

MJev-Spatial은 선택형·수치형·좌표형 공간 질의를 모두 "유한한 후보 집합에 대한 분류" 문제로 통일하고, 백본 VLM의 사전학습된 Query/Key 투영을 그대로 재사용해 답변 토큰을 생성하지 않고 한 번의 순전파로 결정을 내리는 "System 1(직관적·즉각적 판단)" 방식의 멀티모달 공간 이해 모델이다.

한 줄 요약

MJev-Spatial은 선택형·수치형·좌표형 공간 질의를 모두 "유한한 후보 집합에 대한 분류" 문제로 통일하고, 백본 VLM의 사전학습된 Query/Key 투영을 그대로 재사용해 답변 토큰을 생성하지 않고 한 번의 순전파로 결정을 내리는 "System 1(직관적·즉각적 판단)" 방식의 멀티모달 공간 이해 모델이다.

배경 및 문제의식

공간지능(spatial intelligence)은 로봇 내비게이션이나 물체 조작처럼 실시간 상호작용이 필요한 작업에서 핵심적인 역할을 한다. 그런데 기존 비전-언어모델(VLM)들은 공간적 관계 선택, 거리·개수 같은 수치 추정, 물체를 가리키는 지점 예측과 같은 과제를 모두 자유형식 텍스트 생성으로 처리한다. 저자들은 이 방식이 두 가지 비효율을 낳는다고 지적한다. 첫째, 답을 텍스트 형태(포맷, 보일러플레이트 포함)로 재현하도록 학습시키는 과정에서 실제 공간적 판단과 무관한 부가적인 지도 신호가 섞인다. 둘째, 추론 시점에 답변 토큰을 순차적으로 생성한 뒤 다시 파싱해야 하므로 디코딩과 파싱 오버헤드가 발생한다. 반면 선택형 질문의 답은 이미 유한하고, 수치나 좌표도 적절한 범위와 해상도로 이산화하면 유한한 후보 집합으로 표현할 수 있다는 관찰에서 출발해, 후보들에 대한 확률만을 반환하는 "Jev" 계열 System 1 디코딩 방식을 공간 이해 과제로 확장한다.

핵심 기여

  1. 선택(choice), 수치 추정(길이·개수·각도), 지점 예측(pointing)이라는 세 가지 서로 다른 공간 출력 유형을 하나의 "유한 후보 집합 분류" 틀로 통합하는 System 1 패러다임을 제안.
  2. 이 틀 위에서 추가 파라미터나 새로운 예측 헤드 없이, 백본의 마지막 어텐션 층에 있는 사전학습된 Query/Key 투영만을 재사용해 후보를 채점하는 MJev-Spatial 모델과, 모든 과제·모든 세분화(coarse-to-fine) 단계를 하나의 teacher-forcing 순전파로 동시에 지도하는 통합 학습 레시피를 개발.
  3. 길이 기준 정렬(length grouping)과 GPU 간 작업 분배(load balancing)를 결합한 효율적 배칭 기법으로 학습 처리량을 기존 대비 30.8% 향상.
  4. 12개 공간 이해 벤치마크에서 8개 비교 모델 중 평균 점수 1위(65.64%), 7개 벤치마크에서 1위를 기록했으며, 자신의 원본 오토리그레시브 백본(Qwen3.5-4B) 대비 12개 벤치마크 전부에서 성능이 향상되었고, 가장 빠른 베이스라인보다 2.5배, 베이스 모델보다 5.6배 빠른 추론 속도를 달성.

방법론

통일된 분류 프레임워크: 각 단계(stage)에서 질문과 이전 선택/시각적 정제 결과로부터 후보 집합 Ct를 구성하고, 공유된 스코어러가 각 후보에 로짓을 부여한 뒤 소프트맥스로 확률을 계산해 최고 점수 후보를 선택한다(식 1). 선택형 질문은 한 번의 결정으로 끝나지만, 수치·지점 예측은 선택된 클래스가 다음 후보 집합과 새 이미지 크롭을 결정하는 다단계 과정을 거친다.

수치 예측: 길이는 로그 간격(log1p)으로 나눈 30개의 "거친(coarse)" 구간과 정확히 0 또는 범위 초과를 나타내는 클래스로 먼저 분류한 뒤, 선택된 구간을 다시 4~8개의 "세밀한(fine)" 셀로 나누어 2단계로 추정한다. 개수(count)는 32×32 이진 분할로 0~1023을 정확히 표현하고, 각도는 12개의 거친 구간과 셀당 32개의 세밀한 구간으로 처리한다.

지점(point) 예측: 현재 사각 영역을 3×3 격자로 나누는 9지선다 결정을 3단계 반복한다. 각 단계에서 선택된 영역은 원본 이미지에서 다시 크롭되어 동일한 동결(frozen) 비전 인코더로 재인코딩되며, 이렇게 얻은 지역 시각 정보가 다음 결정에 사용된다. 3단계를 거치면 27×27 해상도에 해당하는 셀 중심이 최종 좌표로 디코딩된다. 여러 지점을 동시에 찾아야 할 때는 추가 학습 없이 여러 결정 경로를 동시에 평가하는 "조건부 확률 트리"로 확장해, 경로별 확률이 높은 영역들을 분리된 다중 후보로 반환한다.

모델 구조: Qwen3.5-4B를 백본으로 사용한다. 각 후보 설명(선택지 텍스트, 수치/구간 텍스트, "top-left"·"center" 같은 영역 이름)은 전용 종료 마커로 끝나고, 전체 후보 목록 뒤에는 결정 마커가 붙는다. 31개 언어 레이어를 통과한 뒤, 마지막 전체-어텐션 레이어의 사전학습된 Query/Key 투영을 재사용하여 결정 마커의 은닉 상태를 쿼리로, 각 후보 종료 마커의 은닉 상태를 키로 삼아 내적 유사도(식 6, 헤드 평균)를 로짓으로 사용한다. 이 과정에서 새로운 예측 헤드나 파라미터를 추가하지 않으며, 마지막 레이어의 불필요한 value/gate/output/FFN 경로는 제거한다.

학습 레시피: RefSpatial, SAT, SenseNova-SI, VSI-590K, VST-P 등 기존 공간 데이터셋을 변환해 1,230만 개의 질의-응답 쌍(선택형 710만, 지점 350만, 길이 160만, 각도 12만, 개수 3.8만)을 구축했다. 다단계 질문의 모든 단계를 teacher forcing으로 하나의 순전파에서 동시에 지도하며, 단계별 손실을 질문당 평균 내어 다단계 질문이 단일 단계 질문보다 과도한 가중치를 받지 않도록 한다(식 7). 서로 다른 길이의 시퀀스를 전역적으로 길이별로 정렬하고 GPU 간 작업량을 균등하게 분배하는 배칭 전략을 적용해 패딩 낭비와 동기화 지연을 줄였다.

실험 설정 및 결과

Qwen3.5-4B, Qwen3-VL-8B-Instruct, InternVL3.5-8B, Molmo2-ER, Spatial-SSRL, SenseNova-SI, SpatialThinker 등 7개의 오토리그레시브 생성형 VLM과 SAT, CV-Bench, BLINK, MMSI-Bench, RefSpatial-Bench, Where2Place, Point-Bench, RoboSpatial(VQA/Pointing), ERQA, EmbSpatial, VSI-Bench 등 12개 벤치마크에서 비교했다. MJev-Spatial은 평균 65.64%로 1위(2위 Qwen3-VL-8B-Instruct 62.79%)를 기록했고, 12개 벤치마크 모두에서 원본 백본보다 우수했으며(RoboSpatial VQA +22.89점, RefSpatial-Bench +12.50점 등), NVIDIA B200 GPU 기준 평균 지연시간 160.6ms로 가장 빠른 베이스라인보다 2.5배, 베이스 모델보다 5.6배 빨랐다.

세부 분석(ablation) 실험에서는: (1) 사전학습된 Q/K 재사용이 새로 초기화한 선형 분류기나 KEV 포인터 방식과 비교해 과제별로 우열이 엇갈리지만 학습 비용과 파라미터 수 측면에서 가장 효율적이었고, (2) 수치 예측에서는 세밀한 구간(960개)보다 오히려 더 거친 구간(216개)을 쓸 때 양자화 오차는 커지지만 실제 예측 MAE는 더 낮아지는(0.3277m→0.3202m) 역설적 결과가 나왔으며, (3) 지점 예측에서 크롭 재인코딩을 제거하면 RefSpatial 정확도가 51.00%에서 9.00%로 급락해 지역 시각 정보 재인코딩의 중요성이 확인되었고, (4) 다중 지점 예측에서는 단순 continue/stop 방식 대신 확률 트리 전개를 쓸 때 Point-Bench 카운팅 성공률이 19.39%→38.78%로 향상되었으며 가지치기로 평균 결정 노드 수를 91개에서 51.1개로 줄여 1.79배 속도를 개선했다. (5) 학습 배칭 측면에서는 전역 길이 정렬과 GPU 간 부하 분산을 결합해 패딩 비율을 35.17%에서 1.77%로 줄이고 처리량을 기존보다 30.8% 끌어올렸다.

한계점

논문에 별도의 "한계점" 절은 존재하지 않지만, 본문에서 다음과 같은 제약이 언급되어 있다. 첫째, 후보 스코어링 방식(Q/K vs. 선형분류기 vs. KEV)의 성능 우열은 과제마다 달라 일관된 승자가 없었다. 둘째, 크롭 재인코딩을 제거하면 성능이 급격히 저하되므로 지점 예측은 추가적인 시각 재인코딩 연산(지점당 2회의 추가 이미지 인코딩)에 의존한다. 셋째, 결정 트리의 앞 단계에서 오류가 발생하면 이후 단계에서 올바른 영역을 복구할 수 없어, 기하학적으로 보장되는 해상도(27×27 격자, 축당 최대 1/54 오차)가 실제 예측 정확도를 보장하지는 않는다. 넷째, 학습 처리량 개선 실험은 100회 업데이트의 짧은 실행으로 처리량만 측정했을 뿐 수렴이나 전체 학습 결과물의 품질은 평가하지 않았다. 다섯째, 이 시스템은 미리 정의된 유한 후보 집합을 전제로 하므로, 자유형식의 설명이나 후보 집합으로 표현하기 어려운 개방형 공간 추론에는 적용하기 어렵다.

시사점

MJev-Spatial은 VLM이 반드시 텍스트를 순차적으로 생성해야 한다는 통념에서 벗어나, 선택·수치·좌표라는 이질적인 공간 과제들을 "사전학습된 어텐션 투영을 재사용한 후보 분류"라는 단일한 메커니즘으로 환원할 수 있음을 보인다. 이는 추가 파라미터 없이도 기존 VLM이 가진 시각-언어 지식을 그대로 활용해 정확도와 지연시간을 동시에 개선할 수 있다는 점에서, 실시간 로봇 제어나 임베디드 에이전트처럼 저지연이 중요한 공간지능 응용에 유용한 설계 방향을 제시한다. 또한 coarse-to-fine 이산화와 조건부 확률 트리를 이용한 다중 지점 확장은, 수치·좌표 예측을 "분류의 반복"으로 재구성하는 일반적 패턴으로서 다른 멀티모달 과제(예: 시간적 구간 찾기, 다중 객체 로컬라이제이션)에도 적용될 수 있는 잠재력을 보여준다.
