Youtu-Parsing-Omni: One Encoder, One Schema, All Modalities

유튜파싱옴니: 하나의 인코더, 하나의 스키마, 모든 모달리티

문서·이미지·오디오·비디오를 하나의 인코더(Youtu-Omni-Encoder)와 하나의 통합 출력 스키마(OmniSchema)로 처리하는 50억 파라미터급 옴니모달 파서로, 문서 파싱에서 최고 성능을, 오디오·비디오를 포함한 옴니모달 파싱 벤치마크에서 오픈 웨이트 모델 중 최고 성능을 달성했다.

한 줄 요약

문서·이미지·오디오·비디오를 하나의 인코더(Youtu-Omni-Encoder)와 하나의 통합 출력 스키마(OmniSchema)로 처리하는 50억 파라미터급 옴니모달 파서로, 문서 파싱에서 최고 성능을, 오디오·비디오를 포함한 옴니모달 파싱 벤치마크에서 오픈 웨이트 모델 중 최고 성능을 달성했다.

배경 및 문제의식

LLM 에이전트는 검색, 도구 호출, 화면 조작 등에서 텍스트가 아닌 문서·이미지·음성·영상을 다뤄야 하는데, 이를 모델이 원본 픽셀/파형 형태로 매번 직접 인코딩하는 것은 비용이 크고 결과의 근거(어느 영역·구간에서 왔는지)를 추적하기 어렵다. "옴니모달 파싱"은 입력을 한 번 구조화된 텍스트 레코드로 변환해, 텍스트 전용 모델조차 이를 읽고 근거를 인용할 수 있게 하는 지각(perception) 계층을 제공한다. 그러나 기존 파서는 입력 범위가 제한적이다. 문서 파서는 표준 페이지에는 강하지만 화학구조식·악보 같은 기호 콘텐츠는 전문 모델에 맡기는 경우가 많고, 문서를 넘어선 범위(이미지·오디오·비디오)의 파싱은 아직 미성숙하며, 옴니모달 모델 대부분은 캡셔닝·QA에 치우쳐 있어 모달리티별로 서로 다른 모델과 출력 형식이 쓰인다. 저자들은 출력이 결국 공간/시간에 고정(anchored)된 구조화 레코드라는 공통점에 착안해, 모달리티별 전문 모델 대신 하나의 인코더와 하나의 스키마로 통합할 것을 제안한다. 이를 위해 두 가지 과제를 해결해야 한다: (C1) 모달리티 간 공동 지각(비전·오디오를 별도 인코더로 처리하면 모달리티 간 융합과 시간 정렬이 어려움), (C2) 10개 과업에 걸친 공동 최적화(SFT는 참조 프리픽스만 학습하고, RLVR은 과업별 이질적 기준에 대한 스칼라 보상 설계가 어려움).

핵심 기여

  • Youtu-Omni-Encoder: 비전 타워와 오디오 타워를 분리하던 기존 구조를 하나의 공유 Transformer로 대체. 사전학습된 텍스트 LLM(Qwen3-0.6B-Base)으로 초기화해 텍스트 판독 능력을 강화했으며, 모달리티별로는 가벼운 입력 스템(stem)과 출력 프로젝터만 둔다.
  • 통합 시공간 위치 인코딩과 선택적 융합: 비전 패치는 (t, h, w), 오디오 토큰은 (t, 0, 0)으로 하나의 로터리 위치 인코딩 축을 공유하며, 일부 "융합 레이어"에서만 같은 시간대의 영상 프레임과 오디오가 서로 주의(attention)를 주고받도록 하여 지각 단계에서부터 모달리티 간 정렬이 이뤄지게 한다.
  • OmniSchema: 문서(일반 문서, 화학구조식, 악보, 차트, 플로차트, 기하 도형, 자연 이미지), 오디오, 비디오(일반/텍스트 중심) 등 10개 파싱 과업의 출력을 모두 박스/타임스탬프로 고정된 요소(element)·구간(segment) 목록과 전역 설명(global_description)으로 통일한 JSON 스키마.
  • OSAD(OmniSchema-Aware On-Policy Distillation): 스키마 토큰을 "구조(structure)" 토큰과 "내용(content)" 토큰으로 구분하고, 참조 정답을 보고 학습한 고정된 교사(teacher) 모델이 학생(student)의 자기 생성 출력(on-policy rollout)에 대해 토큰별 타깃 분포를 제공하는 자기진화형 사후학습 절차. 매 라운드가 끝나면 학습된 학생 가중치가 다음 라운드의 교사로 갱신되어 파서와 그 감독(supervision)이 함께 발전한다.

방법론

모델은 디코더 전용 언어모델(텍스트 전용 Youtu-LLM 계열 기반)에 하나의 지각 인코더가 붙은 구조다. 인코더는 (1) 모달리티별 스템이 픽셀/로그-멜 스펙트로그램을 토큰으로 변환, (2) 양방향 어텐션의 공유 Transformer 블록(RMSNorm, SwiGLU, GQA, QK-Norm, RoPE 사용)이 이를 맥락화, (3) 모달리티별 머저(merger)·프로젝터가 디코더 폭으로 다운샘플/매핑하는 3단 파이프라인이다. 로터리 위치 인코딩의 주파수 슬롯을 T/H/W 세 축으로 분할해 모든 모달리티가 같은 시간 좌표계를 공유하도록 하며, 비디오는 학습 시 일정 확률(p_fus)로 오디오-비주얼이 융합되는 경로와 독립적으로 처리되는 경로 중 하나를 택해 두 경로 모두 추론 시 사용 가능하게 유지한다.

학습은 사전학습 4단계(Stage 0 지각 정렬 → Stage 1 옴니모달 사전학습 → Stage 2 어닐링 → Stage 3 장문맥 확장, 총 2.24T 토큰)와 사후학습 3단계(SFT → 스키마 라우팅 RLVR → OSAD)로 구성된다. RLVR은 GRPO를 사용하며 보상은 디코딩 가능성·페이로드 존재 여부로 게이팅된 뒤 스키마 유효성/반복/미흡 커버리지에 대한 공통 요인과 과업별 내용 정확도 요인의 곱으로 계산된다(식 2). OSAD는 LoRA로 학습되는 학생과 참조 조건부 고정 교사 간에, 내용 토큰에는 대칭 Jensen-Shannon 발산, 구조 토큰에는 forward KL 발산을 각각 다른 온도로 적용하는 손실(식 3~5)을 사용하며, 총 6라운드를 수행한다.

실험 설정 및 결과

단일 5B 체크포인트, 단일 추론 설정으로 OmniDocBench v1.6, PureDocBench, OmniParsingBench, Video-MME-v2, ChemOCR, PDMX-Synth 등 여섯 개 벤치마크에서 평가했다. - OmniDocBench v1.6(문서 파싱, 1,651샘플): Overall 96.96으로 비교 대상 중 1위(2위 TeleOCR 96.91, 2B 미만 전문 모델). 이전 모델 Youtu-Parsing(93.74) 대비 표(TEDS +4.8)와 수식(CDM +3.2)에서 큰 향상을 보였다. - PureDocBench(정상/디지털 열화/실사 재촬영 트랙): 엔드투엔드 모델 중 평균(Avg3) 76.29로 1위, 세 트랙 모두에서 전문 모델을 능가했다. - OmniParsingBench(자체 평가 툴킷으로 재채점): 평균 75.08로 오픈 웨이트 모델 중 1위(Logics-Parsing-Omni 72.26, Qwen3-Omni-30B-A3B 66.44 대비 우위이며 Gemini-3-Pro(API) 77.44보다는 낮음), 특히 오디오·비디오 분할에서 이득이 크다. - 도메인 특화 벤치마크: ChemOCR에서 정확 분자 핑거프린트 일치율(Tani@1.0) 54.2로 DeepSeek-OCR2(49.6)를 상회, PDMX-Synth(악보→ABC 표기)에서 문자오류율(CER) 22.73으로 전문 모델 LEGATO(23.30)에 근접. - 인코더 비교 연구: 랜덤 초기화된 통합 인코더는 사전학습된 분리 타워(SigLIP-2+SenseVoice) 대비 일반 멀티모달 평균(Avg-6)에서 약간 열세였지만, 텍스트 LLM으로 초기화하면 OCRBench 등에서 분리 타워를 크게 앞서며 격차를 거의 해소했다(읽기 능력 위주 향상, 공간추론 성능 BLINK는 오히려 스크래치 학습이 더 높음). - OSAD의 기여: SFT 이후 OmniDocBench Overall이 1.99점 상승했는데, 이 중 1.75점(88%)이 OSAD 6라운드에서, 0.24점만 RLVR에서 나왔으며, 라운드가 진행될수록 점진적으로 효과가 작아지는 양상을 보였다.

한계점

저자들이 직접 명시한 한계는 추론 가속화 부재다. 이전 모델 Youtu-Parsing은 공유 인코더 특징을 페이지 내 여러 영역에 재사용하고 토큰·쿼리 단위 병렬 디코딩을 적용했지만, Youtu-Parsing-Omni는 더 큰 디코더로 엔드투엔드 자기회귀 디코딩을 수행하므로 표와 같은 조밀한 구조화 콘텐츠에서 처리량(throughput)이 낮을 것으로 예상되며, 병렬 디코딩 등 가속 기법 도입은 향후 과제로 남겨두었다.

시사점

비전·오디오를 별도 전문 인코더로 다루던 관행에서 벗어나, 텍스트 LLM으로 초기화된 단일 공유 인코더와 통합 시공간 위치 인코딩만으로도 모달리티 간 융합과 정렬을 지각 단계 자체에서 해결할 수 있음을 보였다. 또한 이질적인 10개 과업의 출력을 하나의 스키마로 통일하면, 토큰의 "구조/내용" 역할 구분에 기반한 단일 자기진화형 사후학습(OSAD) 절차로 과업 전반을 함께 개선할 수 있다는 점에서, 과업별 보상 설계나 전용 교사 모델 없이도 온-폴리시 distillation을 확장하는 일반적인 방법론을 제시한다. 이는 멀티모달 파싱을 에이전트의 "지각 계층"으로 범용화하는 방향, 즉 다양한 전문 모델 대신 범용 파서 하나로 문서·이미지·음성·영상을 아우르는 접근이 특화 모델 수준의 정밀도를 희생하지 않고도 가능하다는 근거를 제공한다.
