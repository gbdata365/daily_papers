SoftwareGym: Scaling Computer-Use Agent Training with Diverse Synthesized Software Environments

소프트웨어짐: 다양한 합성 소프트웨어 환경으로 컴퓨터 사용 에이전트 학습 확장하기

한 줄 요약

SoftwareGym은 다양한 인터페이스와 실제 동작 가능한 기능을 갖춘 GUI 소프트웨어 환경을 자동으로 합성하는 멀티에이전트 파이프라인으로, 이를 통해 생성한 학습 데이터만으로 컴퓨터 사용 에이전트(CUA)의 OSWorld 벤치마크 성능을 크게 향상시켰다.

배경 및 문제의식

컴퓨터 사용 에이전트를 학습시키려면 실행 가능한 소프트웨어 환경에서 나온 상호작용 데이터가 필요하다. 그러나 기존 방식은 실제 데스크톱/모바일 앱을 통합하는 데 막대한 공학적 비용이 들어 애플리케이션 범위가 제한되고 특정 앱에 과적합될 위험이 있으며, 브라우저 기반 환경은 구축이 쉽지만 상호작용 깊이와 워크플로 복잡성이 제한적이다. 즉 기존 방법들은 (1) 다양성, (2) 기능적 신뢰성, (3) 확장성을 동시에 만족시키지 못한다.

핵심 기여

  1. 다양하고 기능적으로 신뢰할 수 있는 GUI 소프트웨어를 대규모로, 수작업 개발보다 훨씬 적은 시간과 비용으로 합성하는 자동화 파이프라인 SoftwareGym 제안.
  2. 12개 카테고리에 걸친 182개의 실행 가능한 애플리케이션을 공개하고, 동일 카테고리를 다루는 120개 과제 평가 세트 SoftwareGym-Bench를 구축.
  3. 광범위한 평가와 어블레이션을 통해 파이프라인의 핵심 구성요소를 검증하고, SoftwareGym 트라젝토리만으로 학습한 모델이 OSWorld Pass@3를 15.58점 끌어올려 56.97%에 도달함을 입증.

방법론

SoftwareGym은 세 단계로 구성된다. (1) 설계 단계: 최소한의 인간 입력을 카테고리 수준의 기능 명세, 다양한 UI 블루프린트, 상호작용 스킴으로 확장한다(FunctionDesigner, IconDesigner, StyleDesigner, SubStyleDesigner 등 전담 에이전트 활용). (2) 구현 단계: 각 설계 패키지를 실행 가능한 애플리케이션으로 변환(Coder, DevCoder)하고 소스 수준에서 기능을 검증한다. (3) 평가 단계: 체크포인트 기반 GUI 테스트(EvalTaskGenerateAgent, GUI Agent)를 실행하고, 실패한 경우 실행 흔적과 런타임 증거를 바탕으로 국소적인 반복 수정(iterative repair)을 수행한다. 소스 수준 검증과 GUI 검증을 모두 통과한 애플리케이션만 최종 소프트웨어 라이브러리에 포함된다. 수집된 트라젝토리는 GPT-5.5 기반의 결과(outcome) 판정과 과정(process) 판정을 모두 0.8 이상 받은 경우에만 학습 데이터로 채택된다.

실험 설정 및 결과

SoftwareGym으로 12개 카테고리에서 182개의 실행 가능한 애플리케이션을 합성했으며 평균 GUI 과제 통과율은 91.5%였다. 이 환경들에서 수집한 트라젝토리로 학습한 모델은, OSWorld의 어떤 애플리케이션·과제·트라젝토리도 학습에 사용하지 않았음에도 완전 범위 외(out-of-domain) 평가인 OSWorld에서 Pass@3를 41.39%에서 56.97%로 끌어올렸다. 또한 자체 구축한 SoftwareGym-Bench(120개 과제)에서 40.0% Pass@3를 기록하며 여러 더 큰 규모의 특화 컴퓨터 사용 에이전트보다 우수한 성능을 보였다.

한계점

논문에 명시된 별도의 한계점 절은 없다. 다만 합성된 소프트웨어는 12개 카테고리, 182개 애플리케이션 규모로 범위가 정해져 있으며, 트라젝토리의 품질 평가가 LLM 기반 판정자(GPT-5.5)의 판단에 의존한다는 점은 본문에서 확인되는 구조적 특징이다.

시사점

이 연구는 실제 애플리케이션 통합의 높은 비용 문제를 "합성된 소프트웨어 환경"으로 우회함으로써, 컴퓨터 사용 에이전트 학습 데이터를 확장 가능하고 전이 가능한 방식으로 생산할 수 있음을 보여준다. 이는 실제 앱에 대한 과적합 위험을 줄이면서도 다양한 GUI 상호작용 패턴에 대한 일반화 능력을 높이는 새로운 데이터 확보 경로로서 의미가 있다.
