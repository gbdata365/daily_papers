PhysLoop: Harnessing LLMs' Physics Awareness for Self-Improving Video Generation Models

피직스루프: LLM의 물리 인식 능력을 활용한 비디오 생성 모델의 자기개선

PhysLoop는 LLM이 물리 시뮬레이터의 제약 아래에서 비디오 생성 모델의 학습 데이터를 만들고 오류를 검증·수정하도록 안내하는 통합 하네스(harness)로, 적은 사람 개입으로 비디오 생성 모델의 물리적 정합성을 자기개선(self-improving)시킨다.

한 줄 요약

PhysLoop는 LLM이 물리 시뮬레이터의 제약 아래에서 비디오 생성 모델의 학습 데이터를 만들고 오류를 검증·수정하도록 안내하는 통합 하네스(harness)로, 적은 사람 개입으로 비디오 생성 모델의 물리적 정합성을 자기개선(self-improving)시킨다.

배경 및 문제의식

비디오 생성 모델은 시각적으로는 사실적인 영상을 만들어내지만, 물체가 갑자기 사라지거나 늘어나는 등 물리 법칙과 인과관계를 위반하는 경우가 많다. 이를 개선하려면 다양한 물리적 조건을 체계적으로 포함한 학습 영상이 필요하지만, 실제 실험으로 이런 데이터를 수집하는 것은 비용이 크고 통제가 어렵다. LLM은 물리적 지식은 갖고 있지만 이를 비디오 생성 과정에 일관되게 적용하도록 안내하기 어렵다는 것이 핵심 문제의식이다.

핵심 기여

  • LLM이 비디오 생성·선별·수정 전 과정에서 물리 지식을 활용하도록 안내하고 제약하는 통합 하네스 PhysLoop 제안
  • 다양한 실내외 장면을 포괄하는 10만 개 규모 영상 데이터셋(PhysLoop-100K)과 생성·수정 평가용 데이터셋(PhysLoop-Gen, PhysLoop-Repair) 공개
  • 생성(generation), 수정(repair), 외부 벤치마크(Physics-IQ Verified)에서의 물리적 행동까지 포괄적으로 평가하여 제한된 사람 개입으로도 재귀적 자기개선(RSI)이 가능함을 보임

방법론

PhysLoop는 Planner, Asset Manager, Executive, Verifier, Refiner, Final Verifier 등 여러 에이전트로 구성된 파이프라인이다. 먼저 LLM 기반 에이전트가 사용자 요청을 구체적인 작업 명세(목표 이벤트, 가정, 검증 조건)로 확장하고, 필요한 3D 에셋을 검색·생성한다. 이후 Unreal Engine(보조로 Taichi, Genesis 사용)을 이용해 물리 시뮬레이션을 수행하고, 초기 조건에 따른 운동을 수치적으로 계산한다. 시뮬레이션이 검증을 통과하면 비디오 리파이너가 이를 모션 레퍼런스로 삼아 요청된 시각적 외형으로 영상을 다듬는다. 마지막으로 최종 검증기가 리파인 이후에도 물리적 사건과 관계가 유지되는지 재확인하며, 실패 시 피드백을 바탕으로 이전 단계로 되돌아가 수정한다. 이 공유 워크플로우는 학습 데이터 구축(텍스트/이미지로부터 물리적으로 올바른 학습 영상 생성)과 기존 영상의 국소적 오류 수정(video repair, 지정 구간만 교체) 두 가지 응용에 모두 사용된다.

실험 설정 및 결과

기본 구성은 에이전트 백본으로 GPT-6 Astra, 영상 정제기로 Seedance 2.5를 사용하며, Claude Opus 5, Kimi K3, MiniMax H3, Gemini Omni 1.1 Flash 등 다른 백본·정제기 조합과도 비교하였다. PhysLoop-Gen에서 PhysLoop는 85%의 과제 성공률(표준 Seedance 2.5는 73%)을 기록했고, 사람 평가에서 물리적 타당성(4.06 대 3.80)과 인과적 일관성(4.12 대 3.80) 점수가 더 높았으나 시각적 실재감은 다소 낮았다. PhysLoop-Repair에서는 86%의 성공률로, 비교 대상인 단독 영상 생성 모델들(모두 20% 미만)을 크게 앞질렀다. 외부 벤치마크 Physics-IQ Verified에서도 기본 구성이 52.06점으로 표준 Seedance 2.5(48.07점)보다 높은 점수를 얻었다.

한계점

PhysLoop의 성능은 시뮬레이터, 에셋, 검증 조건의 커버리지에 의존하며, 관측되지 않은 기하·재질·초기 상태에 대한 가정이 필요해 시뮬레이션이 실제 물리 과정을 완벽히 재현하지 못할 수 있다. 외형 정제 단계에서 새로운 오류가 생길 수 있고, 이미 이후 사건에 영향을 준 오류는 국소적 교체만으로 충분히 수정되지 않을 수 있어 모호한 경우 사람의 검토가 필요하다. 완전한 재귀적 자기개선(RSI) 루프로 확장하려면 약점 탐색, 후보 생성, 검증, 데이터 선별, 모델 갱신을 반복 연결해야 하며, 이 과정이 실제로 지속적인 성능 향상을 가져오는지에 대한 검증은 향후 과제로 남아있다.

시사점

PhysLoop는 LLM의 암묵적 물리 지식을 실행 가능한 시뮬레이터 제약과 결합함으로써, 비디오 생성 모델이 스스로 생성한 데이터로 물리적 정합성을 개선해 나갈 수 있는 구체적인 경로를 제시한다. 이는 사람이 일일이 물리적으로 정확한 학습 데이터를 라벨링할 필요 없이, 검증 가능한 피드백 루프를 통해 제한된 개입만으로 비디오 생성 모델을 지속적으로 고도화할 수 있는 가능성을 보여준다.
