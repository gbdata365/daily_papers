H3-World: Turning Language Understanding into World Control

H3-World: 언어 이해를 세계 제어로 전환하기

330억 파라미터의 대형 비디오 생성 모델 MiniMax-H3가 이미 갖고 있는 "언어를 통한 대략적 제어 능력"을, 전체 파라미터의 0.199%만 미세조정하는 경량 LoRA 어댑테이션으로 정밀하고 시간 축에 정합된 인터랙티브 월드 모델 제어로 바꾸는 프레임워크 H3-World를 제안한다.

한 줄 요약

330억 파라미터의 대형 비디오 생성 모델 MiniMax-H3가 이미 갖고 있는 "언어를 통한 대략적 제어 능력"을, 전체 파라미터의 0.199%만 미세조정하는 경량 LoRA 어댑테이션으로 정밀하고 시간 축에 정합된 인터랙티브 월드 모델 제어로 바꾸는 프레임워크 H3-World를 제안한다.

배경 및 문제의식

비디오 생성 모델이 커질수록 언어가 캐릭터의 움직임, 카메라 동작, 장면 전개를 조종하는 고수준 인터페이스로 떠오르고 있다. 그러나 기존의 인터랙티브 월드 모델들은 대개 이산적인 액션 임베딩, 조건부 모듈, 카메라 기하 정보, 혹은 백본 자체를 직접 수정하는 방식으로 별도의 제어 경로를 새로 학습시켜야 했다. 이런 방식은 추가적인 지도학습용 데이터와 계산·저장 비용을 요구하고, 대규모 적응 과정에서 사전학습 때 얻은 능력을 훼손할 위험이 있다. 저자들은 MiniMax-H3 같은 최신 비디오 생성기가 이미 자연어 지시만으로 캐릭터·카메라의 대략적인 제로샷 제어를 보여준다는 관찰에서 출발해, 제어 능력을 "처음부터 새로 학습"하는 대신 모델이 이미 이해하는 언어 공간 안에서 표현하고자 한다.

핵심 기여

  • 대형 비디오 생성 모델이 별도의 액션 학습 없이도 이미 대략적인 언어 기반 제어를 지원한다는 사실을 실증적으로 보임
  • 캐릭터·카메라 액션을 구조화된 텍스트 지시문으로 변환하고, 이를 해당 시점의 비디오 잠재 구간에 정렬시킨 뒤 "temporal attention routing(시간적 어텐션 라우팅)"으로 각 지시문이 의도된 시간 구간에만 영향을 주도록 제한하는 H3-World 프레임워크 제안. 별도의 전용 액션 모듈이 필요 없음
  • 8,000개의 게임플레이 샘플, 1만 스텝의 LoRA 학습, 전체 파라미터의 0.199%만으로 효과적인 제어를 달성하면서 생성 품질을 유지하고, 학습 시 보지 못한 액션 조합·장면에도 일반화됨을 확인

방법론

H3-World는 MiniMax-H3(양방향 오디오-비디오 파운데이션 모델)를 프리즈(freeze)한 상태에서 세 가지 요소로 구성된다. 1. 의미론적 액션 인터페이스(Semantic Action Interface): 8개의 캐릭터/카메라 키 상태와 1개의 카메라 속도 플래그로 구성된 이산 제어 상태를, 캐릭터 절과 카메라 절로 분리한 뒤 "the character strafes left, camera pans right slowly"와 같은 짧은 텍스트 지시문으로 매핑한다. 이는 9가지 캐릭터 절과 16가지 카메라 절의 조합(135개의 유효 조합)으로 구성된다. 2. 잠재 구간 정합 시간 바인딩(Latent-Aligned Temporal Binding): 각 지시문을 비디오의 특정 잠재 구간(latent interval)과 1:1로 대응시켜, 시퀀스 내에서 텍스트 위치가 대응되는 비디오 잠재보다 일정 오프셋만큼 앞서도록 배치한다. 이를 통해 시간이 지남에 따라 바뀌는 액션도 세밀하게 지정할 수 있다. 3. 단일 출구 라우팅(Single-Egress Routing)과 저랭크 적응(LoRA): 각 액션 스팬(span)이 오직 자신과 매칭된 비디오 잠재에만 직접 접근(attention)할 수 있도록 결정론적 마스크를 적용해, 액션 간 정보 누출(leakage)을 차단한다. 비디오 잠재들 사이의 양방향 어텐션은 그대로 유지해 장면의 연속성을 보존한다. 이 제한된 경로 위에서 QKV·출력 projection과 2-layer 토큰 리파이너에 rank-32 LoRA를 적용해 액션 조건부 시각 동역학을 학습한다.

실험 설정 및 결과

  • 데이터: ABot-World-Explorer-500h 데이터셋에서 추출한 7,872개의 게임플레이 학습 클립과 128개의 평가 클립 사용 (각 클립 124프레임, 24fps, 832×480 해상도)
  • 학습: rank-32 LoRA를 학습률 1e-4로 1만 스텝 학습. 추론 시 50-step 디노이징으로 124프레임 생성
  • 적응 효과 검증: 카메라가 초반엔 좌로, 후반엔 우로 급격히 팬(pan)하는 시나리오에서 (1) 고정된 H3에 전역 프롬프트만 부여, (2) LoRA 없이 잠재별 지시문만 부여, (3) 학습된 H3-World를 비교. Optical flow(Farneback 방법)로 측정한 결과, 전역 프롬프트는 전환 이후에만 약한 반응(누적 수평 flow −17.3)을 보이고 LoRA 없는 조건은 거의 반응이 없었던(≈0) 반면, H3-World는 전환 전후 각각 +52.7/−106.0의 뚜렷하고 방향에 맞는 반응을 보임
  • 직접 액션 조건화와의 비교: 학습된 벡터를 비디오 특징에 더하는 additive-bias 방식(ReactiveGWM 방식)과 FiLM 방식은 기록된 컨트롤 변화에 약하거나 일관되지 않은 반응을 보인 반면, 텍스트 기반 H3-World는 캐릭터·카메라 변화를 일관되게 재현
  • 일반화: 학습 데이터에 없던 캐릭터-카메라 조합(구성적 일반화)과, 게임플레이와 크게 다른 1인칭/3인칭·실내외·판타지/SF 등 다양한 시각적 장면(시각적 일반화) 모두에서 캐릭터·카메라 제어가 유지되고 장면 레이아웃과 피사체 정체성이 보존됨을 정성적으로 확인

한계점

논문이 스스로 명시한 한계는 다음과 같다. 첫째, 현재 연구는 짧은 구간(short-horizon) 생성에 집중되어 있고, 구성적 일반화와 시각적 전이 평가가 주로 대표적인 예시 위주로 이루어져 있어 액션 조합·장면·랜덤 시드 전반에 걸친 보다 체계적인 정량 평가가 필요하다. 둘째, 현재 모델은 고정된 길이의 세그먼트만 생성하며, 지속적인 월드 상태 유지, 실시간 상호작용, 계획(planning), 정책 학습(policy learning) 기능은 아직 제공하지 않는다.

시사점

이 연구는 대형 비디오 생성 모델이 사전학습만으로도 인터랙티브 제어에 필요한 구조를 상당 부분 이미 내재하고 있으며, 이를 별도의 전용 제어 모듈 없이 "언어"라는 기존 인터페이스를 통해 저비용으로 끌어낼 수 있음을 보여준다. 이는 향후 월드 모델 개발에서 새로운 제어 표현을 처음부터 설계하기보다, 사전학습된 모델의 언어 이해 능력을 재활용하는 경량 적응 전략이 유효한 대안이 될 수 있음을 시사한다.
