AltRA-Test: An Alternative Annotator Test for LLM Judges Without Shared Annotators

알트라테스트: 공유 주석자 없는 LLM 심사자를 위한 대안 주석자 테스트

동일한 주석자 집단이 모든 항목에 라벨을 다는 것을 전제했던 기존 "대안 주석자 테스트"와 달리, 항목마다 서로 다른 주석자 부분집합이 라벨을 다는 실제 상황(희소 주석)에서도 LLM이 인간 주석자를 대체할 수 있는지를 통계적으로 검증하는 ALTRA-TEST를 제안한다.

한 줄 요약

동일한 주석자 집단이 모든 항목에 라벨을 다는 것을 전제했던 기존 "대안 주석자 테스트"와 달리, 항목마다 서로 다른 주석자 부분집합이 라벨을 다는 실제 상황(희소 주석)에서도 LLM이 인간 주석자를 대체할 수 있는지를 통계적으로 검증하는 ALTRA-TEST를 제안한다.

배경 및 문제의식

LLM은 인간 주석자를 대체하는 저비용 대안으로 빠르게 쓰이고 있지만, LLM이 인간 주석자들이 공유하는 "신호(signal)"를 충실히 보존하는지는 보장되지 않는다. 이를 검증하기 위해 기존에 ALT-TEST(Calderon et al., 2025b)와 STT(통계적 튜링 테스트, He et al., 2025a)가 제안되었으나, 두 방법 모두 평가 집합의 모든 항목에 동일한 주석자 그룹이 라벨을 달았다고 가정한다. 그러나 크라우드소싱에서는 작업자가 임의로 작업을 선택하거나 중도에 그만두고, 선호 주석에서는 많은 참여자가 소수의 항목에만 판단을 제공하며, 일부 데이터셋은 주석자 신원 자체를 기록하지 않는 등, 실제로는 이 가정이 성립하지 않는 경우가 많다. 실제로 저자들이 수집한 20개 데이터셋 중 11개가 기존 테스트의 요건을 충족하지 못했다.

핵심 기여

  1. 항목마다 서로 다른 주석자 부분집합이 라벨을 달아도(희소 주석, sparse annotation) 적용 가능하고 주석자 신원을 전혀 사용하지 않는 새로운 대체-적합성 검정, ALTRA-TEST(Alternative annotator test with Resampled Annotations) 제안.
  2. 쌍대 백분위수 부트스트랩(paired percentile bootstrap)에 기반해 "혼합 패널(인간 k명 중 1명을 LLM 주석으로 대체)"의 평가자간 일치도(IAA)가 "전원 인간 패널"의 IAA보다 통계적으로 열등하지 않음을 비열등성(non-inferiority) 검정으로 확인하며, 인간 간 불일치 수준에 비례해 자동으로 조정되는 적응형 마진(adaptive margin)을 도입.
  3. ALTRA-TEST가 점근적 수준 α의 일관된(consistent) 검정임을 이론적으로 증명.
  4. 시뮬레이션과 텍스트·이미지·오디오·비디오 20개 실세계 데이터셋(18개 LLM, 5가지 프롬프팅 기법)에 대한 대규모 실증 평가를 통해 기존 방법(ALT-TEST, STT) 대비 더 나은 교체 판단 트레이드오프를 보임.
  5. 집단별 관점을 대표해야 하는 경우를 위한 그룹별 검정(group-wise testing)과 동등성 검정(EQ-ALTRA-TEST) 변형 제시.

방법론

데이터셋 D의 각 항목 x_i에 대해 사람 주석 H_i(최소 M_i≥k개)와 LLM 주석 f(x_i)가 주어졌을 때, 부트스트랩 반복 b=1,...,B마다 (1) 항목을 복원추출로 N개 샘플링하고, (2) 각 샘플 항목에서 k개의 인간 주석을 비복원추출로 뽑아 "전원 인간 패널" Y_h를 구성하며, (3) 그중 하나를 LLM 주석으로 교체한 "혼합 패널" Y_m을 만든다. Krippendorff's α 같은 신뢰도 점수 R을 적용해 R_h=R(Y_h), R_m=R(Y_m)을 계산하고, 대체 격차 Δ=R_m−R_h를 구한다. 적응형 마진 ε=c·(k_c/k)·(1−R_h)는 관찰된 인간 불일치(1−R_h)에 비례하여 설정되며(기본값 c=0.1은 최대 10%의 불일치 증가까지 허용), 조정된 격차 Δ_adj=Δ+ε의 B개 부트스트랩 값 중 α-분위수 q_α가 0보다 크면 귀무가설(H0: R_m+ε≤R_h, 즉 교체가 신뢰도를 과도하게 떨어뜨린다)을 기각하고 "LLM이 테스트를 통과(교체 가능)"한다고 판정한다. 이 검정은 항목별로 주석자 신원을 전혀 요구하지 않고, 항목마다 독립적으로 k개를 다시 추출하므로 희소 주석 환경에 적용 가능하다. 저자들은 N과 B가 커질수록 q_α가 실제 조정 격차에 확률수렴하고, 유효하지 않은 교체를 점근적으로 α 이하 확률로만 받아들임을 증명해 검정의 일관성을 보인다. 또한 집단별 관점을 보존해야 하는 경우를 위한 그룹별 검정과, 혼합 패널의 일치도가 마진 내에서 증가/감소 모두 하지 않아야 통과로 보는 동등성 변형(EQ-ALTRA-TEST)도 제시한다.

실험 설정 및 결과

시뮬레이션: 참값 라벨을 알고 있는 합성 데이터에서 인간과 LLM의 잡음 수준을 통제해 "더 나은 모델 수용률"과 "더 나쁜 모델 수용률"을 측정한 결과, 기존 테스트들이 전제하는 설정(동일 주석자가 모든 항목 라벨링)에서도 ALTRA-TEST가 ALT-TEST와 STT를 파레토 지배(동일한 거짓 수용률에서 더 높은 올바른 수용률)했다. 마진 상수 c=0.1이 보수적이면서도 효과적인 기본값임을 확인했고(더 나은 모델 수용률 0.98, 더 나쁜 모델 수용률 0.05 이하), 항목 수 N이 늘수록(특히 100개 이상) 성능이 안정화됨을 보였다. 다양한 주석자 수, 패널 크기, 라벨 수, 주석자 편향, 희소 주석 비율에 대한 강건성도 확인했다.

실세계 실험: 텍스트(12)·이미지(5)·오디오(2)·비디오(1) 20개 데이터셋, 18개 LLM 심사자, 5가지 프롬프팅 기법(제로샷·퓨샷·CoT·앙상블·GEPA)으로 평가한 결과, 기본 CoT 설정에서 201개 (심사자, 데이터셋) 조합 중 71개(35.3%)가 테스트를 통과했고, 각 심사자가 최적의 프롬프팅을 사용했을 때는 95개(47.3%)로 늘었다. 통과 여부는 심사자나 프롬프팅보다 데이터셋(과제)에 크게 좌우되었다(예: CEBaB에서는 전원 통과, Persuasion·Measuring-Hate-Speech·Loneliness에서는 전원 실패). 참 라벨이 존재하는 CIFAR-10H에서는, 테스트를 통과한 LLM-프롬프팅 조합 9개 중 8개가 실제로 인간 주석자(평균 정확도 0.94)만큼 정확했던 반면, 통과하지 못한 36개 조합 중 정확한 조합은 하나도 없어, 테스트의 통과 여부가 실제 대체 적합성과 일치함을 확인했다. 대부분의 심사자는 약 100개 항목만으로도 (300개 항목 기준과 비교해) 안정적인 판정에 도달했다.

한계점

저자들이 명시한 한계는 다음과 같다. (1) 검정은 관찰된 인간 주석자 풀에 상대적이므로, 인간 간 일치도(IAA) 자체가 매우 낮을 때(권장 하한 R_h≥0.2 미만)는 통과 결과가 유의미한 신호 존재를 보장하지 않는다. (2) 인간과 LLM이 공유하는 체계적 오류는 이 검정으로 탐지할 수 없다. (3) 통과는 LLM이 주석자들이 "공유하는" 신호를 보존함을 의미할 뿐이며, 서로 다른 주석자 그룹의 다양한 관점을 대표하려는 목적에는 적합하지 않으므로 이 경우 그룹별/동등성 변형을 사용해야 한다. (4) 현재는 LLM이 항목당 단일 주석만 제공하는 경우를 다루며, LLM 주석의 분포를 고려해 인간 주석 분포와의 정합성을 평가하는 확장은 향후 과제로 남겨두었다.

시사점

LLM을 데이터 주석에 활용하려는 연구자들에게, "LLM이 인간보다 유창하거나 그럴듯해 보인다"는 인상이 아니라 통계적으로 검증된 근거에 기반해 대체 여부를 결정하도록 하는 실용적 도구를 제공한다. 특히 실제 주석 파이프라인 대부분이 전제하는 "모든 항목을 동일 주석자가 라벨링"이라는 비현실적 가정을 제거했다는 점에서 실무 적용성이 높으며, 과제(데이터셋)별로 교체 적합성이 크게 달라진다는 결과는 LLM 심사자를 일반적 관행으로 채택하기보다 과제별로 개별 검증해야 한다는 메시지를 준다.
