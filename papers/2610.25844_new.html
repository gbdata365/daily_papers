SWIFT: Self-guided Weak-to-strong dIFfusion models via Target extrapolation

스위프트: 타겟 외삽을 통한 자기지도 약-강 확산 모델

한 줄 요약

SWIFT는 추론 시점에 적용되던 "약한 모델 대비 외삽(guidance)" 기법을 학습 단계로 옮겨, 고정된 약한 디노이저를 이용해 회귀 타겟 자체를 깨끗한 샘플보다 더 멀리 밀어내는 방식으로 확산 모델을 학습시키는 자기지도 학습법이다.

배경 및 문제의식

확산 모델은 깨끗한 샘플(또는 노이즈)을 예측하도록 단순 회귀 손실로 학습되지만, 최고 성능의 생성 결과는 대개 분류기 없는 가이던스(CFG)나 오토가이던스(autoguidance)처럼 추론 시점에 별도의 약한 모델을 이용한 외삽에 의존한다. 즉 학습된 강한 모델의 예측을, 더 약하거나 덜 학습된 모델의 예측 반대 방향으로 밀어내면 품질이 개선된다는 관찰이다. 저자들은 이 외삽을 추론이 아니라 학습 중에 적용해서, 최종적으로 얻어지는 단일 디노이저 자체가 그 보정 효과를 내재화하고 약한 모델은 학습 후 버릴 수 있도록 만들 수 있는지를 질문한다.

핵심 기여

1) 고정된 약한 디노이저를 방향 참조로 사용해 깨끗한 샘플 회귀 타겟을 외삽시키는 학습 방법(SWIFT)을 제안했다. 약한 모델은 학습 중 역전파 없이 평가만 되며 학습 후 폐기되고, 샘플링 절차와 조건부/비조건부 생성 구조는 그대로 유지된다. 2) CIFAR-10과 ImageNet-256에서 VAE 잠재공간, 표현-오토인코더(RAE) 잠재공간, 엔드투엔드 학습 잠재공간, 픽셀 공간 등 다양한 표현 방식에 걸쳐 일관된 성능 향상을 보였다. 3) 재생산 커널 힐베르트 공간(RKHS)에서의 유한시간 모집단 그래디언트 플로우 분석을 통해, 조기 종료된 약한 가이드를 사용할 때 특정 양의 외삽 강도 범위에서 사후평균(posterior-mean) 오차가 표준 학습보다 엄밀하게 더 작아짐을 이론적으로 증명했다(정리 1).

방법론

표준 학습은 노이즈가 섞인 입력에서 깨끗한 샘플 x0을 직접 회귀하도록 손실을 구성하지만, SWIFT는 타겟을 y_α = x0 + α(x0 − D_weak(x_t, σ_t))로 바꾸어, 약한 디노이저의 예측 반대 방향으로 외삽된 지점을 회귀 타겟으로 사용한다. 여기서 α=0이면 표준 학습과 같아지고, α>0이면 타겟이 깨끗한 샘플을 넘어 약한 모델 예측의 반대쪽으로 더 멀리 이동한다. 약한 디노이저는 메인 모델보다 작은 구조(기본적으로 약 1/4 파라미터 수)를 가지며 메인 모델 학습 절반 정도의 기간만 통상적인 방식으로 학습한 뒤 고정(freeze)되어 사용된다. 이 외삽은 오토가이던스가 샘플링 시점에 하던 연산을 학습 타겟 구성으로 옮긴 것과 유사하지만, 학습이 끝나면 약한 모델이 필요 없어진다는 점이 다르다. 이론적으로는 커널 그래디언트 플로우 관점에서, 유한 학습 시간 내에 "아직 덜 학습된 방향"을 약한 모델과의 차이를 통해 증폭시켜 보정한다는 메커니즘을 제시하고, 가우시안 혼합 모델 등 단순한 사례로 이를 검증했다.

실험 설정 및 결과

ImageNet-256에서는 DiffusionBench 벤치마크의 19가지 모델 구성(VAE, RAE, 엔드투엔드 잠재, 픽셀 공간 등)에 대해 가이던스 유무 모두에서 FID, sFID, 표현공간 FD_r, MIND, Precision/Recall을 측정했다. 대표적으로 RAE/DINOv2-B 구성에서 가이던스 없는 FID가 2.09에서 1.75로, RAEv2/DINOv3-L 구성에서는 1.56에서 1.15로 개선되었으며, 동일한 고정 레시피를 적용한 18개 구성 전체에서 가이던스 없는 FID가 16.3%~49.4%(중앙값 31.3%) 개선되었다. 추론 시점 가이던스와 결합해도 이득이 유지되어, RAEv2에서는 내부 가이던스 재조정 후 FID가 1.04에서 0.99로 더 낮아졌고, 선호되는 가이던스 강도 자체도 더 낮아졌다. 학습 비용 측면에서는 약한 가이드 준비와 추가 forward pass로 에폭당 약 9%의 추가 연산이 들지만, 동일 FID 품질에 도달하는 데 필요한 총 연산량은 기존 대비 약 0.44~0.45배 수준으로 보고되었다. CIFAR-10에서는 외삽 강도 α, 약한 가이드의 폭(채널 수), 가이드 학습 길이에 대한 민감도 분석을 수행해 적당히 양수인 α(약 0.7~0.9)와 메인 모델 대비 절반 폭 정도의 약한 가이드가 최적임을 확인했다.

한계점

타겟 외삽은 이론적으로 비제약 모집단 최적해(사후평균)를 개선하는 것이 아니라 유한 학습 시간 내 추정 오차를 줄이는 것이므로, 정리 1의 보장은 특정 양의 α 범위에 한정되며 모든 약한 디노이저에 대해 보장되는 것은 아니다. 또한 분석은 모집단 수준의 그래디언트 플로우에 기반하며, 실제 유한 샘플·유한 스텝 학습에서는 보조적 분석(부록)으로만 다루어진다. 약한 가이드 준비 및 추가 forward pass로 인한 연산 오버헤드가 존재하며, α 및 가이드 구조의 최적값은 모델별로 다소 다르게 나타나 완전히 하이퍼파라미터 자유롭지는 않다. 공동 학습(jointly trained guide) 방식은 CIFAR-10 비교에서 뚜렷한 추가 이득을 주지 못했다.

시사점

이 연구는 확산 모델 학습에서 그동안 거의 고정값으로 취급되던 "회귀 타겟"을 설계 가능한 인터페이스로 재조명한다. 추론 시점 가이던스가 제공하던 약자-강자 보정 효과를 학습 중에 단일 모델에 내재화함으로써, 배포 시에는 추가 모델이나 추론 비용 없이도 성능 향상을 유지할 수 있음을 보여준다. 이는 향후 다른 형태의 타겟 보정(예: 조건부 작업, 다른 생성 모델링 프레임워크)으로 확장될 수 있는 일반적인 학습 설계 원칙을 시사한다.
