HABIT-Bench: Evaluating Habit Induction from Longitudinal Weak Evidence in Agent Memory

HABIT-Bench: 에이전트 메모리에서 종단적 약한 증거로부터의 습관 추론 평가

LLM 에이전트가 수백 세션에 걸친 희박한(weak) 증거로부터 사용자의 "습관(habit)"을 추론하고 이를 상황·예외·시간 변화에 맞게 올바르게 적용할 수 있는지를 평가하는 벤치마크인 HABIT-Bench를 제안하며, 기존 memory 시스템들이 이 과제에서 약 33% 수준의 낮은 정확도에 머문다는 것을 보여준다.

한 줄 요약

LLM 에이전트가 수백 세션에 걸친 희박한(weak) 증거로부터 사용자의 "습관(habit)"을 추론하고 이를 상황·예외·시간 변화에 맞게 올바르게 적용할 수 있는지를 평가하는 벤치마크인 HABIT-Bench를 제안하며, 기존 memory 시스템들이 이 과제에서 약 33% 수준의 낮은 정확도에 머문다는 것을 보여준다.

배경 및 문제의식

장기 상호작용 에이전트는 명시적 사실을 저장하는 것만으로는 부족하며, 사용자의 반복적 선택이나 행동에서 암묵적인 습관적 기본값(behavioral default)을 추론하고, 그것이 현재 요청에 적용 가능한지(예외, 시간적 유효성, 사용자 승인 여부 등)를 판단해야 한다. LoCoMo, LongMemEval, MemoryAgentBench, PersonaMem 등 기존 벤치마크들은 장기 기억의 회상이나 선호 추적, 선택적 개인화 억제 등 부분적 측면만 다루었고, "약한 증거로부터의 습관 귀납"과 "맥락에 따른 적용 여부 판단"을 동시에, 그리고 체계적으로 평가하는 벤치마크는 없었다.

핵심 기여

(1) habit memory를 "불완전한 증거로부터 행동 기본값을 추론하고, 그 범위·예외·시간적 유효성·사용자 승인 여부에 따라 적절히 적용하는 능력"으로 정식화했고, (2) 음식(Food)·금융(Finance)·소프트웨어(Software)·여행(Travel) 4개 도메인에 걸쳐 114명의 사용자, 37,152개 세션, 3,328개 probe로 구성된 benchmark를 구축했으며, (3) 8개의 memory 방법과 검색 기준선을 공통 프로토콜로 비교하고 증거 접근(evidence access)과 의사결정 정확성을 분리하는 진단 지표를 제공했다.

방법론

각 사용자 u에 대한 세션 히스토리 H를 바탕으로, probe p는 요청 x_p, 4개의 선택지 A_p, 가시성 컷오프 t_p, 목표 시점 τ_p로 구성된다. 각 습관 상태 z는 행동 기본값·적용 범위·예외·시간적 유효성·사용자 승인 여부를 포함하며, 정답 a*는 이 습관 상태들을 종합해 결정된다. 데이터는 CookDial(음식), MultiDoGO(금융·소프트웨어), Taskmaster-2(여행) 등 기존 task-oriented dialogue 데이터를 시드로 사용해 통제된 habit graph를 바탕으로 합성 히스토리를 구성했으며, 샘플링된 문항은 두 명의 독립적 인간 검토자(및 불일치 시 세 번째 조정자)가 답변 가능성·증거 충분성·범위·예외·자연스러움 등 8개 기준으로 재검증했다. 평가 시 memory 시스템은 세션을 시간순으로 수집해 사용자별 memory를 구성(M_u^t = Update(M_u^{t-1}, s_t))하고, probe 시점에 검색(Retrieve)한 내용을 공유 answerer 모델에 제공해 4지선다 중 하나를 고르게 하며, 정답과의 exact-match로 채점한다(균등 랜덤 추정치는 25%).

실험 설정 및 결과

Qwen3-235B-A22B와 GLM-5.3-Flash 두 모델을 기본 answerer/memory 연산 모델로 사용해 No Memory/Full Memory 컨트롤, Recency-5/10·BM25·Dense RAG·Temporal Hybrid RAG 검색 기준선, A-MEM·Mem0·MemOS·MemRL·LightMem·SeCom 등 6개 단일 memory 방법, Letta·MIRIX 등 2개 multi-store memory 방법을 비교했다(총 308개 설정). 최고 성능의 memory 방법은 Qwen3-235B-A22B에서 4-도메인 macro accuracy 33.06%, GLM-5.3-Flash에서 33.61%에 그쳤으며, 이는 단순 BM25/Dense 검색 기준선(32.50%/33.21%)과 큰 차이가 없었고, GLM의 Full Memory(압축 히스토리) 컨트롤(41.98%)보다도 낮았다. 금융·소프트웨어 도메인에서는 memory 방법들이 No Memory보다도 낮은 경우가 많았던 반면, 음식·여행 도메인에서는 최대 20%p 이상의 이득이 관찰되어 memory의 효용이 도메인에 크게 의존함을 보였다. 또한 정답에 필요한 증거를 직접 제공하는 Oracle Evidence 조건에서도 정확도는 39~58% 수준에 머물러(반면 습관 상태 자체를 제공하는 Oracle Habit State는 98%+), 증거 검색 실패만으로는 낮은 성능을 설명할 수 없고 "습관 재구성과 적절한 적용" 자체가 어려운 과제임을 보였다.

한계점

저자들은 검색 top-k나 ingestion chunk 크기를 조정해도(k=2→20 등) 관찰된 한계가 해소되지 않음을 보였으며, 모델 크기를 늘려도(Qwen3 4B~235B) 일관된 성능 향상이 나타나지 않고 비단조적인 양상을 보였다. 또한 memory/answer 모델이 동시에 바뀌는 설정이라 모델 규모만을 독립적으로 분리한 비교는 아니라는 점, 그리고 Hit@5·evidence recall 등 진단 지표가 전체 추론 과정의 타당성을 완전히 보장하지는 않는다는 점을 스스로 명시했다.

시사점

이 벤치마크는 현재의 agent memory 시스템들이 단순 회상(recall)을 넘어선 "습관 귀납과 맥락적 적용"이라는 과제에서 여전히 크게 미달한다는 것을 보여주며, memory 시스템 평가 시 증거 접근 성공 여부와 최종 의사결정 정확성을 분리해서 진단해야 한다는 방법론적 시사점을 제공한다. 이는 앞서 Memory Tax 논문이 제기한 "memory가 항상 이득이 아니다"는 주장과도 맥을 같이 하며, 더 정교한 memory 설계가 필요한 지점(예외 처리, 시간적 유효성 추적, 미승인 제안 구분 등)을 구체적으로 드러낸다.
