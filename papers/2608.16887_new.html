An Empirical Study of Training Pixel-Space Text-to-Image Diffusion Models

픽셀 공간 텍스트-이미지 확산 모델 학습에 관한 실증 연구

대규모 픽셀 공간(pixel-space) text-to-image 확산 모델은 처음부터 학습하면 잠재 공간(latent-space) 모델보다 수렴이 훨씬 느리다는 사실을 실증적으로 밝히고, 잠재 공간에서 사전학습한 뒤 후처리 단계에서 픽셀 공간으로 전환하는 "latent-to-pixel" 전략의 핵심 설계 선택(초기화·데이터·예측 목표·디코더·노이즈 스케줄)을 체계적으로 규명해, 잠재 공간 모델과 동등하거나 더 나은 성능을 유지하면서 3.18~4.75배 빠른 추론 속도를 달성하는 실전 레시피를 제시한다.

한 줄 요약

대규모 픽셀 공간(pixel-space) text-to-image 확산 모델은 처음부터 학습하면 잠재 공간(latent-space) 모델보다 수렴이 훨씬 느리다는 사실을 실증적으로 밝히고, 잠재 공간에서 사전학습한 뒤 후처리 단계에서 픽셀 공간으로 전환하는 "latent-to-pixel" 전략의 핵심 설계 선택(초기화·데이터·예측 목표·디코더·노이즈 스케줄)을 체계적으로 규명해, 잠재 공간 모델과 동등하거나 더 나은 성능을 유지하면서 3.18~4.75배 빠른 추론 속도를 달성하는 실전 레시피를 제시한다.

배경 및 문제의식

  • 픽셀 공간 확산은 VAE 재구성 한계(reconstruction ceiling)에 얽매이지 않고 잠재 압축으로 손실된 시각 정보를 복원할 수 있으며, 추론 시 별도 VAE 디코딩 단계 없이 직접 픽셀을 생성해 효율적이라는 장점이 있음.
  • 그러나 기존 픽셀 공간 연구는 대부분 class-conditional ImageNet이나 소규모 text-to-image 세팅에 국한되어, 대규모(20B+ 이미지-텍스트 쌍) 환경에서 잠재 공간 모델과 견줄 만한 픽셀 공간 text-to-image 모델을 어떻게 학습시켜야 하는지는 불명확했음.
  • 핵심 질문: (1) 대규모 환경에서 픽셀-잠재 공간 학습 효율은 어떻게 다른가, (2) 생성 품질과 추론 효율을 동시에 확보하는 픽셀 공간 학습 레시피는 무엇인가.

핵심 기여

  1. 동일 아키텍처·데이터·연산 자원 하에서 픽셀 대 잠재 공간 사전학습을 통제 비교하여, 픽셀 공간 사전학습이 훨씬 느리게 수렴함을 실증
  2. Latent-to-pixel 전환의 핵심 설계 요소(가중치 초기화, 학습 데이터 구성, 예측 목표, 디코더 구조, 노이즈 스케줄)를 체계적으로 연구해 실전 레시피 도출
  3. 점진적 패치 크기 적응(progressive patch-size adaptation)과 스텝 증류(step distillation)를 결합해 추론 효율을 추가로 개선
  4. Z-Image, FLUX2-klein 두 모델 계열에서 일관되게 검증되어 레시피의 일반화 가능성을 확인, 최종 모델은 잠재 공간 대비 3.18배~4.75배 종단간(end-to-end) 추론 가속 달성

방법론

  • 비교 실험 설계: Z-Image와 동일한 아키텍처·학습 데이터(20B+ 쌍)·연산 자원·학습 설정을 사용하되 예측 공간(픽셀 vs 잠재)만 변경하여 통제 비교 (p.2-3, Sec.3)
  • Latent-to-pixel 전략: 잠재 공간에서 먼저 사전학습해 시각 지식과 텍스트-이미지 정렬을 효율적으로 획득한 뒤, 후처리(post-training) 단계에서 픽셀 공간 예측으로 전환 (Sec.4)
  • 가중치 초기화: 픽셀 공간 모델을 사전학습된 잠재 공간 모델 가중치로 초기화 vs 무작위 초기화 비교
  • 학습 데이터 구성: 실제 이미지만 / 소스 모델(같은 잠재 모델) 자기 생성 데이터만 / 타 모델(FLUX2-klein-9B) 생성 데이터 / 자기 생성+실제 이미지 혼합의 4가지 설정 비교
  • 예측 목표: 잠재 공간에서 쓰던 v-prediction을 유지할지 x-prediction으로 전환할지 검증
  • 디코더 아키텍처: JiT(선형 헤드), DiP(경량 합성곱 U-Net), PiT(Transformer 헤드), Deco(주파수 분리 헤드), 기존 VAE(FLUX-AE, 참조용) 비교
  • 노이즈 스케줄: 픽셀 해상도가 잠재 대비 8배 높다는 점을 반영해 노이즈 스케일 계수 γ를 도입(x_t = t·x_0 + (1-t)·γ·ε), 해상도 기반 이론값(γ=8)과 실측 최적값을 비교
  • 효율화: ps16(16배 압축 상당 토큰 그리드)에서 학습 후 ps32로 점진 적응, Decoupled-DMD·DMDR 기반 픽셀 공간 스텝 증류 적용

실험 설정 및 결과

  • 사전학습 비교(p.2-3, Fig.2-3): 동일 연산 예산 하에서 잠재 공간 모델이 GenEval·DPG 지표 모두에서 픽셀 공간 모델을 일관되게 앞섬. 특히 학습 초반 격차가 크며, 20B+ 데이터로도 픽셀 모델이 격차를 좁히지 못함.
  • 가중치 초기화(p.4, Fig.4-5): 잠재 가중치로 초기화한 픽셀 모델이 처음부터 학습한 모델보다 훨씬 빠르게 수렴.
  • 데이터 구성(p.4-5, Fig.6-7): 실제 이미지만 사용 시 수렴이 느림. 소스 모델 자기 생성 데이터는 빠른 수렴을 제공하지만 소스 모델의 오류(예: 글자 왜곡)를 그대로 물려받음. 자기 생성+실제 이미지 혼합이 가장 좋은 트레이드오프.
  • 예측 목표(p.5, Fig.8): 잠재 초기화 덕분에 v-prediction·x-prediction 모두 안정적으로 수렴하지만, x-prediction이 전 구간에서 더 나은 벤치마크 점수를 보임.
  • 디코더 비교(p.5-6, Table 1): PiT가 GenEval 최고(0.7697)지만 디코더만 2.25B 파라미터(백본의 37.5%), 19,731 GFLOPs로 비현실적. JiT는 효율적이나 패치 경계 격자 아티팩트 발생. DiP는 DPG 최고(87.54), GenEval 0.7545로 경쟁력 있으면서 파라미터 10.09M, 834 GFLOPs로 가장 우수한 품질-효율 트레이드오프 → DiP 채택.
  • 노이즈 스케일(p.6, Table 2): γ=1,2,4,8 비교 결과 γ=2가 GenEval 0.7545, DPG 87.54로 최고 성능. 해상도 기반 이론값 γ=8은 오히려 준최적이며 색상 왜곡 발생, 실측 보정이 필요함을 확인.
  • 패치 크기 적응(p.7, Fig.11-12): ps16→ps32 점진 적응(ps32-adapt16)이 직접 ps32 학습보다 훨씬 빠르게 수렴하고 토큰 1/4만 사용하면서도 ps16과 유사한 성능 달성. ps64까지 더 적응하면 다시 성능 저하.
  • 최종 시스템 비교(p.7-8, Table 3): Z-Image 기준 100 NFE에서 픽셀 모델이 GenEval 0.7644(잠재 0.7510), DPG 87.60(잠재 86.91)으로 오히려 우수하면서 4.41배 가속(4.56s vs 20.12s). 4 NFE(스텝 증류) 시 0.20s로 4.75배 가속. FLUX2-klein 계열에서도 3.18~3.29배 가속과 함께 대다수 벤치마크에서 개선. 선행 latent-to-pixel 방법 L2P, AsymFlow 대비도 대부분의 벤치마크에서 우위.
  • 패치 적응+스텝 증류를 결합하면 원래 잠재 공간 파이프라인 대비 최대 100.6배 종단간 가속 달성(p.7, Fig.13).

한계점

  • 저자가 명시적으로 별도 "한계점" 절을 두지는 않았으나, 본문에서 다음이 드러남: ps32→ps64 등 더 공격적인 패치 압축 시 미세 디테일이 저하되어 극단적 토큰 압축 하에서 디테일 보존이 향후 과제로 남음(p.7, Takeaway 7).
  • 자기 생성 데이터에 의존하는 latent-to-pixel 전환은 소스 잠재 모델의 오류(예: 텍스트 렌더링 아티팩트)를 상속하는 근본적 한계가 있으며, 실제 이미지 혼합으로 완화하나 완전히 해소되지는 않음(p.4-5).
  • 노이즈 스케일처럼 이론적으로 유도한 값(해상도 기반 γ=8)이 실제 최적값(γ=2)과 어긋나, 아직 이론적으로 완전히 설명되지 않는 분포 이동(distribution shift) 요소가 남아있음을 저자 스스로 인정(p.6, Takeaway 6).
  • 실험이 Z-Image와 FLUX2-klein 두 계열에 한정되어 있어 다른 아키텍처(예: 완전히 다른 백본 계열)로의 일반화는 추가 검증이 필요.

시사점

  • 대규모 생성 모델을 밑바닥부터 픽셀 공간에서 학습하는 것은 비효율적이므로, "잠재 공간 사전학습 + 픽셀 공간 후처리 전환" 패턴은 향후 고해상도/고효율 생성 모델 설계에서 재사용 가능한 일반 원칙으로 참고할 만함.
  • 디코더 헤드 선택 시 파라미터 수·GFLOPs 대비 품질을 함께 고려하는 품질-효율 트레이드오프 분석(Table 1, p.6)은 유사한 경량화 디코더 설계에 실용적인 참고 자료가 됨.
  • 노이즈 스케줄과 같은 하이퍼파라미터는 이론적 유도값을 출발점으로 삼되 반드시 실측 보정이 필요하다는 점은, 다른 표현 공간 전환(예: 다른 압축률 간 전환) 작업에도 일반화될 수 있는 실무적 교훈.
