WorldSculpt: Generating Compositional Worlds from Grounded Videos

그라운딩된 비디오로부터 조합형 3D 월드 생성하기

단일 객체용 3D 생성 모델(Pixel3D)에 다중 뷰 조건화 경로를 더해, 수백 개의 객체가 서로 심하게 가려진 어수선한 실내외 장면도 씬 단위 학습 없이 개별 메쉬들의 조합으로 생성할 수 있음을 보인 연구.

한 줄 요약

단일 객체용 3D 생성 모델(Pixel3D)에 다중 뷰 조건화 경로를 더해, 수백 개의 객체가 서로 심하게 가려진 어수선한 실내외 장면도 씬 단위 학습 없이 개별 메쉬들의 조합으로 생성할 수 있음을 보인 연구.

배경 및 문제의식

게임, AR/VR, 시뮬레이션, 로보틱스 등의 응용은 장면을 뭉뚱그린 표면 덩어리가 아니라, 각 객체를 독립적으로 선택·이동·재시뮬레이션할 수 있는 개별 메쉬들의 집합으로 필요로 한다. 그러나 여러 이미지로부터 실제 어수선한 장면의 조합형(compositional) 3D 콘텐츠를 생성하는 문제는 오랫동안 풀리지 않은 과제였다. 기하학 기반 방법(포인트맵 기반 재구성, 피드포워드 볼륨/가우시안 회귀 등)은 관측된 영역은 정확히 복원하지만 가려진 영역은 불완전하게 남긴다. 반면 생성적 프라이어를 활용하는 방법은 두 갈래로 나뉘는데, Marble과 같은 씬 레벨 월드 생성 모델은 장면 전체를 하나의 단일 표현으로만 생성해 개별 객체 분리가 안 되고, Pixel3D·TRELLIS 같은 네이티브 3D 생성 프라이어는 포즈 없는 단일 이미지의 개별 객체 하나만을 다루도록 설계되어 일관된 다중 뷰에 직접 조건화하거나 알려진 씬 좌표계에서 객체를 생성하기 어렵다. 최근의 조합형 접근법들도 여러 인스턴스를 동시에 생성하거나 객체 생성과 씬 레이아웃 추정을 결합하지만, 탁자 위 소품처럼 비교적 단순한 장면에서만 검증되어 왔다.

핵심 기여

  • 수백 개 객체로 구성된 조합형 3D 장면을, 각 객체를 하나의 개별 메쉬로 생성하는 WorldSculpt 프레임워크를 제안. 다중 뷰 씬 관측을 앵커 정렬 정준(canonical) 좌표계로 매핑하고, 이 정렬된 관측에 강력한 객체 단위 3D 생성 프라이어를 조건화한 뒤, 정준-월드 변환으로 생성된 메쉬를 원래 장면에 배치한다.
  • 개별 객체에 대해서만 파인튜닝된 생성 프라이어가 다중 뷰 조건화와 타깃형 데이터 증강 커리큘럼을 통해, 씬 레벨 학습 없이도 수백 개의 심하게 가려진 객체로 구성된 대규모 장면에 일반화될 수 있음을 입증.
  • 수백 개 객체가 포함된 사실적인 대규모 실내외 장면과, 정확한 객체별 주석 및 정답 메쉬를 갖춘 새로운 벤치마크 UE-MeshyScene을 공개.

방법론

WorldSculpt는 포즈가 알려진 이미지 집합, 각 객체의 뷰별 인스턴스 마스크, 대략적인 3D 위치 박스를 입력으로 받아 (개별 메쉬, 정준-월드 변환) 쌍의 집합을 출력한다. 전체 파이프라인은 세 단계로 구성된다.

  1. 앵커 정렬 객체 정준화: 각 객체마다 가장 온전하게 보이는 뷰를 "앵커"로 선택하고, 이 앵커 카메라 방향을 기준으로 정규화된 정육면체(정준 공간)를 정의한다. 대략적인 위치 박스의 중심과 방향은 그대로 쓰되, 박스가 다소 헐겁거나 빡빡할 수 있으므로 정육면체 투영이 모든 선택 뷰에서 객체 마스크를 덮을 때까지 등방적으로 크기를 키운다. 각 관측 뷰는 이 정준 정육면체를 기준으로 크롭·리사이즈되고 배경이 마스킹되어 객체 중심 이미지로 변환된다.
  2. 다중 뷰 조건화 객체 생성: TRELLIS.2 구조적 잠재 표현 기반의 네이티브 3D 생성 프라이어인 Pixel3D를 기반 모델로 사용한다(희소 구조 단계 + 형상 단계, 텍스처·재질 단계는 향후 과제로 남김). 각 정준 관측을 DINOv3로 인코딩해 2D 특징 맵을 얻고, 이를 정준 볼륨의 각 복셀에 투영해 3D 특징 격자로 끌어올린다. IBRNet 스타일의 순열 불변(permutation-invariant) 집계기가 여러 뷰의 특징을 교차-뷰 평균과 뷰별 잔차 가중합으로 융합하며, 집계기의 마지막 레이어는 0으로 초기화되어 학습 초기에는 단순 평균으로 시작해 점차 뷰별 보정을 학습한다. 집계된 3D 조건은 0-초기화된 주입 레이어를 통해 Pixel3D의 두 기하 생성 단계에 더해지고, 사전학습된 파라미터는 고정한 채 LoRA로 어텐션 및 프로젝션 레이어만 미세조정한다.
  3. 추론 및 장면 합성: 추론 시 각 객체를 독립적으로 처리하여 앵커를 고르고 정준 정육면체를 구성한 뒤, 가시 영역이 큰 관측을 우선하여 제한된 수의 조건 뷰를 선택한다. 두 단계 Pixel3D 생성을 거쳐 정준 공간 메쉬를 얻고, 정준-월드 변환을 적용해 원래 장면 좌표계에 배치한다. 최종 장면은 융합되지 않은 개별 메쉬들의 모음이다.

학습 시에는 객체마다 가변 개수의 조건 뷰와 무작위로 선택된 앵커를 사용하는 랜덤 뷰 학습을 적용하고, 실제 어수선한 장면에서 흔한 부분 관측·저품질 관측과의 격차를 줄이기 위해 2D/3D 가림 시뮬레이션, 카메라 포즈 왜곡, 마스크 경계 오류, 다운샘플링 등 네 종류의 열화를 학습이 진행됨에 따라 점진적으로 강하게 적용하는 조건-뷰 증강 커리큘럼을 사용한다. 증강은 입력 관측에만 적용되고 지도학습 타깃에는 적용되지 않는다.

실험 설정 및 결과

  • 벤치마크: (1) Toys4k(단일 객체, 뷰 수 1~16개·가림 0~75%로 통제된 실험), (2) Toys4k 객체들을 어수선하게 배치해 렌더링한 합성 다중 객체 벤치마크 Toys4k-Scene, (3) 실측 스캔 메쉬를 갖춘 실사 데스크톱 장면 데이터셋 HouseCat6D, (4) 저자들이 새로 만든 UE-MeshyScene(격납고·버려진 도시·성당·오피스·일본 학교·사막 마을 등 6개 장면, 객체 수 93~701개, 총 2,299개 객체·5,964개 뷰, Unreal Engine 5.8로 렌더링).
  • 비교 대상: Pixel3D, TRELLIS/TRELLIS.2, SAM3D, SceneGen, SceneMaker, RecGen, ShapeR 등.
  • 단일 객체 결과(Toys4k): 깨끗한 입력에서는 단일 뷰 Pixel3D와 대등한 성능을 보이며, 뷰 수가 늘수록 베이스라인 대비 우위가 커진다. 16개 뷰 사용 시 가림 50%까지도 성능이 거의 저하되지 않아, 다중 뷰 조건화와 증강 커리큘럼이 부분 관측에 대한 강인성을 크게 높임을 확인.
  • 다중 객체 결과: HouseCat6D에서 CD-ℓ2 0.28×10⁻³(ShapeR 1.26), F-Score 0.995(ShapeR 0.973); Toys4k-Scene에서 CD-ℓ2 0.61×10⁻³(ShapeR 8.38), F-Score 0.981(ShapeR 0.781). 씬이 복잡하고 가려짐이 심할수록 개선 폭이 더 커짐.
  • UE-MeshyScene 결과: 자사 방법이 ShapeR 대비 CD-ℓ2 2.48×10⁻³(ShapeR 7.42), F-Score 0.951(ShapeR 0.813)로 전 지표에서 우위를 보였으며, 평균뿐 아니라 중앙값 지표에서도 일관된 개선을 보여 소수의 어려운 사례가 아니라 전형적인 객체 전반에서 성능 향상이 나타남을 확인.
  • 어블레이션: 학습된 IBR 집계기가 단순 평균 융합보다 대체로 우수하며, 특히 다중 뷰·고가림 조건에서 이득이 두드러진다(예: 2뷰·75% 가림에서 CD-ℓ2가 12.91→10.03으로 개선). 씬 레벨 어블레이션에서도 장면이 복잡해질수록(HouseCat6D→Toys4k-Scene→UE-MeshyScene) IBR의 이득이 커짐을 확인.
  • 응용 사례: 추가 학습 없이, Marble이 생성한 3D 가우시안 스플래팅(3DGS) 월드에서 포즈가 알려진 RGB/깊이 프레임을 렌더링하고 SAM3로 객체 마스크·궤적을 추출한 뒤 WorldSculpt를 그대로 적용해, 하나의 뭉친 3DGS 표현을 개별 편집 가능한 메쉬들의 집합으로 변환할 수 있음을 시연.

한계점

저자들이 논문에서 직접 밝힌 한계는 다음과 같다: (1) 카메라 포즈, 객체별 인스턴스 마스크, 대략적인 3D 위치 박스 등 업스트림 추정치에 의존하며, 증강 커리큘럼이 어느 정도의 오차에는 강인하지만 심하게 잘못된 박스나 마스크 오류에는 여전히 취약하고, 저조도·모션 아티팩트 등 학습 시 명시적으로 다루지 않은 촬영 조건에서도 성능이 저하될 수 있다. (2) 현재 모델은 기하 구조만 생성하며 외형(텍스처·재질)은 다루지 않는다(Pixel3D와 TRELLIS.2가 지원하는 물리 기반 렌더링 재질 단계로의 확장은 향후 과제). (3) 정적 장면을 가정하므로 각 객체의 다중 뷰 관측을 동일한 고정 기하·자세의 측정치로 취급하며, 움직이거나 변형되는 객체는 현재 지원하지 않는다(옵티컬 플로우 기반 모션 추정이나 스켈레톤/SMPL-X 기반 표현으로의 확장이 가능한 방향으로 제시됨).

시사점

이 연구는 단일 객체용 강력한 3D 생성 프라이어에 가벼운 다중 뷰 조건화 경로만 추가해도, 씬 레벨의 별도 학습 없이 수백 개 객체 규모의 매우 어수선한 실제 장면까지 일반화될 수 있음을 보여줌으로써, "객체 프라이어의 조합적 확장"이라는 실용적인 패러다임의 타당성과 확장성을 입증한다. 이는 게임 콘텐츠 제작, AR/VR, 로보틱스 시뮬레이션 등에서 요구되는 편집 가능한 객체 단위 3D 자산을 실제 촬영 영상이나 심지어 다른 생성 모델(Marble, HY-World 2.0 등)이 만든 월드로부터도 얻어낼 수 있는 실용적 경로를 제시한다. 또한 UE-MeshyScene 벤치마크는 극도로 어수선하고 가려짐이 심한 장면에서의 조합형 3D 생성 연구를 위한 대규모 정답 데이터를 제공함으로써, 향후 관련 연구의 평가 기준으로 활용될 수 있다.
