SLA: Scaling Spatial-Language-Action Model via Continual Pre-training

SLA: 지속적 사전학습을 통한 공간-언어-행동 모델 확장

SLA는 사전학습된 π0.5 로봇 정책을 초기값으로 삼아, 고정된(frozen) 3D 인식 모델이 제공하는 공간 표현에 시각 임베딩을 정렬시키는 보조 학습 신호를 지속 사전학습(continual pre-training) 단계부터 적용함으로써, 추론 구조를 전혀 바꾸지 않고도 로봇 조작 정책에 전이 가능한 3차원 공간 이해 능력을 심어주는 공간-언어-행동(Spatial-Language-Action) 기초 모델이다.

한 줄 요약

SLA는 사전학습된 π0.5 로봇 정책을 초기값으로 삼아, 고정된(frozen) 3D 인식 모델이 제공하는 공간 표현에 시각 임베딩을 정렬시키는 보조 학습 신호를 지속 사전학습(continual pre-training) 단계부터 적용함으로써, 추론 구조를 전혀 바꾸지 않고도 로봇 조작 정책에 전이 가능한 3차원 공간 이해 능력을 심어주는 공간-언어-행동(Spatial-Language-Action) 기초 모델이다.

배경 및 문제의식

비전-언어-행동(VLA) 기초 모델들은 2D 비전-언어 사전학습에서 물려받은 시각 표현을 사용하지만, 실제 로봇 조작은 3차원 공간에서의 정밀한 제어를 요구한다. 기존 방법들은 공간적 지도(supervision)를 주로 과제별 후처리(post-training) 단계에서만 도입하거나, depth map·포인트 클라우드 같은 3D 센서 입력을 명시적으로 모델에 주입하는데, 이는 (1) 신뢰할 수 있는 3D 센서 데이터 확보의 어려움, (2) 로봇·센서 종류와 캘리브레이션 상태의 이질성, (3) 대규모 공개 로봇 데이터셋 중 상당수가 깊이 정보를 포함하지 않는다는 점에서 한계가 있다. 저자들은 선행 연구인 Spatial Forcing(암묵적 3D 표현 정렬)이 post-training 단계에만 공간 능력을 부가하는 데 그쳐, 확장 가능한 3D 기초 모델로 발전시키지 못했다는 점을 지적하며, 이를 지속 사전학습 단계로 확장할 필요성을 제기한다. 저자들은 사전 실험(depth probing)을 통해, 정렬 없이 2D 이미지만으로 학습된 VLA의 시각 임베딩은 의미 있는 공간 구조를 담고 있지 않음을 보여, 명시적 공간 지도의 필요성을 뒷받침한다.

핵심 기여

  • SLA를 제안: VLA의 중간 시각 임베딩을 외부 3D 인식 기초 모델의 공간 표현과 암묵적으로 정렬시키는 학습 방식으로, π0.5의 사전학습 가중치를 그대로 재사용하며 추론 구조·연산량을 추가하지 않는다.
  • 이 정렬 기법을 지속 사전학습 단계로 확장하여, 약 170만 에피소드·14,330시간 규모의 이질적인 공개 로봇 데이터셋을 통일된 상태·행동 표현으로 정제한 코퍼스 위에서 공간 정보가 내재된 기초 모델을 학습한다.
  • 동일한 정렬 원리를 다운스트림 post-training에도 유지 적용하여, 벤치마크 성능과 함께 양팔 협응(bimanual coordination), 공간·동적 일반화, 소수 샘플(few-shot) 크로스-임바디먼트 적응, 지시 따르기(instruction following) 능력을 입증한다.

방법론

SLA는 π0.5 정책을 초기화 기반으로 사용하며, 학습 중에만 작동하는 세 가지 보조 구성 요소를 둔다. 1. 외부 공간 지도(External Spatial Supervision): 멀티뷰 이미지를 고정된(frozen) 3D 인식 모델 OmniVGGT(VGGT 기반)에 입력해 픽셀 단위 3D 표현을 얻고, 이를 위치 임베딩과 함께 VLA의 시각 토큰 해상도로 이중선형 리샘플링하여 정렬 타깃 y로 사용한다. OmniVGGT의 GeoAdapter는 카메라 내·외부 파라미터와 깊이 정보가 일부만 있거나 전혀 없는 경우에도 placeholder 토큰과 확률적 멀티모달 융합으로 대응해, 이질적인 기하 어노테이션을 활용할 수 있게 한다. 2. 적응형 레이어 선택(Adaptive Layer Selection): VLA의 여러 트랜스포머 레이어에서 나온 시각 임베딩에 대해 토큰·채널 단위의 게이트(시그모이드 기반)를 학습해, 레이어별 기여도를 데이터에 따라 자동으로 가중합한다(F[·] 연산). 이는 특정 레이어가 특정 도메인에만 적합한 고정 레이어 선택의 한계를 보완한다. 3. 상태 드롭아웃(State Dropout): 학습 중 일부 샘플에서 로봇 상태(proprioceptive state) 토큰 전체를 확률적으로 제거하여, 정책이 시연 궤적-상태 간의 단축 연관(shortcut)에 의존하지 않고 시각 정보를 활용하도록 유도한다.

최종 학습 목표는 표준 행동 생성 손실(Laction, 플로우 매칭 기반 action expert)과 코사인 유사도 기반 정렬 손실(Lalign)을 가중합(α)한 것이다(L = Laction + αLalign). 정렬 과정에서 3D 교사 모델은 고정(frozen)되고, VLA 백본·MLP 프로젝터·게이트만 업데이트된다. 추론 시에는 교사 모델, 프로젝터, 게이트가 모두 제거되어 원래의 π0.5 추론 구조와 동일하게 동작한다.

데이터 측면에서는 RoboCOIN, AgiBot World Beta, DROID, InternData-A1, MolmoAct, RoboCasa365-Pretrain 등 6개 공개 데이터셋(약 170만 에피소드, 1,504개 과제, 14,330시간)을 정제했다. 서로 다른 로봇의 조인트 상태·행동 공간을 엔드이펙터(EEF) 기반의 절대 상태/상대(델타) 행동 표현으로 통일하고, 로봇 중심 좌표계(단일/양팔 로봇별 원점 정의)로 변환했다. 회전 표현은 오일러 각 직접 차분 시 각도 랩어라운드(wrap-around)로 발생하는 이상치를 피하기 위해 SO(3) 합성을 거친 회전 벡터(rotation vector)를 사용하고, 채널별 정규화를 적용했다. 또한 과도하게 반복적인 스크립트 기반 시뮬레이션 궤적은 데이터셋·과제별로 다운샘플링(예: InternData-A1 일부 과제 3~10%만 유지)했고, 양손이 아닌 덱스터러스 핸드 데이터, 베이스 이동이 포함된 궤적, 비정상적인 팔 속도를 보이는 데이터, 정지(idle) 프레임을 필터링했다.

실험 설정 및 결과

SLA는 π0.5를 초기화로 36k 스텝(유효 배치 4,608, 48×H100 GPU, 약 110시간) 지속 사전학습 후, 벤치마크별로 post-training을 수행했다.

  • LIBERO-Plus: 카메라·로봇·언어·조명·배경·관측 노이즈·배치 등 7개 교란 축 평가(10,030회 롤아웃)에서 가중 평균 성공률 87.4%를 기록, π0.5(84.4%) 및 선행 연구 Spatial Forcing(85.1%)을 상회했다.
  • RoboTwin 2.0: 50개 양팔 조작 과제에서 Clean 시연으로 학습 후 Clean2Random(도메인 랜덤화) 설정 72.3%, Clean2Clean/Random 평균 79.2%를 달성해 π0.5(평균 58.3%) 대비 20.9%p, 최강 경쟁 모델 ME-Dex-1.0(78.9%) 대비 소폭 개선했다.
  • RoboCasa-Panda: 과제당 50개의 적은 시연만으로 평균 성공률 68.4%를 기록, 300~3,000개 시연을 사용한 다른 기존 정책들을 능가했다.
  • RoboDojo-Real: ARX X5, Piper, Piper X 세 가지 실물 로봇 임바디먼트에 걸쳐 단일 정책으로 전체 성공률 33.9%(π0.5 12.8%, 최강 경쟁 모델 InternW0-Δ 31.7% 대비 우위)를 달성했다.
  • 실제 환경 배치(8개 조건 A–H): 양팔 과일 전달(A), 사람이 던진 물체 회수(B), 움직이는 물체 포착(C), 소수 샘플 임바디먼트 적응(D), 테이블 높이 변화(F), 동적 테이블 위 포착(G), 미학습 물체에 대한 지시 따르기(H) 등에서 SLA는 전 조건 평균 83.8% 성공률로 π0.5(59.8%) 대비 24.0%p, Spatial Forcing(68.0%) 대비 15.8%p 개선을 보였다.
  • 분석 실험: (1) 데이터 스케일링 실험에서 지속 사전학습과 post-training 양 단계 모두에 정렬을 적용한 조합이 모든 데이터 비율(5~100%)에서 가장 우수했다(100%에서 72.3%, 두 단계 중 한쪽만 적용 시 63.2%/57.1%). (2) 적응형 레이어 선택이 고정 레이어(1·6·12·18) 대비 최고 성능(평균 79.2%)을 보였다. (3) 상태 드롭아웃은 확률 25%에서 최적(79.2%, 미적용 시 38.1%)이었고, 확률이 과도하게 높아지면 오히려 성능이 떨어졌다. (4) 회전 벡터 표현이 오일러 각·Rot6D·쿼터니언보다 우수했다. (5) OmniVGGT에 카메라 캘리브레이션을 추가 제공하면 RGB 전용 대비 추가로 성능이 개선되었다.

한계점

논문 본문에 별도의 한계점(Limitations) 절은 없다. 다만 본문에서 간접적으로 드러나는 제약으로, RoboDojo-Real의 ARX X5 임바디먼트에서는 SLA가 InternW0-Δ에 이어 2위에 머물렀다는 점, RoboTwin의 Clean2Clean 설정에서는 ME-Dex-1.0에 뒤처진다는 점이 언급된다. 또한 학습에 사용하는 외부 3D 인식 모델(OmniVGGT)과 깊이·캘리브레이션 데이터의 품질·가용성에 성능이 어느 정도 의존하며, 전체 방법이 양지(two-finger gripper) 조작과 비(非)이동 베이스 로봇 데이터로 범위를 제한하고 있다(덱스터러스 핸드, 모바일 베이스 이동 데이터는 필터링으로 제외).

시사점

이 연구는 로봇 파운데이션 모델에서 "공간 이해 능력"을 과제별 후처리 단계의 부가 기능이 아니라, 대규모·이질적 데이터를 활용한 지속 사전학습 단계의 핵심 역량으로 설계할 수 있음을 보여준다. 특히 (1) 외부 3D 교사 모델에 대한 정렬이 학습 시에만 필요하고 추론 구조·연산 비용을 전혀 늘리지 않는다는 점에서, 기존에 배포된 VLA 파이프라인에 비교적 저부담으로 공간 지능을 주입할 수 있는 실용적 경로를 제시하며, (2) 이종(heterogeneous) 로봇 데이터를 통일된 EEF 기반 표현으로 정규화하고 적응형 레이어 게이팅으로 처리하는 방법론은 멀티 임바디먼트·멀티 데이터셋 스케일링이 필요한 향후 로봇 파운데이션 모델 연구에 일반적으로 적용 가능한 설계 지침을 제공한다.
