REA: A Routed Embodied Agent Runtime for Asynchronous Brain-Cerebellum Control

REA: 비동기 브레인-소뇌 제어를 위한 라우팅 기반 임베디드 에이전트 런타임

한 줄 요약

느린 추론형 "브레인"(에이전트)과 빠른 반사형 "소뇌"(VLA·코드 정책)를 비동기적으로 연결하는 3계층 로봇 런타임 REA를 제안하여, 실행 중인 정책이 브레인을 기다리지 않고도 LIBERO-Pro에서 95.9%의 성공률을 달성했다.

배경 및 문제의식

파운데이션 모델 기반 에이전트는 고차원 추론에는 뛰어나지만 세밀한 제어기로 쓰기엔 느리고 비용이 크며, 반대로 VLA 등 빠른 정책은 효율적이지만 일반화에 약하다. 이 둘을 결합하려는 시도는 있었지만, 에이전트 기반 시스템과 VLA 기반 시스템이 서로 다른 시뮬레이터·관측 형식·성공 기준 위에서 구축되어 공정한 비교가 어렵고, 비동기적 협응 자체도 어렵다는 두 가지 걸림돌이 있다. 예컨대 에이전트가 매 호출마다 빠른 정책을 멈춰 세우면 로봇이 유휴 상태로 대기하고, 반대로 정책이 오류 시에만 에이전트를 부르면 조용한 실패(실패해도 오류가 나지 않는 경우)를 거의 포착하지 못한다.

핵심 기여

(1) 에이전트와 VLA, 프로그램형 정책을 동일한 인터페이스로 평가할 수 있는 3계층 런타임 REA를 제시했다. (2) 정책별 과거 성공률을 미리 저장해두는 라우트 메모리, 정책이 반환되는 경계 지점에서만 브레인에게 완료 여부를 묻는 판정 게이트, 예산을 공유하는 단계적 에스컬레이션(복구) 사다리라는 세 가지 설계로 "브레인이 실행 중인 정책을 절대 막지 않는다"는 원칙을 구현했다. (3) 3만 건 이상의 정렬된 테스트 에피소드와 실제 로봇 실험을 통해 라우팅·판정 모듈 각각의 기여를 검증했다.

방법론

REA는 System 2(브레인, 정책을 생성·조언·판정하는 에이전트), System 1(임베디드 라우터, 어떤 정책을 언제 실행할지 결정), System 0(빠른 정책을 실제로 실행하는 셀)으로 구성된다. 라우터는 개발 에피소드에서 측정한 정책별 성공률과 평균 스텝 수를 라우트 메모리로 저장해 테스트 시점에는 조회만으로 정책을 바로 디스패치하고, 정책이 세그먼트 경계에서 반환될 때만 시각 판정 모델(VLM)을 호출해 완료(done) 또는 미완료(not_done·에스컬레이션)를 결정한다. 복구가 필요하면 동일한 스텝·시간 예산 안에서 다음 후보 정책으로 넘어가는 에스컬레이션 사다리를 사용하며, 예외가 발생했을 때만 작동하는 '예외 게이트'와 매 반환마다 작동하는 '판정 게이트'를 구분해 적용한다.

실험 설정 및 결과

LIBERO-Pro 60개 태스크·3,000 에피소드 평가에서 REA는 95.9% 성공률로 가장 강력한 단일 베이스라인인 Agents SDK + GPT-6(94.7%)를 능가했고, 제어 시간은 차단형(blocking) 어드바이저 대비 25%, Agents SDK 대비 17% 단축했다. 별도의 RoboTwin 2.0 100에피소드 연구에서는 VLA 정책만으로 84%, VLA+코드 혼합 정책으로 86%를 기록해 최강 단일 VLA 베이스라인 MEDex(80%)를 상회했다. BEHAVIOR-1K, RoboTwin 2.0, 실제 Unitree G1 휴머노이드, AlohaMini2 로봇팔로의 전이 실험에서도 비교 대상 중 가장 높은 관측 성공률을 보였으며(AlohaMini2 블록 배치 10/10), 라우터 제거(ablation) 실험에서 라우트 메모리와 판정 게이트 각각이 성능 향상에 기여함을 확인했다.

한계점

논문은 별도의 "한계점" 절을 두지 않았으나, 논의에서 다음을 인정한다. 라우트 메모리는 평가 전 별도의 개발(development) 에피소드에서 정책별 성공률을 미리 측정해야 하며, 판정 게이트와 예외 게이트 중 어느 쪽을 쓸지는 정책 라이브러리의 특성에 따라 선택해야 하는 설계상 트레이드오프가 있다. 또한 RoboTwin VLA 확장 실험에서는 학습된 선택기가 에피소드 시작 시 한 번만 정책을 고르고 바꾸지 않으며, 복구 게이트 효과는 LIBERO-Pro에서만 별도로 검증되어 다른 환경에서의 게이트 효과는 명시되지 않음.

시사점

브레인(느린 추론)과 정책(빠른 반사)을 결합할 때 핵심은 더 큰 정책 풀이나 매 스텝 개입이 아니라 "언제 브레인을 부를지"를 잘 설계하는 라우팅 그 자체에 있음을 보여준다. 이는 에이전트·VLA·고전적 제어기를 가리지 않고 재사용 가능한 공통 런타임으로서, 서로 다른 정책 생성 방식들을 동일한 기준으로 비교·조합하는 플랫폼의 가능성을 제시한다.
