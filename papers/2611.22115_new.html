TeleChat to Xing4: Advancing Frontier Agentic Models on Domestic Chips and Frameworks

싱4(Xing 4): 국산 칩과 프레임워크 기반 프론티어 에이전틱 모델 고도화

한 줄 요약

중국 화웨이 Ascend NPU와 MindSpore 프레임워크만으로 2850억 파라미터급 MoE 모델을 훈련·서빙할 수 있도록, 아키텍처 설계부터 분산 학습 인프라, 에이전트 강화학습 플랫폼까지 전 과정을 국산화한 TeleChat 후속 모델 Xing 4 시리즈의 기술 보고서.

배경 및 문제의식

대부분의 오픈소스 대형언어모델은 GPU 기반으로 훈련되지만, 이 연구는 GPU가 아닌 Ascend 910C NPU와 MindSpore 프레임워크라는 국산(도메스틱) 칩·프레임워크 생태계에서 프론티어급 에이전틱 모델을 훈련하는 데 따르는 시스템적 과제를 다룬다. 긴 문맥 처리 시 KV 캐시 접근 비용 증가, 깊은 네트워크에서 발생하는 비행렬 연산(정규화, 라우팅, 인덱싱 등) 오버헤드로 인한 Ascend 하드웨어 활용도 저하가 핵심 병목으로 지적된다.

핵심 기여

논문은 세 가지 축의 기여를 제시한다. 1. Ascend 지향 아키텍처 설계: 희소 활성화, 어텐션 설계, 깊이-너비 균형, 추론적 디코딩을 모델 용량·장문맥 요구사항과 Ascend의 행렬 연산·메모리 접근·순차 실행 비용에 연결해 설계 트레이드오프를 명시. 2. 대규모 사전학습을 위한 분산 시스템 최적화: 토폴로지 인지형 하이브리드 샤딩(HSDP), 소유자 기반 Muon 옵티마이저 실행, 장시퀀스 워크로드 밸런싱, KV 압축, 활성화 메모리 관리를 통합. 3. TeleGym과 통합 강화학습: 에이전트 실행, 평가, 궤적 생성을 정책 최적화로 연결하는 통합 플랫폼을 도입하고, 비동기 분산 실행과 부분 롤아웃(partial rollout)으로 이질적인 작업 소요 시간을 수용.

방법론

대표 구성(285B 파라미터, 토큰당 17B 활성화)은 45개 층 중 처음 3개 층을 Dense FFN으로, 나머지를 MoE FFN으로 구성하며, MLA(Multi-head Latent Attention)에 DSA(DeepSeek Sparse Attention)와 IndexShare(교차 층 인덱스 재사용)를 결합해 장문맥에서의 과거 KV 접근과 인덱스 재계산을 줄인다. 디코딩 단계에서는 블록 단위 드래프트 모델, 경량 마르코프 헤드, 수락 신뢰도 헤드로 구성된 DSpark 추론적 디코딩을 적용한다. 학습 인프라는 MindSpore HyperParallel 기반의 HSDP(Hybrid Sharded Data Parallel)로 슈퍼노드 내부는 완전 샤딩, 슈퍼노드 간에는 복제를 수행해 파이프라인 병렬화 없이도 통신 오버헤드를 억제하며, Muon 옵티마이저의 전행렬 직교화 연산을 매트릭스별 소유자(owner) 랭크에 위임해 중복 계산을 제거한다. 또한 연산자 단위 선택적 재계산(선택적 체크포인팅)으로 활성화 메모리를 절감하고, CPU 어피니티·코어 격리로 호스트 스케줄링 지연을 줄인다. 후속 학습 플랫폼 TeleGym은 TeleGym(실행 계층)–중간 서버(상호작용→학습 궤적 변환)–Slime(비동기 정책 최적화)의 3계층 구조로 수학 추론, 코드 생성, 멀티턴 에이전트 과제를 하나의 강화학습 루프로 통합한다.

실험 설정 및 결과

8,192장의 Ascend 910C 카드로 구성된 대규모 프로덕션 클러스터에서 285B 모델을 사전학습했다. 어텐션 설계 비교에서 MLA+DSA+IndexShare 조합은 MLA 단독 대비 프리필 처리량 4.68배, 디코딩 처리량 1.27배를 달성했고, DSpark 추론적 디코딩은 6개 수학·코드 벤치마크에서 기본 설정 대비 2.67~3.77배의 출력 처리량 향상을 보였다(MTP 기반 방식 대비도 1.48~2.10배 우수). 깊이-너비 트레이드오프 실험에서는 60층 구성보다 45층의 넓고 얕은 구성이 디코딩 처리량 1.11배, 훈련 처리량 약 10% 개선을 보여 채택되었다. 1,024 NPU 프로파일링 클러스터 기준으로 HSDP 도입만으로 파이프라인 병렬 기준선 대비 스텝 시간이 12.6%(1.14배) 단축되었고, 여기에 소유자 기반 Muon 실행이 추가로 9.1%, 레이어별 인덱서 역전파 최적화가 15.2%의 스텝 시간 단축을 각각 독립적으로 기여했다. CPU 핀닝과 코어 격리를 함께 적용하면 512장 클러스터에서 1~2%, 8,192장 클러스터에서는 5~10%의 훈련 처리량 향상이 관측되었다.

한계점

시뮬레이션 기반 성능 모델링(화웨이 Zhanlu 프레임워크)은 실제 프로덕션 서빙의 모든 오버헤드를 완전히 반영하지 못해, 보고된 결과가 실제 엔드투엔드 배포 측정치보다 낙관적일 수 있다고 저자들이 직접 명시한다. 또한 연산 재배치나 배치 커널 사용이 부동소수점 결과를 변화시킬 수 있어, 행렬별 직교화 도메인 선택이 수치적 동일성을 보장하지 않으며 실제 학습 구성에서 런타임·통신량·수치 거동을 별도로 측정해야 한다고 언급한다.

시사점

이 연구는 GPU 독점에 의존하지 않고도 비(非)엔비디아 국산 하드웨어·프레임워크 생태계에서 트랜스포머 기반 프론티어 모델을 처음부터 끝까지(아키텍처-사전학습-에이전트 후속학습) 구축할 수 있음을 보여주는 사례로서, 하드웨어 다변화 및 지정학적 공급망 제약 상황에서 대형언어모델 인프라 전략을 수립하는 데 참고할 수 있는 구체적 설계 패턴을 제공한다.
