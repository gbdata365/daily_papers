Paint-Anything: Unified Any-Color Control for Image Generation and Editing

Paint-Anything: 이미지 생성과 편집을 위한 통합 임의 색상(Any-Color) 제어

Paint-Anything은 텍스트 프롬프트 안에 24비트 16진수(hex) 색상 코드를 `#HEX` 형태로 직접 삽입하는 방식으로, 하나의 파인튜닝된 모델이 이미지 생성과 이미지 편집 모두에서 객체 단위의 임의 색상(any-color) 제어를 수행하도록 만든 통합 모델이다.

한 줄 요약

Paint-Anything은 텍스트 프롬프트 안에 24비트 16진수(hex) 색상 코드를 <color>#HEX</color> 형태로 직접 삽입하는 방식으로, 하나의 파인튜닝된 모델이 이미지 생성과 이미지 편집 모두에서 객체 단위의 임의 색상(any-color) 제어를 수행하도록 만든 통합 모델이다.

배경 및 문제의식

브랜드 로고나 제품 이미지처럼 전문 디자인 작업은 "파란색"이라는 모호한 표현이 아니라 정확한 16진수 색상값을 요구하지만, 기존 텍스트-이미지 생성·편집 모델은 이런 명시적 색상 지정을 안정적으로 따르지 못한다. 기존 색상 제어 연구들은 전용 색상 모듈, 학습된 색상 토큰, 또는 추론 시점의 샘플링 가이던스·어텐션/값 조작 같은 training-free 기법에 의존해왔는데, 이는 다양한 색상으로 확장하거나 다른 아키텍처로 이식하기 어렵고 추론 비용도 크다는 문제가 있다. 저자들은 소형 언어모델(Qwen3-4B)조차 hex 코드와 색상 의미를 그럴듯하게 연결할 수 있다는 사전 관찰(논문 Figure 2)에서 출발해, hex 문자열 자체를 프롬프트 네이티브 색상 인터페이스로 활용할 수 있다는 아이디어를 제안한다. 생성·편집·컬러라이제이션을 서로 별개의 문제로 다뤄온 기존 접근과 달리, 이 논문은 이를 하나의 프롬프트-following 능력으로 통합하고자 한다.

핵심 기여

  1. 객체 수준 hex 색상 지도학습만으로도 생성과 편집 모두에서 통합된 프롬프트 네이티브 색상 제어가 가능함을 보이고, 타임스텝 게이팅된 순수색(pure-color) 그라운딩으로 이를 강화하는 방법을 제안했다.
  2. 실제 이미지-캡션 쌍을 객체 수준 hex 지도학습 데이터로 변환하는 데이터 파이프라인을 개발하여, 약 50만 개 샘플 규모의 Paint-500K 데이터셋을 구축했다.
  3. 생성과 편집에서 객체 수준 hex 색상 충실도를 측정하는 Any Color Benchmark(ACBench, ACBench-T2I·ACBench-Edit로 구성)를 새로 도입하고, 여러 백본과 독립적인 기존 벤치마크에서도 일관된 성능 개선을 입증했다.

방법론

베이스 모델은 rectified-flow 기반 텍스트-이미지 모델(FLUX.2-klein-base-4B, Z-Image Base)로, frozen 텍스트 인코더·VAE·denoising transformer로 구성되며 flow-matching 목적함수로 학습된다. 편집 시에는 소스 이미지를 동일 VAE로 인코딩한 clean latent를 노이즈 타깃 latent와 concat하여 조건으로 사용한다.

핵심 설계 요소는 다음과 같다. - 명시적 색상 태그 래핑: 프롬프트 내 hex 코드를 <color>#HEX</color>로 감싸 텍스트 인코더가 색상 스팬을 명확히 인식하도록 만든다. - 통합 생성/편집 학습 포맷: 모든 샘플이 타깃 이미지와 hex 조건 프롬프트로 구성되고, 편집 샘플만 소스 이미지 조건이 추가되어 한 모델이 동일한 denoising objective로 두 과제를 함께 학습한다. - 순수색 앵커(pure-color anchor): 실제 이미지에서 추출한 색상 라벨은 그림자 등으로 노이즈가 섞인 근사값이므로, 단색 이미지와 그에 대응하는 hex 코드를 쌍으로 만든 "순수색" 샘플을 보조로 학습시켜 hex→RGB 매핑에 대한 깨끗한 저수준 신호를 제공한다. - high-noise gating: 순수색 궤적을 분석한 결과(부록 E) 색상이 비교적 초기(높은 노이즈) 단계에서 이미 안정화되는 경향이 있어, 순수색 앵커 샘플은 t∈[t_gate, 1] (t_gate=0.8)인 고노이즈 구간에서만 학습에 사용하고, 저노이즈 구간은 실제 이미지 학습에 집중시킨다. - 학습 손실: T2I·편집·순수색 앵커 세 스트림에 대한 flow-matching loss를 각각 동일 가중치(1)로 합산한다.

데이터 파이프라인(Paint-500K)은 VLM(Seed1.8)로 캡션에서 관련 객체를 그라운딩하고, SAM3로 인스턴스 마스크를 얻은 뒤, CIELAB 색공간에서 MeanShift 클러스터링(고정 K인 K-means 대비 인지적으로 더 일관된 결과)으로 지배색을 추출한다. 픽셀 커버리지 기준으로 필터링한 뒤 VLM이 캡션을 다시 작성해 hex 스팬을 해당 명사구에 결합한다. 편집용 데이터는 사전학습된 편집 모델(Qwen-Image-Edit + Lightning LoRA)로 원본 이미지를 재색칠해 소스 이미지로 삼고, 원본 사진을 타깃(생성 아티팩트 없는 실제 이미지)으로 사용한다. 최종적으로 T2I 40만 개(단일객체 10만+다중객체 30만)와 편집 10만 개, 총 50만 개 샘플이 구성된다.

실험 설정 및 결과

평가는 자체 제안한 ACBench(ACBench-T2I 1000개 프롬프트, ACBench-Edit 500개 실제 이미지 리컬러링 프롬프트), 기존 CompColor(색상 이름 대신 hex로 치환한 프로토콜 포함), 독립적인 GenColorBench NCU를 사용한다. 지표는 SAM으로 분할한 타깃 객체 영역의 평균 sRGB 값과 요청된 hex 값 간 평균 절대오차(MAE)를 0~100 점수로 환산한 값이다. 비교 대상은 SD1.5, FLUX.1, Z-Image-Turbo, Qwen-Image/Edit, FLUX.2-9B, FLUX.2-dev(56B), FLUX.2-4B 등 오픈소스 모델과 ColorBind/Edit, CtrlColor, ColorPeel, ColorWave 등 색상 특화 방법이다.

FLUX.2-4B를 동일 레시피로 파인튜닝한 결과, base 모델 대비 ACBench-T2I 점수가 37.02→68.58(약 85.3% 개선), ACBench-Edit 점수가 58.90→75.57(약 28.3% 개선)로 상승했다. 파인튜닝된 8B 모델이 파라미터 수가 훨씬 큰 56B FLUX.2-dev보다 ACBench-T2I에서 16.88점, ACBench-Edit에서 6.70점 더 높은 점수를 기록했다. CompColor의 hex 프로토콜에서는 base 모델 점수가 named-color 대비 크게 떨어졌던 것(0.72→0.38)이 파인튜닝 후 0.79로 회복·향상되었고, 동시에 named-color 성능도 0.72→0.79로 개선되어 hex 이해 능력 추가가 기존 색상-바인딩 능력을 해치지 않음을 보였다. 가장 강한 색상 특화 베이스라인 대비로도 ACBench-T2I에서 ColorWave보다 22.04점, ACBench-Edit에서 ColorBind/Edit보다 15.19점 높았다. 독립적인 GenColorBench NCU 평가에서도 34.00→57.89로 개선되어 공개된 FLUX+NumColor 결과(51.90)를 능가했다. Ablation 실험에서는 color-token wrapping, pure-color anchor, high-noise gating, full fine-tuning(LoRA 대비) 각 요소가 모두 성능에 기여함을 확인했으며, t_gate=0.8이 가장 좋은 균형을 보였다.

한계점

논문은 현재 학습 데이터(Paint-500K)가 팔레트 단위(palette-specific) 색상 지도학습을 포함하지 않는다는 점을 한계로 명시적으로 언급하며, 이를 향후 과제로 남겨두었다. 그 외 세부적인 실패 사례나 한계에 대한 구체적 논의는 논문에 명시되지 않음.

시사점

이 연구는 텍스트 인코더가 hex 색상 문자열의 의미를 어느 정도 이미 이해하고 있다는 관찰에서 출발해, 별도의 색상 인코더나 추론 시점 제어 장치 없이도 프롬프트 자체를 통해 객체 단위의 임의 색상 제어가 가능함을 보였다. 이는 색상 제어를 이미지 생성 파운데이션 모델의 native capability로 통합할 수 있는 실용적 경로를 제시하며, 브랜드 색상 일치가 중요한 실제 디자인·전자상거래 응용(제품 이미지, 로고, 카탈로그 리컬러링 등)에 바로 활용될 수 있는 잠재력을 시사한다.
