Sage-Med: Scaling Medical Multimodal Intelligence

세이지메드: 의료 멀티모달 지능 스케일링

의료용 멀티모달 대형언어모델(MLLM)이 범용 모델에 비해 시각 이해 능력에서 뒤처지는 문제를 데이터 큐레이션과 단계적 학습 커리큘럼으로 해결한 350억 파라미터(활성 30억) 모델 Sage-Med-Preview를 제시한다.

한 줄 요약

의료용 멀티모달 대형언어모델(MLLM)이 범용 모델에 비해 시각 이해 능력에서 뒤처지는 문제를 데이터 큐레이션과 단계적 학습 커리큘럼으로 해결한 350억 파라미터(활성 30억) 모델 Sage-Med-Preview를 제시한다.

배경 및 문제의식

의료 영상 판독은 진단 의료의 핵심 병목이며, 전문의 부족은 특히 저소득·중간소득 국가에서 더 심각하다. 텍스트 기반 의료 LLM은 전문가 수준의 지식을 보여주지만, 이미지와 언어를 함께 다루는 멀티모달 모델은 특정 전문 분야별로 따로 개발되어 왔다. 저자들은 기존 의료 MLLM들이 범용 최신 MLLM보다 여러 의료 과제에서 성능이 떨어지며, 모델 크기를 키워도 주로 텍스트 능력만 개선되고 시각 인지 격차는 좁혀지지 않는다는 점을 실증적으로 보였다. 이는 (1) 고품질 의료 이미지-텍스트 데이터의 부족, (2) 범용 모델을 의료 전문 역량으로 전환하는 효과적 적응 방법의 부재, (3) 임상 워크플로우를 충분히 반영하지 못하는 평가 체계라는 세 가지 근본적 난제에서 비롯된다고 분석한다.

핵심 기여

  • 대규모 의료 데이터 큐레이션: 200개 이상의 공개 데이터셋, 2,500만 건의 생물의학 문헌(PDF·책·웹페이지), 100개 이상의 비공개 자원으로부터 약 3억 2,270만 건의 단계별 후보 레코드를 수집하고, 사전학습(약 9,380만 건)·지도미세조정(약 6,960만 건)·강화학습(약 30만 건) 용도로 6단계 필터링 파이프라인을 통해 정제했다.
  • 점진적 멀티모달 학습 커리큘럼: 의료 지식·시각-의미 정렬을 위한 지속 사전학습과 과제지향 중간학습, 3단계 지도미세조정(명령어 정렬→과제 다양화→선택적 정교화), 그리고 정책 조건부 난이도 샘플링과 독립 참조 재생(replay)을 결합한 적응적 강화학습(GRPO 기반)으로 구성된 학습 체계를 설계했다.
  • 대규모 종합 평가: 공개 모델 68개와 독점 모델 9개를 포함한 77개 모델을 대상으로, 61개 공개 벤치마크와 14개 기관이 제공한 13개 비공개 다기관 벤치마크(총 238개 임상 과제, 40개 이상 모달리티)에서 비교 평가를 수행했다.

방법론

Sage-Med-Preview는 과학 멀티모달 기반모델인 Intern-S2-Preview(350억 파라미터, 활성 30억)에서 초기화되었다. 학습은 세 단계로 구성된다: ① 의료 적응(지속 사전학습 8,380만 건 + 과제지향 중간학습 2,810만 건), ② 3단계 점진적 지도미세조정(각각 610만/960만/620만 건, 난이도 높은 예제와 사고과정(chain-of-thought) 비중을 단계적으로 확대), ③ 적응적 강화학습(GRPO)으로, 정책이 학습됨에 따라 변하는 과제 난이도를 추정해 성공률이 중간 수준(정답 2~6개/8개 응답)인 과제에 샘플링을 집중시키고, 폐쇄형 과제는 검증기로, 개방형 과제(보고서 생성 등)는 심판 모델의 루브릭으로 보상을 산정했다.

실험 설정 및 결과

45개 핵심 공개 벤치마크를 포함한 61개 공개 벤치마크(31개는 멀티모달)와 13개 비공개 다기관 벤치마크에서 평가한 결과, 기존 의료 MLLM들은 31개 멀티모달 벤치마크 중 29개에서 범용 MLLM보다 낮은 성능을 보였다. Sage-Med-Preview는 해당 31개 벤치마크에서 평균 58.26%를 기록하여 오픈소스 의료 모델 Hulu-Med-235B-A22B(50.99%)와 범용 과학 모델 Intern-S2-Preview(52.24%, 베이스 모델)를 능가했으며, 독점 모델 GPT-6.2-Sol과 비교해 종합적 멀티모달 이해 및 보고서 생성에서는 더 우수하고 시각적 위치추정(grounding)에서는 비슷한 수준을 보였다. 비공개 다기관 벤치마크에서도 평균 57.72%로 모든 평가 모델 중 최고 성능(GPT-6.2-Sol 51.24%)을 기록했다. 다만 복잡한 의료 추론과 다단계 임상 워크플로우에서는 여전히 큰 과제가 남아있다고 밝혔다.

한계점

저자들이 직접 명시한 한계는 다음과 같다: (1) 더 넓은 파라미터·데이터·연산 규모에서의 정량적 스케일링 법칙을 체계적으로 규명하지 못했다. (2) 학습 단계마다 멀티모달 비율이 달라져(SFT 2·3단계 60%·53%, RL 80%) 모달리티 균형의 독립적 효과를 분리하기 어렵다. (3) 고정된 시각 토큰 예산 하에서 해상도 대 볼륨/시간적 프레임 커버리지의 상대적 기여도를 체계적으로 비교하지 못했다. (4) API 및 연산 비용 제약으로 모든 최신 프런티어 범용 모델을 전체 벤치마크에서 평가하지 못했으며, 일부 독점 모델은 벤치마크 일부에만 적용되었다.

시사점

이 연구는 의료 멀티모달 지능의 발전이 단순히 모델 크기나 데이터량 확대가 아니라 지도학습 품질, 모달리티 균형, 학습 커리큘럼의 정합성에 좌우된다는 점을 보여준다. 저자들은 향후 임상 도구, 반복적 검증, 구조화된 하네스를 갖춘 에이전트 프레임워크에 멀티모달 기반모델을 통합하는 방향이 범용 의료 멀티모달 지능으로 가는 유망한 경로라고 제안한다.
