3AGameFactory-Motion: Agentic Rigging and Reliable Complex Motion Generation for Diverse 3D Assets

3A게임팩토리-모션: 다양한 3D 에셋을 위한 에이전트 리깅과 신뢰 가능한 복합 모션 생성

한 줄 요약

에이전트가 사람·동물 骨격을 가정하지 않는 다양한 3D 에셋에 대해 컴팩트한 파라메트릭 리깅/모션 프로그램을 작성하고, 결정론적 실행기(executor)가 이를 역/정기구학과 스키닝으로 정확히 실행하도록 하는 Agentic Motion Framework와, 이를 평가할 DivDynBench 벤치마크를 제안한다.

배경 및 문제의식

기존 모션 생성 모델은 긴 지시문에서 요구되는 타이밍·각도·반복 횟수 등을 정확히 지키지 못하며, 대부분 인간형이나 동물형 등 전형적인 skeleton에 맞춰 학습되어 다리가 여러 개이거나 날개·기계 구조를 가진 비정형 3D 에셋에는 일반화되지 않는다. 또한 기존 모션 벤치마크들은 전형적인 skeleton과 단순한 지시문만을 다루어, 복잡한 다중 파트·다중 단계 지시 수행 능력을 제대로 평가하지 못한다.

핵심 기여

  • 다양한 3D 에셋에 대한 지시문 기반 모션 생성 문제를 정식화하고, LLM 활용 3가지 패러다임(특화 모션 생성기 결합, 비디오 생성 후 모션 복구, LLM 직접 모션 생성)을 체계적으로 비교·분석
  • 휴머노이드, 다지류, 축형(axial), 유익(날개 달린), 혼합 사지, 기계 구조 등 6개 형태(morphology) 범주와 850개 모션 과제로 구성된 DivDynBench 벤치마크 제안, 비주얼 스코어링과 프로그램 기반 검증을 결합한 평가 체계 설계
  • 세 패러다임을 controllability, 형태 간 적응성, 생성 비용 측면에서 비교
  • Agentic Motion Framework 제안: 에이전트가 스켈레톤 구성과 모션 프로그램을 적은 수의 의미론적 파라미터로 작성하고, 결정론적 실행기가 리깅·역기구학 해결·기하 보정을 수행하여 생성 오버헤드를 줄이고 리깅 신뢰성과 모션 제어 정확도를 향상

방법론

리깅 단계에서는 에이전트가 다중 시점(멀티뷰) 이미지에서 관절을 주석(annotate)하고 뼈대 체인으로 연결하면, 실행기가 2D 주석을 3D 관절 위치와 계층 구조로 융합(lifting)하고, 거리 감쇠 기반 geodesic-gated skinning weight를 계산해 파트 간 영향 누출(leakage)을 방지한다. 모션 생성 단계에서는 에이전트가 지시문을 단계(phase)와 타이밍으로 분할하고, 각 단계에서 핵심 파트와 엔드이펙터를 선택해 궤적과 목표를 설계한다. 이 정보는 (T, f, H, K, R0, {Pp}, ξ)로 구성된 컴팩트한 모션 프로그램으로 표현되며, root 제어(R0)와 파트별 체인 제어(Pp)로 구분된다. 엔드이펙터 연산자는 하나의 스칼라 값을 체인 전체에 분산시켜 뼈 길이를 보존하면서 임의 길이의 체인(꼬리, 촉수 등)을 제어할 수 있게 한다. 실행기는 역/정기구학으로 전신 포즈를 계산하고, 변형된 메시 기반 피드백으로 관통(penetration)과 접지(ground contact) 오차를 보정하며 최대 5회까지 재해결(re-solve)한다.

실험 설정 및 결과

50개 에셋과 850개 모션 과제(텍스트 428개, 수치형 422개)로 구성된 DivDynBench에서, 리깅은 Puppeteer, SkinTokens, UniRig, RigAnything 등 특화 리깅 기법과 GPT6.1-sol·Claude-ops5.5 에이전트를 비교했다. Agentic Motion Framework를 적용하면 두 에이전트 모두 Source Fidelity가 100%에 도달하고 J2J, mIoU, Joint validity 등 지표가 크게 향상되었다(예: Claude-ops5.5+Ours의 Joint validity 0.92, 기존 특화 기법 대비 우수). 모션 생성에서는 직접 LLM 생성 방식이 가장 우수한 성능을 보였으며, Claude-ops5.5+Ours가 Overall 50.07점으로 최고 성능을 기록했고, 비용은 case당 0.047달러로 비디오 생성 기반 방식(0.418달러) 대비 훨씬 저렴했다. 휴머노이드 서브셋에서는 Claude-ops5.5+Ours가 Overall 57.27점으로 MoMask, MotionBricks 등 인간형 특화 모델을 능가했다. 30명 참가 사용자 평가에서도 GPT 기반 자동 평가와 동일한 순위 경향이 확인되었다.

한계점

논문은 LLM 에이전트 직접 생성 방식이 가장 유망하지만 "여전히 불안정(unstable)"하다고 명시하며, 에이전트와 형태(morphology)에 따라 성능 편차가 크다는 점을 한계로 언급한다. 또한 평가는 제공된 참조 리그(reference rig) 기반 모션 생성과 원본 메시 기반 리깅을 분리하여 수행했기 때문에, 예측된 리그를 사용한 end-to-end 성능은 본문이 아닌 보충 자료에서만 다뤄진다.

시사점

이 연구는 복잡한 지시문 기반 3D 애니메이션 생성에서 "에이전트가 적은 수의 의미론적 파라미터만 작성하고 나머지는 결정론적 모듈이 처리"하는 역할 분담 방식이 임의의 骨격 구조에서도 신뢰성과 제어 정확도를 크게 높일 수 있음을 보여준다. 이는 게임·애니메이션 제작 파이프라인에서 비정형 3D 에셋의 자동 리깅 및 동작 생성 자동화 가능성을 시사하며, 향후 더 다양한 형태 범주와 더 긴 호라이즌의 복합 동작으로 확장될 수 있는 기반을 제공한다.
