VisSearch-Bench: Evaluating Long Horizon Visual Search in Multimodal Agents

비스서치벤치: 멀티모달 에이전트의 장기 시각 탐색 능력 평가

한 줄 요약

여러 이미지와 검색 단계에 걸쳐 시각 정보를 연결·관리하는 능력("visual context management")을 평가하기 위해, 204개의 사람이 직접 작성한 장기(long-horizon) 시각 탐색 과제로 구성된 벤치마크 VisSearch-Bench를 제안한다.

배경 및 문제의식

기존 멀티모달 검색 벤치마크들은 이미지가 초기 개체(entity)를 식별하는 용도로만 쓰이고 이후에는 텍스트 검색에 의존하는 경우가 많아, 에이전트가 여러 이미지·객체·검색 단계에 걸쳐 시각 정보를 실제로 "어떻게" 연결하고 활용하는지는 제대로 평가하지 못했다. 저자들은 단순히 시각 정보가 한 번이라도 쓰였는지가 아니라, 검색이 진행되며 누적되는 시각적 증거를 에이전트가 신뢰성 있게 조직하고 재사용할 수 있는지를 핵심 질문으로 제기한다.

핵심 기여

  1. 오픈월드(open-web) 검색에서 "시각적 맥락 관리" 능력을 평가하는 과제 기반 관점을 제시.
  2. 7개 주요 도메인, 25개 하위 도메인에 걸친 204개의 사람 작성 과제로 구성된 VisSearch-Bench를 구축. Set-wise Visual Search, Sequential Visual Search, Hybrid Wide-Deep Search, Competitive Visual Disambiguation, Visual-Structure-Guided Search의 5개 과제군을 포함.
  3. 사람이 주도하고 자동 검증이 뒷받침하는 데이터 구축 프로세스를 개발하여, 각 과제에 근거 출처(evidence source), 정답, 채점 규칙을 부여. 전체 정답 일치도를 보는 Accuracy와 개별 하위 결과·답변의 정확성·완전성을 보는 Process Score를 함께 사용.

방법론

각 과제는 자연어 질문, (있을 수 있는) 초기 이미지 집합, 요구 출력 형식으로 구성되며, 에이전트는 텍스트 검색·이미지 검색·역이미지 검색·웹페이지 열람·이미지 크롭 등 5가지 도구를 사용해 다단계로 상호작용한다. 데이터 구축은 3단계 원칙(시각적 필수성, 시각-증거 통합, 공개적으로 검증 가능성)을 따르며, 출처 선정→근거 그래프 구조화→과제 설계→정답 고정(locked reference answer) 및 골드 경로 작성→결정론적 무결성 검사 및 LLM 기반 후처리·사람 재검토의 파이프라인을 거친다. 평가는 최종 답의 완전 일치 여부를 보는 Accuracy와, 과제별로 정의된 중간 상태(critical states)의 회수율을 측정하는 Process Score 두 지표를 사용한다.

실험 설정 및 결과

GLM-5.3-Flash, Kimi-K3, DeepSeek-V4.1-Flash, Qwen3 계열 등 오픈소스 모델과 GPT-5.5, Gemini 3.5 Flash, Claude Opus 4.8 등 폐쇄형 모델을 포함해 총 16개 모델을 Direct Answer(도구 미사용), ReAct 에이전트, DeerFlow 에이전트 설정으로 평가했다. Direct Answer에서는 모든 모델이 6.37% 이하의 정확도에 그쳤다. 검색 도구를 사용하는 ReAct+Kimi-K3가 26.47%로 가장 높은 정확도를, ReAct+GPT-5.5가 가장 높은 Process Score(49.52%)를 기록했으나, 최고 성능 시스템조차 과제의 약 1/4 정도만 완전히 해결했다. 도구 사용이 정확도와 Process Score를 모두 끌어올리지만 프레임워크(ReAct vs DeerFlow)의 우위는 모델마다 달랐고, Set-wise Visual Search처럼 다수 객체를 모두 다뤄야 하는 과제군에서는 정확도가 특히 낮게 나타났다. 추가로 이미지 설명(caption)만 제공하는 설정은 직접 이미지 검사(Full) 대비 성능이 떨어져, 세부 시각 정보 손실이 실질적 손해로 이어짐을 보였다.

한계점

저자들은 최고 성능 시스템도 과제의 26.47%만 완전히 해결하는 수준이며, 특히 Set-wise Visual Search와 같이 다수 후보를 모두 확인·종합해야 하는 과제에서 부분 정답과 완전한 과제 해결 사이에 뚜렷한 격차가 있음을 한계로 지적한다. 또한 더 많은 도구 호출이 반드시 더 높은 정확도로 이어지지는 않는다는 점, 모델별·프레임워크별 강점이 과제 유형에 따라 크게 달라진다는 점도 확인되었다. 그 외 세부 한계(예: 평가 비용, 언어 범위 등)는 논문에 명시되지 않음.

시사점

VisSearch-Bench는 멀티모달 에이전트가 단순 시각 인식을 넘어, 검색 전 과정에 걸쳐 시각적 증거를 조직·연결·종합하는 능력을 체계적으로 드러내는 진단 도구를 제공한다. 결과는 현재의 최상위 에이전트들도 여러 이미지와 객체를 아우르는 장기 시각 탐색에서 근본적 한계를 지니고 있음을 보여주며, 향후 연구가 시각적 맥락을 누적·활용하는 에이전트 설계(증거 상태 관리, 교차 이미지 비교, 후보 필터링 전략 등)에 집중해야 함을 시사한다.
