Learning Video Foresight Reasoning from Unlabeled Videos via On-Policy Self-Distillation

라벨 없는 비디오에서 온폴리시 자기증류로 비디오 예측추론 학습하기

한 줄 요약

비디오에서 미래를 예측하는 추론 능력을 라벨 없이 학습시키기 위해, 과거-미래 영상 쌍 자체를 자기지도 신호로 활용하는 온-폴리시 자기증류 프레임워크 Future-OPSD를 제안하고, 미래 클립 중 실제로 중요한 "콘텐츠 정보"만 선택적으로 학습하도록 설계했다.

배경 및 문제의식

비디오 기반 미래예측 추론(video foresight reasoning)은 자율주행, 로보틱스, 능동형 에고센트릭 어시스턴트 등에 필수적인 능력이다. 기존 VLM 기반 방법들은 두 가지 한계를 가진다. 첫째, 정답 주석이나 외부 대형 모델(LLM 평가자 등)에 의존해 학습 확장성이 떨어진다. 둘째, 미래 클립 전체를 동등하게 중요한 학습 대상으로 취급하지만, 실제로는 미래 영상의 대부분이 질문과 무관한 "맥락 정보"이고 일부만이 실제로 중요한 "콘텐츠 정보"다. 예를 들어 "다음에 무엇을 할 것인가"를 예측할 때, 수도꼭지나 설거지대 같은 주변 정보보다 "칼을 헹군다"는 행동 자체가 핵심 정보다.

핵심 기여

  1. 주석이나 외부 LLM 없이, 비디오 자체의 과거-미래 쌍만으로 자기지도 학습 신호를 만드는 최초의 온-폴리시 자기증류 프레임워크 Future-OPSD를 제안했다.
  2. 학생 모델의 응답이 실제 미래와 얼마나 일치하는지를 측정하는 "foresight score"를 정의하고, 이를 직접 최적화하기 어려운 문제를 다루기 위해 다루기 쉬운 하한(lower-bound) 대체 목적함수를 유도했다.
  3. 이 대체 목적함수는 대조적 특권 어드밴티지(contrastive privilege advantage)와 교사-학생 증류 어드밴티지를 보간하여, 공유된 맥락 정보는 억제하고 미래에 특화된 콘텐츠 정보는 증폭시킨다.

방법론

Future-OPSD는 각 비디오를 과거 클립과 미래 클립(짝지어진 미래)으로 나눈다. 학생 모델은 과거 클립만 보고 추론 및 답변을 생성하고, 초기 학생 모델의 복사본인 고정된 교사 모델은 과거와 짝지어진 미래를 모두 보고 학생의 응답을 토큰 단위로 채점한다. foresight score는 모든 가능한 미래에 대해 평균을 취해야 해서 직접 계산이 불가능하므로, 실제 짝지어진 미래와 무관한 참조 미래 각각에 대한 교사의 채점 차이(대조적 특권 어드밴티지)와 짝지어진 미래를 본 교사로의 증류 어드밴티지를 보간하는 다루기 쉬운 하한을 대신 최적화한다. 이 결합된 목적함수는 공유되는 맥락 정보를 억제하고 미래에 고유한 콘텐츠 정보를 증폭시키는 효과를 낸다.

실험 설정 및 결과

Qwen3-VL과 Qwen3.5를 기반 모델로 하여 개방형 예측(open-ended prediction)과 폐쇄형 계획(closed-ended planning)이라는 두 가지 비디오 미래예측 과업에서 평가했다. Future-OPSD는 기반 모델 대비 최대 14.2점(개방형 예측), 15.9점(폐쇄형 계획)의 성능 향상을 보였으며, foresight score를 최적화하지 않는 Naive OPSD 베이스라인을 일관되게 앞섰다. 이러한 향상은 과업 간에도 전이되었고, 일반적인 비디오 이해 능력을 손상시키지 않았다. 더 강한 교사 모델과 더 많은 데이터를 사용할수록 성능 향상이 더 커졌으며, 토큰 단위 분석을 통해 실제로 맥락 정보가 억제되고 콘텐츠 정보가 증폭됨을 확인했다.

한계점

연구에서 도출한 결론은 논문에서 다룬 데이터셋과 모델 범위 내로 한정된다고 저자들은 명시한다. 그 외의 세부적인 한계는 논문에 명시되지 않음.

시사점

정답 주석이나 외부 대형 모델 없이도 비디오 자체의 시간적 구조(과거-미래 쌍)를 자기지도 학습 신호로 활용할 수 있다는 점에서, 데이터 주석 비용 없이 확장 가능한 미래예측 추론 학습 패러다임을 제시한다. 또한 미래 정보 중 "중요한 것"과 "무관한 것"을 구분해 학습하는 설계는, 월드 모델이나 에이전트의 계획 수립 능력을 향상시키는 데도 응용될 수 있음을 시사한다.
