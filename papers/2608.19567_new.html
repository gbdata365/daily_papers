Block3D: Efficient Text-to-3D Generation via Block-Wise Diffusion

블록3D: 블록 단위 확산을 통한 효율적인 텍스트-3D 생성

Block3D는 이산 3D 형상 토큰 시퀀스를 블록 단위로 나누어 블록 간에는 자기회귀적으로, 블록 내부에서는 병렬 확산 방식으로 생성함으로써, 기존 Cube 모델 대비 기하학적 품질을 유지하거나 개선하면서 생성 속도를 5.15배 향상시킨 텍스트-3D 생성 프레임워크이다.

한 줄 요약

Block3D는 이산 3D 형상 토큰 시퀀스를 블록 단위로 나누어 블록 간에는 자기회귀적으로, 블록 내부에서는 병렬 확산 방식으로 생성함으로써, 기존 Cube 모델 대비 기하학적 품질을 유지하거나 개선하면서 생성 속도를 5.15배 향상시킨 텍스트-3D 생성 프레임워크이다.

배경 및 문제의식

텍스트로부터 고품질 3D 에셋을 생성하는 기술은 게임, 영화, VR/AR, 로보틱스 등에서 수요가 커지고 있지만, 높은 기하학적 충실도와 낮은 추론 비용을 동시에 달성하기 어렵다는 문제가 있다. 기존 접근은 크게 두 갈래로 나뉜다. 첫째, 이산 형상 토큰을 자기회귀적으로 하나씩 순차 디코딩하는 방식(예: Cube, MeshGPT 계열)은 한 번 생성된 토큰을 되돌릴 수 없어 오류가 누적되며, 시퀀스가 길어질수록 지연 시간이 커진다. 둘째, 확산(diffusion)이나 흐름 매칭(flow matching) 기반 방식(예: TRELLIS, Hunyuan3D 2.0, Pandora3D)은 전체 잠재 표현을 반복적으로 정제해야 하므로, 세밀한 형상을 표현할수록 반복 정제 비용이 증가한다. 즉 자기회귀 방식은 오류 수정이 불가능하고, 확산 방식은 전체 시퀀스를 매번 다시 처리해야 하는 근본적 한계가 있다.

핵심 기여

  • 이산 형상 토큰 시퀀스를 인접한 블록들로 분할하여, 블록 간에는 좌에서 우로 인과적(causal)으로 생성하되 블록 내부에서는 양방향 어텐션으로 모든 토큰을 동시에 디노이징하는 Block3D 프레임워크를 제안. Cube의 토큰 단위 자기회귀 의존성을 블록 단위로 전환한 것이 핵심 아이디어.
  • 블록이 확정(freeze)되기 전에 신뢰도가 낮은 토큰을 다시 교정하는 confidence-guided intra-block correction(마스크 채우기 M2T + 토큰 교체 T2T)을 도입하여 블록 내 오류 누적을 완화.
  • 100개 held-out 객체 실험에서 Block3D가 평가된 방법들 중 가장 우수한 기하 지표를 달성하면서, Cube 파인튜닝 베이스라인 대비 평균 종단 간 생성 시간을 25.71초에서 4.99초로 줄여 5.15배 가속을 입증.

방법론

Block3D는 Cube의 동결된 VQ 오토인코더(코드북 크기 V=16384, 메시당 N=1024개 이산 코드)와 CLIP ViT-L/14 텍스트 인코더를 그대로 사용하고, Cube의 23층 DualStream RoFormer 생성기만 파인튜닝한다. 방법은 세 요소로 구성된다.

  1. 조건부 블록-인과적 디노이징(Block-Causal Denoising): N개의 코드 위치를 K=⌈N/B⌉개의 연속 블록으로 나눈다. 블록은 Block Diffusion의 스케줄을 따라 좌에서 우로 순차 생성되며, 각 블록 생성 시 조건과 이미 확정된 이전 블록(프리픽스)에 대해서는 어텐션하고, 현재 활성 블록 내부의 모든 위치는 양방향으로 동시에 예측한다. 학습 시에는 깨끗한 시퀀스와 손상된 시퀀스를 함께 하나의 순전파로 처리하는 벡터화된 어텐션 마스크 구조를 사용한다.
  2. 편집 인지 학습(Edit-Aware Training): 각 학습 샘플·블록에 대해 마스킹(M2T) 또는 무작위 토큰 치환(T2T) 중 하나의 손상 방식을 샘플링하고, 그래디언트 없는 1회의 모델 기반 롤아웃(rollout)을 수행한 뒤, 롤아웃 결과와 정답이 다른 잔차(residual) 위치에 대해서만 손실을 계산한다.
  3. 경계가 있는 신뢰도 기반 디코딩(Bounded Confidence-Guided Decoding): classifier-free guidance(CFG)로 얻은 가이드 로짓에서 후보 토큰을 제안하고, 조건부 로짓의 신뢰도 점수로 수용 여부를 판단한다. M2T는 신뢰도 임계값(ηM)을 넘거나 top-k에 해당하는 마스크 위치를 채우고, T2T는 이미 채워진 토큰 중 신뢰도(ηT)를 넘는 다른 후보로 교체한다. 매 반복(iteration)마다 결정론적 최소 공개 할당량(quota)을 두어 최대 T번 반복 내에 블록이 반드시 완성되도록 보장한다. 기본 설정은 블록 크기 B=64, 반복 수 T=4, (ηM, ηT)=(0.95, 0.9), 가이던스 계수 g=3.0이며 K=16개 블록이 생성된다.

실험 설정 및 결과

TRELLIS-500K에서 30만 개 객체로 생성기를 파인튜닝하고, 시드 42로 무작위 선정한(파인튜닝 풀에서 제외한) 100개 객체로 평가했다. 비교 대상은 ShapeLLM-Omni, TRELLIS-text, AR3D-R1, Cube이며, 특히 Cube는 동일 체크포인트·동일 학습 조건의 통제된 비교 대상이다. 평가 지표는 Chamfer-L1(CD-L1), Normal Consistency(NC), F-score@1%, 8-view CLIPScore, 그리고 A100 GPU 기준 종단 간 생성 시간이다.

주요 결과로, Block3D는 CD-L1 0.078, NC 0.668, F@1% 0.309로 비교 방법들 중 최고 기하 지표를 기록했으며 CLIPScore(23.24)도 경쟁력 있는 수준을 유지했다. 생성 시간은 평균 4.99초(중앙값 4.96초)로, Cube의 25.71초 대비 5.15배 빨랐고 P90·표준편차 등 모든 지연 통계에서 가장 우수했다. 어블레이션에서는 블록 크기가 커질수록(B=64→256) 속도는 빨라지지만 F@1%가 크게 떨어져(0.309→0.103) B=64가 품질-속도 균형점으로 선택되었고, 디노이징 반복 수는 T=4 이상 늘려도 품질 향상이 단조적이지 않아 T=4가 채택되었다. 또한 T2T 편집을 추가하면 M2T 단독 대비 CD-L1이 4.7% 감소하고 F@1%와 CLIPScore가 모두 향상되어, 토큰 교정이 마스크 채우기만으로는 해결 못 하는 오류를 보완함을 확인했다.

한계점

논문은 Block3D가 Cube의 1차원 코드 순서를 그대로 따르고 확정된 프리픽스 블록을 다시 열지 못하므로, 블록 내부 오류만 교정할 뿐 의미론적 부품 구조나 블록 간(cross-block) 노출 편향(exposure bias)은 해결하지 못한다고 명시한다. 또한 학습 시에는 양방향·teacher-forced 프리픽스를 사용하지만 추론 시에는 토큰-인과적·모델 생성 프리픽스를 사용하는 학습-추론 불일치가 존재하며, 캐싱은 계산량만 줄일 뿐 이 불일치나 노출 편향 자체를 제거하지는 않는다고 밝히고 있다. 향후 연구로 블록 간 정제(cross-block refinement)와 더 다양한 형상 표현·데이터셋으로의 확장을 언급했다.

시사점

Block3D는 자기회귀 방식의 순차적 비가역성과 확산 방식의 전체 시퀀스 반복 정제라는 두 패러다임의 단점을 절충하여, 언어 모델링 분야의 Block Diffusion과 LLaDA2.1의 편집 메커니즘을 3D 형상 생성에 성공적으로 이식한 사례다. 기존에 동결된 VQ 토크나이저·디코더를 그대로 활용하면서 생성기만 교체·파인튜닝하는 방식은 다른 사전학습된 3D 생성 파이프라인에도 비교적 적은 비용으로 적용 가능한 일반적인 가속 전략을 제시한다. 다만 블록 내 교정에 국한된 설계이므로, 블록 간 오류를 되돌릴 수 있는 후속 메커니즘이나 의미론적 구조를 고려한 블록 분할이 추가되면 품질을 더 개선할 여지가 있다는 점에서, 실시간·저지연 3D 콘텐츠 생성이 필요한 실무 응용(게임 에셋 제작, 인터랙티브 디자인 툴 등)에 특히 시사하는 바가 크다.
