AesCode: Aesthetic Code Generation with Decoupled Cross-Modal Rewards

에스코드: 분리형 교차모달 보상을 통한 심미적 코드 생성

한 줄 요약

슬라이드·포스터·대시보드 같은 정보 밀도가 높은 시각 결과물을 HTML/CSS 코드로 생성할 때, 동일 프롬프트로 만든 참조 이미지를 "미적 가이드"로 활용하고 이를 그래프 구조로 분해해 검증 가능한 보상과 시각적 보상을 분리 학습시킴으로써, 콘텐츠 정확성과 디자인 품질을 동시에 끌어올리는 코드 생성 모델 AesCode를 제안한다.

배경 및 문제의식

코드로 시각 산출물을 생성하면 구조적이고 편집·검증이 가능하다는 장점이 있지만, 코드 모델은 자신이 작성한 레이아웃과 색상이 캔버스에서 실제로 어떻게 보이는지 "볼" 수 없어 공간 배치나 미적 품질이 떨어지는 경향이 있다. 반대로 이미지 생성 모델은 시각적으로는 뛰어나지만 텍스트·숫자·논리적 관계를 잘못 렌더링하는 경우가 많아 그대로 결과물로 쓰기 어렵고 편집도 불가능하다. 기존의 이미지-투-코드 방법들은 참조 이미지를 절대적 정답(ground truth)으로 취급해 픽셀 단위 복제를 강요하는데, 이는 참조 이미지에 포함된 환각(hallucination)이나 오류까지 그대로 베끼게 만들고 유효한 디자인 변형을 오히려 페널티로 처리하는 한계가 있다.

핵심 기여

  • 동일 프롬프트로 생성한 참조 이미지를 코드 모델의 입력 조건이자 학습 시 시각적 신호 공급원으로 사용하는 새로운 패러다임 제시
  • 생성 목표를 "Design Graph"(디자인 그래프)로 구조화하여, 코드/DOM에서 파싱 가능한 속성은 결정론적 검증기로, 파싱 불가능한 속성(미적 요소 등)은 그래프에 결부된 Visual Graph Rubric(VGR)을 활용하는 VLM 심사로 각각 분리해 평가하는 cross-modal(교차 모달) 보상 체계 설계
  • 검증 정확성과 시각 품질을 별도로 측정하고 사람 평가와 높은 일치를 보이는 인포그래픽 벤치마크(300개 평가셋) 공개

방법론

AesCode는 프롬프트 p와 참조 이미지 I_ref로부터 "Design Graph" G_tgt를 구성한다. 이 그래프는 캔버스 전체를 루트 노드로 하고, 텍스트·이미지·차트·표 등 요소를 노드로, 컨테이너(영역·카드·패널·리스트 등)를 포함 관계로, 정렬·순서·인접·의미적 연결 등을 엣지로 표현한다. 생성된 코드와 렌더링 결과에서도 동일한 방식으로 그래프를 파싱해 목표 그래프와 속성별로 비교한다.

보상은 두 갈래로 나뉜다. 첫째, 여섯 종류의 결정론적 검증기(실행 가능성, 필수 텍스트, 캔버스 경계, 표/차트 구조, 의미적 레이아웃, 여백 분포)가 코드·DOM·OCR·렌더링 픽셀에서 점수를 산출한다. 둘째, 그래프의 노드·속성·관계에 결부된 샘플별 이진 질문 목록(Visual Graph Rubric, VGR)을 만들어 VLM이 각 질문에 Yes/No로 답하게 하고 통과율을 시각 보상으로 사용한다. 이렇게 7개 채널의 보상을 Group reward-Decoupled Normalization Policy Optimization(GDPO)로 채널별로 정규화한 뒤 합산함으로써, 조밀하고 쉽게 포화되는 규칙 기반 보상이 희소한 미적 보상 신호를 압도하는 문제를 방지한다. 학습은 사람이 디자인한 약 1.8만 개의 슬라이드·포스터·대시보드·웹페이지 데이터를 활용한 콜드스타트 SFT(3,000개 샘플) 후, GPT-Image-2로 생성한 합성 참조 이미지를 이용한 RL(GDPO) 단계로 진행된다.

실험 설정 및 결과

8B 및 32B 규모의 Qwen3-VL을 백본으로 하여 AesCode-8B, AesCode-32B를 학습시키고, 300개 프롬프트로 구성된 자체 인포그래픽 벤치마크에서 GPT-5.5, GPT-5.4, GPT-5.1, GPT-4o, Claude Opus 4.8, Gemini 3.1 Pro 등 폐쇄형 모델 및 다수의 오픈소스 VLM과 비교했다. 참조 이미지를 입력으로 제공했을 때, 동일 백본(Qwen3-VL) 대비 AesCode-8B는 Visual 점수를 31.1점, AesCode-32B는 22.4점 끌어올려 GPT-5.5·Claude Opus 4.8 등 프런티어 모델과 비슷한 수준의 시각 품질에 도달했으며, 표/차트 등 검증 가능한 정확성에서는 오히려 이들을 능가했다(32B 모델 Table/Chart 점수 90.37). Design2Code, SlidesBench, GDB/lica 등 외부 벤치마크로의 전이 평가에서도 AesCode-32B는 백본 대비 14개 지표 전부에서 성능이 향상되었다. 블라인드 인간 평가에서는 학습용 VGR 및 평가용 체크리스트가 사람 다수결 판단과 각각 89.3%, 93.3% 일치했고, AesCode-32B는 GPT-5.5 대비 콘텐츠 충족도가 더 높으면서 미적 품질은 동등한 수준으로 확인됐다. 소거 실험에서는 참조 이미지가 학습뿐 아니라 추론 시 입력으로도 주어질 때 가장 효과가 크며, 그래프 기반 VGR이 전체 질문을 직접 작성하거나 단일 홀리스틱 VLM 점수, CLIP 유사도를 사용하는 것보다 더 우수함을 보였다.

한계점

학습 과정이 최종 픽셀 단위 기하 구조를 완벽히 예측하지 못해 드물게 캔버스 오버플로우(내용이 캔버스 밖으로 넘침)가 남아 있다. 또한 여러 요소 간의 관계 구조(예: 다수의 연결선)를 하나의 패턴으로 뭉뚱그려 단순화하는 등 관계 수준의 희소한 보상으로는 복잡한 구조적 관계를 완전히 포착하기 어렵다. 세밀한 SVG 아이콘처럼 그래프 수준에서 표현되지 않는 정교한 시각적 요소는 일반적인 도형으로 뭉개지는 경향(semantic element degradation)도 관찰되었다. 아울러 Style(완성도) 지표는 모든 비교 모델에서 60% 미만으로 공통적인 병목으로 남아 있다.

시사점

이미지 생성 모델이 단순히 최종 결과물을 만드는 용도를 넘어, 구조화된 코드 생성 모델에게 확장 가능한 "시각 디자인 교사" 역할을 할 수 있음을 보여준다. 프롬프트의 콘텐츠 요구사항과 참조 이미지의 시각적 단서를 그래프로 분리해 다루는 접근은, 참조 이미지의 오류나 환각을 그대로 답습하지 않으면서도 레이아웃·스타일 정보만 선택적으로 흡수하도록 학습시키는 일반적인 방법론으로서, 슬라이드·대시보드·웹페이지 등 다양한 구조적 시각 산출물 생성 작업에 폭넓게 적용될 수 있다.
