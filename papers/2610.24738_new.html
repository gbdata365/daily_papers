Editing Images into Reusable Layers via Compositional Edit-Prior Distillation

레이어에디터: 편집-우선순위 증류로 재사용 가능한 RGBA 레이어 생성하기

한 줄 요약

명령 기반 이미지 편집과 재사용 가능한 RGBA 레이어 생성을 하나의 통합 모델로 결합해, 편집된 캔버스와 순서가 있는 레이어 스택을 동시에 생성하면서도 사전학습된 편집 모델의 품질을 유지하는 LayerEditor를 제안한 연구.

배경 및 문제의식

기존 명령 기반 이미지 편집 모델(InstructPix2Pix, Qwen-Image 등)은 텍스트와 이미지를 하나로 융합한 "평면화된(flattened)" 결과만 생성하기 때문에, 세부 요소를 정밀하게 조작하거나 레이어를 재사용하기 어렵고, 후속 수정이 필요할 때마다 전체를 다시 생성해야 해 처리 비용이 크고 의도치 않은 변경이나 경계 아티팩트가 발생할 위험이 있다. 한편 이미지 분해(decomposition) 방법은 레이어를 복원할 수는 있지만 편집과는 별도의 단계로 최적화되기 때문에, 시각적으로는 그럴듯해도 레이어 구조가 불완전하거나 재사용하기 어려운 결과를 낳는다. 즉 편집과 레이어 분해가 서로 다른 목표로 분리 최적화되어 온 문제를, LayerEditor는 하나의 통합된 형식으로 해결하고자 한다.

핵심 기여

  • In-Context RGB-Alpha Token Modeling: 편집된 캔버스와 순서가 있는 RGB-Alpha 레이어 시퀀스를 하나의 토큰 시퀀스 안에서 공동 표현하여, 레이어 수를 가변적으로 지원하면서도 레이어 간 의존성과 투명도 상호작용을 포착
  • Compositional Edit-Prior Distillation (C-EPD): 동결된 사전학습 편집 모델을 온폴리시 교사로 사용해, 직접 편집 결과와 예측된 레이어들의 합성 결과 양쪽 모두에 편집 사전지식(prior)을 전이시켜, 레이어화 과정에서 발생하는 편집 품질 저하를 완화
  • LayerEditor-100K: 2~10개의 가변적 레이어 수를 가진 10만 건 규모의 명령 기반 레이어 편집 데이터셋 구축 및 Crello-Testset, ScaleEdit-Testset 두 개의 전용 평가 벤치마크 제안
  • 별도로 학습된 전용 Alpha 디코더를 도입해 미세 구조와 반투명 경계의 연속적인 불투명도를 복원

방법론

소스 이미지, 편집 명령, 요청 레이어 수(N)가 주어지면, LayerEditor는 사전학습된 멀티모달 확산 트랜스포머(MMDiT, FireRed-Image-Edit-1.1 기반)를 In-Context RGB-Alpha 토큰 모델링으로 확장해 편집 캔버스(Direct)와 N개의 RGBA 레이어(Layer stack)를 공동 노이즈 제거(denoising)한다. 레이어-인식 회전 좌표를 도입해 소스 토큰, 편집 캔버스, 각 레이어의 RGB/Alpha 필드가 동일한 공간 좌표를 공유하면서도 슬롯 좌표로 필드 정체성과 스택 순서를 구분한다.

레이어화된 출력으로의 적응이 원래의 편집 능력을 약화시키는 문제(텍스트 손상, 구조 왜곡 등)를 막기 위해 C-EPD를 제안한다. 학생 모델의 디노이징 궤적에서 추출한 중간 노이즈 상태를 동결된 교사 모델에 질의해, 교사가 예측한 속도(velocity)로 Direct 출력을 정렬시키는 동시에, 학생이 예측한 레이어들을 배경부터 앞쪽 순서로 알파-오버 합성한 결과(Composite)가 교사가 디코딩한 타깃과 일치하도록 유도한다. 학습은 LoRA(rank-256)를 사용해 2 에폭의 흐름매칭(flow-matching) 워밍업 후 C-EPD를 결합한 공동 최적화로 진행되며, 전체 손실은 흐름매칭 손실과 C-EPD 손실(λ_C로 가중)의 결합으로 구성된다.

LayerEditor-100K는 Crello·PrismLayersPro의 네이티브 레이어드 디자인(Route A)과 ScaleEdit의 평면화된 편집쌍에서 레이어 구조를 복원한 데이터(Route B)를 결합해 구축되었으며, 텍스트 편집 48,329건, 객체 편집 36,858건, 포스터 수준 외형 편집 14,813건으로 구성된다.

실험 설정 및 결과

Crello-Testset(2,994건)과 ScaleEdit-Testset(1,000건) 두 벤치마크에서 Seedream5-Pro, FireRed-Image-Edit + Qwen-Image-Layered(QIL) 조합, QIL-Control, QIL-Edit-SFT, RevealLayer 등과 비교했다. LayerEditor는 두 벤치마크 모두에서 최고 수준의 Composite SSIM/FID와 Alpha IoU를 달성했으며, Seedream5-Pro(Joint) 대비 Crello-Testset에서 Composite SSIM을 5.7% 개선하고 FID를 38.8% 낮췄다. 루브릭 기반 5개 차원(편집 일관성, 시각 품질, 레이어 분할, 레이어 합성, 알파 정확도) 평가에서도 Crello-Testset 평균 6.00점으로 최고 베이스라인(Seedream5-Pro Joint, 4.50점)을 크게 상회했다.

레이어 수 제어(layer-count controllability) 실험에서는 동일한 편집 내용을 다른 레이어 세분화 수준으로 재구성하는 능력을 평가했는데, LayerEditor가 Alpha IoU 및 의미적 그룹화 루브릭 점수에서 최고 성능(Seedream5-Pro Joint 대비 Alpha IoU +0.0493, 의미 그룹화 +0.97점)을 보였다. 또한 레이어 내용을 프롬프트로 명시적으로 지정하는 실험에서도 요청된 시각적 내용을 올바른 레이어에 정확히 배정하는 능력을 확인했다. 순수 이미지-레이어 분해(I2L) 과제에서도 레이어화 전용 미세조정 없이 QIL, LayerD 등 기존 분해 전용 베이스라인을 능가하는 Composite SSIM(0.8761)과 Alpha IoU(0.6343)를 기록했다. 절삭 연구(ablation)에서는 C-EPD를 제거할 경우 편집 일관성이 6.14→4.67, 레이어 분할이 6.83→5.01로 크게 떨어져, C-EPD의 두 구성 요소(Direct OPD, Composition OPD)가 모두 성능에 필수적임을 확인했다.

한계점

논문에 별도의 한계점 섹션은 명시되어 있지 않다. 다만 본문 내용으로 미루어 볼 때, 비교 대상인 Seedream5-Pro가 일부 Crello-Testset 문서(5건)에서 플랫폼 제약(저작권 관련 거부 등)으로 사용 가능한 출력을 생성하지 못해 해당 문서를 집계에서 제외해야 했다는 점, 그리고 레이어화 적응이 기본적으로 원 편집 품질을 저하시키는 경향이 있어 C-EPD와 같은 별도의 증류 기법 없이는 성능 저하가 발생한다는 점이 간접적인 한계로 지적된다.

시사점

LayerEditor는 명령 기반 이미지 편집과 레이어 분해를 하나의 생성 과정으로 통합함으로써, 전자상거래 콘텐츠 제작이나 광고 디자인처럼 편집 후에도 개별 요소(텍스트, 배경, 객체 등)를 독립적으로 재조정해야 하는 실무 워크플로우에 바로 적용 가능한 "재사용 가능한 편집" 패러다임을 제시한다. 온폴리시 증류를 통해 사전학습 모델의 생성 능력을 유지하면서 출력 구조를 확장하는 C-EPD 방식은, 레이어·다중 뷰 등 유사하게 구조화된 출력으로 확장해야 하는 다른 생성 모델 적응 문제에도 일반화될 수 있는 접근법으로 보인다.
