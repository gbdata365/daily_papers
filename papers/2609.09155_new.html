SyncWorld: Visual Calibration Enables World Models as Zero-Shot Simulators

싱크월드: 시각적 보정을 통한 세계 모델의 제로샷 시뮬레이터화

SyncWorld는 짧은 '시각 보정(visual calibration)' 에피소드를 문맥(in-context)으로 제공함으로써, 추가 학습 없이도 처음 보는 카메라 시점과 로봇 embodiment에서 행동-시각 매핑을 추론해 정확한 미래 영상을 생성하는 제로샷 로봇 세계 모델이다.

한 줄 요약

SyncWorld는 짧은 '시각 보정(visual calibration)' 에피소드를 문맥(in-context)으로 제공함으로써, 추가 학습 없이도 처음 보는 카메라 시점과 로봇 embodiment에서 행동-시각 매핑을 추론해 정확한 미래 영상을 생성하는 제로샷 로봇 세계 모델이다.

배경 및 문제의식

행동 조건부 세계 모델은 정책 평가와 계획을 위한 '상상 환경(imagination environment)'으로 널리 쓰이지만, 동일한 수치적 행동 값이라도 카메라 배치, 로봇 베이스 위치, embodiment(로봇 종류)에 따라 픽셀 공간에서 전혀 다른 시각적 결과로 나타난다는 근본적 문제가 있다. 이 때문에 여러 설정(setup)의 데이터를 혼합해 학습하면 하나의 모델이 서로 모순되는 행동-시각 매핑을 동시에 맞춰야 하는 '충돌하는 지도학습(conflicting supervision)' 문제가 생기고, 새로운 환경에 배포할 때는 추가 학습 없이는 행동-시각 매핑이 깨지는 '비적응적 테스트 시점 매핑' 문제가 발생한다.

핵심 기여

  • 행동-시각 매핑(Action-Visual Mapping)을 시각 도메인에서 문맥 내(in-context) 보정 가능한 잠재적 관계로 취급하여, 짧은 보정 상호작용 에피소드(6개 자유도 각각의 방향성 동작을 담은 페어링된 프레임·행동 시퀀스)를 조건으로 제공하는 SyncWorld 프레임워크 제안
  • 학습 중 다양한 소스의 궤적에 보정 문맥을 체계적으로 주입하여, 명시적 보정이 없을 때도 상호작용 히스토리만으로 설정별 매핑을 근사하도록 하는 '보정 증류(calibration distillation)' 기법
  • GPC-Rank 테스트 시점 스케일링 프레임워크와 결합하여, 세계 모델의 상상된 롤아웃으로 후보 행동을 평가·선택함으로써 추가 학습 없이 새로운 환경에서 정책 성능을 개선

방법론

SyncWorld는 Diffusion Transformer(DiT, Wan2.2-TI2V-5B 백본 기반) 구조 위에 자세(pose) 조건화 모듈을 추가한 행동 조건부 세계 모델이다. 각 설정 s마다 고정 카메라로 촬영한 보정 에피소드 Es를 수집하며, 각 자유도(x, y, z 이동과 yaw, pitch, roll 회전)에 대해 +/− 방향 동작을 수행한 뒤 원위치로 복귀하는 과정에서 12개의 짧은 보정 세그먼트(Cs)를 추출해 고정된 표준 순서로 문맥 접두사로 연결한다. 학습 시에는 (1) 행동 좌표 증강(부호 반전, 축 순열, 스케일 변화)을 적용하여 모델이 고정된 좌표 관례에 의존하지 않고 Cs로부터 실제 의미를 추론하도록 강제하고, (2) 보정을 포함한 '교사' 입력과 보정을 제외한 '학생' 입력을 함께 학습시켜 학생이 히스토리만으로도 교사의 예측을 근사하도록 하는 보정 증류를 수행한다. 테스트 시점에서는 GPC-Rank 방식으로 정책이 생성한 여러 후보 행동 청크(chunk) 각각에 대해 SyncWorld로 미래 영상을 상상한 뒤, VLM(GPT-5)이 각 상상 결과를 지시문 기준으로 채점하여 최고 점수의 행동을 실행한다.

실험 설정 및 결과

  • RLBench, RoboCasa, RoboMimic 시뮬레이션 데이터와 실세계 DROID 데이터로 학습, 4×8 H100 GPU에서 2~3일간 학습
  • 평가는 학습 시 보지 못한 ManiSkill, LIBERO(동일 Franka Panda embodiment이나 새로운 환경/시점)와 처음 보는 로봇팔(xArm)을 사용한 실세계 롤아웃으로 수행
  • 영상 품질 비교(PSNR, SSIM, LPIPS, FID)에서 IRASim, WorldGym, Ctrl-World 등 기존 베이스라인 대비 SyncWorld가 모든 도메인·지표에서 큰 격차로 우수했으며, 보정 없이도(SyncWorld w/o Calib) 베이스라인을 능가
  • 다중 시점 3D 일관성 지표(Met3r)에서도 SyncWorld가 최고 성능을 보였고 실제 정답(oracle) 성능에 근접
  • LIBERO 하위 과제에서 GPC-Rank와 결합한 제로샷 정책 개선 실험 결과, SyncWorld 기반 순위화가 직접 정책 대비 성공률을 높였고(예: Orange Juice 과제 0.56→0.72) 오라클 시뮬레이터 상한에 근접
  • 소거 실험에서 보정 제거 시 전 도메인에서 성능이 크게 저하되었고, 증류 제거 시 특히 보정이 없는 테스트 시점에서 성능이 크게 하락하여 두 설계 요소의 상호보완적 역할을 확인

한계점

논문 본문에는 별도의 명시적 '한계점' 절은 없으나, 실험 결과에서 SyncWorld의 성능이 실제 오라클(ground-truth 시뮬레이터) 상한에는 근접하되 완전히 도달하지는 못함을 확인할 수 있다. 또한 정책 개선 실험은 오라클 순위화가 유의미한 향상 여력(headroom)을 보이는 진단적 과제 부분집합에 국한되어 있으며, VLM 기반 채점(GPC-Rank)의 순위화 성능 자체에 병목이 있을 수 있음을 언급한다. 학습 데이터는 대부분 시뮬레이션에서 생성되며, 실세계 DROID 데이터는 보정 에피소드를 제공하지 않아 보정 지도학습의 주요 원천은 시뮬레이션에 한정된다.

시사점

SyncWorld는 이질적인 로봇 데이터(서로 다른 카메라·embodiment·컨트롤러 규약)를 하나의 세계 모델로 통합 학습할 수 있는 실용적 경로를 제시하며, 시각적 문맥 내 보정이라는 아이디어는 별도의 외부 파라미터(카메라 외부 변수 등) 추정이나 파인튜닝 없이도 새로운 로봇 설정에 신속히 적응할 수 있음을 보여준다. 이는 세계 모델을 실제 정책 개선을 위한 제로샷 시뮬레이터로 활용할 수 있는 가능성을 제시하며, 향후 이질적 로봇 데이터의 대규모 확장 학습과 배포 시 적응 전략에 중요한 실마리를 제공한다.
