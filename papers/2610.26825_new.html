MemT-1.0: Towards Memory-Native Evolution

MemT-1.0: 메모리 네이티브 진화를 향하여

MemT-1.0은 메모리를 모델의 연산 과정 자체에 내재화한 "메모리 기반모델(memory foundation model)" 아키텍처로, 토큰 단위의 안정적인 메모리 갱신 메커니즘(Gated DeltaNet-2 기반)과 메모리 용량을 확장하는 Mixture-of-Storage 기법을 통해, 전체 문맥을 유지하지 않고도 파라메트릭 메모리 방식 중 최고 수준의 성능과 큰 폭의 추론 속도·저장공간 이점을 동시에 달성한다.

한 줄 요약

MemT-1.0은 메모리를 모델의 연산 과정 자체에 내재화한 "메모리 기반모델(memory foundation model)" 아키텍처로, 토큰 단위의 안정적인 메모리 갱신 메커니즘(Gated DeltaNet-2 기반)과 메모리 용량을 확장하는 Mixture-of-Storage 기법을 통해, 전체 문맥을 유지하지 않고도 파라메트릭 메모리 방식 중 최고 수준의 성능과 큰 폭의 추론 속도·저장공간 이점을 동시에 달성한다.

배경 및 문제의식

최근 추론(reasoning), 멀티모달리티처럼 외부 시스템의 기능이 점차 모델 자체에 내재화되는 추세 속에서, 저자들은 "메모리" 역시 모델이 장기간의 상호작용에서 경험을 축적하고 활용할 수 있도록 내재화되어야 할 핵심 능력이라고 본다. 저자들의 이전 연구인 Metis가 메모리를 기반모델의 네이티브 능력으로 처음 도입했으나, 토큰 선택(token selection) 방식의 갱신 메커니즘은 안정성 측면에서 한계가 있었다. MemT-1.0은 이를 개선하여 메모리-네이티브 진화(memory-native evolution)로 나아가는 실질적 한 걸음을 제시하고자 한다.

핵심 기여

  • Metis 대비 대폭 개선된 아키텍처인 MemT-1.0을 제안하며, GDN-2 기반의 안정적인 토큰 단위 메모리 갱신 메커니즘과 메모리 용량 확장을 위한 Mixture-of-Storage(MoS)를 도입했다.
  • 신중한 백본 준비(backbone preparation) 이후 지속 사전학습(CPT)과 후속학습(post-training)으로 구성된 2단계 학습 파이프라인을 설계하고, 340억 토큰 규모의 학습 데이터와 효율적인 학습·추론 인프라를 구축했다.
  • 메모리 능력의 스케일링 거동(학습량 및 메모리 용량에 따른 변화)을 분석했다.
  • MemT-1.0-Nano(360억 파라미터, 30억 활성화, 1,000만 동적 메모리)와 MemT-1.0-Flash(2,880억 파라미터, 170억 활성화, 3.36억 동적 메모리) 두 모델을 공개하고, 메모리·일반 능력을 종합 평가했다.
  • 에이전틱 코딩 과제에서 검색된 절차적 경험(procedural experience)을 네이티브 메모리에 내재화하여 과제 성공률을 높이는 응용을 시연했다.

방법론

MemT-1.0은 선택된 트랜스포머 블록마다 "네이티브 메모리 블록"을 병렬로 추가하는 구조다. 원본 어텐션 출력에 메모리 어텐션 출력을 더해 결합하며, 백본의 Pre-Attention/Attention/Post-Attention 연산은 그대로 유지해 백본 고유 능력을 보존한다. 메모리 블록은 (1) 상호작용 중 온라인 정보를 저장하는 동적 "로컬 메모리"와 (2) 메모리 저장·활용 능력 자체를 데이터 기반으로 학습하는 "하이퍼 메모리"로 구성된다.

메모리 저장 절차는 GDN-2(Gated DeltaNet-2)를 기반으로 한 "안정적 토큰 단위 갱신" 메커니즘을 사용하여, 매 턴이 끝날 때 지우기 게이트(erase), 쓰기 게이트(write), 망각 게이트(forget)를 통해 메모리 상태를 점진적으로 갱신한다. 메모리 활용 절차는 현재 은닉 상태로부터 쿼리를 생성해 메모리 상태를 읽어내고(RMSNorm을 적용한 행렬 읽기), 게이트(SoftCapSiLU)로 조절된 출력을 어텐션에 결합한다.

메모리 용량을 확장하기 위해 Mixture-of-Storage(MoS)를 제안한다. 이는 기존의 희소(sparse) MoE와 달리 모든 메모리 전문가(expert)가 조밀(dense)하게 참여하는 라우팅 방식으로, 저장용·활용용 두 개의 라우터가 공유된 전문가 주소(expert address) 행렬을 바탕으로 각 전문가에 대한 읽기·쓰기 비중을 결정한다.

학습은 2단계로 이루어진다. 먼저 백본 준비 단계에서, 메모리 부착 전 DeepSeek-V4-Flash를 세 가지 트랙(일반 능력, 에이전틱 코딩, 에이전틱 작업)에 걸쳐 후속학습하여 신뢰성을 높인다. 이후 지속 사전학습(CPT)에서는 세그먼트 단위로 분할된 시퀀스에 대해 이전 세그먼트 정보를 네이티브 메모리로만 접근하게 하며 언어모델링 능력을 학습시키고, 후속학습(post-training)에서는 전체 문맥에 접근 가능한 "교사(teacher)" 백본의 분포를 KL 발산 기반으로 증류(off-policy distillation)하여 메모리 학생 모델이 전체 문맥 없이도 교사와 유사한 응답을 생성하도록 학습한다. 분산 학습 인프라는 메모리 상태 갱신의 순서를 보존하면서도 트랜스포머 계산을 배치로 처리할 수 있도록 설계되었고, 청크 단위 WY 분해와 "완전한 스텝 단위 윈도우" 기법으로 MoS의 활성화 메모리 사용량을 크게 절감했다.

실험 설정 및 결과

메모리 능력은 궤적 길이에 따라 네 그룹으로 나뉜 11개 벤치마크(MemBench, ImplicitMemBench, PersonaMem, PS-Bench, LoCoMo, PerMemSafe, Memora, MemOps, LongMemEval-S, MemoryAgentBench, BEAM-1M)에서 평가했으며, 전체 문맥(Full Context), DenseRAG, MemOS, Mem0, OpenViking, Graphiti 같은 텍스트 메모리 방식과 Temp-LoRA, Doc-to-LoRA, SHINE, δ-mem, LiveMem, MemoryLLM, ICAE 등 파라메트릭 메모리 방식을 베이스라인으로 비교했다. 그 결과 MemT-1.0-Flash와 MemT-1.0-Nano는 평균 점수 50.6, 47.0으로 파라메트릭 메모리 방법 중 각각 1, 2위를 차지했으며, 가장 강력한 파라메트릭 베이스라인보다 각각 12.5점, 8.9점 높았다. 다만 LongMemEval-S, BEAM-1M 등에서는 여전히 명시적 텍스트 증거를 제공하는 최강 텍스트 메모리 시스템에 못 미쳤다.

일반 능력 평가(노이즈 설정: 평가 전 무관한 정보를 메모리에 주입)에서는 MemT-1.0-Flash가 백본(DeepSeek-V4-Flash) 대비 평균적으로 거의 동일한 성능(평균 차이 0.0)을 보였고, MemT-1.0-Nano는 평균 약 1점 하락에 그쳐 일반 능력을 대체로 보존했다.

아키텍처 소거 실험에서는 갱신 단위를 토큰 단위에서 턴 단위로 바꿀 경우 평균 점수가 약 6점(46.97→40.98) 급락해, 토큰 단위 갱신이 가장 중요한 설계 요소임이 확인됐다. 학습 단계 소거에서는 CPT를 제외하면 2.1점, 후속학습을 제외하면 10.7점 하락해 후속학습의 기여가 가장 컸다.

효율성 측면에서, 128K 토큰 길이의 이력(history)에서 MemT-1.0-Nano는 전체 문맥 대비 약 1.86배의 종단 간(end-to-end) 추론 속도 향상과 약 66배의 영속 저장공간 절감을 달성했으며, 256K에서는 각각 약 3.99배, 질의 응답 첫 토큰 생성(TTFT) 기준 약 4.19배의 속도 향상을 보였다. 메모리 상태 크기는 이력 길이와 무관하게 일정(O(1))하게 유지된다.

에이전틱 코딩 응용에서는 과거 성공 궤적(41,057개)에서 추출한 1,040개의 절차적 경험을 네이티브 메모리에 저장해 SWE-bench Verified와 SWE-bench Multilingual에서 평가했다. MemT-1.0-Nano는 경험 없는 백본 대비 평균 성공률을 각각 7.6%p, 8.3%p(Harness-Triggered 설정 기준) 향상시켰고, 텍스트로 경험을 직접 주입하는 방식과 대등하거나 그 이상의 pass^3(3회 반복 모두 성공) 성능을 보였다.

한계점

고정 크기 메모리 상태는 이력 길이 N에 대해 O(1) 용량만 가지므로, 상호작용이 누적될수록 과거의 세부 정보를 유지하는 것과 최신 정보를 반영하는 것 사이에 트레이드오프가 발생하며, 이는 정밀한 회상이 필요한 과제에서 메모리 충실도(fidelity) 저하로 이어진다. 또한 로컬 메모리(상호작용 중 축적된 정보)와 하이퍼 메모리(저장·활용 능력 자체) 사이의 관계, 즉 로컬 메모리에 축적된 경험이 추가 학습을 통해 하이퍼 메모리 파라미터로 공고화될 수 있는지 등은 아직 충분히 연구되지 않은 과제로 남아 있다. 에이전틱 응용 측면에서도 현재 프레임워크는 외부에서 구축된 경험 뱅크에 의존하므로 경험의 품질과 검색 정확도에 성능이 좌우되며, 경험 저장 자체가 추가 연산 비용을 유발해 텍스트 문맥 축소가 곧바로 전체 실행 비용 절감을 의미하지는 않는다. 완전히 자율적인 지속 학습(continual learning) 체계로의 확장은 향후 과제로 남겨두었다.

시사점

MemT-1.0은 메모리를 외부 검색 시스템이 아닌 모델 연산 그 자체의 일부로 내재화함으로써, 긴 이력에 대해 일정한 추론 지연·저장 비용을 유지하면서도 파라메트릭 메모리 방식 중 최고 수준의 성능을 보여, 지속적으로 상호작용하는 개인화 에이전트나 장기 실행 에이전트에 실용적인 기반을 제공한다. 특히 절차적 경험을 텍스트 문맥이 아닌 메모리 상태에 내재화해 에이전트 행동을 안내할 수 있다는 결과는, 에이전트가 스스로의 경험을 메모리에 축적·활용하며 성능을 개선하는 "자기 진화형(self-evolving)" 에이전트로 나아가는 구체적 경로를 제시한다. 다만 메모리 충실도와 용량 확장, 하이퍼 메모리-로컬 메모리 간의 상호작용, 자율적 경험 획득 등은 추후 연구가 필요한 방향으로 남아 있다.
