Axion 1.0: Open Agent Foundation Models, Simplified

액시온 1.0: 단순화된 완전 공개형 에이전트 파운데이션 모델

중간학습(mid-training)·선호 최적화(DPO)·온폴리시 증류(OPD) 없이 2단계 지도미세조정(SFT)과 강화학습(RL)만으로 구성된 단순한 3단계 학습법으로, 상업용 프런티어 모델과 경쟁하는 완전 공개형 에이전트 파운데이션 모델 Axion 1.0을 만든 연구.

한 줄 요약

중간학습(mid-training)·선호 최적화(DPO)·온폴리시 증류(OPD) 없이 2단계 지도미세조정(SFT)과 강화학습(RL)만으로 구성된 단순한 3단계 학습법으로, 상업용 프런티어 모델과 경쟁하는 완전 공개형 에이전트 파운데이션 모델 Axion 1.0을 만든 연구.

배경 및 문제의식

최근 에이전트 모델들은 중간학습, 다단계 SFT, 역량별 특화 데이터, 선호 최적화, RL 등 점점 더 복잡한 학습 파이프라인을 쌓아가고 있어, 어떤 구성요소가 실제로 필요한지 파악하기 어렵고 재현 비용도 커진다. 또한 많은 "오픈" 모델이 가중치만 공개하고 데이터 구축·필터링·검증·프롬프트·학습 절차는 비공개로 남겨둔다. 저자들은 "강력하고 넓은 범용 에이전트 능력을 만드는 데 실제로 이 정도의 복잡성이 필요한가?"라는 질문에서 출발한다.

핵심 기여

  • 중간학습·DPO·OPD 없이 경량 SFT 2단계 + RL 1단계로만 구성된 단순한 3단계 학습 레시피로 Axion 1.0을 학습.
  • 자기완결형(self-contained) 추론과 도구 의존형(tool-dependent) 추론 각각을 위한 데이터 구축 파이프라인을 설계 — 베이스 모델이 실제로 풀 수 있는 문제를 기준으로 난이도를 강화하는 방식(모델 인식적 데이터 구축)과, 결정론적 계산에 기반해 자동으로 검증 가능한 도구 사용 과제를 만드는 방식을 결합.
  • 이 압축된 레시피만으로도 폭넓은 에이전트 벤치마크에서 강력한 성능을 보이며 일부 지표에서는 상업용 프런티어 모델과 경쁠하는 수준에 도달.
  • 데이터 구축·생성·필터링·검증·프롬프트·학습 코드까지 포함한 전체 개발 과정을 공개해, 모델 가중치뿐 아니라 개발 과정 자체의 재현성을 확보.

방법론

학습은 (1) 공개 교재·경진대회·추론 데이터셋의 시드 문제를 조합(Composition)·매개변수화(Parameterization)·범위 변경(Range Shift)·사례 분석(Case Analysis) 중 하나로 변형해, 베이스 모델이 못 푸는 문제와 풀 수 있었던 문제를 더 강화한 문제로 재구성하는 Stage I(자기완결형 추론 SFT), (2) 천문학·생물학·화학·수학·핵물리 등 공개 데이터베이스에서 필터→선택→계산→언어화의 4단계로 문제를 구성하고, 구축 시점의 데이터베이스는 차단한 채 검색·웹 방문·Python만으로 풀게 하여 도구 사용을 강제하는 Stage II(도구 의존형 추론 SFT), (3) Stage II 체크포인트에서 시작해 verl 프레임워크 기반 GRPO로, 정답이면 보상 1, 오답이면 중간 검증 목표(verification target)의 달성도에 따라 부분 보상을 주는 강화학습 순서로 진행된다. 이 과정에서 토큰 단위로 직접 주고받는 TITO(Token-In-Token-Out)로 롤아웃과 학습 간 토큰 불일치를 없애고, MoE 모델의 추론-학습 엔진 간 전문가(expert) 라우팅 차이를 재현하는 R3(Rollout Routing Replay)로 학습 안정성을 높인다.

실험 설정 및 결과

Qwen3.6-35B-A3B와 Qwen3.5-122B-A10B를 베이스로 한 Axion 1.0-35B/122B를 검색·웹 방문·학술 검색·Python이 가능한 ReAct 환경에서 Humanity's Last Exam(HLE), BioMysteryBench, SEAL-0, HiPhO, FrontierScience(올림피아드·연구) 등 6개 벤치마크로 평가했다. Axion 1.0-35B는 비슷한 규모의 Agents-A1 대비 HLE +4.6%p, SEAL-0 +5.8%p, FrontierScience Olympiad +7.0%p 우위를 보였고, Axion 1.0-122B는 FrontierScience Research에서 GPT-5.6 Sol(66.7% vs 63.3%)을 능가했다. 체크포인트별 분석에서는 SFT Stage I·II가 성능 향상의 대부분을 이끌고 RL이 HLE-130·SEAL-0 등 일부 벤치마크에서 추가 개선을 제공함을 확인했으며, 4B/9B/35B/122B 크기 비교에서는 동일한 SFT 레시피가 작은 모델에서도 효과가 있음을 보였다.

한계점

논문은 명시적인 "한계점" 절을 따로 두지 않지만 본문에서 다음을 스스로 언급한다: (1) 체크포인트별 비교는 구성요소 제거(ablation) 실험이 아니라 순차적 비교이며, 35B/122B 결과는 서로 다른 베이스 아키텍처와 RL 적용 여부가 섞여 있어 통제된 크기 확장 실험으로 해석할 수 없음. (2) RL의 효과는 벤치마크·모델 크기에 따라 일관되지 않으며(예: FrontierScience Research는 35B에서는 RL 후 오히려 소폭 하락), (3) 롤아웃 라우팅 재생(R3)이 평균적인 학습 안정성(그래디언트 노름, PPO KL 등)은 개선하지만 최대 그래디언트 스파이크와 보상 표준편차는 오히려 증가해, 간헐적 불안정성을 완전히 해소하지는 못함. (4) 외부에서 가져온 베이스라인 점수들은 평가 환경(도구 접근 범위 등)이 다를 수 있어 교차 비교가 엄격하게 통제되지 않음.

시사점

에이전트 파운데이션 모델의 역량이 반드시 점점 더 복잡해지는 학습 스택(중간학습, DPO, OPD 등의 누적)에서 나오는 것이 아니라, 모델이 실제로 풀 수 있는 난이도에 맞춰 정교하게 구성된 데이터와 명확한 '자기완결형 추론 → 도구 기반 상호작용'의 학습 진행, 그리고 그 위에 RL을 더하는 것만으로도 충분히 확보될 수 있음을 보여준다. 데이터 구축 과정 자체를 공개하는 것이 가중치 공개보다 재현성 확보에 더 본질적일 수 있다는 점도 시사한다.
