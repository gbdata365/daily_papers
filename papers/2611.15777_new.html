SO-Arena: Benchmarking the Capability Spectrum and Reliability of System One Models

SO-Arena: System One 모델의 역량 범위와 신뢰성 벤치마킹

한 줄 요약

System One(단일 forward pass로 구조화된 선택지 중 답을 고르는) 모델들의 역량 범위와 "결정 신뢰성"을 동시에 측정하는 11개 도메인, 2,919개 과제 규모의 벤치마크 SO-Arena를 제안한다.

배경 및 문제의식

System Two(긴 추론 체인을 생성하는) 모델과 달리, System One 모델은 한 번의 forward pass로 미리 정의된 선택지에 대한 확률 분포를 출력해 추론 지연을 크게 줄인다. 그러나 기존 벤치마크는 정답 레이블의 근거가 불충분하거나(ambiguous label), 난이도가 균일하게 섞여 모델 간 변별력이 낮고, 단순 정확도만 측정할 뿐 "선택지 순서가 바뀌거나 정답이 사라졌을 때도 일관되게 판단하는지"와 같은 결정 신뢰성은 평가하지 않는다는 한계가 있다.

핵심 기여

  • 40개의 공개 데이터셋·벤치마크·환경(GoEmotions, MATH500, GPQA Diamond, Mind2Web, BFCL, ToolSandbox 등)에서 수집·가공한 2,919개 과제를, 의미 이해·지식 및 추론·안전/정책 준수·근거 평가·에이전트 과제 수행의 5개 역량군 11개 도메인으로 구성하고, 참조 레이블을 사람과 LLM이 교차 검증했다.
  • 9개 도메인에 난이도 등급(Easy/Medium/Hard/Very Hard)을 부여해 모델 간 변별력을 높이고, 정적 선택 과제 외에 웹·툴 사용 등 샌드박스 기반 다단계 상호작용 과제와 "실행 기록을 올바르게 판정하는 검증자 역할" 과제도 포함했다.
  • 정확도와 별개로 "선택지 순서를 바꿔도 같은 답을 유지하는지(순서 안정성)"와 "정답이 선택지에서 빠졌을 때 이를 인지하는지(결측 인지력)"를 결합한 신뢰성 점수를 새로 정의했다.
  • 21개 모델(오픈웨이트 System One, 폐쇄형 API, System Two 기준 모델 포함)을 평가해 역량 순위와 신뢰성 순위가 크게 다를 수 있음을 보였다.

방법론

과제는 상태 s, 결정 목표 q, 선택 가능한 결과 집합 C로 구성된 (s, q, C) 형태로 정의되며, 모델은 각 결과에 대한 확률 분포를 반환한다. 출력 형식은 범주형 선택(choice), 이진 판단(noul, yes/no), 순서형 평가(score) 세 가지를 지원한다. 데이터 파이프라인은 (1) 40개 소스에서 과제 수집 후 사람·LLM 검토로 품질이 낮은 항목 제거, (2) 11개 도메인·5개 역량군으로 구성하고 정적/환경 기반 과제로 분류, (3) 가장 어려운 난이도 구간을 중심으로 도메인별 동일 가중 평균을 내는 역량 점수(Capability Score)와, 선택지 재정렬 시 안정성 및 정답 결측 인지력을 결합한 신뢰성 점수(Reliability Score)를 산출하는 3단계로 구성된다.

실험 설정 및 결과

오픈웨이트 System One 모델(0.4B~31B), 폐쇄형 결정 API, 그리고 System Two 참조 모델(GPT-6 계열) 등 21개 모델을 비교했다. System Two 모델이 전반적 역량 점수에서 가장 높았고, 최상위 System One 모델도 약 10점 차이로 뒤따랐다. 반면 System One 모델은 GPU 1장에서 과제당 0.3초 이내로 응답해 System Two보다 수십 배 빨랐다. 신뢰성 측면에서는 역량 순위와의 불일치가 뚜렷하게 나타났는데, 역량 평가에서 1위를 차지한 모델이 신뢰성에서는 7위에 그쳤고, 신뢰성이 가장 높은 두 모델은 역량 순위에서 6~8위에 불과했다. 선택지 순서 안정성은 18개 System One 모델 중 14개가 0.8을 넘었지만, 정답 결측 인지력은 모델 간 편차가 매우 커서 거의 운(chance) 수준부터 약 0.8까지 분포했으며, 모델 크기가 클수록 반드시 더 높은 것은 아니었다.

한계점

논문에 별도의 "한계점" 절은 명시되어 있지 않다. 다만 본문에서 난이도 등급은 도메인 간에 서로 보정(calibrate)되어 있지 않다고 밝히고 있어, 도메인 간 난이도를 직접 비교하기는 어렵다. 또한 과제 레이블은 사람·LLM 검토를 거쳤으나 일부는 모델이 생성한 참조값(model-derived reference)에 기반해 메타데이터에 별도로 표시해 두었다고 언급한다.

시사점

단순 정확도만으로는 System One 모델의 실제 신뢰성을 가늠할 수 없으며, 특히 실제 서비스에 빠른 의사결정 모델을 배치할 때는 정확도와 더불어 선택지 변화에도 일관된 판단을 유지하는지, 정답이 없는 상황을 인지하는지를 함께 검증해야 한다는 점을 보여준다. 이는 추후 System One 모델 개발 시 역량과 신뢰성을 동시에 고려한 학습·평가 설계가 필요함을 시사한다.
