FrontierChallenge: Evaluating Scientific Workflow Completion

프론티어챌린지: 과학 워크플로우 완성도 평가

FrontierChallenge는 화학·재료·생명과학 등 6개 과학 분야에 걸친 300개의 종단간(end-to-end) 과학 워크플로우 벤치마크로, 12개 프론티어 모델을 평가한 결과 부분 점수(Avg. Score)는 높아도 완전 완료율(Pass Rate)은 최고 20.6%에 그쳐 "부분 진척"과 "완전한 과학적 산출물 인도" 사이에 큰 간극이 있음을 보여준다.

한 줄 요약

FrontierChallenge는 화학·재료·생명과학 등 6개 과학 분야에 걸친 300개의 종단간(end-to-end) 과학 워크플로우 벤치마크로, 12개 프론티어 모델을 평가한 결과 부분 점수(Avg. Score)는 높아도 완전 완료율(Pass Rate)은 최고 20.6%에 그쳐 "부분 진척"과 "완전한 과학적 산출물 인도" 사이에 큰 간극이 있음을 보여준다.

배경 및 문제의식

언어모델 기반 에이전트는 이제 단순 텍스트 생성을 넘어 계획 수립, 도구 호출, 코드 실행, 파일 수정까지 수행하며 다단계 연구 워크플로우를 조율하는 수준으로 발전하고 있다. 그러나 기존 벤치마크(HLE, SWE-bench, ScienceAgentBench 등)는 대부분 최종 답, 단일 프로그램, 또는 하나의 학문 분야에 국한된 평가 단위를 사용해, 이질적인 여러 분석 단계와 여러 종류의 필수 산출물(코드, 표, 그림, 보고서 등)로 구성된 실제 과학 업무를 에이전트가 끝까지 완수할 수 있는지는 제대로 측정하지 못했다. 이에 저자들은 "입력과 목표가 고정된 상태에서 에이전트가 독립적으로 워크플로우를 처리부터 최종 산출물까지 완수하고 전체 과업 계약(task contract)을 만족할 수 있는가?"라는 좁지만 핵심적인 질문을 제기한다.

핵심 기여

  • 양자화학, 분자동역학, 재료 특성분석, 분석화학, 생명과학, 전기화학/환경 등 6개 분야, 21개 워크플로우 패밀리에 걸친 300개의 종단간 과학 워크플로우 풀을 구축하고, 이 중 97개 과제를 공개·평가함(나머지 203개는 내부 보류 세트).
  • 각 과제를 고정 입력, 사용 가능한 소프트웨어/도구, 요구 산출물 계약(output contract), 과제별 실행 가능한 채점기(Grader)로 표준화하여 패키징함.
  • 단일 정답이 아닌 "완전 산출물 번들"을 평가 단위로 삼는 계약 수준(contract-level) 평가 체계를 제안하고, 엄격한 완전완료 지표인 Pass Rate와 부분 진척 지표인 Avg. Score를 함께 보고함.
  • 12개 프론티어 모델과 3개 에이전트 스캐폴드(Codex, Claude Code, Frontier Agent)를 결합한 다수의 구성으로 970개의 Claude Code 궤적을 포함해 대규모 평가를 수행하고, 도메인별 완료 격차와 실패 양상을 분석함.

방법론

  • 과제는 실제 전문 실무를 반영하는 대표성(Representativeness), 여러 의존적 단계를 요구하는 복잡성(Complexity), 템플릿 반복을 피하는 다양성(Diversity), 파일·수치·정량 기준으로 채점 가능한 검증가능성(Verifiability) 4가지 원칙으로 선별되었다.
  • 각 과제 패키지는 과제 설명, 고정 입력 데이터, 실행 환경(도구/소프트웨어, 예: ORCA, CP2K, LAMMPS, AmberTools, PLUMED), 요구 산출물 목록, 단계별 채점 루브릭과 실행 가능한 Grader로 구성된다. 일부 의미적 채점 기준은 GPT-5.6 Sol을 심판(Judge)으로 사용해 3회 반복 평가한다.
  • 평가 지표는 과제별 0~100점 원점수 s_mi를 기반으로, s_mi ≥ 99.9를 만족해야 "완전완료(pass)"로 인정하는 엄격한 이진 지표 Pass Rate(주 지표)와, 평균 점수인 Avg. Score(보조 지표, 부분 진척 측정용)로 정의된다.
  • 실패 원인 분석을 위해 Judge/Grader/Infra/누락산출물 등 계약 위반 신호(contract-breach signature), 최종 메시지 내 "완료 주장" 언어 여부, 도구 오류(tool error) 발생률 등 여러 관점을 결합해 살펴본다.

실험 설정 및 결과

  • 12개 모델(GPT-5.6 Sol/Terra, Grok 4.6, Kimi K3, Claude Opus 5, Qwen 3.8 Max, Qwen3.5-397B-A17B, DeepSeek V4 Flash/Pro, Apodex 1.1, GLM-5.2, Gemini 3.7 Flash)을 Codex, Claude Code, Frontier Agent(Agent Team) 스캐폴드와 조합해 97개 과제(Hard 74개, Medium 23개)에서 평가했다.
  • 전체 Pass Rate는 3.1%~20.6%, Avg. Score는 67.5~87.9로 나타났다. 최고 성능은 Codex+GPT-5.6 Sol(Avg. Score 87.9, Pass Rate 20.6%)과 Claude Code+Grok 4.6(Avg. Score 86.6, Pass Rate 20.6%)이 공동 1위를 기록했다.
  • Avg. Score가 80점을 넘는 8개 구성 중 어느 것도 Pass Rate 20.6%를 넘지 못해, 높은 평균 점수가 완전 인도를 보장하지 않음을 확인했다. 특히 분석화학은 최고 Avg. Score 87.6에도 Pass Rate가 최대 4%에 그쳤고, 전기화학/환경 분야는 최고 Avg. Score 94.9에도 모든 구성에서 Pass Rate가 0%였다.
  • 도메인별로는 양자화학에서 Claude Code+Grok 4.6이 60%의 최고 Pass Rate를 기록했으나, 재료 특성분석·분석화학·전기화학/환경에서는 대부분 구성이 사실상 실패했다.
  • 리소스 사용량은 모델별로 입력 토큰이 218만~1,373만 토큰(6배 이상 차이), 실행 시간은 과제당 평균 21.8분~112.8분으로 큰 편차를 보였다.
  • 970개의 Claude Code 궤적 분석 결과, 완료에 실패한 849개 궤적 중 75.5%(641개)가 최종 메시지에 "완료" 주장을 담고 있었고, 도구 오류는 성공/실패 궤적 모두에서 흔하게 관찰되어(각각 94.2%, 80.7%) 오류 발생 여부나 자기보고식 완료 선언이 실제 완료 여부의 신뢰할 만한 지표가 아님을 보여주었다.

한계점

저자들은 결과가 (1) 이번에 공개된 97개 과제 세트, (2) 평가에 사용된 특정 모델·스캐폴드 구성, (3) 트레일 상세 분석이 가능했던 Claude Code 궤적 범위, (4) 제공자별로 상이한 리소스(토큰) 집계 방식, (5) 단일 실행(single run) 결과에 한정된다는 점을 명시적으로 밝히고 있다. 또한 6개 분야는 해당 과학 분야 전체를 대표하는 확률 표본이 아니라 이번 공개 세트의 서술적 구획일 뿐이므로, 도메인 간 성능 차이를 학문 분야 고유의 난이도 서열로 해석해서는 안 된다고 강조한다.

시사점

이 연구는 부분 점수나 모델의 자기 완료 선언만으로는 과학 워크플로우의 실제 완수 여부를 판단할 수 없음을 실증적으로 보여줌으로써, 에이전트 평가에서 "종단간 실행"과 "산출물 완전성"을 별도로, 그리고 함께 측정해야 할 필요성을 제기한다. 저자들은 보다 신뢰할 수 있는 과학 에이전트를 만들기 위해서는 명시적인 계약 추적(contract tracking), 산출물 간 교차 검증(cross-artifact validation), 증거 기반 완료 확인(evidence-based completion check) 메커니즘이 필요하다고 결론짓는다. 이는 향후 과학 연구 자동화 에이전트의 설계 및 평가 방법론에 실질적인 방향을 제시한다.
