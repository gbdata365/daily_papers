ProgramGym: Scaling Training Environments for Long-Horizon Program Reproduction Agents

프로그램짐: 장기 호라이즌 프로그램 재현 에이전트를 위한 학습 환경 확장

한 줄 요약

ProgramGym은 코딩 에이전트가 소프트웨어 엔지니어처럼 처음부터 프로그램을 재현(설계+구현)하도록 학습시키기 위해, 검증 가능한 학습 환경(Program-Env)과 장기 호라이즌 작업을 위한 역할 분리형 워크플로(Program-Agent)를 함께 제공하는 프레임워크다.

배경 및 문제의식

현재 코딩 에이전트들은 저장소 내 이슈를 해결(SWE-bench류)하거나 요구사항 문서로부터 저장소를 생성(NL2Repo-Bench류)하는 과제를 주로 다루는데, 두 경우 모두 에이전트가 이미 주어진 코드베이스나 명시된 기능에서 출발한다. 반면 실제 소프트웨어 엔지니어는 "무엇이 필요한지"와 "어떻게 설계해야 하는지"를 계속 탐색하며 처음부터 프로그램을 만든다. 프로그램 재현(program reproduction) 과제(ProgramBench 등)는 소스코드나 네트워크 접근 없이 사용 문서와 참조 프로그램만으로 그 동작을 재현하도록 요구하지만, 이를 위한 확장 가능하고 검증 가능한 학습 환경은 부족했고, 범용 에이전트 하네스는 탐색과 구현을 장기간 일관되게 유지하지 못했다.

핵심 기여

  1. 저장소로부터 참조 실행 파일과 런타임 샌드박스를 구축하고 블랙박스 테스트를 생성하는 피드백 기반 파이프라인 Program-Env 제안.
  2. 분석·구현·리뷰의 역할 분리형 워크플로와 컴파일 점검·실패 복구를 위한 리비전 관리 기능을 갖춘 Program-Agent 제안.
  3. ProgramBench에서 Program-Env와 Program-Agent 각각이 프로그램 재현 성능을 향상시킴을 광범위한 실험으로 입증.

방법론

Program-Env는 온라인 의존성 준비와 오프라인 컴파일을 분리하고 빌드 진단 정보를 활용해 참조 실행 파일과 런타임 샌드박스를 반복적으로 복구(repair)하며 구축한다. 테스트 생성은 기능 모듈별로 병렬적으로 진행되며, 프로그램 분석을 통해 아직 탐색되지 않은 동작을 표적으로 삼고 검증 피드백을 반영한다. 이 파이프라인으로 C, C++, Go, Rust 전반에 걸쳐 1,648개의 학습 환경을 구축했으며, 각 환경은 참조 실행 파일, 런타임 샌드박스, 사용 문서, 블랙박스 동작 테스트 모음을 제공한다. Program-Agent는 참조 프로그램 탐색에서 얻은 증거를 먼저 기록하고, 구현과 동작 리뷰를 별도의 세션에서 번갈아 수행하는 역할 분리형 반복 워크플로를 사용한다. 지속적인(persistent) 기록이 여러 라운드에 걸쳐 요구사항을 전달하고, 오프라인 빌드 점검과 검증된 체크포인트가 리비전과 실패 복구를 지원한다.

실험 설정 및 결과

ProgramBench에서 Program-Env로 생성한 트라젝토리로 파인튜닝하면 Qwen3.8-27B의 성능이 34.87%에서 42.84%로 향상되었다. Program-Agent를 추가로 적용하면 베이스 모델과 SFT 모델이 각각 55.71%, 56.25%까지 올라가며, 이는 Claude Opus 4.7 등 일부 플래그십 모델을 능가하는 수준이다. 행동 분석에서는 Program-Agent가 Claude Code 하네스에 비해 모델이 "읽기(read)"와 "git" 행동을 더 많이 사용하도록 유도해, 에이전트를 탐색과 리비전 중심으로 재구성함을 보였다.

한계점

논문 결론부에는 별도의 명시적 한계점 절이 없다. 본문에서 확인되는 범위상의 특징으로는, 학습 환경이 C, C++, Go, Rust 네 언어로 구성된 1,648개 저장소에 한정되어 있다는 점이 있다.

시사점

이 연구는 코딩 에이전트 훈련의 초점을 "이슈 해결"이나 "문서 기반 생성"에서 "처음부터 요구사항을 발견하고 시스템을 설계하는" 더 근본적인 소프트웨어 엔지니어링 역량으로 확장하며, 검증 가능한 환경 구축과 장기 호라이즌 워크플로 설계가 함께 필요함을 보여준다.
