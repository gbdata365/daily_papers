Self-Generated Feedback Destabilizes Test-Time Training: A Causal Decomposition of Long-Horizon Adaptation

자가 생성 피드백이 테스트시점학습을 불안정화시키는 원인에 대한 인과적 분해 분석

추론 중 모델이 자신이 생성한 텍스트로부터 계속 학습하는 "닫힌 루프(Closed Loop)" 설정에서는 128K 토큰 규모의 장기 스트림에서 독립적인 실제 텍스트에 대한 예측 성능이 꾸준히 악화되며, 저자들은 생성-피드백·주의집중(attention) 내 읽기·가중치에 저장되는 쓰기라는 세 경로를 분리하는 인과적 비교를 통해 그 원인을 규명하고, 업데이트를 영구 반영하기 전에 독립적인 실제 텍스트로 검증하는 Settlement 기법으로 손상을 크게 줄인다.

한 줄 요약

추론 중 모델이 자신이 생성한 텍스트로부터 계속 학습하는 "닫힌 루프(Closed Loop)" 설정에서는 128K 토큰 규모의 장기 스트림에서 독립적인 실제 텍스트에 대한 예측 성능이 꾸준히 악화되며, 저자들은 생성-피드백·주의집중(attention) 내 읽기·가중치에 저장되는 쓰기라는 세 경로를 분리하는 인과적 비교를 통해 그 원인을 규명하고, 업데이트를 영구 반영하기 전에 독립적인 실제 텍스트로 검증하는 Settlement 기법으로 손상을 크게 줄인다.

배경 및 문제의식

테스트시점학습(Test-Time Training, TTT)은 추론 중에도 모델 파라미터(fast weights) 일부를 계속 갱신해 긴 문서·스트림·장시간 에이전트 작업에서 전체 이력을 어텐션에 담아두는 비용을 줄이는 기법이다. 그러나 모델이 자기 자신이 생성한 텍스트로부터 학습을 이어가면, 현재 가중치가 다음 학습 청크를 생성하고 그 청크로부터 또 가중치가 갱신되는 피드백 루프가 발생한다. 생성된 청크에 대한 손실(loss)이 낮아지는 것은 그 업데이트가 "자신이 만든 입력"에 잘 맞는다는 뜻일 뿐, 다른(독립적인) 텍스트에 대한 예측력이 향상되었다는 의미는 아니다. 저자들은 이 지속적 자가 쓰기(self-writing)가 실패하는 원인이 피드백 루프의 어느 부분에 있는지를 묻는다.

핵심 기여

  1. 장기 호라이즌 실증: TTT-E2E 세 가지 규모(125M, 760M, 3B)와 일반 Adam 옵티마이저로 Qwen3-4B를 갱신하는 설정 모두에서, 128K 토큰 스트림에 걸쳐 생성 텍스트 업데이트를 유지하면 독립적인 실제 텍스트 예측이 악화됨을 보였다(외부 텍스트 노출 경계도 함께 분석).
  2. 인과적 분해(causal decomposition): Fixed Generation(생성기 고정), Recorded Replay(녹화된 텍스트 재생), 짝지은 단일 업데이트(paired one-update) 비교를 통해 (a) 미래 학습 텍스트 변화, (b) 어텐션상의 읽기, (c) 가중치에 저장되는 쓰기라는 세 경로의 기여를 분리했다. 손상은 소수의 궤적(trajectory)에 집중되는 상태 의존적(state-dependent) 성격을 가진다.
  3. 전이 기준(transfer criterion) 제시: 소스 적합도(source fit)나 반복(repetition) 통계만으로는 업데이트를 유지할지 판단할 수 없음을 보이고, 후보 상태 전체를 독립적인 실제 텍스트로 검증하는 Settlement 방법을 제안했다.

방법론

  • TTT-E2E 구조: 슬라이딩 윈도우 Transformer의 마지막 1/4 레이어 MLP 블록을 fast weight로 삼아 1024토큰 청크마다 한 번의 클리핑된 경사 업데이트를 수행한다. 비교 대상 정책은 Closed Loop(생성 후 업데이트 유지), Writes Off(생성 텍스트는 읽지만 업데이트는 버림, 주통제군)이다.
  • Fixed Generation: 동결된 초기 가중치 W0가 모든 생성 청크를 만들고, 별도의 학습 모델이 그 텍스트로부터 학습한다. 즉 학습은 계속되지만 생성기에는 피드백이 전달되지 않도록 차단한다.
  • Recorded Replay: 동일하게 녹화된(저하된) 토큰 스트림을 서로 다른 수신 모델에 두 번 흘려보내, 한 번은 읽기만(업데이트 없음), 한 번은 읽기+쓰기(업데이트 적용)로 처리해 "어텐션상의 손상"과 "가중치에 저장되는 손상"을 분리한다.
  • 짝지은 단일 업데이트 비교(paired one-update): 동일한 가중치·어텐션·텍스트 상태에서 복사본 하나는 업데이트를 유지하고 다른 하나는 버린 뒤, 생성 소스 자체에 대한 적합도와 다음 실제 텍스트에 대한 예측력을 각각 측정한다.
  • 그래디언트 충돌 신호: 생성 청크의 그래디언트와 다음 실제 텍스트의 그래디언트 간 코사인 유사도, 그리고 1차 손실 예측값을 계산해 어떤 업데이트가 해로울지 사전에 랭킹화할 수 있는지 검증한다.
  • Settlement: 현재 fast weight W에서 후보 변화량 δ를 더한 임시 상태 W+δ를 만들고, 아직 학습에 쓰이지 않은 독립적인 실제 텍스트 q에서 A(δ)=L(q;W)-L(q;W+δ) ≥ 0일 때만 δ를 확정(commit)하는 순차적 검증 절차(Algorithm 1)이다. 생성/실제 텍스트 라벨을 직접 이용하지 않고, 후보가 실제로 성능을 개선하는지만으로 판단한다.

실험 설정 및 결과

  • 데이터/모델: DCLM으로 사전학습 후 PG-19(책) 장문 맥락으로 추가 학습한 TTT-E2E 125M/760M/3B 모델, 그리고 Qwen3-4B의 기존 feed-forward 가중치에 Adam을 직접 적용한 설정. 6권의 책, 5개 시드, 128K 토큰 호라이즌을 기본 평가 단위로 사용.
  • 장기 손상 확인: Writes Off 대비 Closed Loop의 실제 텍스트 NLL 악화량(H)은 125M에서 +3.01, 760M에서 +6.00, 3B에서 +0.40 nats로 모든 구간에서 신뢰구간이 0을 배제했다. 손상은 초기 평가 구간(8K+8K)에서는 거의 없다가 긴 호라이즌에서 누적적으로 커졌다.
  • Fixed Generation 효과: 생성기를 고정하는 것만으로 Closed Loop 손상의 98.3%(125M), 98.8%(760M)가 제거되어, 피드백(미래 학습 텍스트 변화)이 손상의 핵심 경로임이 확인되었다.
  • Recorded Replay 효과: 125M에서 저하된 텍스트를 읽기만 해도 1.606 nats의 손상이 생기고, 거기에 업데이트까지 반영하면 3.874 nats로 늘어나(추가 비용 2.268 nats). 3B에서도 쓰기로 인한 추가 비용이 .193 [.104, .327] nats로 유의했다.
  • 단일 업데이트 비교: 업데이트를 유지하면 소스 청크 자체의 손실은 항상 낮아지지만(적합도 향상), Closed Loop 이력 하에서는 다음 실제 텍스트 NLL이 평균 +.0381 증가했다. 그래디언트 코사인 유사도는 -.502~-.788로 모두 음(상충)이었고 측정된 손상과 유의하게 상관되었다.
  • 완화 요인: 디코딩 온도/반복 페널티 조정, 일정 간격으로 실제 텍스트를 섞는 것(31% 실제 텍스트 삽입 시 손상 약 94% 감소), 주기적 fast weight 리셋(8청크마다 리셋 시 손상 94.2% 제거하지만 적응 이득의 55.9%도 함께 사라짐) 등이 손상 속도나 크기를 바꾸지만 "어떤 업데이트가 안전한지"는 식별하지 못했다.
  • Settlement 성능: 125M에서 평균 endpoint 격차 .07 nats, 760M에서 -.02 nats로 Writes Off 수준까지 손상을 억제하면서도 실제 텍스트 적응 이득은 유지했다(125M에서 936개 생성 후보 중 22개만 수용). WebShop 에이전트 과제에서는 정확 성공률을 Closed Loop .1053에서 Settlement .1853으로, ALFWorld에서는 미확인 과제 성공률을 Closed Loop 18.7~27.6%에서 Settlement 90~91%로 끌어올렸다.

한계점

  • 손상은 평균적으로 완만해 보여도 실제로는 소수의 "소스-수신자" 궤적에 집중되는 이질적(heterogeneous) 성격을 가져, 반복도나 스트림 위치만으로는 어떤 패시지가 위험한지 사전에 식별할 수 없었다.
  • 디코딩 전략, 반복 페널티, 주기적 리셋 등은 손상의 속도나 크기를 바꿀 뿐 안전/위험 업데이트를 구분하는 신뢰할 기준을 제공하지 못한다.
  • Settlement는 독립적인 실제 텍스트(검증용 패시지)가 주기적으로 도착한다는 전제에 의존하며, 검증 텍스트가 없거나 라벨이 심하게 오염된 극단적 상황에서의 견고성은 별도로 다뤄지나(부록 F) 일반적 적용 한계는 논문에 명시되지 않음.
  • 실험은 TTT-E2E와 Qwen3-4B/Qwen3.8-27B에 대한 Adam 기반 업데이트, 그리고 WebShop/ALFWorld 두 에이전트 벤치마크에 한정되며, 더 넓은 아키텍처·과제 범주에 대한 일반화 여부는 논문에 명시되지 않음.

시사점

자가 생성 텍스트로부터 지속적으로 학습하는 장기 추론 에이전트나 TTT 시스템을 설계할 때, 생성 텍스트에 대한 업데이트를 무조건 유지하는 것은 위험할 수 있으며, 업데이트를 커밋하기 전에 독립적인 실제(또는 검증 가능한) 신호로 성능을 확인하는 절차(Settlement류 기법)가 장기 안정성과 적응 이득을 동시에 확보하는 데 효과적인 안전장치가 될 수 있음을 시사한다. 이는 언어모델 프리트레이닝 단계의 "모델 붕괴(model collapse)" 논의를 단일 추론 스트림 내 피드백 루프로 확장한 것으로, 에이전트의 행동-보상 루프(WebShop, ALFWorld)에서도 동일한 검증 원리가 과제 성공률을 크게 개선함을 보여 실용적 적용 가능성을 뒷받침한다.
