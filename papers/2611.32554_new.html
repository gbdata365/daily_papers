PartAgent: Agentic 3D Part Segmentation via Expert Integration and Closed-Loop Refinement

PartAgent: 전문가 통합과 폐루프 정제를 통한 에이전틱 3D 부품 분할

PartAgent는 별도의 학습 없이 기존 3D·2D 전문가 모델을 결합하고, VLM(비전-언어 모델)이 분할 결과를 관찰·검증하며 반복적으로 고쳐나가는 에이전트형 3D 부품(part) 분할 프레임워크다.

한 줄 요약

PartAgent는 별도의 학습 없이 기존 3D·2D 전문가 모델을 결합하고, VLM(비전-언어 모델)이 분할 결과를 관찰·검증하며 반복적으로 고쳐나가는 에이전트형 3D 부품(part) 분할 프레임워크다.

배경 및 문제의식

3D 객체를 의미 있는 부품 단위로 나누려면 기하학적 구조 정보와 의미적 맥락을 함께 고려해야 한다. 기존 3D 전문가 모델은 공간적으로 근거 있는 영역(region)을 제안하지만 하나의 구성요소를 여러 조각으로 쪼개거나 여러 구성요소를 하나로 묶는 오류를 낼 수 있고, 2D(이미지) 전문가 모델이 주는 시점별 의미 정보는 서로 불일치할 수 있다. 또한 두 정보를 결합해 만든 초기 분할 결과도 불완전할 수 있어 추가적인 점검과 수정이 필요한데, 기존 방법들은 이런 통합과 반복적 교정 과정을 체계적으로 다루지 못했다.

핵심 기여

논문은 세 가지 기여를 제시한다. - 학습이 필요 없는 에이전트 프레임워크: 고정된(frozen) 2D·3D 전문가 모델을 결합해 VLM이 주도하는 의사결정으로 부품 분할을 구성하고 반복 개선한다. - 구조-의미 전문가 통합(Structural–Semantic Expert Integration, SSEI): 다중 시점의 2D 의미 예측을 3D 전문가가 제안한 영역에 매핑해 영역을 정제하고, 여러 단위(granularity)의 후보 분할을 구성한다. - 관찰 기반 폐루프 분할 정제(Observation-Driven Closed-Loop Partition Refinement, CLR): 현재 분할 상태와 근거를 관찰해 검사(Inspect), 2D 마스크 보정(Repair 2D), 재구성(Compose), 재선택(Reselect), 종료(Finish) 중 하나의 행동을 선택하고, 제안된 변경을 검증한 뒤 반영 여부를 결정한다.

방법론

먼저 SSEI 단계에서 3D 전문가(P3-SAM)가 제안한 영역을 공간적 "뼈대"로 삼고, 여러 시점에서 얻은 2D 의미 분할 마스크를 이미지-표면 대응 관계를 통해 메쉬 표면에 투영해 영역을 세밀하게 정제한다(Semantic Leaf Refinement). 이렇게 얻은 세분화된 영역들을 다양한 조합으로 묶어 여러 단위의 후보 분할을 구성하는 Mask DAG(트리/DAG 구조)를 만들고, 그중 하나를 초기 분할로 선택한다. 이후 CLR 단계에서는 VLM이 투영된 분할 결과, 기하 렌더링, 의미 예측을 함께 살펴보고 어디를 점검할지, 무엇을 수정할지, 제안된 변경이 결과를 개선하는지를 판단한다. 2D 마스크를 보정하는 경우에는 보정된 마스크를 다른 시점의 마스크와 다시 결합해 SSEI의 통합 절차를 재사용하고, 변경 전후를 비교하는 별도의 VLM 검증을 통과해야 분할에 반영된다. 각 행동의 성공·실패 결과는 다음 행동 선택에 참고된다. PartNetE처럼 포인트 클라우드로 주어지는 경우에는 메쉬 인접 관계와 픽셀-표면 대응 대신 점 인접 관계와 픽셀-포인트 대응을 사용한다.

실험 설정 및 결과

PartObjaverse-Tiny 및 PartObjaverse-Tiny-WT(각 200개 객체 전체)와 3DCoMPaT200·PartNeXt·PartNetE(API 비용 관리를 위해 범주 균형을 맞춰 각 500개 객체를 샘플링)에서 평가했다. 주요 지표는 Mask Match mIoU(각 정답 부품 마스크와 가장 잘 맞는 예측 후보 마스크의 IoU 평균)이며, 보조적으로 전체 후보 분할 단위를 평가하는 Partition Match mIoU도 사용했다. 3D 전문가로 P3-SAM, 2D 전문가로 GPT-Image-2.5, 추론·검증 VLM으로 GPT-6.1-sol을 사용한 기본 설정에서 PartAgent는 PartObjaverse-Tiny-WT에서 68.41 mIoU로 경쟁 방법 중 최고 성능(59.88)보다 8.53점 높았고, 4개 데이터셋 평균 69.36으로 경쟁 방법 평균(62.08) 대비 7.28점 앞섰다. 소거 실험(ablation)에서는 SSEI와 CLR 두 모듈이 함께 있을 때 가장 좋은 성능을 보였고(3D 전문가 단독 58.51 → SSEI만 적용 시 65.11/67.60 → SSEI+CLR 65.98/68.94), Semantic Leaf Refinement와 Mask DAG 각각을 제거하면 성능이 떨어졌다(특히 Mask DAG 제거 시 손실이 더 큼). P3-SAM, PartSAM, PartField 등 서로 다른 3D 전문가에 적용해도 모두 성능이 개선되었으며, 2D 전문가와 VLM을 다른 모델로 교체해도(GPT-Image-2, SAM3, GPT-6, GPT-5.6, Qwen3.5-9B 등) 효과가 유지되었다. 또한 정제 루프를 반복할수록(최대 6회) mIoU가 점진적으로 상승함을 보였다(67.60 → 68.94).

한계점

논문은 별도의 "한계점" 절을 명시하지 않았다. 다만 실험 설계상 PartNeXt·3DCoMPaT200·PartNetE에서는 API 비용 문제로 전체 데이터셋이 아닌 500개 객체 표본만 평가했다고 밝히고 있어, VLM을 반복적으로 호출하는 에이전트 구조 특성상 추론 비용과 호출 횟수가 적지 않음을 시사한다. 또한 성능이 기반이 되는 고정된 2D·3D 전문가 모델과 VLM의 품질에 의존한다는 점도 실험(전문가·VLM 교체 비교)을 통해 간접적으로 드러난다.

시사점

PartAgent는 새로운 모델을 처음부터 학습시키는 대신, 이미 존재하는 2D·3D 전문가 모델의 강점을 결합하고 VLM의 관찰·검증 능력을 활용해 반복적으로 품질을 끌어올리는 "에이전트형 후처리" 접근이 3D 지각 작업에서도 효과적일 수 있음을 보여준다. 이는 고비용의 재학습 없이도 기존 파이프라인의 성능을 끌어올릴 수 있는 실용적 방향으로, 3D 인식·생성 파이프라인에 VLM 기반 반복 검증 루프를 결합하는 후속 연구에 참고가 될 수 있다.
