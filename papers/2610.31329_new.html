WeVisOne-VL: Unified Visual Perception from Objects to Pixels

위비스원-VL: 객체부터 픽셀까지 통합된 시각 인지

Tencent WeChat Vision 팀이 개발한 WeVisOne-VL은 객체 탐지·지칭 표현 localization·카운팅·OCR 같은 "객체 단위" 작업과 분할·매팅 같은 "픽셀 단위" 작업을 하나의 자연어 인터페이스와 구조화된 다음 토큰 예측으로 통합한 비전-언어 모델(VLM)이다.

한 줄 요약

Tencent WeChat Vision 팀이 개발한 WeVisOne-VL은 객체 탐지·지칭 표현 localization·카운팅·OCR 같은 "객체 단위" 작업과 분할·매팅 같은 "픽셀 단위" 작업을 하나의 자연어 인터페이스와 구조화된 다음 토큰 예측으로 통합한 비전-언어 모델(VLM)이다.

배경 및 문제의식

지난 10년간 컴퓨터 비전은 YOLO·DETR 같은 전통적 탐지/분할 모델에서 Grounding-DINO·SAM 같은 오픈월드 인지 모델, 그리고 최근의 대규모 VLM으로 발전해 왔다. 그러나 성능과 효율을 함께 고려하면 현재 모델들은 여전히 실제 배포에 부족한 수준이다. 존재하지 않는 객체를 환각으로 만들어내거나, 낯선 표현을 접하면 사용자 의도를 잘못 해석하거나, 눈에 잘 띄지 않는 인스턴스를 놓쳐 재현율(recall)이 떨어지는 문제가 흔하다. 저자들은 "신뢰할 수 있는 시각 인지 시스템"이라는 목표 아래, 객체 수준 인지와 픽셀 수준 인지를 하나의 모델·하나의 자연어 인터페이스로 통합할 필요성을 제기한다.

핵심 기여

  1. 통합 데이터 엔진(WDE, WeVisOne-VL Data Engine): 지식 그래프를 매개로 카테고리 개념과 합성적 지칭 표현을 정리하고, 복수의 탐지·분할 전문가 모델의 예측을 시각-언어 검증으로 통합해 1억 장 이상의 이미지, 약 36억 개의 바운딩박스 수준 주석을 구축했다. 분할 마스크뿐 아니라 연속적인 알파 매트(투명도) 주석까지 자동으로 확장하는 전용 매팅 파이프라인도 포함한다.
  2. 통합 모델 설계: Qwen3-VL을 백본으로, 좌표를 압축 표현하는 전용 토큰(<0>~<1000>)과 인스턴스 표현을 나타내는 특수 <OBJ> 토큰을 도입했다. <OBJ> 토큰의 은닉 상태를 경량 픽셀 디코더(약 960만 파라미터)에 전달해 별도의 대형 분할 모델(예: SAM) 없이도 마스크와 알파 매트 같은 밀집 예측을 생성한다.
  3. 3단계 커리큘럼 SFT + 혼합 작업 RL 학습 파이프라인: 작업 정렬 → 고해상도/고밀도 인지 확장 → 토큰-픽셀 교차 학습의 3단계 지도미세조정 후, 불확실성이 높은 샘플을 선별해 GRPO 기반 강화학습으로 그라운딩 품질을 직접 최적화한다.
  4. 2B/4B 두 가지 크기의 오픈소스 공개: 30개 이상의 벤치마크에서 객체/픽셀 수준 과제 모두 선도적 성능을 보이며, 대상이 없는 질의에 대한 거부(rejection) 능력도 함께 확보했다.

방법론

  • 작업 형식화: 탐지, 지칭 localization, 포인팅, 카운팅, OCR, 분할/매팅 등 모든 시각 과제를 구조화된 다음 토큰 예측으로 통일했다. 좌표는 정규화된 <0>~<1000> 토큰으로 표현하고, 대상이 이미지에 없으면 좌표 필드를 None으로 채워 "거부"를 직접 학습시킨다. 분할·매팅처럼 픽셀 단위 출력이 필요한 경우 바운딩박스 바로 뒤에 <OBJ> 토큰을 추가로 생성한다.
  • 모델 구조: Qwen3-VL 비전 인코더가 이미지를 인코딩하고, 언어모델이 자기회귀적으로 구조화된 응답을 생성한다. 픽셀 단위 과제에서는 <OBJ> 토큰마다 경량 디코더가 호출되며, 이 디코더는 (1) ViT의 다중 레벨 특징을 정리하는 시각 특징 어댑터, (2) 박스 사전 정보를 활용하는 Deformable DETR 스타일의 박스 가이드 쿼리 디코더, (3) 쿼리와 시각 특징을 융합해 전체 해상도의 마스크/알파 매트를 생성하는 인스턴스 조건부 밀집 예측 단계로 구성된다. 매팅에는 세밀한 경계와 부분 투명도를 위한 코스-투-파인(coarse-to-fine) 정제 모듈이 추가된다.
  • 데이터 엔진: 지식 그래프 기반 개념 발굴 → SAM3/자체 오픈보캐뷸러리 탐지기 + Qwen3-VL 검증으로 탐지·지칭 주석 생성 → SAM2로 마스크 생성 → BiRefNet·MatAnyone2 전문가 예측과 자체 학습한 매팅 어노테이터로 알파 매트 생성 → 모델 오류를 리뷰해 데이터 수집·보정에 피드백하는 반복적 정제 과정을 거친다. 모호한 부정(negative) 질의를 신중히 검증해 하드 네거티브/하드 포지티브 샘플도 구성한다.
  • 학습 파이프라인: SFT 1단계(작업 정렬, 어휘 확장, 비전 인코더 동결), 2단계(해상도·박스 수 확장, 전체 파인튜닝), 3단계(세그멘테이션 워밍업 후 토큰-픽셀 교차 학습, 이어서 매팅 전용 파인튜닝)로 진행된다. 이후 SFT 모델의 불확실성(보상 평균·분산 기반 점수)이 높은 약 14만 개 샘플을 선별해, Hungarian 매칭 기반 IoU 세제곱 보상으로 GRPO 강화학습을 수행한다.

실험 설정 및 결과

  • 객체 수준 5개 과제(탐지, 지칭 탐지, 카운팅, 포인팅, OCR)와 픽셀 수준 2개 과제(지칭 분할, 이미지 매팅)에 대해 30개 이상 벤치마크로 평가했으며, Qwen3-VL/Qwen3.5 계열과 Rex-Omni, LocateAnything 등 전문 그라운딩 모델을 주요 비교 대상으로 삼았다.
  • 탐지: COCO, LVIS, Dense200(고밀도), VisDrone(드론 촬영)에서 비슷한 규모의 VLM 대비 평균 F1이 일관되게 우수했고, 특히 밀집·소형 객체가 많은 Dense200·VisDrone에서 격차가 크게 벌어졌다.
  • 지칭 탐지: RefCOCOg, HumanRef, RefAdv, PR-Bench, DVGBench, Ref-L4 및 자체 구축한 WeRef-Bench(영어·중국어 2,880개 질의)에서 단일/다중/부재 타겟 전 상황에 걸쳐 기존 VLM을 상회했다.
  • 카운팅: CountQA, PixMo-Count, CLOC, KubriCount, MixCount 전 벤치마크·분할에서 최고 정확도를 기록(예: PixMo-Count test 89.6%).
  • 포인팅: PointBench, PixMo-Points 및 탐지 기반 포인팅 변환 평가에서 최상위 성능.
  • OCR: HierText, ICDAR2015, TotalText, SROIE에서 전문 OCR 시스템(PP-OCRv5)과 범용 VLM을 모두 상회.
  • 지칭 분할: RefCOCO/+/g, ReasonSeg, Ref-ZOM에서 LISA·GSVA·UniPixel·Youtu-VL 등 기존 분할 특화 모델 대비 우수했으며, 특히 Ref-ZOM의 부재 타겟 거부율에서 큰 차이를 보였다(예: 4B 모델 거부율 86.0%).
  • 매팅: P3M-500-NP, AM-2K, PPM-100(박스 프롬프트) 및 자체 WeRefMat(카테고리/지칭 프롬프트)에서 Matte Anything, SAM2-Matting 계열보다 낮은 오차(MAD/MSE/SAD 등)를 기록.
  • 정성적 분석에서는 먼지에 가려진 먼 거리 코끼리 탐지, 인접 인스턴스 분리, 서수·속성·관계 기반 지칭 표현 해석, "쌍(pair)"과 같은 집계 단위 카운팅, 대상 부재 질의의 올바른 거부 등에서 베이스라인 대비 강점을 보였다.

한계점

  • 범용 목적 학습 데이터 비중이 제한적이어서 기반 모델(Qwen3-VL) 대비 일반적인 범용 능력이 저하될 수 있다.
  • 추론 효율을 위해 Chain-of-Thought 추론 없이 구조화된 출력을 바로 생성하도록 학습해, 복잡한 추론 과제 처리 능력에 제약이 있을 수 있다.
  • 현재는 단일 턴(single-turn) 예측에 한정되어 있으며, 다중 턴 도구 상호작용을 통한 점진적 시각 이해 개선(에이전트 프레임워크 결합)이 향후 과제로 남아 있다.
  • 벤치마크의 질의는 대체로 명확하고 잘 정의되어 있지만, 실제 사용자 지시는 모호하고 머뭇거리는 경우가 많아, 이런 실세계 복잡성에 대응하는 강력한 의도 추론 능력이 아직 부족하다.

시사점

WeVisOne-VL은 객체 단위 로컬라이제이션과 픽셀 단위 밀집 예측(분할·매팅)을 별도의 전문 모델(예: SAM) 없이 하나의 VLM과 경량 디코더로 통합함으로써, "포인트부터 박스, 마스크, 알파 매트까지" 사용자가 원하는 임의의 세분화 수준으로 응답하는 실용적인 시각 인지 시스템의 가능성을 보여준다. 특히 대상이 없는 질의를 정확히 거부하는 능력과 밀집/혼잡 장면에서의 높은 재현율은 콘텐츠 제작, 산업 검사, 자율주행, 임베디드 지능 등 실제 배포 환경에서 VLM의 신뢰성을 높이는 데 중요한 시사점을 제공한다. 데이터 엔진(지식 그래프 기반 개념 정리, 다중 전문가 검증, 모델 오류 피드백 루프)과 불확실성 기반 RL 샘플링 전략은 향후 다른 통합 멀티모달 인지 모델 구축에도 참고할 만한 방법론적 틀을 제시한다. 모델과 코드, 가중치가 오픈소스로 공개되어 커뮤니티의 후속 연구를 촉진할 것으로 기대된다.
